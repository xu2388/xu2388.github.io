关于

内容来自我和 AI 助手（DeepSeek、豆包、WorkBuddy）一年多的科研与学习对话，由 WorkBuddy 整理。 原则只有一条：原始信息不删减、思考过程原样保留、每条结论尽量能溯源到具体对话。

纯静态站点，零依赖，托管于 GitHub Pages。新增内容：把 Markdown 放进 notes/（带 frontmatter 的学科笔记）或 articles_src/（长文章）， 跑一遍 ./publish.sh 即可自动收录、归类、生成学科页与搜索索引。
