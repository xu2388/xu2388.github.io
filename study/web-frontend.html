Web开发/前端

Django 路由、模板与 ORM · 共 1 篇

  • Web开发 · Django 路由、ORM 与模板Django 把一次请求拆成 URL 解析、视图处理、模型取数、模板渲染四段，MTV 是它对 MVC 的改写。路由用 path 与 include 分层，命名后可用 reverse 反向生成；ORM 以模型类描述表结构，迁移文件是 Python 脚本而非 SQL；QuerySet 惰性求值，filter 与 Q 对象负责筛选，select_related 与 prefetch_related 负责减少查询次数。模板靠 extends 与 block 继承，POST 表单必须带 CSRF token。多数报错可按「路由名、模板路径、迁移状态」三步定位。
