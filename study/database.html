数据库/MySQL

SQL、索引、事务与范式 · 共 7 篇

  • 数据库 · SQL 查询、视图、触发器与完整性安全性围绕从查询到安全保护的链条梳理结论：SELECT 子句按 FROM、WHERE、GROUP BY、HAVING、ORDER BY 次序执行，故「不计不及格」只能写在 WHERE、「门数不小于四」只能写在 HAVING；自然连接会匹配并合并全部同名列，两个同名列同时相等才保留，因而李四一行被排除；NOT IN 在子查询含空值时整体返回空集，NOT EXISTS 免疫；「每门课至多 60 人选修」可用断言配 ALL 表达，但 MySQL 不支持断言，须改用 BEFORE 触发器加 SIGNAL 拦截；收回用 REVOKE 加 CASCADE。
  • 数据库 · 事务、并发控制与恢复事务是不可分割的操作序列，ACID 分别由锁与日志支撑。并发带来丢失更新、脏读、不可重复读与幻读，四级隔离级别划定允许范围，三级封锁协议与两段锁保证可串行化，意向锁与间隙锁细化封锁粒度。MVCC 用隐藏事务号与回滚指针串成版本链，由 ReadView 判定可见性。redo 重放已提交修改，undo 支持回滚与旧版本，WAL 要求日志先落盘，恢复按分析、重做、回滚推进。文末对原料结论作限定与勘误。
  • 数据库 · 关系代数与 SQL 互译关系代数与 SQL 是同一件事的形式层与实现层。五种基本运算为并、差、笛卡尔积、选择、投影，交、连接、除均由它们导出。翻译规则可机械执行：选择落 WHERE，投影落 SELECT，笛卡尔积落 FROM 多表，连接落 JOIN ON，并差交由集合运算承担。除运算有两种写法，双重 NOT EXISTS 对应全称语义，分组计数对应包含。外连接补空值，WHERE 与 ON 的位置决定它是否退化为内连接。
  • 数据库 · 函数依赖、候选码与范式分解从函数依赖与 Armstrong 公理切入，梳理完全/部分/传递三个层次，给出属性闭包算法与按 L/R/LR 分类速判候选码的通用步骤；以 F={A→B, A→C, D→A}、F={BCD→A, A→C} 两组字母算例演示候选码由「AD」修正为「D」、由「仅 BCD」补全为「ABD、BCD」；沿 1NF→2NF→3NF→BCNF 逐级给出「在防什么」对照，并用学生-选课-课程与图书-作者-出版社两组语义算例演示保持依赖且无损的 3NF 分解，同时整理 chase 表格法与规范化取舍。
  • 数据库 · 索引原理与查询优化索引以写代价换取定位能力，B+ 树因高扇出、数据集中在叶子、叶子成链而适配磁盘。InnoDB 以主键建聚簇索引，二级索引叶子存主键，取整行需回表，查询列全在索引内即覆盖索引。复合索引按最左前缀匹配，范围列会截断后续列；列上函数、隐式转换、前导通配符是失效写法。IN 与 EXISTS 差别在值匹配与存在判断，NOT IN 遇空值整体为空。执行计划看扫描行数与回表次数，优化是否成立须对照实验验证。
  • 数据库与 MySQL · 复习与实操笔记以学生选课数据库的四个实验为主线，梳理 MySQL 8.0 的安装配置与排错、Navicat 图形化操作、建表与约束、触发器、索引与视图、交互式 SQL 查询及用户权限管理，并归纳常见报错的成因与解决办法。
  • 数据库原理 · 关系运算、SQL 查询与权限管理以关系模型的形式化定义为主线，梳理关系、元组、属性、域与候选码、主码、外码的术语层级及三类完整性约束；给出选择、投影、连接、除法的运算对照与五种基本运算的完备性，用象集完整推演 R÷S 得 {201,202} 的算例；归纳「书写时先连接再选择投影最保险、执行层应先选择后投影」的顺序结论，并整理 SQL 侧的等值连接写法、WHERE 与 HAVING 的分工、DELETE、DROP、TRUNCATE 的五项区别与库到行的授权粒度。
