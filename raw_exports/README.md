# 把导出的对话放这里

这个文件夹用来收集你从豆包 / DeepSeek 导出的科研对话。WorkBuddy 会读取这里的内容，
自动抽取科研相关的问题与结论，归纳成博客文章。

## 支持的格式
- **Markdown**（.md）—— DeepSeek「复制为 Markdown」、或导出工具产出的最方便
- **纯文本**（.txt）—— 复制粘贴的对话
- **图片**（.png / .jpg）—— 豆包「导出为图片」的对话截图（我会用 OCR 提取文字）
- **JSON**（.json）—— DeepSeek「导出所有历史对话」的官方备份

## 怎么导出（简述）
- **DeepSeek**：头像 → 设置 → 数据管理 → 导出所有历史对话（7 天内下载）
- **豆包**：对话页右上角「分享」→ 导出为图片 / 完整对话；或网页版全选复制成文本

## 建议
1. 只导**科研相关**的对话即可，非科研的（闲聊、JavaWeb 等）可以先不导，减少噪音。
2. 文件丢进来后，回 WorkBuddy 说一句「对话导好了」，我就会开始处理。

放好后不要改文件名里的关键信息，脚本靠扩展名区分类型。
