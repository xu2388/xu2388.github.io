### DeepSeek

想做PPT的AI Agent，现在确实有不少选择。和你可能用过的“AI PPT生成器”不同，Agent类工具的核心区别在于**多了一步“执行”能力**——它不只是给你一份内容草稿，还能直接操作PowerPoint软件或输出可编辑的PPTX文件，自动化程度更高[reference:0]。

按使用方式，目前主要有三类，你可以根据自己的工作习惯来选。

### 集成在办公软件里的 Agent（最省事）

如果你平时就用WPS或Microsoft 365，这类Agent几乎是无缝的。

**WPS AI**
深度集成在WPS演示里，输入主题或大纲就能生成PPT，导出的是标准PPTX，跨软件打开不跑版[reference:1]。免费可用，学习成本低，适合年终总结、课程汇报、日常方案这类中文办公场景[reference:2]。

**Microsoft Copilot for PowerPoint**
原生在PowerPoint里工作，生成后直接用PowerPoint改，不需要导出再修格式[reference:3]。如果你的公司已经用Microsoft 365且有Copilot权限，它能从Word文档直接生成PPT并自动写演讲备注[reference:4]。适合正式汇报、客户提案等企业场景。

**Templafy Agent 插件（免费）**
这是一个免费的PowerPoint插件，装上后可以直接在PowerPoint里对话操作——创建新幻灯片、重写内容、修正格式、添加可编辑图表[reference:5]。个人用户免费，适合已经习惯用PowerPoint、不想切换软件的人[reference:6]。

### 独立 Agent 产品（智能化程度更高）

这类工具不需要你打开PPT软件，直接用自然语言下指令，Agent自己完成从构思到排版的全流程。

**千问 AI PPT（Agent 版）**
阿里巴巴旗下产品，已完成“PPT Agent”智能体架构升级。你输入需求后，它能在**1到3分钟**内输出可直接使用的标准PPT文件，支持中英混排[reference:7]。速度优势明显，适合临时需要出稿的场景。

**库库 AI（百度）**
百度文库网盘推出的通用办公智能体，一句指令可以同时调用Word、Excel、PPT等多个Office智能体完成复杂任务[reference:8]。如果你需要的不只是做PPT，还涉及数据处理和文档整理，它能一次搞定。金融场景有专门优化，适合需要产出研报、路演PPT的用户[reference:9]。

**Sembly 3.0**
定位是“AI执行层”，能把组织的文档、会议记录、CRM内容转化为完整品牌演示文稿，支持45种以上语言[reference:10]。你只需说明目标（比如“推销我的服务”）和客户网站，它会自动研究客户并生成定制化的提案PPT[reference:11]。适合销售、咨询等需要针对客户快速出方案的场景。

### 开源自部署 Agent（技术用户可选）

如果你有技术背景，或者对数据隐私有要求，可以看看开源的方案。

**PPTAgent / DeepPresenter（中科院软件所开源）**
中科院软件所开源的幻灯片智能体系统，最大的特点是**本地部署**——支持在单张消费级显卡或Mac终端上运行，也适配华为昇腾国产算力[reference:12]。它采用“生成—渲染—审视—修正”的闭环工作流，每生成一页就渲染成图片检查排版，发现问题自动修正[reference:13]。9B参数版本的综合评分达到4.19，接近GPT-5的4.22，输出格式是**可编辑的PPTX**[reference:14]。适合对内容质量和数据安全都有要求的技术用户。

### DeepSeek

你提到的 **PPTAgent / DeepPresenter**，正是中科院软件所开源的一个很有代表性的项目。它的核心思路是让AI像人类设计师一样，**“边做边看边改”**，以此来生成一份内容扎实、排版专业的演示文稿。

### 📌 它是什么？

PPTAgent（第二代系统名为 **DeepPresenter**）是由**中国科学院软件研究所中文信息处理实验室**开发的开源幻灯片智能体系统[reference:0]。它的核心技术论文已被国际顶会 **EMNLP 2025** 收录，定位是一个具备深度研究能力的AI智能体，而非简单的文本转幻灯片工具[reference:1]。

### ⚙️ 核心工作原理：给AI装上“手”和“眼睛”

它之所以能生成高质量的PPT，关键在于其创新的 **“生成—渲染—审视—修正”** 闭环工作流[reference:2]。

1.  **赋予“手”去研究**：它将智能体置于一个功能完整的**Docker沙箱环境**中，内置了**20多种专业工具**。这意味着AI可以：
    *   **深度解析文档**：支持Word、PDF、Excel等多种格式的输入[reference:3]。
    *   **自主深度研究**：实时连接 **arXiv** 等学术数据库进行文献检索，确保内容有据可查[reference:4]。
    *   **执行代码与绘图**：直接运行Python代码来处理数据、绘制图表，保证数据的准确性[reference:5]。

2.  **赋予“眼睛”去审视**：在排版环节，每生成一页幻灯片，系统都会调用沙箱内的浏览器将其**渲染成真实图片**。AI会“亲眼”检查这张截图，如果发现标题被遮挡、排版错乱等问题，就会**立即自适应调整并重新生成**，直到视觉效果达到标准[reference:6][reference:7]。

3.  **独立的“评审”机制**：为了克服AI“自我感觉良好”的偏差，团队在训练阶段引入了**独立评审机制**，由另一个模型作为外部评估者，专门负责指出生成内容中的排版或逻辑缺陷，从而引导AI产生高质量的结果[reference:8]。

### 🏆 性能表现

在团队使用自研的 **PPTEval** 框架进行的系统评测中，DeepPresenter展现了出色的性能：

*   **综合评分**：其 **9B参数版本**取得了 **4.19** 的综合评分，与闭源模型 **GPT-5** 的 **4.22** 分表现非常接近[reference:9]。
*   **成本优势**：评测指出，DeepPresenter-9B处于**成本与性能平衡的最优前沿**，能以远低于闭源模型的算力成本，实现同等级别的生成质量[reference:10]。
*   **输出格式**：最终输出为**可编辑的 `.pptx` 格式**，你可以在PowerPoint或WPS中自由修改和二次创作[reference:11]。

### 💻 如何部署与使用？

**硬件与系统要求**[reference:12][reference:13]：

*   **操作系统**：官方测试于 **Linux** 和 **macOS**，**不支持Windows**（Windows用户可通过WSL使用）。
*   **硬件**：支持在**单张消费级显卡（如NVIDIA 3090/4090）** 或 **Apple Silicon Mac** 上本地部署。最低要求 **8GB内存**。
*   **依赖环境**：需要 **Python 3.11+**、**LibreOffice**、**Chrome**、**NodeJS** 等。

**三种主要使用方式**：

1.  **命令行（CLI）— 最快捷**
    安装包管理工具 `uv` 后，通过简单的命令即可完成配置和生成。
    ```bash
    # 安装 uv
    curl -LsSf https://astral.sh/uv/install.sh | sh

    # 首次配置（交互式向导）
    uvx pptagent onboard

    # 生成PPT
    deeppresenter generate "你的演示主题" -f 参考文件.pdf
    ```
    [reference:14]

2.  **Docker — 环境隔离，最省心**
    官方提供了Docker镜像，可以一键拉取运行，所有系统依赖都已预配置好[reference:15]。
    ```bash
    docker pull forceless/pptagent
    docker run -dt --gpus all --ipc=host --name pptagent ...
    ```

3.  **Web UI — 可视化操作**
    项目也提供了基于Gradio的Web界面，适合偏好图形化操作的用户[reference:16]。

**本地模型部署**：
为了获得最佳体验并保护数据隐私，官方强烈建议部署其微调后的 **DeepPresenter-9B** 模型。你可以在 **HuggingFace** 或 **ModelScope** 上找到模型的GGUF量化版本[!reference:17]。

### DeepSeek

PPTAgent / DeepPresenter 对内存和显存的要求，主要取决于你选择**哪种运行模式**。它提供了从低配置到高配置的灵活部署方案。

### 💻 基础运行模式：调用云端API（配置要求最低）

如果你的电脑配置不高，或者只是想先体验一下，可以选择这种模式。此时，核心的模型推理工作在云端完成，你的本地设备主要负责运行智能体框架和文档处理任务。

*   **内存 (RAM)**：**最低 4GB**，但**推荐 8GB 以上**。如果处理的文档比较大或复杂，**16GB 内存**会更流畅。[reference:0]
*   **显存 (VRAM)**：**基本无要求**，因为不进行本地模型推理。集成显卡或入门级独立显卡即可。

### 🚀 高级模式：本地LLM推理（推荐，数据隐私更好）

这是官方推荐的模式，能充分发挥 DeepPresenter 的性能，并确保数据完全保留在本地。此时，显存是关键的硬件指标。

*   **显存 (VRAM) - 最关键指标**：
    *   **最低要求**：**6GB** 显存。官方测试中，使用 **NVIDIA GTX 1060 (6GB)** 可以运行。[reference:1]
    *   **推荐配置**：**12GB 及以上**。例如 **RTX 3060 (12GB)** 或更高型号。根据另一份指南，本地推理的显存门槛建议为 **≥ 10GB**。[reference:2][reference:3]
    *   **理想配置**：**16GB+**。如果你希望获得最流畅的体验，并可能同时处理其他任务，更大的显存会更从容。[reference:4]
*   **内存 (RAM)**：
    *   本地推理模式对系统内存的要求也更高。官方文档提到**最低 8GB RAM**，而一些实践指南则建议**16GB 以上**，以确保在处理复杂文档时系统不会因为内存不足而卡顿。[reference:5][reference:6]

### 📱 特殊版本：GGUF 量化模型（Mac用户的福音）

针对 Apple Silicon Mac 或其他边缘设备，官方发布了**量化版 (GGUF) 模型**，专门用于“轻量化部署”。这个版本对显存（在Mac上是统一内存）的要求会进一步降低，使得在 Mac 上运行成为可能。[reference:7]

### 💎 总结与建议

简单来说，你的硬件配置决定了你的选择：

| 你的情况 | 推荐模式 | 关键硬件要求 |
| :--- | :--- | :--- |
| **电脑配置一般，想先试试** | **API 模式** | 内存 **8GB+**，无需独立显卡 |
| **有独立显卡，追求数据隐私和最佳效果** | **本地推理模式** | 显存 **≥ 6GB**（最低），**12GB+**（推荐） |
| **使用 Apple Silicon Mac** | **GGUF 量化模型** | 统一内存 **8GB+** 即可尝试 |

简单来说，一张 **6GB 显存**的显卡是本地运行的“入场券”，而 **12GB 及以上**的显存能让你获得更稳定、快速的体验。

### DeepSeek

PPTAgent / DeepPresenter 并非一个单一的模型，而是一个**多智能体（Multi-Agent）协作框架**。其核心是名为 **DeepPresenter-9B** 的预训练语言模型，该模型被赋予了不同角色，并通过一套精巧的机制协同工作来生成演示文稿[reference:0][!reference:1]。

### 🧠 核心模型：DeepPresenter-9B

作为整个系统的“大脑”，DeepPresenter-9B 是一个参数量为 **9B（90亿）** 的语言模型，专为自动演示文稿生成任务设计。官方通过监督微调（SFT）对其进行了训练，使其能更好地理解和执行智能体工作流。在性能上，它以远低于闭源大模型的算力成本，达到了接近 **GPT-5** 的综合评分（4.19 vs 4.22），体现了其高效性。[reference:2][!reference:3][reference:4]

### 👥 多智能体协作架构

DeepPresenter 的核心设计是“**双智能体架构**”，将复杂的演示文稿生成任务分解为两个专业角色，它们共享同一个基础模型（DeepPresenter-9B），但被赋予了不同的职责和工具[reference:5][reference:6][reference:7]。

*   **研究员 (Researcher)**：负责**内容生成**。它自主探索、检索并整合信息，形成一份与用户意图高度吻合的结构化文稿。它会调用多种工具（如 arXiv 文献检索、文档解析等）来确保内容的深度和准确性。
*   **呈现者 (Presenter)**：负责**视觉设计**。它将研究员产出的文稿，通过内容驱动的设计方法，转化为视觉上连贯的 HTML/CSS 幻灯片，而非简单地套用模板。
*   此外，系统还包含 **规划者 (Planner)**、**设计智能体 (Design Agent)** 等专业角色，共同构成了一个完整的智能体生态[reference:8][reference:9]。

### 🔄 关键创新：环境感知反思机制

这是 DeepPresenter 区别于其他工具的核心所在。传统的 AI 生成工具通常只能“自我反思”，检查内部代码或逻辑，但无法预知最终渲染效果。DeepPresenter 引入了 **“环境感知反思”（Environment-Grounded Reflection）** 机制，让智能体能够“**亲眼所见**”[reference:10][reference:11]。

具体工作流是一个 **“生成—渲染—审视—修正”** 的闭环：
1.  **生成**：智能体生成一页幻灯片的 HTML/CSS 代码。
2.  **渲染**：系统立即调用沙箱内的浏览器，将此代码渲染成一张真实的图片。
3.  **审视**：智能体使用 `inspect` 工具“查看”这张截图，识别是否存在**文字溢出、元素重叠、对比度不足**等视觉缺陷。
4.  **修正**：如果发现问题，智能体通过 `think` 工具规划并执行针对性的修正，然后重新渲染，直到效果达标。

### 🛠️ 底层支撑：共享智能体环境

为了让上述机制得以运行，DeepPresenter 将智能体置于一个功能完整的 **Docker 沙箱环境**中。这个环境集成了**20余种专业工具**，为智能体提供了强大的执行能力，包括：**实时文献检索（如 arXiv）**、**Python 代码执行与数据可视化**、**文件处理**等。[reference:12][reference:13]

### 📚 第二步：创建笔记本并上传“唯一事实来源”

1.  **新建笔记本**：登录后，点击“**新建笔记本**”，给它起一个清晰的名字，比如“2026 Q3 行业分析”或“毕业论文文献综述”[reference:4]。

    *   **其他**：音频文件、EPUB 电子书

**关键建议**：为了做出高质量的演示文稿，**一个笔记本最好围绕一个明确的主题，上传 5 到 15 份最核心的资料**。资料太少内容会空洞，太多则容易让重点变得零散。确保上传的 PDF 是可选中文字的版本，如果是扫描件，需要先做 OCR 处理。[reference:6]

系统会自动基于你的资料和大纲，生成一份完整的幻灯片草稿。你会看到每一页的标题和要点，并且关键结论旁边都带有**引用标记**，点击即可跳回原文核实[reference:9]。

### ✏️ 第四步：修改与导出
