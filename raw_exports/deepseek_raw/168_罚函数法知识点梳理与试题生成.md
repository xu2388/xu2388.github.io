## 一、核心知识点梳理

### 1. 外罚函数法
- 适用于等式和不等式约束问题
- 构造罚函数：\( P(x, \sigma) = f(x) + \sigma \tilde{P}(x) \)
  - 等式约束：\( \tilde{P}(x) = \sum c_i^2(x) \)
  - 不等式约束：\( \tilde{P}(x) = \sum [\max(0, c_i(x))]^2 \)
- 算法流程：逐渐增大 \( \sigma_k \to +\infty \)，求解无约束问题
- 收敛性质：\( f(x^k) \) 单调递增，\( P(x^k, \sigma_k) \) 单调递增
- 缺点：Hesse矩阵病态，条件数大

### 2. 内罚函数法
- 仅适用于不等式约束，要求初始点严格可行
- 构造障碍函数：
  - 对数障碍：\( B(x) = -\sum \ln(-c_i(x)) \)
  - 倒数障碍：\( B(x) = -\sum \frac{1}{c_i(x)} \)
- 内罚函数：\( P(x, r) = f(x) + r B(x) \)
- 算法流程：逐渐减小 \( r_k \to 0 \)
- 优点：迭代点始终可行
- 缺点：不能处理等式约束，也有病态问题

### 3. 乘子法（增广Lagrange法）
- 引入Lagrange乘子，克服病态
- 增广Lagrange函数：
  \[
  \phi(x, \lambda, \sigma) = f(x) + \sum \lambda_i c_i(x) + \frac{\sigma}{2} \sum c_i^2(x)
  \]
- 乘子迭代公式：
  - 等式：\( \lambda_i^{k+1} = \lambda_i^k + \sigma_k c_i(x^k) \)
  - 不等式：\( \lambda_i^{k+1} = \max\{0, \lambda_i^k + \sigma_k c_i(x^k)\} \)
- 终止准则：约束 violation 小于 ε
- 优点：σ 不必趋于无穷，病态问题缓解

### 四、计算题详解

#### 1. 外罚函数法
构造：
\[
P(x, \sigma) = x_1^2 + x_2^2 + \sigma (x_1 + x_2 - 2)^2
\]
求偏导：
\[
\frac{\partial P}{\partial x_1} = 2x_1 + 2\sigma(x_1 + x_2 - 2) = 0
\]
\[
\frac{\partial P}{\partial x_2} = 2x_2 + 2\sigma(x_1 + x_2 - 2) = 0
\]
两式相减得 \( x_1 = x_2 \)，代入第一个方程：
\[
2x_1 + 2\sigma(2x_1 - 2) = 0 \implies x_1 + 2\sigma x_1 - 2\sigma = 0
\]
\[
x_1(1 + 2\sigma) = 2\sigma \implies x_1 = \frac{2\sigma}{1 + 2\sigma}
\]
令 \( \sigma \to +\infty \)，得 \( x_1 = 1, x_2 = 1 \)，最优解 \( x^* = (1, 1)^T \)，\( f(x^*) = 2 \)。

---

#### 2. 内罚函数法
对数障碍函数：
\[
P(x, r) = x - r \ln(x - 1)
\]
求导：
\[
\frac{\partial P}{\partial x} = 1 - \frac{r}{x - 1} = 0 \implies x = 1 + r
\]
令 \( r \to 0 \)，得 \( x^* = 1 \)，\( f(x^*) = 1 \)。

### 五、证明题详解

**证明：**

1. **可行性**：  
   由于 \( x^k \) 是 \( P(x, \sigma_k) \) 的极小点，有：
   \[
   P(x^k, \sigma_k) \leq P(x^*, \sigma_k) = f(x^*) + \sigma_k \sum c_i^2(x^*) = f(x^*)
   \]
   即：
   \[
   f(x^k) + \sigma_k \sum c_i^2(x^k) \leq f(x^*)
   \]
   由于 \( f(x^k) \) 有下界，令 \( \sigma_k \to +\infty \)，必有 \( \sum c_i^2(x^k) \to 0 \)，即 \( c_i(x^k) \to 0 \)。由 \( x^k \to \bar{x} \) 得 \( c_i(\bar{x}) = 0 \)，故 \( \bar{x} \) 可行。

2. **最优性**：  
   由上述不等式：
   \[
   f(x^k) \leq f(x^*) - \sigma_k \sum c_i^2(x^k) \leq f(x^*)
   \]
   取极限得 \( f(\bar{x}) \leq f(x^*) \)。又因 \( \bar{x} \) 可行，\( x^* \) 是全局极小点，故 \( f(\bar{x}) \geq f(x^*) \)。因此：
   \[
   f(\bar{x}) = f(x^*)
   \]
   证毕。
