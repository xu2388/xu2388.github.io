### 💡 和你项目适配的几点建议

选好框架后，要顺利整合，关键是想清楚下面几个问题：

1.  **📋 第一步：搞清楚你的项目**
    *   **你的魔方教学项目是用什么技术开发的？** 比如是纯静态页面、WordPress，还是用Python/Java等语言开发的后端项目？确定这一点是后续一切选择的基础。
    *   **论坛的用户数据要和主站的打通吗？** 是需要**单点登录 (SSO)**（一个账号登录两边），还是用户数据完全独立？这决定了整合的复杂度。
    *   **论坛的界面风格要和主站统一吗？** 完全一样还是只要风格和谐就好？这关系到前端主题定制的工程量。
    *   **你的服务器配置怎么样？** 配置够高的话，选择就多（比如资源大户Discourse）；配置有限的话，Flarum这类轻量级的会更合适。

2.  **🤝 第二步：选择整合方式**
    *   **独立部署，共享用户数据 (推荐新手)**：将论坛作为独立应用安装，只通过简单的跳转关联。优点是部署简单，互不影响；缺点是用户需要二次登录，体验割裂。
    *   **集成到主站导航，统一用户认证**：将论坛的UI嵌入主站，并配置**单点登录 (SSO)**。用户体验一体化，但技术实现稍复杂，需要后端配合。
    *   **完全二次开发**：将论坛框架的代码作为基础，在其之上开发，完全融入主站。这提供了最高灵活性，但开发成本和维护难度也最大。

3.  **🛠️ 第三步：开发语言很重要，但不是全部**
    开发语言确实是选型的关键，因为它决定了你的维护成本。但不是说非要用同一种语言：
    *   **优势互补 (推荐)**：你可以保持现有项目（例如用Python开发的）不变，在另一台服务器上用最适合的框架（如NodeBB）部署论坛，通过API或单点登录连接它们。这样能发挥各语言的优势，也是最省心的做法。
    *   **语言统一 (适用于定制开发)**：如果你打算大量修改论坛代码，那选一个和主站开发语言相同的框架会更顺手，比如主站是Python，就选`Misago`；主站是PHP，就选`Flarum`。

### 📚 推荐的部署与整合路径

对于零基础新手，更推荐一个相对简单的路径：**先独立部署，再考虑整合**。

*   **部署一个独立的论坛**
    *   **首推Flarum**：它对新手最友好，界面现代化，安装文档清晰，有中文社区支持。
    *   **其次NodeBB**：如果你对Node.js稍有兴趣，它的安装过程也不算复杂，社区很活跃。
    *   **避免起步就碰Discourse**：它虽然功能强大，但对服务器配置和运维知识要求较高，不适合新手入门。

*   **实现单点登录 (SSO)**
    *   这是打通用户系统的核心技术。确保主站和论坛能通过OAuth2.0或JWT等方式，让用户在一边登录，另一边自动识别身份。具体实现方式，可以参考你选择的论坛框架的官方文档。

*   **对接用户数据**
    *   通过SSO，你可以决定是仅共享用户登录状态，还是将用户ID、用户名、头像、积分等基础资料都同步过去，实现“一次注册，两边使用”。

*   **统一前端样式**
    *   在论坛后台修改主题，简单调整主色调、导航栏等，就能让论坛的视觉风格和主站和谐统一。

### 📌 快速上手指南（以Flarum为例）

1.  **环境准备**：你需要一个能跑PHP的服务器（如Nginx/Apache），以及MySQL/MariaDB数据库[reference:24]。
2.  **安装Flarum**：可以使用Composer一键安装，目前也有“一行代码”的简化安装工具，非常方便[reference:25]。
3.  **基础配置**：在Web界面完成管理员账号、论坛标题等基础设置。
4.  **数据关联**：**通过官方或第三方SSO插件**，实现Flarum和主站（比如你的WordPress或自建系统）的用户数据打通。

总的来说，多花点时间规划好**论坛和主站的用户系统如何打通、界面如何融合**，比纠结“选什么语言”更重要。独立部署是让你最快看到效果的方式，后续再根据技术能力逐步整合。

### 💡 为什么不需要和后端语言一致？

你的 Tauri 应用是**桌面客户端**，论坛可以是：

- 通过 Tauri 的 **HTTP 客户端**调用论坛的 API 来读取/发帖，完全用前端渲染（但这样工作量较大）。

所以论坛用什么语言写根本不重要，关键是它提供**清晰的 API** 和**易于嵌入的界面**。

### 🔐 一、为Tauri桌面应用集成Supabase Auth

这是实现统一登录的起点。Tauri 桌面应用的特殊之处在于它需要处理 OAuth 登录后的回调，不能用传统网页的方式。

#### 核心挑战：桌面应用的 OAuth 回调
一般的网页应用 OAuth 登录后能跳回指定网页，但桌面应用没有这个机制[reference:0]。

#### 解决方案：本地服务器拦截
解决思路是在你的应用里启动一个临时的本地服务器，专门“拦截”登录成功后返回的授权码[reference:1]。

**具体操作步骤：**

1.  **安装插件**：在你的 Tauri 项目中安装 `tauri-plugin-oauth` 插件[reference:2]。
2.  **配置 Supabase 回调地址**：登录 Supabase 后台，在 `Authentication` -> `URL Configuration` 的 **Redirect URLs** 列表中，添加 `http://localhost:9999/**`。这个地址就是你的本地服务器地址，用于接收 OAuth 回调[reference:3][reference:4]。
3.  **编写前端登录逻辑**：在你的 React 登录页面，实现以下流程：
    *   用户点击“使用 Google/GitHub 登录”。
    *   你的代码调用 `tauri-plugin-oauth` 插件，启动本地服务器并开始监听[reference:5]。
    *   同时，调用 Supabase 的 `signInWithOAuth` 方法，并将 `redirectTo` 参数设置为 `http://localhost:9999`[reference:6]。
    *   应用会自动打开系统默认浏览器，跳转到 Google/GitHub 的授权页面。
    *   用户在浏览器完成授权后，页面会跳转到 `http://localhost:9999`，并在 URL 中携带一个 `code` 参数[reference:7]。
    *   你的本地服务器捕获到这个带有 `code` 的请求，并从 URL 中解析出 `code`[reference:8]。
    *   将获取到的 `code` 发送给 Supabase，换取用户的 `access_token` 和 `refresh_token`[reference:9]。
    *   最后，通过 Supabase SDK 的 `setSession` 方法，将这些 token 保存下来，完成登录[reference:10]。

> **一个需要注意的地方**：在 Supabase 中启用 Google OAuth 后，如果应用还处于“测试”阶段，需要将你的邮箱添加为测试用户，否则只有你自己能登录[reference:11][reference:12]。

### 🧩 二、打通Answer论坛用户体系

这是统一登录的核心，让 Answer 论坛也接入 Supabase 认证。Answer 支持通用的 **OAuth 2.0** 标准登录，可以很方便地对接 Supabase Auth[reference:13]。

**关键操作指南：**

1.  **配置 Supabase**：在 Supabase 的 `Authentication` -> `URL Configuration` 的 **Redirect URLs** 中，需要添加 Answer 论坛的回调地址，格式通常是 `http(s)://你的论坛地址/login/oauth2/code/supabase`。
2.  **配置 Answer 插件**：登录 Answer 后台，在 **Plugins** 中启用 **OAuth2 Basic** 插件[reference:14]。启用后，在 **Users and groups** -> **Settings** -> **OAuth2 Authentication** 中进行配置[reference:15]。
    *   **Name**: 给这个登录方式起个名字，例如 “使用主站账号登录”。
    *   **Client ID**: 在 Supabase 后台 `Authentication` -> `Providers` 中，为 Answer 创建一个 OAuth 应用，获取对应的 ID 和 Secret。
    *   **Auth URL**: `https://你的 Supabase 项目 ID.supabase.co/auth/v1/authorize`
    *   **Token URL**: `https://你的 Supabase 项目 ID.supabase.co/auth/v1/token`
    *   **User Info URL**: `https://你的 Supabase 项目 ID.supabase.co/auth/v1/user`
    *   **Scopes**: 填入 `openid email profile`。

#### 选型理由

| 维度 | PostgreSQL | MySQL | MongoDB | SQLite |
|------|-----------|-------|---------|--------|
| **ACID事务支持** | ✅ 完整支持 | ✅ 完整支持 | ⚠️ 部分支持 | ✅ 完整支持 |
| **JSON/JSONB支持** | ✅ 原生支持 | ⚠️ 基础支持 | ✅ 原生文档 | ❌ 不支持 |
| **全文搜索** | ✅ 内置FTS | ⚠️ 基础 | ✅ 文本索引 | ❌ 不支持 |
| **复杂查询** | ✅ CTE、窗口函数 | ⚠️ 有限支持 | ❌ 聚合管道 | ❌ 有限支持 |
| **扩展性** | ✅ 插件丰富 | ⚠️ 中等 | ✅ 水平扩展 | ❌ 单文件 |
| **并发性能** | ✅ MVCC | ✅ MVCC | ✅ 无锁 | ❌ 写锁 |
| **开源协议** | ✅ PostgreSQL | ⚠️ GPL | ✅ SSPL | ✅ Public Domain |
| **社区活跃度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |

### 1.2 技术优势

1. **强大的JSONB支持**
   ```sql
   -- 存储帖子元数据（标签、自定义字段等）
   CREATE TABLE posts (
     metadata JSONB DEFAULT '{}'
   );
   
   -- 高效查询JSON字段
   SELECT * FROM posts WHERE metadata->>'tags' @> '["CFOP"]';
   ```

2. **内置全文搜索**
   ```sql
   -- 创建全文搜索索引
   CREATE INDEX idx_posts_search ON posts 
   USING GIN (to_tsvector('chinese', title || ' ' || content));
   
   -- 搜索示例
   SELECT * FROM posts 
   WHERE to_tsvector('chinese', title || ' ' || content) 
   @@ plainto_tsquery('魔方教程');
   ```

3. **优秀的并发控制**
   - MVCC（多版本并发控制）
   - 无锁读取
   - 行级锁粒度

4. **丰富的数据类型**
   - 数组类型：`TEXT[]` 用于存储标签ID列表
   - UUID类型：用于主键
   - 枚举类型：用于状态字段
   - 网络地址类型：用于IP记录

### 1.3 版本要求

- **最低版本**: PostgreSQL 14+
- **推荐版本**: PostgreSQL 16.x（最新稳定版）
- **原因**: 支持并行查询、更好的JSONB性能、增强的分区功能

## 3. 表结构详细定义

### 3.1 users 用户表

```sql
CREATE TABLE users (
  -- 主键
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- 基本信息
  username VARCHAR(50) NOT NULL UNIQUE,
  email VARCHAR(255) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  
  -- 个人资料
  display_name VARCHAR(100),
  avatar_url TEXT,
  bio TEXT,
  location VARCHAR(100),
  website VARCHAR(255),
  
  -- 权限与角色
  role VARCHAR(20) NOT NULL DEFAULT 'user'
    CHECK (role IN ('guest', 'user', 'moderator', 'admin')),
  is_active BOOLEAN NOT NULL DEFAULT true,
  is_email_verified BOOLEAN NOT NULL DEFAULT false,
  
  -- 统计信息
  reputation INTEGER NOT NULL DEFAULT 0,
  post_count INTEGER NOT NULL DEFAULT 0,
  comment_count INTEGER NOT NULL DEFAULT 0,
  like_received INTEGER NOT NULL DEFAULT 0,
  
  -- 时间戳
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  last_login_at TIMESTAMPTZ,
  
  -- 约束
  CONSTRAINT chk_username_length CHECK (char_length(username) >= 3 AND char_length(username) <= 50),
  CONSTRAINT chk_email_format CHECK (email ~* '^[A-Za-z0-9._%-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$')
);

-- 索引
CREATE UNIQUE INDEX idx_users_username ON users (username);
CREATE UNIQUE INDEX idx_users_email ON users (email);
CREATE INDEX idx_users_role ON users (role);
CREATE INDEX idx_users_reputation ON users (reputation DESC);
CREATE INDEX idx_users_created_at ON users (created_at DESC);
```

### 3.2 forums 板块表

```sql

-- 索引
CREATE INDEX idx_forums_slug ON forums (slug);
```

### 3.3 posts 帖子表

```sql
CREATE TYPE post_status AS ENUM ('draft', 'published', 'locked', 'deleted');

CREATE TABLE posts (
  -- 主键
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- 外键关联
  forum_id UUID NOT NULL REFERENCES forums(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE SET NULL,
  
  -- 内容
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL, -- Markdown格式
  content_html TEXT, -- 渲染后的HTML（缓存）
  excerpt TEXT, -- 摘要（自动生成或手动编辑）
  
  -- 状态
  status post_status NOT NULL DEFAULT 'published',
  is_pinned BOOLEAN NOT NULL DEFAULT false,
  is_essence BOOLEAN NOT NULL DEFAULT false,
  is_locked BOOLEAN NOT NULL DEFAULT false,
  is_deleted BOOLEAN NOT NULL DEFAULT false,
  
  -- 统计计数（冗余存储，提升查询性能）
  view_count INTEGER NOT NULL DEFAULT 0,
  like_count INTEGER NOT NULL DEFAULT 0,
  comment_count INTEGER NOT NULL DEFAULT 0,
  bookmark_count INTEGER NOT NULL DEFAULT 0,
  
  -- 元数据（JSONB）
  metadata JSONB DEFAULT '{}'::jsonb,
  -- metadata 示例: {"tags": ["CFOP", "三阶"], "cover_image": "url"}
  
  -- SEO
  slug VARCHAR(250),
  
  -- 时间戳
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  published_at TIMESTAMPTZ,
  last_comment_at TIMESTAMPTZ,
  deleted_at TIMESTAMPTZ,
  
  -- 约束
  CONSTRAINT chk_title_length CHECK (char_length(title) >= 5 AND char_length(title) <= 200),
  CONSTRAINT chk_content_length CHECK (char_length(content) >= 10)
);

-- 索引
CREATE INDEX idx_posts_forum ON posts (forum_id, created_at DESC);
CREATE INDEX idx_posts_user ON posts (user_id, created_at DESC);
CREATE INDEX idx_posts_status ON posts (status, is_deleted, created_at DESC);
CREATE INDEX idx_posts_pinned ON posts (forum_id, is_pinned, created_at DESC) WHERE is_pinned = true;
CREATE INDEX idx_posts_essence ON posts (is_essence, created_at DESC) WHERE is_essence = true;
CREATE INDEX idx_posts_slug ON posts (slug);

-- 全文搜索索引
CREATE INDEX idx_posts_fulltext ON posts 
  USING GIN (to_tsvector('simple', coalesce(title, '') || ' ' || coalesce(content, '')));

-- 复合索引（常见查询模式）
CREATE INDEX idx_posts_hot ON posts (forum_id, like_count DESC, comment_count DESC) 
  WHERE status = 'published' AND is_deleted = false;
```

## 4. 关系定义与完整性规则

### 4.1 外键关系

| 关系 | 类型 | 级联操作 | 说明 |
|------|------|---------|------|
| `posts.forum_id → forums.id` | 多对一 | CASCADE | 删除板块时删除所有帖子 |
| `posts.user_id → users.id` | 多对一 | SET NULL | 删除用户时保留帖子（设为匿名） |
| `comments.post_id → posts.id` | 多对一 | CASCADE | 删除帖子时删除所有评论 |
| `comments.user_id → users.id` | 多对一 | SET NULL | 删除用户时保留评论 |
| `comments.parent_id → comments.id` | 自引用 | CASCADE | 删除父评论时删除所有子评论 |
| `post_tags.post_id → posts.id` | 多对一 | CASCADE | - |
| `post_tags.tag_id → tags.id` | 多对一 | CASCADE | - |
| `post_likes.post_id → posts.id` | 多对一 | CASCADE | - |
| `post_likes.user_id → users.id` | 多对一 | CASCADE | - |

### 4.2 业务规则约束

```sql
-- 规则1: 帖子发布后不能修改为草稿
CREATE OR REPLACE FUNCTION check_post_status_transition()
RETURNS TRIGGER AS $$
BEGIN
  IF OLD.status = 'published' AND NEW.status = 'draft' THEN
    RAISE EXCEPTION '已发布的帖子不能转为草稿';
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_post_status_transition
BEFORE UPDATE ON posts
FOR EACH ROW EXECUTE FUNCTION check_post_status_transition();

-- 规则2: 锁定的帖子不能被普通用户编辑
CREATE OR REPLACE FUNCTION check_post_edit_permission()
RETURNS TRIGGER AS $$
DECLARE
  user_role VARCHAR;
BEGIN
  SELECT role INTO user_role FROM users WHERE id = NEW.user_id;
  
  IF OLD.is_locked = true AND user_role NOT IN ('moderator', 'admin') THEN
    RAISE EXCEPTION '锁定的帖子只能由管理员编辑';
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 规则3: 自动更新时间戳
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 应用到所有需要自动更新的表
CREATE TRIGGER update_users_updated_at BEFORE UPDATE ON users
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
  
CREATE TRIGGER update_posts_updated_at BEFORE UPDATE ON posts
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- 规则4: 自动维护统计数据（使用触发器或应用层）
CREATE OR REPLACE FUNCTION increment_post_stat(stat_column TEXT)
RETURNS TRIGGER AS $$
BEGIN
  EXECUTE format(
    'UPDATE posts SET %I = %I + 1 WHERE id = $1',
    stat_column, stat_column
  ) USING NEW.post_id;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 点赞时自动增加计数
CREATE TRIGGER increment_like_count AFTER INSERT ON post_likes
  FOR EACH ROW EXECUTE FUNCTION increment_post_stat('like_count');
```

```sql
WITH RECURSIVE comment_tree AS (
  -- 基础查询：顶级评论
  SELECT c.*, 1 as depth, ARRAY[c.id] as path
  FROM comments c
  WHERE c.post_id = $1 AND c.parent_id IS NULL AND c.is_deleted = false
  
  UNION ALL
  
  -- 递归查询：子评论
  SELECT c.*, ct.depth + 1, ct.path || c.id
  FROM comments c
  JOIN comment_tree ct ON c.parent_id = c.id
  WHERE c.is_deleted = false AND ct.depth < 5 -- 限制嵌套深度
)
SELECT * FROM comment_tree ORDER BY path, depth;

-- 方法2: 物化路径（更高效，适合大数据量）

WHERE post_id = $1 AND is_deleted = false
```

```sql
  slug VARCHAR(100) UNIQUE NOT NULL,
  description TEXT,
  icon VARCHAR(50),
  sort_order INT DEFAULT 0,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 帖子表
CREATE TABLE IF NOT EXISTS public.posts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  forum_id UUID REFERENCES public.forums(id) ON DELETE CASCADE,
  user_id UUID REFERENCES public.profiles(id) ON DELETE SET NULL,
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  view_count INT DEFAULT 0,
  like_count INT DEFAULT 0,
  comment_count INT DEFAULT 0,
  is_pinned BOOLEAN DEFAULT false,
  is_essence BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 评论表
CREATE TABLE IF NOT EXISTS public.comments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  post_id UUID REFERENCES public.posts(id) ON DELETE CASCADE,
  user_id UUID REFERENCES public.profiles(id) ON DELETE SET NULL,
  parent_id UUID REFERENCES public.comments(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  like_count INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 启用 Row Level Security（必须）
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.forums ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.posts ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.comments ENABLE ROW LEVEL SECURITY;

-- 基础 RLS 策略：允许所有用户读取，只有本人可以修改自己的 profile
CREATE POLICY "公开读取 profiles" ON public.profiles FOR SELECT USING (true);
CREATE POLICY "用户可修改自己的 profile" ON public.profiles FOR UPDATE USING (auth.uid() = id);

CREATE POLICY "公开读取 forums" ON public.forums FOR SELECT USING (true);
CREATE POLICY "公开读取 posts" ON public.posts FOR SELECT USING (true);
CREATE POLICY "用户可发帖" ON public.posts FOR INSERT WITH CHECK (auth.uid() = user_id);
CREATE POLICY "用户可编辑自己的帖子" ON public.posts FOR UPDATE USING (auth.uid() = user_id);
CREATE POLICY "公开读取 comments" ON public.comments FOR SELECT USING (true);
CREATE POLICY "用户可评论" ON public.comments FOR INSERT WITH CHECK (auth.uid() = user_id);
```

```sql
CREATE OR REPLACE FUNCTION increment_post_like_count()
RETURNS TRIGGER AS $$
BEGIN
  IF TG_OP = 'INSERT' THEN
    UPDATE posts SET like_count = like_count + 1 WHERE id = NEW.post_id;
  ELSIF TG_OP = 'DELETE' THEN
    UPDATE posts SET like_count = like_count - 1 WHERE id = OLD.post_id;
  END IF;
  RETURN NULL;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_post_likes_count
AFTER INSERT OR DELETE ON post_likes
FOR EACH ROW EXECUTE FUNCTION increment_post_like_count();
```

### 1. 数据库表设计（Supabase PostgreSQL）

```sql
-- 课程表
CREATE TABLE courses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title VARCHAR(200) NOT NULL,
  description TEXT,
  cover_image TEXT,
  level VARCHAR(20) DEFAULT 'beginner', -- beginner, intermediate, advanced
  instructor_id UUID REFERENCES profiles(id),
  view_count INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 章节表
CREATE TABLE chapters (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  course_id UUID REFERENCES courses(id) ON DELETE CASCADE,
  title VARCHAR(200) NOT NULL,
  content TEXT, -- Markdown 或视频 URL
  video_url TEXT,
  sort_order INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 用户学习进度表
CREATE TABLE user_progress (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  chapter_id UUID REFERENCES chapters(id) ON DELETE CASCADE,
  completed BOOLEAN DEFAULT false,
  completed_at TIMESTAMPTZ,
  UNIQUE(user_id, chapter_id)
);

-- 课程评分表
CREATE TABLE course_reviews (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  course_id UUID REFERENCES courses(id) ON DELETE CASCADE,
  user_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  rating INT CHECK (rating >= 1 AND rating <= 5),
  comment TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(course_id, user_id)
);
```

```python
from fastapi import FastAPI
from pydantic import BaseModel
import kociemba

app = FastAPI()

class CubeState(BaseModel):
    # 例如: "UUUUUUUUURRRRRRRRRFFFFFFFFFDDDDDDDDDLLLLLLLLLBBBBBBBBB"

@app.post("/solve")
def solve(state: CubeState):
    try:
        solution = kociemba.solve(state.state)
        return {"solution": solution, "steps": len(solution.split())}
    except Exception as e:
        return {"error": str(e)}
```

### 1. 数据库表设计

```sql
-- 文章分类
CREATE TABLE categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(50) NOT NULL UNIQUE,
  slug VARCHAR(50) NOT NULL UNIQUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 文章标签
CREATE TABLE tags (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(50) NOT NULL UNIQUE,
  slug VARCHAR(50) NOT NULL UNIQUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 文章主表
CREATE TABLE posts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title VARCHAR(200) NOT NULL,
  slug VARCHAR(250) NOT NULL UNIQUE,
  excerpt TEXT,
  content TEXT NOT NULL,          -- Markdown 原始内容
  content_html TEXT,              -- 渲染后的 HTML（缓存）
  cover_image TEXT,
  category_id UUID REFERENCES categories(id),
  author_id UUID REFERENCES profiles(id) NOT NULL,
  view_count INT DEFAULT 0,
  like_count INT DEFAULT 0,
  comment_count INT DEFAULT 0,
  is_published BOOLEAN DEFAULT false,
  published_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 文章-标签关联
CREATE TABLE post_tags (
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
  tag_id UUID REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (post_id, tag_id)
);

-- 评论（复用之前的 comments 表，或者单独建一个）
CREATE TABLE post_comments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  post_id UUID REFERENCES posts(id) ON DELETE CASCADE,
  user_id UUID REFERENCES profiles(id) ON DELETE SET NULL,
  content TEXT NOT NULL,
  parent_id UUID REFERENCES post_comments(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 🧱 传统 Web 应用经典类型（从简单到复杂）

### 1️⃣ **短链接服务**（最简单）
- **功能**：把长网址缩短，并提供点击统计、二维码生成。
- **技术栈**：任意后端（Node/Go/Python）+ 数据库（存映射关系）。
- **上线**：Vercel + Redis 或 Supabase，一天搞定。
- **为什么经典**：几乎每个开发者都做过，但麻雀虽小五脏俱全（路由重定向、计数、API设计）。

### 2️⃣ **个人记账本 / 账单管理**
- **功能**：记录收入/支出，分类统计，图表展示。
- **技术栈**：React/Vue + 任意后端 + SQLite/Postgres。
- **上线**：可以纯前端 + localStorage，也可以加后端同步。
- **为什么经典**：贴近生活，用户需求明确，可扩展到多人家庭账本。

### 3️⃣ **待办事项 + 番茄钟**
- **功能**：任务列表 + 专注计时 + 统计完成度。
- **技术栈**：React + IndexedDB（纯前端）或加上后端同步。
- **上线**：PWA 可安装到手机，类似 Todoist 的极简版。
- **为什么经典**：学习状态管理、计时器、通知 API。

### 4️⃣ **链接聚合 / 书签墙**（类似 Hacker News 或 Reddit 精简版）
- **功能**：用户提交链接，投票，按热度排序。
- **技术栈**：Node/Go/Python + Postgres（存储链接、投票数）。
- **上线**：类似你自己做的一个“魔方资源聚合站”。
- **为什么经典**：涉及用户生成内容、投票算法（如威尔逊得分）、防刷。

### 5️⃣ **简易论坛 / 留言板**（比 Stack Overflow 轻量得多）
- **功能**：板块、帖子、评论，没有复杂权限。
- **技术栈**：Supabase 一键开表，前端用 Next.js 或 Vite。
- **上线**：一天搭建，适合做小社区。
- **为什么经典**：你已有问答，但纯论坛更传统，比如 “魔方爱好者小站”。

### 6️⃣ **图片分享墙**（类似 Pinterest 极简版）
- **功能**：上传图片，展示瀑布流，点赞或收藏。
- **技术栈**：任意后端 + 对象存储（Supabase Storage / AWS S3）。
- **上线**：需要处理图片上传、缩略图、CDN。
- **为什么经典**：媒体文件处理是 Web 开发的常见需求。

### 7️⃣ **天气预报仪表盘**（调用第三方 API）
- **功能**：输入城市，展示实时天气 + 未来一周预报，可保存常用城市。
- **技术栈**：纯前端（React/Vue） + 免费天气 API（如 OpenWeatherMap）。
- **上线**：Vercel 部署，无需后端。
- **为什么经典**：学习 API 调用、异步数据加载、图表展示。

### 8️⃣ **RSS 阅读器**（聚合订阅）
- **功能**：订阅网站 RSS，展示文章列表，标记已读/未读。
- **技术栈**：Node 后端定时拉取 RSS，前端展示。
- **上线**：可以做成纯前端版（使用 CORS 代理）或后端版。
- **为什么经典**：数据聚合、定时任务、XML 解析。

### 9️⃣ **在线简历生成器**
- **功能**：用户填写表单，生成精美简历网页或 PDF。
- **技术栈**：React 表单 + 打印样式 + jsPDF 或 html2canvas。
- **上线**：纯前端，无需后端（可加 localStorage 保存草稿）。
- **为什么经典**：表单处理、实时预览、导出文件。

### 🔟 **抽奖 / 转盘小游戏**
- **功能**：用户登录后每天可抽奖，奖品积分或虚拟徽章。
- **技术栈**：任意后端 + 数据库（存储用户奖品记录）。
- **上线**：适合拉新活动，简单有趣。
- **为什么经典**：概率算法、用户行为记录、简单游戏逻辑。

#### 2. 编写天气 API 服务

在 `/src` 下新建 `services` 文件夹，然后创建 `weatherService.ts` 文件，用来封装所有和后端 API 的交互逻辑。这个模块的核心功能就是**根据城市名，向 OpenWeatherMap 的服务器请求并返回该城市的实时天气和未来5天预报**。
```ts
import axios from 'axios';

const API_KEY = import.meta.env.VITE_OPENWEATHER_API_KEY;
const BASE_URL = 'https://api.openweathermap.org/data/2.5';

// 定义数据类型，让我们的代码更可靠
export interface CurrentWeather {
  city: string;
  temperature: number;
  feelsLike: number;
  humidity: number;
  windSpeed: number;
  description: string;
  icon: string;
}

export interface ForecastItem {
  dt: number;
  temp: number;
  feelsLike: number;
  humidity: number;
  windSpeed: number;
  description: string;
  icon: string;
}

// 获取当前天气
export const fetchCurrentWeather = async (city: string): Promise<CurrentWeather> => {
  const response = await axios.get(`${BASE_URL}/weather`, {
    params: {
      q: city,
      appid: API_KEY,
      units: 'metric', // 使用摄氏度
      lang: 'zh_cn'   // 使用中文
    }
  });

  const data = response.data;
  return {
    city: data.name,
    temperature: Math.round(data.main.temp),
    feelsLike: Math.round(data.main.feels_like),
    humidity: data.main.humidity,
    windSpeed: data.wind.speed,
    description: data.weather[0].description,
    icon: `https://openweathermap.org/img/wn/${data.weather[0].icon}@2x.png`
  };
};

// 获取5天天气预报（每3小时一次）
export const fetchForecast = async (city: string): Promise<ForecastItem[]> => {
  const response = await axios.get(`${BASE_URL}/forecast`, {
    params: {
      q: city,
      appid: API_KEY,
      units: 'metric',
      lang: 'zh_cn'
    }
  });

  // 提取未来5天每天中午12点的数据，共5条
  const dailyForecasts: ForecastItem[] = [];
  const today = new Date().setHours(0, 0, 0, 0);
  
  for (const item of response.data.list) {
    const itemDate = new Date(item.dt * 1000);
    if (itemDate.getHours() === 12 && itemDate.getTime() > today) {
      dailyForecasts.push({
        dt: item.dt,
        temp: Math.round(item.main.temp),
        feelsLike: Math.round(item.main.feels_like),
        humidity: item.main.humidity,
        windSpeed: item.wind.speed,
        description: item.weather[0].description,
        icon: `https://openweathermap.org/img/wn/${item.weather[0].icon}.png`
      });
      if (dailyForecasts.length === 5) break;
    }
  }
  
  return dailyForecasts;
};
```

#### 5. 整合主页面

最后，在 `App.tsx` 中，我们将上面的城市搜索、当前天气卡片和未来天气预报图表组合在一起。核心逻辑是**当用户选择一个城市时，我们使用之前写好的 `weatherService` 来请求数据，并把结果显示在页面上**。

```tsx
import { useState } from 'react';
import CitySearch from './components/CitySearch';
import WeatherChart from './components/WeatherChart';
import { fetchCurrentWeather, fetchForecast } from './services/weatherService';

function App() {
  const [currentWeather, setCurrentWeather] = useState(null);
  const [forecast, setForecast] = useState(null);
  const [loading, setLoading] = useState(false);

  const handleCityChange = async (selectedCity) => {
    setLoading(true);
    try {
      // 并行请求当前天气和天气预报，提高效率
      const [weather, forecastData] = await Promise.all([
        fetchCurrentWeather(selectedCity.value),
        fetchForecast(selectedCity.value)
      ]);
      setCurrentWeather(weather);
      setForecast(forecastData);
    } catch (error) {
      console.error('获取天气数据失败:', error);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="min-h-screen bg-gradient-to-br from-blue-400 to-purple-600 p-8">
      <div className="max-w-4xl mx-auto">
        <h1 className="text-4xl font-bold text-white text-center mb-8">
          天气仪表盘
        </h1>
        <CitySearch onCityChange={handleCityChange} />
        
        {loading && <div className="text-white text-center">加载中...</div>}
        
        {currentWeather && (
          <div className="bg-white/20 backdrop-blur-lg rounded-2xl p-6 my-6">
            <h2 className="text-2xl font-bold text-white">{currentWeather.city}</h2>
            <div className="text-6xl font-bold text-white my-4">
              {currentWeather.temperature}°C
            </div>
            <div className="text-white">{currentWeather.description}</div>
          </div>
        )}
        
        {forecast && <WeatherChart data={forecast} />}
      </div>
    </div>
  );
}
```

创建 `src/services/weatherService.ts`，这是项目的 **“数据层”** ，封装所有 API 调用逻辑。

**完整代码：**

```ts
import axios from 'axios';

const API_KEY = import.meta.env.VITE_OPENWEATHER_API_KEY;
const BASE_URL = 'https://api.openweathermap.org/data/2.5';

// 类型定义
export interface CurrentWeather {
  city: string;
  country: string;
  temperature: number;
  feelsLike: number;
  humidity: number;
  windSpeed: number;
  description: string;
  icon: string;
}

export interface ForecastItem {
  dt: number;
  temp: number;
  feelsLike: number;
  humidity: number;
  windSpeed: number;
  description: string;
  icon: string;
}

// 获取当前天气
export const fetchCurrentWeather = async (city: string): Promise<CurrentWeather> => {
  const response = await axios.get(`${BASE_URL}/weather`, {
    params: {
      q: city,
      appid: API_KEY,
      units: 'metric',   // 摄氏度
      lang: 'zh_cn'      // 中文描述
    }
  });

  const data = response.data;
  return {
    city: data.name,
    country: data.sys.country,
    temperature: Math.round(data.main.temp),
    feelsLike: Math.round(data.main.feels_like),
    humidity: data.main.humidity,
    windSpeed: data.wind.speed,
    description: data.weather[0].description,
    icon: `https://openweathermap.org/img/wn/${data.weather[0].icon}@2x.png`
  };
};

// 获取未来5天预报（每天中午12点的数据）
export const fetchForecast = async (city: string): Promise<ForecastItem[]> => {
  const response = await axios.get(`${BASE_URL}/forecast`, {
    params: {
      q: city,
      appid: API_KEY,
      units: 'metric',
      lang: 'zh_cn'
    }
  });

  const dailyForecasts: ForecastItem[] = [];
  const today = new Date().setHours(0, 0, 0, 0);
  
  for (const item of response.data.list) {
    const itemDate = new Date(item.dt * 1000);
    // 取每天中午12点的数据，最多5天
    if (itemDate.getHours() === 12 && itemDate.getTime() > today) {
      dailyForecasts.push({
        dt: item.dt,
        temp: Math.round(item.main.temp),
        feelsLike: Math.round(item.main.feels_like),
        humidity: item.main.humidity,
        windSpeed: item.wind.speed,
        description: item.weather[0].description,
        icon: `https://openweathermap.org/img/wn/${item.weather[0].icon}.png`
      });
      if (dailyForecasts.length === 5) break;
    }
  }
  
  return dailyForecasts;
};
```

### 1. 使用 Zustand 管理城市列表（持久化存储）

Zustand 的 `persist` 中间件能将状态自动保存到 `localStorage`，刷新页面后城市列表不会丢失。[reference:6]

创建 `src/store/useCityStore.ts`：

```ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

interface City {
  id: string;
  name: string;
}

interface CityStore {
  cities: City[];           // 保存的城市列表
  currentCity: string | null;  // 当前选中的城市
  addCity: (cityName: string) => void;
  removeCity: (cityId: string) => void;
  setCurrentCity: (cityName: string) => void;
}

export const useCityStore = create<CityStore>()(
  persist(
    (set) => ({
      cities: [],
      currentCity: null,
      addCity: (cityName) =>
        set((state) => {
          // 防止重复添加
          if (state.cities.some((c) => c.name === cityName)) return state;
          return {
            cities: [...state.cities, { id: Date.now().toString(), name: cityName }]
          };
        }),
      removeCity: (cityId) =>
        set((state) => ({
          cities: state.cities.filter((c) => c.id !== cityId)
        })),
      setCurrentCity: (cityName) =>
        set(() => ({
          currentCity: cityName
        }))
    }),
    {
      name: 'weather-cities',  // localStorage 中存储的 key 名称
    }
  )
);
```

```tsx
interface CitySearchProps {
  onSearch: (city: string) => void;
  isLoading: boolean;
}

// 常用城市列表（作为搜索建议的备选）
const POPULAR_CITIES = [
  '北京', '上海', '广州', '深圳', '杭州', '成都', '武汉', '西安',
  'New York', 'London', 'Tokyo', 'Paris', 'Singapore', 'Sydney'
];

export const CitySearch = ({ onSearch, isLoading }: CitySearchProps) => {
  const [inputValue, setInputValue] = useState('');
  const [suggestions, setSuggestions] = useState<string[]>([]);
  const [showSuggestions, setShowSuggestions] = useState(false);

  // 本地模糊搜索
  const handleInputChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const value = e.target.value;
    setInputValue(value);
    
    if (value.trim()) {
      const filtered = POPULAR_CITIES.filter(city =>
        city.toLowerCase().includes(value.toLowerCase())
      );
      setSuggestions(filtered.slice(0, 5));
      setShowSuggestions(true);
    } else {
      setSuggestions([]);
      setShowSuggestions(false);
    }
  };

  const handleSearch = () => {
    if (inputValue.trim() && !isLoading) {
      onSearch(inputValue.trim());
      setShowSuggestions(false);
    }
  };

  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter') {
      handleSearch();
    }
  };

  const handleSuggestionClick = (city: string) => {
    setInputValue(city);
    onSearch(city);
    setShowSuggestions(false);
  };

  const handleClear = () => {
    setInputValue('');
    setSuggestions([]);
    setShowSuggestions(false);
  };

  return (
    <div className="relative w-full max-w-md mx-auto">
      <div className="relative flex items-center">
        <input
          type="text"
          value={inputValue}
          onChange={handleInputChange}
          onKeyDown={handleKeyDown}
          placeholder="输入城市名称..."
          className="w-full px-5 py-3 pr-24 text-gray-700 bg-white/90 backdrop-blur-sm rounded-2xl shadow-lg focus:outline-none focus:ring-2 focus:ring-blue-400 transition-all"

        />
        <div className="absolute right-2 flex gap-1">
          {inputValue && (
            <button
              onClick={handleClear}
              className="p-2 text-gray-400 hover:text-gray-600 rounded-full transition-colors"
            >
              <X size={18} />
            </button>
          )}
          <button

            <Search size={18} />
          </button>
        </div>
      </div>

      {/* 搜索建议下拉 */}
      {showSuggestions && suggestions.length > 0 && (
        <div className="absolute z-10 w-full mt-2 bg-white rounded-xl shadow-xl overflow-hidden">
          {suggestions.map((city) => (

              key={city}

            >
              {city}
            </button>

};
```

```tsx
    }
```

```tsx
  // 处理收藏
  const handleAddToFavorites = () => {
    if (weather && !cities.some(c => c.name === weather.city)) {
      addCity(weather.city);
    }
  };

  // 检查当前天气是否已被收藏
  const isCurrentFavorited = weather && cities.some(c => c.name === weather.city);

  // 首次加载时尝试显示默认城市
  useEffect(() => {
    if (cities.length > 0 && !currentCity) {
      loadWeather(cities[0].name);
    } else if (cities.length === 0) {
      loadWeather('北京');
    }
  }, []);

  return (
    <div className="min-h-screen bg-gradient-to-br from-blue-500 via-purple-500 to-pink-500 p-6">
      <div className="max-w-4xl mx-auto">
        {/* 头部 */}
        <div className="flex items-center justify-between mb-8">
          <div className="flex items-center gap-2">
            <CloudSun className="text-white" size={32} />
            <h1 className="text-3xl font-bold text-white tracking-tight">
              天气仪表盘
            </h1>
          </div>
          <a
            href="https://github.com/你的用户名/weather-dashboard"
            target="_blank"
            rel="noopener noreferrer"
            className="text-white/80 hover:text-white transition-colors"
          >
            <Github size={24} />
          </a>
        </div>

        {/* 搜索栏 */}
        <CitySearch onSearch={loadWeather} isLoading={loading} />

        {/* 收藏列表 */}
        <div className="mt-4">
          <SavedCities
            onSelectCity={loadWeather}
            currentCity={currentCity}
            isLoading={loading}
          />
        </div>

        {/* 错误提示 */}
        {error && (
          <div className="mt-6 p-4 bg-red-500/20 backdrop-blur-sm rounded-2xl text-white text-center">
            {error}
          </div>
        )}

        {/* 加载状态 */}
        {loading && (
          <div className="mt-12 text-center text-white">
            <div className="inline-block w-8 h-8 border-4 border-white/30 border-t-white rounded-full animate-spin"></div>
            <p className="mt-2">获取天气数据中...</p>
          </div>
        )}

        {/* 天气内容 */}
        {!loading && weather && (
          <>
            <div className="mt-6">
              <WeatherCard data={weather} />
            </div>
            
            {/* 收藏按钮 */}
            <div className="mt-3 flex justify-end">
              <button
                onClick={handleAddToFavorites}
                disabled={isCurrentFavorited}
                className={`flex items-center gap-2 px-4 py-2 rounded-xl backdrop-blur-sm transition-all ${
                  isCurrentFavorited
                    ? 'bg-yellow-500/30 text-yellow-200 cursor-default'
                    : 'bg-white/20 text-white hover:bg-white/30'
                }`}
              >
                <Star size={18} fill={isCurrentFavorited ? 'currentColor' : 'none'} />
                {isCurrentFavorited ? '已收藏' : '收藏此城市'}
              </button>
            </div>
          </>
        )}

        {/* 预报图表 */}
        {!loading && forecast && forecast.length > 0 && (
          <div className="mt-6">
            <WeatherChart data={forecast} />
          </div>
        )}
      </div>
    </div>
  );
}

export default App;
```
