#### 三、简答题（每题5分，共4题，满分20分）

1. **简述最大间隔超平面的意义，为什么要选择最大间隔超平面？**  
   - 最大间隔超平面是位于两类训练样本“正中间”的划分超平面（1分）。  
   - 意义：该超平面对训练样本局部扰动的“容忍”性最好，泛化能力最强（2分）。  
   - 选择原因：现实中训练集存在局限性或噪声，最大间隔超平面受噪声影响最小，能有效降低未见样本的分类误差，避免模型过拟合（2分）。

2. **简述核函数的作用，以及核矩阵半正定的意义。**  
   - 核函数作用：隐式实现样本到高维特征空间的映射，无需直接计算高维特征空间的内积，解决原始空间线性不可分问题，同时降低计算复杂度（3分）。  
   - 核矩阵半正定的意义：核矩阵半正定是函数成为核函数的充要条件，保证了高维特征空间的内积具有良好的数学性质，使得优化问题有解（2分）。

3. **对比硬间隔支持向量机和软间隔支持向量机的区别，说明软间隔引入的必要性。**  
   - 区别：硬间隔要求所有样本满足\(y_i(w^T x_i + b) \geq 1\)，仅适用于线性可分样本；软间隔允许部分样本不满足该约束，通过引入松弛变量和正则化常数\(C\)平衡间隔与训练误差（3分）。  
   - 软间隔引入必要性：现实任务中，原始样本空间或特征空间中很难实现完全线性可分，硬间隔会导致模型无法训练或过拟合；软间隔能缓解过拟合，提高模型的泛化能力和实用性（2分）。

4. **简述表示定理的核心内容，以及其对核方法的意义。**  
   - 核心内容：令\(\mathbb{H}\)为核函数\(\kappa\)对应的再生核希尔伯特空间，对于任意单调递增函数\(\Omega\)和非负损失函数\(\ell\)，优化问题\(\min_{h \in \mathbb{H}} F(h) = \Omega(\|h\|_{\mathbb{H}}) + \ell(h(x_1),...,h(x_m))\)的最优解可表示为\(h^*(x) = \sum_{i=1}^m \alpha_i \kappa(x,x_i)\)（3分）。  
   - 对核方法的意义：表明无论损失函数和正则化项如何选择（满足条件），最优解都可通过核函数的线性组合表示，为核方法的广泛应用提供了理论基础，简化了模型求解过程（2分）。

#### 四、计算题（每题10分，共2题，满分20分）

1. **给定训练样本集\(D=\{(x_1,1),(x_2,1),(x_3,-1)\}\)，其中\(x_1=(1,1)^T\)，\(x_2=(2,2)^T\)，\(x_3=(0,0)^T\)，假设样本线性可分，求硬间隔支持向量机的最大间隔超平面\((w,b)\)及间隔\(\gamma\)。**  

   **步骤1：确定硬间隔优化目标（2分）**  
   优化目标为\(\min_{w,b} \frac{1}{2}\|w\|^2\)，约束条件\(y_i(w^T x_i + b) \geq 1\)，即：  
   \(w_1 + w_2 + b \geq 1\)（\(x_1\)），  
   \(2w_1 + 2w_2 + b \geq 1\)（\(x_2\)），  
   \(b \leq -1\)（\(x_3\)）。

   **步骤2：分析支持向量（3分）**  
   由于\(x_1\)和\(x_3\)距离超平面最近，为支持向量，满足等号约束：  
   \(w_1 + w_2 + b = 1\)，\(b = -1\)。

   **步骤3：求解\(w\)（3分）**  
   将\(b=-1\)代入，得\(w_1 + w_2 = 2\)；  
   优化目标\(\frac{1}{2}(w_1^2 + w_2^2)\)，由均值不等式，当\(w_1 = w_2 = 1\)时最小。

   **步骤4：计算间隔（2分）**  
   \(\|w\| = \sqrt{2}\)，间隔\(\gamma = \frac{2}{\|w\|} = \sqrt{2}\)。  
   最终超平面：\(x_1 + x_2 - 1 = 0\)（即\(w=(1,1)^T,b=-1\)），间隔\(\gamma = \sqrt{2}\)。

2. **已知SVR的\(\epsilon=0.5\)，\(C=1\)，某训练样本\((x_i,y_i)=(2,3)\)，模型预测值\(f(x_i)=2.3\)，计算该样本的\(\epsilon\)-不敏感损失，并说明该样本是否为SVR的支持向量。**  

   **步骤1：计算\(\epsilon\)-不敏感损失（6分）**  
   差值\(z = f(x_i) - y_i = -0.7\)，\(|z| = 0.7 > \epsilon = 0.5\)，故损失\(\ell_\epsilon(z) = |z| - \epsilon = 0.2\)。

   **步骤2：判断是否为支持向量（4分）**  
   SVR支持向量是满足\(|f(x_i) - y_i| > \epsilon\)的样本，本题\(0.7 > 0.5\)，因此该样本是SVR的支持向量。

#### 五、证明题（满分15分）

1. **证明：若\(\kappa(\cdot,\cdot)\)是核函数，则其对应的核矩阵\(K\)是半正定矩阵（定理6.1的必要性证明）。**  

   **证明：**  
   已知\(\kappa(\cdot,\cdot)\)是核函数，存在映射\(\phi: X \mapsto \mathbb{F}\)（\(\mathbb{F}\)为高维特征空间），使得\(\kappa(x_i,x_j) = \phi(x_i)^T \phi(x_j)\)（3分）。  
   核矩阵\(K \in \mathbb{R}^{m \times m}\)，元素\(K_{ij} = \kappa(x_i,x_j) = \phi(x_i)^T \phi(x_j)\)（2分）。  
   要证\(K\)半正定，需证对任意非零向量\(\alpha = (\alpha_1,...,\alpha_m)^T \in \mathbb{R}^m\)，有\(\alpha^T K \alpha \geq 0\)（3分）。  
   展开：  
   \[
   \alpha^T K \alpha = \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j \phi(x_i)^T \phi(x_j)
   \]（3分）  
   根据内积线性性质：  
   \[
   = \left( \sum_{i=1}^m \alpha_i \phi(x_i) \right)^T \left( \sum_{j=1}^m \alpha_j \phi(x_j) \right) = \|v\|^2 \geq 0
   \]（其中\(v = \sum_{i=1}^m \alpha_i \phi(x_i)\)）（3分）。  
   因此\(\alpha^T K \alpha \geq 0\)，即核矩阵\(K\)半正定（1分）。  
   定理6.1的必要性得证（1分）。

        \]（3分）

### 五、证明题答案

**证明**：  
已知\(\kappa(\cdot,\cdot)\)是核函数，则存在映射\(\phi: X \mapsto \mathbb{F}\)（\(\mathbb{F}\)为高维特征空间），使得\(\kappa(x_i,x_j) = \phi(x_i)^T \phi(x_j)\)。  
核矩阵\(K \in \mathbb{R}^{m \times m}\)的元素\(K_{ij} = \kappa(x_i,x_j) = \phi(x_i)^T \phi(x_j)\)。  
对任意非零向量\(\alpha = (\alpha_1,\alpha_2,...,\alpha_m)^T \in \mathbb{R}^m\)，有  
\[
\alpha^T K \alpha = \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j \phi(x_i)^T \phi(x_j) = \left( \sum_{i=1}^m \alpha_i \phi(x_i) \right)^T \left( \sum_{j=1}^m \alpha_j \phi(x_j) \right) = \|v\|^2 \geq 0,
\]  
其中\(v = \sum_{i=1}^m \alpha_i \phi(x_i)\)。因此\(\alpha^T K \alpha \geq 0\)，核矩阵\(K\)半正定。证毕。

### 三、简答题详细解析（每题5分，共4题，满分20分）

**1. 简述最大间隔超平面的意义，为什么要选择最大间隔超平面？**  
- **答案要点**：  
  - 最大间隔超平面是指以最大间隔将两类样本分开的超平面，它位于两类样本的“正中间”。  
  - 意义：该超平面对训练样本的局部扰动（噪声）具有最强的容忍性，即鲁棒性最好，从而泛化能力最强。  
  - 原因：现实任务中训练集通常包含噪声或采样误差，最大间隔超平面受这些扰动影响最小，能够更准确地对未见样本进行分类，降低过拟合风险。

**2. 简述核函数的作用，以及核矩阵半正定的意义。**  
- **答案要点**：  
  - 核函数作用：通过 \(\kappa(x_i,x_j)=\phi(x_i)^T\phi(x_j)\) 隐式地将样本从原始空间映射到高维特征空间，使得原本线性不可分的问题在高维空间中变得线性可分；同时避免直接计算高维特征向量，降低了计算复杂度（核技巧）。  
  - 核矩阵半正定的意义：核函数对应的核矩阵 \(K_{ij}=\kappa(x_i,x_j)\) 必须是半正定矩阵，这是Mercer定理的核心，也是函数能作为核函数的充要条件。半正定性保证了特征空间中存在内积表示，从而SVM等算法的优化问题是凸优化问题，有全局最优解。

**3. 对比硬间隔支持向量机和软间隔支持向量机的区别，说明软间隔引入的必要性。**  
- **答案要点**：  
  - **区别**：硬间隔要求所有样本严格满足 \(y_i(w^T x_i+b)\ge 1\)，仅适用于线性可分数据集；软间隔允许部分样本不满足该约束，通过引入松弛变量 \(\xi_i\) 和正则化常数 \(C\) 来平衡间隔大小与训练误差。  
  - **必要性**：现实任务中数据往往线性不可分（存在噪声或重叠），硬间隔无法找到可行解或导致过拟合；软间隔通过容忍少量误差，能够获得更好的泛化性能，是实际应用中的标准形式。

**4. 简述表示定理的核心内容，以及其对核方法的意义。**  
- **答案要点**：  
  - **核心内容**：设 \(\mathbb{H}\) 为核函数 \(\kappa\) 对应的再生核希尔伯特空间（RKHS），对于任意单调递增的正则化项 \(\Omega\) 和非负损失函数 \(\ell\)，优化问题 \(\min_{h\in\mathbb{H}} F(h)=\Omega(\|h\|_{\mathbb{H}})+\ell(h(x_1),\dots,h(x_m))\) 的最优解可以表示为 \(h^*(x)=\sum_{i=1}^m \alpha_i \kappa(x,x_i)\)，即核函数的线性组合。  
  - **意义**：表示定理说明了无论选择什么样的损失函数和正则化项，最优解都位于训练样本张成的有限维子空间中。这为核方法（如SVM、核岭回归等）提供了理论基石：任何RKHS中的学习问题都可以转化为有限维参数估计问题，从而能够高效求解。

### 四、计算题详细解析（每题10分，共2题，满分20分）

**1. 给定训练样本集 \(D=\{(x_1,1),(x_2,1),(x_3,-1)\}\)，其中 \(x_1=(1,1)^T\)，\(x_2=(2,2)^T\)，\(x_3=(0,0)^T\)，假设样本线性可分，求硬间隔支持向量机的最大间隔超平面 \((w,b)\) 及间隔 \(\gamma\)。**  

**详细步骤：**  

1. **设立优化目标**  
   硬间隔SVM要求：  
   \[
   \min_{w,b} \frac{1}{2}\|w\|^2 \quad \text{s.t.} \quad y_i(w^T x_i + b) \ge 1,\ i=1,2,3.
   \]  
   代入数据：  
   - 样本1: \((1,1), y=1\) → \(w_1 + w_2 + b \ge 1\)  
   - 样本2: \((2,2), y=1\) → \(2w_1 + 2w_2 + b \ge 1\)  
   - 样本3: \((0,0), y=-1\) → \( -b \ge 1\) 即 \(b \le -1\)

2. **分析支持向量**  
   由于样本2与样本1共线且距离超平面更远（因为 \((2,2)\) 是 \((1,1)\) 的缩放，若超平面使 \((1,1)\) 满足等式，则 \((2,2)\) 自动满足严格大于），因此最靠近超平面的点可能是 \(x_1\) 和 \(x_3\)。假设它们为支持向量，即满足等式：  
   \[
   w_1 + w_2 + b = 1 \quad \text{(1)}, \qquad b = -1 \quad \text{(2)}.
   \]  
   检查样本2：\(2w_1+2w_2+b = 2(w_1+w_2)-1\)。由(1)得 \(w_1+w_2=1-b=2\)，则 \(2\times2-1=3>1\)，满足约束，确认支持向量为 \(x_1,x_3\)。

3. **求解 \(w\)**  
   将 \(b=-1\) 代入(1)：\(w_1+w_2=2\)。  
   最小化 \(\frac{1}{2}(w_1^2+w_2^2)\) 在约束 \(w_1+w_2=2\) 下的解：由均值不等式，当 \(w_1=w_2=1\) 时平方和最小（也可用拉格朗日乘子法）。故 \(w=(1,1)^T\)。

4. **计算间隔**  
   \(\|w\| = \sqrt{1^2+1^2}=\sqrt{2}\)，间隔 \(\gamma = \frac{2}{\|w\|} = \frac{2}{\sqrt{2}} = \sqrt{2}\)。

5. **最终答案**  
   最大间隔超平面：\(x_1 + x_2 - 1 = 0\)，间隔 \(\gamma = \sqrt{2}\)。

### 五、证明题详细解析（满分15分）

**1. 证明：若 \(\kappa(\cdot,\cdot)\) 是核函数，则其对应的核矩阵 \(K\) 是半正定矩阵（定理6.1的必要性证明）。**  

**证明过程：**  

1. **由核函数定义**（3分）  
   若 \(\kappa\) 是核函数，则存在一个从输入空间到高维特征空间 \(\mathbb{F}\) 的映射 \(\phi: X \to \mathbb{F}\)，使得对所有 \(x_i,x_j\)，有 \(\kappa(x_i,x_j) = \phi(x_i)^T \phi(x_j)\)。

2. **写出核矩阵**（2分）  
   给定 \(m\) 个样本点 \(x_1,\dots,x_m\)，核矩阵 \(K \in \mathbb{R}^{m\times m}\) 定义为 \(K_{ij} = \kappa(x_i,x_j) = \phi(x_i)^T \phi(x_j)\)。

3. **要证半正定**（3分）  
   对于任意非零向量 \(\alpha = (\alpha_1,\dots,\alpha_m)^T \in \mathbb{R}^m\)，考虑二次型 \(\alpha^T K \alpha\)：
   \[
   \alpha^T K \alpha = \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j K_{ij} = \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j \big(\phi(x_i)^T \phi(x_j)\big).
   \]

4. **利用内积线性性质**（3分）  
   \[
   \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j \phi(x_i)^T \phi(x_j) = \left(\sum_{i=1}^m \alpha_i \phi(x_i)\right)^T \left(\sum_{j=1}^m \alpha_j \phi(x_j)\right).
   \]  
   令 \(v = \sum_{i=1}^m \alpha_i \phi(x_i)\)，则上式等于 \(v^T v = \|v\|^2\)。

5. **非负性**（1分）  
   向量范数的平方总是非负的，即 \(\|v\|^2 \ge 0\)。因此 \(\alpha^T K \alpha \ge 0\) 对所有 \(\alpha\) 成立。

6. **结论**（1分）  
   核矩阵 \(K\) 是半正定矩阵。必要性得证。  
   （注意：半正定允许零特征值，正定则要求严格大于0，这里只需半正定。）
