**1. 树状缩进式（适合展示文件夹/代码结构）**
```
项目文件/
├── src/
│   ├── main.py
│   └── utils.py
├── docs/
│   └── readme.md
└── config/
    └── settings.json
```

**2. 多级编号式（适合逻辑分级，如法律条文、技术规范）**
```
1. 项目概述
   1.1 背景说明
   1.2 研究目标
2. 实施方案
   2.1 阶段一：需求分析
   2.2 阶段二：系统设计
       2.2.1 数据库设计
       2.2.2 接口设计
```

**3. 缩进列表式（适合Word/PPT中的简洁层级）**
- **一级类别：销售数据**
  - **二级：2024年**
    - 三级：第一季度
    - 三级：第二季度
  - **二级：2025年**
    - 三级：第一季度（预估）

**4. 表格层级式（适合对比多个文件的属性）**
| 层级 | 文件/目录名称 | 类型   | 说明             |
|------|---------------|--------|------------------|
| 1    | 项目文件       | 根目录 | -                |
| 2    | ├─ src         | 目录   | 源代码           |
| 3    │  └─ main.py  | 文件   | 主程序入口       |
| 2    | ├─ docs        | 目录   | 文档             |

**选择建议：**
- 报告偏**技术/项目管理** → 用树状缩进式
- 报告偏**制度/流程说明** → 用多级编号式
- 报告需要**插入表格混排** → 用表格层级式
