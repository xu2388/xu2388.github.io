```
输入文本
```

**关键代码**:

```python
# 提取句子嵌入
def extract_embeddings(texts):
    outputs = erlangshen_model(input_ids, attention_mask)
    cls_emb = outputs.last_hidden_state[:, 0, :]  # [CLS] token
    mean_emb = torch.mean(outputs.last_hidden_state, dim=1)  # Mean pooling
    return torch.cat([cls_emb, mean_emb], dim=1)  # 1536维

# PCA降维
pca = PCA(n_components=128)
X_reduced = pca.fit_transform(X_embeddings)

svm = SVC(kernel='rbf', C=1.0, probability=True)
```

### 核心经验与发现

#### 1. **数据质量 > 数据量** ⭐
- 5,000条人工标注 > 60,000条BERT自动标注
- 84.98% vs 67.91%，差距17个百分点
- **结论**: 干净的标注比大量噪声数据更重要

#### 2. **预训练模型威力巨大** ⭐
- BERT微调: 93.27%（超越所有传统方法8%+）
- Erlangshen嵌入: 92.07%（无需训练BERT，性价比最高）
- **结论**: 预训练语言模型是NLP任务的利器

#### 3. **特征工程决定上限**
- TF-IDF: 84.98%（简单但有效）
- Word2Vec: 59.00%（小数据集效果差）
- Erlangshen嵌入: 92.07%（句子级语义理解）
- **结论**: 好的特征表示比复杂模型更重要

#### 4. **模型选择要考虑场景**

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 追求极致精度 | BERT微调 | 93.27%准确率 |
| **性价比最优** | **Erlangshen + SVM** | 92.07%，仅需20秒训练 |
| 实时性要求高 | TF-IDF + 朴素贝叶斯 | 毫秒级响应 |
| 需要可解释性 | TF-IDF + 逻辑回归 | 特征权重可见 |
| 资源受限 | TF-IDF + 朴素贝叶斯 | 轻量级部署 |

#### 5. **算法技巧不能弥补数据缺陷**
- 虚假标签算法: 92.07% → 57.69%（下降34%）
- 聚类一致性仅56.6%，无法替代人工标注
- **结论**: 数据质量是根本，算法技巧只是锦上添花
