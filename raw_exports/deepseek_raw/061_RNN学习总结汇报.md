        <div class="slide" data-index="2">
            <h2>🧠 1. RNN 基础</h2>
            <div class="row">
                <div class="col">
                    <h3>基本结构</h3>
                    <ul>
                        <li><strong>输入层</strong>：接受序列数据（文本、股价、语音等）</li>
                        <li><strong>隐藏层</strong>：循环连接维护“记忆”状态，包含过去信息</li>
                        <li><strong>输出层</strong>：每个时间步可产生输出</li>
                    </ul>
                    <div class="highlight-box">
                        <strong>核心思想</strong>：同一组权重在序列的每个时间步复用，捕获时序依赖。
                    </div>
                </div>
                <div class="col">
                    <div class="formula-block">
                        <div class="math">
                            $$h_t = \tanh(W_{ih} \cdot x_t + b_{ih} + W_{hh} \cdot h_{t-1} + b_{hh})$$
                        </div>
                        <div style="margin-top:8px;font-size:0.95rem;color:#8aa4d0;">
                            \(h_t\): 隐藏状态 · \(x_t\): 输入 · \(W\): 权重 · \(b\): 偏置
                        </div>
                    </div>
                    <div class="highlight-box green">
                        <strong>代码示例</strong> — PyTorch 简易 RNN
                    </div>
                    <pre><code class="language-python">class SimpleRNN(nn.Module):
        def __init__(self, input_size, hidden_size):
            super().__init__()
            self.rnn = nn.RNN(input_size, hidden_size, batch_first=True)
        def forward(self, x):
            out, _ = self.rnn(x)
            return out</code></pre>
                </div>
            </div>
        </div>

        <!-- ========================================================== -->
        <!-- SLIDE 4: RNN 数学模型 & 时间展开 -->
        <!-- ========================================================== -->
        <div class="slide" data-index="3">
            <h2>📐 数学模型 &amp; 时间展开</h2>
            <div class="row">
                <div class="col">
                    <h3>核心方程</h3>
                    <div class="formula-block">
                        <div class="math">
                            $$h_t = \sigma(W_{hh} \cdot h_{t-1} + W_{ih} \cdot x_t + b_h)$$
                        </div>
                        <div class="math" style="margin-top:6px;">
                            $$y_t = W_{ho} \cdot h_t + b_o$$
                        </div>
                        <div style="margin-top:6px;font-size:0.9rem;color:#8aa4d0;">
                            \(\sigma\): tanh 或 ReLU · \(y_t\): 输出
                        </div>
                    </div>
                    <div class="highlight-box">
                        <strong>时间展开</strong>：将 RNN 按时间步展开为深度等于序列长度的前馈网络，每个时间步共享权重。
                    </div>
                </div>
                <div class="col">
                    <h3>信息流动</h3>
                    <ul>
                        <li><strong>输入→隐藏</strong>：新输入与旧隐藏状态结合生成新状态</li>
                        <li><strong>隐藏→隐藏</strong>：循环连接使信息在时间步间传播</li>
                        <li><strong>隐藏→输出</strong>：每个时间步生成对应输出</li>
                    </ul>
                    <div class="highlight-box orange" style="margin-top:12px;">
                        <strong>缺点</strong>：长序列记忆弱，梯度消失/爆炸，训练耗时长。
                    </div>
                </div>
            </div>
        </div>

        <!-- SLIDE 5: 梯度消失与爆炸 -->
        <!-- ========================================================== -->
        <div class="slide" data-index="4">
            <h2>⚠️ 梯度消失 &amp; 梯度爆炸</h2>
            <div class="row">
                <div class="col">
                    <div class="highlight-box red">
                        <strong>根源</strong>：BPTT 中梯度沿时间步连乘，每步乘以 \(W^T\) 与 tanh 导数（≤1）。
                    </div>
                    <ul>
                        <li><strong>梯度消失</strong>：\(W\) 最大特征值 &lt; 1 → 指数衰减 → 长距离信息丢失</li>
                        <li><strong>梯度爆炸</strong>：\(W\) 最大特征值 &gt; 1 → 指数增长 → 训练不稳定</li>
                    </ul>
                    <div class="highlight-box" style="margin-top:12px;">
                        <strong>后果</strong>：序列开头的梯度传不到尾部，模型学不到长距离依赖。
                    </div>
                </div>
                <div class="col">
                    <h3>BPTT 直观理解</h3>
                    <div class="formula-block" style="text-align:left;font-size:1rem;">
                        <div>对 \(W\) 的总梯度 = \(\displaystyle \sum_{t=1}^{T} \frac{\partial L_t}{\partial W}\)</div>
                        <div style="margin-top:6px;color:#8aa4d0;">每个时间步的梯度沿时间回传并累加</div>
                        <div style="margin-top:10px;border-top:1px solid #253050;padding-top:10px;">
                            <span class="tag">例 T=3</span>
                            \[
                            \frac{\partial L_3}{\partial W} + \frac{\partial L_2}{\partial W} + \frac{\partial L_1}{\partial W}
                            \]
                        </div>
                    </div>
                    <div class="highlight-box green">
                        <strong>LSTM 的改进</strong>：细胞状态 \(c_t\) 采用加法更新，梯度沿 \(c_t\) 传递时主要乘以遗忘门 \(f_t\)，缓解消失。
                    </div>
                </div>
            </div>

        <!-- ========================================================== -->
        <div class="slide" data-index="6">
            <h2>🔮 2. LSTM — 长短期记忆</h2>
            <div class="row">
                <div class="col">
                    <h3>核心优势</h3>
                    <ul>
                        <li><strong>解决长期依赖</strong>：有效捕获远距离依赖关系</li>

                    </div>

                <div class="col">
                    <div style="background:rgba(255,255,255,0.03);border-radius:12px;padding:16px;border:1px solid #253050;">
                        <h4>数字求和任务示例</h4>
                        <ul>
                            <li>开头两个非零数字 → \(f_t \approx 1\) 保留，\(i_t \approx 1\) 写入</li>
                            <li>后续大量 0 → \(f_t \approx 0\) 屏蔽，\(i_t \approx 0\) 拒绝写入</li>
                            <li>\(c_t\) 始终保存前两数之和，无论序列多长</li>
                        </ul>
                        <div class="highlight-box green" style="margin-top:8px;">
                            ✅ 原生 RNN 无独立 \(c\) 传送带，梯度指数衰减，长距离信息丢失。
                        </div>
                    </div>
                </div>
            </div>
        </div>

        <!-- ========================================================== -->
        <!-- SLIDE 8: LSTM 门控机制详解 -->
        <!-- ========================================================== -->
        <div class="slide" data-index="7">
            <h2>🚪 LSTM 门控机制（4 步拆解）</h2>
            <div class="row">
                <div class="col">
                    <h3>步骤 1 &amp; 2</h3>
                    <ul>
                        <li><strong>拼接</strong>：\([h_{t-1}, x_t]\) 作为四路共享输入</li>
                        <li><strong>遗忘门</strong>：\(f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)\)<br>控制旧记忆保留多少</li>
                        <li><strong>输入门</strong>：\(i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)\)<br>控制新信息写入</li>
                        <li><strong>候选状态</strong>：\(\tilde{c}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)\)<br>准备写入的新信息</li>
                    </ul>
                </div>
                <div class="col">
                    <h3>步骤 3 &amp; 4</h3>
                    <ul>
                        <li><strong>更新细胞状态</strong>：<br>
                            \(c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t\)<br>
                            <span style="color:#8aa4d0;">旧记忆 × 遗忘门 + 新信息 × 输入门</span>
                        </li>
                        <li><strong>输出门</strong>：\(o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)\)<br>控制输出多少</li>
                        <li><strong>最终输出</strong>：\(h_t = o_t \odot \tanh(c_t)\)</li>
                    </ul>
                    <div class="highlight-box" style="margin-top:8px;">
                        <strong>核心传送带</strong>：\(c_t\) 线性传递，梯度稳定回传。
                    </div>
                </div>
            </div>
        </div>

        <!-- ========================================================== -->
        <!-- SLIDE 9: LSTM 数学公式 -->
        <!-- ========================================================== -->
        <div class="slide" data-index="8">
            <h2>📝 LSTM 数学公式</h2>
            <div class="formula-block">
                <div class="math">
                    \[
                    \begin{aligned}
                    f_t &amp;= \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) &amp; \text{(遗忘门)} \\
                    i_t &amp;= \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) &amp; \text{(输入门)} \\
                    \tilde{c}_t &amp;= \tanh(W_c \cdot [h_{t-1}, x_t] + b_c) &amp; \text{(候选状态)} \\
                    c_t &amp;= f_t \odot c_{t-1} + i_t \odot \tilde{c}_t &amp; \text{(细胞更新)} \\
                    o_t &amp;= \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) &amp; \text{(输出门)} \\
                    h_t &amp;= o_t \odot \tanh(c_t) &amp; \text{(隐藏输出)}
                    \end{aligned}
                    \]
                </div>
                <div style="margin-top:6px;font-size:0.95rem;color:#8aa4d0;">
                    \(\odot\): 逐元素乘 · \(\sigma\): sigmoid · 所有门控输出范围 [0, 1]
                </div>
            </div>
            <div class="row">
                <div class="col">
                    <div class="highlight-box green">
                        <strong>实现示例</strong> — PyTorch LSTM
                    </div>
                    <pre><code class="language-python">class LSTM(nn.Module):
        def __init__(self, input_size, hidden_size, output_size):
            super().__init__()
            self.lstm = nn.LSTM(input_size, hidden_size, batch_first=True)
            self.fc = nn.Linear(hidden_size, output_size)
        def forward(self, x, (h_0, c_0)):
            out, (h_n, c_n) = self.lstm(x, (h_0, c_0))
            return self.fc(out)</code></pre>
                </div>
                <div class="col">
                    <div class="highlight-box orange">
                        <strong>LSTM 缺点</strong>
                        <ul style="margin:6px 0 0 0;">
                            <li>计算复杂度高（更多参数）</li>
                            <li>内部机制不直观，难以解释</li>
                            <li>需要大量数据避免过拟合</li>
                        </ul>
                    </div>
                </div>
            </div>
        </div>

        <!-- ========================================================== -->
        <!-- SLIDE 10: 自回归 -->
        <!-- ========================================================== -->
        <div class="slide" data-index="9">
            <h2>🔄 3. 自回归（Autoregressive）</h2>
            <div class="row">
                <div class="col">
                    <h3>核心含义</h3>
                    <div class="highlight-box purple">
                        <strong>一句话</strong>：用模型自己上一时刻的输出，作为下一时刻的输入，一步步递推生成完整序列。
                    </div>
                    <div class="formula-block" style="text-align:left;">
                        <div class="math">
                            $$x_t = f(x_{t-1}, x_{t-2}, \dots, x_1)$$
                        </div>
                        <div style="color:#8aa4d0;font-size:0.95rem;">第 \(t\) 步由全部历史决定，不能看到未来</div>
                    </div>
                </div>
                <div class="col">
                    <h3>关键特点</h3>
                    <ul>
                        <li><strong>因果性</strong>：只能用到过去信息，符合真实生成逻辑</li>
                        <li><strong>串行性</strong>：必须等待前一步完成，无法并行</li>
                        <li><strong>误差累积</strong>：一步错，步步错 → “漂移问题”</li>
                    </ul>
                    <div class="highlight-box" style="margin-top:8px;">
                        <strong>与统计 AR 模型联系</strong>：深度学习自回归是 AR 模型的非线性拓展。
                    </div>
                </div>
            </div>
            <div style="margin-top:10px;background:rgba(255,255,255,0.03);border-radius:10px;padding:12px 18px;border:1px solid #253050;">
                <h4 style="margin:0 0 4px 0;font-size:1rem;">两种工作模式</h4>
                <ul style="margin:0;">
                    <li><strong>非自回归</strong>：输入完整序列，输出整体结果（如分类、求和）</li>
                    <li><strong>自回归</strong>：推理时上一步输出作为下一步输入（如文本续写、滚动预测）</li>
                </ul>
            </div>
        </div>

        <!-- ========================================================== -->
        <!-- SLIDE 11: RNN 参数学习 — BPTT -->
        <!-- ========================================================== -->
        <div class="slide" data-index="10">
            <h2>📉 4. RNN 参数学习 — BPTT</h2>
            <div class="row">
                <div class="col">
                    <h3>核心差异（vs CNN）</h3>
                    <ul>
                        <li><strong>CNN</strong>：空间维度共享，反向沿空间回传，路径短</li>
                        <li><strong>RNN</strong>：时间维度共享，反向沿时间回传（BPTT），路径 = 序列长度</li>
                    </ul>
                    <div class="highlight-box">
                        <strong>权重共享</strong>：RNN 只有三组核心权重 \(U, W, V\)，所有时间步复用，参数量与序列长度无关。
                    </div>
                </div>
                <div class="col">
                    <h3>前向 &amp; 反向</h3>
                    <div class="formula-block" style="text-align:left;">
                        <div class="math">
                            \[
                            \begin{aligned}
                            h_t &amp;= \tanh(W \cdot h_{t-1} + U \cdot x_t + b_h) \\
                            \hat{y}_t &amp;= \text{softmax}(V \cdot h_t + b_y)
                            \end{aligned}
                            \]
                        </div>
                        <div style="margin-top:6px;color:#8aa4d0;">
                            总损失：\(L = \sum_{t=1}^{T} L_t(\hat{y}_t, y_t)\)
                        </div>
                    </div>
                    <div class="highlight-box orange">
                        <strong>梯度累加</strong>：对 \(W\) 的总梯度 = 每个时间步产生的梯度之和。
                    </div>
                </div>
            </div>
        </div>

        <!-- ========================================================== -->
        <div class="slide" data-index="13">
            <h2>🔧 GRU — 门控循环单元</h2>
            <div class="row">
                <div class="col">
                    <h3>GRU 公式</h3>
                    <div class="formula-block" style="text-align:left;">
                        <div class="math">
                            \[
                            \begin{aligned}
                            r_t &amp;= \sigma(W_r \cdot [h_{t-1}, x_t] + b_r) &amp; \text{(重置门)} \\
                            z_t &amp;= \sigma(W_z \cdot [h_{t-1}, x_t] + b_z) &amp; \text{(更新门)} \\
                            \tilde{h}_t &amp;= \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h) &amp; \text{(候选状态)} \\
                            h_t &amp;= (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t &amp; \text{(最终状态)}
                            \end{aligned}
                            \]
                        </div>
                    </div>
                    <div class="highlight-box">
                        <strong>重置门 \(r_t\)</strong>：控制计算候选状态时对旧状态的依赖程度。<br>
                        \(r_t \to 0\)：忽略历史，仅靠当前输入 → “重置记忆”
                    </div>
                </div>
                <div class="col">
                    <h3>实现示例</h3>
                    <pre><code class="language-python">class GRU(nn.Module):
        def __init__(self, input_size, hidden_size, output_size):
            super().__init__()
            self.gru = nn.GRU(input_size, hidden_size, batch_first=True)
            self.fc = nn.Linear(hidden_size, output_size)
        def forward(self, x, h_0):
            out, h_n = self.gru(x, h_0)
            return self.fc(out)</code></pre>
                    <div style="margin-top:12px;background:rgba(255,255,255,0.03);border-radius:8px;padding:12px;border:1px solid #253050;">
                        <h4 style="margin:0 0 4px 0;font-size:1rem;">GRU 优势</h4>
                        <ul style="margin:0;">
                            <li>计算效率更高，参数量少</li>
                            <li>与 LSTM 性能相近</li>
                            <li>适合快速迭代实验</li>
                        </ul>
                    </div>
                </div>
            </div>

        (function() {
            'use strict';

            const slides = document.querySelectorAll('.slide');
            const total = slides.length;
            let current = 0;

            const prevBtn = document.getElementById('prevBtn');
            const nextBtn = document.getElementById('nextBtn');
            const counter = document.getElementById('slideCounter');
            const progress = document.getElementById('progressBar');

            function updateSlide(index) {
                // 边界
                if (index < 0) index = 0;
                if (index >= total) index = total - 1;
                current = index;

                // 切换 active
                slides.forEach((el, i) => {
                    el.classList.toggle('active', i === current);
                });

                // 按钮状态
                prevBtn.classList.toggle('disabled', current === 0);
                nextBtn.classList.toggle('disabled', current === total - 1);

                // 页码
                counter.textContent = (current + 1) + ' / ' + total;

                // 进度条
                const pct = ((current + 1) / total) * 100;
                progress.style.width = pct + '%';

                // 滚动到顶部
                slides[current].scrollTop = 0;
            }

            function next() {
                if (current < total - 1) updateSlide(current + 1);
            }

            function prev() {
                if (current > 0) updateSlide(current - 1);
            }

            // 事件绑定
            prevBtn.addEventListener('click', prev);
            nextBtn.addEventListener('click', next);

            document.addEventListener('keydown', (e) => {
                if (e.key === 'ArrowRight' || e.key === 'ArrowDown' || e.key === ' ') {
                    e.preventDefault();
                    next();
                } else if (e.key === 'ArrowLeft' || e.key === 'ArrowUp') {
                    e.preventDefault();
                    prev();
                } else if (e.key === 'Home') {
                    e.preventDefault();
                    updateSlide(0);
                } else if (e.key === 'End') {
                    e.preventDefault();
                    updateSlide(total - 1);
                }
            });

            // 触屏滑动支持
            let touchStartX = 0;
            let touchStartY = 0;
            document.addEventListener('touchstart', (e) => {
                touchStartX = e.changedTouches[0].screenX;
                touchStartY = e.changedTouches[0].screenY;
            });
            document.addEventListener('touchend', (e) => {
                const dx = e.changedTouches[0].screenX - touchStartX;
                const dy = e.changedTouches[0].screenY - touchStartY;
                if (Math.abs(dx) > Math.abs(dy) && Math.abs(dx) > 40) {
                    if (dx < 0) next();
                    else prev();
                }
            });

            // 鼠标滚轮（防抖）
            let wheelTimeout = false;
            document.addEventListener('wheel', (e) => {
                if (wheelTimeout) return;
                // 仅在幻灯片区域滚动
                const target = e.target.closest('.slide');
                if (!target) return;
                // 如果内容可滚动且未到底部，不触发翻页
                const scrollable = target.scrollHeight > target.clientHeight;
                if (scrollable) {
                    const atTop = target.scrollTop === 0;
                    const atBottom = target.scrollTop + target.clientHeight >= target.scrollHeight - 2;
                    if (e.deltaY > 0 && !atBottom) return;
                    if (e.deltaY < 0 && !atTop) return;
                }
                e.preventDefault();
                wheelTimeout = true;
                if (e.deltaY > 0) next();
                else prev();
                setTimeout(() => { wheelTimeout = false; }, 600);
