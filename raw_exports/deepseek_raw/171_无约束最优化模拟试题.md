4.  对于下降算法，若产生的迭代序列 \(\{x^k\}\) 满足 \(\lim_{k\to\infty} \frac{\|x^{k+1}-x^*\|}{\|x^k-x^*\|} = 0\)，则称该序列的收敛速度是（ ）。

## 参考答案及评分标准

### 一、选择题（每题4分，共20分）

1.  **D**。解析：全局解是定义在整个定义域上的最小值点，一定是某个邻域内的最小值点，因此一定是局部解。反之则不一定（课件第3页）。
2.  **C**。解析：局部极小点的二阶必要条件是Hessian矩阵半正定，而非正定。正定是二阶充分条件的一部分（课件第6-8页）。
3.  **A**。解析：黄金分割法中，两个试探点关于区间对称，且缩短率为0.618。左试探点距左端点距离为区间长的0.382倍，即 \(a + 0.382(b-a)\)，右试探点为 \(a + 0.618(b-a)\)（课件第23-26页）。
4.  **B**。解析：收敛速度定义：\(0<\beta<1\)为线性，\(\beta=0\)为超线性，\(\beta=1\)为次线性（课件第49页）。
5.  **B**。解析：二次终止性是评价算法对正定二次函数求解效率的重要指标（课件第51页）。

### 三、简答题（共20分）

1.  **参考答案**（10分）：
    **基本迭代格式**：从一个初始点 \(x^1\) 出发，按照如下规则产生迭代序列：
    \[
    x^{k+1} = x^k + a_k d^k, \quad k = 1, 2, \dots
    \]
    其中 \(d^k\) 为搜索方向，\(a_k > 0\) 为步长。（4分）
    **基本要求**：
    - **对 \(d^k\) 的要求**：必须是下降方向，即满足 \(\nabla f(x^k)^T d^k < 0\)。理想情况下，该方向应与负梯度方向夹角小于90度，以保证函数值有“充分”下降。（3分）
    - **对 \(a_k\) 的要求**：通过某种线性搜索（精确或非精确）选取，使得 \(f(x^{k+1}) = f(x^k + a_k d^k) < f(x^k)\)，即保证目标函数值单调下降。（3分）

2.  **参考答案**（10分）：
    **精确线性搜索**：在给定搜索方向 \(d^k\) 后，沿着该方向寻找一个步长 \(\alpha_k\)，使得一元函数 \(\phi(\alpha) = f(x^k + \alpha d^k)\) 达到其最小值。（5分）
    **数学定义**：
    \[
    \phi(\alpha_k) = \min_{\alpha \ge 0} f(x^k + \alpha d^k)
    \]
    **正定二次函数的精确步长公式**：（5分）
    \[
    \alpha_k = -\frac{d^{k^T} \nabla f(x^k)}{d^{k^T} G d^k}
    \]
    其中 \(G\) 是正定二次函数的Hessian矩阵。或者根据课件第15页的符号，若 \(f(x) = \frac{1}{2} x^T H x + C^T x + b\)，则 \(\alpha_k = -\frac{d^{k^T} (H x^k + C)}{d^{k^T} H d^k}\)。

### 四、计算题（25分）

**解：**
给定 \(f(x) = x^2 + 2x\)，区间 \([a, b] = [-3, 5]\)，缩短率 \(\tau = 0.618\)。
**初始区间长度** \(L_0 = 5 - (-3) = 8\)。

**第一次迭代：**
- 左试探点：\(x_1 = a + (1-\tau)(b-a) = -3 + 0.382 \times 8 = -3 + 3.056 = 0.0560\)
- 右试探点：\(x_2 = a + \tau (b-a) = -3 + 0.618 \times 8 = -3 + 4.944 = 1.9440\)
- 计算函数值：
  \(f(x_1) = (0.0560)^2 + 2 \times 0.0560 = 0.0031 + 0.1120 = 0.1151\)
  \(f(x_2) = (1.9440)^2 + 2 \times 1.9440 = 3.7791 + 3.8880 = 7.6671\)
- 比较：\(f(x_1) < f(x_2)\)，因此舍去右区间 \([x_2, b] = [1.9440, 5]\)。
- **新区间**：\([a_1, b_1] = [a, x_2] = [-3, 1.9440]\)，长度 \(L_1 = 4.9440\)。

**第二次迭代：**
新区间 \([a, b] = [-3, 1.9440]\)，长度 \(L = 4.9440\)。
- 新左试探点：注意 \(x_1\) 在原区间中已经计算过，它成为了新区间的右试探点。
  \(x_1' = a + (1-\tau)L = -3 + 0.382 \times 4.9440 = -3 + 1.8886 = -1.1114\)
- 右试探点：\(x_2' = a + \tau L = -3 + 0.618 \times 4.9440 = -3 + 3.0554 = 0.0554\) （由于舍入误差，此值应等于第一次迭代的左试探点0.0560）
- 计算函数值：
  \(f(x_1') = (-1.1114)^2 + 2 \times (-1.1114) = 1.2352 - 2.2228 = -0.9876\)
  \(f(x_2') = (0.0554)^2 + 2 \times 0.0554 = 0.0031 + 0.1108 = 0.1139\)
- 比较：\(f(x_1') < f(x_2')\)，因此舍去右区间 \([x_2', b] = [0.0554, 1.9440]\)。
- **新区间**：\([a_2, b_2] = [a, x_2'] = [-3, 0.0554]\)。（或精确地，\([ -3, 0.0560 ]\)）

### 五、证明题（20分）

**证明：**

1.  **证明一阶必要条件 \(\nabla f(x^*) = 0\)** （10分）：
    对任意的非零方向 \(d \in \mathbb{R}^n\)，构造函数 \(\varphi(\alpha) = f(x^* + \alpha d)\)。
    由于 \(x^*\) 是 \(f\) 的局部极小点，则 \(\alpha=0\) 是 \(\varphi(\alpha)\) 的局部极小点。
    根据一元函数极小点的一阶必要条件，有 \(\varphi'(0) = 0\)。
    又因为 \(\varphi'(\alpha) = \nabla f(x^* + \alpha d)^T d\)，所以 \(\varphi'(0) = \nabla f(x^*)^T d = 0\)。
    由于方向 \(d\) 是任意的，要使 \(\nabla f(x^*)^T d = 0\) 对任意 \(d\) 都成立，必有 \(\nabla f(x^*) = 0\)。证毕。

2.  **证明二阶必要条件 \(\nabla^2 f(x^*)\) 是半正定矩阵** （10分）：
    由一阶必要条件已知 \(\nabla f(x^*) = 0\)。
    对任意非零方向 \(d \in \mathbb{R}^n\)，由 \(x^*\) 是局部极小点知，存在 \(\varepsilon > 0\)，使得对任意 \(0 < \alpha < \varepsilon\)，有
    \[
    f(x^* + \alpha d) \ge f(x^*)
    \]
    将 \(f(x^* + \alpha d)\) 在 \(x^*\) 处作二阶泰勒展开：
    \[
    f(x^* + \alpha d) = f(x^*) + \alpha \nabla f(x^*)^T d + \frac{1}{2} \alpha^2 d^T \nabla^2 f(x^*) d + o(\alpha^2)
    \]
    代入 \(\nabla f(x^*) = 0\)，并移项得：
    \[
    \frac{1}{2} \alpha^2 d^T \nabla^2 f(x^*) d + o(\alpha^2) \ge 0
    \]
    两边同除以 \(\alpha^2\)，并令 \(\alpha \to 0^+\)，可得：
    \[
    d^T \nabla^2 f(x^*) d \ge 0
    \]
    由于 \(d\) 是任意非零向量，根据半正定矩阵的定义，\(\nabla^2 f(x^*)\) 是半正定矩阵。证毕。
