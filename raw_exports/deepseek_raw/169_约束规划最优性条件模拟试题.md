这个课件讲的是约束规划的最优性条件，内容挺丰富的。从基本概念开始，有局部解、全局解、严格局部解这些定义。然后讲可行方向FD*和线性化可行方向LD*，还有它们之间的关系，FD*包含于LD*，但反过来不一定成立。还有有效约束、非有效约束、有效集这些概念。

接着是约束限制条件，也就是保证LD*=FD*的条件，比如约束函数是线性的，或者梯度线性无关。然后就是一阶必要条件，也就是Kuhn-Tucker条件，这个很重要，课件里给了两种表述方式，还有证明过程用到了Farkas引理。还举了例子说明如果没有约束限制条件，局部解也不一定是K-T点。

二阶充分条件讲的是在K-T条件成立的基础上，再加上严格松弛互补条件，以及在某个临界方向集M上，Lagrange函数的Hesse矩阵正定，就能保证是严格局部解。课件里还给了证明思路，用反证法。

最后是凸规划的内容，凸规划的定义是目标函数凸、可行域凸。课件里证明了凸规划的局部解一定是全局解，而且如果K-T点存在，那一定是全局解。

### 三、计算题（每题15分，共30分）

#### 1. 求K-T点并判断全局解

**问题：**
\[
\begin{align*}
\min \quad & f(x) = x_1^2 + x_2^2 \\
\text{s.t.} \quad & c_1(x) = x_1 + x_2 - 2 \le 0 \\
& c_2(x) = -x_1 \le 0 \\
& c_3(x) = -x_2 \le 0
\end{align*}
\]

**解：**  
Lagrange函数  
\[
L(x, \lambda) = x_1^2 + x_2^2 + \lambda_1 (x_1 + x_2 - 2) + \lambda_2 (-x_1) + \lambda_3 (-x_2)
\]  
K-T条件：
\[
\begin{cases}
\frac{\partial L}{\partial x_1} = 2x_1 + \lambda_1 - \lambda_2 = 0 \\
\frac{\partial L}{\partial x_2} = 2x_2 + \lambda_1 - \lambda_3 = 0 \\
c_1(x) \le 0, \ c_2(x) \le 0, \ c_3(x) \le 0 \\
\lambda_1 \ge 0, \ \lambda_2 \ge 0, \ \lambda_3 \ge 0 \\
\lambda_1 (x_1 + x_2 - 2) = 0, \ \lambda_2 (-x_1) = 0, \ \lambda_3 (-x_2) = 0
\end{cases}
\]

**分析：**  
由非负约束 \( x_1 \ge 0, x_2 \ge 0 \)（因为 \( -x_1 \le 0 \Rightarrow x_1 \ge 0 \)），可行域为三角形区域（包括边界）。

尝试 \( x_1 > 0, x_2 > 0 \)，则 \( \lambda_2 = 0, \lambda_3 = 0 \)。梯度条件变为：
\[
2x_1 + \lambda_1 = 0, \quad 2x_2 + \lambda_1 = 0
\]
由于 \( \lambda_1 \ge 0 \)，由第一式得 \( 2x_1 = -\lambda_1 \le 0 \Rightarrow x_1 \le 0 \)，与 \( x_1 > 0 \) 矛盾。故不可能 \( x_1 > 0, x_2 > 0 \)。

尝试边界 \( x_1 = 0, x_2 > 0 \)：则 \( \lambda_2 \ge 0 \) 不一定为0。由互补松弛：\( \lambda_2 (-x_1)=0 \) 自动满足。梯度：
\[
2\cdot 0 + \lambda_1 - \lambda_2 = 0 \Rightarrow \lambda_1 = \lambda_2
\]
\[
2x_2 + \lambda_1 - \lambda_3 = 0
\]
若 \( x_2 > 0 \)，则 \( \lambda_3 = 0 \)，得 \( 2x_2 + \lambda_1 = 0 \Rightarrow \lambda_1 = -2x_2 < 0 \)，与 \( \lambda_1 \ge 0 \) 矛盾。

尝试 \( x_2 = 0, x_1 > 0 \)：对称得矛盾。

尝试 \( x_1 = 0, x_2 = 0 \)：则 \( \lambda_2, \lambda_3 \) 自由，梯度：
\[
\lambda_1 - \lambda_2 = 0, \quad \lambda_1 - \lambda_3 = 0
\]
可行条件：\( x_1 + x_2 - 2 = -2 \le 0 \) 满足。取 \( \lambda_1 = 0 \)，则 \( \lambda_2 = 0, \lambda_3 = 0 \) 满足非负。故 \( x^* = (0,0)^T \) 是一个K-T点，乘子 \( \lambda^* = (0,0,0)^T \)。

**全局性判断：** 目标函数 \( f(x) = x_1^2 + x_2^2 \) 是凸函数，约束均为线性（凸），故为凸规划。凸规划的K-T点必为全局解。因此 \( x^* = (0,0)^T \) 是全局极小点，最小值为0。

**答案：** K-T点为 \( (0,0)^T \)，且是全局解。

---

#### 2. 验证二阶充分条件

**问题：**
\[
\min f(x) = x_1^2 - x_2^2, \quad \text{s.t. } c(x) = x_1^2 + x_2^2 - 1 = 0
\]
已知K-T点 \( x^* = (1,0)^T \)，乘子 \( \lambda^* = -1 \)。

**解：**  
首先验证一阶条件：  
\[
\nabla f = (2x_1, -2x_2)^T, \quad \nabla c = (2x_1, 2x_2)^T
\]
在 \( (1,0) \) 处：\( \nabla f = (2,0) \)，\( \nabla c = (2,0) \)。  
\[
\nabla f + \lambda \nabla c = (2,0) + (-1)(2,0) = (0,0)
\]
满足。

**二阶充分条件：**  
Lagrange函数 \( L(x, \lambda) = x_1^2 - x_2^2 + \lambda (x_1^2 + x_2^2 - 1) \)。  
Hesse矩阵：
\[
\nabla^2 L = \begin{pmatrix} 2 + 2\lambda & 0 \\ 0 & -2 + 2\lambda \end{pmatrix}
\]
在 \( \lambda^* = -1 \) 时：
\[
\nabla^2 L(x^*, \lambda^*) = \begin{pmatrix} 0 & 0 \\ 0 & -4 \end{pmatrix}
\]

**临界方向集 \( M \)**：  
有效约束指标 \( I(x^*) = \{1\} \)（等式约束始终有效）。  
\[
M = \{ d \neq 0 \mid \nabla c(x^*)^T d = 0 \}
\]
\[
\nabla c(x^*) = (2,0) \Rightarrow 2d_1 = 0 \Rightarrow d_1 = 0
\]
所以 \( M = \{ (0, d_2)^T \mid d_2 \neq 0 \} \)。

计算二次型：  
\[
d^T \nabla^2 L d = (0, d_2) \begin{pmatrix} 0 & 0 \\ 0 & -4 \end{pmatrix} \begin{pmatrix} 0 \\ d_2 \end{pmatrix} = -4 d_2^2 < 0
\]
不满足 \( d^T \nabla^2 L d > 0 \)（实际上为负）。因此**二阶充分条件不成立**，该点不是严格局部极小点（实际上它是鞍点，因为沿约束方向 \( x_1=1 \) 运动时 \( f \) 减小）。

**答案：** 不满足二阶充分条件。

### 四、证明题（共30分）

**题目：** 设 \( x^* \) 是约束优化问题的局部解，且在该点处约束限制条件成立（即 \( FD^* = LD^* \)）。试证明存在乘子 \( \lambda^* \) 使得Kuhn-Tucker条件成立。

**证明：**  

1. **局部解的必要条件**  
   已知 \( x^* \) 是局部解，则不存在可行下降方向，即  
   \[
   FD^* \cap DD^* = \emptyset
   \]
   其中 \( DD^* = \{ d \mid \nabla f(x^*)^T d < 0 \} \)。

2. **利用约束限制条件**  
   由假设 \( FD^* = LD^* \)，因此  
   \[
   LD^* \cap DD^* = \emptyset
   \]
   其中  
   \[
   LD^* = \{ d \neq 0 \mid \nabla c_i(x^*)^T d = 0, \forall i \in E; \ \nabla c_i(x^*)^T d \le 0, \forall i \in I(x^*) \}
   \]

3. **转化为线性不等式组无解**  
   系统  
   \[
   \begin{cases}
   \nabla c_i(x^*)^T d = 0, & i \in E \\
   \nabla c_i(x^*)^T d \le 0, & i \in I(x^*) \\
   \nabla f(x^*)^T d < 0
   \end{cases}
   \]
   无解。将等式拆分为两个不等式：  
   \[
   \nabla c_i(x^*)^T d \le 0, \quad -\nabla c_i(x^*)^T d \le 0, \quad i \in E
   \]
   于是得到形如 \( A d \le 0, \ \omega^T d > 0 \) 的无解系统，其中 \( A \) 的行由 \( \nabla c_i (i\in E) \)、\( -\nabla c_i (i\in E) \)、\( \nabla c_i (i\in I(x^*)) \) 构成，\( \omega = -\nabla f(x^*) \)。

4. **应用Farkas引理**  
   Farkas引理：\( A d \le 0, \ \omega^T d > 0 \) 无解当且仅当存在非负向量 \( y \) 使得 \( A^T y = \omega \)。  
   因此存在非负乘子 \( u_i^+, u_i^- (i\in E) \) 和 \( v_i (i\in I(x^*)) \) 使得  
   \[
   -\nabla f(x^*) = \sum_{i\in E} u_i^+ \nabla c_i(x^*) + \sum_{i\in E} u_i^- (-\nabla c_i(x^*)) + \sum_{i\in I(x^*)} v_i \nabla c_i(x^*)
   \]
   整理得  
   \[
   \nabla f(x^*) + \sum_{i\in E} (u_i^+ - u_i^-) \nabla c_i(x^*) + \sum_{i\in I(x^*)} v_i \nabla c_i(x^*) = 0
   \]
   令 \( \lambda_i = u_i^+ - u_i^- \) 对于 \( i\in E \)（无符号限制），\( \lambda_i = v_i \ge 0 \) 对于 \( i\in I(x^*) \)，并对于 \( i \in I \setminus I(x^*) \) 取 \( \lambda_i = 0 \)。则得到：
   \[
   \nabla f(x^*) + \sum_{i=1}^{l+m} \lambda_i \nabla c_i(x^*) = 0
   \]
   且满足 \( \lambda_i \ge 0 \ (i\in I) \)，\( \lambda_i c_i(x^*) = 0 \ (i\in I) \)（因为当 \( i\notin I(x^*) \) 时 \( c_i(x^*) < 0 \) 迫使 \( \lambda_i = 0 \)）。

5. **结论**  
   因此存在乘子向量 \( \lambda^* \) 使得Kuhn-Tucker条件成立。证毕。
