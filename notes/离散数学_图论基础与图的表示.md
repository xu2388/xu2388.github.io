## 一、概述

图论研究的对象很朴素：一组点，以及点与点之间的一些连线。但正是这种极简的结构，能够描述交通网络、社交关系、任务依赖、电路连接、状态转移等大量问题。离散数学中的图论侧重定义、计数与存在性判定，数据结构中的图论侧重存储与算法，两者使用的是同一套语言，只是关注点不同。

本笔记先厘清图的基本类型和度的定义，重点说明握手定理为什么成立、度序列满足什么条件才可图；接着讨论完全图、二部图、完全二部图的边数公式与识别方法；然后区分通路、迹、圈这几个容易混淆的术语，给出连通性、割点、桥的概念；在此基础上整理欧拉回路与哈密顿圈的判定条件，并用彼得森图说明“必要条件是必要条件，充分条件是充分条件”；最后介绍树与生成树、邻接矩阵与关联矩阵，以及图同构的直观判断。

约定：无向图记为 $G=(V,E)$，$|V|=n$，$|E|=m$；除非特别说明，讨论的是简单图，即没有自环、没有重边。有向图的边称为弧，记为 $(u,v)$，方向从 $u$ 指向 $v$。

## 二、图的基本定义与分类

### 2.1 无向图与有向图

无向图由顶点集 $V$ 和边集 $E$ 组成，每条边是 $V$ 的一个二元子集 $\{u,v\}$，表示 $u$ 与 $v$ 之间有连接，不区分方向。有向图的每条边是有序对 $(u,v)$，表示从 $u$ 指向 $v$ 的弧，$u$ 称为尾，$v$ 称为头。

与边相关的术语有：边的两个端点、边与端点关联、两个端点相邻、顶点与顶点相邻。若一条边的两个端点相同，称为自环；若两条边连接同一对顶点，称为重边。允许重边的图称为多重图，允许自环的图称为伪图。简单图既不允许自环也不允许重边，是讨论最多的一类。

有向图中，顶点的入度 $d^-(v)$ 是以 $v$ 为头的弧数，出度 $d^+(v)$ 是以 $v$ 为尾的弧数，总度数为两者之和。无向图中没有方向，只有一个度 $d(v)$。

以 $V=\{a,b,c,d\}$、$E=\{ab,ac,bc,bd\}$ 为例，各顶点的度为

$$
d(a)=2,\quad d(b)=3,\quad d(c)=2,\quad d(d)=1.
$$

度之和为 $8$，边数为 $4$，恰好是边数的两倍。

### 2.2 子图、补图与导出子图

设 $G=(V,E)$。若 $V'\subseteq V$、$E'\subseteq E$，且 $E'$ 中每条边的端点都在 $V'$ 中，则 $G'=(V',E')$ 是 $G$ 的子图。若 $V'=V$，称为生成子图；若 $E'$ 包含 $E$ 中所有两个端点都在 $V'$ 中的边，称为由 $V'$ 导出的子图，记为 $G[V']$。

补图 $\overline{G}$ 与原图有相同的顶点集，两个顶点在 $\overline{G}$ 中相邻当且仅当它们在 $G$ 中不相邻。完全图 $K_n$ 的补图是 $n$ 个孤立点组成的空图，空图的补图是完全图。补图把“有边”与“无边”互换，很多关于独立集、团、二部图的命题都可以在补图中重新表述。

### 2.3 图的同构直觉

两个图同构，指存在一个双射 $f:V_1\to V_2$，使得 $u,v$ 在 $G_1$ 中相邻当且仅当 $f(u),f(v)$ 在 $G_2$ 中相邻。同构的图在“连接方式”上完全相同，只是顶点被重新命名、画法被重新摆放。

判断同构没有简单的充要条件，通常先比较不变量：顶点数、边数、度序列、连通分量数、围长、各长度圈的数量、是否二部、邻接矩阵的特征值等。若某个不变量不同，一定不同构；但所有不变量都相同，也不一定同构。例如 $K_{3,3}$ 与三角棱柱图都有 6 个顶点、9 条边、每个顶点度为 3，但前者是二部图、没有三角形，后者含三角形，因此不同构。这个例子说明度序列相同远远不够。

## 三、度与握手定理

### 3.1 度的基本性质

无向图中，顶点 $v$ 的度是与 $v$ 关联的边数，自环对度的贡献为 2，因为自环的两端都是 $v$。图的最大度记为 $\Delta(G)$，最小度记为 $\delta(G)$。若每个顶点的度都是 $k$，称图为 $k$-正则图。完全图 $K_n$ 是 $(n-1)$-正则图，圈 $C_n$ 是 2-正则图，彼得森图是 3-正则图。

有向图中，每条弧对尾贡献一个出度、对头贡献一个入度，因此所有顶点的入度之和等于出度之和，都等于弧数：

$$
\sum_{v\in V} d^-(v)=\sum_{v\in V} d^+(v)=m.
$$

### 3.2 握手定理

无向图的所有顶点度之和等于边数的两倍：

$$
\sum_{v\in V} d(v)=2m.
$$

证明用双重计数：每条边有两个端点，对两个端点的度各贡献 1，因此把所有顶点的度相加，每条边恰好被数了两次。自环也适用：自环对同一个顶点贡献 2，仍然被数了两次。

由握手定理可以推出几条常用结论。

第一，度之和一定是偶数。因此不可能存在一个图，其度序列为 $3,3,3,1$（和为 10，虽为偶数，但还要看可图性）；更直接地，若度之和为奇数，一定不存在。

第二，奇度顶点的个数一定是偶数。因为度之和为偶数，偶度顶点贡献偶数，奇度顶点必须成对出现才能让总和为偶数。

第三，平均度为 $2m/n$。若平均度大于 $2$，图中必有度至少为 $3$ 的顶点；若最小度 $\delta\ge 2$，图中必有圈（从任意顶点一直走，必然重复经过某个顶点）。

以度序列 $4,3,3,3,2,1$ 为例，度之和为 $16$，故边数为 $8$；奇度顶点有四个（三个 3 和一个 1），个数为偶数，符合握手定理。

### 3.3 度序列的可图性

握手定理只是必要条件，不是充分条件。判断一个非负整数序列能否成为某个简单图的度序列，常用 Havel–Hakimi 算法：每次取最大的度 $d$，删去它，并把剩余序列中前 $d$ 大的度各减 1；若出现负数，则不可图；若序列最终全为 0，则可图。

以 $4,3,3,3,2,1$ 为例：

| 步骤 | 当前序列 | 操作 | 结果 |
| --- | --- | --- | --- |
| 1 | $4,3,3,3,2,1$ | 取 4，后四个减 1 | $2,2,2,1,1$ |
| 2 | $2,2,2,1,1$ | 取 2，后两个减 1 | $1,1,1,1$ |
| 3 | $1,1,1,1$ | 取 1，后一个减 1 | $0,1,1$ |
| 4 | $1,1,0$ | 取 1，后一个减 1 | $0,0$ |
| 5 | $0,0$ | 全为零 | 可图 |

再看 $3,3,1,1$：取 3，后三个减 1，得到 $2,0,0$；再取 2，后两个减 1，出现 $-1$，因此不可图。直观上，一个度为 3 的顶点要连向其余三个顶点，剩余三个顶点都被占用一次，其中两个原本度为 1 的顶点已经满足，度为 3 的另一个顶点还需要两条边，却已经没有可连的对象。

Havel–Hakimi 的正确性来自“最大度顶点一定可以与度最大的若干个顶点相连”的交换论证。实际手算时，只需按步骤执行，遇到负数或剩余度数超过剩余顶点数即可提前判定不可图。

## 四、完全图、二部图与完全二部图

### 4.1 完全图

完全图 $K_n$ 是 $n$ 个顶点两两相邻的简单图。边数为

$$
|E(K_n)|=\binom{n}{2}=\frac{n(n-1)}{2},
$$

每个顶点的度为 $n-1$，度之和为 $n(n-1)=2|E|$。前几个完全图的边数为：$K_1$ 有 0 条，$K_2$ 有 1 条，$K_3$ 有 3 条，$K_4$ 有 6 条，$K_5$ 有 10 条。

完全图是“边数最多”的简单图。给定 $n$ 个顶点，任何简单图的边数都不超过 $n(n-1)/2$；达到这个上界的图就是完全图。完全图的补图是空图，这一关系在判断补图结构时很有用。

### 4.2 二部图

若图 $G$ 的顶点集可以划分成两个不相交的子集 $X$ 与 $Y$，使得每条边的两个端点分别属于 $X$ 和 $Y$，则称 $G$ 为二部图，$X$ 与 $Y$ 称为两个部。等价地说，$X$ 内部没有边，$Y$ 内部也没有边，两个部都是独立集。有些教材要求两个部都非空，此时孤立点需要单独约定；本笔记按“允许一个部为空”的宽松定义处理，不影响主要结论。

二部图最常用的判定定理是：一个图是二部图，当且仅当它不含奇数长度的圈。必要性很简单：沿着二部图的边走，每走一步就从一个部切换到另一个部，走奇数步后必然停在另一个部，不可能回到起点，因此不存在奇圈。充分性可以用染色法证明：对每个连通分量做广度优先或深度优先遍历，把起点染成黑色，邻居染成白色，逐层交替；若某条边的两个端点被染成同色，沿这条边与遍历树上的路径就构成一个奇圈，矛盾；若整个图都能正常二染色，则按颜色划分两个部，图就是二部图。

```c
int color[MAXV];
int IsBipartite(int n, int adj[][MAXV], int deg[]) {
    for (int i = 0; i < n; i++) color[i] = -1;
    int queue[MAXV];
    for (int s = 0; s < n; s++) {
        if (color[s] != -1) continue;
        int head = 0, tail = 0;
        queue[tail++] = s;
        color[s] = 0;
        while (head < tail) {
            int u = queue[head++];
            for (int k = 0; k < deg[u]; k++) {
                int v = adj[u][k];
                if (color[v] == -1) {
                    color[v] = color[u] ^ 1;
                    queue[tail++] = v;
                } else if (color[v] == color[u]) {
                    return 0;
                }
            }
        }
    }
    return 1;
}
```

这段代码对每个连通分量分别染色，因此非连通图也能正确处理。若只从一个顶点出发，其他分量可能被漏掉。

常见的二部图有：偶数长度的圈 $C_{2k}$、路径 $P_n$、超立方体 $Q_k$、树（所有树都是二部图）、以及“工人与任务”“学生与课程”这类关系图。奇数长度的圈 $C_{2k+1}$ 不是二部图，$K_3$ 就是最小的反例。

### 4.3 完全二部图

完全二部图 $K_{m,n}$ 的两个部大小分别为 $m$ 和 $n$，且每个 $X$ 中的顶点与每个 $Y$ 中的顶点都相邻。边数为

$$
|E(K_{m,n})|=mn.
$$

$X$ 中每个顶点的度为 $n$，$Y$ 中每个顶点的度为 $m$，度之和为 $m\cdot n+n\cdot m=2mn$，与握手定理一致。

$K_{1,n}$ 是星形图，中心度为 $n$，叶子度为 1。$K_{2,3}$ 有 6 条边，$K_{3,3}$ 有 9 条边，$K_{3,3}$ 是最著名的非平面图之一，后面讨论平面图时会再次出现。

完全二部图的补图是两个不相交的完全图 $K_m$ 与 $K_n$ 的并：在 $X$ 内部，所有边在补图中出现；在 $Y$ 内部同理；$X$ 与 $Y$ 之间的边在补图中全部消失。这个结构可以用来快速识别完全二部图。

### 4.4 完全图与二部图的关系

完全图 $K_n$ 是二部图，当且仅当 $n\le 2$。$K_1$ 没有边，可以看作二部图；$K_2$ 只有一条边，两个端点分属两个部；$K_3$ 含三角形，不是二部图；$n\ge 3$ 时 $K_n$ 都含三角形，因此都不是二部图。

二部图的边数有一个经典上界。若 $n$ 个顶点的图不含三角形，则边数不超过 $\lfloor n^2/4\rfloor$，这就是 Mantel 定理。达到上界的是完全二部图 $K_{\lfloor n/2\rfloor,\lceil n/2\rceil}$。例如 $n=10$ 时最多 25 条边，由 $K_{5,5}$ 取得。这个定理说明：在禁止三角形的条件下，把顶点尽量均匀地分成两组、只连组间边，是最“密”的构造。

| 图 | 顶点数 | 边数 | 度 | 是否二部 |
| --- | --- | --- | --- | --- |
| $K_n$ | $n$ | $n(n-1)/2$ | 每个 $n-1$ | 仅 $n\le 2$ |
| $K_{m,n}$ | $m+n$ | $mn$ | 两部分别为 $n$、$m$ | 是 |
| $C_{2k}$ | $2k$ | $2k$ | 每个 2 | 是 |
| $C_{2k+1}$ | $2k+1$ | $2k+1$ | 每个 2 | 否 |
| 树 | $n$ | $n-1$ | 不定 | 是 |

## 五、通路、回路与连通性

### 5.1 通路、迹、圈

在图论中，walk、trail、path、cycle 是四个不同层次的概念，中文教材的译名也不完全统一，必须按定义区分。

| 术语 | 英文 | 允许重复的要素 | 说明 |
| --- | --- | --- | --- |
| 通路 | walk | 顶点和边都可以重复 | 只要求相邻两项相接 |
| 迹 | trail | 顶点可重复，边不可重复 | 每条边最多走一次 |
| 简单通路 | path | 顶点不可重复（端点除外） | 也叫路径 |
| 回路 | closed walk | 起点终点相同 | 允许重复 |
| 圈 | cycle | 起点终点相同，其余顶点不重复 | 简单图里长度至少 3 |

一条通路可以写成 $v_0,e_1,v_1,e_2,\dots,e_k,v_k$，其中 $e_i$ 连接 $v_{i-1}$ 与 $v_i$，长度定义为边的条数 $k$。若 $v_0=v_k$，称为闭通路；若闭通路的边互不重复，称为 circuit；若闭通路除起点终点外顶点互不重复，称为 cycle。

举例说明：在三角形 $a,b,c$ 中，$a,b,c,a$ 是圈；$a,b,a,c$ 是闭通路但不是迹，因为边 $ab$ 走了两次；$a,b,c,b$ 是通路但不是迹，因为边 $bc$ 走了两次；$a,b,c,a,b$ 是迹（三条边各走一次）但不是简单通路，因为顶点 $a,b$ 重复；$a,b,c$ 是简单通路。

原料中的两个序列需要特别澄清。序列 $a,c,d,e,d,c,g$ 中，边 $de$ 与 $ed$ 是同一条无向边的两次使用，因此它只是通路，不是迹；把它判为迹，等于忽略了“无向边不分方向，往返一次仍算重复”。序列 $a,g,c,d,f,e,d$ 中出现了边 $df$，而图中并没有这条边，因此它连通路都不是；原料通过悄悄改动序列来“修正”结论，这种做法掩盖了原始判断的错误。判断这类题时，应先把每条边按端点对写出来，再检查是否有重复边或不存在的边。

### 5.2 连通性、割点与桥

无向图中，若两个顶点之间存在通路，称它们连通。若任意两个顶点都连通，称图连通；否则图的连通分量是极大的连通子图。孤立点本身是一个连通分量。

删去顶点 $v$ 后连通分量数增加，称 $v$ 为割点；删去边 $e$ 后连通分量数增加，称 $e$ 为桥。割点和桥刻画了网络的“关键节点”和“关键链路”。

| 图 | 割点 | 桥 |
| --- | --- | --- |
| 路径 $P_4$ | 中间两个顶点 | 三条边都是桥 |
| 圈 $C_n$ | 无 | 无 |
| 两个三角形共享一个顶点 | 共享顶点 | 无 |
| 两个三角形由一条边相连 | 该边两个端点 | 连接边 |

一个常用结论是：边 $e$ 是桥，当且仅当 $e$ 不属于任何圈。若 $e$ 在某个圈上，删去它后仍可沿圈的另一方向从一个端点走到另一个端点，图不会因此断开；反之，若 $e$ 不是桥，删去后两端仍连通，这条替代路径与 $e$ 合起来就是一个圈。

### 5.3 有向图的连通性

有向图的连通性分三个层次。强连通：任意两个顶点 $u,v$ 之间既有 $u\to v$ 的通路，也有 $v\to u$ 的通路。单向连通：任意两个顶点之间至少有一个方向存在通路。弱连通：把每条弧看成无向边后，底图连通。

强连通分量是有向图中极大的强连通子图。把每个强连通分量缩成一个点，得到的商图是一个有向无环图，称为凝聚图。这个性质在依赖分析、循环检测、2-SAT 等问题中非常关键。

例如，有向环 $a\to b\to c\to a$ 是强连通的；若再加一条 $c\to d$，则 $d$ 不能回到 $a$，$\{a,b,c\}$ 是一个强连通分量，$\{d\}$ 是另一个，凝聚图为 $\{a,b,c\}\to\{d\}$。

## 六、欧拉图与哈密顿图

### 6.1 欧拉回路与欧拉通路

欧拉通路经过图中每条边恰好一次；欧拉回路是起点终点相同的欧拉通路。注意“每条边恰好一次”是边的条件，顶点可以重复经过。

无向图存在欧拉回路的充要条件是：图连通（忽略孤立点），且所有顶点的度都是偶数。存在欧拉通路（不是回路）的充要条件是：图连通，且恰有 0 个或 2 个奇度顶点；当恰有 2 个奇度顶点时，通路必须从一个奇度顶点出发、到另一个奇度顶点结束。

必要性的直观解释：在欧拉回路中，每进入一个顶点一次，就要从它出去一次，进入与离开的边成对出现，因此每个顶点关联的边数是偶数。欧拉通路有两个端点，起点的出边比入边多一条，终点的入边比出边多一条，其余顶点仍然成对，所以恰有两个奇度顶点。

充分性的构造可以用 Hierholzer 算法：从任意顶点出发，沿着未使用的边一直走，直到回到起点，得到一个回路；若还有未使用的边，就在回路中某个顶点处插入新的子回路，反复直到所有边都被使用。Fleury 算法则每次尽量不走桥，也能保证走遍所有边。

有向图的欧拉回路条件是：所有顶点的入度等于出度，且所有非零度顶点在同一个强连通分量中。欧拉通路条件是：至多一个顶点出度比入度大 1（起点），至多一个顶点入度比出度大 1（终点），其余顶点入度等于出度，且底图连通。

| 图 | 欧拉回路 | 欧拉通路 | 原因 |
| --- | --- | --- | --- |
| $K_5$ | 有 | 有 | 每个顶点度为 4，全偶 |
| $K_4$ | 无 | 无 | 4 个奇度顶点 |
| 三角形 | 有 | 有 | 每个顶点度为 2 |
| 路径 $P_n$ | 无 | 有 | 两个端点度为 1 |
| 两个三角形共享一个顶点 | 有 | 有 | 共享顶点度为 4，其余四个度为 2，全偶 |

上表最后一行值得展开：两个三角形共享一个顶点时，图是连通的，共享顶点度为 4，其余四个顶点度为 2，所有度都是偶数，因此存在欧拉回路。可以沿一个三角形走一圈回到共享点，再沿另一个三角形走一圈，正好经过每条边一次。这个例子说明“有割点”并不妨碍欧拉回路，因为欧拉回路关心的是边，不是顶点；割点可以被重复经过。

### 6.2 哈密顿圈

哈密顿圈经过图中每个顶点恰好一次，并回到起点；哈密顿通路经过每个顶点恰好一次，但不要求回到起点。与欧拉问题不同，哈密顿问题限制的是顶点，边可以不用完。

哈密顿问题没有像欧拉回路那样简洁的充要条件。判断一个图是否有哈密顿圈是 NP 完全问题，目前没有已知的多项式时间算法。教材中给出的是若干必要条件和充分条件。

必要条件：若 $G$ 有哈密顿圈，则对任意非空真子集 $S\subset V$，删去 $S$ 后的连通分量数满足

$$
c(G-S)\le |S|.
$$

直观上，哈密顿圈是一个经过所有顶点的大圈，从 $S$ 中每个顶点最多“进出”一次，因此 $S$ 最多把圈切成 $|S|$ 段，每段属于一个连通分量。若某个 $S$ 删去后连通分量数超过 $|S|$，一定不存在哈密顿圈。

另一个必要条件是：若 $G$ 是二部图且有哈密顿圈，则两个部的顶点数必须相等；若有哈密顿通路，则两个部的顶点数之差不超过 1。因为哈密顿圈在二部图中必须交替经过两个部，圈长为偶数，两部各占一半。

充分条件中最著名的是 Dirac 定理和 Ore 定理。

Dirac 定理：若 $n\ge 3$ 且最小度 $\delta(G)\ge n/2$，则 $G$ 有哈密顿圈。

Ore 定理：若 $n\ge 3$ 且对每一对不相邻的顶点 $u,v$，都有

$$
d(u)+d(v)\ge n,
$$

则 $G$ 有哈密顿圈。

这两个定理都是充分条件，不是必要条件。圈 $C_n$（$n\ge 5$）是哈密顿图，但 $\delta=2<n/2$，且任意两个不相邻顶点的度之和为 $4<n$，既不满足 Dirac 也不满足 Ore。因此不能用“不满足 Dirac/Ore”来否定哈密顿圈的存在。

### 6.3 彼得森图：必要与充分的边界

彼得森图有 10 个顶点、15 条边，每个顶点度为 3。它可以用外层五边形与内层五角星构造：外层顶点 $a,b,c,d,e$ 依次成环；内层顶点 $f,h,j,g,i$ 依次成环（注意顺序是五角星，不是五边形）；对应顶点之间连辐条 $af,bg,ch,di,ej$。

彼得森图是 3-正则图，满足 $\delta=3<5$，不满足 Dirac；任意两个不相邻顶点的度之和为 $6<10$，不满足 Ore。它确实没有哈密顿圈，因此常被用作“3-正则、3-连通仍可能非哈密顿”的反例。

证明它可以这样看：若彼得森图有哈密顿圈 $H$，由于每个顶点度为 3，圈上每个顶点已经用了两条边，剩下的第三条边构成一个完美匹配 $M$。也就是说，$H$ 的补边集是一个完美匹配。彼得森图恰有 6 个完美匹配，逐一检查会发现，删去任意一个完美匹配后，剩下的 10 条边都分成两个 5-圈，而不是一个 10-圈。因此不存在这样的哈密顿圈。

彼得森图还是“删去任意一个顶点后都有哈密顿圈”的图。例如删去顶点 $j$ 后，$a,b,g,i,f,h,c,d,e,a$ 构成一个 9 个顶点的哈密顿圈。这种“删一点就变好”的性质称为 hypohamiltonian，说明哈密顿性对局部改动非常敏感。

原料中给出的彼得森图标注并不是真正的彼得森图：按那组边计算，围长为 4，只有 8 个五圈，而且存在哈密顿圈。正确的标注应满足围长 5、恰有 12 个五圈、没有哈密顿圈。这个差异不是画法问题，而是图本身不同构；判断此类问题时，应回到边集逐条核对，而不能只看“看起来像五角星”。

### 6.4 欧拉与哈密顿的对比

| 维度 | 欧拉回路 | 哈密顿圈 |
| --- | --- | --- |
| 经过的对象 | 每条边恰好一次 | 每个顶点恰好一次 |
| 顶点/边是否可重复 | 顶点可重复，边不可 | 顶点不可重复，边可不用完 |
| 充要条件 | 有（连通且全偶） | 未知，判定为 NP 完全 |
| 典型算法 | Hierholzer、Fleury | 回溯、状态压缩、启发式 |
| 充分条件 | 无需额外 | Dirac、Ore |
| 常见反例 | $K_4$ 无欧拉回路 | 彼得森图无哈密顿圈 |

这张表的核心信息是：欧拉问题是“边覆盖”问题，结构约束强，判定容易；哈密顿问题是“顶点覆盖”问题，组合爆炸，判定困难。两者名字相似，难度却完全不同。

## 七、树与生成树

### 7.1 树的等价定义

树是连通且无圈的图。以下几条定义等价：

1. 连通且无圈；
2. 有 $n$ 个顶点、$n-1$ 条边且连通；
3. 有 $n$ 个顶点、$n-1$ 条边且无圈；
4. 任意两个顶点之间有且仅有一条简单通路；
5. 无圈，且任意添加一条边都会产生唯一的圈；
6. 连通，且任意删去一条边都会不连通。

树在 $n\ge 2$ 时至少有两个叶节点（度为 1 的顶点）。证明思路：取一条最长路径，其两个端点不可能再有其他邻居，否则路径可以延长或形成圈，因此两端都是叶子。

树一定是二部图。取任意一个顶点为根，按到根的距离奇偶染色，相邻顶点距离相差 1，颜色必然不同，因此可以二染色。

### 7.2 生成树、树枝与弦

连通图 $G$ 的生成树是包含全部 $n$ 个顶点、$n-1$ 条边的子图。生成树一定连通且无圈，是原图的一个“最小连通骨架”。

给定生成树 $T$，属于 $T$ 的边称为树枝，共 $n-1$ 条；不属于 $T$ 的边称为弦，共

$$
m-(n-1)=m-n+1
$$

条。每一条弦与 $T$ 中连接其两个端点的唯一路径合起来，构成一个基本圈。基本圈共有 $m-n+1$ 个，它们构成圈空间的一组基，任一回路都可以表示为若干基本圈的对称差。

### 7.3 Kruskal 与 Prim

带权连通图的最小生成树是总权值最小的生成树。两个经典算法从不同角度贪心。

Kruskal 算法按边权从小到大排序，依次考察每条边：若它的两个端点属于不同的连通分量，就加入生成树并合并分量；否则跳过，因为加入会形成圈。判定连通分量用并查集，时间复杂度为 $O(m\log m)$，主要由排序决定。Kruskal 适合稀疏图。

Prim 算法从一个顶点出发，每次选择连接“已加入集合”与“未加入集合”的最小权边，把新顶点加入集合。用邻接矩阵和朴素找最小值时复杂度为 $O(n^2)$，适合稠密图；用优先队列可降到 $O(m\log n)$。

两个算法都基于割性质：对任意割，横跨割的最小权边一定属于某棵最小生成树。只要每一步都安全地加入一条这样的边，最终就能得到最小生成树。若图中存在相同权值的边，最小生成树可能不唯一，但总权值唯一。

## 八、图的矩阵表示

### 8.1 邻接矩阵

设图有 $n$ 个顶点，邻接矩阵 $A=(a_{ij})$ 是一个 $n\times n$ 矩阵。无向简单图中，$a_{ij}=1$ 表示 $i$ 与 $j$ 相邻，否则为 0；无向图的邻接矩阵是对称矩阵。有向图中，$a_{ij}=1$ 表示存在弧 $(i,j)$，矩阵不一定对称。多重图中，$a_{ij}$ 可以取边的条数；自环通常记在 diagonal 上，按需要取 1 或 2。

邻接矩阵的第 $i$ 行之和等于顶点 $i$ 的出度（无向图即度），第 $j$ 列之和等于入度。对于无向图，$A$ 是对称的，行和与列和相同。

### 8.2 $A^k$ 的计数意义

邻接矩阵的幂有一个非常重要的组合意义：$A^k$ 的第 $(i,j)$ 个元素等于从 $i$ 到 $j$ 长度为 $k$ 的 walk 的条数。

证明用归纳法。$k=1$ 时，$A_{ij}$ 就是一步从 $i$ 到 $j$ 的走法数。假设对 $k-1$ 成立，则

$$
(A^k)_{ij}=\sum_{t=1}^{n}(A^{k-1})_{it}A_{tj},
$$

求和中的每一项表示“先走 $k-1$ 步到 $t$，再走一步到 $j$”的走法数，按 $t$ 分类求和即得所有长度为 $k$ 的走法。

这里的关键是 walk 允许重复顶点和边，不是简单通路。以 $K_3$ 为例，顶点为 $a,b,c$，邻接矩阵为

$$
A=\begin{pmatrix}
0&1&1\\
1&0&1\\
1&1&0
\end{pmatrix}.
$$

计算 $A^3$ 可得

$$
A^3=\begin{pmatrix}
2&3&3\\
3&2&3\\
3&3&2
\end{pmatrix}.
$$

从 $a$ 到 $b$ 长度为 3 的 walk 有 3 条：$a\to b\to a\to b$、$a\to c\to a\to b$、$a\to b\to c\to b$。它们都重复经过了顶点，因此都不是长度为 3 的简单通路；在 $K_3$ 中，$a$ 到 $b$ 的简单通路只有长度为 1 的那一条，长度为 3 的简单通路为 0 条。原料把 $A^3$ 的非对角元素解释为“长度为 3 的路径条数”，混淆了 walk 与 path，这是矩阵计数题中最常见的错误。

若需要统计长度不超过 $k$ 的 walk 总数，可以把 $A^0+A^1+\cdots+A^k$ 相加；若需要统计连通性，只需看 $A+A^2+\cdots+A^{n-1}$ 中对应位置是否大于零。

### 8.3 关联矩阵

关联矩阵 $B$ 的行对应顶点，列对应边。无向图中，若边 $e$ 连接 $u,v$，则 $B_{ue}=B_{ve}=1$，其余为 0；自环通常在该列记 2。有向图中，通常约定尾为 $-1$、头为 $+1$，于是每一列的和为 0。

关联矩阵的每一行之和等于顶点的度（有向图为出度减入度），每一列恰有两个非零元素（自环除外）。关联矩阵适合描述“顶点与边的关联关系”，在电路网络、流网络、拓扑分析中使用较多；邻接矩阵适合描述“顶点与顶点”的相邻关系，在路径计数、谱图理论中使用较多。

| 矩阵 | 行 | 列 | 元素含义 | 典型用途 |
| --- | --- | --- | --- | --- |
| 邻接矩阵 | 顶点 | 顶点 | 相邻或弧的条数 | 路径计数、连通性、谱分析 |
| 关联矩阵 | 顶点 | 边 | 顶点是否与边关联 | 网络流、电路、拓扑 |

### 8.4 同构判断的实践

回到同构问题，矩阵表示提供了一个必要条件的检查方法：若两个图同构，则存在置换矩阵 $P$，使得

$$
A_2=P A_1 P^{-1}.
$$

也就是说，两个邻接矩阵可以通过同时交换行和列变成相同的形式。实际判断时，可以先比较度序列；若度序列相同，再比较各度数的顶点之间的邻接关系、三角形数量、连通分量、二部性等。对于小图，可以尝试按度数分层画图，观察连接模式是否一致。

同构判断的困难在于“不变量相同但结构不同”。$K_{3,3}$ 与三角棱柱图的例子已经说明，度序列、顶点数、边数都相同仍可能不同构。更复杂的例子可以构造出多个 3-正则图，它们的围长、三角形数都相同，但整体连接方式不同。因此，证明同构需要给出具体的双射并逐条验证边；证明不同构只需要找到一个不变量不同，或者找到一个在同构下必须保持的结构特征被破坏。

## 九、平面图与着色

### 9.1 平面图的欧拉公式

若一个图可以画在平面上，使得任意两条边除公共端点外不相交，则称它为平面图。这样的画法把平面分成若干个面，包括一个无界的外部面。

对连通平面图，顶点数 $v$、边数 $e$、面数 $f$ 满足欧拉公式

$$
v-e+f=2.
$$

例如树：$v=n$，$e=n-1$，$f=1$（只有外部面），代入得 $n-(n-1)+1=2$。三角形：$v=3$，$e=3$，$f=2$（内部面与外部面），代入得 $3-3+2=2$。

对简单平面图（$v\ge 3$），每个面至少由 3 条边围成，每条边最多属于两个面，因此 $3f\le 2e$。代入欧拉公式消去 $f$，得到

$$
e\le 3v-6.
$$

若图还是二部图，每个面至少由 4 条边围成（二部图没有三角形），于是 $4f\le 2e$，即 $e\le 2v-4$。

用这两个不等式可以快速判断非平面性：$K_5$ 有 $v=5,e=10$，而 $3v-6=9$，$10>9$，所以 $K_5$ 非平面；$K_{3,3}$ 有 $v=6,e=9$，而 $2v-4=8$，$9>8$，所以 $K_{3,3}$ 非平面。Kuratowski 定理进一步指出：一个图是平面图，当且仅当它不含 $K_5$ 或 $K_{3,3}$ 的细分。这两个图因此成为非平面性的“基本障碍”。

### 9.2 图的着色

图的顶点着色要求相邻顶点颜色不同，所需的最少颜色数称为色数 $\chi(G)$。完全图 $K_n$ 的色数为 $n$；二部图的色数为 2（有边时）；奇圈色数为 3；偶圈色数为 2。

贪心着色按任意顺序给顶点染色，每个顶点选一个未在邻居中使用的最小颜色，最多使用 $\Delta+1$ 种颜色。Brooks 定理说明：若连通图既不是完全图也不是奇圈，则 $\chi(G)\le\Delta$。

平面图的四色定理是图论中最著名的结论之一：任何平面图都可以用 4 种颜色正常着色。它的证明历史上依赖计算机枚举，是“计算机辅助证明”的里程碑。五色定理的证明相对初等，常作为课堂内容。

## 十、常见误区与原料勘误

| 误区或原料错误 | 正确结论 | 说明 |
| --- | --- | --- |
| 自环对度的贡献为 1 | 贡献为 2 | 自环两端都是同一个顶点 |
| 度之和为偶数就一定能图 | 还要满足可图性条件 | $3,3,1,1$ 度之和为 8 但不可图 |
| $K_n$ 的边数为 $n(n-1)$ | 为 $n(n-1)/2$ | 每条边被两个端点各数一次 |
| $K_{m,n}$ 的边数为 $m+n$ | 为 $mn$ | 每个 $X$ 顶点连所有 $Y$ 顶点 |
| $K_3$ 是二部图 | 不是 | 含三角形，奇圈 |
| 二部图只需两个部非空 | 还要求每条边跨部 | 部内不能有边 |
| 无向图中往返一次不算重复边 | 算重复 | $de$ 与 $ed$ 是同一条边 |
| 序列 $agcdfed$ 是通路 | 不是 | 图中没有 $df$ 边 |
| 彼得森图是哈密顿图 | 不是 | 它没有哈密顿圈 |
| 原料标注的“彼得森图”围长为 5 | 该标注围长为 4 | 边集不同，图不同构 |
| Dirac 条件是哈密顿圈的必要条件 | 是充分条件 | $C_n$ 不满足但仍哈密顿 |
| 不满足 Ore 条件就没有哈密顿圈 | 不能否定 | Ore 只是充分条件 |
| 欧拉回路只要求所有度为偶数 | 还要求连通（忽略孤立点） | 两个分离的偶度图没有欧拉回路 |
| 有割点就没有欧拉回路 | 不一定 | 两个三角形共享顶点仍有欧拉回路 |
| $A^k$ 的元素是长度为 $k$ 的简单通路数 | 是 walk 数 | walk 允许重复顶点和边 |
| 平面图欧拉公式对非连通图直接适用 | 连通平面图才为 $v-e+f=2$ | 非连通图需按分量修正 |

关于彼得森图，再补充一个可操作的核对方法。正确的彼得森图有 10 个顶点、15 条边、每个顶点度为 3、围长为 5、恰有 12 个五圈、没有哈密顿圈；删去任意一个顶点后剩下 9 个顶点仍有哈密顿圈。原料中的标注至少满足“10 个顶点、15 条边、3-正则”，但围长、五圈数、哈密顿性三项都不对，因此不是同一个图。只看顶点数和边数就认定是彼得森图，是典型的“不变量不足”错误。

## 十一、总结要点

| 主题 | 核心结论 | 使用要点 |
| --- | --- | --- |
| 握手定理 | $\sum d(v)=2m$ | 奇度顶点个数为偶数 |
| 度序列 | Havel–Hakimi 判定 | 出现负数或超界即可否定 |
| 完全图 | $m=n(n-1)/2$ | 每个顶点度 $n-1$ |
| 二部图 | 不含奇圈 | 可用 BFS 二染色判定 |
| 完全二部图 | $m=mn$ | 补图为两个完全图之并 |
| 通路/迹/圈 | 边与顶点的重复规则不同 | 先列边集再判断 |
| 连通性 | 割点、桥、连通分量 | 桥不在任何圈上 |
| 欧拉回路 | 连通且所有度为偶数 | 有向图要求入度等于出度 |
| 欧拉通路 | 恰有 0 或 2 个奇度顶点 | 两个奇点分别为起点终点 |
| 哈密顿圈 | 无多项式充要条件 | Dirac、Ore 只是充分条件 |
| 哈密顿必要条件 | $c(G-S)\le\lvert S\rvert$ | 二部图两部大小相等 |
| 树 | 连通无圈，$m=n-1$ | 至少两个叶子 |
| 生成树 | 树枝 $n-1$，弦 $m-n+1$ | 基本圈 $m-n+1$ 个 |
| 最小生成树 | Kruskal 稀疏、Prim 稠密 | 基于割性质贪心 |
| 邻接矩阵 | $A^k$ 计数长度为 $k$ 的 walk | 不是简单通路 |

图论的学习可以先抓住三条主线：计数（度、边、圈）、连通（通路、割点、桥）、存在性（欧拉、哈密顿、平面性）。每条主线都有对应的不变量和判定方法。遇到具体问题时，先判断它属于哪条主线，再选择“数一数”“走一走”还是“构造反例”的策略，比死记结论更可靠。
