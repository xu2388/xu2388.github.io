# 中国近现代史纲要 · 口述史作业与复习

## 一、概述

口述史作业是“中国近现代史纲要”课程中兼具实践性与学术性的考核形式。其基本要求是：选取一位或数位亲历特定历史阶段的受访者，通过结构化访谈采集其个人记忆，经转录、整理与考订，写成一篇能够与文献记载相互印证的调查报告。

口述史的价值不在于复述教科书结论，而在于提供**教科书之外的视角**：重大事件在普通人生活中如何被感知、被承受、被记忆。因此，作业的评价重点通常有三：选题是否具体、访谈是否真实深入、口述材料与历史背景是否形成有效对话。若只写成“听爷爷讲过去的故事”式的记叙文，或只写成历史事件的资料汇编，均不符合要求。

本笔记按“方法—规范—结构—坐标”的顺序组织，既可作为作业操作指南，也可作为课程复习的框架。

## 二、核心知识点

### 2.1 口述史的方法特征

口述史以**访谈录音**为主要史料来源，其方法特征可归纳为四点：

- **记忆性**：材料来自受访者的回忆，而非当时的文字记录，因而带有事后重构的成分。
- **主观性**：叙述中包含情感、评价与立场，这些内容本身即为研究资料，不应被剔除。
- **补充性**：能够填补文献的空白，尤其是普通民众、女性、少数民族等群体的经历。
- **互动性**：访谈是访谈者与受访者共同建构意义的过程，提问方式会影响叙述内容。

由此产生一条基本原则：**口述材料须与文献、档案、实物等互证**，不可单独作为史实依据。当口述与文献冲突时，应分析冲突的成因（记忆偏差、立场差异、信息局限），而非简单判定一方为错。

### 2.2 作业流程

1. **选题**：切口宜小。与其写“中国抗日战争”，不如写“一位冀中农民眼中的地道战与日常生计”。题目越小，越能落到具体细节。
2. **确定对象**：优先选择亲历者，年龄、地域、身份应与选题匹配；须确认其表达意愿与身体条件。
3. **设计提纲**：按“背景—经历—细节—感受—评价”五层递进，问题开放为主，避免诱导。
4. **伦理告知**：说明用途、匿名处理方式、可随时终止，征得口头或书面同意。
5. **实施访谈**：单次 40—90 分钟为宜，录音并做要点笔记；适时追问，不打断叙述。
6. **转录整理**：逐字转录，保留口语特征，标注停顿、迟疑与情绪。
7. **主题归纳**：将零散叙述按主题归类，形成分析框架。
8. **撰写报告**：按规范结构成文，附录附提纲与记录。

### 2.3 访谈提纲的设计

提纲不是问卷，不应逐条照读。其功能是**保证覆盖关键维度，同时留出追问空间**。五层问题链如下：

- **背景层**：出生年份、籍贯、家庭成分、受教育程度、当时从事的职业。
- **经历层**：事件发生时您在哪里？当时在做什么？家里人的反应是什么？
- **细节层**：吃什么、穿什么、用什么？东西从哪里来？价格多少？路上要走多久？
- **感受层**：当时害怕吗？最难的时候是什么时候？有没有想过离开？
- **评价层**：现在回头看，您觉得那段时间改变了什么？如果重来，会做同样的选择吗？

细节层是口述史区别于一般采访的关键。宏大的判断随处可得，而“一斤盐多少钱、走几十里路换粮”这类细节只能来自亲历者，也正是史料价值所在。

### 2.4 记录整理的规范

访谈记录采用统一格式：先列**受访者基本情况**（代称、性别、出生年份、籍贯、职业、访谈时间与方式），再以“访谈员／受访者”交替的一问一答形式呈现，每段独立成行。

整理时须遵守三条：**不改写原话**，口语、方言、语气词尽量保留，必要时以括号注明语义；**不删改矛盾之处**，前后不一致的表述应保留并加注；**不出现真实姓名与可识别信息**，人名以姓氏代称，地名可作模糊化处理。录音文件、转录稿与同意记录应一并留存，作为佐证的原始材料。

### 2.5 报告的结构

| 部分 | 内容要点 |
|---|---|
| 标题 | 主标题点明主题，副标题说明对象与方法，如“战火中的日常——一位××村村民的抗战记忆” |
| 摘要 | 150—300 字，交代对象、时间、方法、主要发现与结论 |
| 关键词 | 3—5 个，涵盖时段、地域、主题 |
| 引言 | 选题背景与意义；对象选择理由；访谈时间、地点、方式；报告结构预告 |
| 正文一 | 受访者生平与时代背景，交代其经历的历史坐标 |
| 正文二 | 按主题呈现口述内容，每个主题先叙述后分析 |
| 正文三 | 口述与文献的互证：一致之处、差异之处及差异成因 |
| 结语 | 回应研究问题，说明口述材料的价值与局限 |
| 参考文献 | 著作、论文、档案、地方志，规范著录 |
| 附录 | 访谈提纲、访谈记录全文、照片（图号＋图题） |

### 2.6 史料批判的三个维度

- **记忆的选择性**：人倾向于记住与自身情感关联强的事件，遗忘日常琐事。因而“记得清楚”不等于“确实如此”。
- **事后的重构**：受访者可能将后来的认知、他人的讲述融入自身记忆，形成“二手记忆”。可通过追问细节的确定性（“这是您亲眼所见，还是后来听说的？”）加以区分。
- **立场的介入**：身份、阶层、政治处境会影响叙述的褒贬。分析时应将评价性表述与事实性表述分开处理。

### 2.7 近现代史分期坐标

口述材料须放入明确的时间框架，方能显示其历史意义：

| 时段 | 性质 | 主要线索 |
|---|---|---|
| 1840—1919 | 旧民主主义革命 | 列强侵略与不平等条约；太平天国、洋务运动、戊戌变法、辛亥革命 |
| 1919—1927 | 新民主主义革命·大革命时期 | 五四运动；中共成立；国共第一次合作与北伐 |
| 1927—1937 | 土地革命战争时期 | 农村革命根据地；土地革命；长征 |
| 1937—1945 | 全民族抗日战争 | 国共第二次合作；抗日民族统一战线；沦陷区与根据地的社会状况 |
| 1945—1949 | 解放战争时期 | 土地改革；三大战役；新中国成立 |
| 1949—1956 | 社会主义革命 | 国民经济恢复；三大改造；社会主义制度确立 |
| 1956—1978 | 社会主义建设探索 | 八大；《论十大关系》；曲折与成就并存 |
| 1978 至今 | 改革开放与现代化建设 | 十一届三中全会；社会主义市场经济；新时代 |

使用要点：口述中出现的“解放前／解放后”“土改那年”“入社那年”等民间时间表述，应换算为公元纪年并标注对应的历史阶段；同一事件在不同地区的发生时间可能不同，须以地方史资料校正。

### 2.8 学术规范

引用口述材料须注明来源（受访者代称、访谈时间），引用文献须标注序号并在文末著录。全文须独立完成，重复率控制在课程规定范围以内；若使用人工智能工具辅助整理，须按课程要求声明，不得由工具代写分析部分。涉及在世个人的叙述，发表前宜请受访者确认，避免因误解造成困扰。

## 三、典型例题或范文要点

### 3.1 选题示例与切口比较

- 过宽：“中国抗日战争的历史意义”——属论文题目，无法由口述支撑。
- 适中：“抗战时期冀中农村的粮食获取与日常生活”——可由一位老人的记忆支撑，且能与地方志互证。
- 具体：“一位女性在 1942 年大饥荒中的家庭应对”——切口小、细节密度高，最易出彩。

选题的判据是：**能否用三到五个具体问题问出可验证的细节**。若不能，说明题目仍过于抽象。

### 3.2 访谈记录格式示例

> **受访者基本情况**
> 代称：张；性别：男；出生年份：1931 年；籍贯：河北××县；职业：农民；访谈时间：2024 年 7 月 12 日；方式：面谈，录音 68 分钟。
>
> 访谈员：您还记得日本人来的时候，村里是什么样子吗？
> 张：记得。那时候我七八岁，听见敲锣就跑。往西边沟里跑，沟里全是人。
> 访谈员：跑的时候带东西吗？
> 张：带不了啥，抱个孩子就走。我娘揣着半袋小米，跑丢了一只鞋。

此段示范两点：一是以“跑”“揣”“丢鞋”等动作细节还原情境，而非概括为“群众逃难”；二是访谈员的追问指向具体动作与物件，而非情绪判断。

### 3.3 引言的三段式示范

第一段写选题背景与意义：说明该时段在近现代史中的位置，指出文献记载多集中于重大决策与战役，而基层社会的日常经验记载有限，口述材料可作补充。

第二段写对象选择理由：说明受访者的年龄、地域、身份与选题的匹配性，即其亲历性；同时说明可行性，如居住地相近、家属协助沟通、记忆状况良好。

第三段写访谈概况：交代访谈次数、时长、地点、方式、提纲维度与整理方法，并预告正文的分析框架。

### 3.4 主题归纳的示例

若受访者的叙述散落于“逃难、征粮、参军、土改、入社”等片段，可归纳为三个主题：**生存策略**（逃难路线、粮食储存、亲属互助）、**国家与乡村的关系**（征粮、参军动员、政策执行中的变通）、**记忆的选择**（反复讲述的事件与被略过的事件）。每一主题下先呈现原话，再作分析，最后与文献记载比对。

## 四、小结

口述史作业的成败取决于三个环节：**选题是否够小**，决定材料能否落地；**追问是否够细**，决定史料是否具备不可替代性；**互证是否够严**，决定结论能否成立。

复习层面，须牢记两点：其一，口述材料是史料之一种，其价值与局限并存，使用时必须交代来源、辨析真伪；其二，任何个人记忆都须放回具体的历史坐标中理解，1840 年以来的分期框架不是背诵对象，而是定位工具。掌握了这两点，作业便从“讲故事”转为“做研究”。
