# 思政 · 新民主主义革命理论

## 一、概述

新民主主义革命理论，是中国共产党在领导中国革命过程中，把马克思列宁主义基本原理同中国具体实际相结合形成的理论成果。它不是从书本上推演出来的方案，而是从近代中国的社会性质、阶级结构和革命实践中逐步总结出来的路线、纲领与策略。理解这一理论，首先要理解它所面对的是一个什么样的中国；离开半殖民地半封建社会这个总背景，总路线中的对象、动力、领导与前途都会变成孤立的条文。

这一理论的核心问题，是中国革命走什么路、由谁领导、依靠谁、反对谁、建立一个什么样的社会。围绕这些问题，中国共产党逐步形成了新民主主义革命总路线、三大基本纲领、三大法宝以及农村包围城市、武装夺取政权的道路理论。1948年，毛泽东在晋绥干部会议上的讲话中完整表述了新民主主义革命总路线，标志着这一理论在路线层面已经成熟。

本文按“国情与任务—总路线—纲领—三大法宝—革命道路—新旧对比—新民主主义社会经济结构”的顺序展开，重点在于说明各项结论之间的逻辑关系，而不是罗列名词。文中的时间、会议与著作均以教材通行表述为准，不涉及具体试题与答案。

## 二、近代中国的基本国情与两大历史任务

### 2.1 半殖民地半封建社会

鸦片战争以后，中国逐步由独立的封建社会沦为半殖民地半封建社会。这一社会形态不是完整的殖民地，也不是完整的封建社会，而是两种性质并存、交织的特殊社会。其基本特点可以从四个方面把握。

第一，**国家主权遭到破坏，但并未完全丧失**。帝国主义列强通过不平等条约控制中国的通商口岸、海关、财政、交通与外交，操纵中国的经济命脉和政治局势。中国形式上仍有自己的政府，实际上受到帝国主义的严重控制，因此是“半殖民地”而不是完全殖民地。

第二，**封建剥削制度依然存在，并在社会经济生活中占据优势**。封建地主土地所有制没有根本改变，地主阶级对农民的剥削依然严重。帝国主义侵略势力又同封建势力相勾结，把封建地主阶级作为统治中国的社会基础。因此，反封建不是单纯的文化主张，而是改变土地制度与社会关系的革命任务。

第三，**民族资本主义有所发展，但没有成为社会经济的主要形式**。中国民族资本主义在外资与封建势力的夹缝中产生，发展缓慢，力量弱小，同帝国主义、封建主义既有矛盾又有联系。民族资产阶级因此具有革命性与妥协性的两面性，这种两面性直接影响它在革命中的位置。

第四，**政治、经济、文化发展极不平衡**。帝国主义划分势力范围，地方军阀割据，城乡之间、沿海与内地之间差距悬殊。这种不平衡一方面造成革命的困难，另一方面也为革命力量在敌人统治薄弱的农村地区生存和发展提供了空间。后来农村包围城市道路之所以可能，与这一特点密切相关。

### 2.2 两大主要矛盾

半殖民地半封建社会的性质，决定了近代中国存在两对主要矛盾：**帝国主义和中华民族的矛盾**，**封建主义和人民大众的矛盾**。其中，帝国主义和中华民族的矛盾是最主要的矛盾。帝国主义是近代中国贫穷落后和民族灾难的总根源，封建主义则是帝国主义统治中国的社会基础，二者相互勾结，共同压迫中国人民。

两对矛盾不是并列静止的，而是随着革命形势变化而起伏。当帝国主义发动侵略战争时，民族矛盾上升为主要矛盾，国内阶级矛盾暂时缓和，统一战线范围扩大；当帝国主义采取间接统治、国内反动势力加紧压迫时，阶级矛盾又可能突出。理解这种变化，才能理解为什么不同时期统一战线的范围与土地政策会调整。

### 2.3 两大历史任务

近代中国面临两大历史任务：**争取民族独立、人民解放**，**实现国家富强、人民富裕**。前者是后者的前提，后者是前者的最终目标。没有民族独立和人民解放，国家富强就缺乏政治条件；离开国家富强和人民富裕，民族独立和人民解放也难以巩固。

这两大任务决定了中国革命必须分两步走。第一步，完成反帝反封建的民主革命任务，改变半殖民地半封建的社会性质，建立人民当家作主的国家；第二步，在此基础上进行社会主义革命和建设，逐步实现国家富强与人民富裕。新民主主义革命理论处理的，主要是第一步的任务及其领导力量、动力与前途问题。

### 2.4 革命性质为什么是资产阶级民主革命

新民主主义革命的性质，是**资产阶级民主革命**，更准确地说，是“新式的、特殊的资产阶级民主革命”。判断革命性质，主要看革命任务，而不是只看领导阶级。新民主主义革命的任务是反帝国主义、反封建主义、反官僚资本主义，不消灭民族资本主义私有制，客观上为资本主义发展扫清障碍。这样的任务属于资产阶级民主革命范畴，而不是社会主义革命。

这里需要区分“任务属性”与“领导力量”。在欧美资产阶级革命中，反封建的任务由资产阶级领导完成；在近代中国，民族资产阶级由于软弱性和妥协性，无法完成这一任务，只能由无产阶级及其政党领导人民来完成。领导阶级变了，革命任务的性质并没有变；任务性质不变，革命的前途却可以不同。这正是“新式”与“特殊”的含义。

## 三、新民主主义革命总路线

### 3.1 总路线的完整表述

新民主主义革命总路线是：**无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命**。这一表述包含四个要点：领导力量是无产阶级，革命主体是人民大众，革命对象是帝国主义、封建主义和官僚资本主义，革命性质是资产阶级民主革命。

总路线不是一句口号，而是一套判断标准。它回答了“谁来领导”“依靠谁”“反对谁”“革命向何处去”四个问题。四个问题中，领导权是核心；对象与动力决定统一战线的范围；性质与前途决定革命两步走的关系。

### 3.2 革命对象

新民主主义革命的 object，是帝国主义、封建主义和官僚资本主义，通常称为压在中国人民头上的“三座大山”。三者不是彼此孤立的，而是相互勾结的整体。

| 对象 | 在压迫体系中的位置 | 革命的具体指向 |
|---|---|---|
| 帝国主义 | 民族压迫的总根源，控制中国主权与经济命脉 | 推翻帝国主义在华特权，争取民族独立 |
| 封建主义 | 帝国主义统治中国的社会基础 | 废除封建地主土地所有制，消灭封建剥削 |
| 官僚资本主义 | 帝国主义与封建势力结合的产物，垄断国家经济 | 没收官僚资本，摧毁其经济基础 |

帝国主义是近代中国民族灾难的总根源，反对帝国主义是争取民族独立的前提。封建主义是帝国主义统治中国的社会基础，不废除封建土地制度，就无法发动农民、改变农村的社会关系。官僚资本主义依附帝国主义，又同封建势力相结合，垄断金融、工业与商业，压迫民族工商业和广大人民。三者之中，帝国主义是首要对象，但反帝、反封建、反官僚资本必须作为整体任务来理解。

需要特别说明，**民族资产阶级不是革命对象**。民族资产阶级受帝国主义、封建主义和官僚资本主义的压迫，具有革命性；同时它同三者又有千丝万缕的联系，具有妥协性。因此，对民族资产阶级采取又联合又斗争的政策，而不是把它当作敌人。这是新民主主义革命区别于旧式资产阶级革命的重要特点。

### 3.3 革命动力

新民主主义革命的动力包括无产阶级、农民阶级、城市小资产阶级和民族资产阶级。四个阶级的地位并不相同。

| 阶级 | 地位 | 革命态度与作用 |
|---|---|---|
| 无产阶级 | 最基本的动力，领导阶级 | 受压迫最深，革命性最彻底，代表先进生产力 |
| 农民阶级 | 主力军，无产阶级最可靠的同盟军 | 占人口绝大多数，深受封建剥削，革命要求强烈 |
| 城市小资产阶级 | 可靠的同盟者 | 受压迫，倾向革命，是人民范畴内的劳动者 |
| 民族资产阶级 | 可以联合的力量 | 具有两面性，既有革命性又有妥协性，不能充当领导者 |

无产阶级之所以能够成为领导阶级，不是因为它人数最多，而是因为它代表先进生产力，具有严密的组织性和纪律性，并且拥有以马克思列宁主义为指导的政党。农民阶级人数最多、受压迫最深，是革命的主力军；但农民不是先进生产力的代表，不能独立提出科学的革命纲领，因而不能成为领导者。城市小资产阶级是劳动者，革命要求较强，是可靠的同盟者。民族资产阶级可以参加革命，但不能领导革命，也不能在革命中掌握领导权。

### 3.4 领导权：新旧民主革命的根本区别

无产阶级掌握革命领导权，是新民主主义革命区别于旧民主主义革命的根本标志，也是新民主主义革命的核心问题。领导权不是自封的，而是在长期斗争中实现的。无产阶级要实现对革命的领导，必须具备四个条件：一是建立以马克思列宁主义为指导的政党；二是提出符合中国实际的革命纲领；三是同农民结成巩固的同盟；四是在统一战线中坚持独立自主原则。

领导权问题之所以重要，是因为它决定革命的方向。由资产阶级领导，革命的前途是建立资产阶级共和国，走资本主义道路；由无产阶级领导，革命的前途是先建立新民主主义社会，再过渡到社会主义。领导权一变，革命的归宿就随之改变。

### 3.5 革命性质与前途

新民主主义革命的性质是资产阶级民主革命，前途是社会主义。这两个判断并不矛盾，而是统一于中国革命两步走的战略。

第一步，完成新民主主义革命，建立无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国。这个社会还不是社会主义社会，而是属于过渡性质的新民主主义社会。第二步，在新民主主义社会的基础上进行社会主义革命，通过社会主义改造确立社会主义基本制度，进而向社会主义社会过渡。

两步走是先后衔接、不可分割的。新民主主义革命是社会主义革命的必要准备，社会主义革命是新民主主义革命的必然趋势。既不能把两步合并为一步，幻想“毕其功于一役”；也不能在两步之间横插一个独立的资本主义社会，走“二次革命”的老路。前一种错误混淆了革命性质，后一种错误割裂了革命进程。

## 四、三大基本纲领

### 4.1 政治纲领

新民主主义革命的政治纲领，是推翻帝国主义、封建主义和官僚资本主义的统治，建立无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国。这个共和国的国体，是各革命阶级联合专政；政体，是民主集中制的人民代表大会制度。

“各革命阶级联合专政”不同于资产阶级专政，也不同于单纯的无产阶级专政。它包含工人阶级、农民阶级、城市小资产阶级和民族资产阶级等革命阶级，但领导权属于工人阶级。民主集中制则要求在国家权力机关中实行广泛的民主，在决策与执行中实行必要的集中，既反对独裁，也反对无政府状态。

### 4.2 经济纲领

新民主主义革命的经济纲领包含三项内容：**没收封建地主阶级的土地归农民所有**，**没收官僚资产阶级的垄断资本归新民主主义国家所有**，**保护民族工商业**。三项内容各有侧重，共同构成新民主主义经济的基本框架。

| 纲领 | 主要指向 | 性质与意义 |
|---|---|---|
| 没收地主土地归农民 | 废除封建地主土地所有制 | 民主革命的基本内容，解决农民土地问题 |
| 没收官僚资本归国家 | 摧毁官僚垄断资本 | 具有民主革命与社会主义革命的双重性质 |
| 保护民族工商业 | 保护民族资本主义经济 | 新民主主义经济纲领的中国特色，利于恢复和发展经济 |

没收地主土地归农民，是新民主主义革命的主要内容。封建地主土地所有制是封建剥削的经济基础，不改变这一制度，农民就无法摆脱封建束缚，革命也得不到广大农民的支持。土地改革在不同时期的具体政策有所调整，但废除封建土地所有制这一根本方向没有改变。

没收官僚资本归国家所有，具有双重性质。一方面，官僚资本依附帝国主义、同封建势力结合，没收官僚资本具有反帝反封建的民主革命性质；另一方面，官僚资本是垄断资本，没收它归国家所有，又具有社会主义革命的性质。这一措施使国家掌握了经济命脉，为后来向社会主义过渡准备了物质条件。

保护民族工商业，是新民主主义经济纲领中最具中国特色的内容。民族资产阶级是革命的同盟者，民族工商业对恢复经济、改善民生具有积极作用。因此，在新民主主义革命阶段，不没收民族资本，不消灭民族资本主义私有制，而是保护其合法经营，允许其发展。保护民族工商业不是保护剥削制度，而是从革命全局出发，团结民族资产阶级，发展社会生产。

### 4.3 文化纲领

新民主主义革命的文化纲领，是发展无产阶级领导的、民族的、科学的、大众的文化。所谓民族的，是指反对帝国主义压迫，维护民族尊严，具有中国作风和中国气派；所谓科学的，是指反对封建迷信和愚昧思想，主张实事求是，尊重科学；所谓大众的，是指文化为占人口绝大多数的工农群众服务，而不是少数人的专利。

文化纲领不是经济纲领的附属品，而是革命总任务的一部分。革命不仅要改变政治制度与经济关系，也要改变人的思想文化状况。没有文化上的动员与启蒙，政治动员难以持久；没有科学的世界观，革命队伍也难以形成统一的意志。

## 五、三大法宝

### 5.1 统一战线

统一战线，是无产阶级及其政党为了反对主要敌人，同其他革命阶级、阶层、党派和团体结成的政治联盟。新民主主义革命时期，统一战线是战胜敌人的重要武器。

统一战线包含两个联盟。第一个是**劳动者之间的联盟**，主要是工人阶级同农民阶级的联盟，也包括同城市小资产阶级、革命知识分子的联盟。这是统一战线的基础，是最可靠、最基本的联盟。第二个是**劳动者同非劳动者之间的联盟**，主要是工人阶级同民族资产阶级、开明绅士等的联盟。这个联盟是必要的，但必须坚持独立自主原则。

不同历史时期，统一战线的具体形式不同。国民革命时期是国民革命联合战线，土地革命时期是工农民主统一战线，抗日战争时期是抗日民族统一战线，解放战争时期是人民民主统一战线。形式变化，但两条原则不变：一是坚持无产阶级领导权，二是在联合中保持独立自主。统一战线不是无原则的联合，而是又联合又斗争：联合其革命性的一面，斗争其妥协性的一面。

### 5.2 武装斗争

武装斗争，是中国革命的主要斗争形式。近代中国没有民主制度，反动统治者掌握军队，人民没有合法斗争的条件。革命要推翻反动统治，必须以武装的革命反对武装的反革命。

武装斗争的实质，是无产阶级领导下的农民战争。农民占中国人口的绝大多数，是革命的主力军；人民军队的兵员主体是农民，革命根据地建立在农村，战争的形式也以游击战争和人民战争为主。因此，离开农民，就没有武装斗争的基础；离开无产阶级领导，武装斗争又会失去方向。

人民军队建设有两条根本原则。第一，**党指挥枪**，而不是枪指挥党。军队必须置于党的绝对领导之下，这是人民军队区别于旧军队的根本标志。第二，**全心全意为人民服务**，是人民军队的唯一宗旨。军队不仅要打仗，还要做群众工作，帮助群众建立政权、发展生产。这两条原则，使人民军队不仅是战斗队，也是工作队、宣传队。

### 5.3 党的建设

党的建设，是新民主主义革命取得胜利的根本保证。中国共产党是在半殖民地半封建社会的农村环境中领导革命的，党员成分以农民和其他小资产阶级出身者居多，各种非无产阶级思想容易带入党内。因此，党的建设必须把**思想建设放在首位**，用马克思列宁主义武装全党，反对各种错误思想。

党的建设包括思想建设、组织建设、作风建设等方面。在长期实践中，中国共产党形成了三大优良作风：**理论联系实际**、**密切联系群众**、**批评与自我批评**。三大作风是中国共产党区别于其他政党的显著标志，也是党保持先进性和战斗力的重要原因。

党的建设被称为“伟大的工程”。在战争环境、农村环境和统一战线环境中建设一个全国范围的、广大群众性的、思想上政治上组织上完全巩固的党，是一项艰巨任务。没有这一工程，统一战线和武装斗争都缺乏领导核心。

### 5.4 三者关系

统一战线、武装斗争、党的建设，是中国共产党在中国革命中战胜敌人的三个法宝。三者不是并列的三件事，而是有内在联系的整体。

| 法宝 | 主要作用 | 与其他两者的关系 |
|---|---|---|
| 统一战线 | 团结一切可以团结的力量，孤立和打击主要敌人 | 为武装斗争提供群众基础和政治联盟 |
| 武装斗争 | 以革命战争推翻反动统治 | 是统一战线的支柱，也是党的中心任务 |
| 党的建设 | 提供政治领导、组织保证和思想武装 | 是掌握统一战线与武装斗争的领导核心 |

统一战线和武装斗争，是战胜敌人的两个基本武器。统一战线是实行武装斗争的统一战线，武装斗争是在统一战线领导下的武装斗争。党的组织，则是掌握这两个武器的领导核心。离开党的领导，统一战线会失去方向，武装斗争会失去灵魂；离开统一战线和武装斗争，党的领导也无法落到实处。

## 六、农村包围城市、武装夺取政权

### 6.1 为什么不能先占城市

中国革命道路的特殊性，首先来自国情。近代中国是半殖民地半封建社会，内部没有民主制度，外部没有民族独立。反动统治者掌握强大的军队，中心城市是敌人统治的中心，反动力量集中，交通便利，便于调兵镇压。革命力量如果首先在城市发动武装起义，很容易在敌强我弱的条件下被各个击破。

另一方面，中国无产阶级人数较少，城市中的革命力量相对薄弱；农民占人口绝大多数，农村是敌人统治的薄弱环节。因此，革命不能照搬俄国“先城市、后农村”的道路，而必须把工作重心放在农村，积蓄力量，逐步包围城市。

### 6.2 为什么农村能够存在革命根据地

农村革命根据地能够存在和发展，是由中国社会的特点决定的。第一，**政治经济发展不平衡**。帝国主义划分势力范围，军阀之间长期混战，敌人内部矛盾重重，难以集中力量对付农村革命力量。第二，**农村地域广阔，敌人统治薄弱**。广大农村特别是偏远山区，交通不便，反动统治力量分散，革命力量有回旋余地。第三，**农民群众有强烈的革命要求**。土地集中、剥削沉重，农民愿意参加土地革命，支持革命军队。第四，**有党的正确领导和一定数量的红军**。这是根据地存在和发展的主观条件。

农村根据地不是消极避世的“山寨”，而是革命战争的战略基地。根据地提供兵员、粮食、情报和休整场所，是红军生存和发展的依托。没有根据地，武装斗争就会变成流寇式的游击；没有武装斗争，根据地也无法保卫。

### 6.3 工农武装割据的三个要素

“工农武装割据”是农村包围城市道路的核心概念，包含三个相互联系的要素：**土地革命**、**武装斗争**、**农村革命根据地**。

| 要素 | 地位 | 具体内容 |
|---|---|---|
| 土地革命 | 中心内容 | 打土豪、分田地，废除封建土地所有制，发动农民 |
| 武装斗争 | 主要斗争形式 | 建立红军，开展游击战争，保卫根据地 |
| 农村革命根据地 | 战略依托 | 建立红色政权，提供兵员、粮食与后方 |

土地革命是中心内容。只有解决农民的土地问题，才能调动农民的革命积极性，使红军获得广泛的群众基础。武装斗争是主要形式。没有武装，土地革命的成果无法保卫，根据地也无法存在。农村革命根据地是战略依托。没有根据地，武装斗争就失去后方，土地革命也无法稳定开展。三者相互依存，缺一不可。

### 6.4 道路的形成与意义

农村包围城市、武装夺取政权的道路，是在实践中逐步形成的。井冈山革命根据地的创建，是这一道路的开端；《星星之火，可以燎原》等著作，从理论上回答了“红旗到底能打多久”的问题，说明农村革命根据地能够长期存在和发展。此后，随着革命根据地扩大和革命战争发展，这一道路逐渐成熟。

这条道路的意义，不仅在于找到了一种适合中国的革命方式，更在于它体现了马克思主义基本原理同中国具体实际相结合的原则。照搬俄国城市起义模式，在中国行不通；从中国国情出发，把工作重心放在农村，以农村包围城市，才使革命力量由小到大、由弱到强。道路理论的形成，标志着马克思主义中国化迈出了重要一步。

## 七、新旧民主主义革命的比较

### 7.1 相同点

新旧民主主义革命，都是资产阶级民主革命，革命对象都是帝国主义和封建主义，革命任务都是反帝反封建，革命动力都包括无产阶级、农民阶级、城市小资产阶级和民族资产阶级。两者都属于民主革命范畴，都不是社会主义革命。

正因为有这些相同点，两者才能前后衔接，构成近代中国民主革命的两个阶段。新民主主义革命不是另起炉灶，而是旧民主主义革命的继续和发展；它继承反帝反封建的任务，又解决了旧民主主义革命无法解决的领导权和前途问题。

### 7.2 不同点

| 比较项 | 旧民主主义革命 | 新民主主义革命 |
|---|---|---|
| 领导力量 | 资产阶级、农民阶级 | 无产阶级及其政党 |
| 指导思想 | 三民主义、资产阶级启蒙思想 | 马克思列宁主义 |
| 革命前途 | 建立资产阶级共和国，走资本主义道路 | 建立新民主主义社会，过渡到社会主义 |
| 所属范畴 | 世界资产阶级革命的一部分 | 世界无产阶级社会主义革命的一部分 |
| 革命彻底性 | 受阶级局限，反帝反封建不彻底 | 彻底反帝反封建，最终完成民主革命任务 |

新旧民主主义革命的根本区别，是领导权不同。领导权不同，带来指导思想、革命前途和所属世界革命范畴的不同。旧民主主义革命由资产阶级领导，其前途是资本主义；新民主主义革命由无产阶级领导，其前途是社会主义。五四运动是旧民主主义革命向新民主主义革命转变的标志，中国共产党成立则是这一转变得以完成的关键。

### 7.3 “新”在何处

新民主主义革命的“新”，可以从四个方面理解。第一，**新的领导阶级**。无产阶级及其政党掌握领导权，这是最根本的“新”。第二，**新的指导思想**。以马克思列宁主义为指导，而不是以资产阶级民主主义为指导。第三，**新的革命范畴**。十月革命后，中国革命成为世界无产阶级社会主义革命的一部分，而不是旧的世界资产阶级革命的一部分。第四，**新的革命前途**。革命胜利后不建立资产阶级共和国，而是建立新民主主义社会，进而过渡到社会主义。

这四个“新”不是并列的标签，而是有主次的。领导权是根本，指导思想是灵魂，革命范畴是时代条件，革命前途是归宿。理解四者的关系，才能理解为什么新民主主义革命既属于资产阶级民主革命范畴，又不同于旧式资产阶级革命。

## 八、新民主主义社会的经济成分

### 8.1 五种经济成分

1949年中华人民共和国成立，标志着中国进入新民主主义社会。新民主主义社会不是独立的社会形态，而是从半殖民地半封建社会向社会主义社会过渡的过渡性质社会。其经济结构包含五种成分。

| 经济成分 | 性质 | 地位与作用 |
|---|---|---|
| 国营经济 | 社会主义性质 | 掌握国家经济命脉，居于领导地位 |
| 个体经济 | 小私有经济 | 农民、手工业者的个体经营，数量最大 |
| 合作社经济 | 半社会主义性质 | 个体经济向集体经济过渡的形式 |
| 私人资本主义经济 | 资本主义性质 | 民族资本经营的工商业，允许其合法发展 |
| 国家资本主义经济 | 过渡性质 | 国家与私人资本合作，向社会主义过渡的形式 |

国营经济主要来源于没收官僚资本，掌握金融、重工业、交通等命脉部门，是国民经济的领导力量。个体经济以农民和手工业者的个体劳动为基础，人数最多、分布最广，但在生产技术上落后，容易发生分化。合作社经济是劳动群众自愿联合的经济形式，具有半社会主义性质，是个体经济走向集体经济的桥梁。私人资本主义经济是民族资本经营的工商业，在新民主主义社会阶段具有有利于国计民生的一面，也有追逐利润、盲目生产的一面。国家资本主义经济是国家同私人资本合作的经济形式，是从资本主义向社会主义过渡的中间环节。

### 8.2 过渡性质与主要矛盾

新民主主义社会的过渡性质，表现在经济上就是多种经济成分并存、社会主义因素不断增长。国营经济居于领导地位，但个体经济、私人资本主义经济还占相当大的比重；社会主义方向已经明确，但社会主义制度尚未完全确立。这种状态不是停滞的，而是处在向社会主义过渡的过程中。

随着土地改革基本完成和国民经济恢复，工人阶级同资产阶级的矛盾、社会主义道路同资本主义道路的矛盾逐渐成为主要矛盾。解决这一矛盾，不是立即消灭私人资本，而是通过国家资本主义形式，逐步实现对资本主义工商业的社会主义改造；通过合作社形式，逐步实现对农业和手工业的社会主义改造。1953年提出的过渡时期总路线，概括为“一化三改”：社会主义工业化是主体，对农业、手工业和资本主义工商业的社会主义改造是两翼。1956年三大改造基本完成，社会主义基本制度在中国确立，新民主主义社会随之结束。

### 8.3 经济纲领与社会性质的关系

新民主主义革命的经济纲领，与新民主主义社会的经济结构是衔接的。没收地主土地归农民，形成了个体经济的基础；没收官僚资本归国家，形成了国营经济的主体；保护民族工商业，保留了私人资本主义经济。三项纲领共同塑造了五种经济成分并存的格局。

这种格局既不同于半殖民地半封建社会的经济结构，也不同于社会主义社会的单一公有制。它允许私人资本存在，但国营经济掌握命脉；它保留个体经济，但通过合作社引导其走向集体化；它利用国家资本主义形式，逐步实现和平过渡。理解这一格局，才能理解为什么新民主主义革命胜利后，中国没有立即进入社会主义社会，而是经历了一个过渡时期。

## 九、易错点

1. **把新民主主义革命当成社会主义革命**。新民主主义革命的任务是反帝反封建反官僚资本，不消灭民族资本主义私有制；社会主义革命的任务是消灭私有制、确立公有制。两者性质不同，不能混为一谈。
2. **用领导阶级判断革命性质**。革命性质主要由革命任务决定。新民主主义革命由无产阶级领导，但任务属于资产阶级民主革命范畴，因此性质仍是资产阶级民主革命。
3. **把民族资产阶级当作革命对象**。民族资产阶级具有两面性，是革命的同盟者，不是敌人。革命对象是帝国主义、封建主义和官僚资本主义。
4. **把保护民族工商业理解为发展资本主义**。保护民族工商业是从革命全局出发的统一战线政策和经济政策，不是放弃社会主义方向。
5. **把农村包围城市理解为不要城市**。农村包围城市的最终目标仍然是夺取城市、夺取全国政权；农村是积蓄力量的基地，不是革命的终点。
6. **把农民阶级当成领导阶级**。农民是革命的主力军，但不是先进生产力的代表，不能独立领导革命。领导权属于无产阶级。
7. **把统一战线理解为无原则联合**。统一战线必须坚持无产阶级领导权和独立自主原则，对同盟者又联合又斗争。
8. **混淆三大法宝、三大作风、三大纲领**。三大法宝是统一战线、武装斗争、党的建设；三大作风是理论联系实际、密切联系群众、批评与自我批评；三大纲领是政治、经济、文化纲领。
9. **混淆1949年与1956年**。1949年新中国成立，进入新民主主义社会；1956年三大改造基本完成，社会主义基本制度确立。
10. **把五四运动与新中国成立混为同一节点**。五四运动是新民主主义革命的开端，新中国成立是新民主主义革命取得基本胜利的标志。

## 十、小结

| 知识块 | 核心结论 |
|---|---|
| 基本国情 | 半殖民地半封建社会；帝国主义与中华民族的矛盾、封建主义与人民大众的矛盾 |
| 两大任务 | 民族独立、人民解放；国家富强、人民富裕；前者是前提，后者是目标 |
| 总路线 | 无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命 |
| 革命对象 | 帝国主义、封建主义、官僚资本主义；民族资产阶级不是对象 |
| 革命动力 | 无产阶级是基本动力，农民是主力军，城市小资产阶级是可靠同盟者，民族资产阶级可以联合 |
| 领导权 | 无产阶级领导是新旧民主革命的根本区别，也是新民主主义革命的核心问题 |
| 革命性质 | 资产阶级民主革命，不是社会主义革命 |
| 革命前途 | 两步走：新民主主义社会，再过渡到社会主义 |
| 三大纲领 | 政治：各革命阶级联合专政；经济：没收地主土地、没收官僚资本、保护民族工商业；文化：民族的科学的大众的文化 |
| 三大法宝 | 统一战线、武装斗争、党的建设；党的建设是领导核心 |
| 农村道路 | 农村包围城市、武装夺取政权；土地革命、武装斗争、根据地三者结合 |
| 新民主主义社会 | 五种经济成分并存，过渡性质社会；1956年三大改造完成，进入社会主义 |

新民主主义革命理论的逻辑，可以概括为一句话：**从半殖民地半封建的国情出发，确定反帝反封建反官僚资本的任务，由无产阶级领导、依靠人民大众，以农村包围城市、武装夺取政权，经过新民主主义社会过渡到社会主义。** 理解这条逻辑链，比记住零散结论更重要。国情决定任务，任务决定性质，性质决定前途，领导权决定方向，道路与法宝则解决“怎么走到那里”的问题。
