# 虚拟染色 · HistDiT 与 HISTDIST 架构对比

## 一、概述：两个近名模型，两条结构路线

病理虚拟染色里有两个名字只差几个字母的模型：HistDiT 与 HistDiST。它们都把 H&E 映射到 IHC，都用潜扩散，都强调结构保真，但技术路线并不相同。把两者放在一起比较，价值不在于分出高下，而在于看清「结构约束可以放在哪几个位置」这个问题有多少种答案。

粗略地说，HistDiT 把结构写进**主干的形式**：用 DiT 替换 UNet，把 H&E 的潜特征 patch 化成 token，作为空间条件的键值，让每一步去噪都对着这些 token 做交叉注意力。HISTDIST 把结构写进**采样的轨迹**：主干仍是潜扩散 UNet，但用病理自监督 ViT 的全局特征做语义条件，并在推理时从 H&E 反演出初始潜码，让采样从源图出发而不是从纯噪声出发。

这两个选择对应两种不同的失败模式。前者的风险在 token 化：patchify 会把 2×2 的潜像素压成一个向量，细胞核级别的细节在这一步就丢了，后面再怎么注意也补不回来。后者的风险在反演：DDIM 反演本身有误差，误差会沿着采样轨迹放大，结构对齐的精度取决于反演步数与调度。理解这两条风险，比记住「DiT 比 UNet 强」这种结论有用。

## 二、从 UNet 到 DiT：patchify 换来了什么

### 2.1 UNet 的归纳偏置

潜扩散的默认主干是 UNet。它的结构是编码器逐级下采样、解码器逐级上采样，中间用跳连把高分辨率特征接回解码端。这个结构天然带有三个归纳偏置：局部性（3×3 卷积只看邻域）、多尺度（下采样构造金字塔）、平移等变（卷积核共享）。

对病理图像，局部性既是优点也是缺点。优点是细胞核边界、染色质纹理这类高频结构被保留得很好；缺点是感受野受限，模型难以判断「这个腺体属于哪个结构」「这个肾小球和那个肾小球是不是同一类病变」。UNet 里通常只在低分辨率层加自注意力，注意力覆盖的范围有限，长程依赖靠堆层数间接获得。原料在讨论病理扩散的常见问题时把「高分辨率下 UNet 感受野不足导致细胞核糊化」列为典型症状，说的就是这条局限。

### 2.2 patchify 做了什么

DiT 的第一步是把潜特征图切成不重叠的 patch，每个 patch 线性投影成一个 token：

$$
z_i=W_p\,\operatorname{vec}(x_{\mathcal{P}(i)})+b_p,\qquad i=1,\dots,N,\quad N=\frac{HW}{p^2},
$$

其中 $x$ 是 VAE 潜特征，$H\times W$ 是潜空间尺寸，$p$ 是 patch 边长，$W_p\in\mathbb{R}^{d\times (p^2 C)}$。HistDiT 的配置是 $512\times512$ 输入、VAE 压缩 8 倍得 $64\times64\times4$、patch 边长 2，于是

$$
N=\frac{64\times64}{2^2}=1024,\qquad d=768 .
$$

1024 个 token 排成一维序列，接位置编码，之后所有层都是同样的 Transformer 块。这里有一个容易忽略的算术：patch 边长从 1 变到 2，token 数从 4096 降到 1024，注意力矩阵的元素数从 $4096^2\approx1.68\times10^{7}$ 降到 $1024^2\approx1.05\times10^{6}$，正好是 16 倍。**patch 边长是这类模型最有效的显存旋钮**，比调层数、调宽度都直接。

位置编码在这里不是可有可无的装饰。卷积自带平移等变，注意力没有；把图像切成一维序列之后，「哪个 token 在左上、哪个在右下」这件事必须靠位置编码显式告诉模型。病理图像的结构高度依赖空间关系：肾小球在皮质、髓放线在髓质、肿瘤前沿朝向间质，这些都不是「有哪些 token」能表达的，而是「token 怎么排」才能表达的。若位置编码被插值到训练时没见过的分辨率，模型对相对位置的判断会失准，表现为生成图在边缘出现结构重复或拉伸。这是 DiT 类模型换分辨率时必须重训或至少重标定位置编码的原因。

patch 边长还有一个不那么直观的副作用：它决定了模型能「看见」的最小结构。$512\times512$ 的图压到 $64\times64$ 潜空间，一个细胞核大约占 3 至 8 个潜像素；patch 边长取 2，意味着核的边界被切成两到四个 token，边界信息被打散到多个 token 里，靠注意力重新拼起来。若 patch 边长取 4，一个核可能只落在两个 token 内，边界细节就基本丢了。因此 patch 边长不能只看显存，还要看目标结构的尺度：做细胞核级别的任务，边长 1 或 2 是上限；做组织结构级别的任务，边长 4 可以接受。

### 2.3 全局注意力的收益与代价

每个 token 都能看见其他所有 token，注意力复杂度为

$$
\mathcal{O}(N^2 d)=\mathcal{O}\!\left(\frac{H^2W^2}{p^4}\,d\right).
$$

对 $N=1024$、$d=768$，单层注意力的乘加量约为 $2N^2d\approx1.6\times10^{9}$，加上投影的 $4Nd^2\approx2.4\times10^{9}$，单层在 $4\times10^{9}$ 量级；堆到二十多层，前向就是百 GFLOPs 量级。这个量级与同分辨率的 UNet 相当，并没有因为「Transformer 更重」而爆炸，原因是 patchify 已经把序列长度压下来了。

收益是全局感受野。病理图像里有大量需要跨区域判断的结构：肾小球在皮质里的分布密度、肿瘤前沿与间质的交界、腺体的排列方向。这些信息在 UNet 的低分辨率层勉强可见，在 DiT 里是每一层都能直接访问。代价是失去了局部性先验：模型不再天生知道相邻像素应该相似，必须从数据里学。对小数据集，这是劣势；对十万级 patch 的病理数据集，这个劣势被数据量抵消。

还有一笔隐性代价：patchify 是不可逆的信息瓶颈。每个 2×2×4 的潜块被压成 768 维向量，信息量足够，但空间排布被「打包」了。解码时 VAE 要把 token 还原成像素，还原的锐度取决于 VAE 本身的重建能力，而不是扩散模型。这就是为什么这类工作都要强调「VAE 先在病理数据上单独训好」：VAE 糊，后面的注意力再强也没用。

### 2.4 扩展性

DiT 相对 UNet 的最大优势是扩展性可预测：加宽、加深、加 token 数，性能大致按幂律提升，超参不用大改。UNet 的宽度与深度受跳连结构约束，改一处要重调一片。这一点在自然图像上已经被反复验证，在病理上还没有系统的大规模消融，原料也没有给出 scaling 曲线，所以只能作为趋势判断，不能当作已证实的结论。

## 三、HistDiT 的条件注入

### 3.1 两条条件流

HistDiT 把条件拆成两条互不干扰的流。

**空间结构流**：H&E 经 VAE 编码器得到 $64\times64\times4$ 的潜特征，patchify 成 1024 个 768 维 token（原料称 HE Tokens）。这条流不经过任何语义压缩，保留的是「哪个位置有什么形状」。

**语义诊断流**：H&E 经预训练病理大模型（原料写 UNI Encoder）提取一个 $1\times1536$ 的全局向量，与时间步嵌入结合后映射到 $1\times768$。这条流保留的是「这张图整体像什么病变、HER2 表达大概是什么级别」。

两条流的维度被刻意对齐到 768，目的是让它们能在同一个 Transformer 块里相遇，而不需要额外的投影层反复转换。

### 3.2 空间 token 怎么用

关键在于用法：HE Tokens 不作为查询，而是作为交叉注意力的键与值。设噪声潜特征 patch 化后得到查询 $Q$，则

$$
\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}}\right)V,\qquad K=W_K Z_{\text{HE}},\ V=W_V Z_{\text{HE}} .
$$

这个方向的语义是「生成端的每个位置去源图里找对应位置」。查询来自待生成的 IHC，键值来自 H&E，注意力权重形成一个软对应矩阵。若模型学到的是恒等对应，输出就与源图逐位置对齐；若学到的是偏移，偏移量会被注意力权重显式记录，可以被可视化检查。这一点比「把源图直接拼到输入通道」更可控：拼接是硬对齐，模型没有余地；交叉注意力是软对齐，模型可以在局部做微调，但微调的幅度受注意力分布约束。

### 3.3 语义条件怎么用

语义向量走 AdaLN：每个 Transformer 块从语义向量与时间步嵌入回归出一组缩放与平移参数，

$$
\operatorname{AdaLN}(h)=\gamma(c)\odot\frac{h-\mu(h)}{\sigma(h)}+\beta(c),
$$

其中 $c$ 是语义与时间步的融合嵌入，$\gamma,\beta$ 由一个小 MLP 预测。这样做的好处是**语义只调制特征的尺度与偏置，不直接改写 token 的内容**。原料把这套设计概括为「语义流不干扰结构」，机制上说得通：AdaLN 是逐通道的仿射，作用于整个特征图，不会像交叉注意力那样在空间上重新分配信息。

### 3.4 一个内部矛盾

原料在描述 DiT Block 时同时写了两句话：一句是「语义条件只通过 Scale&Shift 调整注意力权重，不直接修改空间 Token 的内容」，另一句是「用自注意力加交叉注意力融合结构与语义信息」。这两句并不等价。AdaLN 调制与交叉注意力融合是两种不同的注入方式，前者不改变空间对应关系，后者会。若语义真的只走 AdaLN，那么「交叉注意力融合语义」的说法就不成立；若语义也参与交叉注意力，那么「不干扰结构」的保证就弱了。

按架构图的常见画法，更可能的实现是：空间流做自注意力，噪声潜特征对 HE Tokens 做交叉注意力，语义与时间步一起走 AdaLN。本文按这个版本理解，并在第七节把这条矛盾列为待核项。

## 四、HISTDIST 的建模对象与训练目标

### 4.1 先分清两个名字

原料里有一处很容易误导的地方：提问者先说自己在用「HISTDIST 模型」，回答给出的却是一个通用描述——UNet 主干、染色标签作为 condition 拼进 UNet、$T=1000$、线性 $\beta$、DDIM 50 或 100 步加速。这段描述更像是对「病理扩散基线」的泛化总结，而不是某一篇论文的准确复述。随后回答自己更正：HistDiST 是 2025 年 DAGM GCPR 的工作，做 H&E 到 IHC（Ki67、CD3）的转换，核心是潜扩散加双条件，用 Phikon 而不是通用 CLIP。

因此本文把两者分开：文件名里的 HISTDIST 指后一个，即 HistDiST；前一个泛化描述只作为「基线长什么样」的参照，不作为该论文的架构。

### 4.2 建模对象：像素、潜码还是浓度

这是比较两个模型时最容易被跳过、却最影响结论的一项。HistDiST 建模的是**潜码**：VAE 把 H&E 与 IHC 都压到潜空间，扩散在潜空间里做，解码回像素。它不显式建模染料浓度，也不把比尔-朗伯分解写进网络。这一点与浓度空间扩散的工作形成对照：后者只对某一种染料的浓度通道加噪，RGB 由浓度与光谱重构，物理可解释性更强，但需要准确的染料分解。

三者可以做一张对照：

| 建模对象 | 代表做法 | 结构约束的来源 | 主要风险 |
|---|---|---|---|
| 像素 | 像素空间 DDPM | 像素级重建损失 | 高分辨率下算力爆炸，细节仍可能糊 |
| 潜码 | HistDiT、HistDiST、StainFuser | VAE 重建 + 条件注入 | VAE 是瓶颈，潜空间可能丢高频 |
| 浓度 | 浓度空间扩散、物理约束扩散 | 分解出的浓度图与源图同构 | 分解误差被固化，饱和区无解 |

HistDiST 选潜码，是为了在 256 或 512 的分辨率上把算力压到可训练范围；代价是所有的结构保真都受 VAE 重建质量约束。原料在「常见坑」里写「结构错位：VAE 编码器训练不足，先单独训 VAE 重建 H&E 再训扩散」，正是这个意思。

### 4.3 训练目标：v-prediction 与重标定调度

HistDiST 用 v-prediction 而不是 $\epsilon$-prediction。两者的关系是

$$
v_t=\sqrt{\bar\alpha_t}\,\epsilon-\sqrt{1-\bar\alpha_t}\,x_0,\qquad
x_0=\sqrt{\bar\alpha_t}\,x_t-\sqrt{1-\bar\alpha_t}\,v_t .
$$

当 $t$ 接近 0（几乎无噪声）时，$\epsilon$-prediction 的目标噪声幅度与输入信号幅度不匹配，网络要花容量去学「几乎为零的噪声」；v-prediction 把目标重新加权，使不同噪声水平下的目标方差更均衡。对病理图像，这个差别表现为亮区不容易过曝、暗区不容易糊成一团，原料把它概括为「亮度更稳」。

配合 v-prediction 的是重标定的噪声调度（rescaled noise schedule）：调整 $\beta$ 曲线，让信噪比在中间段下降得更平缓，避免亮区在早期就被噪声淹没。原料还提到 trailing timesteps，即在末尾几步强制信噪比趋零，减少残留噪声造成的伪影。这三项合起来，是「让采样末端更干净」的一组工程手段，而不是独立的架构创新。

### 4.4 推理：DDIM 反演加 eta 调度

HistDiST 的推理不是从纯噪声开始，而是从 H&E 反演出的潜码开始。DDIM 反演把采样公式反过来用：给定 $x_0$（这里是 H&E 的潜码），沿着确定性轨迹正向走，得到 $x_T$，再从 $x_T$ 反向采样生成 IHC。由于 $\eta=0$ 时 DDIM 是确定性的，正反两趟可以严格互逆（在数值精度内），源图的结构因此被「记住」。

这一步的强度取决于两件事。其一是反演步数：步数太少，正反两趟的离散化误差大，源图信息丢失；步数太多，推理时间线性增长。其二是 $\eta$：$\eta>0$ 时采样引入随机噪声，能提升染色的多样性，但会破坏可逆性，结构对齐变松。原料写的「eta-cosine 噪声调度」在术语上含混：$\eta$ 在 DDIM 里是一个标量，不是一个随 $t$ 变化的调度；更可能的意思是「$\eta$ 随时间步按余弦方式从大到小」，即早期保留随机性、后期收紧到确定性。这个解释与「可控随机，平衡结构一致性与分子特异性」的描述相符，但原料没有给出公式，复现时需要回原文核对。

### 4.5 评价：MRA

HistDiST 提出分子检索准确率（MRA）：用病理大模型（原料写 GigaPath）提取生成 IHC 与真实 IHC 的特征，衡量两者的分子语义相似度。这个指标的动机是：像素指标（PSNR、SSIM）对染色强度的整体偏移敏感，对「阳性信号是否落在正确细胞上」不敏感；而临床关心的恰恰是后者。

原料称 HistDiST 在 H&E 到 Ki67 的任务上比当时最优方法提升 28%。这个数字只有单一来源，没有给出数据集规模、评价协议与置信区间，本文按「原料口径」记录，不作为可复现的结论。方法上的要点比数字更重要：把评价从像素层搬到特征层，并用病理预训练模型做特征提取器，这个思路值得借鉴，即便具体数值需要复核。

## 五、结构保持与染色准确性：两者的侧重不同

### 5.1 结构保持的机制对比

| 环节 | HistDiT | HistDiST |
|---|---|---|
| 结构来源 | H&E 潜特征 patch 化成 1024 个 token | H&E 潜码 + Phikon 全局特征 |
| 注入位置 | 每个 DiT 块的交叉注意力（token 作键值） | UNet 中间层（拼接或加性融合） |
| 语义注入 | AdaLN 的缩放与平移 | 与潜码一起进条件嵌入 |
| 推理起点 | 纯噪声（常规）或带条件的噪声 | H&E 的 DDIM 反演潜码 |
| 结构约束的时点 | 每一步去噪都受 token 约束 | 起点由反演固定，过程靠条件 |
| 主要失效模式 | patchify 丢高频，VAE 解码糊 | 反演误差累积，条件太弱时漂移 |

这张表里最值得比较的是最后两行。HistDiT 的约束是「过程性」的：每一步都拉回源结构，误差不会累积，但每一步都可能因为注意力分散而局部松动。HistDiST 的约束是「初始性」的：起点极其准确，但如果条件嵌入太弱，采样走到一半就可能偏离，而且偏离之后没有机制把它拉回来。原料在「常见坑」里写「结构错位：Phikon embedding 权重太弱，增大条件嵌入维度或加注意力融合」，说的正是后者。

### 5.2 染色准确性靠什么

结构保持与染色准确是两个目标，优化路径并不相同。

HistDiT 面向 HER2 评估，染色准确性的关键是「阳性区域的强度分级」是否符合病理判读标准。它靠语义流（UNI 的全局特征）提供诊断先验，靠像素级损失与感知损失约束颜色。这条路线的问题是：全局语义向量只有 768 维，它能表达「这张图整体是 HER2 2+」，但很难表达「这个细胞的膜染色是 1+、旁边那个是 2+」这种空间异质性。

HistDiST 面向 Ki67、CD3，染色准确性的关键是「阳性细胞的比例与定位」。它靠 v-prediction 稳定亮度、靠重标定调度抑制过曝，这两项直接作用于「染色深浅是否可信」。它的评价也用 MRA 而不是像素指标，说明作者认为分子语义比像素相似更重要。

一句话概括：**HistDiT 更强调「结构不许动」，HistDiST 更强调「染色要像真的」**。这不是说前者不管染色、后者不管结构，而是优化重心不同，失败时的表现也不同：HistDiT 出错往往是「结构对但染色偏」，HistDiST 出错往往是「染色对但局部结构漂」。

### 5.3 怎么做一次能分辨两者的消融

如果没有对照实验，上面这些论断都只是架构图上的推测。设计一个能分辨两者的消融并不难，关键是把「结构」与「染色」拆成两组互不干扰的指标。

结构侧用三类量：一是像素级对齐，把生成图与真实 IHC 做刚性配准后再算 SSIM 与 LPIPS，配准这一步不能省，因为 H&E 与 IHC 是相邻切片，本身就有位移；二是结构侧的分割一致性，用同一个细胞核分割模型分别跑 H&E 与生成 IHC，比较核的数量、面积分布与质心偏移，这个指标比 SSIM 更贴近临床关心的「核有没有移位、有没有丢」；三是高频能量比，对生成图与源图做拉普拉斯滤波，比较高频能量的比值，比值显著小于 1 说明细节被抹平。

染色侧用三类量：一是颜色统计，在组织掩膜内比较 CIELAB 的均值与协方差，或用染色解混后的光密度分布；二是阳性区域的重合度，对 IHC 用阈值分割出阳性像素，算与真值的 Dice，这一项直接对应「染没染对地方」；三是特征层语义，即原料里的 MRA 思路，用病理基础模型提特征后算余弦相似度或做检索。

有了这两组指标，四种消融就能各归其位。把 HistDiT 的空间 token 去掉，只留语义条件，结构侧指标应当明显下降而染色侧变化较小；把 HistDiST 的反演关掉、改从纯噪声采样，结构侧下降而染色侧未必下降，因为条件嵌入仍在；把 HistDiT 的 patch 边长从 2 改成 4，结构侧的高频能量比会下降，染色侧可能反而略升，因为模型被迫学全局色调；把 HistDiST 的条件嵌入维度减半，结构侧的质心偏移会上升，染色侧的阳性 Dice 会下降，两者同时退化，说明这个条件下限已经卡住了两个目标。

这套设计的价值在于：它能把「结构保持」从一个笼统的好评，变成一个可以被证伪的量。若某个模型在结构侧三项里两项下降、染色侧三项里两项上升，那么「它更擅长染色、不擅长结构」这个判断才有依据，而不是凭架构图猜测。

### 5.4 一个共同的盲区

两者都在 patch 级别工作（256 或 512），都不建模全切片的全局一致性。一张全切片切成上万个 patch 分别生成，相邻 patch 的染色强度可能不一致，拼接后出现网格状色差。这个问题在单张 patch 的指标里完全看不出来，只有把 WSI 拼回去才会暴露。原料在讨论 StainFuser 时提到「在全切片上保持一致，避免相邻图像块风格断裂」，说明这在工程上是被认识到的，但 HistDiT 与 HistDiST 的原料都没有给出解法。实际部署时需要额外的后处理，例如按 patch 统计量做平滑，或用一个低分辨率全局图做引导。

## 六、显存与步数的工程代价

### 6.1 显存拆解

原料给出的 SD1.5 微调显存数据可以直接用来估算这一类模型：UNet 参数约 8.6 亿，FP16 下约 1.7 GB；前向激活最大项在注意力与上采样，约 4 至 6 GB；梯度与 AdamW 优化器状态约为参数的三倍，约 5 GB；缓存与碎片 1 至 2 GB。合计 12 至 14 GB，最低 10 至 12 GB 可跑（batch 为 1，开梯度检查点与 xformers），稳定推荐 16 GB 以上，全参数 FP32 无优化则要 24 至 32 GB。

DiT 的显存结构与 UNet 不同。参数量的分布更均匀，激活的主要项是每层的 token 特征与注意力矩阵。对 $N=1024$、$d=768$、12 个注意力头，单个注意力矩阵的元素数为 $1.05\times10^{6}$，按 FP16 计约 2 MB，乘头数约 25 MB；若 28 层全部保存，约 0.7 GB。这个量级比 UNet 的高分辨率激活小，因为 token 数少。真正吃显存的是优化器状态与梯度检查点关闭时的逐层激活缓存。

由此得到一条实用结论：**在相同分辨率下，DiT 的显存瓶颈从「高分辨率特征图」转到了「序列长度与层数」**。想把 512 提到 1024，UNet 是激活爆炸，DiT 是 token 数翻四倍、注意力翻十六倍，两者都不可行，必须靠 patch 边长或分块推理。

### 6.2 步数预算

两个模型都用 DDIM 系采样。设采样步数 $S$、是否开分类器无关引导为 $g\in\{1,2\}$、反演步数为 $S_{\text{inv}}$，则单张图的前向次数约为

$$
F=g\cdot S+g\cdot S_{\text{inv}}\quad(\text{有反演}),\qquad F=g\cdot S\quad(\text{无反演}).
$$

HistDiT 没有反演，取 $S=50$、$g=2$，得 $F=100$。HistDiST 有反演，取 $S=S_{\text{inv}}=50$、$g=2$，得 $F=200$。也就是说，反演这一步让推理成本直接翻倍。若为了省时间把反演步数砍到 20、采样 30，则 $F=100$，与 HistDiT 持平，但反演误差会上升，结构对齐变差。这个权衡没有免费的解。

把不同预算列成表会更清楚（$g=2$ 指开启引导，$g=1$ 指关闭）：

| 配置 | 采样步数 | 反演步数 | 引导 | 前向次数 $F$ | 相对 1000 步 DDPM 的比值 |
|---|---|---|---|---|---|
| DDPM 原生长采样 | 1000 | 0 | 1 | 1000 | 1 |
| DDPM 加引导 | 1000 | 0 | 2 | 2000 | 2（更慢） |
| DDIM 标准 | 50 | 0 | 2 | 100 | 1/20 |
| DDIM 加反演 | 50 | 50 | 2 | 200 | 1/10 |
| DDIM 省算力 | 30 | 20 | 2 | 100 | 1/20 |
| LCM / 少步 | 4 | 0 | 1 | 4 | 1/500 |

这张表要读两件事。第一，引导的代价是实打实的翻倍：分类器无关引导每步要跑一次条件分支和一次无条件分支，质量提升换来的是两倍时间，在病理任务里是否值得要看评价指标是否对引导尺度敏感。第二，反演把「省下来的步数」又还回去了一半：DDIM 从 1000 步压到 50 步是 20 倍收益，加上反演就只剩 10 倍。若再叠加引导，实际收益是 5 倍（2000 对 200）。这个账在写论文的「效率」一节时经常被漏算，只报采样步数不报前向次数，会让读者误以为加速比是 20 倍。

还有一个容易忽略的开销：VAE 解码。潜扩散的每一步都在 $64\times64$ 的潜空间里算，但最后要把潜码解码回 $512\times512$，这一步的计算量与一次 UNet 前向同量级。对 50 步的模型，解码占比不到百分之几；对 4 步的少步模型，解码可能占到总时间的三成以上。压缩到极少数步数之后，瓶颈会从去噪网络转移到 VAE，这是很多加速工作报告「端到端没有理论加速比那么高」的原因。

对比轻量模型：StainNet 单张 $512^2$ 约 1 毫秒，StainFuser 约 0.41 秒（多步），HistDiT 与 HistDiST 在百步量级，单张在秒级。全切片按一万个 patch 计，百步模型需要数小时到十几小时。这就是为什么这个方向的下一个战场是步数而不是架构：把 50 步压到 4 步，等于把一小时压到五分钟，收益远大于换一个更强的骨干。

### 6.3 训练成本

原料给出的 HistDiST 训练配置是 $T=1000$、线性 $\beta$、v-prediction、重标定调度，数据为 MIST/BCI 一类 H&E-IHC 配对 patch。HistDiT 的训练分辨率为 512，潜空间 $64\times64$。两者都需要先单独训 VAE，再训扩散，两阶段不能合并，因为 VAE 没训好时扩散学到的条件映射是错的。

两阶段的隐性成本常被低估：VAE 在病理数据上重训需要几十万张 patch，扩散再训一轮，总时间与单阶段相比接近翻倍。若直接用自然图像预训练的 VAE（如 SD 的 VAE），重建质量在病理纹理上会下降，细胞核边缘发糊是所有后续问题的源头。原料把「先用 H&E 单独训 VAE 重建」列为必做项，是经验之谈。

## 七、常见误区与原料勘误

**误区一：DiT 一定比 UNet 好。** 两者是归纳偏置的交换，不是能力的高低。UNet 的局部性对细胞核纹理有利，DiT 的全局性对组织结构有利。在 patch 级、以细胞形态为主的任务上，UNet 常常更稳；在需要跨区域判断的任务上，DiT 才有优势。原料写「DiT 替代 U-Net 更好地建模长程依赖」，方向正确，但把「更好」当成普遍结论就过头了。

**误区二：把「全局注意力」理解成「看到整张切片」。** HistDiT 的 token 来自 $64\times64$ 的潜特征，对应 $512\times512$ 的 patch。全局注意力的范围是这一个 patch，不是整张 WSI。跨 patch 的一致性需要另外的机制。

**误区三：以为 v-prediction 只是换了个参数化。** 它改变的是不同噪声水平下的损失权重，进而改变模型容量在「早期布局」与「后期细节」之间的分配。对病理图像，这个改变直接影响亮区是否过曝，不能当成实现细节忽略。

**误区四：以为 DDIM 反演是无损的。** 反演是数值过程，步数有限、网络非完美，误差必然存在。把反演当成「把源图编码进去」的精确操作，会高估结构保持能力。

**原料勘误一：HistDiST 不等于「HistDist」。** 如 4.1 节所述，原料前半段描述的 UNet 加染色标签条件、$T=1000$ 线性 $\beta$ 的模型，是一个泛化的病理扩散基线，不是 HistDiST 的架构。两者被文件名混在一起，引用时必须分开。

**原料勘误二：「eta-cosine 噪声调度」术语不成立。** $\eta$ 是 DDIM 采样里的标量随机性系数，不是噪声调度；把它与 cosine 调度并列，容易让读者以为存在一个「eta 调度表」。合理的解释是「$\eta$ 随时间按余弦衰减」，但原料没有给出公式，本文只作此推测。

**原料勘误三：HistDiT 的语义注入方式前后矛盾。** 3.4 节已述，一处说语义只走 AdaLN、不改空间 token，另一处说交叉注意力融合语义。两种说法不能同时成立，需回原文核对。

**原料勘误四：MRA 提升 28% 缺上下文。** 没有数据集规模、评价协议、基线列表与方差，这个数字只能当宣传口径。方法本身（用病理基础模型特征衡量分子语义）有价值，数值不可直接引用。

**原料勘误五：SD1.5 UNet 8.6 亿参数是公开量级，不是 HistDiT 的参数。** 两者架构不同，参数量不可互推。本文只用它来估算显存的数量级，不用于比较模型大小。

## 八、总结要点

| 对比项 | HistDiT | HistDiST |
|---|---|---|
| 主干 | DiT（patchify + 全局自注意力） | 潜扩散 UNet |
| 结构条件 | H&E 潜特征切成 1024 个 768 维 token，作交叉注意力键值 | H&E 潜码 + Phikon 全局特征，融合后进 UNet 中间层 |
| 语义条件 | UNI 全局向量经 AdaLN 调制 | Phikon 嵌入与潜码一起作条件 |
| 扩散目标 | 噪声预测（原料未明确写 v-prediction） | v-prediction + 重标定噪声调度 + trailing timesteps |
| 推理起点 | 噪声 | H&E 的 DDIM 反演潜码 |
| 结构约束时点 | 每一步 | 起点固定 + 过程条件 |
| 染色准确性的抓手 | 语义流提供诊断先验 + 感知损失 | 亮度稳定的参数化 + 重标定调度 + MRA 评价 |
| 单张前向次数 | 约 100（50 步 × 2 引导） | 约 200（50 步反演 + 50 步采样，各 × 2 引导） |
| 主要风险 | patchify 丢高频、VAE 解码糊 | 反演误差累积、条件弱时漂移 |

两个模型其实回答了同一个问题的两种问法。HistDiT 问的是「怎样让每一步去噪都看着源图」，答案是把它做成注意力里的键值；HistDiST 问的是「怎样让采样从源图出发」，答案是反演。前者在结构上更彻底，后者在工程上更省事（不用改主干）。真正决定成败的，往往不是这两个选择，而是更朴素的两件事：VAE 有没有在病理数据上训好，以及评价指标有没有测到「阳性信号落在正确的细胞上」。这两件事没做好，换什么骨干都救不回来。
