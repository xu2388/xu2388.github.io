# 算法与数据结构 · 学习笔记

## 一、概述

本笔记围绕四组相互关联的内容展开：**堆与优先队列**（结构、复杂度、C++ 实现）、**平衡二叉树的旋转判据**（平衡因子与高度）、**二分查找的区间不变式**（三种写法与边界技巧）、**动态规划的状态设计**（0-1 背包的暴力搜索、二维 DP 与一维滚动数组）。

四者的共同主题是"用结构约束换取操作效率"：堆用完全二叉树的偏序约束把取最值降为 $O(1)$、把插入删除降为 $O(\log n)$；AVL 树用平衡因子约束把查找稳定在 $O(\log n)$；二分查找用有序性把查找降为 $O(\log n)$；动态规划用状态定义消除重叠子问题，把指数级搜索降为多项式时间。

## 二、核心知识点

### 2.1 堆的结构与复杂度

堆是完全二叉树，分为大顶堆（父节点值 $\ge$ 子节点值）与小顶堆（父节点值 $\le$ 子节点值）。含 $n$ 个节点的完全二叉树高度为 $\lfloor\log_2 n\rfloor$，即 $O(\log n)$。

**入堆（push）**：新元素放到数组末尾（完全二叉树的最后一个位置），然后**上浮**——与父节点比较，不满足堆序则交换，直到满足或到达根。最坏情况从叶上升到根，经过约 $\log n$ 条边。

**出堆（pop）**：取出堆顶（大顶堆为最大值），把末尾元素移到堆顶，然后**下沉**——与较大的子节点比较并交换，直到满足堆序或到达叶。最坏情况从根降到叶，同样约 $\log n$ 条边。

**复杂度推导**：沿一条边进行的比较与交换是常数次基本操作，即 $O(1)$；总代价为"边数 × 单步代价" $=O(1)\times O(\log n)=O(\log n)$。

**建堆**：若逐个 `push`，总代价 $O(n\log n)$；若采用**自底向上堆化**，从最后一个非叶节点开始倒序遍历、对每个节点执行下沉，总代价可证明为 $O(n)$（大部分节点位于底层，下沉距离很短）。

### 2.2 数组实现与下标关系

堆通常用数组而非链表实现，因为完全二叉树的结构可由下标隐式表达，无需存储指针：

- 左子节点：$2i+1$
- 右子节点：$2i+2$
- 父节点：$\lfloor (i-1)/2 \rfloor$

**叶节点判定**：若 $2i+1\ge n$，则节点 $i$ 无左子节点，必为叶节点；若 $2i+1<n$，则为非叶节点（当 $2i+2<n$ 时还有右子节点）。

**最后一个非叶节点**：下标 $\lfloor (n-2)/2 \rfloor$，它也正是最后一个叶节点的父节点，是自底向上建堆的起点。

### 2.3 堆化函数

递归版本（大顶堆）：

```cpp
void maxHeapify(vector<int>& heap, int index, int heapSize) {
    int largest = index;
    int left = 2 * index + 1;
    int right = 2 * index + 2;
    if (left < heapSize && heap[left] > heap[largest]) largest = left;
    if (right < heapSize && heap[right] > heap[largest]) largest = right;
    if (largest != index) {
        swap(heap[index], heap[largest]);
        maxHeapify(heap, largest, heapSize);  // 交换后子树可能失序，递归修复
    }
}
```

迭代版本（`while`）：

```cpp
void maxHeapify(vector<int>& heap, int index, int heapSize) {
    while (true) {
        int left = 2 * index + 1, right = 2 * index + 2;
        int largest = index;
        if (left < heapSize && heap[left] > heap[largest]) largest = left;
        if (right < heapSize && heap[right] > heap[largest]) largest = right;
        if (largest == index) break;      // 当前节点已是子树最大值，堆序成立
        swap(heap[index], heap[largest]);
        index = largest;                  // 沿交换方向继续下沉
    }
}
```

两种写法等价：交换后新位置上移的节点可能破坏其子树堆序，必须继续向下修复。**终止条件**是"当前节点不小于其子节点"（即 `largest == index`），而非"索引越界"；到达叶节点时因无子节点可比较，自然满足该条件而退出。

### 2.4 C++ priority_queue

`priority_queue` 是 STL 的**容器适配器**，默认以 `vector` 为底层容器、以二叉堆为算法内核封装而成。模板声明：

```cpp
template <class T,
          class Container = std::vector<T>,
          class Compare = std::less<typename Container::value_type>>
class priority_queue;
```

- 第一参数 `T`：元素类型；
- 第二参数 `Container`：底层容器，需支持随机访问及 `push_back`、`pop_back`；
- 第三参数 `Compare`：比较器类型。`less<int>` 使大者优先（大顶堆），`greater<int>` 使小者优先（小顶堆）。

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;   // 小顶堆
priority_queue<int, vector<int>, less<int>>    maxHeap;   // 大顶堆

maxHeap.push(1); maxHeap.push(3); maxHeap.push(2);
maxHeap.push(5); maxHeap.push(4);
int peek = maxHeap.top();   // 5
maxHeap.pop();              // 5，随后依次弹出 4、3、2、1
int size = maxHeap.size();
bool isEmpty = maxHeap.empty();

// 由已有区间建堆，内部为 O(n) 建堆
vector<int> input{1, 3, 2, 5, 4};
priority_queue<int, vector<int>, greater<int>> h(input.begin(), input.end());
```

**与普通队列的区别**：

| 维度 | queue | priority_queue |
|---|---|---|
| 出队规则 | 先进先出 | 优先级最高者先出，同优先级按先进先出 |
| 底层实现 | 默认 `deque` | 默认 `vector` + 二叉堆 |
| 入队/出队 | $O(1)$ | $O(\log n)$ |
| 访问队首 | `front()` | `top()` |
| 典型场景 | BFS、任务排队 | Dijkstra、调度、Top-K |

**优先队列与排序**：`push`/`pop` 只维护偏序，不产生全序；连续 `pop` 可得到有序序列，但需要额外的 $O(n)$ 空间收集结果，因此它适合"反复取最值"，而非替代 `sort`。

**概念层次**：优先队列是**抽象数据类型**，只定义"插入、取最值、删除最值"的操作语义；堆是**具体数据结构**，是实现该 ADT 的首选方案。二者是"接口"与"实现"的关系，说"堆通常作为实现优先队列的首选数据结构"并不与"优先队列是内置容器"矛盾——后者指语言提供了封装好的实现。

### 2.5 AVL 树的平衡因子

平衡因子定义为节点左子树高度减右子树高度：

$$
\mathrm{BF}(node)=h(node.\text{left})-h(node.\text{right})
$$

高度按"节点到叶节点的最长路径上的节点数"计，空树高度为 0，叶节点高度为 1（若按边数计则叶节点为 0，需全篇统一）。

```python
def height(self, node):
    if node is None:
        return 0
    return 1 + max(self.height(node.left), self.height(node.right))

def balance_factor(self, node):
    if node is None:
        return 0
    return self.height(node.left) - self.height(node.right)
```

旋转判据：

- $\mathrm{BF}>1$：左偏。若左孩子 $\mathrm{BF}\ge 0$，执行**右旋**（LL 型）；若左孩子 $\mathrm{BF}<0$，先对左孩子**左旋**再对当前节点**右旋**（LR 型）。
- $\mathrm{BF}<-1$：右偏。若右孩子 $\mathrm{BF}\le 0$，执行**左旋**（RR 型）；若右孩子 $\mathrm{BF}>0$，先对右孩子**右旋**再**左旋**（RL 型）。
- $|\mathrm{BF}|\le 1$：已平衡，直接返回。

注意：上述 `height` 每次递归重算，单次调用 $O(n)$；工程实现通常在节点中维护高度字段，使 $O(1)$ 读取、插入删除维持 $O(\log n)$。

### 2.6 二分查找的三种区间写法

二分查找的正确性取决于**区间定义与循环不变式的一致性**。三种写法只在初始化、循环条件、边界更新、中点取整上不同。

**（1）双闭区间 $[left,right]$**

```python
left, right = 0, len(nums) - 1
while left <= right:                 # 区间非空的条件
    mid = left + (right - left) // 2
    if nums[mid] < target:      left = mid + 1     # 新区间 [mid+1, right]
    elif nums[mid] > target:    right = mid - 1    # 新区间 [left, mid-1]
    else:                       return mid
return -1
```

**（2）左闭右开 $[left,right)$**

```python
left, right = 0, len(nums)          # right 为哨兵位置，取不到
while left < right:                 # left == right 时区间为空
    mid = left + (right - left) // 2
    if nums[mid] < target:      left = mid + 1     # [mid+1, right)
    elif nums[mid] > target:    right = mid        # [left, mid)
    else:                       return mid
return -1
```

**（3）左开右闭 $(left,right]$**

```python
left, right = -1, len(nums) - 1     # left 为哨兵位置
while left < right:
    mid = left + (right - left + 1) // 2   # 上取整，避免死循环
    if nums[mid] < target:      left = mid         # (mid, right]
    elif nums[mid] > target:    right = mid - 1    # (left, mid-1]
    else:                       return mid
return -1
```

**统一记忆法**：先确定区间开闭，再让"循环条件"与"区间非空条件"一致，让"边界更新"恰好排除已判断过的 `mid`。左开右闭写法必须上取整，否则当 `right - left == 1` 时 `mid == left`，若走 `left = mid` 分支将原地死循环。

**边界查找的 +0.5 技巧**：在整数数组中查找最后一个 `target` 时，可改为查找 `target + 0.5`。因为整数数组中不存在 `target + 0.5`，二分必然停在"最后一个不大于它的元素"处，即 `target` 的最右出现位置。取 0.5 而非 0.6、0.7，是因为 0.5 是相邻整数间唯一的中点，构造简单、结论唯一且便于验证；任意 $(0,1)$ 内的小数在数学上都能起到"插入一个不存在的虚拟值"的作用，但 0.5 最直观、最不易出错。

### 2.7 0-1 背包：从 DFS 到滚动数组

**问题**：$n$ 件物品，第 $i$ 件重 $w_i$、价值 $v_i$，背包容量 $C$，每件至多取一次，求最大总价值。

**暴力搜索**：

```cpp
int knapsackDFS(vector<int> &wgt, vector<int> &val, int i, int c) {
    if (i == 0 || c == 0) return 0;              // 无物品可选或无剩余容量
    if (wgt[i - 1] > c)                           // 装不下，只能不选
        return knapsackDFS(wgt, val, i - 1, c);
    int no  = knapsackDFS(wgt, val, i - 1, c);
    int yes = knapsackDFS(wgt, val, i - 1, c - wgt[i - 1]) + val[i - 1];
    return max(no, yes);
}
```

参数含义：`i` 表示"当前考虑前 `i` 件物品"（从 1 计数，故取数据用 `i-1`）；`c` 表示**当前剩余容量**。两个终止条件：`i == 0` 表示物品已全部决策完毕，`c == 0` 表示容量耗尽，二者能获得的价值均为 0。该搜索每层展开两支，时间复杂度 $O(2^n)$。

**二维 DP**：定义 $dp[i][c]$ 为前 $i$ 件物品、容量 $c$ 的最大价值，

$$
dp[i][c]=\max\bigl(dp[i-1][c],\ dp[i-1][c-w_i]+v_i\bigr)
$$

表尺寸为 $(n+1)\times(C+1)$：物品维度需容纳 $i=0..n$ 共 $n+1$ 行（$i=0$ 为边界），容量维度需容纳 $0..C$ 共 $C+1$ 列。若省略 $i=0$ 的边界行而用一维下标 $0..n-1$ 描述决策，则写作 $n\times(C+1)$，两种写法只差边界行的处理方式。

**滚动数组**：$dp[i][\cdot]$ 只依赖 $dp[i-1][\cdot]$，故可用一维数组 $dp[c]$ 原地覆盖，空间由 $O(nC)$ 降为 $O(C)$，时间仍为 $O(nC)$。

```cpp
vector<int> dp(C + 1, 0);
for (int i = 0; i < n; ++i)
    for (int c = C; c >= wgt[i]; --c)          // 必须倒序
        dp[c] = max(dp[c], dp[c - wgt[i]] + val[i]);
```

**必须倒序的原因**：正序时 `dp[c - w_i]` 在本轮已被物品 $i$ 更新过，等于允许物品 $i$ 被重复选取，退化为完全背包；倒序时 `dp[c - w_i]` 仍是上一轮（前 $i-1$ 件）的值，保证每件物品只用一次。若问题本身是完全背包，则应改为正序。

### 2.8 易错点

1. 认为堆化结束条件是"索引越界"；正确判据是当前节点已不小于子节点。
2. 建堆从"最后一个叶节点"开始；实际应从最后一个**非叶节点** $\lfloor (n-2)/2\rfloor$ 开始。
3. 混淆 `priority_queue` 的比较器语义：`less` 得到大顶堆，`greater` 得到小顶堆。
4. 认为优先队列可直接排序；它只维护偏序，输出有序序列需额外收集。
5. 二分查找混用区间定义与边界更新，导致漏元素或死循环。
6. 0-1 背包一维优化误用正序，把 0-1 背包写成完全背包。
7. AVL 高度定义（节点数或边数）不统一，导致平衡因子差 1。

## 三、典型例题或关键问答

**例 1** 说明堆的入堆、出堆为何都是 $O(\log n)$。
解：完全二叉树高度为 $\lfloor\log_2 n\rfloor$；入堆自底向上上浮、出堆自顶向下下沉，最坏走完整条根叶路径，经过 $O(\log n)$ 条边，每条边的比较交换为 $O(1)$，故总代价 $O(\log n)$。

**例 2** 对 `{1,3,2,5,4}` 依次 `push` 进大顶堆，写出 `top()` 与连续 `pop()` 的输出。
解：`top()` 为 5；连续 `pop()` 依次输出 5、4、3、2、1。

**例 3** $n=10$ 的堆，最后一个非叶节点下标是多少？节点 3 是叶节点吗？
解：$\lfloor(10-2)/2\rfloor=4$；节点 3 的左孩子为 $2\times3+1=7<10$，故非叶。

**例 4** 写出 AVL 中 LL 型与 LR 型的调整方式。
解：LL 型（$\mathrm{BF}>1$ 且左孩子 $\mathrm{BF}\ge0$）对当前节点右旋一次；LR 型（$\mathrm{BF}>1$ 且左孩子 $\mathrm{BF}<0$）先对左孩子左旋，再对当前节点右旋。

**例 5** 在有序数组 `[1,3,5,7,9]` 中查找 7，分别用双闭与左闭右开写法写出前两步。
解：双闭：`left=0,right=4,mid=2`，`a[2]=5<7`，`left=3`；再 `mid=3`，`a[3]=7`，返回 3。左闭右开：`left=0,right=5,mid=2`，`a[2]=5<7`，`left=3`；再 `mid=4`，`a[4]=9>7`，`right=4`；再 `mid=3`，命中返回 3。

**例 6** 0-1 背包 $n=3$、$C=5$，二维 DP 表尺寸是多少？一维优化后呢？
解：二维为 $(3+1)\times(5+1)=24$ 个状态；一维为 $C+1=6$ 个状态。

**例 7** 若把 0-1 背包的一维循环改为正序，会发生什么？
解：`dp[c-w_i]` 已被本轮更新，物品 $i$ 可被多次选取，结果变为完全背包的解，通常大于等于正确答案。

## 四、小结

堆以完全二叉树的数组表示实现 $O(1)$ 取最值、$O(\log n)$ 插入删除、$O(n)$ 建堆，是优先队列的首选实现；`priority_queue` 通过三个模板参数把元素类型、底层容器、比较规则暴露给使用者。AVL 树以平衡因子为判据，通过四种旋转维持 $O(\log n)$ 的高度。二分查找的关键不在背代码，而在保持"区间定义—循环条件—边界更新"三者自洽。0-1 背包则展示了从指数级搜索到二维 DP、再到一维滚动数组的完整优化链条，倒序遍历是保证"每件物品仅用一次"的核心。
