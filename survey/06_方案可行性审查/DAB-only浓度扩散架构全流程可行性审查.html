DAB-only 浓度扩散架构
—— 完整处理逻辑、问题诊断与模型选择

对象：用户补充的完整架构方案——复用 H&E 的 H 浓度、以 H/E 作为形态条件、只扩散 DAB、加入 Protein Estimator A、Real-IHC Score Model B，并用 Beer–Lambert 渲染回 RGB。依据：当前项目已验证的浓度闭环、H 通道块级共享证据（Corr128=0.407，pixel Corr=0.061）以及既有 FeatStainDiff/PST-Diff/物理约束调研。

0先说结论

总判定：DAB-only 是比“同时生成 H+DAB”更合理的收敛方向，但当前完整图仍然过度堆叠，需要拆成 v1/v2

核心方向成立：既然你已经验证 H&E 与 IHC 的 H 通道存在块级共享证据，那么第一版不应让 diffusion 同时重新生成 H。最合理的生成目标是：

[CHHE, CEHE] → diffusion → ĈDABIHC → [CH, ĈDAB] → Beer–Lambert → IHC RGB

但这里的“复用 H”不能等于未经校准的硬拷贝。H 的块级相关性 0.407 支持“作为结构锚/条件”，不支持“像素级等同”；H&E 与 IHC 两侧的 stain matrix、白点、染色强度尺度仍可能不同。因此应使用一个低容量、可测量的 T_H 做域尺度校准，而不是直接假设 C_H^HE=C_H^IHC。

当前架构最大的风险不是 diffusion，而是“非配对数据如何训练条件 diffusion”

如果主训练仍然使用标准噪声预测：

L_diff = || ε - ε_θ(C_DAB^IHC,t,C_H^HE,C_E^HE) ||²

那么 C_DAB^IHC 与 H&E 条件至少要有病例/区域级对应。若完全随机 non-paired，把某张 H&E 和另一张无关 IHC 的 DAB 拼成训练 pair，模型会学到 p(C_DAB) 或 cohort average，而不是 p(C_DAB|H&E)。这是数据识别问题，不是换 U-Net 能解决的问题。

部分判定真正应保留的版本改动成本可复现性

2DAB-only 核心假设

H 通道证据支持“条件复用”，不支持“像素复制”

你给出的块级证据：

Corr_128(C_H^HE, C_H^IHC) = 0.407
Corr_pixel(C_H^HE, C_H^IHC) = 0.061

这组数字的正确解释是：H 具有一定的区域级共享结构，但连续切片/染色链造成的像素级对应很弱。它正好支持：

C_H^HE → structure condition / deterministic anchor
not: C_H^HE(x,y) = C_H^IHC(x,y) as hard pixel GT
H 直接复用仍有一个物理尺度问题

H&E 分解得到的 C_H^HE 使用的是 H&E 侧的 M_HE；最终 IHC 渲染使用 M_IHC。即使两者都叫 H，浓度的数值尺度也未必一致。建议定义：

CHcond = TH(CHHE) = aH CHHE + bH

其中 T_H 先限制为全局 affine/monotone calibration，不要让一个高容量网络自由改变 H。如果 E0 的 H 共享证据是在未校准尺度上得到的，必须先在同一 M/X0 口径下复核。

3逐模块可行性与问题

3.1 H 通道直接复用：成立，但必须加 calibration

推荐形式
C_H^HE ── fixed / low-capacity T_H ──> C_H^cond
                                           │
                                           ├─ condition to DAB diffusion
                                           └─ final H channel for renderer

v1 可以先令 T_H 为固定线性尺度或 identity，作为 baseline；主版本再用低容量 T_H 校准。不要一开始让 diffusion 重建 H，也不要把 H 作为严格像素监督。

必须做的三个消融：

  1. H full：使用 C_H^cond；
  2. H zero：把 H 条件置零；
  3. H shuffled：在 batch 内打乱 H 条件。

如果 H zero/shuffle 后结构指标几乎不变，说明主干没有真正使用 H；如果 H zero 后 DAB 全部崩塌，则要区分“合法结构依赖”和“错误的强条件短路”。

3.2 E 通道与 morphology encoder：E 有用，但“低频=形态”不成立

E 通道的正确地位

C_E^HE 可以携带胞质、基质、胶原、腺体边界和组织空间关系。它不应被解释成 IHC 的输出染色，而应作为morphology evidence。这正是把 E 加进结构条件的合理性。

但用户方案中“low-frequency extraction → morphology encoder”有一个概念风险：

  • 低频更偏组织布局、背景和整体区域；
  • 核边界、细胞膜、胞质边缘也包含重要高频成分；
  • scanner/stain appearance 也会进入 E 的低频。

因此建议 v1：

U_t = concat([u_DAB^t, C_H^cond, norm(C_E^HE)])
U-Net(U_t, t)

先不加 low-pass 和 morphology encoder 两个额外分支。v2 再加一个小型多尺度 encoder：

f_morph = E_morph([C_H^cond, C_E^HE, grad(C_H), grad(C_E)])
U-Net receives f_morph at 2 or 3 scales

这样可以判断收益来自“E 本身”还是“额外 encoder 容量”。

3.3 A：Protein Estimator 的价值与循环监督风险

判定：有条件成立；不能当真实蛋白标签

如果 A 的训练标签来自：

H&E → PSPStain → pseudo-IHC → DAB/FOD statistic

那么 A 学到的是 PSPStain 的表达偏差。它可以作为proxy expression prior，但不能被命名为真实 protein predictor，更不能成为主监督。

A 输出一个全局 c_exp 的能力边界是：

  • 它可以控制 DAB 的大致量级；
  • 它不能确定 HER2 膜阳性区域在哪里；
  • 如果 pseudo-IHC 偏向整图变棕，A 会把这个偏差传给 diffusion。

推荐：

  1. v1 不加入 A，先让 H/E condition + DAB diffusion 跑通；
  2. v2 将 A 作为可 dropout 的 soft condition，训练时随机置零；
  3. 记录 c_exp 与输出 DAB/FOD 的相关性，以及 A zeroing 后是否只改变全局量级而不破坏结构；
  4. 若有真实 HER2 grade，优先用它做 calibration/ordinal check，而不是把 PSPStain pseudo label 当 GT。

3.4 B：Real-IHC Score Model 的两个 P0 问题

P0-1：条件域不一致

B 在真实 IHC 上训练的形式是：

sB = ∇CDABt log p(CDABt | CHIHC,t)

但推理时输入的是 C_H^HE。因此 B 实际上面对 covariate shift：

ptrain(CH) = p(CHIHC)  ≠  ptest(CHHE)

如果不校准，B 可能把 H&E/IHC 的 stain-scale 差异误判成不真实 DAB。

P0-2：B 只提供“真实世界先验”，不提供实例级位置

无配对真实 IHC 训练的 B 只能学：

什么样的 DAB/H 组合在真实 IHC 中常见

它不能知道这张 H&E 的哪一块一定是 HER2 阳性。若 λ_B 太大，B 会把每张图拉向真实 IHC 的平均分布，导致“全局染色更像、实例表达更错”。

因此 B 的三个版本应分阶段：

版本条件优点风险建议
B0p(C_DAB)，不条件 H没有 H 域偏移；最容易验证只提供 marginal prior，弱先做 prior audit
B1p(C_DAB|T_H(C_H^HE))训练/推理条件口径一致需要可靠 H calibration主候选
B2完整采样 score guidance能直接约束每步采样第二个 diffusion/score 网络；梯度尺度和双先验冲突最后做

如果 B2 最终启用，必须做 score normalization：

g_diff = norm(score_main)
g_B    = norm(score_B)
s_final = score_main + λ_B(t) * (g_diff / (g_B + eps)) * score_B

不能把两个 score 直接相加后凭经验调一个绝对 λ。

3.5 主 DAB diffusion：可行，但数据配对边界必须写清楚

标准 conditional diffusion 的必要条件

训练 ε_θ(C_DAB^IHC | H&E) 时，target DAB 至少需要与 H&E 在病例、区域或弱配准层面对应。完全随机 non-paired 的目标 DAB 不能提供实例级条件监督。

数据模式标准 DAB diffusion 是否可用应采用的训练逻辑
registered / weak-paired可以主 diffusion loss 训练；用 distribution/ranking 抵抗错位，记录错位等级
case-matched but patch-unregistered有条件弱配对 target patch + FOD distribution/ranking；不要 pixel L1
完全 non-paired不能直接用标准 conditional MSE需改成 target prior + unpaired transport/cycle/分布约束；实例级表达只能作为不确定分布

5backbone 与参数化选择

主推荐：小型 conditional 2D U-Net + v-prediction

浓度图是 2D spatial field，通道数低、局部结构强、数据规模有限。第一版不应使用 FeatStainDiff 的 U-ViT/FMoE 作为 backbone；应先选择最容易复现、最容易定位问题的 U-Net。

候选优点问题建议改动成本可复现性
2D conditional U-Net多尺度 skip；局部空间归纳偏置；条件注入成熟长程依赖有限第一主干中高
U-ViT与 FeatStainDiff 逻辑相近；全局建模强小数据/小图可能过重；空间 token 设计复杂第二对照中–高中
DiT大规模训练扩展好需要更多数据和算力；局部结构先验弱后置高中
Flow-matching U-Net端点恢复不除法；适合后续稳定性对照重新建立训练/采样管线第二阶段中中–高
FMoE-DCT/MHSA可自适应路由专家 collapse、频率轴解释、复杂度高最后才做高中–低

建议第一版规模：

input:  [u_DAB^t, C_H^cond, C_E^HE]  # 3 channels
output: u_DAB or v_DAB                # 1 channel
base channels: 64 or 96
channel multipliers: [1,2,4,4]
residual blocks per level: 2
attention: only at 24×24 / 12×12 if needed

建议扩散的变量不是 raw C_DAB，而是非负浓度的无约束变换：

uDAB = log(1+CDAB)   → diffusion   → CDAB=exp(uDAB)−1

这样避免对浓度做硬 clamp(min=0) 而造成梯度断裂。监督和 B score model 必须使用同一变量尺度，不能主扩散在 u 空间、B 却在 raw concentration 空间直接相加。

6推荐的收敛版架构

6.1 v1：只保留必要模块

v1 的目标不是做出“所有模块齐全”，而是证明 DAB-only 条件扩散成立
H&E
 ├─ fixed M_HE → C_H^HE → low-capacity T_H → C_H^cond
 └─ fixed M_HE → C_E^HE → normalization → C_E^cond
                                  │
noisy u_DAB^t ────────────────────┤
                                  ▼
                        conditional 2D U-Net
                                  │
                         predicted u_DAB / v_DAB
                                  │
                         C_DAB = exp(u_DAB)-1
                                  │
                    [C_H^cond, C_DAB] + M_IHC
                                  │
                         Beer–Lambert → IHC RGB

v1 暂不加入：A Protein Estimator、B Score Guidance、low-pass 专用分支、FMoE、semantic loss、Cres。每一个都可作为后续独立实验。

v2：加入 A，但只作为软表达条件

c_exp = A(H&E)
condition = concat([C_H^cond, C_E^cond, g_exp(t)*c_exp_token])

training:
- random condition dropout on c_exp
- log c_exp / output FOD correlation
- compare A on / A zero / A shuffled

如果 A zero 后结构保持、DAB 全局量级有可控变化，说明 A 是合法表达先验；如果 A zero 后输出完全失效，说明主模型在抄 pseudo-label shortcut。

v3：最后加入 B prior guidance

B 的推荐不是直接从用户图中的形式一步到位，而是：

  1. 先训练 B0：无条件真实 IHC DAB prior，验证能否识别真实/伪造浓度的分布差异；
  2. 再训练 B1：输入经过 T_H 的统一 H 条件，确认训练/推理域一致；
  3. 最后才在采样中加入 B2：只在 mid/late timestep、小权重、score-normalized 的 guidance。
s_final(t) = s_main(t) + λ_B(t) * normalize(s_B(t))
# λ_B(t) starts at 0; first scan λ_B ∈ {0, 0.05, 0.1} after norm matching

如果 B 只提高 FOD histogram，却降低 membrane DICE 或 regional ranking，应判为“先验过强”，回退到 v2，而不是继续调大 B。

7loss 与 timestep 逻辑

L = Ldiff + λFOD(t)LFOD + λrank(t)Lrank + λsem(t)Lsem + λres||Cres||

建议顺序：

阶段主要约束原因
v1只有 L_diff + renderer 检查先确认 DAB-only diffusion 能生成稳定浓度
v2global FOD mean + 20-bin histogram先控制表达量级与分布，不引入空间错位惩罚
v3regional ranking增加实例/区域层面的表达顺序
v4小权重 pathology semantic auxiliary防止外观/结构被物理 loss 单独劫持
v5B score guidance只在前面稳定后作为真实 IHC prior

时间步上不应把 C_H 简单称为“高频”、把 DAB 简单称为“中频”。更稳妥的表述是：

early/high-noise: strong morphology condition, weak expression prior
middle: global DAB/FOD distribution
late/low-noise: regional DAB ranking / membrane detail
all stages: retain a nonzero H structure floor

如果物理 loss 通过 x_hat_0 回传，使用 λ_FOD(t)∝sqrt(SNR(t)) 或改为 v-prediction；不要用 PCGrad 去掩盖由 x_hat_0 Jacobian 造成的幅度爆炸。

必须记录：

  • 每步 u_DAB/DAB 分位数、x0_pred 范围与 renderer 后 clamp fraction；
  • H condition、E condition、A token、B score 的 RMS/gradient norm；
  • DAB FOD global mean、20-bin histogram、regional ranking；
  • nuclei/membrane DICE、结构 SS、H-score/ordinal consistency；
  • 黑团/AQuA/暗块比例，独立于 PSNR/FID 报告。

9最终决策

建议正式收敛为下面这一版
  1. 扩散目标：只扩散 u_DAB=log(1+C_DAB)，不重新生成 H。
  2. H 处理：C_H^HE 作为结构锚和最终 H 通道，但先经过低容量 T_H 做 M/白点/尺度校准；不做 pixel hard equality。
  3. E 处理：C_E^HE 只做 morphology condition；v1 直接拼接，v2 才加入多尺度 morphology encoder；不把“低频”当作全部形态。
  4. 主 backbone：小型 conditional 2D U-Net + v-prediction；epsilon 作为最小 baseline，flow matching 作为后续对照。
  5. A：先不加；后续只作为 dropout 的 soft expression prior，明确标注 PSPStain pseudo-label 来源。
  6. B：先做真实 IHC DAB prior audit；解决 H 域校准后再做 score guidance；不能让 B 决定实例级阳性位置。
  7. 物理闭环：[C_H^cond,C_DAB] + fixed/calibrated M_IHC + Beer–Lambert；v1 不加 C_res，除非残差审计证明它必要。
  8. 训练顺序：L_diff → global FOD → regional ranking → semantic auxiliary → B guidance，一次只加一个。
最稳的论文方法主张

我们不让扩散模型重复生成已有共享证据的苏木素通道，而是在经过域校准的 H&E 结构条件下，仅生成 marker-specific DAB 浓度；随后使用 fixed/calibrated stain matrix 和 Beer–Lambert 定律将浓度状态渲染为 IHC 图像。蛋白表达估计器只提供软先验，真实 IHC score model 只提供受控的 target-domain prior，二者均不被宣称为实例级真值。

最终可行性等级

整体方向：成立但必须收窄。“DAB-only + H/E condition + physical renderer”是当前最合理的主线；“A+B+形态编码器+低频分支+score guidance 一次性全部加入”不适合作为第一版，因数据配对、H 域偏移、pseudo-label 循环和多重梯度路径会同时让结果不可归因。
