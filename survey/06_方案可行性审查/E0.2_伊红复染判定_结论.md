# E0.2 结论：IHC 片子没有伊红复染 —— 第三通道只能用「未解释残差」

> **本文档同时修正了任务书初版 §3 判据的一个原理性缺陷。**

## 1. 结论（一句话）

**判定"没有伊红复染"成立**，第三通道用 **`C_res`**。

**但成立的理由与自动判读给出的理由不同**——自动判读的判据在原理上无法检出"没有伊红"，这次是**碰巧**给出了正确答案。详见 §3。

## 3. 自动判读是假阳性 —— 而且它的判据原理上就是坏的

任务书初版 §3 的判读逻辑是：

```
if E/H < 0.05            → 没有伊红
elif E_coherence > 1.2   → E 是噪声，不能当第三通道
else                     → ✅ 有伊红，C_E 可作候选
```

代入实测：`E/H = 0.311`（≥0.05），`E_coherence = 0.282`（≤1.2）⇒ 落进 **else** ⇒ 输出"**有**伊红"。

**这是一个假阳性。** 而且更糟的是：**这个判据结构上不可能给出"没有伊红"**，除非残差恰好为零。原因是——

### 3.1 一个代数事实（已实测证明）

在 3×3 解混 `C = pinv(M) @ od`（`M` 的列 = `[H, E, DAB]`）中，**`C[1]`（"E 通道"）恒等于正交补残差通道，与伊红无关**：

```
w2 = M⁻¹ 的第 2 行，满足  w2·s_H = 0,  w2·s_DAB = 0,  w2·s_E = 1
⇒ w2 ∥ (s_H × s_DAB)        实测夹角 8.5e-7 度（数值零）
⇒ C_E = w2 · od = w2 · r，  r = od 在 span{s_H, s_DAB} 正交补上的分量
⇒ C_E / C_res = −1.5918      纯常数（Ruifrok 值下）
```

**实测验证：**

| 构造 | 结果 |
| --- | --- |
| `od = a·s_H + b·s_DAB`（绝对没有伊红） | `\|C_E\| = 1.4e-16`（机器零） |
| 再叠加任何正交补残差 `r` | `r` **100% 落进 `C_E`** |

⇒ **任何"没有伊红、但有残差（光照误差 / 染色向量不准 / 非染色吸收）"的片子，都会给出非零且有结构的 `C_E`。**

⇒ `E_coherence ≤ 1.2` 这个条件**在真实组织上永远成立**（真实组织永远有结构）⇒ 它是**假阳性生成器**。

### 3.2 一个被自检推翻的替代判据

初版还曾打算用 `corr(C_E, C_H) < 0 ⇒ 有伊红`（理由：伊红在胞质、苏木素在核，互斥）。**自检直接推翻，而且方向正好相反：**

| 情形（合成数据，已知真值） | `corr(E,H)` |
| --- | --- |
| 真伊红（独立间质场） | **+0.022** |
| 染色向量误差（纯泄漏） | **−0.974 \~ −1.000** |

**泄漏给强负相关，真伊红给接近 0。** 原因是残差轴的正负号本身是任意的（`w2 ∝ −(s_H × s_DAB)`）⇒ **`corr` 的符号没有意义**。

### 3.3 唯一有效的判据：`R²(C_E ~ C_H, C_DAB)`

问：**`C_E` 里有没有 `C_H` / `C_DAB` 都没有的空间结构？**

| `R²` | 结论 |
| --- | --- |
| ≥ 0.90 | 纯泄漏 ⇒ 没有第三种染色 |
| ≤ 0.50 | 有独立第三成分（但**不能证明是伊红**） |
| 0.50–0.90 | 不确定 |

**自检结果（合成数据 + PNG 存盘 + uint8 往返）：**

| 情形 | `R²` | `E_absmean` |
| --- | --- | --- |
| 真伊红（独立间质场） | **0.0008** | 0.1722 |
| 染色向量误差 δ=0.03 | 0.9489 | 0.0044 |
| 染色向量误差 δ=0.10 | 0.9958 | 0.0128 |
| 染色向量误差 δ=0.20 | 0.9991 | 0.0242 |

判据干净可分。**适用下限**：`E_absmean ≲ 0.01` 时残差淹没在 uint8 量化底噪里，`R²` 不可信（会虚低到 ~0.03）。

## 4. 为什么"没有伊红"这个结论**仍然成立**

理由不是自动判读，而是下面三条（按强度排序）：

### ① 领域事实（最强）

**ER 是核受体；免疫组化标准流程只做苏木素复染，不做伊红。** 这一条本身就足以定论。

### ② 同口径底噪对照（用户数据里**已经有**，之前没被用上）

用户手上有一个**现成的、同口径的**「缺失染色」对照：

| | 读数 |
| --- | --- |
| 已知 H&E 片上的 **DAB** 通道（DAB 不存在） | **0.0858** ← 缺失染色底噪 |
| ER 片上的 **E** 通道 | **0.0736** |

⇒ 比值 **0.86 < 1** ⇒ **ER 片的 E 读数处在"缺失染色"底噪的量级，甚至更低。**

这比"和 he.jpg 的 0.2592 比（3.5×）"强得多，因为它是**同一个流程、同一个矩阵、一个确定不存在的染色**。

> ⚠️ 严格说这两个底噪不完全对称：一个是 `w3·r₃`（⊥ s_H, s_E），另一个是 `w2·r₂`（⊥ s_H, s_DAB），尺度因子不同。所以它是**指示性**的，不是精确对照。但在没有更强对照时，这是最好的一个。

### ③ 量级差

`E_absmean` 3.5×、`E/H` 2.6× 低于已知含伊红的参考片。支持性证据，单独不足以定论。

## 5. 对方案的三个具体影响

### 5.1 第三通道的**命名**必须改（最重要）

`C_E` 与 `C_res` 是**同一条轴**（差一个常数 `−1.5918`）。所以：

- 第三通道**永远**是这条轴；
- 它的正确名字是「**未解释残差**」，**不是**"伊红"；
- **论文里不能把它写成染色通道**——会被问"这是哪种染色"而答不上来。

这不是措辞问题：如果把它当染色通道，就会期望它有染色应有的物理约束（非负、与表达量单调），而它实际是残差，**必须保持有符号**。

### 5.2 残差通道**必须被约束**，否则是"非物理色偏"的自由通道

渲染是 `M₃ · [C_H, C_DAB, C_res]`，而 `s_res` 是一根**非物理的颜色方向**。

⇒ 如果不对 `C_res` 加约束，扩散模型会乐于往这个自由度里塞内容，产生**无法用任何染色解释的色偏**。

**建议**：给 `C_res` 加一个**向零收缩的惩罚**（或强正则），让它只在"不得不"时被使用。这是 E0.2 结论直接推出的新设计要求。

### 5.3 如果 `R² ≥ 0.9`，残差是**可修的**，E0.3 要提前

`R² ≥ 0.9` 意味着 `C_E` 完全能由 `C_H, C_DAB` 线性解释 ⇒ 残差**来自染色向量不准**，而不是真实的第三成分。这时：

- 换一个更准的 `M` 会把残差压下去；
- **E0.3（矩阵敏感性）的优先级要提到 E0.1 之前**。

## 7. 一句话交接给下游

> 第三通道 `Z = [C_H, C_DAB, C_res]` 中的 `C_res` 是**未解释残差**，不是染色。
> `C_H, C_DAB` 用 softplus 保持非负；**`C_res` 必须保持有符号**，并**加向零收缩惩罚**。
> 渲染矩阵用正交基 `M₃ = [ŝ_H, ŝ_DAB, ŝ_res]`（列序与 `Z` 一致）⇒ `M₃ᵀM₃ = I` ⇒ `M₃⁻¹ = M₃ᵀ` ⇒ 重建精确可逆。
