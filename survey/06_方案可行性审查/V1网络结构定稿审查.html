总判定：表示与条件的设计是对的，backbone 的选型要换，两个必填项缺失

你把「扩散变量 = CDAB、条件 = CH/CE/fmorph/cexp、渲染固定」定下来，方向与 2026 MICCAI 那篇浓度域工作的骨架一致，也与你已验证的闭环一致 —— 这部分我完全同意。

2.2 你的引用有一处过度

你写的是：「他们甚至明确认为『只生成缺失染料、保留已知染料』比直接 RGB→RGB 更物理地保持已知结构」

这句话在原文里不存在。 全文我检索了 preserv 等词，原文对「为什么在浓度域做」的论证只有一段，逐字如下：

The choice of representation space is critical. Rather than operating in the RGB
domain, we adopt a concentration-based representation derived from color
deconvolution, in which the image formation process becomes approximately
linear with respect to stain concentrations. This transformation provides a
physically meaningful space, simplifying the representation of hematoxylin,
eosin, and saffron components and facilitating learning.

⇒ 它的理由是 「成图过程对染色浓度近似线性」，因此「物理上有意义的空间，简化表示、便于学习」。这是线性性 / 可学习性的论证，不是「保留已知结构更物理」的论证。

为什么这一点重要：你打算把这句话写进论文的 motivation。审稿人只要打开这篇 PDF（开放获取）就会发现原文没有这个论断 —— 这属于可被当场证伪的引用。正确写法是引用它真实的那句（线性性），或者改成你自己的论证（下面给你一条更强的）。

建议替换的 motivation（有数据支撑，且是原文没有的）

把「保留已知结构」换成 「H 通道已被输入约束，生成模型的全部容量都花在 H&E 里没有对应物的那一维上」，并用 CFM-HES 自己的消融做对照：

  • CFM-HES 的 saffron 与伊红强相关，所以它的生成模型几乎没有增益 —— 消融里把 CFM 换成确定性 UNet（PredS），PSNR 只差 0.72 dB（见 §2.5）。
  • 而 DAB 在 H&E 里没有对应物，H&E→DAB 是真正的一对多 ⇒ 同样的架构在你这里，生成模型的收益应该更大，而不是更小。

这条论证同时解释了「为什么你需要生成模型」和「为什么 CFM-HES 的结论不能直接照搬到你的任务」，比原文那句被误引的话强得多。这也正是你库内已有的一条判断。

2.3 它的推理反而反对你选 diffusion

CFM-HES 明确论证了为什么选 flow matching 而不是 diffusion，理由两条：训练更稳、推理更快（1000 步 → 50 步）。这不是顺带的，它写在 §2.1 Motivation 里，并且论文的整个方法选择都建立在这上面。

所以：你把它当作最近的先例，就必须回答「为什么你选 diffusion」

可行的三条回答，按强度排序：

  1. （最强）任务的一对多程度不同。 saffron ≈ 伊红的函数，DAB 在 H&E 里没有对应物 ⇒ 你需要一个真正的生成模型，而 CFM 相对确定性 UNet 的增益在 saffron 上被证明很小（0.72 dB），在你的任务上应当更大。这条有原文消融支撑。
  2. （中）score 引导接口。 你的 B 模块需要采样期 score。FM 的确定性 ODE 没有天然的 score 接口 —— 虽然 Feng et al. (ICML 2025) 已给出 FM 的通用 guidance 框架、Guided Flows 也把 CFG 搬进了 FM，所以这条是「更方便」而不是「只能 diffusion」。
  3. （弱）你已有的工程基础。 你已经有 v-prediction + zero-SNR 的实现。这是工程理由，可以写，但不要当主论证。

另外必须诚实写一句：在速度与训练稳定性上，FM 优于 diffusion 是有直接先例支持的（就是这篇）。不要假装这个 trade-off 不存在。

3.2 为什么这在 8 GB 上不成立（数量级论证）

SD1.5 U-Net 的第一级是 320 通道，且第一级分辨率就是输入分辨率（没有前置下采样）。单个激活张量的显存：

320 ch × 256 × 256 × 4 B ≈ 84 MB（fp32，单个张量）

而训练时每个 ResBlock 至少两个卷积、每个尺度要保留 skip 供反传、attention 在低分辨率尺度还会产生二次项。把 batch、层级叠加、梯度与优化器状态算进去，总需求落在几十 GB 量级，与 HistDiST 报告的 24 GB 是同一个数量级 —— 而 HistDiST 还是在 latent 空间、还开了 gradient checkpointing 与 xformers。

换成小 U-Net 之后是什么量级（同一口径）

base channels 64、multipliers [1,2,4,4]、256×256 输入：第一级激活张量

64 ch × 256 × 256 × 4 B ≈ 17 MB

约为 SD 版的 1/5（通道 320→64 是 5×）。配合 AMP + gradient checkpointing，batch 4–8 在 8 GB 上是可行的。这也正是 CFM-HES 用普通 U-Net 在 256×256、batch 16 上训得起来的同一条路线。

诚实标注：以上是数量级估算，不是实测。我没有在你的硬件上跑过。但「SD1.5 U-Net 全分辨率 > 8 GB」这个结论的裕度足够大，不需要实测就能判定。

3.3 更根本的问题：SD1.5 U-Net 的价值全部来自它的预训练权重，而你用不上

SD1.5 U-Net 的设计前提你的设定后果

输入 latent 被 VAE scaling factor（≈0.18215）缩放到近似单位方差浓度图是重尾、含大量零的非标准化量预训练权重统计上完全不匹配
带 cross_attention_dim = 768 的文本 cross-attention 层你不需要文本条件；你的条件是空间特征 + 全局向量这些层要么闲置（浪费参数与显存），要么要改造成你的注入形式 —— 那就不叫「复用 SD U-Net」了

SD1.5 U-Net 的收益 = 预训练先验；你既换了输入空间、又换了条件形式，先验拿不到，只剩下一副为 64×64 latent 设计的重骨架。这是「大而无效」。要么在 latent 空间用 SD 权重（那你得先把浓度图编码进某个 latent，等于多引入一个 VAE —— 又多一个要训的东西），要么换小 U-Net。

IHC → [C_H, C_DAB] → M·C → Beer–Lambert → IHC_recon
if ‖IHC_recon − IHC‖ 大:  先别训 diffusion

这个判断完全正确：如果浓度表示本身不自洽，再好的扩散也救不回来。CFM-HES 也把分离算法当成一个独立的关键环节（用的是 ICIP 的 unrolled projected gradient + TV 正则，不是 Macenko）。

但有三点必须补上，否则这个检查会给出误导性的结论
  1. H&E 侧的解混矩阵必须是 2 列 [s_H, s_E]。 由你自己 E0.2 的实测结论直接推出：在 3×3 解混下，「E 通道」恒等于正交补残差通道（夹角 8.5e-7 度，C_E/C_res = −1.5918 纯常数）。若 H&E 侧用 3 列，CEHE 就不是伊红，后面 Structure Encoder 与 A 的输入语义全部失效。这一条不确认，§4.4 与 §4.5 都建立在流沙上。
  2. IHC 侧的重建残差必然非零，需要一个阈值而不是「差很多」。 E0.2 已证 IHC 片子没有伊红 ⇒ 真实 IHC 的 OD 有一个 ⊥ span([s_H, s_DAB]) 的分量 r。先量 ‖r‖/‖Y‖，把阈值写死，否则你会把「本来就有残差」误判成「分离失败」。
  3. log 底数与 I₀ 要写死并注明。 CFM-HES 用的是 I = I₀ exp(−HW)、I₀ = 255、自然对数；Ruifrok 原始定义是 log₁₀，两者差 ln10 ≈ 2.303。库内已把这条列为澄清点，现在有了可对照的具体取值（CFM-HES: 自然对数 + I₀=255）。

判定：不成立（SD1.5-style）；成立（换成 from-scratch 小 U-Net）。理由见 §3，此处只补三条与网络结构直接相关的点。

你 §5 里那句「你的创新发生在 representation + condition + protein + real-IHC score，而不是重新发明一个 U-Net」——这句话我完全同意，但它推出的结论与你的选型相反

4.3 Input Adapter 与 Output Head

判定：Input Adapter 3→4 不成立；Output Head 4→1 成立但不需要单独一个阶段。

你的写法
Input: [DAB_t, C_H, C_E]   (3ch)
   ↓  3 → 4 Input Adapter
SD1.5-style U-Net
   ↓  4 → 1 Output Head
predicted v
应该的写法
Input: [DAB_t, C_H, C_E]   (3ch)
   ↓  conv_in = Conv2d(3, C, 3, p=1)
U-Net
   ↓  conv_out = Conv2d(C, 1, 3, p=1)
predicted v

为什么 3→4 适配层没有用途：它的唯一可能理由是「保留 SD1.5 的 4 通道 conv_in 权重」。但：

  • SD1.5 的 conv_in 权重是在 VAE latent（被 scaling factor 缩放到近似单位方差）上学的；你的输入是未标准化的浓度图，统计分布完全不同 ⇒ 权重本身没有迁移价值。
  • 而 §5 里要补的「CDAB 逐通道归一化」如果真的做了，那也只是把尺度调成近似单位方差，但那是浓度图的方差，不是 VAE latent 的方差 —— 仍然不等于让预训练权重有意义。

⇒ 直接 Conv2d(3, C, 3, padding=1)。少一层、少一次无意义的映射、少一个要调的参数量。

Output Head：conv_out 从 4 通道改成 1 通道是一行改动；你写的「4→1 Output Head」是把它当成一个额外阶段，没必要 —— 除非你保留 SD 的 4 通道 conv_out 然后再降维，那同样是无意义的（多一层参数 + 多一次梯度路径）。

4.4 Structure Encoder

判定：成立。这是这份 spec 里我最赞成的部分。

三条都对
  1. 「一个编码器，两种用途」（§23）—— 消除了我上一份报告指出的「raw concat + f_morph + c_exp 三条同源条件路径导致收益无法归因」的问题。这是正确的收敛。

一个必须消融掉的疑问：LP(C_H) / LP(C_E) 与 C_H / C_E 的冗余

你把 I_struct = [C_H, C_E, LP(C_H), LP(C_E)] 四条一起喂进 encoder。但一个带下采样的 CNN 本身就在逐级做低通 —— LP(C_H) 与 C_H 在 encoder 的第一、二级里提供的信息高度重叠。所以：

  • v1 建议直接 [C_H, C_E] 两通道，把 LP(·) 当作独立消融去测（加 LP vs 不加 LP）。
  • 「低频 = 形态」这条语义承诺在文献里没有依据（上一份报告已核实的阴性结论），而 HER2 是膜染色，核/膜边界是高频 —— 纯低通可能删掉你最需要的东西。若要加，用多尺度（低通 + 梯度）而不是纯低通。
Residual / ControlNet-lite 注入：选对了

你选 h_i' = h_i + Δh_i 而不是 cross-attention，理由是「C_H、C_E 本身有明确的空间位置」。这条与 GLIGEN（CVPR 2023）的消融说明一致：sum 注入更适合「空间对齐的条件」，而 cross-attention 在该消融中 FID 相近但定位类指标更差（YOLO AP 16.6 vs 21.7）。

两个实现细节：① 若从零训练，ControlNet 的 zero-conv 初始化仍然值得保留（让 Δh 从 0 起，训练初期不破坏主干）；② 你这个结构严格说不是 ControlNet（没有可训练的 encoder 副本），而是特征级加性条件注入。论文里用准确的词，别叫 ControlNet —— 否则审稿人会问「你的 trainable copy 在哪」。

4.5 A 蛋白表达估计器

判定：有条件成立。网络选型（ResNet18 + FPN）没问题，但有两个必须在动代码前解决的问题，其中一个会直接导致「白加参数」。

★ 问题 1：protein map 没有任何监督信号 ⇒ 它会退化成常数图

你给的监督只有：

HE → PSPStain → IHC_pseudo → DAB/FOD → c_exp^pseudo   (一个标量)

而 A 输出两个东西：P_exp ∈ R^{1×H/8×W/8}（protein map）与 c_exp ∈ R^128（全局条件）。

按你 §11 的图，c_exp 来自 Global Pool → MLP。⇒ 标量标签的梯度只会流到 Global Pool 之后的分支；P_exp 那条支路没有任何一项损失直接作用在它上面。

后果可预测：P_exp 会收敛到「让上游共享 trunk 尽量好地预测 cexp」的副产品，最可能是一张近似常数的图（因为常数图对全局池化最"安全"）。然后你把这张常数图经 1×1 conv 注入 32×32 / 64×64 层 —— 等于注入了一个常量偏置，白加参数、白加一条梯度路径、还多一个归因不清的模块。

两条出路，选一条：

  • （推荐，省事）v1 砍掉 protein map，A 只输出 c_exp。等 cexp 这条路验证有效后，再考虑加空间分支。
  • （要空间就给它监督） 用伪 IHC 的 DAB 图作 P_exp 的目标。但这会把 PSPStain 的域偏差 + 10–50 px 错位 一起引进 A —— 而错位的代价在库内已被记录为「把模型推向错误的解」（HER2 Score-Aware NCMT 的受控实验）。如果走这条，P_exp 必须降分辨率监督（≤1/8）并做平滑，且要单独消融。
问题 2：1/8 分辨率的理由用错了对象

你写「为什么 1/8？因为你的真实 IHC/H&E 配对本身存在漂移，我们不应该让 A 学成一个 pixel-perfect map」。

这个推理对监督目标成立，但对 P_exp 不成立 —— P_exp 是喂给主 U-Net 的输入条件，不是被评价的输出。条件的分辨率不需要去匹配目标的可靠性；这两件事被混在一起了。混在一起的后果就是：「因为有漂移所以降到 1/8」被用来给一个本来就没有监督的分支做辩护。

⇒ 先回答「Pexp 的梯度从哪来」，再讨论它的分辨率。

问题 3（沿用上一份报告，此处只重申不重复论证）：监督来源仍是伪标签

你的 §12 明确保留了 HE → PSPStain → IHC_pseudo → DAB/FOD → c_exp^pseudo 这条链。上一份报告已给出三条独立论证判定它不成立（伪标签无先例 / 递归训练退化有 Nature 证据 / 连续标量与临床 ordinal 标签形状不匹配）。

此处只补一条实现层面的建议：既然你决定保留 A，那就把 A 设计成可整体关闭的模块 —— c_exp 训练时以概率 p 置零（p 从 0.3 起），并且记录 c_exp 与输出 FOD 的相关性。如果 A-zero 后输出完全失效 ⇒ 主模型在抄 pseudo-label shortcut ⇒ 撤销 A。这是零成本的「A 是否有害」的检测器。

4.6 B 真实 IHC score model

判定：有条件成立。网络结构（4 层 64/128/256/256、attention 放低分辨率或 bottleneck）是合理的，与「B 不是最终生成器、不需要很大」的判断一致。但有三点要改。

★ 问题 1：用 LP(C_H) 当条件，会把 B 推向「只有 marginal」那一档 —— 而那一档已被证明伤 PSNR/IOD

你 §15 的理由是「B 的 H condition 建议用 LP(C_H) 或 Downsample(C_H)，让 B 专门学区域级的 H→DAB 统计关系」，动机是回避 CHHE 与 CHIHC 不对齐。

但这条路有代价，而且代价是可以量化的：把条件低通/降采样，等价于把 B 往无条件方向推。而 MIU-Diff 的消融（在 BCI / MIST 上）显示：

配置（MISTHER2）PSNR ↑Hist ↑IOD 偏差
Ours（full）14.3680.670−1.146
U-guided（只有 marginal 项）13.8780.558−2.095
w/o guidance（完全无条件）14.3370.217−2.178

⇒ 条件越弱，越靠近 U-guided / w/o 那一档：Hist 掉、IOD 偏差变大。你的 LP 条件是这两档之间的插值。

更关键：LP / 降采样根本不能修域偏移

域偏移的来源是 MHE ≠ MIHC、白点不同、染色强度尺度不同 —— 这些是乘性/加性的整体尺度差。低通滤波与降采样只去掉高频细节，不会改变整体的增益差：

LP( MHE·CHHE )  ≠  LP( MIHC·CHIHC )

⇒ 你为了修域偏移而丢掉了空间信息，但域偏移并没有被修好。这是付出了代价、没有拿到收益。

正确顺序：先用 T_H 把 CHHE 校准到 CHIHC 的尺度（低容量 affine/monotone），域对齐之后再决定用多大带宽。不要用「模糊掉条件」来代替「校准域」。

问题 3：先想清楚 B 到底买到什么 —— 答案是数据规模，不是精度

你的主扩散已经是在真实 IHC 的 DAB 上训练的（弱配对），所以它已经在学 p(C_DAB | H&E)，其中已经包含了 marginal。B 额外提供的，只有「无配对 IHC」那部分信息 —— 也就是 MIU-Diff 的 U 项。

⇒ B 的价值 = 让你能用上没有 H&E 配对的 IHC 数据。 MIU-Diff 的整个动机就是「unpaired」（配对数据稀缺）。

你的情况B 的净收益建议
有大量无配对 IHC（远多于配对集）正：B 把无配对数据变成可用的分布先验值得做，但按 B0 → B1 → B2 分步
无配对 IHC 与配对集同量级或更少≈ 0 或负：marginal 信息主模型已从配对数据里学到，而 B 带来 IOD 偏差风险B 降级为 v3 消融，不作为 v1 组件

动作（开工前就能做）：清点你的无配对 IHC 池（张数、来源、是否同一染色协议）。这个数字直接决定 B 该不该进 v1。 这是本轮对你路线图最有用的一个重构 —— 它把「B 好不好」变成一个可查的事实问题。

你 §18 那句「B 不是 real/fake 分类器，它输出 s_B」—— 完全正确，而且它带来一个有用的工程后果

score model 用 denoising score matching（回归） 训练，不是对抗训练。⇒ B 可以离线训好、冻结、单独评估质量。这正好允许一个干净的 go/no-go 门禁：

注意 B0 恰好没有你担心的域偏移问题（它不条件 H），所以它是最便宜的起点。

4.7 Guidance 模块

判定：成立。你 §19 的两条决定都对：主模型与 B 用同一 noise schedule + 同一 parameterization（统一 v-prediction），以及 guidance 是数学组合不是网络。

但组合的「名分」要写准：这是 product-of-experts，不是贝叶斯后验

你写 s_final = s_diff + λ_B(t)·s_B。数学上，score 相加 = 密度相乘：

sθ + λ·sB = ∇log( pθ · pBλ )

这是 product-of-experts / energy-guidance 构造，不是 p(C_DAB | H&E, real-IHC-domain) 的后验采样。两个直接后果：

  1. 可能过度自信：两项各自都含 marginal 信息，相乘等于把共享信息算了两遍。
  2. 两个 score 的尺度不可比：直接相加会让「有效 λ」随 t 漂移。

⇒ 两个要求：① 组合前做尺度归一化（逐样本 RMS 匹配或方向归一化后再乘 ‖s_main‖）；② 论文里用 energy-guided / product-of-experts 的措辞 —— MIU-Diff 用的就是「energy-guided」，这是正确的词汇。

λ_B(t) 的调度：spec 里没写，必须定

你的图里写的是 λ(t) Score Guidance，但没给形式。三条硬约束（来自库内 `MEMORY_梯度冲突.md`）：

  • 从 0 起扫，只在中/晚时间步开（高 t 段被噪声样本主导，B 的 score 在那里语义最弱）。
  • 先做 score 归一化，再定 λ；不要「先调 λ 再想办法」。MIU-Diff 用的形式是 λ_t = t/S（随 t 线性增长），这是一个可直接试的起点。
  • 上界写进配置：若 λ_B 加大后 FOD 直方图变好但 membrane DICE / ranking 变差 ⇒ 判为先验过强，回退，不要继续调参。

4.8 物理渲染

判定：成立。「V1 完全固定、不让网络学 renderer」是对的，保住了 concentration → physical RGB 的干净解释。

一处与库内既有结论的分歧，我说明理由

库内 `MEMORY.md` 记录的分工是：监督 target 侧固定队列级 M（否则浓度带每图自由度 ⇒ H-score 不可比）；渲染侧可学习 M + 色一致性锚定。

5H&E 侧矩阵列数若是 3 列，CEHE 退化成残差轴 ⇒ §4.4 与 §4.5 的输入语义失效固定 2 列 [s_H, s_E]，标定时加断言P1

一个可以现在就做的成本核算

上面第 1、3、4 条都是几十行代码量级的改动，但它们决定训练能不能收敛、输出有没有系统色偏、以及这篇工作有没有可主张的蛋白贡献。相比之下，「SD1.5-style U-Net vs 小 U-Net」的改动成本要大得多，收益却是负的（§3）。先把便宜的必填项补齐，再动架构。

7开工顺序（修正版）

你的 §25 顺序（Stain Separation → Structure Encoder → DAB Diffusion → +A → +B → +morphology 消融）大方向是对的，一次只加一个模块的纪律也对。我只在前面补一个 Stage 0，并加一条你可能没考虑的对照。

Stage 0  门禁（零训练，全部是几十行脚本）
   0.1  H&E 侧解混矩阵列数审计 —— 必须 2 列 [s_H, s_E]
   0.2  IHC 侧重建残差 ‖r‖/‖Y‖ —— 定阈值，判断 K=2 够不够
   0.3  R²(C_E ~ C_H, C_DAB)（库内遗留，半小时）
   0.4  C_DAB 归一化统计量 —— 逐通道 99 分位 / z-score，写进配置
   0.5  M 标定 + 无色轴断言（E0.3 已有脚本）
   ↓ 全过才动架构
Stage 1  最核心的一步：Stain Separation → Structure Encoder → DAB Diffusion
   变量 u = log(1+C_DAB)；v-prediction；条件 [u_t, C_H^cond, C_E]
   损失 = L_diff
   判据：DAB 非负、空间合理、无幻觉色、renderer 后 clamp 比例极低
   ★ 同时跑 PredS 式确定性 UNet 基线（同一套浓度域管线，只换生成器）
   ↓
Stage 2  + FOD 分布损失（全局均值 + 20-bin 直方图，挂 v̂，λ(t) ∝ √SNR(t)）
   判据：FOD 分布误差下降且结构指标不显著退化
   ↓
Stage 3  消融三件套：H-reuse vs H-gen vs H-zero/shuffle
   ↓
Stage 4  + A（只加 c_exp，可 dropout；记录与 FOD 的相关性）
   ↓
Stage 5  + morphology 消融（加 LP / 多尺度 encoder vs 不加）
   ↓
Stage 6  B：B0 prior audit → B1（T_H 校准后）→ B2（采样 guidance，λ 从 0 起扫）
   ↓
Stage 7  评测：五层（图像相似 / 语义一致 / 物理合规 / 临床效用 / 伪影），禁单一 PSNR
★ Stage 1 里加的那个 PredS 基线，是本报告最实用的一个建议

CFM-HES 的消融正是这个结构：PredS = 同一套 stain separation + 浓度域 + Beer–Lambert 管线，只把生成器换成确定性 U-Net 回归。它给出了 31.34 PSNR / 0.978 SSIM，而 CFM 是 32.06 / 0.968。

在你这里，这个基线的价值更大：

  • 它是证明「生成模型在你的任务上有必要」的唯一方式。如果你的扩散赢不了确定性回归，那么整条 diffusion 路线在你的数据上就没有依据 —— 这是必须知道的事实，而且要趁早知道。
  • 它的成本极低：同一个数据管线、同一个 Structure Encoder、同一套渲染，只把 U-Net 换成回归头。你几乎是在白送一个对照。
  • 它同时是最好的 debug 工具：如果 PredS 都跑不好，说明问题在分离/归一化/M 标定（Stage 0），不在扩散。
一句话纪律

你在 §25 说「尤其重要的是，我现在不建议你同时做 A+B+Morphology+H multi-scale」——这条我完全同意，而且上面这个顺序就是它的严格执行。唯一新增的是：在 Stage 1 就把 PredS 基线一起跑掉，因为它便宜、且它决定了后面所有工作的意义。

三条高置信度假设（可证伪）
  1. 高置信度：SD1.5-style U-Net 在全分辨率浓度空间上无法在 8 GB 显存训练。可证伪预测：跑一个 batch，OOM。若未 OOM，说明我高估了（那我建议你贴出实际配置，我会修正结论）。
  2. 高置信度：A 的 protein map 在只有标量监督时会退化成近似常数。可证伪预测：训练后 P_exp.std() ≈ 0。
  3. 中置信度：PredS 式确定性 UNet 在你的任务上会显著弱于扩散 —— 但这一点我并不确定，正因如此才要测。若 PredS 打平，你应当重新考虑是否真的需要扩散（并把这个负面结果诚实写出来）。
