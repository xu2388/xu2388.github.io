★ 本轮最重要的单条发现：你的 B 模块 = MIU-Diff Stage 1，而且它的消融给出了对你不利的读数

MIU-Diff（Liu, Wang, Cai, Li，Score-based Diffusion Model for Unpaired Virtual Histology Staining，arXiv:2506.23184，CMMCA 2025，DOI 10.1007/978-3-032-06624-4_4）做的是同一件事，自述为「the first study for unpaired virtual histology staining via energy-guided diffusion modelling」，而且用的就是 BCI 与 MIST。

它的 Stage 1 原文逐字：「it first learns the IHC marginal distribution q(y0) and then the conditional distribution q(y0|x0)」「the IHC distribution q(y0) is pretrained with an unconditional score-based diffusion model based on IHC images alone」。这就是你的 B。它的采样期组合逐字为：

M(y, x, t) = λt·U(y, x, t) + (1 − λt)·I(y, x, t),   λt = t/S

更关键的是它的消融（Table 1）。把 U-guided（只留 marginal 项，即「只有 B 在起作用」） 单独拿出来看，在 MISTHER2 上：

4.2 E 通道与 morphology encoder

判定：成立但要收窄。E 作 morphology evidence 是合理的（它承载胞质、基质、胶原、腺体边界），但有两个必须先修的地方。

★ 盲区 1（你没列，但会直接让 CE 失去意义）：H&E 侧分解用几列？

库内 `E0.2_伊红复染判定_结论.md` 已用你自己的实测数据证明一件事：在 3×3 解混 C = pinv(M) @ od 中，第 2 通道（「E 通道」）恒等于正交补残差通道，与伊红无关 —— 实测 w2 ∥ (s_H × s_DAB)，夹角 8.5e-7 度；C_E / C_res = −1.5918 是纯常数。

那条结论是在 IHC 侧（矩阵 = [H, E, DAB]）得到的。现在你要把 CEHE 送进 morphology encoder —— 那么 H&E 侧用的是什么矩阵？

  • 用 2 列 [sH, sE]：超定（3 方程 2 未知），最小二乘解唯一，CH 与 CE 都真实。✅ 这是正确做法。
  • 用 3 列（例如 [H, E, 某个第三方向]）：第 2 通道立刻退化成正交补残差 —— 它就不再是伊红，而是一条没有物理意义的轴。此时「E 承载胞质/基质」这个论断在数学上就不成立，morphology encoder 学到的是一个任意的残差方向。

动作：在写任何代码之前，先确认 H&E 侧解混矩阵的列数与列序，并把「H&E 侧固定用 2 列 H/E」写成硬约束。这一条不确认，§4.2 其余讨论都建立在流沙上。

「低频 = 形态」是一个没有文献背书的语义承诺

你写的是 I_struct = [C_H, C_E, LP(C_H), LP(C_E)]，隐含「低频携带 morphology」。但：

  • 核边界、细胞膜、胞质边缘 包含大量高频成分 —— 而 HER2 恰恰是膜染色，膜形态的主要承载者之一是伊红（库内 `MEMORY_StainFuser审查.md` 已记录）。把形态等同于低频，对膜染色任务方向是反的。

第三条路径的信息重叠问题

你的图里有三条进入主 U-Net 的路径：raw [C_H, C_E] 拼接、f_morph 多尺度注入、以及 c_exp。其中 raw concat 与 f_morph 是同源信息的两种带宽（f_morph 的输入就是 C_H/C_E 及其低通）。两条通道同时存在会让「收益归因」不可能 —— 消融时你无法判断是 E 有用还是 encoder 有用。v1 只留一条（raw concat），f_morph 作为 v2 的独立消融。

B 的 P0：训练条件是 CHIHC，推理条件是 CHHE

B 在真实 IHC 上训练，形式是 sB(CDABt | CHIHC, t)；但推理时你手上只有 CHHE。于是

ptrain(CH) = p(CHIHC)  ≠  ptest(CH) = p(CHHE)

MHE ≠ MIHC、白点不同、染色强度尺度不同 ⇒ B 可能把苏木素域偏移误判成「DAB 不真实」。这解释了为什么 B0（无条件）应当先做：它是唯一没有这个问题的版本。

B2 的 score 归一化：不要直接把两个 score 相加再调 λ
# 错误做法：两个 score 直接相加，靠经验调一个绝对 λ
s_final = s_main + λ_B * s_B

# 正确做法：先归一化尺度，再乘权重
g_main = s_main / (||s_main|| + eps)
g_B    = s_B    / (||s_B||    + eps)
s_final = s_main + λ_B(t) * g_B * ||s_main||     # 或等价地做逐样本 RMS 匹配
# λ_B(t) 从 0 起扫，先只在中/晚时间步开

理由：两个 score 网络的输出尺度不可比，直接相加会让「有效 λ」随 t 漂移，且高 t 段被噪声样本主导（库内 `MEMORY_梯度冲突.md` 的幅度劫持结论）。

B 的正确定位（写进论文的一句话）

B 提供的是目标域染色风格先验，不是实例级阳性位置。它可以在中/晚时间步、以小权重把生成结果拉回真实 IHC 的浓度分布内，但不能决定某张 H&E 的哪一块一定是 HER2 阳性。这句话与 MIU-Diff 的 U/I 分解、以及可辨识性结论（Xie et al. ICLR 2023）完全一致。

6模型选型建议

本节的每一条建议都标出证据来源。凡是没有受控实验、消融数据或我本人实测支撑的，一律写「未找到证据」，不写成「推荐」。

6.1 backbone

结论：from-scratch 的小型 conditional 2D U-Net。不要 U-ViT / DiT / FMoE

证据：本轮逐篇核实了虚拟染色方向的扩散工作，凡是写明 backbone 的全部是 2D U-Net（常在 LDM 里）：StainDiffuser 原文「two UNet diffusion networks」；HistDiST 微调 SD1.5，UNet + self/cross-attention；DiffVS 是 Marigold 式潜扩散 + SD UNet（官方仓库 unet/ 目录）；Star-Diff 摘要未点名，非官方复现用轻量 U-Net。MIU-Diff、PST-Diff、SGCD 的摘要均未说明 backbone（不要替它们推断）。

没有任何一篇虚拟染色论文为 U-ViT/DiT 提供论证 —— U-Net 是惯例而非消融结论。这一点要诚实标注：「U-Net 更好」在本领域没有受控证据，但「U-Net 是惯例、踩坑最少、复现最容易」是有证据的，且与你的优先级（可复现 > 复杂度）一致。

规模建议（仅作数量级参考，你的数据会不同）：base channels 64–96；channel multipliers [1,2,4,4]；每级 2 个 residual block；attention 只在 24×24 / 12×12 或更低分辨率。依据：Min-SNR（arXiv:2303.09556）证明「用更小的架构」也能在 ImageNet 256×256 拿到当时最好的 FID 2.06；Star-Diff 的非官方复现在 512×512 上用的是 dim=64 量级的 U-Net。

反面选项：FeatStainDiff 的 U-ViT + FMoE（4 个 DCT/MHSA 专家）—— 你的库内审查已定：可借 time-routing 的抽象（先做标量 g_struct(t)/g_expr(t)），不要直接堆 4 专家。FMoE 的专家 collapse 与频率轴解释问题在你这没有对应的收益。

6.2 预测参数化

结论：v-prediction。这一条有最硬的受控证据
来源原文结论（逐字或紧贴原意）对你的含义
Salimans & Ho, Progressive Distillation for Fast Sampling, arXiv:2202.00512, ICLR 2022完整消融（CIFAR-10）：「Both predicting x directly, as well as predicting v, or the combination (ε, x), could thus be recommended... 额外的第二条理由（来自你自己的库）：`MEMORY_梯度冲突.md` 的逐变量 Jacobian 表显示，辅助损失挂 x̂₀ 时额外因子是 −SNR(t)^(−1/2)，t→T 发散；挂 v̂ 时是 −σ_t，有界 [−1,0]，作者称其为「v-prediction 的第二个硬收益」。⇒ 如果你要用 v1 同时补上 FOD 蛋白损失（§4.3 路线 β），v-prediction 是让那个损失不炸的前提。

StainDiffuser 用的是朴素的 ε-prediction（‖ε − fθ(·)‖²）且未做任何讨论 —— 那是弱点，不是依据。ε 只有在配了正确的时间步加权（Min-SNR 式）时才等价安全。

6.3 条件注入机制

结论：v1 用「输入拼接」；v2 再加一条低带宽的语义通道。不要上 ControlNet 侧支路

已核实的做法：HistDiST 是双通道 —— Phikon 特征走 cross-attention，VAE 编码的 H&E 在 U-Net 输入处与噪声潜码拼接（原文说明「inspired by InstructPix2Pix」）；DiffVS 用拼接；StainDiffuser 用 H&E encoder 特征生成 attention 矩阵去调制扩散特征（特征级注入）。

6.4 输出变量与激活

结论：单通道 uDAB = log(1 + CDAB)，不要对浓度做硬 clamp
# 输出（单通道）
u_DAB = log(1 + C_DAB)        # 无约束实值，动态范围被压缩
C_DAB = exp(u_DAB) - 1        # 天然非负，且不经过 ReLU/clamp

# 扩散的目标就是这个 u_DAB（不是 raw C_DAB）
# 网络预测 v（§6.2），由 v 与 u_t 恢复 û_0

为什么不用 softplus 或 clamp(min=0)：库内已两次记录同一类故障 —— StainQuant 编码器末端是 nn.ReLU()（负半轴梯度恒零），与你 `physics.py` 的 c.clamp(min=0) 是同一种病；修法是 softplus。而 log(1+·) 比 softplus 更好的一点是：它的逆变换是显式的、可精确往返，且与 B 模块的浓度空间口径一致。

口径纪律（重要）：主扩散、B 的 score、FOD 损失必须活在同一个变量空间。不能主扩散在 u 空间、B 在 raw concentration 空间直接相加 —— 这是库内 `MEMORY_梯度冲突.md` 反复强调的「损失与网络输出必须活在同一空间」。

f_morph = E_morph( [C_H^cond, C_E^cond, grad(C_H), grad(C_E)] )   # 多尺度，不是纯低通
U-Net 在 2–3 个尺度接收 f_morph
对照：v1（raw concat only） vs v2（+f_morph） vs v2-noE（去掉 C_E）

三个 arm 才能分开回答「收益来自 E 本身」还是「来自额外 encoder 容量」。

v3：最后加入 B，按 B0 → B1 → B2 三步
B0: 无条件 p(C_DAB)        —— 验证能否区分真实/伪造浓度的分布差异
B1: 条件 T_H(C_H^HE)        —— 确认训练/推理域一致
B2: 采样期 guidance         —— 只在 mid/late timestep、小权重、score-normalized
    s_final(t) = s_main(t) + λ_B(t) * normalize(s_B(t))
    λ_B 从 0 起扫 {0, 0.05, 0.1}；先做归一化再定 λ

若 B 只提高 FOD histogram，却降低 membrane DICE 或 regional ranking ⇒ 判为「先验过强」，回退 v2，不要继续调大 λ。

与既有报告的推荐有分歧的两处，我说明理由
  1. FOD 损失是否进 v1：既有报告建议 v1 只有 L_diff。我建议进 v1 —— 理由见上（novelty 落点）。若你更看重「先跑通」，那就接受 v1 是里程碑而非论文，这也是合理选择，但要在计划里写明。
  2. H 复用是否保留：既有报告把「H 直接复用」判为成立，我把它降为「有条件成立」。理由是新证据：DeReStainer 的原文只做特征级对齐、并不拷贝像素，而你要拷贝像素 —— 这跨过了文献没有跨的一步，必须用 H-reuse vs H-gen 对照来自己证明。

观察结论行动

A（若保留）zero 后输出完全失效主模型在抄 pseudo-label shortcut撤销 A，或把 dropout 率提高到 0.5 以上并降低其注入带宽
3 seeds 中某一 seed 出现黑团 / 全棕按最差 seed 止损不要用最好 seed 宣称成功；先按库内黑团诊断流程定位（训练侧精度 vs 采样侧潜码）
renderer 后 clamp 比例很高扩散生成的浓度经常落到物理不可达区检查 log(1+·) 参数化是否被绕过；检查 M 的非负约束；检查 C 的归一化是否训练/推理一致

建议的定位（一句话）

不要写「我们提出了一个浓度域的扩散虚拟染色框架」——这句话在 2026 年 10 月已经被占满。建议改成：

「我们量化了 H&E 与 IHC 之间苏木素通道的块级共享（Corr128=0.407）与像素级不共享（0.061），据此设计了一个跨染色矩阵的通道复用与校准方案；并在此基础上，把蛋白表达约束第一次以可微的分布级损失形式接进浓度域扩散的生成过程。」

这样：① 前半句是你独有的实测资产；② 后半句落在唯一仍空的那一格；③ 浓度域扩散与 BL 渲染退居「实现手段」，不再承担 novelty 压力 —— 这反而更安全，因为审稿人无法用 CFM-HES 或 MIU-Diff 直接否掉它。

一个必须提前想清楚的审稿问题

如果审稿人问：「CFM-HES 已经在浓度域做生成、MIU-Diff 已经用 marginal score 做引导、DeReStainer 已经复用共享 H 通道 —— 你的新意是什么？」

上面的定位可以直接回答。但如果 v1 是「没有蛋白损失」的版本，这个问题就答不上来。这就是 §7 里我建议把 FOD 分布损失提前进 v1 的根本原因。
