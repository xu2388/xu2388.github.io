⚠ 落地前必须确认的三件事
  • FastCUT 开关：PSPStain 用 FastCUT ⇒ nce_idt=False、lambda_NCE=10.0、flip_equivariance=True。这意味着生成器只背 1 项 NCE（不是 2 项、也不是 3 项），E0 冲突只在这 1 项 NCE 与 GAN 之间。
  • 下采样段是 2 次 stride‑2 卷积：原 CUT ResnetGenerator 用 Conv(k=3,s=2,p=1) 做 2 级降采样；小波下采样要替换的就是这 2 处，不是 MSCW 那种「池化 + WTConv(stride=1)」。
  • 上采样段是 Upsample(nearest) + Conv：DySample 替换的是 Upsample(nearest) 那一步（空间放大），后面的 1×1/3×3 Conv 通道减半保持不变。

2改动② DySample 接入（最强，填空格）

为什么是这条

你库里已核实：CARAFE / FADE / SAPA / DySample 这类可学习上采样，无一篇进入 GAN 生成器。CUT 系上采样至今是 nn.Upsample(nearest)。把 DySample 接进 ResnetGenerator 的上采样段，是谱系链上第一个动「采样方式」的工作——这是真实的新颖性，不需要你发明算子。

2.1 接入点（替换 Upsample(nearest)）

CUT 标准上采样段（ResnetGenerator.__init__ 内）原写法：

# 原 CUT 上采样段（2 级）
for i in range(n_downsampling):
    mult = 2 ** (n_downsampling - i)
    model += [nn.Upsample(scale_factor=2, mode='nearest'),
              nn.Conv2d(ngf * mult, int(ngf * mult / 2),
                        kernel_size=3, stride=1, padding=1, bias=use_bias),
              norm_layer(int(ngf * mult / 2)),
              nn.ReLU(True)]

改为（DySample 只做空间放大、通道数不变；后面 Conv 仍把通道减半）：

# 改后：DySample 做可学习上采样（保持通道数 = ngf*mult），Conv 照旧减半
from models.ops_resample import DySample
for i in range(n_downsampling):
    mult = 2 ** (n_downsampling - i)
    model += [DySample(in_channels=ngf * mult, scale=2, style='pix', groups=4),
              nn.Conv2d(ngf * mult, int(ngf * mult / 2),
                        kernel_size=3, stride=1, padding=1, bias=use_bias),
              norm_layer(int(ngf * mult / 2)),
              nn.ReLU(True)]
★ 关键修正：DySample 不带频域保证

DySample 是可学习采样位置，不是抗混叠算子。直接「替换」nearest 可能引入新混叠。正确定位是 「固定抗混叠打底 + 可学习采样补偿」：在 DySample 之前保留一次轻量抗混叠（见 §3 的 V4 BlurPool 思路，或直接在 DySample 输出后接一个 3×3 低通），把 DySample 当「在抗混叠基底上做补偿的残差」，而不是裸替换。

2.2 DySample 本体（用官方文件，勿手写）

DySample 来自 Wang et al., 《Learning Dynamic Sampling Position for Semantic Segmentation》(ICCV 2023)，仓库 github.com/tiny-smart/dysample（Apache‑2.0）。请把官方 dysample.py 原样放进 models/，本蓝图只负责接入与通道处理，不重复实现其内部 grid_sample。选型建议：

style='pix'（推荐）

带 scope 幅度调制，比 cnt 更稳；groups=4 足够，groups 过大会涨参。

scale=2

与原 nearest 的 2× 对齐，不破坏 ResNet 的 6‑block 中间分辨率。

离线兜底（仅当无法拉官方仓库时）

若环境离线，可用下面的轻量「采样补偿」占位实现先跑通管线（效果弱于官方 DySample，仅用于验证架构接线）：

import torch, torch.nn as nn, torch.nn.functional as F
class DySampleLite(nn.Module):
    """轻量可学习上采样：content-aware offset 残差 + 双线性重采样。
       非官方 DySample 等价物，仅作离线接线兜底。"""
    def __init__(self, in_ch, scale=2, groups=4):
        super().__init__()
        self.scale = scale
        self.offset = nn.Conv2d(in_ch, 2 * groups * scale * scale, 3, 1, 1, bias=False)
        self.groups = groups
    def forward(self, x):
        B, C, H, W = x.shape
        off = self.offset(x).tanh() * (self.scale / 2)   # [-s/2, s/2]
        off = off.view(B * self.groups, 2, self.scale * self.scale, H, W)
        grid = F.affine_grid(torch.eye(2,3).to(x)[None].repeat(B,1,1),
                             (B, C, H*self.scale, W*self.scale))
        # 把 offset 累加到 base grid 上（简化，逐组循环更稳）
        out = F.grid_sample(x, grid + off.mean(1).permute(0,2,3,1),
                            align_corners=False, mode='bilinear')
        return out

3改动① 小波下采样 4 档（拆误读）

原方案「小波卷积换下采样」的误读在于：MSCW 里 WTConv 不是下采样算子（池化负责降分辨率，WTConv 在已降分辨率上 stride=1 做卷积）。正确做法是把「抗混叠」和「小波特征」拆开，给出 4 档，全部落在生成器的 2 级 stride=2 下采样处。

档做法改动量风险何时选
V1硬 Haar LL 下采样（去混叠，无学习）极小最低；但低频-only 可能丢纹理作为所有档的打底先做对照
V2DWT 四子带 + 1×1 可学习融合（WTConv 思路）小中；通道 4× 后需 1×1 压回想要显式频带分离时
V3stride‑conv 保留 + 小波一致性正则（loss 侧）小低；不改结构最保守，先做
V4抗混叠 BlurPool 打底（固定低通 + stride）极小最低必选：DySample 的配套抗混叠

3.1 V1 / V4 的自包含实现（可直接用）

import torch, torch.nn as nn, torch.nn.functional as F

class HaarDownsampleLL(nn.Module):
    """2x 下采样，仅取 Haar 低频 LL 带（抗混叠、无学习）。
       保持通道数不变，空间 H,W 减半。"""
    def __init__(self):
        super().__init__()
        ll = torch.tensor([[1.,1.],[1.,1.]]) / 2.0
        self.register_buffer('k', ll.unsqueeze(0).unsqueeze(0))
    def forward(self, x):
        if x.shape[-2] % 2: x = F.pad(x, (0,0,0,1))
        if x.shape[-1] % 2: x = F.pad(x, (0,1))
        w = self.k.repeat(x.shape[1], 1, 1, 1)
        return F.conv2d(x, w, stride=2, groups=x.shape[1])

class BlurPool(nn.Module):
    """抗混叠下采样：固定 3x3 低通（[1,2,1]^2/16）+ stride=2。
       放在 DySample 之前当抗混叠打底，或替换原 stride=2 卷积。"""
    def __init__(self, channels):
        super().__init__()
        k = torch.tensor([[1.,2.,1.],[2.,4.,2.],[1.,2.,1.]]) / 16.0
        self.register_buffer('k', k.unsqueeze(0).unsqueeze(0).repeat(channels,1,1,1))
    def forward(self, x):
        return F.conv2d(x, self.k, stride=2, padding=1, groups=x.shape[1])

接线约定

无论 V1/V2/V4，下采样段都要保持「空间 /2、通道 ×2」的 ResNet 约定，否则 6 个 ResBlock 的中间分辨率与后续上采样对不上。V3 不动结构，只在 backward_G 里加一个「原图小波子带 vs 生成图小波子带」的 L1 正则。

4改动③ 梯度冲突：先跑 E0 实测

《审查》判定「门控解梯度冲突」是机制不匹配：门控作用在特征路径，而 GAN loss 与 NCE loss 的冲突发生在同一组生成器参数的梯度空间——CUT 是两者先相加再一次性 backward()，门控根本碰不到两条梯度。所以正确第一步不是写门控，而是量出冲突到底存不存在、有多大。

4.1 E0：只在 backward_G 加梯度钩子，不改任何结构

# 在 CUTModel.backward_G 中，原 loss_G.backward() 之前插入量测
def measure_grad_conflict(self):
    params = [p for p in self.netG.parameters() if p.requires_grad]
    # --- 单独求 GAN 对 G 的梯度 ---
    self.optimizer_G.zero_grad(set_to_none=True)
    self.loss_G_GAN.backward(retain_graph=True)
    g_gan = [p.grad.detach().clone() for p in params]
    # --- 单独求 NCE 对 G 的梯度（FastCUT 仅 1 项 NCE）---
    self.optimizer_G.zero_grad(set_to_none=True)
    self.loss_NCE.backward(retain_graph=True)
    g_nce = [p.grad.detach().clone() for p in params]
    self.optimizer_G.zero_grad(set_to_none=True)

    dot   = sum((a*b).sum() for a,b in zip(g_gan, g_nce))
    n_gan = torch.sqrt(sum((g*g).sum() for g in g_gan))
    n_nce = torch.sqrt(sum((g*g).sum() for g in g_nce))
    cos   = dot / (n_gan * n_nce + 1e-8)
    # 冲突判据（来自 MEMORY_梯度冲突）：g = g_gan+g_nce，
    #   若  gᵀg < -‖g_gan - g_nce‖²   则两梯度方向性冲突
    g_sum = [a+b for a,b in zip(g_gan, g_nce)]
    g_norm2 = sum((g*g).sum() for g in g_sum)
    g_diff2 = sum(((a-b)**2).sum() for a,b in zip(g_gan, g_nce))
    conflict = float(g_norm2) < -float(g_diff2)
    # λ_crit：NCE 应占的相对权重上界
    lam_crit = float(n_nce**2 / (n_nce**2 + n_gan**2 + 1e-8))
    return dict(cos=float(cos), conflict=conflict, lam_crit=lam_crit)

# 训练循环里每 K 步记录一次（不影响反向，纯观测）
if self.opt.log_grad_conflict and (self.step % 200 == 0):
    m = self.measure_grad_conflict()
    self.logger.write(f"step {self.step} cos={m['cos']:.3f} "
                      f"conflict={m['conflict']} lam_crit={m['lam_crit']:.3f}")
E0 判读
  • cos ≈ 0 或 > 0（无冲突）：第 ③ 条整条不必要，门控 / 调度都不用写，直接删掉这条方案。
  • cos < 0 且 conflict=True（方向性冲突）：再上 §5 的 λ 调度或 PCGrad；仍然不是门控。
  • 跑 3 个 seed，记录 cos / lam_crit 的分布，作为论文「为何需要 / 不需要梯度协调」的实证。

5冲突存在时的正确工具（替代门控）

若 E0 确认冲突，用以下二者之一，都作用在参数空间的梯度上，而非特征路径。

5.1 λ 调度（最小改动，推荐首选）

把「固定 lambda_NCE=10.0」改成随训练动态、且受 lam_crit 约束的系数：

# 用 cosine 相似度把 NCE 权重往「不压制 GAN」方向调
def dynamic_lam(self, cos, lam_crit, base=10.0):
    # cos<0（冲突）时下调 NCE 权重，且不超过 lam_crit 给出的上界
    if cos < 0:
        factor = 1.0 + cos            # cos∈[-1,0] -> factor∈[0,1]
        lam = base * max(factor, 0.1) * min(lam_crit, 1.0)
    else:
        lam = base * min(lam_crit, 1.0)
    return lam
# backward_G 里：
# self.loss_G = self.loss_G_GAN + self.dynamic_lam(cos, lam_crit) * self.loss_NCE

5.2 PCGrad（冲突投影，改动稍大）

def pcgrad(g_a, g_b):
    """把 g_b 投影到 g_a 正交补，消除对 g_a 的负面分量。"""
    dot = sum((a*b).sum() for a,b in zip(g_a, g_b))
    na2 = sum((a*a).sum() for a in g_a) + 1e-8
    if dot < 0:
        return [b - dot / na2 * a for a, b in zip(g_a, g_b)]
    return g_b
# 用法：先分别求 g_gan / g_nce（见 §4.1），g_nce' = pcgrad(g_gan, g_nce)，
# 再手动把 g_gan + g_nce' 写回参数 .grad 并 step。需关掉原自动 backward。
⛔ 不要做的事

不要在生成器中间特征上套一个「门控向量」去「改善对抗 / NCE 冲突」——审稿人一句「门控如何改变两个损失在同一组参数上的梯度方向」就会让这条塌掉。冲突是参数空间的，工具必须是 §4/§5 这类梯度层操作。

6改动④ 3 通道 OD 域（DAB 污染修正）

原方案「2 通道 H 生成再反推 RGB」的顾虑是错的：CUT 的 input_nc/output_nc 完全独立，2 通道输入直接能跑，不需要反推。但库里查过的真问题在别处——IHC 复染弱 10×、DAB 饱和区污染苏木素约 65%。所以正确方向不是压成 2 通道，而是在 3 通道 OD（光学密度）域做生成，并加苏木素保护。

6.1 Beer–Lambert 边界（RGB ⇄ OD）

import torch, torch.nn.functional as F
def rgb_to_od(x):                 # x in [0,1]
    eps = 1e-6
    return -torch.log10(torch.clamp(x, eps, 1.0))
def od_to_rgb(od):
    return torch.clamp(10 ** (-od), 0.0, 1.0)

6.2 接入方式（不改生成器 I/O 维度）

方案 A（推荐，最小侵入）：生成器仍在 RGB 空间，但加一个 苏木素通道保护损失——把目标 IHC 与生成 IHC 各自做 RGB→OD，取 OD 的第 0 轴（苏木素）算 L1；同时约束 DAB 通道（第 1 轴）只在阳性区域激活。不改 input_nc/output_nc。

方案 B（彻底）：把生成器整体搬到 OD 域——在 forward 入口 fake_B_od = netG(rgb_to_od(real_A))，出口 fake_B = od_to_rgb(fake_B_od)。此时输出仍是 3 通道 RGB 喂给判别器，但生成器内部在浓度域运算，天然规避 DAB 饱和非线性。

# 苏木素保护损失（方案 A 的核心新增）
def hematoxylin_protection(self, fake_rgb, real_rgb):
    fo, ro = rgb_to_od(fake_rgb), rgb_to_od(real_rgb)   # B,3,H,W
    loss_H = F.l1_loss(fo[:, 0], ro[:, 0])              # 苏木素轴一致性
    # DAB 只在阳性区活跃：惩罚 fake 在全图的 DAB 扩散
    loss_DAB_sparse = fo[:, 1].abs().mean()
    return loss_H + 0.5 * loss_DAB_sparse
为什么不是「2 通道 H」

压成 2 通道会让生成器丢掉 DAB 与残差背景的耦合信息，而真问题（DAB 饱和污染苏木素）恰恰需要显式分离并保护苏木素轴——OD 域的逐轴约束比压通道更对症，且不牺牲信息量。

7改动⑤ 模块仓库（止步）

《审查》判定第 ⑤ 条收益递减：你本地的 plug-nplay-modules 合集被镜像 ≥10 次，且 「医学来源」∩「频域」= ∅——20 个标称医学来源的模块里含 FFT/DWT/DCT 的为 0。继续泛搜只会重复已知项。

收口规则

停止泛搜；只按本蓝图的落点定向补齐：下采样（§3 已覆盖）、上采样（§2 DySample）、梯度协调（§4/§5）。若后续要补频域算子，唯一真 2D‑FFT 模块是库里的 DynamicFilter，其余 WTConv×2 为拷贝、小波下采样.py 已映射到 §3 V1/V2。

10风险、回滚与落地检查

⚠ 主要风险

1. DySample 裸替换引入新混叠 → 用 V4 打底兜底。

2. 下采样改错分辨率 → 6 block 中间尺寸对不上，必崩；改完先单 batch forward 验尺寸。

3. E0 钩子 retain_graph 占显存 → 量完立即 zero_grad，仅观测不 step。

4. OD 域数值：RGB→OD 的 log 在 0 处爆炸 → 已加 clamp(eps,1)。

↩ 回滚策略

所有改动走 --up_mode / --down_mode / --od_domain 开关，默认 = 原 CUT 行为；出问题一键回退到 M0。

DySample / 小波模块独立成 models/ops_resample.py，不污染 networks.py 主干。

10.1 落地检查清单（逐项打勾）

  • □ 确认 checkout 的 ResnetGenerator 下采样段是 2× stride=2 Conv、上采样段是 Upsample(nearest)+Conv
  • □ 确认 FastCUT 开关：nce_idt=False，仅 1 项 NCE
  • □ models/ops_resample.py 写好 DySample（官方）/ HaarDownsampleLL / BlurPool，单测 forward 尺寸
  • □ options/train_options.py 加 --up_mode --down_mode --od_domain --log_grad_conflict
  • □ 先跑 E0（仅日志），3 seed，出 cos / conflict / lam_crit 图
  • □ 冲突=False → 删第③条；冲突=True → 上 §5 λ 调度（首选）或 PCGrad
  • □ 跑 E1：DySample + V4 打底，与 M0 同步比 FID/PSNR/棋盘格
  • □ （可选）E2b：OD 域 + 苏木素保护
  • □ novelty 句落定：「四代谱系首次改重采样路径」
