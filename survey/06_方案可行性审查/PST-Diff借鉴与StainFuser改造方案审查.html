PST-Diff 借鉴与 StainFuser 改造路线
—— 从 Fourier CFG 到浓度/通道引导

对象：IEEE TMI 2024 的 PST-Diff 与当前「冻结 HHE U-Net + 冻结原始 ControlNet + 23.1K condition-LoRA + 冻结 VAE」模型。重点不是复述论文，而是判断：哪些机制能迁移、哪些前提不成立、当前模型应该先改哪里。

0先说结论

一句话判定

PST-Diff 值得借，但不要照着它把当前模型改成「双扩散模型 + LT + Fourier CFG」。真正值得迁移的是一个更窄的原则：源结构与目标染色不应在所有去噪时间步、所有条件通道上以同样强度注入。在你的模型里，这个原则最适合落成：

早期/高噪声：保持 H&E 结构条件为主；后期/低噪声：逐步放大 marker-expression 条件。

第一版不改 VAE、不改 SD2.1 RGB latent、不加第二套 U-Net；只做条件内容清理 + timestep gate + 零初始化 marker token。浓度域的 C_H/C_DAB 分阶段引导放到第二阶段，等当前 RGB-latent baseline 先通过泄漏门禁。

模块对 PST-Diff 的准确理解迁移到当前模型的判定改动成本可复现性
AAM源域→latent 用 local attention；latent→目标用 global attention。它是两个方向/两套扩散网络的非对称注意力，不只是「H&E 权重大、IHC 权重小」成立但要收窄：借「结构路径/表达路径不对称」，不要加双 U-Net。当前 ControlNet + cross-attention 已有粗粒度的两路径雏形低–中高
LT把 HE latent 映射到 IHC latent；用 patch-wise paired latent L2 训练 F(x_A^l)≈x_B^l有条件成立：非配对/弱配对下不能照搬 latent L2；当前单 U-Net 也没有两个独立域 latent 可直接迁移中–高中–低
CFG采样期间对去噪图的 Fourier 低/高频分量做分阶段投影：t=700–400 低频，t=400–0 高频边缘最值得借：换成 semantic/channel-time gate；但浓度通道不是 Fourier 频率，不能把 C_H 直接称为「高频」低（门控）/高（生成空间）高（门控）
当前模型必须先守住的红线

当前推理调用仍把 tgt_latents 同时送入 ControlNet 的 encoder_hidden_states 与 U-Net。若它来自真实配对 IHC，那么模型可能直接读取目标外观甚至空间信息。在这个 T1/T2/T3 泄漏门禁通过前，任何 PST 风格 CFG 改善都不能解释为「结构/表达机制有效」。

1PST-Diff 到底做了什么

1.1 真实数据与配对假设：它不是严格非配对先例

论文题目与任务确实直接对应 H&E→IHC。PST-Diff 使用两个独立训练的扩散模型，通过 DDIB / probability-flow ODE 把源域映射到噪声 latent，再从噪声 latent 反向生成目标域。它的实验包含：

  • BCI：3,896 对训练、120 对测试；作者把它描述为同一肿瘤样本的连续切片，一张 HE、一张 HER2-IHC。
  • ACROBAT：100 位患者、200 张 WSI，用于跨数据集泛化；包含 HE 与 ER/PGR/HER2/KI67 等多 marker。
  • LT 训练：论文明确写的是用 patch-wise paired HE/IHC latent 训练 LT，200,000 steps，batch size 8，256×256 patch。
对你最重要的边界

论文说「不需要严格结构化配对数据」，更准确的意思是：它不要求 pixel-perfect registration，但它仍然使用了patch-wise paired 的 latent 监督。这不能直接证明它在你的真实 non-paired / weak-paired 设定下成立。尤其 LT 的 ||F(z_HE)-z_IHC||²，在没有实例对应时是不可辨识的。

1.2 三个模块的真实位置

阶段PST-Diff 的操作它解决的问题不是它解决的问题
源域编码HE diffusion 的 forward / reverse，源侧使用 priority local attention尽量把局部病理结构写入 source implicit latent不等于显式分离 H/E/DAB；也不保证实例级 IHC 表达可辨识
跨域 latentLT：z_HE → F(z_HE) → z_IHC-like缓解直接把两个域 latent 当成同一坐标系的偏置没有 paired latent 监督时不能靠 L2 自己发现正确对应

采样 CFG对每步 denoised image 的 Fourier 分量做 source-image 条件投影补回多步采样中丢失的源结构它不是训练 loss；不能替代真实表达约束

3三个模块逐项判定

3.1 AAM：原则可搬，但不要加「双模型」

判定：成立但要收窄

PST 的 AAM 真正利用的是「源域编码需要局部、精确；目标域生成需要全局、灵活」这一不对称性。当前模型恰好已有两个不同槽位：ControlNet = H&E 结构，cross-attention = target/marker 表达。因此你不需要再堆一层 AAM；需要把这两个槽位的语义清掉，再给它们不同的 timestep 权重。

  • 源结构侧：保留 H&E condition 的局部卷积与多尺度 residual；不要让它被目标 token 覆盖。
  • 表达侧：把 tgt_latents 换成可学习 HER2 marker token；token 只表达「我要生成 HER2/DAB」，不携带某张 IHC 的空间布局。
  • 不建议：复制 PST 的两套 local/global U-Net。你的当前 ControlNet 主干已经能保住结构，新增完整模型只会扩大显存、训练与归因成本。

3.2 LT：不能照搬 latent L2

判定：有条件成立；当前阶段不应实现为 PST-LT

PST-LT 的监督是 F(z_HE)≈z_IHC。在你的 non-paired / weak-paired 场景中，任意 HE latent 都可能对应多个合理 IHC 表达，直接 latent L2 会把「跨样本差异」误当成模型误差。它会把模型拉向数据集平均 latent，而不是学到 marker-specific biology。

如果以后真的需要 latent adapter，正确的收窄版本是：

  1. 输入只使用 H&E structure latent/feature 与 marker token，绝不输入配对 IHC latent。
  2. 训练目标改为分布级与语义级约束：固定队列级 stain matrix 下的 DAB/FOD 均值、20-bin 直方图、组织区域 ranking；而不是实例 latent L2。
  3. adapter 零初始化，且记录 adapter 输出 RMS；其幅度不能无界地抢走 noise MSE。
  4. 只有当 Stage 1 证明「去掉 target latent 后仍能保持结构并产生合理表达」，才进入 adapter 消融。

3.3 CFG：最值得借，但「通道 ≠ 频率」

判定：成立；推荐先做「timestep-conditioned semantic guidance」，不要先做 Fourier

PST-CFG 的可迁移抽象是：不同信息成分在 reverse process 的不同阶段注入。但 Fourier low/high 是数学上的空间频率；C_H、C_DAB 是染色/语义分量。一个 DAB 图同时包含低频的整体阳性比例、中频的腺体分布和高频的膜边界。所以「C_DAB = 中频」不成立。

你的直觉需要修正的地方可保留的工程含义
C_H = 高频结构它是 hematoxylin 语义通道，不是 Fourier 高频；核边缘通常高频，但组织布局也有低频成分早期优先保证 C_H / H&E morphology，后期仍保留非零结构底座
C_DAB = 中频表达DAB 同时有全局、区域与膜级尺度，且 H&E 中没有真实 C_DAB后期提高 marker-expression token 与 DAB 相关 loss 的权重；不能从 H&E 直接复制 DAB
背景/整体染色 = 低频大体正确，但受白点、scanner、stain matrix 影响用队列级 M 与全局 histogram/FOD 约束，不用逐图自由标定

4推荐的改造后模型

4.1 推荐路线 A：当前 RGB-latent 模型的最小 PST 借鉴

这是现在应该做的主线：改动小、可回退、归因清楚

保持 SD2.1 RGB latent、冻结 VAE、冻结主体 ControlNet/U-Net，只改「条件的语义」与「条件的时间调度」。这不是 PST-Diff 的复制，而是把 PST 的不对称原则映射到你已有的两条条件路径。

H&E RGB
  └─ fixed H/E deconvolution ─> h=C_H, e=C_E
       └─ keep 3-channel contract: [g_H(r)·h, g_H(r)·h, g_E(r)·e]
                                      │
                                      ▼
                         frozen ControlNet + condition-LoRA
                                      │
HER2 marker token ── zero-init projector ──> cross-attention K/V
                                      │
                                      ▼
                    frozen HHE U-Net ──> SD2.1 latent ── frozen VAE ──> RGB IHC

这里先保留当前的三通道接口 [C_H,C_H,C_E]，因为首层是硬编码 3 通道，且已有 LoRA/ControlNet 权重可复用。新增的第一步不是改成三通道生成空间，而是给这三个输入加一个固定语义分组的 gate：

r = timestep / T                    # r≈1: 早期高噪声，r≈0: 后期低噪声
cond_t = concat([
    g_struct(r) * C_H,
    g_struct(r) * C_H,
    g_expr(r)   * C_E,
], dim=1)

# cross-attention 不再吃 tgt_latents，而吃零初始化的 HER2 token
marker_t = g_expr(r) * marker_token
为什么先不把第三个 H 换成 C_res

C_res 是你生成浓度空间的推荐第三轴，但当前这里是预训练 ControlNet 的输入接口。立刻换内容会增加归因变量，而且 C_res 有符号，必须重新设计归一化。第一版先保持 [H,H,E] 的形状和数值契约；等 gate 实验通过，再做 [H,E,res] 作为独立消融，不能混在第一版里。

4.2 主线路线 B：浓度域的 PST-inspired 版本

如果 Stage 1 证明 RGB latent 的结构/表达解耦仍然不够，再进入你原本的浓度域主线：

H&E ── fixed M_HE ──> C_H, C_E ── structure condition
                                  │
HER2 token ───────────────────────┤
                                  ▼
     diffusion / flow matching directly predicts Z
     Z = [C_H, C_DAB, C_res]      # C_H/C_DAB nonnegative; C_res signed
                                  │
                  fixed/learnable M_IHC + Beer-Lambert
                                  ▼
                                RGB IHC

这里 PST-CFG 才能真正变成「通道投影」而不是把 RGB 傅里叶分量硬解释成染色成分：

  • 早期：对 C_H 与结构条件给高权重，保护核/组织布局；不是把 C_H 当作 Fourier 高频。
  • 中期：引入 HER2 marker token 与 DAB 的全局分布约束，先确定阳性量级。
  • 后期：提高 DAB 局部/区域 ranking 与膜边缘细节的权重；C_H 保持一个非零 floor，避免后期结构漂移。
  • 全程：用 BL 正演保证输出能回到 RGB；C_res 加向零收缩，不能 clamp 成非负。
这条路线的代价

它不是当前 LoRA 的小改动。当前 SD2.1 VAE 是冻结的 RGB latent 解码器；把输出改成浓度图意味着换生成空间/解码器，当前 23.1K LoRA 不能直接作为最终权重继续用。因此它是阶段 2，不是现在立刻做的 patch。

5时间步 × 通道引导设计

5.1 建议的第一版门控函数

不要复制 PST 的绝对步数 700–400。PST 使用 T=1000，而当前 StainFuser 的 scheduler、采样步数和 timestep index 可能不同。统一使用归一化时间 r=t/T，再做小范围消融。

# r=1 is early/noisy, r=0 is late/clean
# first-pass values are starting points, not claims of optimality
g_struct(r) = 0.35 + 0.65 * sigmoid((r - 0.55) / 0.10)
g_expr(r)   = 0.20 + 0.80 * sigmoid((0.45 - r) / 0.10)

# implication:
# early: g_struct≈1, g_expr≈0.2
# late:  g_struct≈0.35, g_expr≈1

为什么结构要有 floor=0.35：后期虽然应该增加表达细节，但 HER2 膜形态依赖 H&E 的伊红/胞质结构；把结构条件降到 0 会让后期 DAB 自由生成并可能漂移。为什么表达不从 0 开始：全局染色风格不必等到最后一刻才出现，否则 late-stage gate 可能只会把局部棕色硬贴上去。

5.2 在当前代码中最小的实现位置

位置改法优点风险
ControlNet 输入前对 [C_H,C_H,C_E] 做 [g_H·h,g_H·h,g_E·e]3 通道不变；已有 checkpoint 可载入；最小改动只能做输入级不对称，不能精确拆分多尺度 residual
marker token projector用 g_expr(t) 乘 token；projector 零初始化把目标表达与结构条件分开；推理不再需要 IHC reference必须先解决当前 tgt_latents 泄漏；需要训练 token/projector
ControlNet residual 分支拆成 structure residual / expression residual 后分别 gate最接近 PST 的不对称路径中高改动；需重新定义 residual 分解，不能只按 down-block 层名猜语义
sampling-time literal projection把 denoised output 做 C_H/Fourier projection，再回到 latent最像 PST-CFG当前 RGB VAE 往返昂贵且会引入 VAE 误差；x̂0 梯度在高噪声端有 SNR 风险

推荐顺序：输入前 gate → marker token gate → residual branch gate → 浓度域 literal projection。不要倒过来。

6.1 必须记录的量

  • 每个 timestep 的 g_struct、g_expr、ControlNet residual RMS、marker token RMS/grad norm。
  • 每个输出的 decoder clamp fraction、x0_pred_min/max、latent 每通道 1%/99% 分位。
  • 结构：nuclei/membrane segmentation DICE、H&E 与生成图的结构 SS/边缘一致性；不能只报 PSNR。
  • 表达：固定队列级 stain matrix 下的 DAB FOD 全局均值、20-bin histogram、区域 ranking、H-score/临床分级一致性。
  • 伪影：AQuA 或暗块/黑团检测器，黑团比例独立于 FID/PSNR 报告。

7不能从 PST-Diff 直接推出的结论

四个不能偷换的等号
  1. 「PST 的 Fourier CFG 有效」≠「C_H/C_DAB 是频率」。前者是空间频率投影，后者是染色语义分解；可以借调度原则，不能借名词。
  2. 「PST 用 LT」≠「非配对 latent L2 可行」。PST 的 LT 有 patch-wise paired HE/IHC 监督；你的 non-paired coupling 不可辨识。
  3. 「PST 保结构」≠「HER2 实例级表达正确」。PST 自己报告的是 SS、LC、VIF、Hist 与 IHC Profiler 0.72；没有医生盲评，也没有把 DAB spatial ranking / FOD distribution 与 H-score 作为训练约束。
  4. 「论文声称可泛化」≠「当前 23.1K LoRA 已经有效」。当前 LoRA 的五样本推理图尚未生成，不能用训练 loss 代替结果。

此外，本轮在作者公开 GitHub 主页上没有找到 PST-Diff 官方训练仓库或 checkpoint。作者后续的 StainExpert 有公开代码，采用 multi-expert、text+visual guidance、SD-Turbo 与参数高效训练，但它不是 PST-Diff 的复现代码，不能把它当作 PST 的实现补足。

最终建议

不要把 PST-Diff 当成「再加三个模块」的清单；把它当成一条时间轴设计原则。你当前最合理的改动是：移除/门禁 target latent → 用零初始化 HER2 token；保留 H&E ControlNet；在 [C_H,C_H,C_E] 输入前加结构/表达 timestep gate；先做四臂固定样本实验。只有这条路线证明「结构和表达都能独立改善」，才值得把同一原则下沉到 Z=[C_H,C_DAB,C_res] + Beer–Lambert 的生成空间。
