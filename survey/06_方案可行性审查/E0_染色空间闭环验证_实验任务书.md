## 2. E0.1 三通道闭环重建上限测试 ★ 最高优先级

### 目的

回答：**「IHC RGB → 浓度 → RGB」这个往返，理论残差能到多小？现在测到的 0.023 到底是不是"M 秩亏"造成的？**

### 为什么这个实验有决定性

这个往返在数学上是**恒等式**（推导见 §2.3）。所以如果残差不为 0，一定来自四个可定位的原因之一，**不是"方法本身有损"**。这个实验就是把四个原因分离开。


### 2.1 实现

**`e01_closed_loop.py`**：

```python
#!/usr/bin/env python3
"""E0.1 染色空间闭环重建上限测试。纯 CPU，无训练。"""
import os, json, glob, argparse
import numpy as np
from PIL import Image

# ---------------- 配置 ----------------
CLIP_EPS = 1e-3          # OD 计算的夹紧下限。物理上 OD>3 已不现实，故用 1e-3 而非 1e-6
I0_MODE  = "white"       # "white" → I0=[1,1,1]；"p99" → 逐图 99 分位
# -------------------------------------


def load_stain_matrix():
    """返回 (3,2)，列 = [s_H, s_DAB]。优先用用户自己的矩阵。"""
    try:
        import sys
        sys.path.insert(0, os.environ.get("HISTDIST_ROOT", ""))
        from hdadapt.physics import STAIN_MAT_FULL          # ← 按实际情况改 import 路径
        M = np.asarray(STAIN_MAT_FULL, dtype=np.float64)
        assert M.shape[0] == 3, f"STAIN_MAT_FULL 第一维应为 3，实际 {M.shape}"
        # 假设列顺序 [H, E, DAB] → 取 H 和 DAB
        M2 = M[:, [0, 2]] if M.shape[1] == 3 else M
        print(f"[info] 使用用户矩阵，形状 {M.shape} → 取列 [0,2] 得 {M2.shape}")
        return M2, {"source": "user", "full_shape": list(M.shape)}
    except Exception as e:
        print(f"[warn] 无法 import 用户矩阵（{type(e).__name__}: {e}），回退 Ruifrok 标准值")
        s_H   = np.array([0.65, 0.70, 0.29])
        s_DAB = np.array([0.27, 0.57, 0.78])
        return np.stack([s_H, s_DAB], axis=1), {"source": "ruifrok_fallback"}


def build_bases(M2):
    """M2: (3,2) 列=[s_H,s_DAB] → 归一化 2 列基 + 3x3 正交基。"""
    s_H = M2[:, 0] / np.linalg.norm(M2[:, 0])
    s_D = M2[:, 1] / np.linalg.norm(M2[:, 1])
    u2  = s_D - (s_D @ s_H) * s_H              # Gram-Schmidt
    s2  = u2 / np.linalg.norm(u2)
    s3  = np.cross(s_H, s2)                    # 两者正交且单位 ⇒ 已是单位向量
    M2n = np.stack([s_H, s2], axis=1)          # 归一化后的 (3,2)
    M3  = np.stack([s_H, s2, s3], axis=1)      # 正交矩阵 (3,3)
    return M2n, M3, s3


def rgb_to_od(img, i0, eps=CLIP_EPS):
    """img: (H,W,3) float [0,1] → OD。返回 (od, n_clipped, n_total)"""
    x = img / i0
    n_clipped = int((x < eps).sum())
    od = -np.log10(np.clip(x, eps, 1.0))
    return od, n_clipped, img.shape[0] * img.shape[1] * img.shape[2]


def od_to_rgb(od, i0):
    return np.clip(i0 * (10.0 ** (-od)), 0.0, 1.0)


def psnr(a, b, peak=1.0):
    mse = float(np.mean((a - b) ** 2))
    return float("inf") if mse == 0 else 10.0 * np.log10(peak ** 2 / mse)


def process_one(img01, M2n, M3, i0):
    """返回一张图的全部诊断量。img01: (H,W,3) float [0,1]"""
    H, W, _ = img01.shape
    od, n_clip, n_tot = rgb_to_od(img01, i0)
    # ★★ 展平必须「通道优先」：od 是 (H,W,3)，内存里通道是最后一维，
    #    直接 .reshape(3,-1) 会把每个像素的 (R,G,B) 三元组错位切分！
    #    必须先 transpose(2,0,1) 再 reshape。
    od_flat = od.transpose(2, 0, 1).reshape(3, -1)          # (3, N)

    def unflat(x3):                                          # (3,N) → (H,W,3)
        return x3.reshape(3, H, W).transpose(1, 2, 0)

    # ---- V1: 3x2，不 clamp（复现用户的 0.023）----
    C2 = np.linalg.pinv(M2n) @ od_flat                      # (2, N)
    od_v1 = unflat(M2n @ C2)

    # ---- V2: 3x2，clamp 负浓度 ----
    od_v2 = unflat(M2n @ np.clip(C2, 0.0, None))

    # ---- V3: 3x3 正交基，不 clamp（理论上应为机器精度）----
    C3 = M3.T @ od_flat                                     # (3, N)
    od_v3 = unflat(M3 @ C3)

    # ---- V4: 3x3，只对 H/DAB 加非负（现实版本）----
    C3c = C3.copy()
    C3c[0] = np.clip(C3c[0], 0.0, None)
    C3c[1] = np.clip(C3c[1], 0.0, None)
    od_v4 = unflat(M3 @ C3c)

    out = {}
    for name, odv in [("V1_3x2_noclamp", od_v1), ("V2_3x2_clamp", od_v2),
                      ("V3_3x3_noclamp", od_v3), ("V4_3x3_clampHD", od_v4)]:
        rec = od_to_rgb(odv, i0)
        out[name] = {
            "mae_rgb":   float(np.mean(np.abs(rec - img01))),      # ← 和 0.023 同量纲
            "rmse_rgb":  float(np.sqrt(np.mean((rec - img01) ** 2))),
            "psnr_rgb":  psnr(rec, img01),
            "mae_od":    float(np.mean(np.abs(odv - od))),
        }

    # ---- 浓度本身的诊断 ----
    out["conc_stats"] = {
        "C2_neg_frac":      float((C2 < 0).any(axis=0).mean()),   # 至少一维为负的像素占比
        "C2_H_neg_frac":    float((C2[0] < 0).mean()),
        "C2_DAB_neg_frac":  float((C2[1] < 0).mean()),
        "C3_res_abs_mean":  float(np.abs(C3[2]).mean()),
        "C3_res_abs_p95":   float(np.percentile(np.abs(C3[2]), 95)),
        "C3_res_std":       float(C3[2].std()),
        "C3_H_mean":        float(C3[0].mean()),
        "C3_DAB_mean":      float(C3[1].mean()),
    }
    out["od_clip_frac"] = n_clip / n_tot
    return out


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--data", default="data/ihc")
    ap.add_argument("--out",  default="out")
    ap.add_argument("--limit", type=int, default=100, help="最多处理多少张")
    args = ap.parse_args()
    os.makedirs(args.out, exist_ok=True)

    M2, info = load_stain_matrix()
    M2n, M3, s_res = build_bases(M2)

    files = sorted(sum([glob.glob(os.path.join(args.data, e))
                        for e in ("*.png", "*.tif", "*.tiff", "*.jpg")], []))[:args.limit]
    if not files:
        raise SystemExit(f"❌ {args.data} 下没找到图像。先放 50–100 张真实 IHC patch 进去。")
    print(f"[info] 共 {len(files)} 张图")

    per_img, agg = [], {k: [] for k in
                        ["V1_3x2_noclamp", "V2_3x2_clamp", "V3_3x3_noclamp", "V4_3x3_clampHD"]}
    clip_fracs, conc_rows = [], []

    for i, f in enumerate(files):
        img = np.asarray(Image.open(f).convert("RGB"), dtype=np.float64) / 255.0
        if I0_MODE == "white":
            i0 = np.ones(3)
        else:
            i0 = np.percentile(img.reshape(-1, 3), 99, axis=0).clip(1e-3, 1.0)
        r = process_one(img, M2n, M3, i0)
        clip_fracs.append(r.pop("od_clip_frac"))
        conc_rows.append(r.pop("conc_stats"))
        per_img.append({"file": os.path.basename(f), **r})
        for k in agg:
            agg[k].append(r[k]["mae_rgb"])
        if (i + 1) % 20 == 0:
            print(f"  ... {i+1}/{len(files)}")

    summary = {}
    for k, v in agg.items():
        v = np.array(v)
        summary[k] = {
            "mae_rgb_mean":   float(v.mean()),
            "mae_rgb_median": float(np.median(v)),
            "mae_rgb_p95":    float(np.percentile(v, 95)),
            "mae_rgb_max":    float(v.max()),
        }
    conc = {k: float(np.mean([c[k] for c in conc_rows])) for k in conc_rows[0]}

    result = {
        "experiment": "E0.1",
        "stain_matrix_info": {**info,
                              "s_H": M2n[:, 0].tolist(),
                              "s_DAB_orth": M2n[:, 1].tolist(),
                              "s_res": s_res.tolist()},
        "config": {"clip_eps": CLIP_EPS, "i0_mode": I0_MODE, "n_images": len(files)},
        "summary": summary,
        "concentration_stats": conc,
        "od_clip_frac_mean": float(np.mean(clip_fracs)),
        "od_clip_frac_max":  float(np.max(clip_fracs)),
        "per_image": per_img,
    }
    with open(os.path.join(args.out, "e01_results.json"), "w", encoding="utf-8") as fp:
        json.dump(result, fp, indent=2, ensure_ascii=False)

    # ---------- 打印判读表 ----------
    psnr_mean = {k: float(np.mean([p[k]["psnr_rgb"] for p in per_img])) for k in agg}
    print("\n" + "=" * 62)
    print(f"{'变体':<22}{'MAE(RGB)':>12}{'中位数':>12}{'PSNR(dB)':>12}")
    print("-" * 62)
    for k in agg:
        s = summary[k]
        print(f"{k:<22}{s['mae_rgb_mean']:>12.5f}{s['mae_rgb_median']:>12.5f}"
              f"{psnr_mean[k]:>12.2f}")
    print("=" * 62)
    print(f"OD 被夹紧像素占比：均值 {np.mean(clip_fracs):.4%}，最大 {np.max(clip_fracs):.4%}")
    print(f"C2 出现负浓度的像素占比：{conc['C2_neg_frac']:.4%}"
          f"（H {conc['C2_H_neg_frac']:.2%} / DAB {conc['C2_DAB_neg_frac']:.2%}）")
    print(f"|C_res| 均值 {conc['C3_res_abs_mean']:.4f}，p95 {conc['C3_res_abs_p95']:.4f}")

    # ---------- 误差分解 ----------
    v1 = summary["V1_3x2_noclamp"]["mae_rgb_mean"]
    v2 = summary["V2_3x2_clamp"]["mae_rgb_mean"]
    v3 = summary["V3_3x3_noclamp"]["mae_rgb_mean"]
    v4 = summary["V4_3x3_clampHD"]["mae_rgb_mean"]

    print("\n【误差分解】")
    print(f"  秩亏代价   V1 − V3 = {v1 - v3:+.6f}")
    print(f"  截断代价   V2 − V1 = {v2 - v1:+.6f}   （对浓度 clamp 的代价）")
    print(f"  现实版本   V4      = {v4:.6f}   （3×3 + 只对 H/DAB 非负）")
    print(f"  ⇒ 主导原因：{'秩亏' if (v1 - v3) > (v2 - v1) else '非负截断'}")

    # ---------- 自动判读 ----------
    print("\n【自动判读】")
    if v3 < 1e-5:
        print(f"  ✅ V3 残差 {v3:.2e} ≈ 机器精度 ⇒ 闭环代数正确，管线无 bug。")
        if v1 > 20 * max(v3, 1e-9):
            print(f"  ✅ 换 3×3 可把残差从 {v1:.6f} 降到 {v3:.2e} ⇒ 秩亏确实是来源之一。")
        else:
            print(f"  ⚠️ V1({v1:.6f}) ≈ V3({v3:.2e}) ⇒ M 可能已是 3×3，或残差主要来自截断。")
        if v4 > 0.005:
            print(f"  ⚠️ 即使换 3×3，现实版本 V4={v4:.6f} 仍不小 ⇒ 非负截断是另一条"
                  f"必须处理的来源。改用天然非负的参数化（softplus/exp），不要用 clamp。")
        print("  ⇒ E0.1 通过，把上面的数字写进 E0_results.json 的 e01 字段。")
    else:
        print(f"  ❌ V3 残差 {v3:.2e} 远大于机器精度 ⇒ 管线本身有问题。")
        print("     逐项检查：① M3 是否真正交（np.abs(M3.T@M3 - np.eye(3)).max() 应 < 1e-12）"
              "② 图像是否已归一化到 [0,1] ③ 是否 float64 "
              "④ ★展平是否用了 transpose(2,0,1)（直接 reshape(3,-1) 会静默出错）")
        print("     先用 make_synthetic.py 生成合成数据跑一遍：合成数据下 V3 必须是机器精度。")

    print("\n结果已写入 out/e01_results.json")


if __name__ == "__main__":
    main()
```

### 2.3 判据（**这一步的结论决定后面所有事**）

> ★ **先修正一个常见误解（本机已数值验证）**：往返误差**只有两类来源**，不是四类。  
> · **`I₀` 精确抵消**，不造成任何误差：`I′ = I₀·10^(−OD) = I₀·(I/I₀) = I`。实测 `I₀=1.0` 与 `I₀=p99` 的往返 MAE 都是 `~5e-17`。**但有一个例外**：如果你的 OD 公式里写了 `clip(I/I₀, ·, 1.0)`，而某些像素比 `I₀` 亮，那些像素会被**上界截断**——这属于「截断」，不属于「I₀ 误差」。  
> · **uint8 量化不造成往返误差**（uint8 进 → 同一 uint8 出，实测 0.0000% 像素改变）。它的真实作用是**给监督目标加噪声**（`dC/dI = 1/(I·ln10)·M⁻¹`），是**监督精度上限**，不是重建误差。
>
> **⇒ 误差只有两个来源：① M 秩亏　② 截断（对浓度做 `clamp(min=0)`，或对 `I/I₀` 做上界 clip）。**

**本机实测的量化量级**（合成数据，`M` 为 3×3 正交基）：

| 配置                                   | MAE         | 说明                       |
| ------------------------------------ | ----------- | ------------------------ |
| 3×3 正交基，不 clamp，`I₀=1.0`             | **5.1e-17** | 精确                       |
| 3×3 正交基，不 clamp，`I₀=p99`             | **5.1e-17** | **`I₀` 确实精确抵消**          |
| 3×3 正交基，不 clamp，但 `clip(I/I₀,·,1.0)` | **3.7e-5**  | 上界截断的代价（很小但非零，且是**静默**的） |
| 3×3 正交基，**对浓度 `clamp(min=0)`**       | **4.1e-2**  | **非负截断的代价——比秩亏还大**       |
| 3×2（秩亏），不 clamp                      | **7.4e-2**  | 秩亏的代价                    |

**⇒ 误差分解方式**：

```
秩亏代价   = V1 − V3     （3×2 相对 3×3 多出来的）
截断代价   = V2 − V1     （clamp 负浓度多出来的）
```

**两者谁大，谁就是主导原因。** 脚本会自动打印这个分解。

| 观察                  | 结论                          | 行动                                                                       |
| ------------------- | --------------------------- | ------------------------------------------------------------------------ |
| **V3 ≈ 1e-5 或更小**   | 闭环代数正确，管线无 bug              | 继续看分解                                                                    |
| **V1 − V3 大**       | 秩亏是主要来源                     | 第三通道用 `s_res`，`M` 用 3×3 正交基                                              |
| **V2 − V1 大**       | **非负截断是主要来源**               | ⚠️ 见下方「关键提醒」                                                             |
| **V4 仍 > 0.005**    | 现实版本（3×3 + 只对 H/DAB 非负）依然有损 | 必须处理截断，不能只换矩阵                                                            |
| V3 远大于 1e-5         | 管线有 bug                     | 检查 `M3.T@M3 ≈ I`、图像是否归一化到 [0,1]、是否 float64、**展平是否用了 `transpose(2,0,1)`** |
| `od_clip_frac` > 1% | 大量像素被夹到 OD 下界               | 记录这个比例（「隐藏失败」的计数器）                                                       |
| `C2_neg_frac` 高     | 伪逆解出现大量负浓度                  | 说明真实 OD 不在 `span{s_H,s_DAB}` 里——这正是要用 3×3 的直接证据                          |

> ⚠️ **关键提醒（V2 − V1 大的时候）**：非负截断的代价**不能靠"不 clamp"解决**——因为浓度在物理上确实不能为负，而且不加约束训练会发散。  
> 正确的做法是**改变参数化**：让模型输出的量**天然非负**（`softplus` / `exp` / 平方），而不是先自由输出再 `clamp`。  
> **区别很重要**：`clamp` 会把梯度在边界处归零（本项目的 `physics.py` L79 就是这个错误）；`softplus` 是可微的、梯度处处非零。

### 2.5 失败怎么办

**如果 V3 也很大**：说明问题不在秩，而在管线。**不要继续做 E0.2–E0.4**，先回来查管线，并用 §2.6 的合成数据确认代码。

## 3. E0.2 伊红复染检测

### 目的

决定第三通道选 **`C_res`（残差/正交补）** 还是 **`C_E`（伊红）**。  
判据：**你的 IHC 片子上到底有没有伊红复染。**

### 为什么重要

标准 IHC 流程通常只有苏木素复染（无伊红）。如果片子确实没有伊红，那么用 `C_E` 当第三通道就是**在拟合噪声**。  
但如果有伊红（有些实验室用 H\&E 复染），`C_E` 就是有真实物理意义的胞质/膜成分，**而且它正好补上 H 通道缺失的膜结构**——这对 HER2 特别有价值。


### 实现

**`e02_eosin.py`**：

```python
#!/usr/bin/env python3
"""E0.2 判定 IHC 片子上的第三通道该用什么。

★ 先读这一段：一个代数事实，它改变了整个判据的设计（2026-10-05 实测证明）

在 3x3 解混 C = pinv(M) @ od（M 的列 = [H, E, DAB]）中，
C[1]（习惯叫它"E 通道"）在代数上 **恒等于正交补残差通道**，与伊红无关：

    w2 = M^-1 的第 2 行，满足  w2 . s_H = 0,  w2 . s_DAB = 0,  w2 . s_E = 1
    ⇒ w2 ∥ (s_H x s_DAB)           实测夹角 8.5e-7 度（数值零）
    ⇒ C_E = w2 . od = w2 . r， r = od 在 span{s_H, s_DAB} 正交补上的分量
    ⇒ C_E / C_res = -1.5918        纯常数（Ruifrok 值下）

实测验证：
  · od = a*s_H + b*s_DAB（绝对没有伊红）         → |C_E| = 1.4e-16（机器零）
  · 再叠加任何正交补残差 r                        → r 100% 落进 C_E

⇒ 三条推论，全部推翻了初版判据：
  ① **coherence 不能判别伊红**。任何"没有伊红但有残差"的片子都会给出
     非零且有结构的 C_E。coherence 只能排除"纯白噪声"这一种情况。
  ② **corr(C_E, C_H) 也不能判别**。初版曾想用"负相关 ⇒ 伊红"，自检直接推翻：
     实测（合成数据，已知真值）
        真伊红（独立间质场）   corr(E,H) = +0.022   ← 接近 0
        向量误差（纯泄漏）     corr(E,H) = -0.974 ~ -1.000
     **泄漏给强负相关，真伊红给接近 0** —— 与直觉**正好相反**。
     原因：残差轴的正负号是任意的（C_E = w2·r，而 w2 ∝ -(s_H×s_DAB)）。
     ⇒ corr 的**符号没有意义**，有意义的只有 |corr| 的大小，而 R² 才是正确度量。
  ③ 能用的判据只有一个：**C_E 里有没有 C_H / C_DAB 都没有的空间结构？**
     用 R²(C_E ~ C_H, C_DAB) 度量：
        R² ≈ 1  → C_E 完全是 H/DAB 的线性组合 ⇒ 纯泄漏，没有第三种染色
        R² ≈ 0  → C_E 携带独立空间结构       ⇒ 存在第三种吸收成分
     自检结果（合成数据，已知真值，**经过 PNG 存盘 + uint8 往返**）：
        真伊红（独立间质场）              R² = 0.0008   E_absmean = 0.1722
        染色向量误差 δ=0.03（无伊红）     R² = 0.9489   E_absmean = 0.0044
        染色向量误差 δ=0.10（无伊红）     R² = 0.9958   E_absmean = 0.0128
        染色向量误差 δ=0.20（无伊红）     R² = 0.9991   E_absmean = 0.0242
     ⇒ 判据干净可分。（注意测试图必须用**与解混矩阵不同**的「真实」矩阵生成——
        否则残差恒为 0，测不出任何东西。这一点第一次就写错过。）

★ 判据的适用下限（实测）：**残差必须显著高于 uint8 量化底噪**。
  rgb 在 0.5 附近时，uint8 一格 ≈ Δod 0.0034，经 |w2|≈1.59 传到 C_E ≈ 0.003。
  所以 **E_absmean ≲ 0.01 时 R² 不可信**（会被量化噪声主导，虚低到 0.03 左右）。
  脚本用 MIN_SIGNAL 拦这一种情况。用户的真实数据 E_absmean≈0.074，远高于此下限。

★ 另一个副产品：R² ≈ 1 说明残差**是染色向量不准造成的、因此可修**。
  这时 E0.3（矩阵敏感性）的优先级要提前——换准 M 会把残差压下去。
"""
import os, json, glob

from PIL import Image


def load_full_matrix():
    """返回 (3,3)，列 = [s_H, s_E, s_DAB]。"""
    try:
        import sys
        sys.path.insert(0, os.environ.get("HISTDIST_ROOT", ""))
        from hdadapt.physics import STAIN_MAT_FULL
        M = np.asarray(STAIN_MAT_FULL, dtype=np.float64)
        assert M.shape == (3, 3), f"需要 (3,3)，实际 {M.shape}"
        return M, "user"
    except Exception as e:
        print(f"[warn] 回退 Ruifrok HED 标准值（{type(e).__name__}）")
        s_H   = np.array([0.65, 0.70, 0.29])
        s_E   = np.array([0.07, 0.99, 0.11])
        s_DAB = np.array([0.27, 0.57, 0.78])
        return np.stack([s_H, s_E, s_DAB], axis=1), "ruifrok_hed"


def decompose(M, path):
    """→ C (3,H,W)，通道 = [H, E, DAB]。★ 必须通道优先展平。"""
    img = np.asarray(Image.open(path).convert("RGB"), dtype=np.float64) / 255.0
    od = -np.log10(np.clip(img, 1e-3, 1.0)).transpose(2, 0, 1).reshape(3, -1)
    return (np.linalg.pinv(M) @ od).reshape(3, *img.shape[:2])


def spatial_coherence(ch):
    """相邻像素差分方差 / 全局方差。白噪声 → 2.0，完全平滑 → 0.0。
    ⚠️ 只用于排除"纯白噪声"。**不能**判别伊红（见文件头 ①）。"""
    dx, dy, var = np.diff(ch, axis=1), np.diff(ch, axis=0), ch.var()
    return 2.0 if var < 1e-12 else float((dx.var() + dy.var()) / (2 * var))


def pearson(a, b):
    a, b = a.ravel(), b.ravel()
    return 0.0 if (a.std() < 1e-12 or b.std() < 1e-12) else float(np.corrcoef(a, b)[0, 1])


def resid_r2(C):
    """★ 判据主力：C_E 能被 (C_H, C_DAB) 线性解释多少。
    R² ≈ 1 ⇒ 纯泄漏；R² ≈ 0 ⇒ 有独立第三成分。"""
    y = C[1].ravel()
    X = np.stack([C[0].ravel(), C[2].ravel(), np.ones(y.size)], 1)
    beta, *_ = np.linalg.lstsq(X, y, rcond=None)
    return float(1.0 - (y - X @ beta).var() / max(y.var(), 1e-12))


def stats_of(C):
    aH, aE, aD = (float(np.abs(C[i]).mean()) for i in range(3))
    return {
        "H_absmean": aH, "E_absmean": aE, "DAB_absmean": aD,
        "E_over_H": aE / max(aH, 1e-9),
        "resid_r2": resid_r2(C),                 # ★ 判据主力
        "corr_E_vs_H": pearson(C[1], C[0]),      # 仅描述性；★ 符号无意义，见文件头 ②
        "corr_E_vs_DAB": pearson(C[1], C[2]),    # 仅描述性；★ 符号无意义
        "E_coherence": spatial_coherence(C[1]),  # 仅用于排除纯噪声
        "H_coherence": spatial_coherence(C[0]),
        "DAB_coherence": spatial_coherence(C[2]),
    }


R2_LEAK = 0.90     # R² 高于此 ⇒ 判为纯泄漏
R2_INDEP = 0.50    # R² 低于此 ⇒ 判为存在独立成分
NOISE_CUT = 1.2    # coherence 高于此 ⇒ 纯噪声
MIN_SIGNAL = 0.01  # E_absmean 低于此 ⇒ 残差淹没在 uint8 量化底噪里，R² 不可信


def calibrate(M, he_ref_dir):
    """用已知含伊红的 H&E 图定标。

    ★ he_dab_absmean = 已知 H&E 上 **DAB 通道** 的读数 = 「缺失染色」底噪。
      同一条流程、同一个矩阵、一个不存在的染色 ⇒ 这是唯一同口径的对照。
    """
    anchors = {"white_noise": spatial_coherence(np.random.randn(256, 256))}
    if not (he_ref_dir and os.path.isdir(he_ref_dir)):
        return anchors
    fs = sorted(sum([glob.glob(f"{he_ref_dir}/{e}") for e in
                     ("*.png", "*.tif", "*.tiff", "*.jpg")], []))[:30]
    if not fs:
        return anchors
    st = [stats_of(decompose(M, f)) for f in fs]
    anchors["he_ref_n"] = len(fs)
    for k, key in [("E_absmean", "he_E_absmean"), ("E_over_H", "he_E_over_H"),
                   ("resid_r2", "he_resid_r2"), ("E_coherence", "he_E_coherence")]:
        anchors[key] = float(np.mean([s[k] for s in st]))
    anchors["he_dab_absmean"] = float(np.mean([s["DAB_absmean"] for s in st]))
    return anchors


def main():

    ap = argparse.ArgumentParser()
    ap.add_argument("--data", default="data/ihc")
    ap.add_argument("--he_ref", default="data/he",
                    help="一批已知含伊红的 H&E 图，用于同口径定标")
    args = ap.parse_args()

    if not files:
        raise SystemExit(f"❌ {args.data}/ 下没有图像")

    anchors = calibrate(M, args.he_ref)

    os.makedirs("out/e02_vis", exist_ok=True)
```

### 判据

> **⚠️ 本节判据已于 2026-10-05 全部重写。** 初版判据（`E/H` + `E_coherence`）**在原理上无法检出"没有伊红"**，已在真实数据上产生假阳性。原因见下。

#### 先记住一个代数事实（已实测证明）

在 3×3 解混 `C = pinv(M) @ od`（`M` 的列 = `[H, E, DAB]`）中，**`C[1]` 恒等于正交补残差通道，与伊红无关**：

```
w2 = M⁻¹ 的第 2 行，满足  w2·s_H = 0,  w2·s_DAB = 0,  w2·s_E = 1
⇒ w2 ∥ (s_H × s_DAB)        实测夹角 8.5e-7 度（数值零）
⇒ C_E = w2 · od = w2 · r，  r = od 在 span{s_H, s_DAB} 正交补上的分量
⇒ C_E / C_res = −1.5918      纯常数（Ruifrok 值下）
```

实测：`od = a·s_H + b·s_DAB`（绝对没有伊红）⇒ `|C_E| = 1.4e-16`（机器零）；但**只要叠加任何正交补残差，它就 100% 落进 `C_E`**。

⇒ **任何"没有伊红但有残差（光照误差 / 染色向量不准 / 非染色吸收）"的片子，都会给出非零且有结构的 `C_E`。**

#### 因此两条旧判据都失效

| 旧判据                        | 为什么失效                                                                   |
| -------------------------- | ----------------------------------------------------------------------- |
| `E_coherence ≤ 1.2` ⇒ 有伊红  | 真实组织**永远**有结构 ⇒ 这个条件永远成立 ⇒ **假阳性生成器**                                   |
| `corr(C_E, C_H) < 0` ⇒ 有伊红 | 自检实测：**纯泄漏给 −0.97~−1.00，真伊红给 +0.02** ⇒ 与直觉**正好相反**。残差轴正负号是任意的，**符号无意义** |

#### 唯一有效判据：`R²(C_E ~ C_H, C_DAB)`

问：**`C_E` 里有没有 `C_H` / `C_DAB` 都没有的空间结构？**

| `R²(C_E ~ C_H, C_DAB)` | 结论                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| **≥ 0.90**             | `C_E` 完全是 H/DAB 的线性组合 ⇒ **残差泄漏，没有第三种染色** → 第三通道用 **`C_res`**；且残差**可修**（多半是 M 不准 ⇒ 提前做 E0.3） |
| **≤ 0.50**             | `C_E` 携带独立空间结构 ⇒ **存在第三种吸收成分**。但**这不能证明是伊红**（也可能是别的色原 / 非染色吸收 / 自发荧光）⇒ 必须人工看图 + 结合实验流程      |
| 0.50 – 0.90            | 不确定 ⇒ 人工看图，并优先把 M 换成实测值后重跑                                                                  |

#### 适用下限（实测）

**残差必须显著高于 uint8 量化底噪。** rgb 在 0.5 附近时 uint8 一格 ≈ Δod 0.0034，经 `|w2| ≈ 1.59` 传到 `C_E` ≈ 0.003。  
⇒ **`E_absmean ≲ 0.01` 时 `R²` 不可信**（会被量化噪声主导，虚低到 ~0.03）。脚本用 `MIN_SIGNAL` 拦这一种情况。

#### 自检结果（合成数据，已知真值，经 PNG 存盘 + uint8 往返）

| 情形            | `R²`   | `E_absmean` | 判定                |
| ------------- | ------ | ----------- | ----------------- |
| 真伊红（独立间质场）    | 0.0008 | 0.1722      | ✅ 有独立第三成分         |
| 染色向量误差 δ=0.03 | 0.9489 | 0.0044      | ⛔ 信号太小，判据失效（诚实报告） |
| 染色向量误差 δ=0.10 | 0.9958 | 0.0128      | ❌ 纯泄漏             |
| 染色向量误差 δ=0.20 | 0.9991 | 0.0242      | ❌ 纯泄漏             |

> **测试图必须用「与解混矩阵不同」的真实矩阵生成**——否则残差恒为 0，测不出任何东西。（这一点初版就写错过。）

#### 同口径对照（辅助证据）

脚本会算 `he_dab_absmean` = **已知 H\&E 图上 DAB 通道的读数** = 「缺失染色」底噪（同一条流程、同一个矩阵、一个不存在的染色）。把 IHC 片的 `E_absmean` 与它比，是唯一同口径的比较。

#### 必须人工看图

`out/e02_vis/*_E.png` 要打开看。**如果自动判据与肉眼判断冲突，以肉眼为准**，并记录冲突。

#### 不论判据结果如何，结论都一样

`C_E` 与 `C_res` 是**同一条轴**（差一个常数）。所以：

- 第三通道**永远**是这条轴；
- 它的正确名字是「**未解释残差**」，**不是**某一种染色；
- 把它当染色通道写进论文，会被问「这是哪种染色」而答不上来。

## 4. E0.3 染色矩阵敏感性（决定 H-score 可不可比）

### 目的

回答：**换一个染色矩阵，DAB 浓度图会变多少？进而逐细胞 H-score 会变多少？**

### 为什么重要

`H-score = Σ_{i∈{1+,2+,3+}} i × (% 细胞落在强度 i)`，强度分箱是按 **DAB-OD 阈值**切的。  
而 `C_DAB = (M⁻¹ 的第 2 行) · OD` —— **换 M 就换了这一行的系数，阈值切的位置整体平移，细胞落进不同的箱子，H-score 就变了。**  
**Ruifrok 2001 量化过这个上界：DAB 饱和时，误分到「苏木素」的量可达实测 IOD 的 65%。**

⇒ **H-score 必须先固定 M 才有可比性和可复现性。没有固定 M 的 H-score 比没有更糟。**

### 实现

对同一批 IHC patch，用四个 M 分别算 `C_DAB`，然后**用同一套阈值**做分箱，比较：

1. **M_A**：Ruifrok 标准值（固定）
2. **M_B**：Macenko 队列级（所有图一起估一个 M，固定）
3. **M_C**：Macenko 逐图（每张图各自估 M）
4. **M_D**：Vahadane 队列级（固定）

对每对组合，报告：

- `C_DAB` 的 **Pearson r** 和 **相对偏差**
- 分箱后**逐像素等级的一致性**：**ICC(2,1)** 和 **Cohen's κ**
- **Bland–Altman 95% 一致性界限**

**判据**：

- 若 **ICC > 0.9 且 κ > 0.8** ⇒ 矩阵选择不敏感，随便挑一个固定下来即可
- 若 **ICC < 0.8** ⇒ **矩阵选择会实质改变 H-score** ⇒ 必须在论文里明确声明用的是哪个 M、怎么得到的、以及为什么不用别的

**实现提示**：Macenko/Vahadane 用 `skimage.color` 或现成实现；如果环境里没有，**先只跑 M_A vs M_C**（固定 vs 逐图），这一对最能说明问题。

**输出**：`out/e03_results.json` + 一张 `out/e03_bland_altman.png`。
