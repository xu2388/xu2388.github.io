2先修诊断学：三个假设的预测高度重叠

在给出排序之前，必须先说清一件事：文档 §7 列出的实验（尤其 E1）在当前形式下无法完成归因。原因是三个假设对同一个观测的预测是重叠的。

观测：cond=none 与 cond=he 比H-A 的预测H-B 的预测能否区分

⇒ E1 只在「he 明显更好」这一个方向上有效。而文档 §3.9 的 ab_cond 已经给出了接近这个方向的信息（条件被读了，r_AB=0.85/0.93），所以 E1 大概率会落在「两者接近」这一格——那一格没有判别力。

真正的问题是：现有全部证据都在「32 个 patch」这个 regime 里

文档 §4.3 自己已经点出了这一点，而且点得很准。这里只补一个结构性理由：在 32 个 patch 上，模型的可行策略是「背下这 32 个目标」（26.6 M 参数对 32 个样本），而不是「学会条件映射」。这两条策略在任何指标上都会给出相似的数字（都低 loss、都在 val 上失败）。因此 32-patch regime 的观测不能用来判断「条件为什么没被利用」——因为在那个 regime 里，模型本来就不需要条件。

⚠ 但要公平地说：文档 §4.3 主张「§3.9 / §3.10 测的是条件怎么被使用这一功能性问题，不依赖泛化，所以可信」。这个辩护部分成立——「条件被读了但没有方向」这个结论是站得住的（因为它是在训练过的 patch 上测的）。不成立的部分是把它外推到「真实任务上条件也不携带信息」：在 32-patch regime 里，条件不携带信息是必然的（模型可以背答案），所以那个观测不能作为真实任务上条件无用的证据。

3H-A 的硬上界：条件到底能降低多少 loss

这一节是本报告的核心。它给出一个与架构无关、与注入方式无关的量：条件对 loss 的贡献上界。如果这个上界本来就很小，那么 H-A 就成立了，而且不需要任何训练就能验证。

3.1 MMG 恒等式（逐字核实）

MMG: Mutual Information Estimation via the MMSE Gap in Diffusion
Longxuan Yu, Xing Shi, Xianghao Kong, Tong Jia, Greg Ver Steeg（UC Riverside / UCSD）· arXiv:2509.20609 · 2025 · 12 页 · 已下载全文逐字核实
VERIFIED

原文 Eq.(7) 逐字：

log p(x|y) − log p(x) = ½ ∫₀^∞ dγ ( mmse(x|γ) − mmse(x|γ,y) )

原文 Eq.(8) 逐字：

I(x;y) = ½ ∫₀^∞ dγ ( mmse_x(γ) − mmse_{x|y}(γ) )

原文逐字（就在 Eq.8 正下方）：

「Conditioning on y can only decrease the MMSE Wu & Verdú (2011), so the mutual information is non-negative as expected. While Eq. 7 appears to be novel, a version of Eq. 8 appeared in Guo et al. (2005).」

原文 §4.2「The Orthogonal Principle」逐字：

「The principle states that for optimal denoisers, the gap in MMSE is precisely the expected squared distance between the conditional and unconditional estimators.」

这三句话合起来就是本报告要用的全部：条件带来的 loss 下降 = 条件估计器与无条件估计器之间的均方距离 = 条件所解释的目标方差。它不可能为负，也不可能超过目标自身的方差。

3.2 翻译成 M0 的语言

把 x 取成 M0 的扩散目标 z₀（归一化后的 C_DAB），把 y 取成 cond=[C_H^HE, C_E^HE]，把 γ 取成噪声水平（与扩散时刻 t 一一对应）：

MMG 的记号在 M0 里是什么
mmse_x(γ)只看 z_t、不看条件时，预测 z₀ 的最小可达 MSE（= 无条件模型的最优 loss）
mmse_{x|y}(γ)同时看 z_t 和 cond 时，预测 z₀ 的最小可达 MSE
差值条件在这一噪声水平上的全部价值 = E‖x̂(z_t,cond) − x̂(z_t)‖²
对 γ 积分条件在整个扩散过程中的总价值 = 2·I(z₀; cond)

3.3 为什么条件的价值集中在高 t，且总量 ≈ R²

高 t（ᾱ_t → 0）：  z_t ≈ ε
                    E[z₀ | z_t] ≈ E[z₀]  ← 已经是个常数，条件无关
                    ⇒ 条件在这里的全部价值 = Var( E[z₀ | cond] ) = R² · Var(z₀)
                    而此处 v_t = √ᾱ ε − √(1−ᾱ) z₀ ≈ −z₀，loss 尺度 ≈ Var(z₀)
                    ⇒ 相对改善上界 ≈ R²

低 t（ᾱ_t → 1）：  z_t ≈ z₀  ← 答案已经在输入里，条件是冗余的
                    ⇒ 条件价值 ≈ 0

⇒ 条件的价值集中在高 t；而 v-prediction 的 MSE 目标对所有权重相同的 t 一视同仁。
核心命题

在 M0 的 v-prediction MSE 目标下，条件能把最优 loss 降低的比例，上界是 R²（条件对 z₀ 的决定系数）。这个上界与架构、注入方式、模型大小全部无关。

3.5 一个放大因素：MSE 在重尾目标上被少数像素主导

文档 §3.10 给出真值 DAB 的范围 [-0.0143, 3.5461]，而归一化常数 hi = 0.8786（§2.2）。最大值是归一化上界的 4 倍 ⇒ 分布极重尾，少数像素的 DAB 是高分位数的数倍。

平方损失（v-MSE）对这些像素的权重是平方级的 ⇒ loss 被少数可能不可预测的极端像素主导，这进一步压低「可被条件解释」的有效方差份额。

这条是「放大器」，不是「主因」——必须分清

重尾会压低像素级的 R²，但解释不了「同数据集上 PSPStain 拿到 0.439、M0 拿到 0.02」这个差距——因为 PSPStain 用的是同一批数据、同一类逐像素损失。⇒ 重尾是背景条件，不是故障本身。它的正确用法是提醒 T1 要分层报告（逐像素 / 块均值 / 高分位像素分开报），而不是报一个聚合 R²。

需要你确认口径

上面 3.5461 与 hi=0.8786 是否同一量纲（都是原始浓度？还是一个是归一化前、一个是渲染后？）。文档 §3.10 里「预测 DAB 范围 [0.0110, 0.8786]」恰好等于归一化的 [lo, hi]，而「真值 DAB 范围」写的是 [-0.0143, 3.5461]——两行疑似不同量纲。这个口径不影响 §3.4 的结论，但会影响 §7 T1 的实现。

  1. 取全量 train（3506 patch，或抽 512）+ val（64 patch）。
  2. 对 C_DAB 与 [C_H, C_E] 都做多尺度分解：块均值（8/16/32/64）+ 局部均值/方差/梯度幅值。目标也做同样分解——这是关键，逐像素的 C_DAB 本身噪声很大，块均值才是「该染多浓」这个可学的量。
  3. 在每个尺度上拟合条件均值 E[C_DAB | cond]：ridge 起步（闭式、秒级），再用小 MLP 或梯度提升树给非线性上界。
  4. 算 R²(scale) = Var(Ê[z₀|cond]) / Var(z₀)，报整条曲线，不只报一个数。

预期结果（按 §3 的推算）：逐像素 R² 约 0.05–0.15；随尺度变粗上升到 R² ≈ 0.2–0.5；粗尺度才是可学的部分。

判据（这条决定后面所有事）

★ 先设一个健全性下限：max R² 必须 ≥ 0.193，否则说明这个探针本身太弱，不是条件太弱。理由：你的 PSPStain 基线在同一数据集上已经实现 R²≈0.193（§0 表）。探针若测不到 0.193，问题在探针（线性/ridge 表达力不足），不在条件。所以 T1 报出的数字要当成下界读，直到它超过 0.193 才可作为「上界」使用。

若 max R² 落在 0.19–0.25 ⇒ H-A 的「信号弱」这一半成立，但「弱到不值得学」不成立：天花板是 0.19 而不是 0.05，M0 拿到 0.0004 仍是真实故障 ⇒ 主攻目标函数与优化，而不是「接受小信号」。
若 max R² > 0.40 ⇒ H-A 被进一步削弱，模型确实在把真信号扔掉 ⇒ 主攻 H-B 与优化。
若粗尺度 R² ≫ 细尺度 R² ⇒ 多尺度注入应主要作用在粗尺度，且 M0 的 patch 尺寸/感受野需要重新审视（这正是文档 §7 E2 的预判，本轮得到文献支持）。

T2 —— 错位测试（零训练，CPU，~15 分钟）

量出 R² 有多少被空间错位吃掉（H-D）
对照库内早先的 Corr_pixel=0.061 vs Corr_128=0.407
零训练 CPU

做法：

  1. 对每对 patch，在 dx, dy ∈ [−8, 8]（可加小旋转/尺度）上搜索，最大化 corr(块均值(C_H^HE), 块均值(C_DAB^IHC))。
  2. 比较「不搜」与「搜过之后」的 R²。
  3. 顺带量：corr(C_H^HE, C_H^IHC) 与 corr(C_DAB^IHC, C_H^HE) 在同一批 patch 上的值——直接解决 §6.4 的矛盾。

预期结果：若错位主导，R² 在允许 ±4–8 像素平移后会明显跳升；若错位不主导，跳升很小。

判据：跳升 > 2× ⇒ 先修数据配对/采样，再谈模型；跳升 < 1.2× ⇒ H-D 排除，回到 H-A/H-B。

T3 —— 条件强度扫描 × 注入路径（★ 分开 H-A 与 H-B，GPU，~40 分钟）

把「条件信息量」与「注入强度」当成两个自变量扫
这是文档 §7 E4 的升级形式，也是分开 H-A 与 H-B 的关键设计
决定性 ~40 min GPU

核心思想：H-A 与 H-B 都预测「Δr 会塌」，但塌的原因不同——H-A 说塌点由 R² 决定，H-B 说塌点由注入方式决定。所以要同时扫这两个自变量。

做法：

  1. 造一个可控 R² 的合成任务：保留强合成信号 S = 0.7·C_E + 0.3·blur3×3(C_H)，但给条件加噪：
    cond(β) = normalize( β·cond + √(1−β²)·noise_cond )，β ∈ {1.0, 0.6, 0.35, 0.2, 0.1, 0.05}。
    目标 tgt = clip(S, −1, 1) 不变 ⇒ 「目标给定条件的 R²」随 β 单调下降且可解析计算（先用 T1 的方法把每个 β 的 R² 量出来）。
  2. 两条注入路径：(a) M0 原样单尺度 concat；(b) §8 的多尺度零初始化门控残差。
  3. 每个 (β, 注入) 组合训 800 步 / 16 patch（与 probe_synth 完全同口径），采样后算 Δr = r(对条件) − r(轮转条件)。
  4. 画 Δr vs β（或 vs R²），两条曲线。
假设预测的曲线形状
H-A（目标函数）两条曲线几乎重合；Δr 只随 R² 下降而塌；塌点与注入方式无关
H-B（注入路径）两条曲线分开；多尺度注入的 Δr 在更低的 R² 处仍不塌（即它能榨出更弱的信号）

成本：6 个 β × 2 条路径 × ~3 分钟 ≈ 36 分钟 GPU（probe_synth 已在数分钟内跑完 800 步，所以这是保守估计）。

为什么这个设计比文档的 E1 / E4 强

E1（cond=none）只在单侧有判别力（§2）；E4（条件强度扫描）只扫了一个自变量，无法把「塌」归因到 R² 还是注入。T3 同时扫两个自变量，是唯一能把两条曲线分开的设计。

T4 —— cond=none 对照（GPU，~40 分钟）

就是文档的 E1。建议仍然跑（它是 M0 规格本来就要求的三个基线之一），但必须知道它的局限：

  • 只有单侧判别力：none ≈ he 时无法归因（H-A/H-B 都预测这个结果）。
  • 它的真正价值在另一个方向：如果 none 明显更好，那就复现了 SLICE 逐字报告的「input-level conditioning 比无条件还差」——那是一个可发表级别的阴性发现，而且直接指向 H-B。
  • 必须同种子、同 patch、同步数、同超参（文档 §2.5 已规定），否则不成立。

T5 —— 全量数据最小判别（GPU，~2 小时，唯一需要「跑一次真的」的实验）

文档 §4.3 已把它列为「本方案目前最大的方法论缺口」。本报告只补一条设计约束：

不要直接跑 run_ladder.sh（三段各 10000 步）

那样会得到三组都无法判别的结果（因为还没有仪器）。正确做法是：先只跑一个 arm（he，全量，10000 步），用它同时测 Δr、R² 达成度、以及 §3.10 的饱和度指标。拿到这组数字后，再决定要不要跑另外两段。文档 §7 E5 说「建议在 E1~E4 给出方向之后再决定」——这个判断是对的，本报告同意，只是把判据换成了 T1/T3。

8.2 若判定为 H-B —— 多尺度注入的具体形式

用户要求的四个细节（在哪里注入 / 注入几层 / 用什么算子 / 是否 zero-init）逐条给出。全部满足 §2.8：不用 ControlNet、不用 LoRA、不用 VAE、不用 GAN、不用分类器引导。

★ 方案 B1（首推）：多尺度零初始化门控残差注入（GLIGEN 式）
不复制 encoder、不新增 loss、step 0 与 M0 数值完全一致
首推 零初始化

在哪里注入：U-Net 的 4 个 up_block 的输出处（分辨率 16/8/4/2，对应 block_out_channels=(64,128,256,256)）。建议同时在 4 个 down_block 的输入处各加一路（T2I-Adapter Table 2 显示只注入 encoder 反而最好，17.36 vs decoder-only 18.32）。

注入几层：3–4 层。T2I-Adapter 的消融显示尺度数从 4 降到 1 时 FID 17.36→22.66（+30%），所以不要只做 1 层；4 层是上限，3 层已能拿到大部分收益。

用什么算子：

对第 l 层（分辨率 H/2^l × W/2^l，通道 C_l）：
    c_l = Conv1×1_l( downsample_l( cond ) )      # cond(2,128,128) → (C_l, H/2^l, W/2^l)
    h_l ← h_l + tanh(γ_l) · c_l                   # γ_l 是每层一个可学习标量，γ_l = 0 初始化

参数量：Σ_l C_l·2 ≈ 2·(64+128+256+256) ≈ 1.4 K —— 可忽略

是否 zero-init：是，必须。两个理由：(a) 有直接先例——GLIGEN 逐字「treated as a residual, whose gate is initially set to 0 (due to γ being initialized as 0). This also enables more stable training」；ControlNet 的 zero-conv 是同一思想。(b) 它保证了 step 0 的输出与 M0 baseline 数值完全一致 ⇒ 之后任何变化都可归因，这是本项目一贯要求的可解释性。

依据汇总：GLIGEN（零初始化门控残差，不复制 encoder）· ControlNet（zero-conv + 逐 encoder level 注入）· T2I-Adapter（注入尺度消融）· DiT（「adaLN-Zero outperforms cross-attention and in-context conditioning at all stages of training」——逐层调制 > 输入 concat 的直接受控证据）。

成本 / 可复现性：改动成本 低（约 50 行，包一层 UNet2DModel）；可复现性 高（GLIGEN + ControlNet 都有公开实现与权重）。

方案 B2：多尺度空间调制（SPADE / AdaGN 的 diffusion 版）
更强，但改动更大
次推

在哪里注入：每个 GroupNorm 处（SPADE 逐字：「each normalization layer uses the segmentation mask to modulate the layer activations」）。

用什么算子：h ← (1 + γ_l(cond)) ⊙ norm(h) + β_l(cond)，其中 γ_l, β_l 由一个小 conv 从下采样后的 cond 产生。zero-init 的等价形式是 γ=0, β=0（即 step 0 时退化为恒等）。

依据：SPADE 逐字指出「the normalization layers tend to “wash away” semantic information」，并证明「simply concatenating semantic input at every layer fails」；ADM 的 AdaGN、DiT 的 adaLN-Zero 都是这一族。

成本 / 可复现性：改动成本 中（要替换 UNet2DModel 里所有 GroupNorm，约 100–150 行）；可复现性 中高（SPADE 有官方实现，但 diffusion 版需自己搭）。

方案 B3：timestep-embedding 注入（SLICE 式）—— 便宜，但对空间条件不适用
必须诚实标注它的局限
不推荐作主方案

SLICE 的机制是：把条件编码后加进 timestep embedding，从而「propagates through all residual blocks without architectural changes」。但 SLICE 的条件是一个全局向量（噪声类型 / 混响 / 失真的分类条件）。

为什么不能直接搬到 M0

M0 的条件是空间图（2×128×128）。把它池化成全局向量塞进 timestep embedding，会丢掉全部空间信息——而「哪里该染」正是空间信息。⇒ SLICE 可迁移的是它的结论（「只在输入层注入不够，要穿到每个 block」），不是它的算子。若要用，只能当作全局染色风格的调制，与 B1 叠加，不能替代 B1。

8.4 H-D（serial-section 错位）在修复计划里的位置

它不产生新的改法，只产生一条前置检查。T2 会告诉你错位吃掉了多少 R²，按结果分流：

  • 若 T2 显示跳升 > 2× ⇒ 说明「配对的两个 patch 不是同一块组织」这个混淆很大，先修采样 / 配对，任何模型改动都排在后面——否则你会在一个错的对应关系上调模型，调出来的结论全部作废。
  • 若 T2 显示跳升 < 1.2× ⇒ H-D 只是背景上限，不改变 §8.1 / §8.2 的任何结论，直接按 H-A / H-B 走。

为什么它不能是主因：同一份 serial-section 数据上，PSPStain 能到 0.439、UNIStainNet 能到 0.867。错位给像素级 R² 设了一个上限，但没有把上限压到 0.0004。所以 H-D 只影响「上限是多少」，不影响「M0 为什么只拿到 0.02」——后者必须由 H-A 或 H-B 解释。

B1 多尺度零初始化门控残差#5（「ControlNet」）B1 不是 ControlNet：不复制 encoder、不加载 SD 权重、不建侧支路；只是几路 1×1 conv + 门控残差。不新增任何 loss / GAN / VAE / teacher / 分类器引导。但它与 ControlNet-lite 形似，边界应由用户裁定。需裁定
B2 SPADE 式多尺度调制#5不新增 loss / GAN / VAE / teacher / 分类器引导；但替换所有 GroupNorm 是较大的结构改动需裁定
B3 SLICE 式 timestep 注入#5只改 timestep embedding 的输入，不改架构。但见 §8.2：对空间条件不适用不违反
H-A 方案 1（Cocos）#5；且改动 §2.3/§2.7 的设计前提不在禁止清单里。但它把「从纯 N(0,1) 出发」改成「带信息先验」——这是一条设计前提的变更，需用户确认需裁定
H-A 方案 2（CFG + dropout）#5（「分类器引导」）CFG ≠ classifier guidance（前者无额外分类器）。按字面不违反 #5；但需要训练时加 condition dropout，是一处训练改动需裁定
H-A 方案 3（loss 重加权到高 t）#5不新增 loss，只是对同一个 v-MSE 加权重；但改了 §2.6 的训练目标需裁定
H-A 方案 5（条件对比损失）#5（「H 相关 loss」）很可能违反——它就是一个与条件相关的附加损失项很可能违反
T5 与 #6 的冲突，需要用户给一个决定

事实：overfit3 门禁未过（终 loss 0.1233 / val 0.14696），而 §2.8 #6 规定「冒烟测试未过之前不启动长训练」。

但门禁本身已被文档 §3.3 证明是失效的（前两次假阳性的根因是 patch 目标方差太小）。所以这里有三条路，请用户选一条：(a) 用 T1/T3 的结果重新定义门禁（推荐——门禁的本意是「确认管线能学」，而 T1/T3 比 loss 更能回答这个问题）；(b) 显式授权越过 #6；(c) 不跑 T5，只靠 T1–T4 下结论。本报告不替用户选。
