浓度域均值坍缩：InstanceNorm 的精确尺度不变性，与这条路的边界

全量 796 张实测 · 机制证明 · 三个判决实验 · 论文定位 · 2026-10-18

一句话结论

模型不是"每张图都偏了一点"，而是对所有切片输出同一个平均 IHC。而这不是调参失误——CUT 生成器里的 InstanceNorm2d 使整个网络对输入的全局缩放严格不变，切片级染色强度在第一个归一化层就被数学地抹掉了。任何损失、任何权重、任何数据量都无法恢复它。

但这也意味着：信息原本在输入里，只是被结构销毁了——所以这条路的边界是"结构"而不是"任务"，有解，只是要动结构。

顺带修正一个口径

真值 D/H 的全量 median 是 0.804，之前 12 张样本给出 0.767，二者接近，说明小样本这次没有带偏。
但"总量之比 ΣD/ΣH"口径给出的是 1.11–1.25，与中位数口径差 40–55%。论文里必须固定用"逐图中位数"这一口径，并在方法节写明估计量——否则同一个模型能被算出两个相差 50% 的偏差。

2机制：IN 的尺度不变性是严格的，不是"大概"

这一步值得单独写，因为它是可证明的，不是经验观察。CUT 的 ResnetGenerator 第一层是：

stem: x → ReLU( InstanceNorm( W7×7 * x + b ) )

InstanceNorm 对每个样本、每个通道，在空间维度上减均值除标准差。于是对任意 a > 0：

mean(a·y + b) = a·mean(y) + b
(a·y + b) − mean = a·( y − mean(y) )
std(a·y + b) = a·std(y)
⇒ IN(a·y + b) = IN(y)

也就是说 stem(a·x) ≡ stem(x)，逐元素相等。后面的下采样、6 个 ResBlock、两次上采样、head 全部接收完全相同的张量，因此：

G(a · x) ≡ G(x)，对任意 a > 0

这条等式意味着什么

切片级染色强度在输入里是以"全局缩放"形式存在的：这张片子染得深，C_H, C_E 整体乘一个大数；染得浅，整体乘一个小数。而 G 对全局缩放严格不敏感。

所以模型不是"学不会逐图自适应"，而是在结构上不可能做到。D/H 的 IQR 窄 20 倍，是这个等式在 796 张图上的直接体现。

注意 ResBlock 的 out = x + conv_block(x) 里那条 identity 不经过 IN——但 x 本身已经是 stem 的 IN 输出，尺度早被消掉，所以整条链上没有任何一处保留全局尺度。

10 秒验证（比任何论证都硬）

import torch
x  = batch['A']                                  # [1,2,H,W]
y1 = netG(x)
for a in (1.5, 0.7, 3.0):
    y = netG(x * a)
    print(a, (y - y1).abs().max().item())        # 预期 ≈ 1e-6（浮点误差）

如果三行都接近 0，这个机制就坐实了。同时也要跑官方 3ch 权重——它用的是同一套 normG=instance，按这个推理也应该同样坍缩。若官方不坍缩，说明 RGB 输入里还有一条绕过 IN 的通路（例如通道间比值在 IN 后仍部分保留），那结论要改写。

3为什么"权重越大，坍缩越彻底"

这一点你的 AI 说对了，但原因不是"梯度是全局平均"，而是更直接的：

  • 设 G 的输出与切片无关，记为常数 c。那么对所有 796 张图，分布损失都是 L(c, p_i)。
  • 训练最小化 Σ_i L(c, p_i)，最优解是 p_i 的某个中位/重心 —— 正是观察到的 1.00。
  • 加大权重只是把 c 更精确地推向这个重心，不改变"输出与输入无关"这件事。

换句话说：在 G 是尺度不变的函数类里，常数解就是全局最优。损失再强，也只是让这个常数收敛得更干净。

顺序不能颠倒

实验 1 是机制，实验 2 是可行性。若先做 2 发现 r 很低，会误判成"任务无解"——但实际上可能是结构先把它毁了。必须先证明"结构毁了它"，再去问"原本有没有信号"。

5如果实验 2 有信号：最小结构改动

核心约束：注入点必须在最后一次归一化之后。生成器里 stem / down1 / down2 / 6×ResBlock / up1 / up2 每一层都带 InstanceNorm，任何在这些位置注入的尺度都会被下一层 IN 立刻抹掉。

先更正两个看起来自然、实际无效的做法

① 只去掉 stem 的 IN —— 尺度活过 stem，但死在紧随其后的 down1 的 IN 上。
② 在瓶颈 ResBlock 后做 FiLM —— 尺度活过瓶颈，但死在 up1 的 IN 上。
两者都只改了一个环节，而下游还有 4 次归一化。这是本节最容易走错的地方。

正确位置：up2 的 ReLU 之后，head 的 Conv7×7 输出上，Tanh 之前——这是全网络最后一次归一化的下游。

# 1) 切片级染色量：在 stem 之前取，此时还没被任何 norm 处理
s = (x[:, 0] + x[:, 1]).mean(dim=(1, 2))        # [B]

# 2) head 处做增益/偏置，零初始化 → 起步严格恒等
class ScaleHead(nn.Module):
    def __init__(self, ngf, out_c=2):
        super().__init__()
        self.conv = nn.Conv2d(ngf, out_c, 7, padding=3)
        self.fc   = nn.Linear(1, out_c * 2)
        nn.init.zeros_(self.fc.weight); nn.init.zeros_(self.fc.bias)
    def forward(self, h, s):
        logits = self.conv(h)
        g, b = self.fc(s[:, None]).chunk(2, dim=1)          # [B,out_c] each
        return torch.tanh(logits * (1 + g[:, :, None, None])
                                + b[:, :, None, None])

净增参数约 4 个（fc 的 4 个，替换原 head 卷积不增加）。零初始化保证从现有权重热启时输出逐元素不变，坍缩会原样保留到第一个梯度步——这反而是好事：说明改动本身没有副作用，后续任何变化都能归因给它。

两个前提必须先确认

① 数据加载器有没有对输入做逐图归一化（per-image 分位缩放、均值归一等）。如果有，s 在进网络前就已经是常数，这个 token 拿到的也是常数，等于没加。必须查 aligned_dataset 的浓度域预处理。

② s 与目标的相关性（实验 2）。若 r≈0，加了也是白加。

6论文：这个结果反而让故事立起来了

先说结论：原来的框架（2 通道 + CGA + 比值损失，靠指标涨点）确实撑不住主会。但这次坍缩的发现，把可写的东西换成了三件更硬的事。

#可写的贡献证据强度
A机制：CUT 系虚拟染色生成器的 InstanceNorm 使其对切片级染色强度严格不敏感，逐图自适应在结构上不可能数学证明 + 796 张实测
B表征价值：浓度域输出把"颜色偏了"这种肉眼判断，变成可逐图测量的 D/H 分布；RGB 输出下这个失效是隐形的恒等映射对照 + 全量分布
C修法：绕过 IN 的尺度条件（FiLM token）恢复逐图自适应，并给出增益与边界待跑（实验 2/3 之后）

关于"2 通道算不算创新"

单独不算——OD 近似一维（PC1 占 96%），信息量几乎没增加，审稿人一句"为什么不用 RGB"就能问住。

但它有一个真实的方法论价值，而且正好是这次发现的：它让一个原本不可见的失效变成可测量量。RGB 输出只能看出"偏黄"，看不出"796 张的 D/H 全挤在 1.00"。这是可以写进 motivation 的，比"浓度域更有物理意义"这种口号硬得多。

指标必须换

BCI 是相邻切片，edgeCorr(真值, HE) = 0.027，等于没有配准。在这个前提下 PSNR/SSIM 度量的是"碰巧像不像那张错位的图"，不构成证据。建议改成：

  • 逐图归一化后的 DAB 空间图案一致性（每张图先按自身强度归一，再比空间分布）
  • 阳性面积占比与 H-score 类统计（临床 IHC 评分本来就是相对该片自身强度）
  • FID / KID（分布级，不需要配准）
  • 绝对强度不可推断 —— 作为 limitation 明确写出来，而不是藏起来

7边界：能做什么，不能做什么

能做不能做
把全局平均水平拉到接近真值（D/H 1.00 vs 0.80、DAB 0.18 vs 0.15，均差约 20%） 在现有结构下实现逐图自适应（被 IN 严格禁止）
证明"失效来自结构而非数据"，并给出可复现的验证方法 靠调损失权重改善坍缩（权重越大越彻底）
用尺度 token 恢复逐图可调性（若实验 2 有信号） 在未配准数据上用 PSNR/SSIM 主张质量提升

留给下一步的一句话

先跑实验 1（1 分钟）和实验 3（几分钟），把"这是结构必然、且是谱系共性"钉死。这两条一旦成立，论文的核心结论已经拿到了，剩下的只是修法与增益。若实验 2 的 r 也很高，那 C 也能补上，故事就完整了。
