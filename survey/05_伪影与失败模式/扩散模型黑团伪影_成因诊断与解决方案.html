扩散模型「黑团」伪影 · 成因分类、诊断流程与解决方案

针对 H&E→IHC 虚拟染色中出现的 2–3 处明显黑团，横向调研通用扩散模型生成领域的同类失败模式

调研日期 2026-10-03更新 2026-10-04（实测反馈收窄）症状：2–3 处离散黑团覆盖 8 类成因含 12 步诊断决策树已核对 arXiv / GitHub / Nature / 厂商技术文档

0先给结论

最关键的一条判据：2–3 个「离散」黑团，几乎排除了全局性成因

这条判断决定了排查方向

你描述的是「明显的黑团，2-3 个」——数量少、位置离散、局部性强。这个形态本身就是一个强约束：

  • 全局性成因会均匀地毁掉整张图，不会只留 2–3 个团。CFG 引导过强、噪声调度无零终端 SNR、采样步数不足，这些问题的表现是全图过饱和 / 对比度异常 / 细节糊，而不是几个孤立黑团。所以它们大概率不是你的主因。
  • 离散的少数黑团指向「局部机制」：潜空间某个位置解码失败、某几个 patch 语义损坏、或某个特定区域触发了幻觉。这类问题的共同特征是定位性——它们只影响图像的某一小块。

因此我把成因按「是否具备定位性」重新排序，而不是按文献热度排序。最可疑的前三名：VAE/潜空间解码失败、DiT 异常 token、结构幻觉（OOD 条件区）。

→ 2026-10-04 更新：用户实测已确认第一项（A1/A2），并排除了 A3（fp16 溢出）。请看 第 7 节 的方案收窄。

1先分类：黑团长什么样，对应什么机制

排查前先给伪影做形态学分类。不同形态几乎一一对应不同机制：

形态外观特征最可能的机制关键鉴别点
离散深色团块2–5 个孤立暗块，边界较清晰，内部无结构潜空间解码失败 / 异常 token换个 seed 是否还在同一位置？在 → 条件相关；不在 → 采样相关
假细胞团暗块看起来像密集细胞核或淋巴细胞聚集结构幻觉该处 H&E 输入是否本身异常/罕见？
模糊暗晕暗块边界模糊，像污渍晕开数据学到的污渍/褶皱/DAB 沉淀真实 IHC 同位置是否也有暗斑？

2通用扩散模型的成因

这一节是横向调研的收获——同样的黑团在其他生成领域早已被系统性报告过，机制是通用的。

A · 解码器与潜空间（最高频的成因）

A1 · VAE 解码器黑团 —— 有据可查的经典问题
CompVis/stable-diffusion Issue #384（2022）· 至今未彻底关闭
定位性 高频

报告原文描述：「生成图像时有很高概率出现小的蓝色或黑色团块，在平滑纹理这类简单图像上尤其明显。」报告者在多台机器、多个在线生成器上100% 稳定复现，并且明确指出：换采样器、换步数、调 CFG 基本没有效果。

这句话极其重要——它直接印证了第 0 节的判断：黑团不是采样参数问题。

社区验证的修复路径：

  • 换成重新微调的 VAE（vae-ft-mse-840000-ema-pruned）→ 报告者实测「明显改善，大多数情况下已不再明显」
  • 但纹理类图像仍然顽固——说明 VAE 修复是缓解而非根治
  • 有用户用负向提示词 blue spot, blue dot 压制——属于 hack，不解决机制

机制解读：VAE 解码器是在编码器输出的潜空间分布上训练的。扩散采样在潜空间里自由游走，会走到编码器从未产生过的区域。解码器对这类「域外潜变量」没有约束，输出就会崩塌成局部异常色块。这与下面的 A2 是同一个问题的两种表述。

A2 · 潜空间「暗区」（Dark Areas）—— 概念性解释
TopVAE, arXiv 2606.13955（2026-06）
定位性

这篇论文提出了一个非常贴切的概念：latent space 中存在「暗区」（dark areas）——采样过程中可达、但解码出来是无效输出的潜空间区域。

原文：「现有 VAE 通常用重建目标学习，这不保证潜空间平滑、有效、可导航……这导致暗区：潜空间中在扩散采样时可达、但解码为不连通或无效结果的区域。」

该文的解法 TopVAE 让解码器在训练阶段就内化结构约束，从而消除暗区，无需测试时修正。效果：QM9 上 FCD-3D 降低 77%。

为什么这篇论文对你重要

它虽然做的是分子生成，不是图像，但给出了你问题的理论骨架：黑团不是「模型画错了」，而是采样点落到了解码器的盲区。这解释了为什么黑团总是局部、离散、无结构——因为它对应潜空间里一个个孤立的坏点，而不是整片坏区域。对策方向也随之明确：要么收紧潜空间（约束采样不越界），要么强化解码器（让盲区变小）。

A3 · fp16 数值溢出 —— 硬边纯黑
madebyollin/sdxl-vae-fp16-fix
半定位性

SDXL 的 VAE 在 fp16 下解码时，内部激活值会超出 fp16 的表示范围（±65504）→ 溢出成 NaN/Inf → 渲染为黑色。社区修复版 sdxl-vae-fp16-fix 的做法是：微调 VAE 以减小内部激活幅度，保持输出质量的同时让 fp16 可稳定运行。

鉴别特征：黑块边界极其锐利、像素值贴 0；强制 fp32 解码后消失。这与 A1/A2 的「有渐变的暗块」不同。

A4 · 解码器的拉回度量畸变
Latent Diffusion Inversion Requires Understanding the Latent Space（CVPR 2026）
定位性

该文指出：LDM 在潜空间里的行为是空间非均匀的——VAE 解码器拉回（pullback）到像素空间的度量，在局部畸变越大的地方，生成/反演越容易出错。这为「黑团为什么出现在某些特定位置而不是均匀分布」提供了又一个解释：畸变大的区域就是脆弱区。

B · 引导与采样（全局性，与你的症状吻合度低，但需排除）

B1 · CFG 引导过强导致过饱和
APG, arXiv 2410.02416（ETH Zürich + Disney Research）
全局性

数学机制（这篇论文讲得最清楚）：CFG 的更新可以重写为

D̂_CFG = D_θ(z_t, t, y) + (w − 1)·ΔD_t
其中 ΔD_t = D_θ(z_t,t,y) − D_θ(z_t,t,y_null)

把更新方向 ΔD_t 按相对于条件预测分解为平行与正交两部分：

  • 正交分量 ΔD⊥ → 提升图像质量（有用的部分）
  • 平行分量 ΔD∥ → 导致过饱和（有害的部分）

平行分量等效于给预测乘上一个 gain > 1 的系数，把像素值往量程两端推：

D_θ + (w−1)·ΔD∥ = [ 1 + (w−1)·‖ΔD∥‖/‖D_θ‖ ] · D_θ

论文进一步证明，CFG 更新等价于在「条件与无条件预测之差的 ℓ₂ 距离」上做一步梯度上升（学习率 γ = w−1），而这个目标函数没有最大值，所以 w 大时会发生任意漂移。

修复：APG（Adaptive Projected Guidance）——投影掉平行分量（η≈0）+ 重缩放限制漂移 + 反向动量。实测：

模型方法FID ↓Recall ↑饱和度 ↓
EDM2-S (w=4)CFG10.420.480.46
APG6.490.620.33
DiT-XL/2 (w=4)CFG19.140.350.37
APG9.340.560.30
SDXL (w=15)CFG26.290.490.28
APG25.350.500.18

关键实现细节（容易踩坑）：投影必须作用在「去噪预测」D_θ 上，不能作用在噪声预测 ε_θ 或其他输出类型上，否则效果与 CFG 几乎一样。推荐 η=0、β∈[−0.75,−0.25]。开销可忽略（SDXL 单张前向 130 ms，引导步骤仅 0.45 ms）。

B2 · 噪声调度没有零终端 SNR
Common Diffusion Noise Schedules and Sample Steps are Flawed, arXiv 2305.08891（WACV 2024）
全局性

常见噪声调度不保证最后一步的 SNR 为 0，且部分采样器实现不从最后一步开始采样。这造成训练与推理的不一致：训练时模型见过的最噪数据仍然残留信号，而推理时喂进去的是纯高斯噪声。

三项修复：① 重缩放噪声调度以强制零终端 SNR；② 用 v-prediction 训练；③ 从最后一步开始采样。这一项在你的 R3 损失报告里已经详细展开过，此处不重复。

C · 架构与注意力

C1 · DiT 异常 token —— 定位性伪影的架构解释
Taming Outlier Tokens in Diffusion Transformers, arXiv 2605.05206（2026-05）
定位性

ViT/DiT 里存在异常 token（outlier tokens）：范数异常大、吸走过量注意力、却几乎不携带局部信息。该文发现这个现象在 RAE-DiT 管线的编码器和去噪器里都会出现，尤其是中间层。

最反直觉、也最有价值的一条发现

「单纯把高范数 token 屏蔽掉并不能改善性能，说明问题不只是几个极端值造成的，而是与局部 patch 语义损坏更相关。」

这句话直接解释了你的黑团：少数 patch 的语义被损坏 → 该 patch 解码成无意义的暗块。因为损坏是局部的、稀疏的，所以表现为2–3 个离散黑团。这也说明「把异常值 clip 掉」这种直觉做法是错的。

修复：Dual-Stage Registers (DSR)——在编码器和去噪器两端都引入 register token（有训练好的就用训练的，没有就用递归测试时 register，去噪器用 diffusion register）。跨 ImageNet 与大规模文生图，均能稳定减少 outlier 伪影并提升生成质量。

D · 训练数据

D1 · 训练数据里的暗色残影被学到
社区实践 + CompVis #384 讨论串
定位性

社区发现：当训练数据里含有水印、文字、logo、深色污点时，模型会学到「某类图像应该带一个暗团」，并在无关位置凭空补出来。这是 SD 早期蓝黑团块的另一个来源。

缓解手段：数据清洗（最难但最有效）、负向提示词（hack）。

对你的直接含义

如果 BCI/MIST 训练集里存在系统性重复出现的暗色伪影（同一台扫描仪、同一批切片、同一个记号笔习惯），模型极可能把它们当成「应该有的东西」而复现。排查方法：统计黑团出现的位置是否与某个扫描仪/批次相关。

3虚拟染色特有的成因

这一节是通用文献不会告诉你的部分——它们是病理图像这个领域独有的。

E · 真实病理图像里本来就有暗色伪影

E1 · WSI 的六类固有伪影
HistoART, arXiv 2507.00044（FDA/CDRH）
定位性

该工具针对全切片图像（WSI）的六类常见伪影：

伪影类型视觉表现与「黑团」的关系
组织褶皱（tissue folds）深色重叠区，因组织层数叠加导致吸收增强高度相关 褶皱在 IHC 里就是深色块
离焦区域模糊、对比度低间接（模糊区易触发幻觉）
气泡（air bubbles）暗色环状或圆形区域相关 可呈暗团
组织损伤撕裂、挤压变形间接
记号笔痕迹（marker traces）深色、高饱和的涂抹块高度相关 笔迹是典型的深色团块
血液污染暗红色弥散区相关

检测性能：微调 UNI 基础模型 patch 级 AUROC 0.995（ResNet50 为 0.977，手工特征为 0.940），在 50,000+ patch、多厂商扫描仪（Hamamatsu / Philips / Leica Aperio AT2）上验证。

为什么这对你是关键信息

这说明「深色团块」在真实病理图像里是常态，不是异常。所以：你的模型产生黑团，可能不是「生成错误」，而是「忠实复现了训练数据里的真实伪影」。这两种情况的处理方式完全相反——前者要修模型，后者要清洗数据。必须先分清是哪一种。

E2 · IHC 染色本身的暗色伪影
IHC/DAB 标准故障排查文档（Thermo Fisher / Boster / 试剂厂商技术中心）
定位性

真实 IHC 切片上就存在多种深色伪影，它们都会被模型当作「正确的目标」学到：

  • DAB 沉淀（precipitate）——显色剂析出形成深棕色/近黑色斑点或团块，是 IHC 最常见的伪影之一
  • 过染（over-staining）——苏木素或 DAB 浓度/时间过度 → 局部死黑
  • 背景染色过高——非特异性结合导致整体发暗
  • 干片伪影——试剂蒸发留下的深色边缘

厂商排查文档给出的根因包括：显色时间过长、抗体浓度过高、封闭不充分、洗涤不彻底、切片干燥等。

对你的直接含义

如果 BCI/MIST 的 IHC 标注图里存在 DAB 沉淀或过染区域，模型会把它们当成目标分布的一部分去学习。尤其是非配对设定——你无法用逐像素损失惩罚它，模型完全有自由在 H&E 上「贴」出这样的暗团。

F · 结构幻觉 —— 最符合「2–3 个离散黑团」的机制

F1 · 条件图像里的 OOD 区域触发幻觉
Tackling Structural Hallucination in Image Translation with Local Diffusion, arXiv 2404.05980（ECCV 2024, UCL + AstraZeneca）
定位性 最贴合

这篇是我认为最贴合你问题的一篇。它把这类失败模式正式定义为 structural hallucination（结构幻觉）：模型生成看起来合理、但结构错误的重建结果。

核心命题：幻觉由条件图像中的局部 OOD（分布外）区域引起。

为什么 OOD 会触发幻觉（论文的理论论证）

  • 标准反向过程估计 p(x_{t−1} | x_t)，它以「部分加噪的数据」为条件，因此是不精确的。
  • 当某区域是 OOD 时，把它与图像其余部分混在一起会产生跨区域干扰：OOD 成分在预测正常区域时充当了「无关噪声」，反之亦然。
  • 论文证明：把估计和条件都按 IND/OOD 分区后能得到更紧的 ELBO 界（ELBO ≤ ELBO_partition）。不分区就会幻觉。

实证证据（很能说明问题）

  • 只在数字 8 上训练的 DDPM，给它一个 3 → 产生幻觉
  • 只在健康脑上训练的 DDPM，给它带肿瘤的脑 → 把肿瘤「修复」成健康组织
  • 边界敏感：「微小的边界调整会导致显著的预测差异」——说明 OOD 定位的准确性至关重要

伪影在反向过程的哪个阶段形成

关键时序发现

幻觉主要发生在反向过程的早期和中期，末期基本不受影响。从更靠近末尾处开始反向过程，能同时改善图像质量与结构准确度（Dice、SSIM 均提升）。这与「模型先捕捉低频结构、再细化高频细节」的规律一致。

修复：Local Diffusion（免训练，可插入任意预训练扩散模型）

  1. OOD 估计——用 PatchCore（单类分类，WideResNet-50 主干）生成条件图像的 OOD 概率图；无需训练、无需 OOD 样本
  2. 分支——把条件拆成 cond^ood 与 cond^ind 两个掩码图，并行跑两路局部生成
  3. 融合——朴素拼接会产生边界伪影，需用融合算子合成（论文 Eq.8），之后反向过程等价于标准 DDPM 采样

  • 采样侧（局部黑团、其余部分正常）→ 潜码局部落到 SD1.5 VAE 未见过的区域 → decoder 输出极端值 ≤ −1 → 被 clamp 成纯黑。

为什么分位数 clamp 只能减半，不能根治

你的 clamp 把潜码限制在「真实 IHC 潜码 0.05%/99.95% 分位」构成的箱体内。它减半而不根治，有四个各自独立的原因——理解这四个原因，才知道下一步该往哪儿改：

① 箱体不是流形

真实潜码分布是一个弯曲、低维、薄的流形；clamp 定义的是一个轴对齐超矩形。

潜码维度是 4×64×64 = 16384 维。在高维空间里箱体体积远大于流形体积——箱内绝大多数点仍在流形外。clamp 只能砍掉「离群到箱外」的部分，箱内的非法点原样保留。

② 全局分位数忽略逐通道各向异性

SD VAE 的 4 个潜通道方差差异很大。用一个跨通道的全局分位数，会让天然小方差的通道即使偏离 5σ 也仍在箱内。

改法：逐通道标准化后再 clamp——z_c ← μ_c + clip((z_c−μ_c)/σ_c, −k, k)·σ_c，k≈3。

③ 末端补救来不及

如果只在解码前 clamp 一次，采样过程中的越界已经影响了后续所有步的走向。

而且 Local Diffusion 的结论是：伪影在反向过程的早期/中期就已形成。等到末端再拉回，轨迹早已走偏。

④ 它约束边缘分布，不是联合分布

clamp 逐维限制取值范围，但潜码的非法性往往体现在维度之间的联合关系上（例如某两个通道的比值异常）。

逐维约束对这种失败完全无效——这是「箱体不是流形」的另一种表述。

小结：clamp 是一个凸的外逼近，它能砍掉明显越界的离群点（这就是「减半」的来源），但抓不住「箱内但非法」的点。要真正解决，必须要么收紧到流形附近，要么扩大流形的覆盖范围。

换句话说——你不需要训练扩散模型，就能先筛掉不合格的 VAE。

具体做法（分层是关键）：

对真实 IHC patch：
  1. z = E(IHC)；ÎHC = D(z)          # 纯 AE 往返，无扩散
  2. 计算重建 PSNR / SSIM
  3. 【分层统计】按该 patch 的 DAB 强度 / 平均光密度分组
       · 低 DAB 组 vs 高 DAB 组，各自的重建 PSNR
  4. 判据：
       若高 DAB 组的重建 PSNR 显著低于低 DAB 组
         → 流形在 IHC 偏离 H&E 最远处最薄 → 坐实根因
       若两组接近
         → 流形覆盖没问题，回头查 F1（结构幻觉）

这一步同时给你一个可量化的 VAE 筛选基线：任何候选 VAE 换进来之前，先在真实 IHC 上量它的 AE 上限。上限低，扩散训得再好也白搭。

Tier 1 · 推理期收紧（改动小，无需重训）

手段改动做法与理由
逐通道标准化 clamp（每步都做）极低把全局分位数换成逐通道 μ±kσ（k≈3），且在每一步去噪后都施加，而不是只在末端。直接修掉「原因②」和「原因③」。约 5 行代码。
事件触发的编码器回投低检测到 x̂₀ 越界时，做 z ← E(D(z))。编码器本身就是一个学到的「投回流形」算子——它把任意图像映到一个解码器能正常处理的潜码。注意诚实地说：这会把硬黑团变成软暗区，是缓解而非修复内容。
潜码低通（3×3 高斯）低解码器崩溃常伴随潜码高频能量异常。对潜码做轻度低通后再解码。理由：真实潜码是空间平滑的，OOD 潜码往往不是。此条为待验证的假设，请自行做对照实验。
区域级物理回退中检测出黑团区域后，该区域改用物理模型渲染（你的 M1 物理输出头 / Beer–Lambert 前向），再与扩散结果融合。逻辑自洽：学习模型失效的地方，正是物理先验该接管的地方。 与你 R2 报告的 M1/M3 模块天然衔接。

Tier 2 · 训练期锚定（改动中，需重训）

潜空间锚定损失 —— 从源头减少越界
原理性修法，实现简单
需重训可复现

思路：既然越界是问题，就在训练时直接惩罚越界的 x̂₀。用真实潜码的逐通道统计量（μ_c, σ_c）做标准化，对超出 k 倍标准差的量加惩罚：

L_anchor = λ · mean( ReLU( |(x̂₀ − μ) / σ| − k )² )     # k ≈ 3

总损失 = L_diffusion + L_PALS + L_PCLS + L_anchor

优点：① 与 PSPStain 原有两个 loss 不冲突，是纯增量项；② 完全可复现（μ、σ 从真实 IHC 潜码统计即可）；③ 可解释（就是「别预测出解码器处理不了的东西」）。

λ 建议先取小值（如 0.01–0.05），观察是否影响生成质量。

Tier 3 · 换 / 微调 VAE —— 文献证明的主导因素

来源：MICCAI 2025 Pathology Image Compression with Pre-trained Autoencoders（arXiv 2503.11591，Stony Brook / Argonne / UChicago）。基座是 stabilityai/sd-vae-ft-ema，即 SD 1.5 VAE（KL-f8-c8）。

为什么它算 drop-in：论文只微调了解码器，编码器完全冻结。原话：「By preserving the encoder, we ensure that the AE latent space is unchanged and we only learn to interpret it differently during reconstruction.」→ 潜码分布不变 → 已有的扩散模型不需要重训，换解码器即可。

arXiv 2604.12152 的核心结论（直接对口你的问题）

论文标题即结论：Domain-Specific Latent Representations Improve the Fidelity of Diffusion-Based Medical Image Super-Resolution（arXiv 2604.12152, 2026-04）。

摘要第一句：「医学图像超分辨的潜扩散模型普遍沿用为自然照片设计的 VAE。我们证明这个默认选择——而不是扩散架构——才是重建质量的主导约束。」

他们做了受控实验：固定其他所有组件（UNet 架构、训练目标、噪声调度、评估协议），只把通用 SD VAE 换成领域特定 VAE（MedVAE，105 万张医学图像预训练）→ PSNR 提升 +2.91 ~ +3.29 dB，Cohen's d = 1.37–1.86，p < 10⁻²⁰（n = 1,820）。

为什么这条结论直接解释了「你的 clamp 只能减半」

该论文做了系统消融：推理调度（T = 50–1000）、预测目标（x₀-prediction vs ε-prediction）、损失权重、生成架构（DDPM vs rectified flow matching）。

结论是：没有任何训练侧或推理侧的改动能接近「换 VAE」带来的提升；SD-VAE 与 MedVAE 的差距在所有消融条件下稳定在 ±0.15 dB 以内。 这正是你观察到的现象——你在采样/解码侧做约束，只能拿回一小部分，因为瓶颈根本不在这里。

一个必须知道的边界条件：换 VAE 治不了幻觉

同一篇论文还有一个容易被忽略但极重要的发现：重建保真度与生成幻觉由相互独立的部件控制。 换 VAE 后 PSNR 涨了约 3 dB，但两者的幻觉率相当（Cohen's h < 0.02，跨全部数据集）。

Tier 4 · 绕开（架构级，成本最高）

像素空间扩散

完全不用 VAE，直接在像素空间做扩散 → 整类问题从原理上消失。

代价：显存与采样时间显著上升；病理 patch 分辨率高，代价更明显。

注意：你刚精读的 Star-Diff 的公式 x_t = x₀ + ᾱ_t·ε + β̄_t·I_res 是直接在图像空间写的（I_res 由图像相减得到），这条路线天然规避了潜空间问题。

混合路线

潜扩散出主体 + 像素空间精修只处理被标记的异常区域。

兼顾效率与稳健性，但管线复杂度上升——按你的优先级（可复现 > 改动小），这条应排在最后考虑。

必须提醒的一个陷阱

你的 clamp 可能把「可检测的失败」变成了「不可检测的失败」

你现在的 clamp 让黑团「减半」。但剩下的那一半可能因为幅值被压小而变得更不显眼——但它并没有被修复。

如果 clamp 把伪影压到了你的质检阈值以下，你就把一个能被眼睛发现的失败变成了一个只有对照真实 IHC 才能发现的失败。对临床可信性而言，这比留着明显的黑团更危险——因为它绕过了你自己的质量把关。

建议的配套动作：clamp 的同时记录被 clamp 的像素比例与区域位置，把它作为一项指标输出。这样「减半」是一个可观测的改进，而不是一个被隐藏的退化。这条也正好落实 §6 里「把伪影检测接进评价体系」的建议。
