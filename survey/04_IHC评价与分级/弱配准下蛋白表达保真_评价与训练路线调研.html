0先给结论

一句话判定

在 H&E/IHC 不是严格像素配准时，“蛋白表达保真”不应定义为逐像素相等，而应定义为固定染色量化体系下的多层保真：全局/区域表达分布 + 形态条件下的表达规律 + 区域之间的排序关系 + 阳性区域的空间组织统计。

最值得先做的路线

Route A：表达分布保真 MVP。在 fixed M、fixed X0、fixed DAB/OD 量化后，对 ROI/patch 集合比较 DAB-IOD、分位数、阳性比例、H-score 代理量和分布距离。它最容易复现、最不依赖配准，适合先验证“指标能否区分好坏”。

最有论文潜力的路线

Route B+C：形态条件的表达关系保真。用 morphology embedding 定义可比较区域，再约束表达排序/相对关系，同时保留 PALS/PCLS。它比单纯 H-score 更有科学问题，但必须防止“相似形态 = 相似蛋白”的过度假设。

必须先修正的认识

最新直接相关工作已经出现：2026 年预印本 Topology-aware Pathological Consistency Matching for Weakly-Paired IHC Virtual Staining 用图拓扑、PageRank 和 correlation matching 处理弱配对。但它仍以同索引节点作为 InfoNCE 正样本，不是完全 correspondence-free。因此“拓扑/图方法尚无人做”已经不能成立；真正的空缺是不制造假对应的表达保真基准与训练/评价协议。

对当前项目的直接决策

不建议现在先上 Gromov-Wasserstein、复杂 graph network 或大量 topology loss。先做：fixed M/X0 → Route A 只评价 → 一个 distribution loss → 再做 morphology-conditioned ranking。若 Route A 已能区分模型，OT 不必要；若 Route A 不够，再引入 soft correspondence。

1问题重新定义：从 pixel correspondence 到 expression fidelity

连续切片、染色、扫描、裁剪和局部形变会让真实配对关系变成“有粗粒度对应，但细胞级坐标不可靠”。因此，下面两个命题不是同一个问题：

错误的强命题：   EHE(x,y) = EIHC(x,y)
可研究的弱命题：   P(E | M)virtual ≈ P(E | M)real，并保持表达区域的关系与空间统计

其中 E 是固定染色空间中的 DAB/表达代理量，M 是组织形态或病理语义。注意：IHC 的 DAB-OD、H-score、阳性比例都是染色代理量，不是未经实验校准的绝对蛋白丰度。

3三个核心概念：分布、形态条件、关系

3.1 Route A：Global / regional distribution fidelity

这是最不依赖配准的一层。真实和虚拟图像不要求阳性区域在同一坐标出现，而要求同一病例/ROI/patch set 的表达统计一致。

E = DAB(M, X0, IHC)；   Ldist = D(P(Ereal), P(Evirtual))

可用的 D：Wasserstein-1、MMD、energy distance、JSD、histogram distance、quantile loss。推荐先比较：

  • mean / median / Q1 / Q3 / P90 / P95；
  • DAB-IOD、mIOD、positive area ratio；
  • 弱/中/强表达比例；
  • 固定阈值下的 H-score 代理量；
  • 病例/ROI 层面的 Spearman、ICC、Bland–Altman。
为什么 Route A 适合当前项目

PSPStain/PALS 已经提供 FOD/平均/直方图/block 的蛋白表达监督；E0.3 已经证明 M、X0 和 DAB 量化必须固定。Route A 只需把现有 PALS 从“某个相同位置的 FOD”扩展为“同一病例/ROI 集合的分布距离”，改动最小、最可复现。

3.2 Route B：Morphology-conditioned expression fidelity

Route B 不按坐标找对应，而按 H&E morphology/pathology embedding 找“可比较区域”。形式上：

mh=fHE(h)，mi=fIHC(i)，wij ∝ exp(sim(mh,i,mi,j)/τ)

然后比较软匹配后的条件分布：

P(E | M=m)virtual ≈ P(E | M=m)real

关键风险是：morphology 相似不等于 protein expression 相似。形态 embedding 只能提供弱对应候选，不能被写成蛋白真值。要控制这个风险：

  1. 用 morphology 只定义候选集合/权重，不直接把它当表达标签；
  2. 同时要求全局表达分布和病例级 ranking；
  3. 报告匹配置信度与低置信区域，不强行监督；
  4. 做 morphology-shuffle 反例，检验模型是否真的利用了形态条件。

3.3 Route C：Relational / ranking fidelity

当绝对位置不可靠时，区域之间的关系可能比坐标更稳定。对于同一病例内具有可信 ROI 定义的区域：

Ereal(A) > Ereal(B) ⇒ Êvirtual(A) > Êvirtual(B)

训练可用 pairwise logistic ranking loss：

Lrank=log(1+exp(-sAB(ÊA-ÊB)))， sAB=sign(EAreal-EBreal)

也可用 Spearman/Kendall 作为评价，但不要直接把 Spearman 当训练 loss。排名信号的前提是 A/B 的区域身份可靠，例如 tumor core / tumor edge / stroma、人工标注 ROI、同一病例多 ROI 或 pathology graph 节点。

Route C 的真正限制

如果 A/B 只是两张完全不相干的切片 patch，排序没有意义；如果排序来自同一个染色矩阵错误或阈值错误，它也会把量化偏差当成真关系。因此 ranking 必须在 frozen M/X0 和可信 ROI 之后做。

3.4 Route D：Soft correspondence / Optimal Transport

OT 把 one-to-one 对应改成 transport matrix：

T* = argminT∈Π(a,b) ⟨T,C⟩ + ε·H(T)

其中 C 可由 morphology feature distance、表达差异和空间代价组成。Wasserstein/ Sinkhorn 适合两个点集位于同一 feature space；Gromov-Wasserstein 更适合两侧内部关系可比、但节点 feature 空间不完全同构的情形。

但当前调研没有找到一篇已经把 Gromov-Wasserstein + weakly paired H&E→IHC virtual staining 做成成熟、可复现的主方法。检索到的最新工作主要是 graph/topology matching 或一般 semantic correspondence，不足以证明 OT 在当前数据上必要。

决策

OT 不作为 MVP，也不作为第一版训练 loss。先把它做成评价器：比较 Route A/B 的失败样本是否确实存在可解释的软对应；只有普通 distribution + ranking 已经不够时，再上 Sinkhorn。Gromov-Wasserstein 放到最后，因为计算和调参成本最高。

4表达空间结构：拓扑、聚集与图

蛋白表达不仅是一个总分。成片高表达、散在阳性细胞、边缘富集和局部聚集，即使发生平移或形变，也可能保留统计结构。

TA-GAN 的启示与边界

2026 年 TA-GAN 是本次最直接相关的新工作。它把 patch feature 建图，用 cosine similarity 建邻接，用 GNN 聚合，再做 topology-aware InfoNCE；TCPM 用 PageRank 增强重要节点，再匹配 virtual/real IHC 的 correlation matrix。它还报告 DAB positive-area ratio、ICC 和 regression slope。

但它的 InfoNCE 正样本仍是同索引 s_i ↔ g_i，所以它是topology-tolerant weak pairing，不是没有 correspondence 假设。对当前项目的正确迁移是：

  • 借鉴 graph statistics 作为评价，不立刻复制 GNN loss；
  • 若训练，正样本改成 local candidate set / confidence-weighted soft positive；
  • TCPM 的 PageRank 不能直接解释为“阳性区域”；需要用独立 DAB/病理标签验证 PageRank 是否真的富集 marker-positive 区域；
  • 不把 FID/KID 改善直接说成蛋白保真改善，必须报告 DAB-IOD/positive ratio/ICC。

6最终只保留三条候选路线

Route A · Fixed-physics distribution fidelity 推荐先做 / MVP
核心：不要求空间对应，比较 DAB-IOD / FOD / 分位数 / 阳性比例 / H-score 代理的集合分布。

数学： L_expr = W1(P_real(E), P_virtual(E)) 或 MMD/JSD；病例/ROI 评价用 MAE、ICC、Spearman、Bland–Altman。

输入输出：输入真实与虚拟 IHC 的 ROI/set；输出每个 ROI 的 expression statistics 与分布距离。

训练位置：先作为 PALS/FOD 的 set-level extension；不需要逐像素 GT。

优点：改动小、可复现、最不依赖配准；直接兼容 fixed M + 2-channel concentration + Beer–Lambert。

缺点：可能出现“总量对但阳性区域放错”；需要 Route C/空间统计补足。

额外标注：无新增标注；最好有 ROI/病例划分。

成本/复现：低 / 高；numpy/PyTorch 均可实现。

创新性：单独作为 loss 创新中等；作为弱配准 protein-fidelity protocol 很实用。

Route B+C · Morphology-conditioned relational fidelity 主线候选
核心：形态 embedding 给候选区域，ranking/relational loss 保持表达高低关系；不把形态当蛋白真值。

数学： w_ij ∝ exp(sim(m_h,i,m_i,j)/τ)；L_rank = log(1+exp(-s_AB(Ê_A-Ê_B)))；评价用 Spearman/Kendall + conditional distribution distance。

输入输出：H&E morphology feature、真实 IHC DAB/表达代理、虚拟 DAB；输出 soft candidate matching、ROI expression ranking。

训练位置：在 PALS/PCLS 之后加低权重；先只在可靠 ROI/病例内做 pairwise ranking。

优点：直接回答“形态条件下表达保真”；比单一 H-score 有更清晰的科学问题；与 marker-conditioned diffusion 兼容。

缺点：morphology ≠ protein；ROI 构造和排序质量决定成败；需要负对照与 shuffle ablation。

额外标注：最好有 tumor/core/edge/stroma 或 region labels；可先用现有 pathology embedding + 弱 ROI。

成本/复现：中 / 中；需要稳定 foundation feature 与候选搜索。

创新性：高于单纯 histogram，但必须诚实命名为 weak/conditional fidelity，不称 causal disentanglement。

Route D · Soft correspondence / OT 后置研究路线
核心：用 Sinkhorn/Wasserstein/FGW 建模候选集合间的 transport，而不是 hard matching。

数学： T*=argmin_T <T,C>+εH(T)；FGW 再加入两侧内部关系 cost。

输入输出：两侧 patch/cell/region feature sets；输出 transport matrix、matching confidence、set distance。

训练位置：先 test-time evaluation；只有 Route A/B 失败样本证明需要 soft matching 时再反传。

优点：理论上最贴合“不知道谁对应谁”；可以保留 feature 与内部关系。

缺点：计算复杂、成本高、容易把错误的 feature similarity 优化成假对应；当前没有找到成熟 H&E→IHC diffusion 先例。

额外标注：不一定需要，但需要合理的 feature cost、mass 和 ROI 设计。

成本/复现：高 / 中低。

创新性：数学上新，但不能因为“高级”就先做；必须由 Route A/B 的失败证据驱动。

训练：L = L_diff + λ_PALS L_PALS + λ_PCLS L_PCLS + λ_dist W1(P_real(DAB),P_virtual(DAB))；初始只在病例/ROI level 计算，不做同坐标 pixel loss。

关键指标：H-score proxy MAE/ICC/Spearman；DAB-IOD MAE；DAB histogram JSD/W1；阳性比例差；AQuA/black-block/clamp fraction。

通过条件：新增机制至少改善表达层 2 项指标，且不显著恶化结构、伪影和 uncertainty；若只有 PSNR 改善，不算通过。

8当前数据适配、现有项目结论与风险

8.1 不能直接套用“完全不配准”假设

当前 BCI 子集的实测事实

现有 `registration_check.py` 对预处理 BCI 子集检查：核信号 cross-correlation 在 ±40 px 搜索中，12 对里 11 对峰值正好在 `(0,0)`，1 对为 `(+3,0)`；峰值 0.73–0.98。错配控制不在 `(0,0)`。因此这一子集可能接近像素配准，full-resolution L1 并非原理上不可用。

但这是 StainFuser-preprocessed BCI subset，不能自动推广到 raw BCI、其他批次或 MIST。正确做法不是预设“都错位”或“都对齐”，而是按 registration confidence 分层：

registration check
  ├─ high confidence / peak near zero
  │    └─ 可报告 pixel/patch 指标，但不能外推为所有数据
  ├─ moderate confidence / small displacement
  │    └─ neighborhood / confidence-weighted feature loss
  └─ low confidence / missing tissue / deformation
       └─ distribution + ranking + topology evaluation；不做 raw pixel loss

8.2 当前项目已有结论如何接入

  • 固定 M/X0 是前置：E0.3/E0.3b 已证明 stain matrix、white point 和 log convention 会系统性改变 DAB 与 H-score；任何 Route A/B/C 都必须在同一 frozen 物理空间中比较。
  • PALS/PCLS 不应删除：Route A 应优先复用 PALS/FOD，Route B/C 应明确与 PCLS 的 prototype/pathology semantics 区分。
  • 不把 H-score 当唯一目标：H-score 只回答总量/分箱代理；必须加 distribution、ranking 或 spatial organization。
  • 不把 topology 直接当蛋白 truth：TA-GAN 的 PageRank/topology 是有启发性的弱监督，但 graph importance 需要独立验证，不能自动命名为 positive-expression map。
  • HER2 是膜染色：结构条件不能只喂 H；要保留 E/膜/胞质形态信息，否则会损害 HER2 相关结构。

9最终决策

对最终科研问题的回答

对于弱配准 H&E→IHC，蛋白表达保真应定义为：在统一 fixed stain/OD 量化体系下，虚拟 IHC 与真实 IHC 的全局/区域表达分布一致，并在可比较的形态条件下保持表达规律、相对排序和阳性区域的空间组织统计；它不等于逐像素颜色相似，也不等于绝对蛋白丰度。

问题当前结论对项目的行动
是否从 pixel consistency 转向 distribution fidelity？是，但不能停在 distributionRoute A 先做；再补 ranking/spatial stats
是否需要 morphology-conditioned expression？值得做，是主线候选；但 morphology 只是弱对应Route B 在 MVP 后做，加入 shuffle negative
ranking 是否比坐标更可靠？在可信 ROI/病例内，很可能；文献直接系统化仍少用 Spearman/Kendall + pairwise loss 验证
是否需要 MIL/set matching？适合 weak correspondence；先用 set distribution，不要立刻 DeepSets/复杂 attention先评价，后训练
OT/GW 是否必要？目前没有必要证据；是后置路线只有 A/B 失败才做 Sinkhorn/GW
空间表达能否拓扑评价？可以做统计拓扑/图统计，不做 node-by-node 对齐作为独立评价层；TA-GAN 是近邻先例
哪些与 StainFuser 兼容？fixed M、PALS/PCLS、distribution、ranking、第三方 evaluator 兼容不动主干，先接 output/feature-side
最简单且可写进论文的创新？Route A MVP + Route B/C 机制扩展先证明指标有用，再加训练约束
我给你的明确建议
  1. 第一步：只做评价，不改模型。用当前 96 张 BCI 子集、fixed M/X0，验证 distribution、ranking、topology 能否区分“好模型”和构造的坏模型。
  2. 第二步：只加一个 distribution loss。保留 PALS/PCLS；优先 histogram/Wasserstein/MMD，不要同时加入 OT/graph/foundation model。
  3. 第三步：如果 Route A 不够，再做 morphology-conditioned ranking。把它作为真正的论文方法候选，明确写“弱对应候选”，不写“形态等于蛋白真值”。
  4. 第四步：OT/GW 最后。除非实验显示 distribution + ranking 仍不能解释错位关系，否则不承担它的计算和复现成本。
一句话止损

如果一个新增机制只让 PSNR/SSIM 变好，却没有改善 DAB-IOD、表达分布、ranking、空间统计、临床 evaluator 或 AQuA/uncertainty 中的至少一层，就不要把它称为“蛋白表达保真提升”。
