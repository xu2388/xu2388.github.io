01结论速览

如果你只看一屏，看这一屏。

核心判断

这是一个连续三年、目标明确、代码全开源的虚拟染色专攻团队，而且他们已经有三篇工作直接踩在你 PSP-Diffusion 的关键假设上——但没有一篇是在浓度空间做生成的。

具体地：他们的 PSPStain / PGVMS 已经大量使用光学密度（OD）——FOD 聚焦光密度图、COD 累积光密度曲线——但只用 OD 做监督信号和评价指标，生成仍在 RGB 空间。他们的 ContiStain 正在正面解决"新 marker 陆续到来怎么不退化"，用的是持续学习蒸馏，不是物理参数解耦。他们的 USIGAN 已经在用光密度 + 最优传输处理弱配对。

维度他们的状态对你意味着什么
技术路线 主线是 GAN（CUT / ASP 血统），只有一篇扩散（AAAI'25，且是免训练的提示反演） 你的扩散路线是差异化的。但要注意他们随时可能转向扩散
光学密度 深度使用：FOD 图、COD 曲线、OD 一致性损失、ImageJ/Fiji 算 OD 他们已经在 OD 空间边缘，但没进去。你"在浓度空间生成"的想法是他们这条线的自然下一步——目前仍无人占坑
多染色 PGVMS 已做 4 个 marker 统一框架（HER2/ER/PR/Ki67），只用 uniplex 训练数据 只做 H+DAB 单染色会显得单薄。必须对标 multiplex 设定
跨域/持续 ContiStain 用持续学习解决新 marker 顺序到来、旧数据不可得 他们的解法是重训/蒸馏；你的 RDCS 是物理参数解耦（换 S 不重训）——完全不同的解法，且更优雅，可以正面打
错位处理 PCLS 原型一致性（跨图对齐，不逐像素）、USIGAN 用 UOT 剔除弱配对项 他们的思路是"不依赖位置对应"，与你的轴 4（桥式扩散）可以对照
工程完备度 代码全开源 + HuggingFace 权重 + 在线 demo + 百度网盘数据 对标门槛被抬高了，你的工程完备性必须跟上
一句话

这个团队是最直接的对标对象——他们做的事和你高度重叠，他们的技术栈比你保守（GAN 为主），但他们的数据、指标、评测协议、工程规范都已经成熟。你要做的不是绕开他们，而是站在他们的评测体系上，用他们没用的方法（扩散 + 浓度空间 + 物理解耦）打他们的短板。

03研究主线时间轴

从 GAN 单染色 → 多染色统一框架 → 持续学习，中间分岔出扩散线与最优传输线。

2022 – 2023
数字病理基础工作期
多倍率相似性学习（JBHI 2023）、肝癌区域弱监督检测（Am J Pathol 2022）、病理+基因多模态预后（Genes 2022）。这一阶段还没做虚拟染色，做的是病理图像分类/检测/预后。
2024.07
PSPStain · MICCAI 2024
虚拟染色方向的起点。提出 PALS（蛋白质感知学习，含 FOD 聚焦光密度图）+ PCLS（原型一致学习）。基于 CUT + ASP。首次把"分子级语义"与"空间错位"作为两个核心问题正面处理。
2024.12
StainPromptInversion · AAAI 2025
分岔出扩散线。熊兵主导。用双路径提示反演做无配对多域虚拟染色，只优化 null visual prompt，不微调预训练模型。实现内容-风格完全解耦。
2025.07
USIGAN · IEEE TIP 2026
分岔出最优传输线。彭越、熊兵主导。用非平衡最优传输 + 光密度 + 自信息处理"弱配对"（weakly paired）问题，从联合边缘分布中剔除弱配对项。提出 UOT-CTM 与 PC-SCM 两个机制。
2026.02
PGVMS · IEEE TMI 2026
PSPStain 的期刊完整版，也是主线的重大升级。引入 CONCH 病理视觉语言模型做自适应提示引导，实现统一的多重 IHC 染色框架（HER2/ER/PR/Ki67），仅用 uniplex 训练数据。PALS 与 PCLS 均被强化。上线在线 demo。
2026.07
ContiStain · MICCAI 2026
转向持续学习。解决"新 biomarker 陆续到来、旧域样本不可得"的灾难性遗忘问题。用 teacher-student 蒸馏 + 域感知 MoE 特征提取器 + 跨域余弦关系矩阵保持。MIST 四域顺序学习（HER2→ER→PR→Ki67 等多种顺序）。
主线的演化逻辑

他们的路线可以概括为：「先解决"像不像"（PSPStain 的蛋白质语义）→ 再解决"能不能一个模型染多种"（PGVMS 的 prompt 统一）→ 最后解决"新染色来了怎么办"（ContiStain 的持续学习）」。每一步都在往更实用、更接近临床部署的方向走。这个演化路径本身就说明了这个领域的真实痛点在哪里——不是"生成质量不够好"，而是多域扩展性与部署成本。

04六篇核心工作逐个拆解

每篇：做什么、关键机制、数据集、代码。

1. PSPStain MICCAI 2024 · arXiv 2407.03655 起点
全称
Pathological Semantics-Preserving Learning for H&E-to-IHC Virtual Staining
作者
Fuqiang Chen, Ranran Zhang, Boyun Zheng, Yiwen Sun, Jiahui He, Wenjian Qin
代码
github.com/ccitachi/PSPStain（权重在百度网盘 / Google Drive）
基础
建在 CUT（对比无配对翻译）与 ASP（自适应监督 PatchNCE）之上 —— GAN 血统
数据
BCI（乳腺癌 HER2）+ MIST

两个核心机制

机制解决什么怎么做
PALS
蛋白质感知学习		 保持蛋白表达水平的一致性（分子级语义） 核心是 Focal Optical Density (FOD) 图——聚焦光密度图。用光学密度量化蛋白表达，自动聚焦高表达区域，避免正常组织干扰。
PCLS
原型一致学习		 空间错位下的病理语义对齐 跨图像的原型一致性学习，增强语义交互。关键是它不依赖逐像素对应——学"哪些区域应该表达蛋白"，而不是死记像素位置。
注意这里

PSPStain 已经用光学密度（OD）了——但用法是"用 OD 量化蛋白表达，作为损失的一项"（FOD 图进 PALS）。它的生成仍然在 RGB 空间。这是理解这个团队和你差异的关键点：他们在 OD 空间门口，但没走进去。

2. PGVMS IEEE TMI 2026 · arXiv 2602.23292 主线主力
全称
PGVMS: A Prompt-Guided Unified Framework for Virtual Multiplex IHC Staining with Pathological Semantic Learning
作者
Fuqiang Chen, Ranran Zhang, Wanming Hu, Deboch Eyob Abera, Yue Peng, Boyun Zheng, Yiwen Sun, Jing Cai, Wenjian Qin
代码
github.com/ccitachi/PGVMS
Demo
pgvms.qin-mixlab.cn（上传 H&E，选 PR / Ki67 / HER2 / ER 生成）
数据
MIST + IHC4BC（后者的多域：HER2/ER/PR/Ki67 混为一个数据集，用文件名后缀标域）
基础
CUT + ASP + CONCH（病理视觉语言模型）

它是 PSPStain 的期刊完整版，但扩得非常厉害。论文明确针对三个挑战给出三个创新：

挑战创新做法
1 自适应提示引导
Adaptive Prompt Guidance		 用病理视觉语言模型（CONCH）动态调整染色提示。让模型"读懂医学语境"——理解 HER2 该出现在细胞膜、ER/PR 是核内标志物、Ki-67 标记增殖细胞核。
2 PALS 强化版
Protein-Aware Learning		 直接量化并约束蛋白分布。用光学密度量化表达水平（0/1+/2+/3+），用 FOD 图自动聚焦高表达区。
3 PCLS
Prototype-Consistent Learning		 建立跨图像语义交互，纠正空间错位。同样是不依赖逐像素对应。

最值得注意的三点

  • 只用 uniplex 训练数据就能生成 multiplex。这是它的核心卖点——现实中多重染色的配对数据几乎拿不到，但单染色（uniplex）配对数据有。他们用"混域 + 提示切换"绕过了这个限制。论文称其为"从专用单任务模型向统一虚拟染色系统的范式转变"。
  • 跨癌种泛化。仅用少量数据微调，就扩展到乳腺癌、结直肠癌、肝癌、鼻咽癌、头颈癌五类病变组织与免疫标志物染色。
  • 病理专家盲评。在细胞定位、染色异质性、染色强度三项指标上均达临床可接受水平（>3 分 / 5 分制）。这是临床可信度的硬证据，很多方法学论文没有这一项。
他们的评价指标里有 COD 曲线

PGVMS 用 累积光密度（Cumulative Optical Density, COD）曲线做统计比较，报告"虚拟染色结果与真实染色曲线几乎重合"。这再次说明他们整套评价体系已经建立在光学密度上。——这对你是好消息：你的浓度空间输出天然能出 COD / IOD 这类指标，而 RGB 空间方法要先做一步色解卷积，多一层误差。

3. ContiStain MICCAI 2026 · arXiv 2607.03851 最新方向
全称
ContiStain: Cross-Domain Relation-Preserving Distillation for Continual Multi-Domain Virtual IHC Staining
作者
Fuqiang Chen, Yifeng Wang, Hongpeng Wang, Yongbing Zhang（HITSZ 侧）
代码
github.com/ccitachi/ContiStain
设定
MIST 四域（HER2 / ER / PR / Ki67）顺序学习，支持 1234 / 4321 / 2413 / 3241 四种顺序

它解决什么问题

现实部署中，新的 biomarker 会陆续到来，而且旧域的样本在后续阶段不可得（数据不能留存）。直接在新区分上微调会严重破坏已学的 biomarker，并打乱 biomarker 表示之间的潜在关系。

三个机制

  • Teacher-student 蒸馏：每个阶段结束后冻结上一版生成器作为 teacher，当前生成器作为 student 学新区分
  • 域感知 MoE 特征提取器：为旧域构建结构化 patch-token 特征
  • 关系保持：约束 student 保持 teacher-student 的跨域余弦关系矩阵——保持 biomarker 之间的结构一致性，同时允许模型适配新染色
这一篇直接撞上你的核心卖点

ContiStain 要解决的就是"新染色来了怎么不重训/不退化"。他们的解法是 持续学习 + 蒸馏——本质上是"用更聪明的训练策略让模型适应"。你的 RDCS 范式是"换 S 不重训"——用物理参数解耦，让染色矩阵本身成为一个可换的接口。这是两种完全不同的哲学：他们改训练，你改表示。你的更优雅，而且可以正面做对比实验。

注意：这篇的评测指标包含 CONCH-FID（在 CONCH 特征空间算 FID）和 DISTS，比只报 PSNR/SSIM/FID 的做法更贴合病理语义。

4. StainPromptInversion（双路径提示反演） AAAI 2025 · arXiv 2412.11106 扩散分支
全称
Unpaired Multi-Domain Histopathology Virtual Staining using Dual Path Prompted Inversion
作者
Bing Xiong, Yue Peng, RanRan Zhang, Fuqiang Chen, JiaYe He, Wenjian Qin
代码
github.com/DianaNerualNetwork/StainPromptInversion

方法要点

  • 双路径提示策略（Dual Path Prompted Strategy）：用特征适配器生成参考图 → Style Target Path（提供风格模板）；用输入图的反演 → Structural Target Path（用视觉提示图保持结构一致性，同时保留风格路径的风格信息）
  • StainPrompt 优化：只优化 null visual prompt 作为"算子"，不微调预训练模型。在关键噪声点的每个时间步上优化结构/风格轨迹，保证双路径反演重建准确
  • 内容-风格完全解耦：在确定性采样过程中通过即插即用的嵌入视觉提示实现
这是这个团队唯一的扩散工作，而且它就是"解耦"的

它做的正是轴 3（内容 ⟂ 风格）的解耦——而且是扩散反演 + 免训练适配路线（不微调预训练模型，只调 prompt）。这跟你上一轮讨论的"解耦扩散范式"是同一个问题的不同解法。值得精读，因为它代表了"如果这个团队转向扩散，他们会从哪条路进"。

5. USIGAN IEEE TIP 2026 · arXiv 2507.05843 · DOI 10.1109/TIP.2026.3679993 最优传输分支
全称
USIGAN: Unbalanced Self-Information Feature Transport for Weakly Paired Image IHC Virtual Staining
作者
Yue Peng, Bing Xiong, Fuqiang Chen, De Eybo, RanRan Zhang, Wanming Hu, Jing Cai, Wenjian Qin
代码
github.com/MIXAILAB/USIGAN · 权重在 HuggingFace · 数据在 HuggingFace（USIGAN_IHC4BC_MIST）

核心：用最优传输 + 光密度处理"弱配对"

  • 自信息 + 最优传输（OT）+ 光密度（OD）三件套。通过 UOT 的循环一致迁移策略 + 批内光密度一致性，把"弱配对项"从联合边缘分布里剔除掉。
  • 两个机制：UOT-CTM（非平衡最优传输一致性）在图像级构建 H&E 与生成 IHC 的相关矩阵；PC-SCM（病理自对应）在组内级构建真实 IHC 与生成 IHC 图像集的相关矩阵。
  • 提出"弱配对（weakly paired）"这个概念——相邻切片间的空间异质性导致一对多映射不准确。这是对"错位"问题的正式建模。
  • 评价指标：IoD（积分光密度）、Pearson-R 相关性，强调临床相关性。评测 OD 需要 Fiji / ImageJ。
两个可以直接借的东西

①"弱配对"这个概念——比笼统说"错位"更精确，可以引用。② 他们的评测脚本——eval_pathology_metric.py（Content Pearson-R）和 pearson_R.py（Pathology Preserve Pearson-R，需 Fiji 算 OD），还有 evaluate_score.sh（PHV/FID/SSIM/PSNR）。这套评测代码是公开的，你可以直接拿来当你的评测基线，省一大块工程。

6. UTADC-Net IEEE JBHI 2025 非染色 · 扩散
全称
UTADC-Net: Unsupervised Topological-Aware Diffusion Condensation Network for Medical Image Segmentation
作者
Yue Peng, Ruodai Wu, Bing Xiong, et al.

不是虚拟染色——是医学图像分割，但用了扩散凝聚（diffusion condensation）。列在这里是因为它说明这个团队在扩散模型上已经有工程积累，不只是"借来用一下"。如果他们要转扩散虚拟染色，技术栈是现成的。

05三条技术分支

他们不是一条线走到底，而是分了三路。

分支主线 / 分支技术栈代表核心问题
A · GAN 主线 陈富强 + 张冉冉 CUT + ASP + CONCH 视觉语言模型 + prompt PSPStain → PGVMS → ContiStain 统一多染色、持续学习、临床部署
B · 扩散分支 熊兵 扩散反演 + visual prompt + 免训练适配 StainPromptInversion（AAAI'25） 无配对多域、内容-风格解耦
C · 最优传输分支 彭越 + 熊兵 非平衡最优传输 + 自信息 + 光密度 USIGAN（TIP'26） 弱配对、临床相关性指标
三条分支的共同点：都在用光学密度

分支 A 用 FOD 图 / COD 曲线；分支 C 用 OD 一致性 + IoD 指标。整个团队已经形成了"光学密度是虚拟染色的正确度量"的共识。但三条分支没有一条把光学密度当作生成空间——都只是拿它做损失项或评价指标。

07对 PSP-Diffusion 的七条启示

这一节是这份调研的真正目的。

启示 1 · 你的"浓度空间"想法得到了强侧证，但坑位仍空着

这个团队三条分支全都在用光学密度——FOD 聚焦光密度图、COD 累积光密度曲线、OD 一致性损失、IoD 指标、ImageJ/Fiji 算 OD。他们已经形成了"OD 是虚拟染色的正确度量"的团队共识。

但没有任何一篇把 OD 当作生成空间。他们的生成全部在 RGB 空间，OD 只出现在损失项和评价指标里。这意味着：① 你的方向被业内最有发言权的团队从侧面验证了（OD 确实是对的量）；② 但这个格子确实还空着。这是好消息——但也意味着他们要转过来成本很低（只需把 OD 从损失挪到表示层）。

启示 2 · 你的技术路线（扩散）与他们的主线（GAN）是差异化的

他们的主线是 CUT + ASP 的 GAN 血统，从 PSPStain 一路到 PGVMS、ContiStain 都没换过。唯一的扩散工作是 AAAI'25 的 StainPromptInversion，而且是免训练的提示反演（不微调预训练模型），属于"轻量适配"路线，不是"从零训练扩散先验"。你从零训浓度空间扩散先验，在方法论上跟他们完全不在一条路上。这是你的空间。

启示 3 · 只做 H+DAB 单染色会显得单薄，必须对标 multiplex

PGVMS 已经做到单模型统一 4 个 marker（HER2/ER/PR/Ki67），且只用 uniplex 训练数据，还跨了 5 类癌种。如果你的 PSP-Diffusion 只做 H+DAB 两通道，评审会直接拿 PGVMS 比。而且从上一轮讨论的"K 的三段论"看，K 越大你的方法越有优势（K=5 时零空间有 2 维，扩散先验才真正开始工作）。所以把 mIHC 作为主战场，既符合理论，也符合竞争格局。

启示 4 · ContiStain 撞上了你的核心卖点，但解法完全不同——这是最好的对比实验

ContiStain 解决"新 biomarker 陆续到来、旧数据不可得"的问题，用的是持续学习 + teacher-student 蒸馏——本质是"用更聪明的训练策略让模型适应"。

你的 RDCS 解决同一个问题，用的是物理参数解耦（换 S 不重训）——本质是"让染色矩阵成为一个可替换的接口"。两种哲学：他们改训练，你改表示。这可以做成一个非常漂亮的对比实验：同样面对第 5 个新染色，他们需要一轮蒸馏训练，你只需要换一个 S 矩阵。把这个实验做出来，你的范式价值立刻可量化。

启示 5 · 直接复用他们的评测代码，省一大块工程

USIGAN 仓库里有完整的评测脚本，全部公开：scripts/evaluate_score.sh（PHV / FID / SSIM / PSNR）、scripts/eval_pathology_metric.py（Content Pearson-R）、scripts/pearson_R.py（Pathology Preserve Pearson-R，需 Fiji 算 OD）。这套指标是他们花了几年打磨出来的临床相关性评价体系，直接用，比你自己重新定义指标有说服力得多。而且因为你的输出是浓度场，IoD 和 COD 这类指标你可以直接算，不需要额外做色解卷积——这是结构性优势。

启示 6 · 他们已经在用 CONCH，你可能也需要一个病理基础模型

PGVMS 引入 CONCH 病理视觉语言模型做自适应提示引导；ContiStain 用 CONCH-FID 做评价；他们的所有工作都依赖病理域先验。你的 L3 条件层（形态引导）如果只用一个通用编码器，会明显弱于他们的 CONCH 条件。建议：条件层至少要用 UNI / CONCH 级别的病理基础模型（这跟上一轮基座调研的结论一致）。

启示 7 · 工程完备度的门槛被他们抬高了

他们的每篇工作都配齐了：代码开源 + HuggingFace 权重 + 在线 demo + 百度网盘数据 + 详细 README。PGVMS 还有可交互的在线 demo（pgvms.qin-mixlab.cn）。你如果只交一个能跑的 repo，在对比中会吃亏。建议至少做到：代码 + 预训练权重 + 一份可复现的评测脚本 + 一个能跑的 demo。

还有一个战略判断

他们转向浓度空间扩散的成本很低，你的窗口期有限

这个团队具备转向你方向的所有条件：① 已经在用 OD（FOD、COD、IoD、OD 一致性）；② 已经有扩散工程积累（AAAI'25 的扩散反演 + JBHI'25 的扩散分割网络）；③ 有病理基础模型经验（CONCH）；④ 有临床合作渠道；⑤ 有成熟的数据与评测体系。他们唯一缺的就是"把 OD 从损失项提升为生成空间"这一步。——这一步你必须尽快做出来，最好先发一个初步结果占位。
