0先给结论

总判定：门控在扩散模型里被用在四个完全不同的位置，而「门控有效」的证据强度在这四个位置差了两个数量级

把「门控」当成一件事谈，是这个方向最常见的错误。文献里的门控至少分四类：① 网络内部算子门控（乘在残差/归一化上）、② 条件注入门控（乘在条件分支的残差上）、③ 专家路由门控（决定哪个专家处理哪个 token）、④ 时间步 / 频带门控（门控本身是 t 或频带的函数）。

证据强度的分布是极端不均的：

  • 位置①有最硬的正面证据——DiT 的 adaLN-Zero、CaiT 的 LayerScale、ReZero 都有受控消融，而且是在同深度、其余条件全部相同下比的。
  • 位置③有最硬的负面证据——ProMoE（ICLR 2026）逐字说：把 MoE 用到 DiT 上「yielded limited gains」，因为视觉 token 空间冗余导致专家同质化。
  • 位置④基本是空格——「按频带索引、且以 t 为条件的可学习门控」在扩散模型里没有任何工作做过；唯一接近的 FreqFormer（2026-04，技术报告）只有吞吐数字，没有质量消融。
★ 本轮最重要的单条发现：「零初始化」是必要起点，但它不是最优解

零初始化残差门控（γ ≡ 0，起点时新分支完全惰性）在文献里被当作金科玉律。本轮核实到一篇直接研究它的论文：《Unveiling the Secret of AdaLN-Zero in Diffusion Transformer》（arXiv 2608.09438，IEEE TPAMI 2026）。它把 adaLN-Zero 的性能来源拆成三个要素（SE 式结构、零初始化、渐进更新顺序），结论是零初始化「最有影响力」——但它同时提出 adaLN-Gaussian（小幅非零高斯初始化），并在同一套设置下一致地优于严格零初始化：

第二重要：门控会「让结果变差」，而且这件事有实证

这不是理论担忧。CaiT（ICCV 2021）在深度匹配、其余条件全部相同下测了三种门控，浅网络里三种全部比不加门控更差；ReZero 自己在 CIFAR ResNet-56 上也复现了同样的现象：

⇒ 门控的收益随深度/容量出现，浅网络里它是「训练稳定性保险」而不是「性能模块」。你的 backbone 是 from-scratch 小 2D U-Net（浅），所以位置①的门控期望值应该是稳定性 + 可解释性，不要指望它涨点。CaiT 还做了一个更锋利的对照：把训练好的门控值固定成非可学习常数重跑，深度 12 得到 80.6（≥ 可学习的 80.5）⇒ 浅层时「可学习」这个属性本身没有价值。

最值得先做的 / 明确不要做的

最值得先做（成本 +2 参数）

位置①的一个标量残差门控：h' = h + γ·Δh，零初始化或小高斯初始化。理由：这是唯一有同深度受控消融支持的一类，成本最低，而且它直接对应你库内已记录的 E1 失败模式（新分支在起点扰动 backbone）。

明确不要做

不要在扩散 backbone 上堆 MoE 专家路由——ProMoE 与 FA-MoE 都给了负结果。也不要一次加四种 gate（标量 / 逐通道 / 逐频带 / γ(t)），那样归因不出来。更不要构造「残差门控塌缩到 0」这个失败——本轮检索没有找到任何论文报告过它。

  • 被单独消融、且证明有用（只有两条链）：DiT adaLN-Zero（逐通道 + 零初始化残差门控，同设置下胜出 vanilla adaLN 与 cross-attn）与 LayerScale / ReZero（残差缩放救活深网络的训练）。但后者的证据来自分类器 / LM，不是扩散。

★ ControlNet 的两句必须逐字记住的话

零初始化的理由：「Zero convolutions protect this backbone by eliminating random noise as gradients in the initial training steps.」以及「progressively grow the parameters from zero and ensure that no harmful noise could affect the finetuning」。

「突然收敛」现象：「we call this the 'sudden convergence phenomenon'」——模型不是逐渐学会跟随条件，而是在某个 step 突然学会，通常不到 10K 步。Fig. 4 标注的具体步数是 6133。

⇒ 这两句话对你的价值是双重的：① 零初始化是防止新分支在起点污染已学好的 backbone 的机制——这正是你库内 E1 失败（FID 109.75→125.96、DAB corr 0.439→0.244）的解药；② 但「突然收敛」意味着前几千步条件实际上是被忽略的，所以「前 3K 步看起来没效果」不是「这个方法不行」的证据——这是一个真实的观测陷阱。

位置②的判定

唯一一个「可学习 + 可微 + 有消融」的条件门控是 GLIGEN 的 tanh(γ) 标量残差门控（γ 初始化为 0）。ControlNet 的零卷积是逐通道的、但主文没有数值消融。T2I-Adapter 与 Composer 根本不学门控——它们用固定 ω + 条件 dropout 来路由。⇒ 「多条件用可学习门控融合」这件事，在文献里其实没有被充分验证过。

6位置③：专家路由门控（MoE）—— 最强的负结果在这里

这一格的门控不乘在残差上，而是做选择：把 token 分配给不同的专家子网络。对你直接相关——「用一个 gate 在 marker 分支和形态分支之间路由」是一个很自然的想法。但这是本轮四个位置里证据最不利于新增设计的一格。

8失效模式与证据清算

这一节回答一个具体问题：门控什么时候不管用、什么时候有害？答案分七条，每条都标注它是「解析为真」还是「实证观测」。

8.1 零初始化：是安全默认，不是定律（实证）

支持零初始化的证据

ControlNet：零卷积「eliminating random noise as gradients in the initial training steps」（定性消融，无数值）。

CaiT：深度 36 不加 LayerScale 训练失败（69.9†），加了 80.5。

adaLN-Zero：FID 20.02 vs vanilla adaLN 24.13（arXiv 2608.09438 复现数字）。

ReZero：α=1 不涨点，α=0 才有收益 ⇒ 初始化是承重的。

反证：零初始化不是最优

adaLN-Gaussian（小幅非零高斯初始化）在同一设置下一致优于严格零初始化：FID 17.86 vs 20.02（400K）、13.14 vs 14.73（800K）、5.28 vs 6.15（CFG 1.5）。

GateSkip（ICLR 2026）把门控初始化成「开」（b=5 ⇒ σ(5)≈1，W_G ~ N(0, 0.01²)）——与零初始化相反，而且有效。

⇒ 「起点惰性」是安全默认（尤其当你想保护一个已预训练的 backbone 时），但不要把它当成普遍定律。

8.2 门控会让结果变差（实证，数字在 §0）

三条独立证据：CaiT 深度 12 的 ReZero（78.3 < 79.9）；ReZero 在 CIFAR ResNet-56 上三种门控全比 baseline 差（6.27 → 6.58/6.80/7.84）；CaiT 的「固定权重」对照（depth 12 固定值 80.6 ≥ 可学习 80.5）。共同规律：门控的收益随深度出现，浅网络里它是负担。

8.3 门控饱和（解析为真）+ 库内「11×」的订正

解析事实

对 γ = γ_max·σ(a)，dγ/da = γ_max·σ(a)(1−σ(a))。σ 的导数上界是 1/4，且在 γ→0 时 →0。⇒ 用 sigmoid 把门控压在接近 0 的地方，会让门控参数自身的梯度非常小。

这个「σ 导数 ≤ 1/4」是解析为真的，且有文献逐字写过——Spectral Gating Networks（arXiv 2602.07679）在定理 3.1 的证明里写「sigmoid has derivative ≤ 1/4」。

★ 订正库内报告的一处数字：库内 §6.2 的「11×」

库内 222 KB 频域报告 §6.2 给出「在同一个 γ₀ 下，tanh 给出的梯度是 sigmoid 的 11 倍」。这个算术是对的，但它不是文献数字，而且强烈依赖参数化。

它的算法（我复核过，算术无误）：在 γ = γ_max·σ(a) 与 γ = γ_max·tanh(a) 这个归一化参数化下，两者都要求 γ₀ = 0.01、γ_max = 0.1 ——
σ 分支：σ(a₀)=0.1 ⇒ a₀ = logit(0.1) = −2.197，dγ/da = 0.1 × 0.1 × 0.9 = 0.009；
tanh 分支：tanh(a₀)=0.1 ⇒ a₀ = atanh(0.1) = 0.1003，dγ/da = 0.1 × (1 − 0.01) = 0.099；
比值 = 0.099 / 0.009 = 11×。

为什么不能当作文献引用：① 没有任何论文写过「11×」这个数字；② 比值完全取决于参数化——如果不做 γ_max 归一化（直接比 g=σ(a) 与 g=tanh(a)），得到的比值是另一个数；③ 本轮检索中没有找到任何论文讨论「小初始化 sigmoid 门控的梯度饥饿」（TASR 用 sigmoid 是为了防 reward hacking，不是为了稳定性）。

⇒ 报告里的正确写法：「σ 导数上界 1/4（有文献）」+「在 γ_max 归一化参数化下，tanh 起点梯度约为 σ 的 11 倍（自证算术，无文献）」。

9.4 一条必须记住的边界：「通道语义 ≠ Fourier 频率」

这是库内 PST-Diff 审查已经立下的结论，本报告再次确认它

你的 H / DAB 两个通道是化学语义（染色种类），不是频带。所以：

  • 「按通道门控」（H 一个 γ、DAB 一个 γ）与「按频带门控」（LL / LH / HL / HH 各一个 γ）是两件不同的事，不能互相替代，也不能混着说。
  • 库内 PST-Diff 审查的边界结论：「通道语义 ≠ Fourier 频率」，PST-LT 的 paired latent L2 不能迁到非配对。同一逻辑在这里适用：不要把「H 是低频、DAB 是高频」当成可以硬编码的通道-频带对应——库内 81 KB 频域报告已指出，伊红成片弥散（相关长度大 ⇒ 低频）、DAB 细线稀疏（相关长度小 ⇒ 高频）是统计倾向，不是可以写死的映射。

10.1 三条关键判断

① 门控对你最大的价值不是「性能」，是「把 E1 那次失败变成可控的」

你库内已记录：E1 失败（FID 109.75→125.96、DAB corr 0.439→0.244），归因是「任何在起点就扰动 backbone 的新分支都会破坏已经学好的 diffusion prior」。零初始化残差门控正是这条失败的解药——ControlNet 的原话就是「eliminating random noise as gradients in the initial training steps」，起点时 Δh ≡ 0，前向完全等价于 baseline。

所以位置①的门控在你项目里的定位应该是：「让新分支可以安全地加上去」的工程保险，顺带给你一个可解释的量（γ 的收敛值告诉你模型依赖哪一路）。

② 但不要把它当「性能模块」——你的 backbone 是浅的

CaiT / ReZero 的实证显示：浅网络里门控可能不涨甚至掉点（CaiT depth 12：78.3 < 79.9；ResNet-56 三种门控全比 baseline 差）。你的 backbone 是 from-scratch 小 2D U-Net（base 64–96），属于「浅」。⇒ 期望值定在「稳定性 + 可解释性」，不是「涨点」。

③ 门控的放置：必须乘在分支输出（残差侧）

GateSkip 的放置对照（入口门控在 15% skip 时掉到 1.0 acc）虽然来自 LLM，但方向与位置①的机制一致：门控乘在残差分支的输出上。不要设计成「乘在输入特征上」。

11可执行实验路线与止损

路线按「改动量从小到大」排序，每一阶段只有一个唯一变量。所有阶段都建在四臂对照之上，且不改变「输出必须经 BL」这条红线。

G0  零训练门禁（<30 行）
     └─ 断言新分支在 step 0 对 hidden stream 完全无影响
        · zero-init 分支：断言 max|h' − h| == 0
        · 小高斯分支：断言 max|h' − h| < 1e-7
        · 记录 ρ_l = RMS(Δh_l)/RMS(h_l)，初始应为 0
     ▼ 若 G0 不过 ⇒ 先修初始化，不要开始训练

G1  只加一个标量门控（唯一变量 = 有无门控）
     └─ h' = h + γ·Δh，γ = γ_max·tanh(a)，γ_max = 0.1，a ← atanh(0.1)
        · 必须同时记录 a（原始参数）与 γ（tanh 后）——只记 γ 分不清
          「a 不动」还是「tanh 压住了」
     ▼ 判据：γ 是否离开 0.01
        · 收敛到有意义的值 ⇒ 继续 G2
        · 稳定停在 0.01 ⇒ 是梯度问题，回去看 §8.3
        · 收敛到 ~0 ⇒ 分支确实无用，这是有效阴性结论

G2  门控的函数形式（唯一变量 = γ 的形式）
     └─ 对比三臂：① 常数 γ ② γ(t)（形状取「弱–强–弱」，中段最强）
                   ③ 小高斯非零初始化（TPAMI 2026 的 adaLN-Gaussian）
     ▼ 判据：γ(t) 是否明显优于常数 γ；小高斯是否优于严格零初始化
        · 都无差别 ⇒ 该任务对门控形式不敏感，省掉这部分复杂度

G3  只在 G1/G2 成立后才做
     └─ 按频带门控（LL/LH/HL/HH 各一个 γ）——这一格没有先例
        · 判据：HH 的 γ 是否被压到 0
          （若被压到 0 ⇒ 高频负迁移，与 StainDiffuser 的警告一致）
     └─ 或 逐通道门控（H / DAB 各一个 γ）——低风险对照
     ✗ 不要做 MoE 路由
