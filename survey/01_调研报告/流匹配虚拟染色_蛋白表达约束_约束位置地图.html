0先说结论

一句话判定

「流匹配 + 蛋白感知的训练损失」这个组合，在能核实的文献里同样是空的。但和扩散版有一个决定性的差别：流匹配这一侧已经进入虚拟染色（能核实到 4 篇正式论文 + 1 个公开项目），而且它带来三件扩散没有的东西——几乎免费的端点估计（挂损失更便宜）、一套完整的 guidance 理论（采样期约束有现成公式）、以及天然处理非配对的 Schrödinger Bridge 路线。⇒ 这个空缺比扩散版更容易填，而且填法更干净。

但先纠正一个可能的误解：「换到流匹配」不会自动解决你的核心困难

你的核心困难是 H&E 与 IHC 不严格配准 ⇒ p(IHC | H&E) 的 coupling 不可辨识。换成流匹配后，这个问题的性质变了，但没有消失：

  • 变好的部分：不再需要 cycle-consistency 去"猜"对应关系。SB / OT-CFM 把「病态的耦合」换成了「良定义的耦合」——它求解的是一个有唯一解的熵正则最优传输问题。这是真实的进步，不是话术。
  • 没变的部分：SB 的唯一性来自参考测度与熵正则的选择，不是从数据里辨识出真实对应。任何边缘分布正确的耦合都是可行解。⇒ 分布级良定义 ≠ 实例级可辨识。
  • 诚实的结论：实例级可信度仍然只能来自额外监督（相邻连续切片 / 生物先验 / 病理基础模型）。而这一点恰好被病理论文自己印证了——TDSB、PASB、SheafStain 三篇全部依赖额外监督，没有一篇是"纯非配对 + SB 就够"。

你最想知道的 5 个问题 —— 直接答案

Q1 · 有真正用于流匹配虚拟染色的 protein-aware loss 吗？

没有。三次独立检索（两个子 agent + 我本人一次定向检索）＋ 五篇虚拟染色工作逐篇核对，全部阴性。蛋白信号在流匹配虚拟染色里只以条件或指标的形式出现。

★ 但有一条极有价值的旁证：一个在 BCI 上做 Rectified Flow Matching 的公开项目，自己的结论是 "RFM preserves structure but fails to model realistic staining"、"lacks the inductive bias necessary to reproduce realistic staining distributions"。这等于有人替你说出了"这里缺一个染色/蛋白分布级约束"。

Q2 · 现在最常见的方法是哪一类？

在流匹配虚拟染色里：语义/结构一致性（VFM 特征、拓扑、对比学习）远多于蛋白约束——TDSB 用拓扑 + 双域对比，PASB 用高层语义对齐，SheafStain 用 VFM 的 class token 锚"生物一致性"。

在非流匹配的蛋白约束里（可迁移池）：DAB/OD 级与分布级最成熟（PSPStain FOD、CCPL、UNIStainNet、TDKstain）。ranking 与 H-score 训练损失仍是空的。

Q3 · 这些约束挂在流匹配的哪个位置？

见 §5.1 位置总表。结论：现有流匹配虚拟染色的约束全部落在「条件输入」与「特征/latent」两格，速度场/端点那一格是空的——而这恰好是最便宜、最直接的一格。

Q4 · 哪些方法不需要严格配准？

L3 分布级及以上都不需要：FOD 全局均值 / 直方图、区域级 ranking、滑片级 MIL 分级、VFM 全局 class token。L1 像素级（DAB 逐像素 L1、HER2 逐层特征回归）在错位下会退化——已有受控实验量化（§7.1）。

Q5 · 现在存在明显空缺吗？

存在，而且比扩散版更值得抢。四要素交集 流匹配 × 显式蛋白/染色表示 × 蛋白感知约束 × 弱配准：

  • 已经有人做到哪一步：流匹配族已进虚拟染色（TDSB / PASB / SheafStain / HUSE / PRISM），但全部停在图像重建 + 语义/拓扑一致性；显式染色表示（H/DAB 浓度 + 物理渲染）在流匹配里完全没人做；蛋白感知约束在流匹配里完全没人做；弱配准已被 TDSB / PASB 用 SB + 相邻切片解决了"要不要配准"这一层，但没解决"表达保真"。
  • 哪一步没被解决：① 速度场/端点上的蛋白损失（零篇）② 流匹配里的浓度空间生成（零篇）③ 流匹配里的区域级表达 ranking（零篇）。
  • 你可能补哪个空：把 PSPStain 的 FOD 分布级损失挂到流匹配的 x̂₁ 上——它有已发表先例（PSPStain）、框架无关、在流匹配里比扩散更便宜更稳、且天然是 L3 抗错位。这是本次调研给出的最具体、最容易落地的一格。

2.1 ★★★ TDSB —— Topology-aware Diffusion Schrödinger Bridge for Unpaired H&E-to-IHC Stain Translation
IEEE J. Biomed. Health Informatics, 2026-03-02 · DOI 10.1109/jbhi.2026.3668658 · Zhang, Xie, Hu, Shi, Li, Liang, Lin, Chen（立命馆大学 + 邵逸夫医院 + 浙江大学）
已核实 SB 非配对

① 它解决什么。H&E→IHC 虚拟染色，且明确针对非配对设定。它认为 SB 路线优于两条既有路线：CycleGAN 会 mode collapse 与出伪影；扩散模型则有高斯先验假设的限制。而直接套用 UNSB 在组织学图像上有两个问题：丢失拓扑特征、以及 IHC 染色表示不足（UNSB 只看域到域的最优路径，忽略局部结构路径）。

② 是不是流匹配族。是。Schrödinger Bridge（diffusion SB，构建在 UNSB 公式之上，桥被离散成连续步骤、每一步对抗式学习）。★ 关键：它不绕道高斯噪声——起点是源图本身。

④ 大白话。它阻止模型犯的错是"把组织结构搞丢了"——桥只优化"从 H&E 分布到 IHC 分布"的整体路径，不管局部结构有没有保住，而卷积网络的感受野又不够，于是腺体、肿瘤巢这类关键结构会被抹掉。所以它额外加一个拓扑打分（结构还在不在）和一个跨两个域的对比损失（IHC 染色纹理对不对）。注意：它管的是"结构 + 染色纹理"，不是"蛋白表达量"。

⑤ 挂在哪里。② latent / feature（拓扑引导 + 双域 patch 对比，都在训练损失里）；不在采样循环里。这是SB 特有的优势——因为它不经过高斯噪声，条件/约束可以直接作用在"从源图出发的传输路径"上。

⑥ 配准要求。不需要配准（L3–L5）。摘要原文：训练消费的是非配对的 H&E 与 IHC 图像，"which is what a sequential-section workflow can realistically produce"。

⑦ 强度与可用性。蛋白约束强度 ★☆☆☆☆——拓扑与对比都不是蛋白量。但对你价值极高：它是「流匹配族 + 非配对 H&E→IHC」唯一有正式发表、且明确以"扩散的高斯先验是缺陷"为动机的工作。你从扩散换到流匹配，可以直接引它这一句作为文献支撑。

2.6 ★ 一个非正式、但对你的选题最有价值的证据：BCI 上的 Rectified Flow Matching 项目
GitHub: nishamaria08/rectified-flow-matching-for-bci-dataset · 2026-03/04 · 非正式发表（无 arXiv ID、无 venue）
已核实（README） 非正式 配对

为什么值得单独列出来。这是我在检索中发现的唯一一个在 BCI（HER2）数据集上做 H&E→IHC 的整流流匹配项目——正好是你的数据集。它不是论文，但它的结论等于替你说出了"这里缺什么"。

它做了什么。在同一套 BCI 数据上横向对比四种范式：Pix2Pix（条件 GAN 基线）· ASP（对比学习法）· Rectified Flow Matching (RFM) · RFM + GAN（提出的混合方案）。

它的结论（README 原文级）：

  • "Flow-based models such as RFM are effective at preserving global morphology and maintaining structural consistency, whereas adversarial approaches are better suited to modelling realistic texture and staining patterns."
  • "Although RFM provides a stable and well-structured mapping between H&E and IHC domains, it lacks the inductive bias necessary to reproduce realistic staining distributions."
  • 结果汇总：Pix2Pix 重建强但过平滑；ASP 感知特征好但不一致；RFM 保结构但无法建模真实染色；RFM+GAN 最平衡。

它的损失。只有三项：flow matching loss（结构对齐）+ adversarial loss（分布真实性）+ perceptual loss（视觉相似）。没有任何蛋白/染色表达级损失。

★ 这条证据怎么用

它在 BCI 上实测出"纯流匹配保结构、但不复现真实染色分布"。这正好是你想加的染色/蛋白分布级约束要解决的问题——一个来自你自己数据集上的、独立复现的经验空白陈述。写论文时这比"文献里没人做"更有力。但必须标注它是非正式项目，不能当作 peer-reviewed 证据引用。

2.8 小结：五条硬事实

这五条都是经我本人复核后才写下的
  1. 流匹配族已经进入虚拟染色，不再是空白领域。能核实到的有 TDSB（SB，非配对）、PASB（SB，弱监督）、SheafStain（SB+UNSB）、HUSE（JiT，配对）、PRISM（GAN-free FM，含 virtual staining 基准）。

这三项合起来叫 L_MLPA，λ=1.0。它确实是训练损失，作用在 DAB 通道上。但论文没有做"去掉这一项会怎样"的完整消融来单独证明它保住了蛋白表达——这是你在引用时要小心的地方。报告里不能把它写成"蛋白保真度被提升了"这类话，要写"它把 FOD 的均值/直方图/分块均值三项作为训练损失"。

配准等级：L3（三项都是统计量，不需要像素对应）。这是本报告推荐它的核心原因之一。

3.2 第二类 · H-score / protein grading / biomarker score 约束

三问回答

① 流匹配里有人做吗？没有。
② 最接近的：HER2 Score-Aware NCMT（Diagnostics 2026）——把 HER2 序数分数做成 MSE 训练损失。
③ 能迁移吗？能，但它要求像素对齐（L1），在你数据上会退化。

★ H-score 是拿来训练的还是只是评价？必须分开说：

训练不用 H-score，测试比较 real/fake H-score   → 这是【评价指标】
L_protein = |HScore(fake) − HScore(real)|      → 这才是【训练损失】
★ H-score 不可微——这是它没人拿来做训练损失的根本原因

标准 H-score = 1×(%弱) + 2×(%中) + 3×(%强)，取值 0–300。它依赖硬阈值分箱 + 计数（常用切点如 DAB <0.2 / 0.2–0.4 / 0.4–1 / >1）。分箱和计数都不可微，梯度回不去。本次检索没有找到任何病理论文用软的 H-score 损失。

三个可微替代（按推荐度排序）：

  1. 序数回归——把 0/1+/2+/3+ 当成连续序数目标做 MSE。HER2 Score-Aware NCMT 就是这么做的（t ∈ {0, 0.33, 0.66, 1}，MSE 同时监督生成图与真值，λ=10）。有先例、可直接搬。
  2. 软分箱（可微直方图）——用光滑核代替硬切点，得到对 DAB 分布的可微描述。比序数回归信息量更大，但没找到病理先例。
  3. 直接回归连续 DAB 加权和——绕开"分级"这个概念，直接对 DAB 强度加权求和。最简单，但丢掉了临床分级的语义。

★ 如果 H&E/IHC 没配准，H-score 怎么算？这是关键问题。答案是：算不了像素级 H-score，只能算分布级或区域级。这正是为什么本报告推荐 L3 分布级方案——它在错位下仍有定义。HER2 Score-Aware NCMT 的受控实验直接量化了错位的代价（§7.1）。

3.4 第四类 · protein feature / foundation model 特征约束

三问回答

① 流匹配里有人做吗？半有人做——SheafStain 把病理 VFM（Prov-GigaPath / UNI / UNI2-h / Virchow2）的 class+patch token 注入 SB 生成器；但它是条件，不是特征级损失。

③ 能迁移吗？技术上能，但有一个从未被验证的前提。

★ 这一节最重要的一句话：普通病理特征 ≠ 蛋白特征

3.5 第五类 · Contrastive / ranking / relative expression 约束

三问回答

① 流匹配里有人做吗？没有。
② 最接近的：TDSB 的 DDAP（双域 patch 对比）——但它是染色/结构对比，不是表达量排序；ASP 的权重调度（处理不一致配对）。
③ 能迁移吗？能，而且这是文献里最空、对错位最友好的一格。

为什么这一类对连续切片特别重要。你不能要求 H&E patch A ↔ IHC patch A，但可以要求：

真实 IHC：   区域 A 表达 > 区域 B 表达
生成 IHC：   区域 A' 表达 > 区域 B' 表达      ← 即使 A 与 A' 不在同一坐标

大白话（按指导书 §十一 要求的方式解释）。本来要求"A 必须对 A"，现在改成"A 可以对 A1/A2/A3"——只要生成图里表达强弱的排序关系和真实图一致，就认为对了。它放弃了"哪个像素对应哪个像素"，只保留"哪个区域比哪个区域表达强"。

★ 检索结果：ranking 损失在虚拟染色里是空的

本次检索（含上一轮扩散版）没有找到任何一篇虚拟染色论文使用蛋白表达的 ranking / 序关系损失。TDSB 的对比学习是patch 级特征对比，不是区域间表达量排序。⇒ 这是一个真正的空白，而且实现成本极低（几行代码：取若干区域算 FOD 均值，比大小，用 pairwise hinge 或 softmax 交叉熵）。

配准等级：L4（只需要区域划分，不需要坐标对应）。

3.6 第六类 · 分布 / histogram / statistics 约束

三问回答

① 流匹配里有人做吗？没有（但 SheafStain 把 DAB-KL / DAB-JSD 作为评价指标，说明这个量在病理圈已被接受）。
② 最接近的：PSPStain 的 20-bin 直方图项 · USIGAN 的非平衡 OT（去掉弱配对项）· RAFM 的"检索式伪配对"。
③ 能迁移吗？能，且与 3.1 是同一套东西。

为什么分布级最抗错位。因为错位改变的是"哪个像素在哪里"，不改变"整块组织里有多少高表达、多少低表达"——只要你的区域选得比错位尺度大得多。

真实 IHC：高表达 20% / 中表达 50% / 低表达 30%
生成 IHC：高表达 18% / 中表达 52% / 低表达 30%   → 判定为"表达分布接近"

★ 流匹配侧的一个额外发现。RAFM（arXiv 2603.00535，整流流做非配对 CBCT→CT）摘要自陈：整流流在非配对下是 "distribution-level coupling and deterministic transport"，且直接套用"随机或批内伪配对"会产生不稳定监督，原因是 "semantically mismatched endpoint samples"。⇒ 它等于从生成模型理论这一侧确认了"分布级耦合"这个性质，并且给出了一个可迁移的工程解法：用检索（frozen DINOv3 + memory bank）构造高质量伪配对，而不是随机配对。

3.7 第七类 · 弱配准 / soft correspondence / optimal transport

三问回答

① 流匹配里有人做吗？有，而且这是流匹配族的主场——TDSB / PASB / SheafStain 全部用 SB 处理非配对。
② 最接近的：OT-StainNet（平衡 Kantorovich OT，求解方式论文未说明）· USIGAN（非平衡 OT，显式去掉弱配对项）· UNSB（非配对 SB 的骨干）。
③ 能迁移吗？能，而且换到流匹配后这条路更自然。

大白话解释 OT（按指导书 §十一 要求）。本来要求"A 只能配 A"，OT 把它改成"A 可以配 A1/A2/A3，由耦合矩阵按总代价最小来分配权重"。代价函数通常是特征空间的 L2 距离，解出来的耦合矩阵 P 告诉你"哪块 H&E 该以多大权重对哪块 IHC"。

★ 关键细节（已拿到 OT-StainNet 全文，2026-10-06 更正）：它用的是平衡 Kantorovich 形式 min_P ⟨P, C⟩（边缘约束两侧质量守恒，这点确证）；而 USIGAN 用的是非平衡 OT（去掉弱配对项，允许质量不守恒）。
★ 但要更正我上一轮的一个说法：我原先写它「无 Sinkhorn 项」——那是从「论文没提」推断出的「没有」，不成立。拿到全文后确认：论文只给了 Kantorovich 形式，从头到尾没有说明 P 用什么算法求解，既没提 Sinkhorn 也没提熵正则。而且反过来想更合理：n×n 精确 LP 在训练循环里根本跑不动（n=1024 时单次约 10⁹ 量级，要跑 3 万次迭代）⇒ 它实际用的很可能就是熵正则 + Sinkhorn，只是没写。⇒ 正确表述是「求解方式论文未说明」，不是「没有 Sinkhorn」；原「病理 OT 里没人用 Sinkhorn」这个阴性结论也随之站不住，只能说「两篇都没写」。详见 02_论文翻译/OT-StainNet_论文中文翻译.html 的缺口清单第 5 条。

5.2 ★ 端点反推：为什么流匹配里挂损失比扩散更便宜

版本 1 · 一句人话

流匹配的网络每步输出的是"往哪个方向走多快"（速度），但你可以用一步算术就把"终点长什么样"（干净图）直接算出来——不需要额外跑一次网络，也不涉及除法。所以"把蛋白损失挂在干净图上"这件事，在流匹配里几乎不花钱。

版本 2 · 流程图

x_t（当前带噪图）
   │
   ├──────────────→ 网络 v_θ(x_t, t) ──→ v̂_t（速度）
   │                                        │
   └────────────────────────────────────────┤
                                            ▼
                         x̂₁ = x_t + (1−t)·v̂_t      ← 一步算术，免费

                                            ▼

                                            ▼

版本 3 · 公式

线性（OT）插值：x_t = (1−t)·x₀ + t·x₁，其速度场满足 v_t = ẋ_t = x₁ − x₀。于是

x̂₁ = x_t + (1 − t)·v̂_t(x_t)     x̂₀ = x_t − t·v̂_t(x_t)

自证（可核对）：x_t + (1−t)(x₁−x₀) = (1−t)x₀ + t·x₁ + (1−t)x₁ − (1−t)x₀ = x₁ ✓；同理 x_t − t(x₁−x₀) = x₀ ✓。且线性调度下分母 α̇_t β_t − β̇_t α_t = 1·(1−t) − (−1)·t = 1，无除法。

与扩散版的正面对比

对比项扩散（DDPM 式）流匹配（线性插值）
反推公式x̂₀ = (x_t − √(1−ᾱ_t)·ε̂) / √ᾱ_tx̂₁ = x_t + (1−t)·v̂_t
额外前向无无
是否含除法含 √ᾱ_t 在 t→T 时 → 0不含
系数范围1/√ᾱ_t 无界（t→T 时发散）(1−t) ∈ [0,1] 有界
最不稳的地方噪声端（t→T）也是噪声端（t→0），但只是"从纯噪声单步 Euler"、对 v̂ 的误差最敏感，不存在除以零
对挂辅助损失的后果在噪声端算 x̂₀ 的损失会被 1/√ᾱ_t 放大，必须做时间步加权或只在低 t 算系数有界，理论上不需要特殊处理；实践上仍建议用 Logit-Normal 或 U 形时间步采样避开两端
★ 但有一个流匹配特有的陷阱：别把 x 空间的损失算成 v 空间的

如果网络输出的是 x₁ 预测（x-prediction，HUSE 的 JiT 就是这一支），而你把损失写在 v 空间，那么两者之间差一个 1/(1−t) 因子：v̂ = (x̂₁ − x_t)/(1−t)。这个因子在 t→1 时发散，梯度会被放大。

规则：损失和网络输出必须在同一个空间里算。要么让网络直接输出 v（标准 CFM），要么让网络输出 x₁ 而损失也写在 x 空间。不要混。

本次检索到一篇专门讲这个的预印本（Prediction–Loss Alignment），但我没有亲自核实，故不引用其编号，只把上面的推导作为独立结论给出（推导是初等的，可自行验证）。

★ 对你的直接结论

在流匹配里，把 PSPStain 的 FOD 损失挂在 x̂₁ 上，比在扩散里挂在 x̂₀ 上更便宜、更稳。这是本次调研给出的、最具体的一个工程收益。而且它不需要改架构——只是在损失里加一项，输入是 x̂₁（或采样完成后的图），输出是标量。

5.3 流匹配的 guidance 机制（位置 ⑤ 的现成工具箱）

扩散的 classifier guidance 在流匹配里不是照搬——Feng et al. 明确指出流匹配的 guidance "更一般、因而与扩散实质不同"。好消息是这个理论已经建好了。

机制作用在什么上需要训练吗代表论文证据
免训练渐近精确 guidance采样时的速度场，用能量函数的梯度修正不需要Feng et al., ICML 2025（arXiv 2502.02150）已核实
训练式 guidance 损失训练一个专门的引导速度场网络需要同上已核实
近似 guidance 族覆盖经典梯度 guidance 作为特例取决于具体形式同上已核实
Classifier-free guidance (CFG)采样速度场：ũ = (1−ω)·u(x) + ω·u(x|y)需要（条件+无条件联合训练，condition dropout）Guided Flows（arXiv 2311.13443）已核实

大白话（指导书 §四 要求的方式）。流匹配本来按自己的速度场往一个方向走，guidance 在旁边说"你现在的蛋白表达太弱了"，于是把每一步的速度往"蛋白表达更强"的方向偏一点。偏多少由能量函数的梯度决定。

★ 为什么位置 ⑤ 在流匹配里比在扩散里更好做

因为 guidance 需要每一步都估计"当前样本的干净版本是什么"，才能算能量。流匹配的 x̂₁ = x_t + (1−t)v̂_t 是免费的（§5.2），而扩散要算 x̂₀ 得除一个趋零量。⇒ 位置 ⑤ 的工程门槛在流匹配里明显更低。

5.4 确定性与「一对多」—— 换到流匹配后新出现的问题

这是扩散→流匹配转换中唯一一个"变差"的地方，必须说清楚。

问题

标准 CFM 用独立耦合 + L2 回归。当条件分布 p(x₁ | x₀) 是多模态的（一张 H&E 对应多种合法的 IHC 表达强度），L2 回归的期望解是条件均值速度——于是采样会退化成"模式平均"：所有样本都生成成中等表达，高表达区被拉低、低表达区被拉高。

这恰好是蛋白表达保真最怕的失败模式（H-score 会因此系统性偏向中间档）。

修法（按推荐度）
  1. ★ ODE → SDE 采样（免重训）：Singh & Fischer（arXiv 2410.02217）给出通用方法，把确定性流的 ODE 转成同边缘分布的一族 SDE，且明确适用于已经训好的确定性流模型。摘要原文："they ... do not permit different samples conditioned on an intermediate state, limiting their application"，以及该方法提供 "an additional knob for controlling the diversity of generation"。⇒ 不用改训练、只改采样器，就能恢复"一对多"的随机性。
  2. 注入潜变量：Stochastic Interpolants（Albergo & Vanden-Eijnden）在插值里引入一个额外的潜变量，把"多模态"转成"给定 z 后确定性、对 z 边缘化后多模态"。
  3. 把表型显式变成条件：给 IHC 表型一个条件编码（marker / 强度档 / 潜码），把"多个合法 IHC"从"随机性"变成"条件维度"。
★ 一个重要澄清：确定性不是"流匹配比扩散差"

扩散的 probability-flow ODE 同样是确定性的，同样有模式平均问题；扩散之所以显得随机，是因为用了反向 SDE 采样。真正的分野是 ODE vs SDE，不是流匹配 vs 扩散。⇒ 两条路线的修法完全一致，你不需要为了"随机性"而放弃流匹配。

7.2 ★ SB / OT-CFM 到底保证了什么 —— 诚实回答

结论：不能。SB / OT-CFM 把"病态的耦合"变成"良定义的耦合"，但没有让实例级对应变得可辨识。

逐条理由（每条都能追溯到已核实来源）：

  1. 约束只在边缘分布上。SB 问题的输入是两个边缘分布 + 一个参考过程。任何边缘正确的耦合都是可行解；熵正则 OT 只是在给定参考测度与熵正则下挑出唯一的一个——这是正则化的选择，不是从数据里辨识出真实对应。
  2. 映射本质是随机的、一对多的。UNSB 论文自己说 SB 是 stochastic 的、做 one-to-many，并把它当作合格 SB 的必要条件，而非缺陷。⇒ SB 在原理上就不给出单值实例对应。
  3. UNSB 的 Theorem 1 保证的是分布匹配，不是逐样本正确。
  4. minibatch OT（OT-CFM）也是分布级。它在批内解 OT 得到确定性耦合，但那是对全局 OT plan 的近似；代价函数定义在像素/特征空间，不含生物语义——两个外观相同的 H&E 块可以合法地被送到不同 IHC，OT plan 依然"最优"。
  5. ★ 生成模型理论这一侧自己也承认这一点。RAFM（整流流做非配对 CBCT→CT）摘要原文：整流流"is theoretically compatible with unpaired learning through distribution-level coupling and deterministic transport"，且"Direct application with random or batch-local pseudo pairing can produce unstable supervision due to semantically mismatched endpoint samples"。
★ 那要拿到实例级可信度，靠什么？——靠额外监督，而病理论文自己印证了这一点

为什么是它：它同时满足五个条件，而这五个条件没有第二个方案能全占。PSPStain 已经把"FOD 均值 + 20-bin 直方图 + 16 块区域均值"这套形式发表过，你不需要发明任何新数学；它是纯预测图的可微函数，与生成框架零耦合；它在 L3，对 24 px 错位免疫；它不碰架构，只加一项损失。

唯一要做的工程判断：挂在哪一层。→ 挂在 x̂₁（§5.2）。注意：如果你用 x-prediction 网络（如 JiT 式），x̂₁ 就是网络的直接输出，连反推都不用。

方案 E —— 第二优先级（★ 文献空白最大的一格）
ranking 无人做 · L4 · 实现成本极低 · 创新空间大

为什么值得做：上一轮扩散版和本轮流匹配版两次检索都没有找到任何虚拟染色论文使用蛋白表达的 ranking 损失。而它对错位最友好（L4），实现只有几行：取若干区域算 FOD 均值 → 比较区域间大小 → pairwise hinge 或 softmax 交叉熵。

建议做法：先只做"分布级"（和方案 B 合并），把 ranking 留作方案 B 有效之后的增量。

方案 F —— 第二步首选（★ 流匹配让它的门槛明显降低）
理论齐备（Feng et al.）· 只改采样器 · 打开"可控性"这个新问题

为什么它排在 B 之后而不是之前：guidance 需要一个可用的蛋白能量函数——而这个函数正好就是方案 B 训练出来的那个 φ(x)→FOD 映射。先把 B 做出来，F 就是"把同一个 φ 从训练期损失升级成采样期能量"，机制几乎零新增设计。

流匹配的额外优势：每一步都免费拿到 x̂₁（§5.2），所以算能量不需要额外前向。这是扩散做不到的便宜。

方案 C —— Stage 3 再做（不是不好，是顺序不对）
创新最大 · 但属"换解码器级"改动 · 前置条件多

让流匹配直接生成浓度图，是可解释性最高的一条路，也是四要素交集的最后一格。但它需要先解决三件事：① 固定 stain matrix（否则浓度带每图自由度，H-score 不可比）② 非负/值域参数化（不能靠 clamp，那是止血）③ 无色轴断言（确保染色平面不含光照方向）。这三件都是你已有的 E0 工作。先做 B 拿到"分布级有效"的证据，再决定要不要花这个代价。

方案 D —— 暂不建议（前置成本被严重低估）
前提未被验证 · 算力高 · 约束的可能不是蛋白

用病理 FM 特征做损失，隐含假设是"这些特征编码了蛋白表达"。但本次检索没有找到任何论文验证过这个假设——它们是在 H&E 形态上自监督预训练的，编码的主要是形态。而且 SheafStain 已经把 VFM 用成了条件（这是更稳妥的用法）。如果你要做，先花半天验证前提：训一个 DAB 回归头，看 FM 特征对它的预测能力是否显著优于直接用 RGB。前提不成立就别做。

方案 A —— 不建议（错位下有害）
L1 · 会主动教模型学错东西

逐像素 RGB / DAB 差在 24 px 错位下不是"效果打折"，而是"引入 label noise、把模型推向学大尺度上下文"（§7.1 的原文）。除非你先做配准，否则不要。

9分阶段实验建议（指导书 §二十三）

每一步都写清"这个实验到底在验证什么假设"，以及止损条件。

Stage 0 · 复现流匹配 baseline（不是复现扩散）
验证的假设：流匹配在你的数据上能训得起来、且不比扩散差
必须做

做什么：在 BCI 或 MIST 上跑一个标准 CFM（线性插值 + 速度场 MSE），条件 = H&E 拼接。评估只用 PSNR/SSIM/FID + 一个 DAB 级指标（例如 FOD 分布距离），作为后续所有实验的对照基线。

为什么不能跳过：你需要一个同框架的对照点。上一轮扩散版的所有结论都是在扩散基线上得出的，换框架后必须重新建立基线，否则任何"加 loss 有效"的结论都无法归因。

顺手要做两件零成本的事：① 测梯度冲突角（记录加辅助损失前后，主损失与辅助损失梯度的夹角）② 确认时间步采样分布（建议 Logit-Normal 起步）。

止损：如果流匹配基线明显差于扩散基线且调不回来 ⇒ 先查是不是损失空间与网络输出空间错配（§5.2 的陷阱），这是最常见的原因。

Stage 1 · 只加最成熟、最确定的蛋白约束
验证的假设：FOD 分布级损失在流匹配里能显著改善表达保真，且不破坏生成质量
第一优先级

做什么：在 x̂₁ 上挂 FOD 的「全局均值 + 20-bin 直方图」两项（16-block 项暂缓，它介于 L2/L3，错位下引边界噪声）。

为什么先做这两项：它们是最纯的 L3 统计量，且分别针对两种最典型的失败模式——整体强度偏（均值项）与表达被压向中间（直方图项）。

消融必须包含的对照（★ 关键）：除了"开/关"，还要跑"全程开"这一臂。因为如果辅助损失在训练早期就压制了主损失，你会得到一个"训练指标很好但生成崩坏"的模型——没有这一臂你分不清"有效"和"有效但用了错误的调度"。

主判据：表达级指标（FOD 分布距离、DAB 相关系数）+ 下游分级一致性。不是 PSNR/FID。

止损：如果表达指标不显著改善，而 FID 也没变差 ⇒ 干净放弃并记为阴性结论（这也是有价值的）。

Stage 2 · 再加一种对空间错位更鲁棒的约束
验证的假设：ranking / 滑片级约束能在错位下进一步保住"表达的空间格局"
第二优先级

做什么：二选一或都做——(a) 区域级表达 ranking 损失（L4，文献空白）；(b) 滑片级 MIL 分级损失（L5，照 MIL-CycleGAN 的做法）。

为什么需要它：Stage 1 的分布级损失不保证空间格局正确——它可以让整图的分布对，但高表达区被挪到别的位置。ranking 项正好补这一格，而且它不需要坐标对应。

顺手做一件便宜的事：把采样器从 ODE 换成 SDE（§5.4，免重训）。这同时解决"一对多"问题——一张 H&E 能生成表达强度不同的多张合法 IHC。

止损：如果 ranking 项让训练不稳（序关系在小区域内噪声大），改用更大区域或分位数分组，而不是放弃这个思想。

Stage 3 · 再考虑 semantic stain representation / 物理渲染
验证的假设：在浓度空间做生成 + 可微渲染，能带来分布级约束拿不到的可解释性与可控性
前置多

做什么：把生成空间从 RGB 换成 [C_H, C_DAB, C_res] 三通道浓度，用可微 Beer–Lambert 渲染回 RGB。蛋白约束直接作用在 C_DAB 上。

为什么排这么后：这是换解码器级的改动（不是加一个头），而且有三个必须先在 Stage 0/1 里解决的前置：① 固定 stain matrix（否则浓度不可比、H-score 无意义）② 非负/值域参数化（必须用天然非负的参数化，不能靠 clamp——clamp 是止血不是治疗）③ 无色轴断言（angle(u, span(M)) > 5° 且 u ∉ cone(M)，确保染色平面不能表示"无色"，否则光照会泄漏进 C_DAB）。

止损：如果换生成空间后生成质量崩坏 ⇒ 停在 Stage 2，并明写"分布级约束已足够、浓度空间不必要"这条边界。

Stage 4 · 如果文献空缺确认，再尝试流匹配原生的蛋白 guidance
验证的假设：把训练期的 φ(x)→FOD 升级成采样期能量，能带来"可控性"这一新能力
有理论支撑

做什么：照 Feng et al.（ICML 2025）的免训练渐近精确 guidance，在每一步 ODE 积分时用 ∇_{x_t} E(φ(x̂₁)) 修正速度场，其中 E 是蛋白能量（例如 FOD 分布距离的负对数似然），x̂₁ = x_t + (1−t)v̂_t 免费得到。

为什么这是"新能力"而不是"更好的损失"：训练期损失只能让模型平均而言表达正确；采样期 guidance 让你在推理时指定"这次我要更强的表达"或"这次我要更接近某个分级"。这是可控性，是一个新问题。

止损：如果 guidance 强度稍大就出伪影（这是 guidance 的经典失败模式）⇒ 记录强度-质量的权衡曲线，把可用的强度区间写进结论，而不是只报最好那一个点。

14★ 回流：流匹配侧的东西，哪些能搬回扩散

前面 13 节都是「把扩散的问题搬到流匹配上」。这一节回答反方向的问题：流匹配侧那些「蛋白条件」机制，能不能拿回扩散里用？——结论是几乎全部能，而这恰恰说明它不构成换框架的理由。

一句话

「条件」与「损失」是整条管线里最与框架无关的两格；真正搬不动的，恰好是流匹配独有的那三样（端点公式、guidance 理论、SB 路径）。所以「把流匹配的蛋白条件搬到扩散」在技术上没有障碍，但在收益上几乎没有意义——因为扩散侧本来就能做条件（StainFuser 已经有两条 condition 通道）。你缺的是训练损失，而训练损失同样与框架无关。

14.2 ★ 一条反方向的实证（这条最有说服力）

SheafStain（SB / 流匹配）的 DAB 强度损失，是从 UNIStainNet 搬过来的。而我这次核实发现：UNIStainNet 既不是扩散、也不是流匹配 —— 它是一个 GAN：SPADE-UNet 生成器 + 无条件 PatchGAN 判别器，单次前向。

原文（我已复核 arXiv 2603.12716 正文）

"Diffusion-based approaches involve iterative inference, whereas GAN-based methods (including UNIStainNet) require only one pass."

"We present UNIStainNet, a SPADE-UNet conditioned on dense spatial tokens from a frozen pathology foundation model (UNI) ..."

"We use a hinge adversarial loss with an unconditional discriminator and R1 gradient penalty, since a conditional discriminator on misaligned pairs learns spatial inconsistency as 'real.'"

⇒ 同一个 DAB 表达损失，已经在 GAN 上用过一次、又在 SB 上用过一次。这从经验上证明了它与生成框架无关。你想把它放进扩散，比 SheafStain 当初搬它更没风险。

★ 顺带核到的两条、与你的架构决策直接相关（arXiv 2603.12716 摘要原文，本轮复核）

① 「可学习染色 embedding」已有公开先例，而且它替代的是「每 marker 一个模型」。摘要原文："learned stain embeddings enable a single model to serve multiple IHC markers simultaneously"，以及 "achieves state-of-the-art distributional metrics on all four stains (HER2, Ki67, ER, PR) from a single unified model, where prior methods typically train separate per-stain models."
⇒ 这正面支持你「单主干 + 独立 marker token」这条设计线：把 marker 身份做成一个可学习向量，而不是为每个 marker 训一个模型，是已被验证可行的，且是在 MIST 的四个 marker 上验证的（正是你的数据集之一）。它只解决了「条件」那一格，没有解决蛋白损失那一格——两件事不要混。

② 它的失败是「系统性的」，而且集中在非肿瘤组织。摘要原文："A tissue-type stratified failure analysis reveals that remaining errors are systematic, concentrating in non-tumor tissue."
⇒ 对你的评价设计有一条直接后果：只报全图平均的 DAB/FOD 指标会把这类失败平均掉。若你要做实例级证据，应当按组织类型分层报（肿瘤区 / 非肿瘤区 / 背景），否则「非肿瘤区系统性偏差」在均值里看不见。这条与评价规范「分布级 ≠ 实例级」是同一件事的两个面。

14.3 为什么「搬蛋白条件」不是重点

三条理由，按重要性排序：

  1. 条件本来就是框架无关的，而且扩散侧已经能做。StainFuser 有两条 condition 通道（controlnet_cond + encoder_hidden_states），SD 有 cross-attention。加一个 marker embedding 是几行代码。你不需要从流匹配侧"搬"条件——你需要的是想清楚条件该喂什么。而这正是任务书 v2 §5.6 在回答的问题：喂配对 IHC = 抄答案；喂非配对 ≈ 一个可学习 token（安不安全取决于 corr(condition, GT)，不取决于架构）。
  2. 你真正的瓶颈不是条件，是训练损失。两轮调研（扩散版 + 流匹配版）都指向同一个空缺：没有任何工作把蛋白表达级信号放进训练损失。而训练损失同样与框架无关——只要你能从预测拿到一张干净图。
  3. ⇒ 流匹配侧对你唯一不可替代的贡献，就是那个端点公式（让"挂损失"更便宜、更稳）。其余机制都是可替代的。

14.4 ★★ 顺手挖到的、比「搬条件」值钱得多的东西：UNIStainNet 的抗错位损失设计

核实 UNIStainNet 时发现：它的整套损失是为「10–50 px 错位的连续切片」专门设计的，而且完全框架无关——每一项都只依赖「生成图 + 真实图 + 输入 H&E」这三个张量。这正面回答了你「错位下怎么挂蛋白损失」这个问题。

原文给出 BCI / MIST 的错位量级是 10–50 px（来自形态差异、组织处理形变、配准误差），并原话承认 "pixel-level losses unreliable"、"pixel-level metrics are unreliable under spatial misalignment"。

做法具体为什么抗错位
★ DAB 损失用尾部统计量L_DAB = 每图 top-10% DAB 强度的均值，λDAB = 0.2（DAB 强度用 Beer–Lambert 颜色反卷积提取）它不是逐像素的。错位会打散像素对应关系，但不会改变"这张图里最强的 DAB 有多强"
配对损失降到低分辨率L1 在 64 px；perceptual 在 128 / 256 px降采样后 10–50 px 错位被压到可忽略
★ 边缘损失挂在「生成图 ↔ 输入 H&E」这一轴L_edge = ‖∇Sobel(x̂) − ∇Sobel(xHE)‖₁，λedge = 0.5这一对是天然像素对齐的（生成图就是 H&E 的产物），即使 GT IHC 不对齐。作者原话："We exploit this asymmetry in loss design."
判别器必须无条件hinge 对抗 + R1 梯度惩罚，不用 conditional 判别器作者原话：conditional discriminator on misaligned pairs learns spatial inconsistency as 'real'
特征匹配L_FM = Σ‖D⁽ˡ⁾(x̂) − D⁽ˡ⁾(xIHC)‖₁，λFM = 10.0提供"抗错位的纹理监督"
★ 对你的直接用处

你要挂的 FOD 分布级损失（全局均值 + 20-bin 直方图）本身就是分布级、天然抗错位——这与 UNIStainNet 的 top-10% 尾部统计量是同一个思路。

UNIStainNet 给了你一个已验证的先例：在 10–50 px 错位的 BCI / MIST 上，一个 DAB 表达级损失确实能训起来，而且消融表显示它有贡献（λ=0.2）。这是"错位下挂蛋白损失可行"的第一个直接证据——比我上一轮说的"PSPStain 的 L_MLPA 没做完整消融"要硬。

另外两条可以零成本顺手抄的（与蛋白无关）

① L_edge 挂在「生成图 ↔ H&E」上，而不是挂在「生成图 ↔ GT IHC」上。这条不涉及蛋白、不涉及配准，纯结构，直接可用。注意它和 §3 里"别锚定 RGB 低频"不冲突——Sobel 边缘是高频。

② 判别器用无条件的。如果你之后加判别器（当前方案没有，但值得记），千万别用 conditional——在错位数据上它会把"空间不一致"学成"真实"。

流匹配侧的蛋白条件几乎全部可搬回扩散（A 档 6 条 + B 档 3 条）。唯一有前提的是 TG 拓扑引导（需先解决可微性）。
决策上
不值得为了"用上这些条件"而换框架。扩散侧本来就能做条件，而且 StainFuser 已经有了两条 condition 通道。
换框架的唯一硬收益
仍然只有一条：x̂₁ 端点免费 ⇒ 挂蛋白损失更便宜、更稳。
这次核实真正的收获
不在"搬条件"，而在于：UNIStainNet 证明了「10–50 px 错位的 BCI/MIST 上，一个 DAB 表达级损失能训起来」，并给出四条可抄的抗错位设计。
