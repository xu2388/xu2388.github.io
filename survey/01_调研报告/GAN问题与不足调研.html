Research report · GAN failure modes

GAN 的问题与不足：原理、失败成因、诊断与可约束改动

本报告从 GAN 的原始博弈目标出发，系统整理训练崩溃、梯度饱和、振荡发散、模式崩溃、棋盘格伪影、判别器过拟合、条件失配和评价指标失真，并把每个问题拆成「成因 → 症状 → 可验证实验 → 可改动位置」。目标不是罗列技巧，而是帮助你围绕 GAN 的真实缺陷设计约束。

对象：GAN / conditional GAN / image-to-image GAN重点：训练稳定性 · 伪影 · 覆盖度 · 可解释约束证据：原始论文、官方 arXiv/会议页面、库内既有报告报告日期：2026-10-13优先级：可复现 > 可解释 > 改动小

0先给结论

一句话判断

GAN 的根本难点不是“生成器不够强”，而是它把生成任务变成了一个非合作的双网络博弈：判别器在变，生成器看到的目标也在变；理论最优解存在，不等于有限步 SGD/Adam 会稳定到达。因此你要围绕问题加约束，第一步应先判断问题属于哪一类，而不是看到伪影就直接换 loss。

最容易犯的三个误判
  1. “loss 下降 = 训练变好”：GAN loss 不是单调的质量指标，旋转博弈可能一边 loss 下降、一边样本恶化。
  2. “FID 变好 = 没有模式崩溃”：单一分数可能把质量与覆盖度混在一起；需要 precision/recall、分层统计和实例级检查。
  3. “WGAN-GP = 已经解决收敛”：它改善了 critic 的约束方式，但已有理论反例表明，有限 critic 更新下 WGAN/WGAN-GP 仍不具有普适收敛保证。
对你的研究最值得优先验证的方向
  1. 先做可观测性约束：记录 D/G 梯度范数、logit、激活范围、NaN 首发位置、样本多样性和分层表达统计。
  2. 再做单因素稳定性：固定网络和数据，只替换一种上采样、一个 critic 正则或一个 D/G 更新比例。
  3. 最后做任务约束：把结构、浓度、表达或物理一致性挂到明确的位置；不要把所有辅助 loss 直接相加后再猜权重。
问题轴根因类别最先测什么最小改动改动成本可复现性
训练崩溃/振荡博弈动力学、D/G 步长与容量不匹配梯度范数、logit、参数/激活是否增长非饱和损失、TTUR、SN 或零中心 GP低–中高
模式崩溃生成器只覆盖容易骗过 D 的少数模式precision/recall、最近邻、多样性分层minibatch discrimination、条件覆盖约束、数据增强中中
棋盘格上采样覆盖不均、频率偏置、损失放大高频随机初始化输出、频谱与局部周期扫描resize-convolution、合适 kernel/stride、抗混叠低高
NaN/Inf/黑图数值范围、归一化、混合精度或激活/梯度溢出逐层 finite check 和首个异常张量修数据范围/AMP、梯度裁剪、降低步长低高
病理/条件错误条件信息不可辨识、错位监督、判别器 shortcut按组织/marker/病例分层，做配准扰动结构/浓度/语义约束；弱配对 loss correction中–高中

1GAN 到底在做什么

1.1 生成器、判别器与博弈

GAN 包含两个模型：

Generator，生成器 G

从 latent noise z∼p_z 生成样本 x̂=G(z)。它试图让生成分布 p_g 接近真实数据分布 p_data。

Discriminator，判别器 D

输入样本并输出“来自真实数据”的概率或 score。它试图区分 x∼p_data 与 G(z)∼p_g。

两者不是串联的普通网络，而是一个 two-player minimax game。Goodfellow 等人在 Generative Adversarial Nets（NeurIPS 2014，arXiv:1406.2661）中给出：在任意函数空间里，目标是让 G 恢复训练数据分布，让 D 在两种来源上都输出 1/2。这个结论是分布级理论结果，不是对实际有限容量、有限步数、随机优化器的承诺。

真实样本 x ~ p_data ───────────► D(x) ──► “real”
                                      ▲
latent z ~ p_z ─► G(z)=x_hat ──────────┘

D：区分真实 / 生成；G：让生成样本骗过 D
两方交替更新 → 目标函数不断变化 → 不是普通的单目标优化

1.2 原始目标函数、最优判别器与 JS 散度

原始 GAN 的 minimax 目标为：

minG maxD V(D,G) = Ex~pdata[log D(x)] + Ez~pz[log(1 − D(G(z)))]

固定 G 时，最优判别器是：

D*G(x) = pdata(x) / (pdata(x) + pg(x))

把这个最优 D 代回去，原论文证明生成器相当于最小化：

C(G) = −log 4 + 2 · JSD(pdata || pg)

所以在理想条件下，p_g=p_data，且 D(x)=1/2。但这里有一个决定性限定：推导假设 D 对当前 G 已充分优化、函数容量足够，并且讨论的是分布级目标。真实训练中 D/G 都是有限网络，只更新有限步，还带 minibatch 噪声。

1.3 一次训练迭代如何发生

  1. 从真实数据采样一批 x，从 latent 分布采样一批 z。
  2. 用当前 G 得到 G(z)，更新 D，使其提高真实样本得分、降低生成样本得分。
  3. 冻结或不更新 D 的参数，更新 G，使 D(G(z)) 变得更像真实。
  4. 重复。此时下一轮 G 看到的 D 已经改变，因此“G 的目标函数”也在移动。

实践中常用 non-saturating generator loss：

LG,NS = −Ez[log D(G(z))]

它与原始 minimax generator objective 具有相同的目标固定点，但在早期 D 很容易识别假样本时，通常提供更强的生成器梯度。需要注意：这只是缓解梯度饱和，不会自动解决模式崩溃、伪影或条件错误。

2问题总地图：先按故障位置分类

同一个“生成质量下降”可能来自不同层。下面这张图是后续诊断的入口。

输入 / 数据层
├─ 数据太少、分布偏、标注或配准错误
└─ 条件信息不可辨识、domain shortcut

博弈 / 优化层
├─ D 过强 → G 梯度饱和
├─ D/G 步长与容量不匹配 → 振荡、发散、循环
├─ critic 约束不当 → 梯度爆炸/消失
└─ 辅助 loss 梯度方向冲突 → 目标漂移、训练抖动

生成器架构层
├─ transpose convolution / 上采样覆盖不均 → 棋盘格
├─ receptive field 与尺度不匹配 → 纹理重复、结构断裂
└─ 归一化/激活/AMP → 数值异常、颜色漂移

分布与评价层
├─ mode collapse / mode dropping → 覆盖不足
├─ FID/IS 单分数 → 质量与覆盖混淆
└─ 局部判别器 → 局部真实但全局/语义错误
一个重要区分

GAN 特有问题：非合作博弈、判别器反馈、模式崩溃、D/G 失衡、critic 约束。
所有生成模型共有的问题：数据不足、条件不可辨识、配准错误、幻觉、评价指标与任务目标不一致。研究设计时要把两类分开，否则容易把“数据本身不提供的信息”误写成 GAN 的缺陷。

3训练崩溃与数值失稳

3.1 梯度饱和与梯度消失：D 先赢时 G 学不到

在原始 minimax 生成器目标中，G 最小化 E[log(1−D(G(z)))]。如果训练早期 D 很强，生成样本几乎都被判为假，即 D(G(z))≈0，这个目标会进入饱和区，传给 G 的有效梯度可能变弱。原始 GAN 论文因此提出 non-saturating 版本，让 G 最大化 E[log D(G(z))]。

可观测现象支持的解释不能单独证明什么最小验证
D(real) 接近 1，D(fake) 接近 0判别器在当前批次过强；与 G 饱和一致不能证明全局 D 已最优，也不能证明只有 loss 的问题记录 logits 而非只记录 sigmoid 后概率
G 梯度范数接近 0可能是饱和、激活饱和、detach 或学习率过小不能仅凭一个 batch 归因逐层梯度、参数 requires_grad、AMP scaler、finite check
样本长期不变G 更新没有有效信号，也可能是 latent 被忽略不等于一定是 mode collapse固定 z 与变化 z 各测一次，比较样本变化

可改动方向：优先切换 non-saturating loss；再检查 D/G 学习率与更新次数；若使用 Wasserstein critic，检查 critic 梯度而不是把 critic score 当概率。不要一开始同时换 loss、网络、数据增强和评价指标。

3.2 振荡、发散与 D/G 失衡：这是博弈动力学问题

GAN 的联合更新场不一定像普通最小化那样直接指向谷底。Mescheder 等人在 Which Training Methods for GANs do actually Converge?（ICML 2018，arXiv:1801.04406）中用 Dirac-GAN 构造反例：存在唯一平衡点，但未正则化 GAN、WGAN 和有限次 critic 更新的 WGAN-GP 并不总能收敛到该点。该结果不是说每次训练都会失败，而是说明“换成某个流行 loss 就有普适收敛保证”是不成立的。

振荡

loss 和样本质量周期性上下波动；某一方刚改善，另一方的更新又把状态推开。常见于 D/G 步长或更新比不匹配，或局部梯度场有明显旋转成分。

发散 / 崩溃

梯度、激活、参数或 critic score 持续增大，图像突然变成常数、噪声或纯黑。可能是步长过大、正则失效、数值溢出，也可能是数据范围错误。

TTUR（Two Time-Scale Update Rule）给 D 和 G 分别设置学习率。Heusel 等人在 NeurIPS 2017（arXiv:1706.08500）中证明，在随机逼近的一系列假设下可收敛到 stationary local Nash equilibrium，并报告在多个数据集上改善 DCGAN/WGAN-GP。正确表述是“在假设下有理论与实验支持”，不是“任意实现都保证收敛”。

3.3 WGAN/WGAN-GP 改善什么，没解决什么

WGAN（ICML 2017，arXiv:1701.07875）把 JS 风格的判别概率目标改为 Wasserstein-1 距离的 critic 目标：

W(Pr,Pg) = sup||f||L≤1 Ex~Pr[f(x)] − Ex~Pg[f(x)]

它的理论动机是：当真实分布和生成分布落在低维流形上时，Wasserstein 距离对生成器参数变化可具有更好的连续性，且 critic 的数值曲线更有诊断意义。WGAN-GP（NeurIPS 2017，arXiv:1704.00028）指出 weight clipping 会导致 critic 过于简单、梯度层间异常等问题，并用输入梯度惩罚替代 clipping：

λ Ex̂[(||∇x̂D(x̂)||2 − 1)2], 其中 x̂ = εx + (1−ε)G(z)

但这个 penalty 是在采样点上的软约束，不等于处处严格满足全局 1-Lipschitz；而 Mescheder 的反例进一步说明有限 critic 更新下 WGAN/WGAN-GP 仍没有普适收敛保证。

研究上应如何使用 WGAN-GP / SN

把它们视为“改变 critic 条件和训练动力学的候选干预”，而不是“理论上已经解决 GAN 崩溃”。实验上应同时报告：训练成功率、梯度范数、样本质量、覆盖度和运行成本。单次最好结果不足以证明稳定性。

3.4 NaN、Inf 与黑图：不要先猜，先定位首个异常

在本轮核实的 GAN 经典论文中，没有一篇给出“所有 NaN/黑图的单一成因”。因此下面是工程诊断假设，不应冒充定理：

优先级候选成因先查什么对应改动
1输入/目标范围不一致，如 [0,1]、[-1,1]、OD 或 log 域混用首个 batch 的 min/max/mean/std，renderer 前后范围统一数据契约，明确每个 head 的物理范围
2激活或梯度溢出，尤其是 AMP、exp/log、除以接近 0 的量逐层 finite check、AMP scaler、exp/log 输入clamp、稳定公式、降低学习率或暂时关闭 AMP

4模式崩溃与覆盖不足

“模式崩溃”不是一个单一现象，至少要区分：

Mode collapse

不同 latent 输入被映射成少数相似输出；生成分布内部多样性不足。

Mode dropping

生成样本可能看起来很真实，但只覆盖真实分布的一部分模式，例如只生成主流类别、主流颜色或主流组织背景。

直觉上，G 可能找到一个容易骗过当前 D 的输出模式，并反复生成它；D 又在这些样本上变强，G 再换一个 shortcut。由于 G/D 同时移动，单纯依靠“看起来没有重复”并不能确认覆盖充分。

4.1 为什么会发生

  • 反馈局部化：D 的梯度只告诉 G 当前边界附近如何变好，不直接给出“还缺哪些真实模式”的覆盖清单。
  • 判别器 shortcut：D 可能利用背景、scanner、边缘、压缩痕迹或 patch 采样差异，而不是目标语义。
  • 条件覆盖不足：条件 GAN 中，少数标签/少数表达等级/少数组织类型更容易被拟合，稀有条件被忽略。
  • 数据不平衡：如果真实数据本身长尾，生成器追逐总体损失时会优先覆盖高频模式。

4.2 如何测：不要只用 FID

Sajjadi 等人在 Assessing Generative Models via Precision and Recall（NeurIPS 2018，arXiv:1806.00035）指出，FID 等单分数难以区分不同失败情况，提出将生成样本的质量（precision）与目标分布覆盖（recall）拆开。Kynkäänniemi 等人在 Improved Precision and Recall Metric for Assessing Generative Models（NeurIPS 2019，arXiv:1904.06991）进一步强调，已有指标可能给出不充分或相互矛盾的结果。

要回答的问题建议指标/实验解释
生成样本像不像真实FID/KID/precision、人工盲评质量维度；不能单独说明覆盖
是否覆盖真实模式recall/coverage、按标签/组织/表达等级分层覆盖维度；需要足够样本与合理特征空间
是否重复生成生成样本两两特征距离、最近邻比例、固定 seed 多次采样检测内部多样性与记忆化
是否保留条件关系condition-to-output accuracy、marker positive/negative recall、病例级相关性条件一致性，不等于整体真实感

4.3 可尝试的改动与证据边界

Salimans 等人在 Improved Techniques for Training GANs（NeurIPS 2016，arXiv:1606.03498）研究了 minibatch discrimination、feature matching、historical averaging 和 label smoothing 等训练技术。它们提供了可操作的稳定化与多样性思路，但论文实验结论绑定于其数据集、架构和训练协议，不能写成“普适消除 mode collapse”。

改动可能作用要验证的预测成本/复现性
Minibatch discrimination让 D 感知同一 batch 内样本的相似性，抑制重复输出内部特征距离上升，同时 recall 不下降中 / 中
Feature matchingG 匹配真实/生成的中间特征统计，减少只追逐单点 D 梯度训练曲线更平滑、覆盖改善，但可能牺牲锐度低 / 高
条件覆盖 loss对表达等级、组织类型或标签分层，防止少数条件被忽略尾部条件 recall 提升，而不是只提升全图均值中 / 中
数据/判别器增强减少 D 记忆或 shortcut，尤其适合小数据train/validation gap 变小，后期 FID 不再恶化中 / 高

5棋盘格与其他生成伪影

5.1 棋盘格的数学/工程成因

棋盘格通常与 decoder 中的转置卷积（transposed convolution，也常被叫 deconvolution）或不恰当的上采样组合有关。核心是输出位置接受到的输入贡献数不均匀：当 stride 与 kernel size 的关系造成 uneven overlap 时，有些输出像素被更多 kernel 覆盖，有些被更少覆盖，固定周期的幅度差异就可能呈现棋盘格。

更具体地说，如果一维上采样的 kernel size 不能被 stride 整除，不同相位位置的覆盖次数通常不同；二维情况下，水平与垂直的覆盖不均相乘，容易形成规则网格。即使 kernel size 可以整除 stride，学习到的卷积权重仍可能偏向某些频率，因此并不代表“数学上完全没有伪影”。

Odena、Dumoulin 和 Olah 的 Distill 文章 Deconvolution and Checkerboard Artifacts（2016）是最直接的机制解释来源；本轮无法稳定抓取该页面全文，因此这里把它作为解释性来源而不是逐字核实的全文证据。Aitken 等人的 Checkerboard artifact free sub-pixel convolution（arXiv:1707.02937）官方摘要明确总结了三类来源：deconvolution overlap、random initialization 和 loss functions。

不均匀覆盖 → 周期性有效增益不同 → 特定频率被放大 → 规则网格/条纹伪影

5.2 为什么 GAN 会把它放大

  • 判别器奖励局部高频：PatchGAN 或局部 critic 可能把锐利、强对比的纹理当作 realism 线索，生成器就有动力保留/放大局部周期信号。
  • 上采样伪影在随机初始化时已经存在：如果模型刚初始化就能看出周期图案，问题不主要来自训练崩溃，而来自架构/初始化；Aitken 摘要对此有明确说明。
  • 损失函数会选择频率：像素、感知和 adversarial loss 的频率偏好不同，伪影可能在多个 loss 竞争时被保留下来。
  • 多尺度输出的相位不一致：不同尺度的上采样路径如果不能对齐，可能造成局部纹理在尺度融合时出现周期性断裂。

因此棋盘格不能简单归结为“GAN 不稳定”：它通常是生成器上采样结构问题 + 训练目标对局部高频的选择共同造成。GAN 训练崩溃会使其更明显，但不是唯一来源。

5.3 可验证的修复路径

方案机制优点风险/边界成本
Resize-convolution先 nearest/bilinear resize，再用普通 convolution把固定尺度变化与可学习卷积分开，通常减少 uneven overlapnearest 可能产生边缘阶梯，bilinear 可能过平滑；不是自动保证无伪影低
合适的 kernel/stride优先选覆盖均匀的组合，如 kernel 能被 stride 整除改动最小，适合作为第一消融只能降低结构性风险，不能消除学习到的频率偏置低
Sub-pixel / pixel shuffle + 合理初始化在高分辨率空间重排通道；使用 convolution NN resize 初始化Aitken 等报告初始化时即可避免棋盘格，并比较了建模能力仍需检查后续卷积与损失是否重新引入频率伪影中
抗混叠/频谱诊断对 feature/output 做频谱约束或频率分层监控能把伪影从视觉描述变成可测信号频谱变平不等于结构更正确；需和任务指标一起看中

最干净的棋盘格实验：固定训练目标、数据和随机种子，只替换 decoder：A 转置卷积；B resize-conv；C 合法 kernel/stride；D sub-pixel + 合理初始化。每种至少多 seed，测随机初始化输出、训练中输出、最终图像的二维频谱峰、周期性自相关和边缘保真。

6数据、条件与判别器的不足

6.1 判别器过拟合：小数据会把 G 的反馈变成坏信号

Karras 等人在 Training Generative Adversarial Networks with Limited Data（NeurIPS 2020，arXiv:2006.06676）明确指出：数据太少通常导致 D 过拟合，进而使训练发散。论文提出 adaptive discriminator augmentation（ADA），不改 loss 和网络架构，通过对 D 看到的样本做自适应增强来降低过拟合，且报告在小数据场景有效。

数据太少 → D 记忆训练集 → D 的反馈不代表目标分布 → G 学到错误方向 → 后期训练发散

可观察症状包括：D 对训练 real/fake 过度自信、训练/验证行为分离、早期质量变好后继续训练反而恶化。ADA 不是万能药：增强过强会引入 augmentation leakage，数据足够时增强也可能伤害性能。

6.2 Patch 判别器的局部真实性陷阱

PatchGAN 擅长判断局部纹理、局部颜色和局部对比度，但它不自动保证全局结构、稀有类别或生物学语义。对 H&E→IHC 尤其要区分：

D 可能管到

局部染色纹理、DAB 的局部对比度、目标域颜色统计、patch-level realism。

D 不能自动保证

哪一个细胞应阳性、阳性是否位于膜而非胞浆、表达等级、细胞结构位置、病例级 marker 分布。

因此“局部看起来很真”与“任务上正确”可以脱钩。已有库内报告 《GAN 虚拟染色：方法路线、独特问题与浓度域先例》已把这一问题映射到 RGB GAN、DAB/OD loss、PALS/PCLS 和错位监督的位置；本报告在此基础上补充通用 GAN 机制。

6.3 条件信息不可辨识与监督错位

conditional GAN 可以让 G 接收图像、标签、文本或 marker token，但“输入了条件”不等于“输出忠实使用了条件”。如果条件信息在数据中弱、稀有或与背景 shortcut 相关，模型可能忽略条件或利用错误线索。

在虚拟染色中，连续切片的像素错位会让 pixel loss 惩罚正确的结构；CycleGAN 可以绕开配对，却不能凭空恢复输入中不存在的 marker 实例信息。库内 DGR 精读明确拆出了 Pix2Pix 的逐像素错位风险、RegGAN 的 warp 后损失漏洞和 DGR 的生成—配准解耦思路。对你的 GAN 改动，建议把“错位鲁棒性”和“GAN 稳定性”做成两个正交消融轴，而不是混为一个新 loss。

7评价指标为什么会误导

7.1 FID、IS 与单一分数的边界

FID 通过特征空间中的均值/协方差统计比较真实与生成样本，能在很多场景提供有用的分布级摘要；TTUR 论文提出 FID 时也强调其相对 Inception Score 更能捕捉生成样本与真实样本的相似性。但任何单一分数都不能同时完整回答“像不像、覆盖多少、条件对不对、是否有局部伪影”。

Sajjadi 2018 和 Kynkäänniemi 2019 的 precision/recall 工作给出一个更适合诊断的拆法：

质量（precision）高、覆盖（recall）低 → 样本很像但 mode dropping
质量低、覆盖高 → 覆盖广但样本不真实
质量与覆盖都高 → 更接近理想
质量与覆盖都低 → 生成分布整体偏离

7.2 对病理/图像翻译任务的额外要求

层级需要回答建议评价不能由什么替代
分布级整体是否接近目标域FID/KID/precision-recall、分层分布距离不能替代实例级正确性
实例级这一张输入的结构/条件是否保留结构相似、边缘/核/膜定位、配准扰动敏感性不能只用 FID
表达级marker 强度和阳性率是否正确IOD、DAB p90、阳性细胞 precision/recall、病例级相关性不能用 RGB MSE 代替
伪影级是否出现周期网格、重复纹理、幻觉细胞频谱峰、重复率、最近邻、专家盲评/幻觉检测不能以“视觉锐利”代替
鲁棒性换病例、组织、scanner、轻微错位后是否仍有效外部集、组织分层、配准扰动、跨域测试不能只报最好 seed

8约束应该放在哪一格

“给 GAN 加约束”必须先说清约束作用于谁。不同位置改变的机制不同，成本和副作用也不同。

位置典型约束主要解决不能保证成本可复现性
G 输出前 / decoderresize-conv、spectral/weight normalization、抗混叠棋盘格、激活爆炸、部分频率偏置条件正确、表达正确、无 mode collapse低高
D 内部Spectral normalization、gradient penalty、feature matchingcritic 条件、D 过强、反馈平滑普适收敛、完整覆盖低–中高
G/D 更新规则non-saturating、TTUR、D:G 更新比、warm-up梯度饱和、振荡、失衡数据错误、结构幻觉低高
G 输出后派生量OD/DAB/FOD、edge、segmentation/feature、结构 loss表达分布、结构、语义这些量本身的不可辨识性与错位误差中中–高
数据 / D 输入ADA、patch 采样、分层 batch、条件随机化D 过拟合、shortcut、长尾遗漏生成器架构产生的棋盘格中高
采样后频谱筛查、异常样本拒绝、不确定性/集成检测和止损从根源改变训练动力学低高
推荐的约束顺序

先结构可见性，再 critic 稳定性，最后任务语义。具体顺序：① decoder 上采样单因素消融；② non-saturating + SN/GP + TTUR 的稳定性基线；③ 分布覆盖与条件覆盖；④ DAB/OD/结构/语义约束；⑤ 最后才考虑多模块联合。每一步都保留一个完全不变的 baseline。

9推荐实验路线与止损标准

9.1 最小可行实验矩阵

阶段唯一变量对照主要指标通过条件
G0 复现基线无当前 GAN 原实现，至少 3 seeds训练成功率、FID/KID、precision/recall、梯度和 NaN能重复得到相近结果，记录全链路日志
G1 梯度稳定non-saturating / SN / GP / TTUR 逐项一次只换一项D/G logits、梯度范数、后期质量、运行时间崩溃率下降且不牺牲 recall
G2 棋盘格transpose conv vs resize-conv vs sub-pixel固定 loss、训练步数、seed随机初始化伪影、频谱峰、自相关、边缘误差伪影下降且结构/高频真实边界不被抹平
G3 覆盖度minibatch discrimination 或 feature matchingG1 最佳基线precision/recall、类/组织/表达分层 recall覆盖提升而不是只降低 FID
G4 任务约束只加一个结构或表达约束G1/G3 最佳基线结构、表达、幻觉、错位扫描改善目标任务且不产生新的训练失稳

9.2 训练监控清单

  • 优化：G/D 学习率、D:G 更新比、每项 loss、每项梯度范数、参数更新范数。
  • 判别器：real/fake logits、训练/验证 gap、不同组织/条件的输出分布。
  • 生成器：固定 latent 的时间序列、不同 latent 的内部距离、每层激活范围。
  • 伪影：随机初始化输出、二维频谱、周期自相关、棋盘周期扫描、最近邻重复。
  • 任务：结构/边缘/细胞定位、表达强度和阳性率、病例级相关性、组织分层结果。
  • 数值：首个 NaN/Inf 的张量、AMP scaler、输入输出范围、所有 exp/log/div 的输入。

9.3 什么时候应该停止当前路线

止损标准
  • 同一配置 3–5 个 seed 中多数出现 NaN/Inf，而首发位置不稳定且无法通过数据契约修正：先停下加模块，回到数值定位。
  • 只要把 adversarial 权重调大就出现结构/表达明显退化：说明目标方向或尺度冲突，不应继续盲调 λ。
  • FID 改善但 recall、尾部条件或实例级表达恶化：拒绝该方案，不把 FID 改善写成成功。
  • 棋盘格在随机初始化输出阶段已出现：优先改 decoder，不要先增加 GAN loss。
  • 训练稳定但条件输出不随条件变化：优先做条件可用性和 shortcut 实验，不要先堆语义 loss。

9.4 可直接写成论文的研究问题

  1. 稳定性约束：SN、GP、TTUR 如何改变 G/D 局部动力学，是否降低 seed 方差而不损失覆盖？
  2. 频率约束：棋盘格是否主要由 decoder 的 uneven overlap 产生，还是由 D 对高频局部纹理的奖励放大？
  3. 覆盖约束：按病例/组织/表达等级分层的 recall 约束，能否比全局 diversity loss 更直接地减少 mode dropping？
  4. 任务约束：结构/浓度/表达约束分别挂在 G 输出、D 输入还是派生量上时，梯度路径与失败模式有什么区别？

本轮明确没有找到的强证据
  • 没有找到任何单一 GAN loss/正则能对任意深度网络、任意数据流形、有限 minibatch 和有限更新次数提供普适收敛保证。
