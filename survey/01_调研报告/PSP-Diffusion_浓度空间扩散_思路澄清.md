# PSP-Diffusion：把扩散的生成空间从 RGB 换到染色浓度场 —— 思路澄清

> 本文是对"Diffusion 输出 Ĉ → Beer–Lambert → RGB IHC"这一范式的一次梳理与校正。  
> 目标不是复述，而是把**真正起作用的机制**和**看起来有用其实空转的部分**分开。

---

## 0. 一句话结论

这个范式真正的价值**不是**"把 RGB 换成浓度这么简单"，而是：

> **把扩散的输出空间从 3 维 OD 空间收缩到 2 维染色平面、并进一步约束到非负象限——  
> 而真实 H+DAB 图像本来就近似落在这张平面上。**

代价是：一旦固定 S，Ĉ 就是 Y 的一个**确定线性重参数化**，你不能再指望它"学到更多"。  
收益是：输出被硬约束在物理可达集合内（消灭幻觉色），且两个坐标**可命名**，  
从而可以在它们上面挂语义损失。

---

## 1. 范式链条（改动点只有一处）

```
H&E
 └─► [结构编码器] + [染色/蛋白条件编码器]  ──► F_cond
                                                │
                              noisy C_t ────────┴──► [条件扩散 U-Net]
                                                          │
                                                          ▼
                                              Ĉ ∈ R^{K×H×W}   (K = 2)
                                              Ĉ = [C_H, C_DAB]
                                                          │
                                          S (固定) ───────┴──► [Beer–Lambert]
                                                          │
                                                          ▼
                                                  X̂ = X₀ ⊙ e^(−S Ĉ)
                                                          │
                                                          ▼
                                                  Virtual IHC RGB
```

**训练时**多一条支路：真实 IHC → OD → 投影到 span(S) → `C_real`，作为扩散的 x₀。  
**推理时**这条支路不存在，只有 H\&E 条件 + 随机噪声。

## 2. 五个必须说清楚的澄清点

### 澄清点 1：固定 S 之后，Ĉ 的"物理意义"来自哪里？

对 H+DAB 这种 **K = 2** 的情形，S ∈ R^{3×2}，方程 `Y = S C` 是  
**3 个方程解 2 个未知数 —— 超定**，最小二乘解唯一：

```
C = pinv(S) · Y = (SᵀS)⁻¹ Sᵀ Y
```

所以 **Ĉ 是可辨识的（identifiable）**，不存在"Ĉ 和 S 互相补偿"的问题——  
这个补偿问题只在 S 可学习、或者 K ≥ 3 时才出现。

> 顺带一个连接：你刚翻译的那篇 InverseAE（IEEE TMI 2026）处理的正是  
> **K > 3 的 mIHC** 情形——那里 S 是 3×K 的欠定系统，无穷多解，  
> 所以他们才需要"Inversion Regulation"来把解空间压回去。  
> 你这里 K = 2，天然没有这个问题，这是你的设计成立的前提，值得在论文里写清楚。

**所以固定 S 的正确论证不是"减少自由度以防补偿"，而是：  
固定 S 让 Ĉ 可辨识，可辨识才谈得上物理意义。**

### 澄清点 2：真正的收益是"可达集合的降维 + 非负"，不是"更好的表达"

|           | 直接输出 RGB / OD   | 输出 Ĉ + 固定 S             |
| --------- | --------------- | ----------------------- |
| 输出自由度     | 3（OD 三通道自由）     | 2（H、DAB），再加非负 → 一个 2 维锥 |
| 可达图像集合    | 整个 OD 空间        | 一张固定的 2 维平面上的锥形区域       |
| 能否生成非物理颜色 | **能**（幻觉色）      | **不能**（被 S 钉死）          |
| 坐标是否有名字   | 否（R/G/B 无生物学含义） | 是（H 量、DAB 量）            |
| 能否挂语义损失   | 只能挂 RGB 像素损失    | 可挂 FOD / 分布 / 稀疏 等      |

**这张表就是这个范式的全部卖点。** 写论文时直接用它做 motivation。

⚠️ 但要注意边界：如果你为了消掉残差而把 S 扩成 **3×3**（H、DAB、背景/残余），  
那么 S 可逆、方程恰好确定，模型又能生成任意颜色 —— **降维收益就消失了**，  
这时"浓度空间"就真的只剩"换了个坐标系"而已。见澄清点 4。

### 澄清点 3：log 底数必须统一，而且它决定 C 的数值尺度

经典 Ruifrok–Johnston 用的是 **log₁₀**：

```
OD = −log₁₀(X / X₀)   ⟹   X = X₀ · 10^(−Y)
```

你原文写的是 `X̂ = X₀ ⊙ exp(−SĈ)`，用的是**自然对数**：

```
OD = −ln(X / X₀)      ⟹   X = X₀ · e^(−Y)
```

两者差一个常数因子 ln10 ≈ 2.303：

```
C_ln = C_log10 / ln10 ≈ 0.434 · C_log10
```

**这不是小事**：它直接改变 C 的数值范围，进而影响扩散的噪声调度和损失权重。  
建议：在代码里显式写死一种，并在论文里写明（推荐沿用 log₁₀，与文献可比）。

另外 **X₀ 怎么取**也要定：全局白点（255）？每张切片估计？逐像素估计？  
逐像素估计会引入信息泄漏（网络可以靠 X₀ 作弊），建议用**每张切片的稳健背景估计**。

### 澄清点 4：残差 —— 训练目标 `C_real` 与 RGB 目标并不自洽

从真实 IHC 分解出 `C_real` 时，实际上：

```
Y_IHC = S · C_real + r ,      r ⊥ span(S)（最小二乘意义下）
```

于是：

```
X_real      = X₀ · e^(−(S·C_real + r))
BL(C_real)  = X₀ · e^(−(S·C_real))
```

**两者不相等。** 也就是说：如果你让扩散去拟合 `C_real`，  
那么渲染出来的 RGB 必然与真实 IHC 有系统性差异，差异 = `r` 经指数放大。

> 在 DAB 深染区（OD 高）指数会放大误差，这是最容易翻车的地方。

**决策分叉：**

| 方案             | 做法                     | 优点              | 代价                  |
| -------------- | ---------------------- | --------------- | ------------------- |
| A. K=2，接受残差    | S = [s_H, s_DAB]，用最小二乘 | 保留 2 维硬约束（核心卖点） | 渲染结果 ≠ 真实 IHC，差一个 r |
| B. K=3，加背景/残余列 | S = [s_H, s_DAB, s_bg] | 精确分解，零残差        | 降维收益消失，退化为换坐标系      |
| C. K=2 + 学 S   | S 与 Ĉ 一起学              | 残差可被 S 吸收       | 重新引入补偿问题，Ĉ 不再可辨识    |

**建议：先做 A，并且把"量残差"作为第 0 步实验。**  
若 `‖r‖/‖Y‖` 很小（H+DAB 主导），A 完全够用；  
若很大，说明真实 IHC 里有第三类成分，再考虑 B 或换染色对。

### 澄清点 5：物理约束挂在哪 —— 大部分"物理损失"在固定 S 下是空转的

你原文正确地指出 `L_phys = ‖BL(Ĉ) − X̂‖` 无意义（因为 `X̂ = BL(Ĉ)` 恒成立）。  
但要说透一点：**固定 S 之后，前向模型的物理性已经全部编码进架构了**，  
再写一个"物理损失"基本只能得到恒等式。真正有效的约束是这几类：

| 损失项                           | 作用对象 | 需要配对？ | 是否有效     | 说明                                          |
| ----------------------------- | ---- | ----- | -------- | ------------------------------------------- |
| `L_RGB = ‖X̂ − X_real‖₁`      | RGB  | 是     | ✅ 主力     | 像素级配对重建                                     |
| `L_C = ‖Ĉ − C_real‖`          | C    | 是     | ⚠️ 半冗余   | 与 `L_RGB` 高度相关，但**在高 OD 区更稳定**（绕开指数放大），值得保留 |
| `L_dist = D(P(Ĉ), P(C_real))` | C    | **否** | ✅ 关键     | 唯一能吃到**无配对**真实 IHC 的通道，是放大数据量的入口            |
| 非负性 `Ĉ = Softplus(C_raw)`     | C    | —     | ✅        | 架构级，不用单独写 loss                              |
| 背景稀疏 / DAB 在非表达区为 0           | C    | 否     | ✅        | 物理先验，且**不等于** RGB 稀疏                        |
| `C_H` 与核密度/核分割相关              | C    | 否     | ✅        | 苏木精染核，是硬先验，可做一致性正则                          |
| `L_phys = ‖BL(Ĉ) − X̂‖`       | —    | —     | ❌ **空转** | 恒为 0，删掉                                     |
| FOD / PCLS / Topology         | 语义   | 视情况   | ✅        | 属于**任务损失**，不是成像损失                           |

> 一句话：**物理性靠架构（BL 解码器 + 固定 S + Softplus）保证，  
> 损失预算应该花在"配对重建 + 无配对分布 + 语义"上。**

## 3. 工程改动清单（相对现有 `psp_diffusion`）

1. **离线预处理**：真实 IHC → OD → 用固定 S 求 `C_real`（最小二乘）→ 存成 2 通道 npy。
2. **扩散 target 换掉**：`x₀_diffusion = C_IHC`（不再是 RGB）。
3. **加一个渲染头**：`X̂ = X₀ ⊙ 10^(−S Ĉ)`（注意底数，见澄清点 3）。
4. **输出激活**：`Ĉ = Softplus(C_raw)`，保证非负。
5. **C 的归一化**（原文没提，但必须做）：C 的分布极度偏斜（背景大量 0、深染重尾），  
   标准高斯扩散假设单位方差。建议**逐通道**做 robust 标准化  
   （如按 99 分位数缩放 / z-score），并保证训练与推理一致。
6. **`C_real` 的负值问题**：最小二乘解可能为负，而预测端是 Softplus ≥ 0 ——  
   **目标与预测的取值范围必须对齐**（要么对 `C_real` 也做 clip/Softplus，要么改用非负最小二乘 NNLS）。  
   这是一个很容易漏、但会让训练发散的具体坑。
7. **噪声调度**：C 的取值范围和 RGB 完全不同，`β` 调度需要重新调（不能直接沿用 RGB 那套）。  
   v-prediction 对偏斜/大动态范围数据更稳，继续用是对的。

## 4. 建议的验证顺序（对你的版本做了一处关键调整）

你的顺序是 `L_H → L_FOD → L_PCLS → Real-IHC dist → Physics`。  
问题在于：**第 0 步应该是先验证"这个分解本身成立吗"，而不是先加损失。**

```
Stage 0（最便宜、最决定性）
  在真实 IHC 上估计 S，算残差 ‖Y − S·pinv(S)Y‖ / ‖Y‖
  看 BL(C_real) 与 X_real 的差距有多大
  → 残差小：K=2 成立，继续
  → 残差大：先解决 S 的问题（加第 3 列 / 换染色对），别急着训扩散

Stage 1  只加 L_RGB
  验证 "Diffusion → 2ch Ĉ → BL → RGB" 能否稳定生成
  重点看：有没有出现非物理颜色？Ĉ 是否非负且空间上合理？

Stage 2  加 L_C + 非负 + 背景稀疏
  验证浓度图本身的质量，而不只是渲染出来的 RGB 好看

Stage 3  加 L_dist（无配对真实 IHC 分布）
  这是把数据规模从"几十张配对"放大到"整个 IHC 库"的关键一步

Stage 4  加 FOD / PCLS / Topology 语义损失
  每个模块单独加、单独消融，贡献才好解释
```

（关于 `L_H`：如果你指的是 hematoxylin 通道的监督，它其实应该归到 Stage 2 的 `L_C` 里；  
如果指 H\&E 输入侧的重建，那它是自监督项，放 Stage 1 也可以。这里建议先明确它的定义。）

## 5. 两通道 vs 单通道：支持你的结论，但补一个风险

同意第一版做 `[C_H, C_DAB]` 两通道，理由你说得对（模型闭合、不用把 H\&E 的苏木精再塞回去）。

补一个风险：**当两个染色向量接近共线时，C_H 会变成"垃圾桶"**，  
吸收本该属于 C_DAB 的误差，反之亦然。H（蓝）与 DAB（棕）差异大，风险低；  
但如果你以后换成染色对相近的（比如两种红色系），这个问题会立刻出现 ——  
这正是 InverseAE 那篇要处理的核心矛盾。

所以建议：**Stage 2 加一个诊断指标**——`C_H` 与核分割掩膜的一致性。  
如果它高，说明 C_H 在干正事；如果低，说明它在当垃圾桶。

## 6. 待确认的三个开放问题

1. **`F_protein` 到底从哪来？** 你的图里 structure encoder 和 protein encoder  
   都吃 H\&E。但 H\&E 里**并不直接含有蛋白信息**，否则虚拟染色就不难了。
   - 如果两个编码器都只吃 H\&E → 请把 `F_protein` 改名为"表达潜变量 / 染色外观先验"，  
     并在论文里如实说明：蛋白是**推断**出来的，不是测出来的。
   - 如果你其实另有输入（连续切片 IHC、或某个 biomarker 预测器的输出）→ 请说明，  
     这会让整篇文章的定位完全不同。  
     **这是目前最需要先钉死的一点。**
2. **H\&E ↔ IHC 是否像素级配准？**
   - 配对 → `L_RGB` / `L_C` 可用，`L_dist` 只是锦上添花（提升数据效率）
   - 不配对 → `L_dist` 变成**唯一**监督，整个训练范式要换成分布匹配 / 最优传输那一套  
     你的文本里两种都提到了，需要明确主场景。
3. **`X₀` 如何估计？**（全局白点 / 每片 / 逐像素）——决定 C 的绝对尺度，也决定是否泄漏。

## 7. 一句话表述（可直接用于论文/答辩）

> 本方法不直接生成 RGB 的 IHC 图像，而是以 H\&E 为条件，  
> 在**染色浓度空间**中采样出一个 2 通道的染色浓度场（苏木精 + DAB），  
> 再通过**显式的 Beer–Lambert 前向模型**完成 IHC 图像形成。  
> 这样生成结果被硬约束在物理可达的染色平面与非负锥内，  
> 既排除了非物理颜色，也让中间表示具备了可命名、可监督的物理含义。
