01结论先行

如果你只看一段，看这一段。

直接回答

没有单一现成模型可以直接拿来做"浓度空间扩散"——所有生成式基座都在 RGB 空间或 Stable Diffusion 的 VAE 隐空间里工作。所以答案是"骨架选 A，表示层必须自己换"。

具体地：以 HistDiST（SD1.5 LDM 工程骨架）为首选基座，把它的 VAE 换成 Beer–Lambert 自编码器（编码器 RGB→C、解码器是可微 BL 渲染、染色矩阵 S 可学），再把条件从 Phikon 的 CLS 嵌入升级为 UNI 稠密空间 token。这样你保住了整套工业级扩散工程（v-prediction、zero-SNR、DDIM inversion、η-cosine 调度、diffusers 生态），同时让生成真正发生在浓度空间。

优先级基座定位一句话理由
首选 HistDiST
arXiv 2505.06793		 工程骨架 唯一成熟、代码公开、病理域已适配的扩散工程；结构保持与生成多样性的解法（DDIM inversion + η 调度）正好命中你的错位数据难题
必移植 Beer–Lambert Autoencoder
arXiv 2601.11336		 表示层组件 直接给你"RGB→C 编码器 + 可微 BL 解码器 + 可学 S"三件套，正是你缺的 VAE

arXiv 2603.12716		 条件注入 + 强基线 冻结 UNI 稠密 token（1024 个 32×32 空间 token）+ FiLM 染色嵌入 + 错位感知损失，全部可直接抄
备选 SPFLOW

慎选 StainDiffuser
arXiv 2403.11340		 架构参考 像素空间 DDPM + 多任务 + 多染色，架构最贴；但官方代码未公开，需自行复现
不要做的事

不要直接拿 Stable Diffusion 的 VAE 隐空间做 Beer–Lambert。SD 的 VAE 是自然图像域训练的，隐空间不可微地映射到 OD 空间，BL 渲染在隐空间里没有物理意义。要么把 VAE 换成染色域自编码器，要么退回像素空间。

一个重要的认知校准

虚拟染色这个领域在 2024–2025 年发生了范式迁移：2024 年前是 GAN 的天下（CycleGAN / CUT / ASP / PyramidP2P / MDCL），2025 年起扩散模型全面反超（HistDiST、MIU-Diff、StainDiffuser），2026 年出现流匹配与基础模型条件化（SPFLOW、UNIStainNet、marker-wise diffusion）。你入场的时间点恰好是扩散刚成为主流、但浓度空间还没人做的窗口期。

03现有方法全景（四代演进）

把 24 篇代表性工作按技术代际铺开，看清演化逻辑。

第一代：颜色映射与色解卷积（经典，非学习）

Macenko、Vahadane、Reinhard 等染色归一化方法，以及经典 Beer–Lambert 色解卷积（Ruifrok & Johnston）。在 OD 空间里染色是可加线性的——这是你整个方案的物理基石，但这类方法只能"分离"不能"生成"。

已知失效边界

经典色解卷积在 K ≤ 3 时是正定或超定的，能解；一旦 K > 3（多重 IHC），逐像素线性解混就变成欠定问题，通道间串扰严重。这正是 Beer–Lambert Autoencoder 这篇论文要解决的问题，也是你 K=2 场景下不存在的问题。

这条旁支的价值被低估了

Beer–Lambert Autoencoder 看起来只是个"色解卷积改进版"，但它提供的组件恰好是你缺的：一个把 RGB 和浓度场双向打通的、可微的、S 可学的自编码器。它现在被用于"从已染色的图里反解浓度"，你只需要把它翻转成"从 H&E 生成浓度"——架构可以整块搬，任务方向反过来。

04关键发现：浓度空间生成是空白

这一节直接决定你的贡献是否成立。

核查结论

我把"生成方向"和"表示空间"两个维度交叉排查了一遍，结果如下：

表示空间 ↓ / 任务 →RGB 空间SD-VAE 隐空间浓度 / OD 空间稠密 marker 场
生成（H&E → 目标） 大量
StainDiffuser, PST-Diff, MIU-Diff, UNIStainNet, ASP…		 多个
HistDiST, Marker-wise, HistDiT		 空白 仅 1 个
SPFLOW（流匹配，非扩散）
分析（RGB → 浓度） — — 若干
BL-AE, InverseAE, PGDIPS		 —
结论：你的思路确实无人占坑

"用扩散模型在浓度空间做生成"这个格子是空的。已有的浓度空间工作（Beer–Lambert Autoencoder、InverseAE、PGDIPS）全部是分析方向——从已经染好的图里反解浓度，用于染色归一化与定量。没有一篇是生成方向——从 H&E 直接生成浓度场再渲染成 IHC。

SPFLOW 是最接近的，但它（a）是流匹配不是扩散，（b）输出的是归一化强度场而非物理浓度，（c）没有 BL 渲染这一步。你的方案在表示空间 + 物理渲染两个点上都比它更靠前。

但这意味着没有现成基座，代价要认

空白 = 没有免费午餐。你不能"下载一个模型然后微调"，必须做表示层替换——这是实打实的工作量，也是你论文的核心贡献点所在。好消息是：所有需要的零件都已经单独存在，只是从来没人把它们拼在一起。

05八个候选基座逐个体检

每个候选回答同一组问题：它是什么、代码在哪、能不能改、致命问题是什么。

1. HistDiST arXiv 2505.06793 · 2025 推荐 · 工程骨架
代码
github.com/ErikGro/HistDiST（官方 PyTorch，含 Google Drive 权重）
框架
Latent Diffusion Model，基于 Stable Diffusion 1.5 微调，diffusers==0.16.1
条件
双路：Phikon 形态嵌入（cross-attention）+ VAE 编码的 H&E 隐变量（通道拼接，InstructPix2Pix 式）
硬件
单/多张 24 GB GPU，300 epochs，batch 16

为什么它是首选骨架

  • 唯一成熟的病理域扩散工程。代码基于 diffusers 官方训练脚本改写，意味着你想要的任何修改（换 VAE、加损失项、改采样器）都有清晰的接入点。
  • v-prediction + zero-terminal-SNR + trailing timesteps 三件套已经实现。这不是花活——它是解决"扩散模型生成 IHC 时亮度分布塌缩"的必要条件。你如果自己搭，大概率会踩这个坑。
  • DDIM inversion + η-cosine 噪声调度：这是全篇最有价值的部分。DDIM 反演把输入 H&E 映射到噪声向量以保结构，但纯确定性采样会让 FID 变差（生成多样性塌缩）；他们用 η_t(t)=0.6−0.4·cos(πt/T) 注入受控随机性，在"结构保真"和"分布真实"之间找平衡点（最优配置：η-cosine 从 20% 处启动）。你的方案要在错位数据上保结构，这套机制几乎是现成的答案。
  • 联合训练（无条件 H&E 生成 + H&E→IHC 翻译）——这是 DDIM inversion 能生效的前提，设计巧妙。
  • 提出 MRA 指标（Molecular Retrieval Accuracy，用 GigaPath 嵌入做分子检索），H&E→Ki67 上比 MDCL 高 28%。这个指标对你也适用。

致命问题

  • 隐空间不可做 Beer–Lambert。SD1.5 的 VAE 是自然图像域训练的，它的隐空间与 OD 空间之间没有可微的物理映射。你必须换掉 VAE，或者退回像素空间。
  • 单染色模型。论文是 per-stain 训练（ER / HER2 / Ki67 / PR 各一个模型），没有统一的多染色条件机制。
  • Phikon 用的是 CLS token 级别的形态嵌入，对"逐像素浓度"来说空间分辨率不够。需要升级为稠密 token（见 UNIStainNet）。
  • 论文没有评估对配准误差的敏感性——这是个未验证项，你用它就要自己补实验。
改造难度

中等。训练脚本、损失、采样器都可复用；主要工作量在"换 VAE / 加浓度头"这一步，以及把条件从 Phikon 换成 UNI 稠密 token。

2. Beer–Lambert Autoencoder arXiv 2601.11336 · 2026 必移植 · 表示层
代码
github.com/measty/StainQuant
作者
Mark Eastwood, Thomas McKee, Zedong Hu, Sabine Tejpar, Fayyaz Minhas（Warwick / Geneva / KU Leuven）
结构
小 U-Net 编码器（两次下采样 + 残差瓶颈 + 两次上采样 + skip）→ K 通道非负浓度图（末端 Softplus）；解码器是可微 Beer–Lambert 前向模型，染色矩阵 S 可学，用典型色素的 OD 向量初始化

它给你的三件套

RGB patch X→ U-Net 编码器 Eθ→ 浓度图 C ∈ ℝ^{H×W×K}_+→ 可微 BL 解码器→ 重建 RGB X̂

公式就是你要的那两行：ô = S·c，x̂ = exp(−ô)。S 初始化自典型色素色相，训练中微调（他们报告 H 从 (0.620,0.637,0.458) 学到 (0.705,0.581,0.408)，MUC2 从 (0.033,0.343,0.939) 学到 (0.028,0.239,0.971)——S 确实能学，且学出来的还在物理合理范围内）。

损失函数（五项，全部可移植）

损失作用对你的价值
L_recL1 重建 + VGG-19 多层感知损失（层 2/7/16/27）基础重建监督
L_ent逐像素通道归一化浓度分布的 Shannon 熵，忽略背景（阈值 τ=1e-2）抑制不必要的染色混合，直接可用
L_colS 与初始估计的逐元素 L1 软锚定防止 S 漂移失去物理身份
L_ovtop-p（p=0.05）重叠惩罚：禁止同一像素同时是多个染色的最强激活降低通道串扰
L_mask稀疏强信号染色的掩码主导损失（色相阈值生成粗掩码）可选

它的局限（你要绕开的）

  • 它是分析方向——输入是已染色的 mIHC RGB，输出浓度。你的任务是反向的。
  • 学到的 S 是面板/队列特定的，跨实验室需微调。
  • 不做绝对定量，只做相对分离（他们没有逐染色真值）。
  • 他们的场景是 K=5（H, CDX2, MUC2, MUC5, CD8）的欠定问题；你的 K=2（H + DAB）是超定的，会更简单。
怎么用

把它的编码器 + 可微 BL 解码器整块搬过来当 VAE：编码器保留（RGB→C），解码器换成 BL 渲染（C→RGB）。训练策略是先在已有 IHC 数据上预训练这个自编码器（自监督，只需 IHC 图，不需要配对），再冻结或半冻结它，把扩散模型放在中间——扩散生成 C，BL 渲染成 RGB，端到端可微。

3. UNIStainNet arXiv 2603.12716 · ACM-BCB 2026 条件层 + 强基线
代码
github.com/facevoid/UNIStainNet（含 HuggingFace Space demo）
结构
SPADE-UNet 生成器 + 冻结 UNI ViT-L/16 稠密 token 条件 + FiLM 染色嵌入；42 M 生成器 + 11 M 判别器，UNI 冻结 303 M
性能
MIST 上四个染色（HER2/Ki67/ER/PR）全部最佳分布指标；BCI 上同样最佳

三个必须抄的设计

  • 稠密空间 token 条件：用 4×4 子裁剪平铺让冻结 UNI 输出 32×32 = 1024 个空间 token（每个 1024 维），比 CLS token 方案多 64 倍空间信息。你要生成逐像素浓度场，必须用稠密条件，CLS 级别的条件在空间上是糊的。
  • 错位感知损失套件：明确针对连续切片 10–50 px 错位设计——感知损失 + 无条件判别器 + DAB 强度监督。这直接回答了你的待确认问题之一：行业做法是承认不对齐，然后让损失对错位不敏感，而不是强行要求逐像素配准。
  • FiLM 染色嵌入：单模型 42 M 参数出四种染色，切换只改嵌入。你的 K 通道 / marker 条件可以天然映射到这上面。
  • 失败分析：零样本组织分类揭示剩余误差是系统性的，集中在非肿瘤组织（MIST 上浸润性癌失败率 <3%）。这个分析框架你写论文时用得上。

为什么不能直接当你的基座

  • 它是 GAN 不是扩散模型。你的技术路线是扩散，直接用它就讲不出"扩散"的故事。
  • GAN 训练的稳定性问题（模式崩塌、判别器失衡）会叠加在你已经很高的改造复杂度上。
正确用法

两个用法：(a) 把它的条件栈（冻结 UNI 稠密 token + FiLM 嵌入 + 错位感知损失）移植到你的扩散骨架上；(b) 直接改它的输出头（K 通道 + Softplus + BL 渲染，约十几行代码），做一个"浓度空间 GAN"作为消融对照——用来证明"扩散比 GAN 更适合浓度空间"这个论点。这是很划算的一步。

4. SPFLOW GitHub 2026 · 预印本 备选 · 表示层
代码
github.com/HIT-JimmyXiao/SPFLOW（MIT License）
任务
从 H&E 预测稠密空间蛋白组场（virtual CODEX / multiplex IHC），而非 RGB
方法
marker 条件流匹配；线性轨迹 z_t = (1−t)·z_coarse + t·y；12 步 Heun 积分

为什么值得认真看

  • 它是唯一一个已经"不输出 RGB"的基座。输出是 224×224×C 的稠密 marker 场（Ultivue C=10，MIST C=4）。对你来说，"把强度场换成浓度场"比"把 RGB 换成浓度场"小得多。
  • marker conditioning 天然对应 K 个染色。可学 marker embedding + 多头 marker 交叉注意力，通道身份稳定可审计。
  • coarse→target 线性轨迹与 BL 渲染天然兼容：t=0 精确等于 H&E 条件粗预测，t=1 精确等于真值，网络只学残差。你的 BL 渲染可以挂在 t=1 端。
  • benchmark 基建很完整：统一协议下对比 HEX、ROSIE、STFlow、HistoPlexer、PyramidP2P、HistDiST 六个方法，有 source-faithful 适配层和逐 marker sidecar。
  • 12 步 Heun + bf16，推理速度远优于 DDPM 的 1000 步。

风险

  • 证据强度弱：单作者预印本，全部结果为单种子点估计（seed 20260518），作者自己标注"完成前不报告 mean ± s.d."。
  • 依赖 H0-mini 权重（CC-BY-NC-ND 4.0，需申请访问），且数据与 checkpoint 不随仓库发布。
  • 它用 Q99.8/log2 归一化，输出的是归一化强度不是物理浓度——你要接 BL 还得做一步标定。
  • MIST 上的外部迁移结果偏弱（v2.7 Pearson 0.516），且作者明确说 v1/v2 在 MIST 上不可靠。
判断

作为思想来源和消融对照极有价值（"流匹配 vs 扩散在浓度空间谁更强"是一个很好的实验），作为主基座风险偏高——证据太薄，且依赖受限权重。

5. StainDiffuser arXiv 2403.11340 · 2024/2025 架构参考 · 代码未公开
作者
Tushar Kataria, Beatrice Knudsen, Shireen Y. Elhabian（University of Utah）
框架
像素空间 DDPM（不是 LDM），双分支同时训练
任务
H&E → CD3 / CK8/18（溃疡性结肠炎监视结肠镜数据）

为什么架构上最贴你的需求

  • 像素空间：改输出通道数 → 加 Softplus → 接可微 BL，三步搞定。这是所有候选里表示层改造最轻的。
  • 多任务设计：染色生成 + 细胞分割两个扩散过程共享 H&E 编码器，通过注意力块交互。在数据有限（几千对而非几百万对）时这个正则化很关键——你的 MIST 场景正好是数据有限。
  • 多染色变体：N 个染色并发生成，用配对 uniplex 数据训练（不需要 multiplex 数据）。
  • 双向变体：无分割数据时，用单个 U-Net 同时训 H&E→IHC 和 IHC→H&E，促进域不变隐空间。
  • 做了 20+ 基线（8 配对 + 15 非配对，含 5 个扩散）的系统评测，是虚拟染色领域少有的完整 benchmark 工作。

问题

  • 官方代码未见公开。论文写的是"接收后开源"，目前检索不到官方仓库——这意味着复现成本。
  • 没有病理基础模型先验，全靠数据量。
  • 论文明确承认未评估配准敏感性（列为 future work）——而错位恰恰是你的核心难题。
  • 推理慢（像素空间 DDPM，无 LDM 加速），论文自列为局限。
  • 数据是自己的结肠数据集（CD3、CK8/18），不在 MIST/BCI 上，数字不可直接比较。
判断

当成架构蓝图读（"像素空间 DDPM 怎么在虚拟染色上做多任务多染色"），但别指望拿到能跑的开源代码。

6. MIU-Diff arXiv 2506.23184 · Springer 2025 思路参考 · 代码未公开
作者
Anran Liu, Xiaofei Wang, Jing Cai, Chao Li（HK PolyU / Cambridge / Dundee）
框架
score-based diffusion（VP-SDE）+ 两阶段训练
关键点
无配对、明确不假设像素对齐

它解决的是你最头疼的问题

  • 明确处理"配对但不对齐"。论文原话："更高的 PSNR 在无配对虚拟染色中并不总是代表更好的生成质量，因为结构不匹配使得像素对齐不可能。"——这句话值得你直接引用。
  • 互信息引导的能量函数做染色风格与组织结构的解耦：因为 H&E/IHC 错位，互信息估计器只在 IHC 域内训练（IHC 图 vs 其梯度图），完全绕开跨域对齐问题。
  • 时间步自适应反向 SDE：λ_t = t/S 控制"先恢复染色细节、后恢复共享结构"的顺序，可调。
  • 局部互信息对比学习（PatchNCE 思路）保证细胞级跨模态一致性。
  • 用了 IOD（Integrated Optical Density）作为临床相关指标——说明这个圈子已经在用光学密度做评价，你的浓度空间叙事有现成的话语体系。

问题

  • 代码未公开（"upon acceptance"，虽已发表但未检索到仓库）。
  • 两阶段 score-based SDE 实现复杂度高于 DDPM，改造成本高。
  • 受显存限制把 1024×1024 缩到 256×256，分辨率损失明显。
  • 超参敏感（N=300、t'₀=40 最优，偏离就崩）。
判断

作为方法论参考读：它的"不对齐怎么办"的思路（在目标域内做互信息估计，绕开跨域对齐）对你极有启发。但别把它当基座——没代码 + 实现复杂。

7. Marker-wise Conditioned Diffusion arXiv 2508.14681 · AAAI 2026 多染色参考
作者
Hyun-Jic Oh, Junsik Kim, Zhiyi Shi, Yichen Wu, Yu-An Chen, Peter K. Sorger, Hanspeter Pfister, Won-Ki Jeong（Korea Univ. / Harvard / CityU HK / HMS）
框架
Stable Diffusion v2 微调，两阶段训练
亮点
单模型生成 18 个 marker；单步推理 0.13 s

值得抄的

  • one-hot marker 条件替代文本条件。消融显示：3 个 marker 时文本和 one-hot 差不多（SSIM 0.667 vs 0.673），18 个 marker 时 one-hot 碾压（0.662 vs 0.288）。如果你的染色数量会增长，这是个必抄的设计。
  • 第二阶段像素级微调 + 单步采样：固定 t=T、用零噪声替换随机噪声，直接在像素空间优化。结果：单步（0.13 s）的 SSIM 0.757 反而超过 50 步 + 10 折集成的 0.673，微调后到 0.836。这直接解决了扩散模型推理慢的问题。
  • H&E 隐变量按 marker 数量复制，让所有 marker 参数更新均衡——一个容易被忽略但重要的训练技巧。
  • U-Net 输入通道加倍时用"复制权重 + 权重减半"初始化（Marigold 做法）。

问题

  • 同样是 SD VAE 隐空间，BL 渲染不可行。
  • 输出是单通道灰度（三通道平均），不是 RGB 染色图，也不是浓度场。
  • 训练用了 4× H100，阶段二在 Orion-CRC 上要 2.5 天。成本高。
  • latent diffusion 导致轻度模糊、某些 marker 过预测（无 skip connection）。
  • 稀有 marker（CD31、FOXP3）相关系数差，因为样本不足。
判断

不是你的基座，但它的 marker 条件机制 + 单步推理微调 两招要抄进你的方案。尤其单步推理那招——你如果要在浓度空间做扩散，采样步数直接决定可用性。

07最终结论：选谁、怎么改

把上面的分析收成一个可执行的决策。

推荐决策

主基座：HistDiST（工程骨架）
必换组件：Beer–Lambert Autoencoder（表示层）
条件层：UNIStainNet（冻结 UNI 稠密 token + FiLM）
可选加速：Marker-wise Diffusion（单步推理微调）

这不是"拼凑"，而是各取所长：HistDiST 提供你改不动的扩散工程，BL-AE 提供你缺的物理表示层，UNIStainNet 提供你缺的病理先验与错位处理。四者的接口（像素/隐空间、条件注入点、损失项）都是清晰可对接的。

三条路线，按你的资源选一条

一个必须提前想清楚的问题

你的方案里 H&E 输入本身不含直接的蛋白信息。浓度空间表示解决的是"输出的物理可解释性"，不解决"信息从哪来"。所以 F_protein 这个条件通路的来源必须先定下来——要么接受"从 H&E 形态学推断蛋白表达"（这是整个虚拟染色领域都在做的事，合法但要明确承认其上限），要么引入外部信号。这件事不解决，浓度空间再漂亮也只是换了个输出编码。

关于 S 怎么设（延续之前的讨论）

你的场景是 H + DAB，K = 2：Y = S·C 是 3 方程 / 2 未知数，超定，最小二乘解唯一 pinv(S) = (SᵀS)⁻¹Sᵀ。所以"S 与 C 互相补偿"的问题不存在（那只在 K ≥ 3 的欠定情形下出现，也就是 BL-AE 论文的 K=5 场景）。

结论：第一版固定 S（用标准 H/DAB OD 向量）是安全的，而且因为超定，C 是可辨识的。让 S 可学主要是为了吸收不同实验室的染色协议差异（BL-AE 的实验显示 S 确实会漂移且漂移方向与串扰一致）。建议：固定 S 起步，把"可学 S"作为消融实验。

10风险清单与备选

提前把可能翻车的地方列出来。

#风险表现与影响应对
R1 BL 渲染的残差问题 Y_IHC = S·C_real + r，其中 r ⊥ span(S)。也就是说即使拿到真实浓度，BL(C_real) ≠ X_real——渲染不出原图。这会让你的重建损失永远有下界。 加一个残差通道（K+1 维，非染色分量）或允许 S 可学来吸收。在论文里明确讨论这个下界，反而是严谨性的加分项。
R2 log 底数不一致 log₁₀ 与 ln 差 2.303 倍。BL-AE 用的是 o = −log(x+ε)（自然对数），经典色解卷积用 log₁₀。混用会让 S 的数值完全错。 全程统一。建议跟 BL-AE 一致用自然对数，并在论文里显式说明。S 的初始化向量也要用同一底数重新标定。
R3 负浓度 vs Softplus 约束 真实数据里可能出现负的 C_real（噪声/背景估计误差导致），而 Softplus ≥ 0 硬约束会让模型无法拟合。 加一个可学的背景/偏置项，或在 OD 域先做背景扣除。别指望 Softplus 能表达负值。
R4 固定 S 时"物理损失"是恒等式 如果 S 固定且渲染就是 exp(−S·C)，那么"物理约束损失"在数学上是恒等映射——它不提供任何额外约束，写成损失项是自欺欺人。 要么让 S 可学（损失才有梯度意义），要么把物理约束改成对 C 的先验（稀疏性、非负性、通道重叠惩罚 L_ent/L_ov），别写成"物理损失"。
R5 F_protein 来源不明 H&E 不含直接蛋白信息。如果方案里有一个"蛋白特征"条件通路但来源说不清，审稿人会直接质疑。 要么明确承认"从形态学推断"（并给出上限分析），要么删掉这条通路。不要含糊。
R6 配准误差主导 MIST/BCI 的 H&E 与 IHC 是连续切片，10–50 px 错位。逐像素的 BL 重建损失会被错位主导，模型学到的可能只是"对齐误差"。 用错位感知损失（UNIStainNet 方案）；评测时明确不把 SSIM/PSNR 当主指标；必要时做人工错位注入实验量化退化。
R7 显存与训练成本 浓度场是逐像素的，LDM 压缩率低（K=2 通道，H×W 全分辨率），比 RGB 隐空间更吃显存。HistDiST 的配置要 24 GB。 用 256×256 patch 起步；或对 C 做轻度下采样（但会损失浓度空间的分辨率优势，需权衡）；或直接用路线 B/C 起步。
R8 SPFLOW 抢先发表 SPFLOW 已经在做"稠密 marker 场"了，如果它下一步加上 BL 渲染，你的贡献窗口会被压缩。 尽快做阶段 2 拿到初步结果；在论文里把 BL 渲染 + 浓度可辨识性作为核心差异点，而不只是"输出不是 RGB"。

如果首选路线走不通，备选怎么降级

  • 如果 HistDiST 的 VAE 替换做不通 → 退到路线 B（像素空间 DDPM），骨架用 I²SB（NVlabs，代码最干净），条件栈从 UNIStainNet 移植。
  • 如果扩散训练不稳定 → 退到路线 C（浓度空间 GAN，改 UNIStainNet），先发一篇"浓度空间表示对虚拟染色的增益"的实证工作。
  • 如果 BL 表示层本身不 work → 转向 SPFLOW 式流匹配（它的 coarse→target 线性轨迹不需要严格的物理渲染，鲁棒性更好），或者把贡献重心从"浓度空间生成"转到"错位鲁棒的虚拟染色"。

11评测口径建议

指标选错，方法再好也讲不出故事。

首要原则：错位数据下不要用 SSIM / PSNR 当主指标

MIU-Diff 论文明确写："更高的 PSNR 在无配对虚拟染色中并不总是代表更好的生成质量，因为结构不匹配使得像素对齐不可能。" 你的 H&E/IHC 来自连续切片，逐像素指标天然被错位污染。把 SSIM/PSNR 降为辅助指标。

指标含义推荐度出处
DAB KL / DAB JSD DAB 通道直方图的分布散度，用 Beer–Lambert 色解卷积算出 主指标 UNIStainNet
IOD / mIOD 积分光密度（Integrated Optical Density），临床相关的染色量指标，衡量阳性信号一致性 主指标 MIU-Diff
DAB p90 Pearson-R DAB 通道前 10% 像素的均值强度，逐图算相关性（即"染色强度"的相关性） 主指标 UNIStainNet
MRA 分子检索准确率：用 GigaPath 嵌入做余弦相似度，检验生成的 IHC 嵌入是否能正确匹配其真值 主指标 HistDiST
FID / KID 分布距离（Inception 特征） 必备 通用
FID-UNI 在 UNI 特征空间算的 FID，比 Inception 更贴合病理语义 建议 UNIStainNet
通道串扰（余弦相似度） 各染色通道之间的平均余弦相似度，越低越好 建议 BL-AE
VIF / Hist 视觉信息保真度 / 直方图相关性（色彩匹配） 可选 MIU-Diff
SSIM / PSNR / LPIPS 像素级相似度 辅助 通用（错位下不可靠）
你的方法应该主打"染色量"指标，这是天然优势

因为你在浓度空间生成，DAB KL / DAB JSD / IOD / 通道串扰 这几个指标是直接从你的输出算出来的，不需要额外的色解卷积步骤。竞品（RGB 空间方法）要先做色解卷积才能算这些指标，多一层误差。这是你的结构性优势，论文里应该把这个作为卖点讲。
