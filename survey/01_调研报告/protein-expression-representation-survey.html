病理图像中「蛋白/分子表达」如何被
表示、量化、保持与约束

一份围绕单一问题的文献调研：当目标染色携带蛋白/分子表达信息时，已有研究究竟用什么手段把「蛋白表达」从视觉颜色变成可测量、可比较、可约束、可验证的数学/物理对象。

唯一核心问题：面对一张包含蛋白表达信息的病理染色图像，科学界如何把「蛋白表达」转成物理量或统计对象？这些对象之间是什么关系？在虚拟染色中，已有方法究竟在哪一层保持蛋白表达？

本报告不评价模型结构优劣（GAN / Diffusion / U-Net / Transformer），不预设 FOD/OD 是正确方向，把 FOD 当作候选方法之一，与 OD、IOD、fluorescence、stain concentration、cell-level expression、spatial statistics、frequency-domain 表示平等比较。

§0核心问题与阅读指引

你的调研需求可以拆成四个递进的问题：

  1. 表示（Representation）：蛋白表达被写成什么数学/物理对象？
  2. 测量（Measurement）：这些对象有没有物理/光学基础？
  3. 约束（Constraint）：在虚拟染色训练中，它们进不进入 loss？
  4. 验证（Validation）：怎么证明"生成的蛋白表达是对的"？
本报告最重要的一条方法论警告 文献中大量论文使用 perceptual loss / feature loss / cycle consistency，并声称"preserves pathology semantics"。这不等于约束了蛋白表达。本报告对每篇论文都单独判断：它有没有真正针对 biomarker / protein expression 的量。凡是只用 perceptual/feature loss 的，本报告一律标记为 非表达约束，不把它算作"蛋白表达约束方法"。
关于 FOD 的先行结论 FOD（Focal Optical Density）不是病理学界的标准物理量。它由 PSPStain（Chen et al., MICCAI 2024, arXiv:2407.03655）提出，定义为 FOD = (OD)α（α 取 1.8），本质是对光密度做的一次幂次重加权，目的是让 loss 更关注肿瘤区（高 OD 区）。目前可检索到的使用 FOD 的论文只有同一研究组的 3 篇（PSPStain → PGVMS → Cross-channel Perception Learning）。它是一个很有参考价值的"物理量 + 数学约束"实例，但把它当成领域主流物理量会严重误判 landscape。

1Executive Summary

这个领域总体采用的思路，可以用一句话概括：

RGB 染色图像 → 反演光学模型得到「染色浓度类物理量」 → 在该物理量上做统计/空间描述 → 用病理学评分或下游临床结局验证

但现实中的文献并不均匀地分布在这条链上。真实的 landscape 是三条彼此脱节的路线：

A. 定量病理学路线（成熟，1990s–今）

OD / IOD / MOD、色解卷积、AQUA 荧光定量、H-score、多重光谱解混、空间点过程统计。这条路把蛋白表达做成可测量对象，做得非常扎实，但基本不涉及生成模型。

Strong 证据充分，是真正的"物理 + 数学"传统。

B. 虚拟染色路线（活跃，2019–今）

H&E→IHC、label-free→IHC、IHC→IHC。绝大多数用 adversarial + L1 + perceptual/feature + contrastive loss，目标是"像"；评价主要用 SSIM/PSNR/FID。2024 年起才出现少量显式使用 OD/DAB 物理量的 loss。

Strong 主流是 image/feature 级约束，不是表达量级约束。

C. 空间生物学 / 空间蛋白组路线（快速上升，2020–今）

把表达放到细胞级/区域级，用 Ripley's K、共现矩阵、Shannon 熵、拓扑数据分析刻画"表达在空间上如何组织"。这条路线在真实多重染色上很成熟，在虚拟染色上刚刚开始（ROSIE、HEX）。

Moderate 用于虚拟染色时证据较少。

D. 频域 / 小波路线（几乎空白）

Fourier / 小波 / 多尺度 loss 在通用图像翻译里很常见，在虚拟染色里只有图像级的 Gaussian Pyramid / Sobel / 频域注意力，没有任何论文把 OD/FOD 表达图送进频域。

未检索到 直接文献。见 §5、§11。

最关键的三个发现

  1. 物理量的"入口"高度统一，但"出口"高度分散。几乎所有方法都以 OD（Beer–Lambert）作为从 RGB 到物理量的入口；但从 OD 出发之后，有人走一阶统计（IOD/MOD）、有人走 H-score、有人走细胞级 OD、有人走光谱解混——没有统一范式。
  2. 「物理量 + 数学约束」确实存在，而且是 2024 年后才真正出现在虚拟染色的训练 loss 里。代表：PSPStain/PGVMS 的 MLPA loss（OD→FOD→均值 + 20-bin 直方图 + 16-block 均值）、UNIStainNet 的 DAB stain loss（Beer–Lambert 解卷积 → top-10% DAB 强度）。这是一个正在形成、但尚未成为主流的方向。Strong
  3. 「物理表达图 + 真空间统计 / 频域 / 形态学约束」在虚拟染色中基本不存在。空间统计只出现在定量病理（Failmezger 2022 的共现矩阵作用于膜 OD；Chervoneva 2021 的标记点过程作用于 CSI）。频域作用于表达图：未检索到。形态学描述子（阳性区形状/尺寸/连通性）作为 loss：未检索到。Weak / 未检索到
必须诚实说明的边界 "未检索到"不等于"从未被提出"。本报告的检索以英文文献为主，覆盖 PubMed / arXiv / Nature / IEEE / Elsevier / Springer / MICCAI / CVPR / AAAI / ICLR 等；可能遗漏非英文文献、非常新的预印本、以及把频域约束写在 supplementary 里的工作。凡属此类，本报告一律标注为 未检索到（不等于不存在）。

3.1 OD / IOD / MOD / AOD —— 最核心的物理量族

3.1.1 Optical Density（OD）

ODC = −log10( IC / I0,C ) = εC · c · l Beer–Lambert 形式：OD 与吸收体浓度 c 成正比，比例系数含摩尔吸光系数 ε 与光程 l
  • 物理含义：标本在通道 C 上对光的衰减（吸收为主）。它是可以直接由像素值计算的物理量，不需要任何模型。
  • 与蛋白表达的关系：OD ∝ cchromogen。而 cchromogen ← 酶放大 ← 一抗结合量 ← 抗原（蛋白）量。这条链每一环都不是线性的，所以 OD 是"染色剂浓度"的直接测量，是"蛋白量"的 proxy，不是直接测量。
  • 必要假设：① 纯吸收、无散射；② I0（背景白光）可准确估计；③ 组织厚度/切片厚度均匀（l 恒定）；④ 在探测器线性范围内（深色区不饱和）；⑤ 染色 protocol 一致。
  • 是否依赖 protocol：强依赖。一抗浓度、孵育时间、显色时间、复染强度都会整体平移 OD 尺度。McCabe 2005（JNCI）用 AQUA 直接证明：抗体浓度从 1:500 改到 1:8000，HER2 高表达与死亡风险的关系方向会反转（RR 从 0.47 变成 1.98）。这是 OD/荧光定量最著名的警示性结果。
  • 易受干扰因素：组织厚度、光照不均（vignetting）、扫描仪色彩响应、染色批次、盖玻片折射、DAB 过染饱和。
  • 是否用于真实定量：是，且是定量 IHC 的默认入口。
  • 是否用于虚拟染色：是，但方式很不同：多数论文只是"用色解卷积把 DAB 通道拆出来做可视化/评价"，少数才把它写进 loss。
  • 经典论文：Ruifrok & Johnston 2001（色解卷积原始论文，Anal Quant Cytol Histol 23:291–299，PMID 11531144）；Vahadane et al. 2016（IEEE TMI 35:1962–1971，DOI 10.1109/TMI.2016.2529665）。

3.1.2 Integrated Optical Density（IOD）

IOD = Σ(x,y)∈Ω OD(x,y) Ω 可为全图、阳性区域、或某个细胞/腺体
  • 物理含义：区域内的"积分吸光度"，物理上正比于该区域染色剂的总量（总量 = 浓度 × 面积 × 光程）。
  • 历史根源：源自图像细胞术（image cytometry）的 DNA 倍体分析（Feulgen 染色 + IOD），后来被中国及国际 IHC 定量文献广泛采纳。它不是 2024 年的新概念，而是几十年的老工具。
  • 在虚拟染色中的用法：PSPStain（MICCAI 2024）把 IOD 与 mIOD 作为评价指标，报告"生成图 IOD − 真值 IOD"的偏差，并明确说 越接近 0 越好。PGVMS（TMI 2026）同样用 IOD。USIGAN（arXiv 2507.05843）用 IoD 与 Pearson-R 作为"临床显著性指标"。
  • 关键陷阱：IOD 同时混合了"浓度"和"面积"两个因素。阳性区面积变大但浓度不变，IOD 也会变大。所以 IOD 不能单独用来判断"表达强度"，这是文献中反复出现的争论（见 §3.1.4）。

3.1.3 Mean / Average Optical Density（MOD / AOD）

MOD = IOD / |Ω| Ω 的取法决定一切：是"阳性区域"还是"全部区域"？
  • 物理含义：区域平均染色剂浓度。
  • 必须注意的术语歧义：文献与软件（ImageJ / IPP）中 "Mean Density"、"Average Optical Density"、"Mean Gray Value" 经常混用，但数值完全不同：
    • ImageJ 的 Mean Gray Value 是 0–255 的亮度值，不是 OD；
    • AOD 常定义为 log(255 / mean gray)，是真实 OD；
    • 若用 IOD / 阳性面积 得"阳性区平均浓度"，若用 IOD / 全图面积 则等价于"阳性面积占比 × 平均浓度"，含义完全不同。
  • 代表性文献：Seyed Jafari & Hunger, "IHC Optical Density Score: A New Practical Method for Quantitative Immunohistochemistry Image Analysis"（Appl Immunohistochem Mol Morphol 2017，PMID 27093452）。该文明确指出 OD 与抗原表达程度成比例，并提出用 OD 替代人工半定量评分。

3.1.4 IOD/MOD 的选择争论（重要）

领域内真实存在的争论 中文与部分国际 IHC 定量实践中长期存在"IOD 派 vs MOD 派 vs 阳性面积占比派"的争论。核心矛盾是：IOD 反映总量（面积×强度），MOD 反映平均强度，%Pos 反映阳性范围。三者对同一张切片可以给出方向相反的结论。这直接说明："蛋白表达"在文献中从来不是一个单一的量，而是一族互相不可替代的量。
相关讨论可见 Rizzardi et al. 2012（Diagn Pathol 7:42，DOI 10.1186/1746-1596-7-42），该文系统比较了数字图像分析指标（%Pos、平均强度）与病理医生目视评分的一致性。

3.2 Beer–Lambert 定律与染色浓度估计

Beer–Lambert 是整个物理路线的公理。它的正确形式与在组织学中的失效边界必须讲清楚。

I = I0 · exp( −Σk εk ck l ) ⇒ OD = Σk εk ck l = ( M · c ) · l 多染料情形：总 OD 是各染料 OD 之和（线性叠加）—— 这正是色解卷积的数学基础

3.2.2 Stain concentration（染色浓度 / 染色密度）

这是物理路线上最接近"蛋白量"的量：

c = M−1 · OD   s.t.   c ≥ 0 ,   c sparse
  • Vahadane et al. 2016（IEEE TMI）是这条路线的奠基工作之一。它明确把"stain density maps"（染色密度图）作为核心中间表示，并用两个物理先验约束求解：① 浓度不能为负（非负性）；② 每个组织区域通常只被一种染料主导（稀疏性）。然后用 NMF + 稀疏正则求解。论文的验证方式值得注意：用"染色密度与 ground truth 的相关性"以及病理医生偏好度来证明方法更好——也就是说，它在 2016 年就已经在做"物理量相关性验证"。
  • Macenko et al. 2009（ISBI）：用 SVD 在 OD 空间估计 stain vector，是另一个被广泛使用的经典。
  • NLTD 2.0（Selaru et al., bioRxiv 2025）：指出线性解卷积在 >3 种染料时失效，提出非线性色解卷积框架，用于多重 IHC 的精确分离。
  • BeerLaNet（Chen et al., MICCAI 2025, arXiv:2510.06592）：把 Beer–Lambert 与 NMF 的求解过程展开（unrolling）成可训练网络，实现物理感知的自适应染色归一化。这是"物理模型 + 深度学习"最干净的结合形式之一。
  • Beer-Lambert Autoencoder（arXiv:2601.11336, 2026）：用 Beer–Lambert 结构约束的自编码器做无监督染色解混，面向多重 IHC。说明这条路线在 2026 年仍在活跃发展。
物理路线的一个关键判断 stain concentration 是"染色剂浓度"的物理量，不是"蛋白浓度"。从染色剂浓度到蛋白量之间隔着抗体亲和力、酶放大非线性、protocol 差异。因此：
  • 说 "OD ∝ 蛋白表达" 是过度声明；
  • 说 "OD ∝ 染色剂浓度，且在 protocol 固定时与蛋白表达单调相关" 才是准确表述；
  • 这也是为什么所有严肃的定量 IHC 论文都强调 protocol 标准化（CAP IHC 验证指南、Taylor & Levenson 2006）。

3.3 色解卷积、stain vector 与 DAB 通道分离

Ruifrok & Johnston 2001 的色解卷积是"物理路线"的技术入口，几乎所有 IHC 定量与虚拟染色论文都间接依赖它。它的数学是：

ODRGB = M · c   ⇒   c = M−1 · ODRGB M 为 3×3 stain matrix，每列是一种染料的单位 OD 向量（stain vector）
  • 物理含义：把混合的 RGB 吸光度分解为各染料独立的吸光度分量（H、E、DAB…）。
  • 必要假设：只有 3 种染料（3 通道）；染料 OD 向量已知或可估计；线性叠加成立。
  • stain vector 的估计方法：手工指定（Ruifrok 原始做法）、SVD 极值法（Macenko 2009）、稀疏 NMF（Vahadane 2016）、非线性方法（NLTD 2.0）。
  • 受什么影响：扫描仪色彩响应、染色批次、组织厚度、染料批次。文献中关于"国际间染色变异"的研究（如 J Pathol Inform 2025 的跨国 stain variability 研究）显示不同中心的同一染色在色空间里差异显著。
  • 虚拟染色中的实际用法：
    • H-DAB 分离作为输入分解：Cross-channel Perception Learning（arXiv 2506.07559）把 RGB HER2 图转换到 HED 空间，分别得到 hematoxylin（核）与 DAB（膜）通道，再分别做感知损失与跨通道一致性。
    • DAB 通道作为 loss 目标：UNIStainNet（arXiv 2603.12716）用 Beer–Lambert 色解卷积提取 DAB 强度，构造 L_DAB 匹配生成图与真值图的 top-10% DAB 强度均值。
    • DAB 膜区掩膜作为任务先验：TDKStain（Peng et al.）从 DAB 通道提取染色膜区域、从 hematoxylin 通道提取核密度图，用密度估计网络预测膜染色强度掩膜。

3.4 FOD —— 它到底是什么，处在什么位置

先把事实钉死 FOD = Focal Optical Density（焦点光密度），出自 Chen et al., "Pathological Semantics-Preserving Learning for H&E-to-IHC Virtual Staining (PSPStain)"，MICCAI 2024，arXiv:2407.03655。它不是病理学既有术语，不在任何定量 IHC 经典文献中出现。

定义

ODC = −log10( IC / I0,C ) = A · cC
FODC = ( ODC )α    with α > 1
α 是"聚焦参数"，论文消融实验得出 α = 1.8 最优（比较了 1.0 / 1.4 / 1.8 / 2.2）

物理含义 —— 老实说

FOD 没有新的物理含义。它只是把 OD 做了一次幂次变换。它的作用完全是优化层面的：由于肿瘤区面积通常远小于非肿瘤区，普通 OD map 里绝大多数像素是低 OD 的背景/间质，这些"容易像素"提供不了有效梯度。取 α>1 后，高 OD 像素被放大、低 OD 像素被压缩，等价于把 focal loss 的思想搬到 OD 域。它是"物理量 × 优化重加权"，不是"新的物理测量"。

3.5 荧光、光谱解混、多光谱/高光谱

3.5.1 Fluorescence intensity 与 AQUA

AQUA（Automated Quantitative Analysis）是荧光路线最重要的经典，由 Yale 团队提出：

  • Camp et al. 2002, Nature Medicine 8:1323–1327, DOI 10.1038/nm791：首次提出 AQUA 算法，实现组织微阵列上蛋白表达的自动化、连续、亚细胞定位定量。
  • McCabe et al. 2005, JNCI 97(24):1808–1815, DOI 10.1093/jnci/dji427：用 AQUA 揭示抗体浓度会反转 biomarker 与预后的关系。

AQUA 的核心机制（值得单独强调）：它不是简单地测"整张图的荧光强度"，而是：

  1. 用 DAPI 或细胞角蛋白 构建区室掩膜：nuclear / cytoplasmic / membrane 分别一个 mask；
  2. 在每个区室内计算目标标记的平均荧光强度，得到 AQUA score；
  3. 用肿瘤掩膜限定只测肿瘤细胞。

这一点对你的研究极其重要：AQUA 早在 2002 年就已经实现了"区室级（核/浆/膜）表达定量"，而这正是虚拟染色论文中大多只停留在像素级的那个层次。它是一个"被虚拟染色社区忽略的、现成的对象级表达表示"。

3.5.2 多光谱 / 高光谱成像与光谱解混

  • 物理基础：线性混合模型 S(λ) = Σi ai Ri(λ) + noise，其中 Ri 是各染料的参考光谱，ai 是丰度。解混得到每个标记的独立丰度图。
  • 代表性工作：Brightfield multiplex immunohistochemistry with multispectral imaging（Laboratory Investigation 2020, DOI 10.1038/s41374-020-0429-0）。该工作用窄带 LED 多光谱成像 + 光谱解混，在明场下实现多重 IHC 定量，并把解混后的每个 biomarker 图与对应的单标 DAB 图做比较来验证准确性。这是"物理解混 + 定量验证"的范例。
  • 高光谱用于虚拟染色：Zhu et al., Comput Biol Med 2024（DOI 10.1016/j.compbiomed.2024.108958）用高光谱成像 + 深度学习做 label-free 胶质瘤虚拟 H&E；Loo et al. 2025（Cancer Res Commun 5:54, DOI 10.1158/2767-9764.CRC-24-0327）用 20 通道自发荧光高光谱做 H&E + 多重免疫荧光虚拟染色。
  • 光谱解混作为 loss 的一部分：在检索范围内没有找到把光谱解混残差写进虚拟染色 loss 的工作。未检索到

4.C.2 直接回答："多少蛋白" vs "蛋白如何组织"

答案分两半 ① 在定量病理 / 空间生物学里：文献确实在做第二层。
Failmezger et al. 2022 是一个干净的范例：它把"膜 OD"作为细胞图的节点值，构造对象级共现矩阵，计算 Homogeneity / Contrast / Correlation / ASM 四个 Haralick 特征 × 4 个邻域半径 = 16 个空间分数；再加上基于 tile 熵的 37 个 tessellation 分数。它的核心结论是：这些空间分数在预后上显著优于"平均表达"（CMET：空间分数 p=0.01，而平均表达 p=0.3；HER2 的多元回归 LR-test p=2.9e-06）。也就是说，空间统计捕捉到了平均表达捕捉不到的信息。

Chervoneva et al. 2021 同理：把 CSI 当作 marked point process 的 mark，构造条件空间指标，明确表达"细胞信号强度在空间上如何分布"。

② 在虚拟染色里：几乎完全停留在第一层。
检索到的虚拟染色工作中，最"空间"的约束是：

  • PSPStain 的 CTPC / PGVMS 的 CPPC：在肿瘤掩膜上做 prototype 一致性 → 区域级而非空间统计；
  • USIGAN：用最优传输构造图像级/组内相关矩阵 → 集合级对齐。
没有任何检索到的虚拟染色论文把 Moran's I / Geary's C / Ripley's K / GLCM 写进 loss 或用作评价指标。

5.2 Wavelet / multi-scale

多尺度监督在虚拟染色中确实存在，但层次是"图像级"

  • PyramidP2P / BCI benchmark（Liu et al., CVPRW 2022, arXiv:2204.11425）：用 4 层 pyramid 对生成图做多尺度监督。这是虚拟染色里最早也最常被引用的多尺度设计。注意：它监督的是 RGB 图像的多尺度重建，不是表达量的多尺度结构。
  • Gaussian Pyramid (GP) loss：在 BCI 提出后成为事实标准，被后续大量工作沿用。PSPStain 的 L_GP（权重 λ_G = 10.0）、PGVMS 的 L_GP、UNIStainNet 的多尺度 edge encoder 都属于这一类。它们都是图像级多尺度，不是物理量多尺度。
  • LapLoss（ICLR 2025, arXiv:2503.05974）：Laplacian pyramid 多尺度损失，用于 I2IT 对比度增强。通用方法，未被用于病理表达约束。
  • Steerable pyramid / scale-space：在检索到的虚拟染色文献中未发现。
一个重要但容易被忽略的区别 文献里常见的说法"多尺度保留表达结构"通常名不副实。GP loss 作用在 RGB 上，它保留的是图像的多尺度外观（包括染色风格），而不是"表达区域在不同尺度上的组织方式"。把 GP loss 当作"表达多尺度约束"是错误的归因。

① 作为训练约束（少见）

  • DeepLIIF：把染色解卷积 + 分割 + 单细胞定量做成一个多任务框架，分割任务与生成任务联合训练 → 这是少数把"细胞级"真正带进训练的框架。

② 作为评价指标（较多）

直接回答："相比 pixel-level expression，cell-level / region-level representation 在虚拟染色中有没有用于保持蛋白表达？"
有，但非常少，且绝大多数只用于评价而非训练约束。
训练约束层面：DeepLIIF、AdvLIF、TDKStain（3 篇量级）。
评价层面：Loo 2025、Cross-channel、PGVMS、UNIStainNet（per-class DAB quantification）等。
不存在把"每个细胞的表达向量分布"或"细胞级表达的直方图"作为 loss 的虚拟染色工作。Weak

7.3 一个重要的时间趋势

2022 → 2026 的真实演变 2022–2023：几乎全部是图像/特征级约束。BCI/PyramidP2P（2022）、ASP（2023）、GramGAN、MVFStain、ODA-GAN。评价指标是 SSIM/PSNR/FID。
2024：出现转折。PSPStain 首次把 OD→FOD 的统计量写进 loss（MICCAI 2024），并首次在评价中引入 IOD/mIOD/Pearson-R 这一组"表达级指标"。
2025–2026：迅速扩散。UNIStainNet 的 DAB stain loss、Cross-channel 的双通道 FOD、PGVMS 的统一多重框架、USIGAN 的 OT 一致性、AdvLIF 的物理启发。同时评价体系也从 SSIM/PSNR 转向 DAB KL、Pearson-r、IOD、TPS/CPS。

结论："把物理量带进虚拟染色的 loss/评价"是一个2024 年才出现、2025–2026 正在快速增长的活跃方向，不是空白，也远未成熟。

7.4 一个被明确指出的方法论问题：SSIM/PSNR 不可靠

多篇论文独立指出，SSIM/PSNR 与虚拟染色的生物学正确性不相关，原因是相邻切片存在固有结构错位：

  • PGVMS（TMI 2026）：明确指出"加入高斯模糊会提高 PSNR/SSIM，同时降低生物学保真度"，因此把 PSNR/SSIM 只当参考。
  • UNIStainNet（2026）：指出不同论文对同一方法（ASP on MIST-HER2）报告的 FID 有 51.4 / 89.3 / 177 三个值，超过 3 倍差异，说明跨论文比较不可靠；并明确说"不同工作用不同的光密度相关性定义（raw IoD 差 / per-pixel Pearson-r / integrated density correlation），使跨论文比较失效"。
  • npj Digit Med 2025 综述：系统梳理了这一点，并因此把评价重心转向临床相关指标。

8.3 一个必须说清的判断

"物理 + 数学"不是新发明，但它被切成了两半 如果把"物理表示 + 数学约束"广义理解，那么定量病理学在 2001–2022 年间已经做得很充分：Ruifrok（OD 分解）、Camp（荧光 + 区室）、McCarty（H-score）、Chervoneva（点过程 + CSI）、Failmezger（共现 + 熵 + 预后）。

真正的"新"在于：把这一整套成熟的定量病理工具，接到生成模型的 loss 上。这件事在 2024 年由 PSPStain 首次做到（OD→FOD→{均值, 直方图, 分块}），2025–2026 年开始扩散。

所以准确的表述是："物理 + 数学"在定量病理中成熟，在虚拟染色中刚刚开始，且目前只用到最基础的三种数学操作（均值、直方图、分块）。共现矩阵、点过程、频域、小波、形态学描述子——这些在定量病理中已有成熟工具——尚未被接入虚拟染色。

9.2 必须警惕的三种混淆

混淆一：把 perceptual loss 当成表达约束 UNIStainNet 同时使用了 LPIPS、edge loss、feature matching loss 和 DAB stain loss。前三个都是外观约束，只有 L_DAB 是表达约束。论文自己在消融中表明，去掉 UNI 条件会同时恶化 FID 与 DAB KL——但不能因此说"perceptual loss 保护了蛋白表达"。
混淆二：把"评价指标"当成"训练约束" IOD/mIOD 在 PSPStain、PGVMS、USIGAN 中主要是评价指标（用来证明生成图与真值图的表达量一致）。只有在 PSPStain/PGVMS 的 FOD 形式下才真正进入 loss。同一篇论文里，"IOD 评价"与"FOD loss"是两个不同的东西，摘要中容易混为一谈。
混淆三：术语歧义 —— "intensity" 到底指什么
写法真实含义范围
RGB intensity原始像素值0–255 / 0–1
gray intensity灰度值0–255（越大越亮，与 OD 反相关）
optical density−log₁₀(I/I₀)0–∞（越大越深）
"mean intensity"（IHC 论文）可能是 gray value，也可能是 OD必须看方法学部分
"DAB intensity"（UNIStainNet）色解卷积后 DAB 通道的 ODOD 尺度
这个歧义是导致"跨论文无法比较"的直接原因之一（UNIStainNet 明确指出了这一点）。

11.5 一张 landscape 地图

Layer 1 · 物理OD / 色解卷积 / 荧光 / 光谱解混成熟
Ruifrok 2001、Macenko 2009、Vahadane 2016、Camp 2002、Lab Invest 2020、BeerLaNet 2025、NLTD 2.0 2025。
这是整个领域的地基。任何"物理表达"讨论都必须从这里出发。
Layer 2 · 统计IOD / MOD / H-score / 直方图成熟（定量病理）
McCarty 1985、Rizzardi 2012、Seyed Jafari 2016。作为虚拟染色 loss 只在 2024 年后出现（PSPStain）。
Layer 1 + Layer 2 的组合在定量病理中早已成熟，但在虚拟染色中刚刚被使用，且只用了最基础的三种操作。
Layer 3 · 空间共现 / 熵 / 点过程 / Ripley's K成熟于定量病理，虚拟染色中缺失
Chervoneva 2021、Failmezger 2022、Spatiopath 2025。
这一层是"物理量 + 空间统计"最直接的可借用对象。虚拟染色目前只有 16-block 均值这种粗糙替代。
Layer 4 · 频域 / 多尺度Fourier / 小波 / 金字塔表达图上未检索到
工具成熟（Focal Frequency Loss 2021、LapLoss 2025），但在病理中只用于图像级（FDA-UNet、GP loss）。
这是检索到的最大空白。但空白 ≠ 有价值，也 ≠ 没人在做。见 §13 问题 6。
Layer 5 · 对象细胞 / 核 / 膜 / 区域级表达成熟（临床主流）
AQUA、DeepLIIF、Ki67 LI、TPS/CPS、Loo 2025。
临床真正认账的粒度。虚拟染色在这一层只有评价，少有训练约束。
Layer 6 · 语义Biomarker status / phenotype / TME / outcome兴起中
ROSIE 2025、HEX 2026、TDKStain 下游分级。
这是目前规格最高、最接近临床落地的方向，但它绕过了低层的物理/空间约束，直接靠大规模配对数据学习映射。
Landscape 的一句话总结 Layer 1（物理）与 Layer 6（语义）都很热，中间的 Layer 3（空间统计）、Layer 4（频域）几乎是空的。而 Layer 2（统计）刚刚开始从定量病理"渗透"到虚拟染色的 loss 里。这个"两头热、中间空"的结构，就是当前领域最真实的形状。

12Most relevant papers —— 最值得精读的论文

12.1 基础方法（物理定量与色解卷积的地基）

1. Quantification of histochemical staining by color deconvolution
Ruifrok AC, Johnston DA · 2001 · Analytical and Quantitative Cytology and Histology 23(4):291–299 · PMID 11531144
为什么必读：色解卷积的原始论文。OD、stain vector、stain matrix 的数学全部在这里。任何"物理表达"路线的起点。
2. Structure-Preserving Color Normalization and Sparse Stain Separation for Histological Images
Vahadane A, Peng T, Sethi A, et al. · 2016 · IEEE Transactions on Medical Imaging 35(8):1962–1971 · DOI 10.1109/TMI.2016.2529665
为什么必读：把"stain density"（染色密度）作为核心中间表示，并显式引入两个物理先验（非负、稀疏）。这是"物理表示 + 数学约束"在病理领域最早的漂亮范例之一，且它的验证方式（染色密度与 GT 的相关性）值得直接借鉴。
3. Automated subcellular localization and quantification of protein expression in tissue microarrays (AQUA)
Camp RL, Chung GG, Rimm DL · 2002 · Nature Medicine 8:1323–1327 · DOI 10.1038/nm791
为什么必读：区室级（核/浆/膜）蛋白定量的经典。虚拟染色社区几乎完全忽略了它，但它 2002 年就解决了"在哪个空间尺度上定义表达"这个问题。
4. Automated Quantitative Analysis (AQUA) of In Situ Protein Expression, Antibody Concentration, and Prognosis
McCabe A, Dolled-Filhart M, Camp RL, Rimm DL · 2005 · JNCI 97(24):1808–1815 · DOI 10.1093/jnci/dji427
为什么必读：证明抗体浓度可以反转 biomarker 与预后的关系（RR 0.47 ↔ 1.98）。这是做任何"定量蛋白表达"时最重要的警示。
5. Quantification of immunohistochemistry — issues concerning methods, utility and semiquantitative assessment II
Taylor CR, Levenson RM · 2006 · Histopathology 49(4):411–424 · DOI 10.1111/j.1365-2559.2006.02513.x
为什么必读：系统梳理 IHC 半定量的方法学陷阱。做物理路线之前必须知道"OD 到底能证明什么、不能证明什么"。
6. Beer–Lambert law for optical tissue diagnostics: current state of the art and the main limitations
2021 · Journal of Biomedical Optics · PMC8553265
为什么必读：BLL 在组织光学中的失效模式清单。散射、厚度、饱和、背景——全部列全。

12.2 物理定量（IOD / OD / 光谱 / 解混）

7. Quantification of spatial tumor heterogeneity in immunohistochemistry staining images
Chervoneva I, Peck AR, et al. · 2021 · Bioinformatics 37(10):1452–1459
为什么必读：把"细胞信号强度（CSI）"作为标记点过程的 mark，构造条件空间指标。这是"物理量 + 真空间统计"在病理中最直接的范例，也是你要做空间约束时最该先读的一篇。
8. Spatial heterogeneity of cancer associated protein expression in immunohistochemically stained images as an improved prognostic biomarker
Failmezger H, Hessel H, Kapil A, Schmidt G, Harder N (AstraZeneca) · 2022 · Frontiers in Oncology 12:964716 · DOI 10.3389/fonc.2022.964716
为什么必读：本报告中最重要的一篇"OD + 空间统计"文献。把膜 OD 做成对象级共现矩阵（Haralick 式），加 tile 熵与 EDI，共 53 个空间分数，并证明空间分数在预后上优于平均表达（p=0.01 vs 0.3）。如果你要做"物理表达图 + 空间统计约束"，这篇是必须吃透的先例。
9. Brightfield multiplex immunohistochemistry with multispectral imaging
2020 · Laboratory Investigation · DOI 10.1038/s41374-020-0429-0
为什么必读：明场多光谱 + 光谱解混做多重 IHC 定量，并把解混结果与单标 DAB 图比对验证。是"光谱物理量"路线的最佳入口。
10. IHC Optical Density Score: A New Practical Method for Quantitative Immunohistochemistry Image Analysis
Seyed Jafari SM, Hunger RE · 2016/2017 · Applied Immunohistochemistry & Molecular Morphology · PMID 27093452
为什么必读：MOD / OD score 的标准引用，明确指出 OD 与抗原表达程度成比例。
11. Quantitative comparison of immunohistochemical staining measured by digital image analysis versus pathologist visual scoring
Rizzardi AE, et al. · 2012 · Diagnostic Pathology 7:42 · DOI 10.1186/1746-1596-7-42
为什么必读："数字定量 vs 目视评分"的早期系统比较，是理解"看起来像 ≠ 定量一致"的实证基础。
12. Adaptive Stain Normalization for Cross-Domain Medical Histology (BeerLaNet)
2025 · MICCAI 2025 · arXiv:2510.06592
为什么必读：把 Beer–Lambert + NMF 的求解过程"展开"成可训练网络。"物理模型 → 可微分网络"最干净的实现参考。

12.3 虚拟染色（与蛋白表达相关）

13. ★ Pathological Semantics-Preserving Learning for H&E-to-IHC Virtual Staining (PSPStain)
Chen F, Zhang R, Zheng B, Sun Y, He J, Qin W · 2024 · MICCAI 2024 · arXiv:2407.03655 · code: github.com/ccitachi/PSPStain
必读第一位。FOD 的提出者，也是"物理量（OD→FOD）+ 数学统计（均值/直方图/分块）写进 loss"的首次实现。L_MLPA = avg + 20-bin histo + 16-block。评价引入 IOD/mIOD/Pearson-R。你的想法与它的差别，必须建立在读懂这篇的基础上。
14. ★ PGVMS: A Prompt-Guided Unified Framework for Virtual Multiplex IHC Staining with Pathological Semantic Learning
Chen F, Zhang R, Hu W, et al. · 2026 · IEEE Transactions on Medical Imaging · arXiv:2602.23292 · code: github.com/ccitachi/PGVMS
必读。同一组的最新工作。把 FOD + MLPA + prototype 一致性扩展到多重 IHC 统一框架，并引入 CONCH-FID。同时是"FOD 路线目前的天花板"——看清它做了什么、没做什么。
15. ★ UNIStainNet: Foundation-Model-Guided Virtual Staining of H&E to IHC
Saurav JR, Pham TLH, Mukherjee P, Yi P, Orr BA, Luber JM · 2026 · arXiv:2603.12716
必读。把 Beer–Lambert 色解卷积的 DAB 强度用成 loss（top-10% 分位数匹配）与评价（256-bin KL）。同时它对"跨论文指标不可比"的分析非常清醒，值得学习它的问题意识。
16. Cross-channel Perception Learning for H&E-to-IHC Virtual Staining
Yang H, Wu JY, Fang R, et al.（复旦中山医院）· 2025 · arXiv:2506.07559
必读。FOD 路线的扩展：区分 hematoxylin 通道与 DAB 通道，各自做 FOD 统计约束 + 跨通道一致性。并引入 3 位病理医生的 PCPA/SIA 人工指标。

Li F, Hu Z, Chen W, Kak A · 2023 · arXiv:2303.06193
必读（作为对照）。纯特征级约束的代表，同时发布 MIST 数据集（HER2/Ki67/ER/PR），是后续所有 FOD 路线论文的公共评测基准。
18. BCI: Breast Cancer Immunohistochemical Image Generation through Pyramid Pix2pix
Liu S, et al. · 2022 · CVPRW 2022 · arXiv:2204.11425
必读。BCI 数据集的来源，也是 Gaussian Pyramid loss 在虚拟染色中的源头。理解"多尺度"在虚拟染色里到底指什么。

Peng Y, Xiong B, Chen F, et al. · 2025 · arXiv:2507.05843
建议读。最优传输一致性 + 明确的 IoD/Pearson-R 评价。是"分布/集合级约束"的代表。
21. Label-Free Virtual HER2 Immunohistochemical Staining of Breast Tissue Using Deep Learning
Wu Y, et al. · 2022 · BME Frontiers 2022:9786242 · DOI 10.34133/2022/9786242
建议读。label-free → 虚拟 HER2 IHC 的首次演示，并用 3 位乳腺病理专家做 HER2 评分验证。在 2022 年就做了"专家评分验证"。

Yu Q, Shao C, et al. · 2026 · Journal of Digital Imaging · DOI 10.1007/s10278-026-02320-4 · PMID 42773343

13核心疑问逐条回答

Q1在病理蛋白表达量化中，FOD / OD 是不是常见路线？它处于整个方法体系中的什么位置？

OD：是，而且是绝对主流。OD 是 Beer–Lambert 直接给出的物理量，从 Ruifrok 2001 起就是 IHC 定量的默认入口，IOD/MOD/H-score 全部由它派生。Strong

FOD：不是。它只在 3 篇论文中出现，且全部来自同一研究组（SIAT，秦文健组）。

论文年份venue
PSPStain（FOD 首次提出）2024MICCAI 2024
Cross-channel Perception Learning2025arXiv 2506.07559

FOD 在方法体系中的位置：它是一个二阶概念——必须先有 OD（一阶物理量），再对 OD 做幂次重加权得到 FOD。它不提供新的物理信息，只改变优化时各区域的权重。因此它在体系中的位置是"OD 的一种任务导向重参数化"，属于 Level 1（物理）与 Level 3（统计）之间的一个变体。

准确表述：OD 是领域公认的物理入口（Strong）；FOD 是一个已被验证有效、但尚未被社区广泛采用的工程技巧（Moderate，单一研究组）。把两者混为一谈会严重高估 FOD 的地位。
Q2除了 FOD / OD，还有哪些"具有物理意义"的表达表示？

Q3虚拟染色研究中，研究者是直接约束蛋白表达的物理量，还是更多依赖 image-level / feature-level / perceptual loss？

证据明确：绝大多数依赖 image-level / feature-level / perceptual loss。Strong

具体计数（本报告覆盖的虚拟染色工作中）：

  • 仅使用通用图像/特征约束（adversarial + L1 + perceptual + PatchNCE + SSIM + pyramid + cycle）：Rivenson 2019、Liu 2022 (BCI)、Li 2023 (ASP)、GramGAN、MVFStain、ODA-GAN、Star-Diff、DiffVS、DGR、PaPIS、UNIStainNet 的大部分损失项 —— 占绝对多数。

Q5有没有 physical + spatial / physical + frequency / physical + morphological 约束？

① physical + spatial：有，但粗

  • 训练约束中：PSPStain / PGVMS 的 L_MLPA-block（16 个 block 的 FOD 均值）——这是分块均值，属于最粗粒度的空间分布描述，不是空间统计。PSPStain 的 CTPC / PGVMS 的 CPPC 在肿瘤掩膜上做 prototype 一致性——属于区域级约束。USIGAN 的 OT 相关矩阵——属于集合级。
  • 定量病理中（未接入虚拟染色）：Failmezger 2022 的对象级共现矩阵（真正的空间统计，作用于膜 OD）；Chervoneva 2021 的标记点过程（作用于 CSI）；Spatiopath 2025 的 Ripley's K（作用于细胞/TME，不含 OD）。
结论：physical + spatial 存在，但在虚拟染色中只有 block 级和 prototype 级；真正的空间统计量（共现矩阵、点过程、Moran's I、Ripley's K）从未进入虚拟染色的 loss。这是"存在但浅"的典型。

② physical + frequency：未检索到

检索范围内没有任何论文把 OD/FOD/DAB map 送入 Fourier / 小波域并构造 loss 或评价。频域/多尺度方法在病理中确实存在，但作用对象是 RGB 图像（FDA-UNet 用于染色归一化；GP loss 用于图像多尺度重建；Frequency-spatial interaction 用于细胞检测）。最接近的是 Focal Frequency Loss（ICCV 2021）与 LapLoss（ICLR 2025），但都是通用 I2IT 方法，未涉及病理表达量。

③ physical + morphological：部分存在，层次很浅

  • 存在：TDKStain 的膜染色强度掩膜（区域）；AdvLIF 的核分割（边界）；DeepLIIF 的细胞分割（对象）；UNIStainNet 的 Sobel edge loss（但作用于 RGB，非表达）。
  • 不存在：把阳性区域的形状描述子（面积、周长、紧凑度、离心率、连通分量数、簇大小分布、分簇程度）作为虚拟染色的约束或评价。检索未发现。
直接回答：研究者确实约束了"区域"，但约束的是区域的位置/掩膜/边界，不是区域的形态学统计量。后者（形状、大小、聚集状态）在检索范围内是空白。

14总范式判断：那条链条存在吗？

Image → Physical representation → Quantitative / Spatial representation → Constraint → Biological validation

答案是：这条链在文献中分散地存在，但没有任何一篇论文完整地走完它。

链条环节是否有文献做到代表工作缺口
① Image → Physical representation✔ 完全成熟Ruifrok 2001、Vahadane 2016、BeerLaNet 2025无缺口
② Physical → Quantitative representation✔ 成熟IOD/MOD/H-score、AQUA、Loo 2025 的 TPS/CPS无缺口
③ Physical → Spatial representation△ 存在于定量病理，虚拟染色中缺失Chervoneva 2021、Failmezger 2022、Spatiopath 2025虚拟染色只到 block/prototype
④ → Constraint（进入 loss）△ 只有一阶/分布/粗空间PSPStain 2024、PGVMS 2026、UNIStainNet 2026空间统计/频域/形态学未进入 loss
⑤ → Biological validation△ 分散、标准不一Wu 2022（专家评分）、Loo 2025（TPS/CPS）、HEX 2026（临床结局）多数论文仍只用 SSIM/PSNR/FID

文献实际呈现的三条分散路线

路线 I：定量病理（闭环，但不含生成）

Image → OD/荧光 → IOD/MOD/H-score/共现/点过程 → 预后或临床指标

完整闭环，有生物验证。但没有生成模型，因此没有"约束 loss"这一环。

路线 II：虚拟染色（有生成，但约束浅）

H&E → 生成 IHC → 图像/特征损失 → SSIM/PSNR/FID（少量 IOD/Pearson）

有生成与约束，但物理量与空间统计极浅；生物验证多为单点。

路线 III：物理量 loss 的新兴线（2024–）

RGB → DAB OD → FOD → {均值, 直方图, 分块} → loss → IOD/Pearson 验证

这是最接近完整链条的一支，但只覆盖了统计层的一小部分，且集中在 1–2 个研究组。

路线 IV：语义级端到端（最高规格）

H&E → 细胞级蛋白表达谱（40 marker） → 临床结局

ROSIE、HEX。跳过了低层的物理/空间显式约束，靠大规模配对数据直接学映射，用临床终点验证。

最终判断 不存在一个统一的范式。现实是四条分散的路线：定量病理路线（成熟但无生成）、虚拟染色路线（有生成但约束浅）、物理量 loss 新兴线（最接近完整链条但很窄）、语义级端到端路线（规格高但跳过低层约束）。

最显著的"结构性裂缝"：定量病理在 2021–2022 年就已经建立了"细胞级 OD + 共现矩阵 / 点过程 / 熵"这套成熟的空间表达表示（Chervoneva 2021、Failmezger 2022），而虚拟染色在 2024 年后才开始使用"OD + 均值/直方图/分块"这种最基础的形式。两套文献之间几乎没有引用关系。
