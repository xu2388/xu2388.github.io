你手上的摘要已经把核心思想、两个渲染方程、验证数字、幻觉声明都抓住了，而且抓得很准（我逐条核对过，没有错误）。本次调研补上的是可操作层：

✅ 新增 1：工具箱本体是可安装的软件

名字是 multiplex2brightfield，pip install multiplex2brightfield 即可，BSD 3-Clause 许可，源码在 GitHub（主仓库 + 分析仓库两个）。你的摘要里没有这个名字——这是最关键的缺失，因为没有它你无法真正用起来。

✅ 新增 2：标题里的「AI-based channel selection」是一个独立功能

论文标题的核心卖点之一，你的摘要完全没提。它用 LLM（ChatGPT 5 / Gemini 2.5 Pro / Claude Sonnet 4.5）自动决定「哪个 marker 通道映射到哪个染色类别」，H&E 上共识 Jaccard 达 0.909。这是它相对传统化学染色模拟方法的真正差异点。

✅ 新增 3：深度学习模块是 NAFNet，不是随便一个 U-Net

架构、复合损失（L1 + SSIM + 图像梯度）、训练策略（随机降采样再最近邻上采样、三种噪声模拟）都拿到了。这对你判断「它的增强会不会引入幻觉」很关键。

✅ 新增 4：6 套数据集的完整 DOI 与分辨率

全部可下载地址、样本数、marker 数、像素尺寸都核实了。我并进一步做了标记物覆盖度分析——这是决定它能否用于你 BCI/MIST（HER2/Ki67/ER/PR）任务的关键（见 3.3 与 8.4）。

⚠️ 新增 5：一个你可能没注意的关键限制

它的 eosin（伊红）不是真正的胞质染色，而是「从可用的蛋白通道拼出来的」——论文原文承认这一点，并说这导致「一些对组织类型分类重要的特征可能看起来与真实 H&E 不同」。这对「用它生成准真值」的计划有直接影响。

⚠️ 新增 6：一个利益冲突声明

通讯作者 TW 是 Minogame Limited 的创始人兼股东，该公司销售研究中使用的 ScanXm 软件。这不影响方法本身，但在评估「工具箱中立性」时值得知道。

一句话结论：工具箱是真实的、可用的、开源的，而且它的 Beer–Lambert 前向模型与你已经计划要做的「M1 物理输出头」是同一个数学模型——这意味着你的扩散模型输出与它的输出可以放在同一个物理空间里比较。但它不能直接给你 HER2/Ki67 的真值，因为公开数据集的组织类型和 marker 面板与 BCI/MIST 不完全对齐（详见 3.3 与 8.4）。

2物理正演模型（完整方程与参数）

2.1 两类渲染模型：加性 vs Beer–Lambert

论文给出了两个并列的渲染模型。加性模型是简化版，Beer–Lambert 是论文实际采用的物理版。

式 (1) · 类别强度图（先把 marker 通道聚合成「染色类别」） Ii = (1 / Ni) · Σm=1..Ni M̃i,m

其中 M̃i,m 是归一化后的第 m 个 marker 图像，Ni 是分配给第 i 个染色类别的 marker 数量。这就是「AI-based channel selection」的落点——LLM 决定的正是「哪些 marker 归到哪个类别」。

式 (2) · 加性模型（线性减色，简化版） R = cR − Σi=1..n ki · Ii · (cR − Si,R)
G = cG − Σi=1..n ki · Ii · (cG − Si,G)
B = cB − Σi=1..n ki · Ii · (cB − Si,B)
式 (3) · 物理模型（Beer–Lambert 指数衰减）—— 论文实际采用 R = dR + (cR − dR) · exp( − Σi=1..n ki · Ii · (cR − Si,R) )
G = dG + (cG − dG) · exp( − Σi=1..n ki · Ii · (cG − Si,G) )
B = dB + (cB − dB) · exp( − Σi=1..n ki · Ii · (cB − Si,B) )
两个模型的形式差异说明了什么

加性模型是「线性减色」：浓度加倍，颜色加深一倍。
Beer–Lambert 是「指数衰减」：浓度加倍，透射光按指数下降。
论文指出物理模型更忠实，因为它复现了「染料浓度与透射光之间的非线性关系」——这是真实显微镜下染色切片的成像规律。论文并说明该模型是推广自 Giacomelli et al. (2016) 的物理方法。

2.3 染色类别定义

H&E：四个类别
  1. 蓝色苏木素（blue hematoxylin）→ 细胞核
  2. 粉色伊红（pink eosin）→ 细胞外基质 + 细胞质
  3. 紫色伊红（purple eosin）→ 上皮组织
  4. 红细胞（erythrocytes）
IHC：两个类别
  1. 蓝色苏木素（复染，细胞核）
  2. 棕色（DAB，对应目标蛋白 marker）

只有两类，意味着所有 marker 的表达强度被平均后统一渲染成棕色——这是一个重要的简化。

2.4 颜色值从哪来

  • H&E 的默认颜色是针对多种显微镜分别标定的，做法是「与 MIDOG 挑战赛（Mitosis Domain Generalization Challenge） 的显微镜特异性图像做颜色匹配」。
  • 缩放常数 ki 允许模拟染色变异。论文展示了改变苏木素强度 kH 与伊红强度 kE 的效果，与实验观测到的变异一致（Runz et al., 2021）。
  • 论文明确承认：「染色颜色与缩放参数是手工调节以逼近该数据集的 H&E 图像的」。

2.5 与 PSPStain 的 FOD 的关系（这一节对你最重要）

🔗 两个模型其实是同一个物理量

回顾你的基线 PSPStain：它的 PALS 策略使用 FOD（Focal Optical Density，焦点光密度图）来保持蛋白表达水平的一致性。

而光密度的定义就是 OD = −log(I / I₀)，这正好是 Beer–Lambert 定律的对数形式。

关键恒等关系 ODi = −log( Itransmitted / Iincident ) = Σi ki · Ii · (c − Si)

也就是说：这个工具箱的指数项里的 Σ ki Ii (c − Si)，本质上就是「多通道叠加后的光密度」。
所以工具箱的输出与 PSPStain 的 FOD 损失处在同一个物理量的不同表示上——一个是 OD 的指数变换（RGB 像素），一个是 OD 本身。这意味着：

  1. 你可以对工具箱的输出做 −log 反变换，得到「由真实分子数据正演出的 OD 图」。
  2. 把这个 OD 图与你的模型输出的 FOD 图直接比较——它们应该在数值上可比。
  3. 这比比较 RGB 图像要严谨得多，因为 RGB 比较受颜色标定影响，OD 比较是物理量比较。
✅ 由此得到一条具体的行动建议

把「与工具箱的 OD 域一致性」作为你的第五层评价指标，加在已有四层金字塔（图像相似 / 语义一致 / 物理合规 / 临床效用）之上或之中。
具体地：把工具箱的正演 OD 图当作「物理可行域的一个锚点」，衡量你的模型输出到该锚点的距离。

3.2 对你最关键的两套数据

① Human-Colorectal-Cancer-CyCIF（ORION 数据集）
40 例 · 18-plex IF + 同片 H&E · 0.325 μm · 公开
价值最高 同片配对
为什么它最特殊

ORION 方法的定义特征就是：在同一个组织切片上同时获得 18-plex 免疫荧光和临床标准的 H&E 图像。原始论文（Lin, Chen, Campton et al., Nature Cancer 2023）的原话是：「Orion 是一种创新的多模态成像方法，允许从同一样本快速获取 18-plex 免疫荧光和 H&E 图像」。

这意味着——这是你唯一能同时拿到「真实 H&E」和「分子真值」的公开数据集。而且两者是同一张切片、像素尺寸完全一致（都是 0.3250 μm），不需要跨切片配准。

② Human-Breast-Cancer-IMC（Jackson et al. 2020）
73 例（论文表格）· 乳腺癌 TMA · 1 μm · 公开 · 48.2 GB
组织类型匹配 分辨率存疑

优势：这是乳腺癌数据，与你的 BCI / MIST 任务组织类型一致。原始论文是 Nature 578:615 (2020)「The single-cell pathology landscape of breast cancer」，Bodenmiller 组的工作，数据集在 Zenodo 记录 3518284，包含 OME-TIFF 栈、单细胞掩膜、肿瘤/间质掩膜、单细胞与病人元数据。

乳腺癌 IMC 面板通常包含 HER2、ER、PR、Ki67 等临床标志物——如果确认包含，那么它可以支撑「用物理正演生成 HER2 IHC 参照」这个用法。

⚠️ 两个必须核实的点
  1. marker 列表要核实：论文表格写 53，原始论文写 35 个 biomarker。以 OME-TIFF 元数据的实际通道名为准。需要确认是否真的含 HER2 / Ki67 / ER / PR。
  2. 分辨率是 1 μm，正好踩在红线：论文自己说「当像素尺寸不够分辨细胞时（约 >1 μm），图像应检查是否出现明显幻觉」。1 μm 的 IMC 是这套数据里最粗的分辨率（CyCIF 0.325 μm、CODEX 0.377 μm、IF 0.344 μm）。在这个分辨率上，细胞级结构（核形态、膜染色模式）无法可靠恢复。

结论：乳腺癌 IMC 数据适合做标记物层面的可行性预研（验证「HER2 表达高的区域，正演的棕色确实更深」这类区域级结论），但不适合做细胞级或像素级的定量验证。

5你摘要里漏掉的核心功能：LLM 自动通道选择

这是论文标题里明确列出的卖点（"with AI-based channel selection"），也是它相对传统化学染色模拟工具的真正差异点。

5.1 它解决什么问题

痛点

多重大成像的数据有几十个通道，通道命名五花八门（CD3、CD3e、Anti-CD3、CD3_1……）。要把它渲染成 H&E，你必须先决定：哪些通道归到「苏木素」，哪些归到「伊红」，哪些归到「红细胞」？传统做法是手工配置，费时且不可扩展。

5.2 机制

工具箱把这个问题交给 LLM：

  1. 给 LLM 一个提示词，内容包含：① 任务说明；② 目标染色名称；③ 该染色的类别列表（每类带描述和颜色）；④ 多重大图像的全部通道名列表。
  2. 解析 LLM 的输出，得到「每个类别对应哪些通道」。
  3. 这些通道随后用于式 (1) 的强度图计算。
论文原文：「The LLM is provided with a prompt that explains the task at hand, the name of the stain, and its associated classes with a description and color, as well as the complete list of channel names from the multiplex image. The output of the LLM is then parsed to obtain the list of channels for each class, which are then used in the subsequent image synthesis process.」

完整提示词在代码仓库里（multiplex2brightfield）。

支持的 LLM

ChatGPT（OpenAI）、Gemini（Google DeepMind）、Claude（Anthropic）。评测时使用的具体版本是：ChatGPT 5 Thinking Extended、Gemini 2.5 Pro、Claude Sonnet 4.5。

5.3 一致性评测结果

方法：在 Mouse-IMC-STPT 的 36 个通道名上测试。因为没有真值标注，所以以三个 LLM 的共识作为参照，计算每个模型与共识的平均 Jaccard 相似度，再对三个模型取平均。

💡 对你的启发

这个功能对你的直接价值是：如果你手上有多重数据（IMC / CODEX / CyCIF），你可以用 LLM 快速建立「通道 → 染色类别」的映射，而不用手工翻文献查 marker 生物学功能。这在做数据探索阶段能省很多时间。
但注意：Jaccard 0.7–0.9 衡量的是「三个 LLM 之间有多一致」，不是「LLM 与生物学真值有多一致」。三个模型可能一起错。所以论文的「谨慎验证」提示是必要的。

6深度学习增强模块：NAFNet（为什么刻意不用 GAN / 扩散）

6.1 架构与复合损失

项目详情
基础架构NAFNet（Chen et al., 2022），原本为图像复原设计
实现在 TensorFlow / Keras 中重实现，做了微调：用步长卷积 + 最近邻上采样替代原版的 pixel shuffle / unshuffle
定位论文明确称之为「确定性复原网络」（deterministic restoration network），与「可能为了照片真实感而牺牲忠实度」的生成式方法（GAN、扩散）相对
复合损失三项之和：
① L1 项——约束输出与参考保持忠实
② SSIM 项——抵消过度平滑
③ 图像梯度损失——显式惩罚边缘梯度差异，保护细胞核与组织边界的细节
训练策略
  • 超分上采样器训练：把输入图像随机降采样，再用最近邻插值放大回原始尺寸（这会产生阶梯状伪影，为模型提供「原始分辨率」的线索）；输入还做随机模糊，促使模型在推理时具备去模糊能力。
  • 去噪训练：向输入加入模拟噪声——高斯噪声、泊松噪声、热像素。噪声按常规加在 RGB 或 HSV 分量上；但对于由 IMC / 荧光数据导出的虚拟 H&E，做法是先把图像分解为苏木素、伊红、DAB 三个分量，对每个分量加噪后再转回 RGB。
  • 另外使用标准颜色抖动与随机旋转/翻转。
  • 推理：虚拟明场图先用最近邻插值缩放到目标分辨率，再以滑动窗口方式应用模型。
💡 一个值得借鉴的细节

「在苏木素/伊红/DAB 分量上分别加噪，再转回 RGB」——这个做法说明作者理解染色通道分解的价值：噪声在染色分量上模拟，比在 RGB 上模拟更符合物理。这与你报告里的「苏木素通道锚定」（M2 模块）思路同源。

6.2 关于幻觉：论文原文声明

🚫 原文（讨论部分）

「尽管模型的设计目标是减轻幻觉，但仍存在模型引入虚假结构的可能性，例如把热点簇误判为细胞，特别是在分辨率较小、深度学习模型需要大幅上采样时。如果像素尺寸不足以分辨细胞（约 >1 μm），应当检查图像是否出现明显幻觉。对于出现此类顾虑的情况，也可以改用传统的滤波方法作为替代。」

为什么选择 NAFNet 而不是 GAN / 扩散（原文）
「与 pix2pix 这类生成对抗网络（Tahmid et al., 2023）或扩散模型（Ho et al., 2020）等生成式方法不同——这些方法可能为了照片真实感而牺牲忠实度——NAFNet 作为确定性复原网络运行，最小化幻觉风险。为在训练中强化这一目标，我们采用了由 L1 项、结构相似性（SSIM）项和一个额外的图像梯度损失构成的复合损失。」

⚠️ 这张表怎么读（重要）

这张表是作者为论证自己方法优越性而构造的，不是中立的第三方评测。它的每一条在「输入是高质量多重大成像数据」的前提下都成立，但有一个隐含前提你需要看穿：

物理方法之所以「低幻觉」，是因为它不做任何推断——它只是把已有的分子信息渲染成颜色。它不需要「猜」组织形态，因为组织形态在分子数据里已经存在（细胞核 marker → 苏木素）。
而你的任务（H&E → IHC）恰恰是反问题：你必须从形态推断分子。这个推断本身就无法避免不确定性——物理方法在这个问题上帮不了你，因为它需要分子输入，而你没有。

🎯 这个认知差是理解全文的关键

工具箱解决的是 分子 → 图像（正问题，确定性，无幻觉）。
你解决的是 图像 → 分子（反问题，不确定，必然有幻觉风险）。
它们是互补的，不是竞争的。工具箱不能替代你的方法，但它可以给你的方法提供一个物理上确定的参照锚点。这正是第 8 节要展开的内容。

8对你项目的迁移评估 ★核心章节

你摘要里写的迁移思路是：「用这个工具箱生成一个「物理上正确」的 IHC 参照集；用它检验你的扩散模型输出是否偏离物理可行域。这是低成本获得「准真值」的最佳路径」。

这个思路方向是对的，但「准真值」这个词需要修正。下面我把它拆成可执行的东西。

8.1 它能给你什么：不是「真值」，是「物理前向投影」

先把概念分清
概念定义工具箱能否提供
真值（Ground Truth） 同一张切片、同一位置的、真实的化学染色 IHC 图像 不能
它渲染的是分子数据，不是化学染色过程
物理前向投影 把已知的分子状态按物理规律投影到「应该呈现什么颜色」 能
这正是它的功能
物理可行域锚点 「给定这套分子数据，IHC 图像在物理上可能是什么样」的一个具体实例 能
这是它对你最有价值的用途

为什么这个区分重要？因为它决定了你能在论文里怎么表述你的验证：

❌ 不能这样写

「我们用物理正演方法生成了 IHC 真值，我们的模型与其达到 PSNR XX」

审稿人会立刻指出：物理正演不是真值，而且它的 PSNR 相对真实 H&E 也只有 20.8——用它当基准，基准本身就有噪声。

✅ 应该这样写

「我们用物理正演方法从独立获得的分子数据构造了一个物理可行域锚点，并检验生成结果在该锚点上的一致性。这是一种三角验证（triangulation），用于检验生成结果是否偏离物理可行域，而非替代真值评估。」

这个表述既诚实，又比「只报 FID」强得多。

8.2 三个可行用法（按价值排序）

用法 A · 把它的 Beer–Lambert 前向模型搬进你的物理输出头（M1）
价值最高 成本最低 零风险

这是唯一一个「今天就能做、不需要任何新数据」的用法，而且我在 2.5 节已经论证了它的物理基础。

✅ 具体做法
  1. 用 pip install multiplex2brightfield 装好工具箱。
  2. 找到它的 Beer–Lambert 渲染函数（在 multiplex2brightfield/ 包内，对应式 3）。
  3. 把它改造成可微版本（PyTorch），作为你扩散 U-Net 的输出头：网络预测 K 个非负的浓度/光密度通道 → 经 Beer–Lambert 可微前向 → RGB。
  4. 由于你的 PSPStain 的 PALS/FOD 本来就工作在光密度域，FOD 损失可以直接挂在这个浓度通道上，不需要额外的颜色反卷积。
为什么这是「最高价值 + 最低成本」
  • 零风险：这是架构改造，不涉及任何额外损失或数据，不会引入梯度冲突问题。
  • 物理链条完整：你的模型输出的是「浓度」，这是一个有物理意义的量，而不是 RGB 像素。这直接回应了你第二份报告里「不能保证符合真实物理成图规律」的问题——因为现在成图规律是你自己写进模型里的。
  • 参考实现免费：BSD-3-Clause 许可，可以直接改。
  • 与工具箱输出天然可比：两者用同一个前向模型，所以你的输出和它的输出处在同一个物理空间。这为用法 B 铺路。
用法 B · 用 ORION-CRC 建立三角验证协议
价值高 成本中 有领域错配

ORION-CRC 数据集（40 例，同片 18-plex IF + 真实 H&E，0.325 μm）是你唯一能同时拿到真实 H&E 与分子真值的公开数据。虽然它是结直肠癌而不是乳腺癌，但：

💡 关键认知

你要验证的是「方法」而不是「疾病」。你的扩散模型是 H&E→IHC 的通用映射。用结直肠癌数据检验它，可以回答「我的模型在物理上是否自洽」这个问题——而这个问题的答案与组织类型无关。
至于「在乳腺癌上表现如何」，那要用你自己的 BCI/MIST 数据来回答（这本来就是你的主实验）。

具体协议见 8.3 节。

用法 C · 用乳腺癌 IMC 数据做标记物层面的预研
价值中 成本中 分辨率硬限制

Jackson et al. (2020) 的乳腺癌 IMC 数据（Zenodo 3518284，48.2 GB）组织类型与你的任务一致，marker 面板很可能包含 HER2/ER/PR/Ki67。

⚠️ 但必须先做两个检查
  1. 下载后先读 OME-TIFF 的通道名列表，确认是否真的含 HER2 / Ki67 / ER / PR。论文表格写 53 通道，原始论文写 35 个 biomarker——以元数据为准。
  2. 确认分辨率是否够用：1 μm 是这套数据里最粗的。论文自己说「>1 μm 时应检查幻觉」。所以只能做区域级（region-level）而非细胞级（cell-level）的验证——例如「HER2 高表达区域，正演的棕色是否确实更深」。

定位：这是「可行性预研」，不是主实验。跑通它能回答「这条路在我关心的 marker 上是否走得通」，成本不高，值得做。

8.3 一个可执行的验证协议（用法 B 的展开）

把「三角验证」写成一个可以照着做的流程。前提：你已经在 ORION-CRC 上跑通了你的 H&E→IHC 模型（哪怕只是零样本推理）。

准备
  · 数据: ORION-CRC（40 例，同片 18-plex IF + H&E，0.325 μm）
  · 工具: multiplex2brightfield（pip 安装）
  · 前提: 选定一个你关心的 marker（ORION 面板里有 Ki67 等增殖标记）

Step 1 · 构造路径 A（学习路径）
  真实 H&E  →  你的扩散模型  →  生成的 IHC
  然后做颜色反卷积，分离出:
      H_A   (苏木素通道)
      DAB_A (棕色通道 = marker 表达)

Step 2 · 构造路径 B（物理路径）
  18-plex IF  →  multiplex2brightfield  →  正演的 IHC
  同样做颜色反卷积，分离出:
      H_B, DAB_B

  ⚠️ 关键: 用同一套颜色反卷积矩阵处理两条路径，否则比较无意义

Step 3 · 转到光密度域（而不是比较 RGB）
  OD_A   = −log(DAB_A / I₀)
  OD_B   = −log(DAB_B / I₀)
  → 这一步是必需的。RGB 比较受颜色标定影响，OD 比较是物理量比较。
    而且这一步让结果与 PSPStain 的 FOD 直接对接。

Step 4 · 三层次比较
  (a) 全局一致性
      · 整片的 OD 分布是否接近（KS 检验 / 直方图重叠度）
      · 区域级 Pearson r（在组织区域上取均值，而不是逐像素）

  (b) 空间模式一致性
      · OD_A 与 OD_B 的通道级相关系数
      · 高表达区域的 IoU（阈值化后比较「哪些区域被判为阳性」）
      → 这一层最重要。它检验的是「你模型找到的表达区域对不对」，
        而不是「颜色像不像」。

  (c) 分级一致性（最接近临床）
      · 按 OD 均值做二分类/三分类（阴性/弱阳/强阳）
      · 计算 Cohen's κ（与路径 B 的分级比）

Step 5 · 报告
  必须同时报告:
    · 一致性指标（上面的 a/b/c）
    · 一个"下界"参照: 路径 B 自身相对真实 H&E 的质量
      （论文给的 PCC 0.62 / MS-SSIM 0.72 / PSNR 20.8）
      → 你的模型不可能比这个"物理上限"更好，报告时要说明
这个协议的三个设计要点
  1. 比较 OD 而不是 RGB。因为 OD 是物理量，RGB 是标定量。而且 OD 让你的结果与 PSPStain 的 FOD 损失直接对接。
  2. 重点看「空间模式一致性」而不是「像素相似度」。你的模型不可能逐像素复现物理正演的结果（因为输入模态不同），但它应该在高表达区域与物理正演一致。这才是「物理可行」的正确检验方式。
  3. 必须报告路径 B 自身的质量作为上限。论文已经诚实报告了 PCC 0.62——这不是一个很高的数。如果不说清这一点，审稿人会说「你的基准本身就不准」。

8.4 四个必须注意的错配

错配具体表现应对
① 领域错配 你的任务：乳腺癌（BCI / MIST）。论文主验证集：结直肠癌 CyCIF。 把结直肠数据用于「方法级验证」（物理自洽性），把乳腺癌数据用于「任务级验证」。在论文里明确区分这两类验证的目的。
② 标记物错配 ORION 18-plex 面板不含 HER2 / ER / PR（见 3.3）。你关心的 marker 不在里面。 ORION 用于方法验证时，选一个面板里确实存在的 marker（如 Ki67 类增殖标记）。不要硬凑 HER2。
③ 分辨率错配 ★ IMC = 1 μm、CODEX = 0.377 μm、CyCIF = 0.325 μm；而你的 BCI/MIST 大约在 0.25–0.5 μm（20×/40×）。1 μm 的 IMC 不足以恢复细胞级结构——论文自己说 >1 μm 要警惕幻觉。 在 1 μm 数据上只做区域级结论，明确声明不做细胞级。优先用 CyCIF（0.325 μm）和 CODEX（0.377 μm）做需要细节的验证。
④ 染色模型错配 ★ 两个子问题：
(a) 工具箱的 IHC 只有两类（苏木素蓝 + 棕色），所有 marker 表达被平均后统一渲染成棕色——丢失了不同 marker 的空间分布差异。
(b) 工具箱的 eosin 是从蛋白通道近似出来的，不是真正的胞质染色——虚拟 H&E 的胞质/间质纹理是近似的。		 (a) 比较时按 marker 单独正演，不要把多 marker 平均。
(b) 绝对不要用虚拟 H&E 作为你模型的训练输入——那会引入系统性纹理偏差。虚拟 H&E 只能用于验证，不能用于训练。
🚫 一个必须避免的做法

不要用工具箱生成「虚拟 H&E → 虚拟 IHC」的合成配对来训练你的模型。
原因：① 虚拟 H&E 的 eosin 是近似的（错配 ④b）；② 这样得到的是「合成→合成」的配对，其中的映射关系是你自己的前向模型定义的，而不是真实生物学定义的。用它训练等于让模型去拟合一个你自己造出来的物理模型——会得到一个在合成数据上完美、在真实数据上失效的模型。
这是这个方向最容易踩的坑，因为它在技术上完全可行，而且训练 loss 会很漂亮。
