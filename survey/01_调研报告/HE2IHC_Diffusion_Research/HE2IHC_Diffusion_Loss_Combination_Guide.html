Training Objectives for Diffusion Models

噪声预测损失与其他损失能否一起训练？
—— 扩散模型多损失联合优化的理论、证据与实操配方

回答「条件生成需要多个损失，但噪声预测损失才是核心，其他损失到底能不能一起加」这个问题

检索时间：2026-10-01 覆盖文献：30+ 篇 前置报告：解耦学习 / 物理合规性 结论：可以加，但必须保护噪声损失的主导地位

0摘要与核心结论

一句话结论

能加，而且大量工作确实这么做。但「加」的方式有讲究——直接加权求和是最差的做法之一。
噪声预测损失的重要性不是「它的权重应该最大」，而是它是唯一一个让网络保持"生成模型"身份的项。辅助损失若在梯度方向上与它冲突，就会把 εθ 推离真实的 score 场，导致采样器失效。
正确的做法是：① 保护噪声损失的主导地位；② 只在梯度方向一致时才让辅助损失发力；③ 在训练末期关闭辅助损失。

0.1 先纠正一个理解偏差

⚠️「噪声预测损失最重要」这句话的准确含义

它不是说「它的数值应该最大」或「它的权重应该占 90%」。
它的准确含义是：只有噪声预测损失在直接优化生成分布 pθ(x)。其他所有损失都在优化「某个从 xt 到期望输出的映射」，但它们不保证这个映射是一个合法的 score 场。

打个比方：
噪声预测损失 = 发动机（决定车能不能动）
其他损失 = 方向盘 / 导航（决定车往哪开）
方向盘不能替代发动机。但如果方向盘打得太猛，车会翻。——这就是直接加权求和的真实后果。

0.2 五个必须记住的判断

判断结论与证据
① 辅助损失确实被大量使用StainDiffuser 用 L = L_gen + λ·L_seg（λ=1 或 3）；DisDiff (NeurIPS 2023) 用 L = L_simple + λ·L_dis；MIU-Diff 用去噪损失 + 局部对比损失；ADD 用蒸馏损失 + 对抗损失。这是主流做法，不是异端。
② 但直接加权求和会灾难性失败Lantern 的受控实验（唯一变量是梯度组合规则）：纯去噪基线 FPD 30.87；加上辅助损失后用 PCGrad/GradNorm/IMTL-G/ConFIG 组合，FPD 变成 68.5 / 60.3 / 406.9 / 204.7——最差恶化 100 倍以上。而加权求和 + 无调度的不确定性加权「使 FPD 恶化了数个数量级」。
③ 冲突的本质是梯度方向，不是损失量级Lantern 实测去噪梯度与辅助梯度的冲突角 θconf ≈ 92°–128°（>90° 即相互对抗）。所以调 λ 是治标——真正要处理的是方向。
④ 训练末期必须关闭辅助损失Lantern 的调度消融（同一架构、同一损失、唯一变量是门控时间）：
S1（一开始就开）FPD 173.4 / S2（warmup 后开，保持到结束）FPD 236.3 / S3（末期关闭）FPD 32.84 ← 唯一可用。
而且：对梯度天然对齐的损失（如 Laplacian），调度完全不敏感（FPD 23.5–26.0）。
⑤ 最安全的做法是不加额外损失把条件做成网络输入（ControlNet / T2I-Adapter / InstructPix2Pix / cross-attention / FiLM / classifier-free guidance），零额外损失。HistDiST 在 H&E→IHC 上就是这么做的——只有 v-prediction 一个损失，条件全部走 cross-attention + latent 拼接。

0.3 你该怎么做（三句话版）

✅ 直接答案
  1. 首选：把能做成条件的都做成条件，不加损失。你的「结构条件」「stain token」都属于这一类——用 SPADE / FiLM / cross-attention 注入即可，零额外损失。
  2. 次选：必须加损失时（比如 PSPStain 的 FOD 和 PCLS），用 「x̂₀ 上计算 + 时间步门控 + 训练末期关闭 + 梯度方向保护」四件套。其中「末期关闭」是最重要、最容易被忽略的一条。
  3. 诊断先行：加之前先测冲突角 θconf（去噪梯度与辅助梯度的夹角）。<90° 可常开；>90° 必须门控 + 末期关闭。

1Part 1 · 噪声预测损失为什么"最重要"

1.1 从表面看：它只是「预测加进去的噪声」

Lsimple(θ) = Ex₀, ε, t [ ‖ ε − εθ(xt, t) ‖² ] 其中 xt = √ᾱt · x₀ + √(1−ᾱt) · ε, ε ~ N(0, I)

看起来就是一个普通的回归任务：给定加噪图 xt 和时间步 t，预测加进去的噪声 ε。为什么它比其他损失特殊？

1.2 它的真实身份：这不是一个"随便设计的损失"

📐 三个等价身份

身份一：变分下界（ELBO）的（重加权）形式。
DDPM 的原始推导是从最大化数据对数似然 log pθ(x₀) 出发的。其变分下界可分解为三项：先验损失 + 重构损失 + 扩散损失。前两项在实践中趋于 0，剩下的扩散损失，在特定重加权下正好就是 Lsimple。
→ 所以它有概率论根基，不是启发式设计。

身份二：去噪分数匹配（Denoising Score Matching）。
εθ 与 score 函数有严格对应关系：

∇x_t log pt(xt) = − εθ(xt, t) / √(1−ᾱt)

→ 所以最小化 Lsimple 等价于学习数据分布的对数密度的梯度。

身份三：反向采样器的唯一输入。
无论是 DDPM、DDIM 还是反向 SDE，采样公式里唯一需要从网络拿的量就是 εθ：

xt−1 = (1/√αt) · ( xt − (βt/√(1−ᾱt)) · εθ(xt,t) ) + σt z

1.3 关键推论：采样器对 εθ 的"信任"是无条件的

这是整个问题的核心。采样过程假设 εθ 是一个合法的 score 场，即它是某个标量势函数 −log pt(x) 的梯度（保守向量场）。采样器的所有理论保证——收敛性、分布正确性、ODE 可逆性——都建立在这个假设上。

🚫 辅助损失做了什么破坏
纯去噪训练:
    ε_θ  →  逼近真实的 score 场（保守场，可积分为势函数）
    采样器有效 ✓

加上辅助损失 L_aux（例如"输出图要像 IHC"）后:
    ε_θ  →  既要逼近 score 场，又要让 x̂₀ 满足 L_aux
    如果两者要求的方向不一致，ε_θ 会被拉离 score 场
    → ε_θ 不再是一个合法的 score 场（可能变成非保守场）
    → 采样器的理论保证失效
    → 表现：样本质量崩塌、模式坍塌、recall 崩溃

Lantern 论文对这个问题的表述非常精准，值得直接引用：

💬 原文

「Denoising is the objective that makes the network generative, so it must stay primary; an auxiliary that overrides it degrades the samples it is meant to improve.」
（去噪是让网络成为生成模型的那个目标，所以它必须保持主导地位；一个压过它的辅助损失，反而会损害它本想改善的样本。）

🔑 由此得到的设计原则

问题被分解为两个正交的子问题（Lantern 原文的框架）：

  1. 如何构造一个更新方向，既接纳辅助信号，又保持去噪主导？→ 这是方向问题。
  2. 决定辅助损失在训练的什么时候生效？→ 这是时间问题。

后面 Part 3 的硬证据会表明：第二个问题（时间）比第一个问题更容易解决，而且收益更大。

2Part 2 · 直接相加会出什么问题

很多人第一反应是：L_total = L_denoise + λ·L_aux，调 λ 就行。这个做法有三个层次的隐患，从浅到深。

2.1 问题一（浅层）：时间步依赖的尺度失衡

这是最容易理解、也最容易被忽略的一点。辅助损失通常作用在 x̂₀ 上，而 x̂₀ 的质量强烈依赖 t。

x̂₀(xt, t) = ( xt − √(1−ᾱt) · εθ(xt, t) ) / √ᾱt
t → T（高噪声端）:  x_t ≈ 纯噪声  →  x̂₀ 几乎无意义  →  辅助损失巨大但信号无意义
t → 0（低噪声端）:  x_t ≈ 干净图  →  x̂₀ 质量高      →  辅助损失有意义

后果:
  · 辅助损失的数值量级随 t 剧烈变化（可能跨越几个数量级）
  · 固定 λ 意味着：在高 t 时辅助损失主导（且是噪声主导的错误信号）
                    在低 t 时辅助损失几乎不起作用
  · 梯度方差极大 → 训练不稳定

另一个陷阱: 除以 √ᾱ_t 在 t→0 时数值爆炸（ᾱ_t → 1 时其实还好，
            但 ε 预测的微小误差会被 1/√ᾱ_t 放大）

2.2 问题二（核心）：梯度方向冲突

🎯 这才是真正的问题

调 λ 只能改幅度，不能改方向。如果两个损失的梯度方向本来就相反，那么无论 λ 多小，你都在持续地把网络往两个矛盾的方向拉——只是慢一点而已。

定义两个梯度: gd = ∇θ Ldenoise （去噪梯度） ga = ∇θ ( waux(s) · Laux ) （辅助梯度） 定义冲突角: θconf = arccos( ĝd · ĝa ) 其中 ĝ = g / ‖g‖ 判据: θ_conf < 90° → 两个目标相互促进（可以放心一起加） θ_conf = 90° → 正交（互不干扰，加了没用但不伤） θ_conf > 90° → 两个目标相互对抗（必须处理）

Lantern 实测：去噪梯度与物理残差损失的冲突角在训练中从合作逐渐转为对抗，实测值 92°–128°。这就是为什么简单加权会失败。

2.3 问题三（深层）：扩散训练本身就是多任务学习

这一点很多人没意识到，但它解释了为什么扩散训练这么"脆"。Min-SNR 论文（Hang et al., ICCV 2023）给出了清晰的论证：

📐 把扩散训练重新表述为多任务学习（MTL）
训练过程包含 T 个任务，每个 timestep 是一个任务:
    L¹(θ), L²(θ), ..., L^T(θ)

理想更新方向 δ 必须对所有任务都不增加损失:
    ⟨ δ , ∇L^t(θ) ⟩ ≤ 0,   ∀ t ∈ {1,...,T}

Pareto 最优解:
    δ* = − Σ_t w_t · ∇L^t(θ)
    其中 w 解 min ‖ Σ_t w^t ∇L^t(θ) ‖²  s.t. Σ w^t = 1, w^t ≥ 0

→ 这说明: 不同 timestep 之间存在真实的梯度冲突，需要显式平衡

实验证据（Min-SNR 论文 Figure 2）：把去噪过程按噪声水平分箱，只在某个区间（如 t∈[200,300)）微调：

「微调特定时间步会使相邻时间步受益，但对相距较远的其他时间步往往有害。」

→ 这直接证明了不同 t 的最优梯度方向是矛盾的。

解决方案：Min-SNR-γ 加权

wt = min{ SNR(t), γ } 其中 SNR(t) = ᾱt² / (1−ᾱt)² （不同预测目标下的形式不同） 预测 x₀ 时: wt = min{ SNR(t), γ } 预测 ε 时: wt = min{ γ / SNR(t), 1 } 预测 v 时: 再除以 (SNR + 1)
  • 推荐 γ = 5（论文默认值，γ ∈ {1,5,10,20} 中 5 最稳）
  • 效果：收敛速度提升 3.4×；ViT-XL 在 ImageNet-256 上以更小参数量达到 FID 2.06（3.3× 快于 DiT）
  • 代码：TiankaiHang/Min-SNR-Diffusion-Training
  • 关键洞察：论文指出运行时 Pareto 优化（UGD / Frank-Wolfe）虽然理论上最优，但实践中失败——因为稀疏性（多数时间步权重被压到 0，而扩散需要所有时间步）、不稳定性（单时间步样本少 → 梯度噪声大）、低效。所以需要一个预定义的全局加权方案。

✅ 三条可直接照搬的结论
  1. 辅助损失必须在训练末期关闭。对比 S2（保持到最后，FPD 236.3）与 S3（末期关闭，FPD 32.84）——差 7 倍。论文原话：「the voxel loss competes with denoising late in training」。
    原因是：体素残差损失的梯度在训练过程中从「合作」逐渐转为「对抗」——早期它帮助模型快速找到结构，后期它开始和去噪抢方向。
  2. 是否需要调度，取决于损失本身是否冲突。Laplacian 损失在 S1/S2/S3 下 FPD 只有 23.5–26.0 的波动，完全不敏感。论文原话：「The gate is therefore necessary where the auxiliary conflicts with denoising and inert where it does not.」（门控在冲突处必要，在不冲突处无作用。）
  3. 「末期关闭」是免费收益。Lantern 最终对两个损失都用 S3，因为「在不损失 Laplacian 性能的前提下移除了体素冲突」，且「保持单一调度、避免逐损失调参」。

3.4 GradBlend 的核心思想（可以借鉴）

💡 分离「方向」与「幅度」
设 ĝ_d = g_d/‖g_d‖,  ĝ_a = g_a/‖g_a‖

冲突角:      θ_conf = arccos( ĝ_d · ĝ_a )

方向: 辅助损失可以参与，但被角度门控
    ρ_eff = 1                        θ_conf ≤ 120°
    ρ_eff = 1 − (θ_conf−120°)/30°    120° < θ_conf ≤ 150°
    ρ_eff = 0                        θ_conf > 150°
    ĝ_dir = ( ĝ_d + ρ_eff · ĝ_a ) / ‖ ĝ_d + ρ_eff · ĝ_a ‖

幅度: 只锚定在去噪梯度上，随冲突收缩
    m_ref = ‖g_d‖ · max( cos(θ_conf/2), 0.05 )

最终更新:  g_blend = m_ref · ĝ_dir

三个关键设计：
① 两个梯度都先单位化——因此辅助梯度不能靠自身的范数主导方向；
② 步长只由去噪梯度决定，辅助损失不进入步长 → 辅助损失无法抬高有效学习率；
③ 冲突越大步长越小（cos(θ/2) 在 θ=180° 时为 0），冲突时自动保守；0.05 的下限防止步长完全崩塌。

局限（论文自述）：角度阈值（120°/150°）与幅度下限（0.05）是经验设定的，未做理论推导；调度关闭时刻也是先验固定的；论文只分别研究了两个辅助损失，未刻画二者同时使用时的交互。代码：Aaheer17/lantern-kdd27。

阶段 1（MSE）: L_mse = ‖ v̂_t − v_t ‖² 阶段 2（自感知）: L_sp = ‖ p*ˡ( x̂_{t′}, t′, c ) − p*ˡ( x_{t′}, t′, c ) ‖²

其中 p*ˡ 是冻结的自身副本在某一层 l 的输出特征，t′ 是一个重新采样的时间步。

★ 关键技巧：感知损失作用在哪里？
既不是噪声，也不是 x̂₀，而是「重加噪后的 x_{t′}」
  1. 把预测的 v̂ 转成 x̂₀ 和 ε̂：
    x̂₀ = √ᾱ_t · x_t − √(1−ᾱ_t) · v̂，ε̂ = √ᾱ_t · v̂ + √(1−ᾱ_t) · x_t
  2. 把真实 x₀ 与预测 x̂₀ 各自重新加噪到新的时间步 t′：
    x_{t′} = forward(x₀, ε, t′)，x̂_{t′} = forward(x̂₀, ε̂, t′)
  3. 比较两者的特征：L_sp = ‖p*ˡ(x̂_{t′},t′,c) − p*ˡ(x_{t′},t′,c)‖²

论文指出：「这里导出的 x̂_{t′} 等价于从时间步 t 到 t′ 的单步 DDIM 求解。」

为什么要这么做？因为直接比较 x̂₀ 与 x₀ 在像素空间差异过大（尤其模型还没训好时），梯度会爆炸。先重新加噪到 t′，相当于把比较放到「与当前训练状态匹配的噪声水平」上——这本质上是一种尺度对齐，与 Part 2.1 的结论一致。如果你的辅助损失必须在噪声域比较，这就是标准做法。

  • 论文自述局限：「SP 目标只是用来验证损失目标的效果，并非作为最终方案提出。」 并建议损失目标「最终应该是被学习出来的」。

#细节做法为什么重要
1末期关闭辅助损失 在训练的最后 15–25% 关闭 waux（cosine 衰减到 0）。Lantern 用 S3：Voxel 在 epoch 650/800 关闭，Laplacian 在 550/800。 收益最大的一条。FPD 从 236.3 → 32.84（7× 改善）。原理：辅助梯度在训练后期从合作转为对抗。
2作用在 x̂₀ 上，不在 ε 上 先用单步估计算出干净图：x̂₀ = (x_t − √(1−ᾱ_t)·ε_θ)/√ᾱ_t，辅助损失作用于 x̂₀。 辅助目标（"输出图要像 IHC"）定义在图像空间。作用在 ε 上则语义不明。
3warmup + 门控 先纯去噪训练 20–50 epoch，再 cosine ramp up 辅助权重。不要一开始就开（Lantern S1 的 FPD 是 173.4）。 让去噪先"站稳"，再让辅助损失引导。
4监控冲突角 每 N 步计算 θ_conf = arccos(ĝ_d · ĝ_a)，记录曲线。
<90° 可常开；>90° 必须门控。		 这是判断"要不要做调度"的唯一客观依据。Lantern 测到 92°–128°，所以它必须做调度。
5梯度手术而非简单加权 优先 GradBlend（分离方向与幅度）；其次 PCGrad；不要用简单的 L1 + λL2。 简单加权使 FPD 恶化数个数量级；PCGrad 也恶化 2–5×；GradBlend 是唯一无损的。
6尺度归一化 把辅助损失归一到与去噪梯度可比的范围。Lantern 对 Laplacian 除以 λ_max(L)² ≈ 95.5（预计算缓存）。 未归一化的辅助损失会因算子增益而膨胀。论文明确说"这使辅助梯度与去噪梯度在同一尺度"。
7用 v-prediction 而非 ε-prediction v = √ᾱt·ε − √(1−ᾱt)·x₀ ① 跨所有噪声水平的难度更均匀；② 数值更稳（无需除法）；③ 在 SNR→0 时不退化。HistDiST 在 H&E→IHC 上用的就是 v-prediction（γ=5）。
8零终端 SNR 重标定噪声调度使 ᾱT = 0。Lin et al. (WACV 2024) 指出常见调度「不强制最后一步 SNR 为零」，导致训练-推理不匹配。 训练时模型看到带信号的数据，推理时输入纯噪声 → 分布错配。HistDiST 采用了这一修复。
9Min-SNR-γ 时间步加权 w_t = min{SNR(t), γ}，γ=5（ε-pred 时为 min{γ/SNR(t), 1}） 缓解时间步之间的梯度冲突，收敛加速 3.4×。与辅助损失问题正交，但叠加使用效果更好。
10稳健损失（Huber） 辅助损失用 Huber 而非 MSE，阈值 δ 设为该残差的预期尺度。 残差超过预期尺度的样本会限制其影响而非主导更新。Lantern 的 voxel loss 用 δvox=1。

6Part 6 · 什么时候可以直接加

判据只有一条：冲突角

不是看损失的「类型」（像素损失 / 感知损失 / 对抗损失），而是看它在你的具体设置下与去噪梯度的夹角。同一个损失在不同任务上可能一个对齐、一个冲突。

θ_conf < 90° · 可以常开

特征：损失约束的方向与「更准确地预测噪声」方向一致。

典型：结构性/平滑性约束（Lantern 的 Laplacian 损失实测不敏感，FPD 23.5–26.0 跨调度不变）。

做法：直接加，不需要门控或末期关闭。

θ_conf ≈ 90° · 加了没用

特征：两个目标正交，互不干扰。

含义：辅助损失无法通过梯度路径影响去噪表征，等于白加。

做法：考虑改用范式 A（做成条件输入）或范式 D（共享表征）。

θ_conf > 90° · 必须保护

特征：两个目标在参数空间里相互对抗。

典型：像素级重建损失、逐体素残差损失（Lantern 实测 92°–128°）。

做法：门控 + 末期关闭 + 梯度手术，三者都要。

⚠️ 一个重要且反直觉的发现

Lantern 发现：同一个损失的冲突程度会随训练过程变化。
「The voxel gradient turns from cooperative to opposing over training.」（体素梯度在训练中从合作转为对抗。）
→ 这意味着：训练早期测得的冲突角不能代表全程。建议在整个训练过程中周期性记录冲突角曲线，而不是只测一次。
→ 也解释了为什么 S2（warmup 后一直开）反而比 S1（一开始就开）更差——因为 S2 让冲突损失在后期持续发挥作用。

6.2 常见误解澄清

常见说法判定正确的理解
「噪声预测损失最重要，所以它的权重应该最大。」 ✗ 不是权重问题。它是唯一出现在采样公式里的损失，其他损失只能通过修正 εθ 间接起作用。它的「重要」是结构性的，不是数值性的。把 λ 设成 0.01 并不能改变这个事实。
「多个损失相加是扩散模型做条件生成的常规做法。」 ✗ 反了。现代条件扩散的主流做法是条件注入（CFG / ControlNet / Cross-Attn / SPADE），损失始终只有一个。损失相加只在「输出端硬约束」时才必要。
「辅助损失不收敛，说明这个损失设计得不好。」 △ 有两种可能：① 损失本身有问题；② 它和去噪损失在打架，网络在两者之间找不到折中点。第二种更常见。诊断方法：看 cos(g_d, g_a)，接近 180° 就是第二种。
「用 PCGrad / GradNorm 做梯度平衡就能解决冲突。」 ✗ 这是最危险的误解。Lantern 实测：这些方法在扩散训练中把 FPD 放大 2–100 倍。原因是它们强行拉平梯度范数，破坏了 score field 的尺度校准。梯度平衡方法是为「多个平级任务」设计的，而去噪任务是尺度基准，不是平级任务。
「辅助损失的权重 λ 设成 1 就行，反正会自动平衡。」 ✗ StainDiffuser 实测：λ 从 0.1 到 10，PSNR 变化 2.5 dB（22.83 → 20.32），且最优 λ 随标记物变化（CK8/18 用 1，CD3 用 3）。λ 是必须调的超参数。
「辅助损失加在噪声 ε̂ 上还是 x̂₀ 上，应该差不多。」 ✗ 差很多。ε̂ 是噪声域、x̂₀ 是图像域。所有像素级/物理级辅助损失都天然属于图像域，挂在 ε̂ 上会造成尺度错配，尤其在低噪声段辅助损失会完全支配优化。永远优先挂 x̂₀。
「加了辅助损失，训练 loss 曲线更平滑了，说明有效。」 ✗ loss 曲线平滑与生成质量没有必然关系。Lantern 的失败案例中训练 loss 是下降的，但 FPD 崩坏。判断标准应该是生成样本的 FID + 梯度诊断，不是训练 loss 曲线。
「扩散模型只能有一个损失，这是理论限制。」 △ 没有这样的理论限制。StainDiffuser 成功用了两个损失（都是 ε-prediction 形式），范式 F 的分阶段替换也成功。限制是工程性的（梯度冲突、尺度失衡），不是理论性的。
「GAN 里能堆 6 个损失，扩散也应该能。」 ✗ UNIStainNet 在 H&E→IHC 上堆了 LPIPS + L1 + Edge + 对抗 + FM + DAB 共 6 项损失，每项都有边际贡献。但它是 GAN，不受 score 场约束。这个经验直接搬到扩散上会引发梯度冲突——这是这个方向最容易犯的错误。

8.1 推荐的三阶段训练配方

Phase 0 · 结构改造（不做训练）
  · 生成器换成 RDDM 式双扩散（残差 U-Net + 噪声 U-Net）
    → 这两个损失都是扩散损失，天然无冲突（范式 E）
  · 结构条件 / stain token 做成 SPADE / FiLM / cross-attn 输入（范式 A）
  · 物理合规性做成可微 Beer-Lambert 输出头（不是损失）
  · 参数化改为 v-prediction；噪声调度改为零终端 SNR
  · 加 Min-SNR-γ 加权（γ=5）

Phase 1 · 纯扩散预热（warmup）
  时长: 前 15–20% 的迭代
  损失: L = L_residual + L_noise          ← 只有扩散损失
  目的: 让模型先学会"生成"，站稳 score 场
  ⚠️ 此阶段绝对不要加 FOD / PCLS

Phase 2 · 辅助损失渐入
  时长: 20% – 80%
  损失: L = L_res + L_noise
            + w(s) · [ λ_fod · L_FOD(x̂₀) + λ_pcl · L_PCLS(x̂₀) ]
  其中 w(s) 为 cosine ramp，从 0 升到 1
  同时: 周期性记录冲突角 θ_conf（每 500 步）

Phase 3 · 末期纯扩散（terminal denoising-only）
  时长: 最后 15–20%
  损失: L = L_residual + L_noise          ← 关闭所有辅助损失
  目的: 消除后期梯度冲突，恢复样本分布覆盖度
  ⚠️ 这是 Lantern 收益最大的一条（FPD 236.3 → 32.84）

8.2 一个必须做的诊断实验（先做这个）

✅ 在正式训练前，用 1–2 小时测出冲突角
步骤:
  1. 用 Phase 1 的方式训一个小模型到基本收敛（或直接用已有 checkpoint）
  2. 取一个 batch，做一次前向
  3. 分别计算:
        g_d = ∇_θ L_denoise        （去噪梯度）
        g_a = ∇_θ L_FOD            （FOD 梯度）
        g_p = ∇_θ L_PCLS           （PCLS 梯度）
     ⚠️ 用 torch.autograd.grad(..., retain_graph=True) 分别取，不要用 backward
  4. 计算冲突角:
        θ_FOD  = arccos( ĝ_d · ĝ_a ) * 180/π
        θ_PCLS = arccos( ĝ_d · ĝ_p ) * 180/π
  5. 在训练过程中每 500 步重复一次，画曲线

判读:
  θ < 90°   → 可以常开，不需要末期关闭
  θ ≈ 90°   → 该损失无效，考虑改成条件输入（范式 A）
  θ > 90°   → 必须门控 + 末期关闭 + 考虑 GradBlend

预期（基于 Lantern 的体素残差损失 92°–128°）:
  FOD 是光密度域的逐区域约束，与像素/体素残差类似 → 预期 θ > 90°，需要保护
  PCLS 是特征空间的跨图对齐，作用在深层特征上 → 预期 θ 较小，但仍需实测

8.5 一个更强的方案：把 PCLS 从「损失」改造成「条件」

方案 C（进阶档）：PCLS → 双 SPADE 条件注入
风险最低 创新性最高
核心洞察

PCLS 的本质是「让生成结果靠近某组蛋白表达原型」。这个约束完全可以改写成条件注入——把原型当成「目标蛋白类型的可学习 token」，通过 cross-attention 注入，或者当成「空间调制图」，通过 SPADE 注入。这样损失仍然只有一个，梯度冲突问题从根上消失。

  • 训练时对 p_k 做随机 dropout（仿 CFG）；推理时可以通过调节 p_k 的插值来控制表达强度。
✅ 为什么这个方案最好（四条理由）
  1. 从结构上消除梯度冲突：辅助约束不再是损失，而是输入。去噪损失是唯一损失，Part 2、Part 3 的所有风险都不存在。
  2. 自然实现你要的解耦：空间调制 = 结构，通道调制 = 染色。这正是你前两份报告确立的「结构 ↔ 染色表达」解耦轴，而且是用架构实现的，不是用损失实现的——更可靠。
  3. 推理时获得额外控制能力：原 PSPStain 是「H&E → 固定一种 IHC」。改成条件注入后，一个模型可以切换 HER2 / Ki67 / ER / PR，甚至做原型插值生成「中间表达状态」——这是原方案做不到的，是真正的创新点。
  4. 与 CFG 天然兼容：原型 dropout 训练后，推理时用引导尺度 s 控制表达强度，无需重训。
代价

改动量比标准方案大：需要改 U-Net 的调制层（引入 SPADE）、为原型设计嵌入层、改数据加载器以提供蛋白类型标签（MIST 数据集有 HER2/Ki67/ER/PR 多标记物，天然支持）。但这是唯一能同时满足「保留 PSPStain 核心思想」+「引入扩散」+「不牺牲生成质量」+「有真正创新」的方案。

8.6 训练循环伪代码（方案 B 用）

# ===== 配置 =====
PRED_TYPE     = "v"        # v-prediction（尺度最均衡，见 Part 2.1）
LAMBDA_FOD    = 0.1        # 从 0.1 开始网格搜索 {0.03, 0.1, 0.3, 1.0}
LAMBDA_PCLS   = 0.05       # PCLS 是危险损失，起步要小
PCLS_TMAX     = 0.5        # PCLS 只在 t < T/2 生效
FINETUNE_FRAC = 0.9        # 前 90% 迭代开辅助项，后 10% 纯去噪收尾

# ===== 训练一步 =====
x0  = batch_ihc                       # 真实 IHC（或 destain-restain 伪配对）
he  = batch_he
t   = randint(0, T);  eps = randn_like(x0)
x_t = sqrt(alpha_bar[t]) * x0 + sqrt(1 - alpha_bar[t]) * eps

# ---- 主损失：v-prediction ----
v_true = sqrt(alpha_bar[t]) * eps - sqrt(1 - alpha_bar[t]) * x0
v_pred = unet(x_t, t, cond=he)
L_v    = mse(v_pred, v_true)

# ---- 还原 x0 估计（辅助损失一律作用在 x_hat_0 上！）----
x_hat0 = sqrt(alpha_bar[t]) * x_t - sqrt(1 - alpha_bar[t]) * v_pred
x_hat0 = x_hat0.clamp(-1, 1)          # ★ 必须 clamp，否则早期会爆炸

# ---- 辅助损失 1：FOD（友好损失，全程开启）----
od_pred = -torch.log((x_hat0 + 1) / 2 + 1e-6)   # ★ 转光密度域，必须加 eps
od_true = -torch.log((x0     + 1) / 2 + 1e-6)
L_fod   = l1(od_pred, od_true)

# ---- 辅助损失 2：PCLS（危险损失，限时 + 归一化）----
mask = (t < PCLS_TMAX * T).float()
if mask.sum() > 0:
    f_pred = unet.midblock_features(x_t, t, cond=he)   # ★ 只取 midblock
    L_pcls = prototype_consistency(f_pred, prototypes, protein_type)
    L_pcls = L_pcls / (ema_norm_pcls + 1e-8)           # 量级归一化
    sched  = 1.0 if step < FINETUNE_FRAC * total_steps else 0.0
    L_pcls = LAMBDA_PCLS * sched * mask.mean() * L_pcls
else:
    L_pcls = 0.0

# ---- 总损失 ----
L = L_v + LAMBDA_FOD * L_fod + L_pcls
L.backward(); optimizer.step()

# ===== 诊断（每 100 步记录）=====
# cos_d  = cos(g_denoise, g_denoise_prev)   # 去噪梯度自相关，期望 > 0.6
# cos_a  = cos(g_aux, g_aux_prev)           # 辅助梯度自相关，< 0.3 要警惕
# cos_da = cos(g_denoise, g_aux)            # 冲突角，> 150° 触发门控
# ratio  = ||g_aux|| / ||g_denoise||        # 期望在 [0.1, 5] 内
⚠️ 代码里三个最容易踩的坑
  1. x_hat0 必须 clamp。早期 x̂₀ 估计可能严重越界，直接进 log() 会 NaN。这是「辅助损失挂 x̂₀」时最常见的崩溃原因。
  2. OD 转换要加 eps。Beer–Lambert 的 −log(I/I₀) 在 I→0 时发散，必须加 1e-6 保护。
  3. PCLS 的特征必须取 midblock，不要取解码器浅层（依据范式 F 的消融，FID 差 64%）。

噪声预测损失的重要性在于它是唯一让网络保持"生成模型"身份的项——采样器无条件信任 εθ 是合法的 score 场。
辅助损失可以加，但必须遵守一条铁律：不能让辅助损失改变"网络往哪个方向走"，只能让它微调"走得多快"以及在什么时候参与。
实践上按优先级：能做成条件的就做成条件（范式 A）→ 能做成输出结构的就做成输出结构（范式 E）→ 必须加损失时就上「x̂₀ + 门控 + 末期关闭 + 梯度保护」四件套（范式 B）→ 或者干脆挪到推理时引导（范式 C）。
