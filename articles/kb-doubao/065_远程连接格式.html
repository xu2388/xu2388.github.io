远程连接格式

杂项/其他 · 3 条消息 · 来源：豆包分享
我问

这个远程连接的格式怎么写

信息提取

  • Host：101.7.166.140
  • Port：6100
  • AddressFamily：inet6 → IPv6
  • HostName：2023u_GaoShiyu
⚠️ 注意：这里Host写的是IPv4字符串，但AddressFamily是inet6，说明目标是IPv6地址，101.7.166.140并不是合法IPv6，大概率是打印输出混淆了，分两种写法给你：

1. 如果是SSH连接（最常见）

IPv6 ssh格式，IPv6地址必须加[]

ssh 2023u_GaoShiyu@[IPv6地址] -p 6100
ssh 2023u_GaoShiyu@101.7.166.140 -p 6100

2. 如果你是写ssh config文件（~/.ssh/config），就是图里这种写法

Host 101.7.166.140
  HostName 101.7.166.140
  AddressFamily inet6
  Port 6100
  User 2023u_GaoShiyu

然后直接 ssh 101.7.166.140 就能连上

3. Xshell / FinalShell / VSCode Remote SSH 填写

  • 主机：101.7.166.140
  • 端口：6100
  • 用户：2023u_GaoShiyu
协议选IPv6的话，主机地址要换成真正IPv6地址并用[]包裹，例[2409:xxxx::xxxx]

你用的是哪个工具连远程？我可以直接给对应完整一行命令。
