对比学习和 CLIP 到底在干什么：从"拉近推开"到"给染色换文本编码器"

写于 2026-10-24 · 教程篇 · 原始来源：DeepSeek 对话 [074][233][082][137]

对比学习是我最晚搞懂、回头看却发现"到处都在用"的一块。有意思的是，它在我项目里以两个完全不同的身份出现：一半是我 Stable Diffusion 里把文字变成条件的 CLIP，另一半是我 001/002 里保住结构的 CUT/PatchNCE。一个是管"生成什么风格"，一个是管"别把结构改崩"，根子上却是同一个特别朴素的思想——把相似的拉近，把不相似的推开。 这篇就从这个思想讲起，一路讲到我自己拍板"把 CLIP 换成 CONCH"的那个决定。

一、对比学习：把相似的拉近，把不相似的推远

我第一次问"什么是对比学习"时，得到的答案用一个比喻我就记住了：教小孩认苹果——给他看同一个苹果切成两半（告诉他"这是同一个"），再给他看个橘子（"这不是苹果"），慢慢他就抓住了苹果的本质，忽略了光照、角度。对比学习就是这个思路的数学版：让相似的样本在特征空间里靠得更近，不相似的离得更远。

核心机制 · 锚点、正样本、负样本 + InfoNCE

它需要三种样本：锚点（当前关注的样本）、正样本（和锚点同类的，比如同一张图的两种增强）、负样本（不同类的）。目标是让锚点和正样本相似度最大、和负样本最小，相似度一般用余弦相似度。最常用的损失叫 InfoNCE：

L = −log [ exp(sim(zᵢ,zⱼ)/τ) / Σₖ exp(sim(zᵢ,zₖ)/τ) ]

翻译成人话：在一堆候选里，能不能准确地把正样本挑出来——这是个分类题。挑得越准，锚点和正样本越近、和负样本越远。τ 是温度，控制"推开/拉近"的力度。

正样本靠数据增强造（同一张图裁剪/变色成两版），负样本就是同一批次里的其他样本——所以对比学习很吃大批量（SimCLR 用到 4096，负样本越多题目越难、学得越好；MoCo 则用动量记忆库绕开大显存）。它最大的好处是不需要人工标签，是自监督表征学习的主力。

二、CLIP：把"对比"用在图和文字之间

CLIP 是把这个思想从"同一张图的两种增强"搬到图文之间：一张图和它的文字描述算正样本，同一个批次里其他图文都算负样本。它训两个编码器——一个把图编码成向量，一个把文字编码成向量——逼着匹配的图文在同一个空间里贴近，不匹配的推远。训好后，图和文字就落在了一个可互相比对的空间里，于是能做零样本分类、图文检索。

接回上一篇 · CLIP 就是 SD 的"文本编码器" 在 Stable Diffusion 里，CLIP 的角色特别具体：你输入的 prompt 经过 CLIP 文本编码器，变成一个 [77, 768] 的嵌入（77 是 CLIP 的 token 上限，768 是维度），这个嵌入就是上一篇讲的 z_text——它作为 K/V 被灌进 U-Net 的交叉注意力层，Q 则是正在去噪的图像特征。所以 006 里"文本怎么变成条件"这个问题，答案的下半段就在这：CLIP 负责把一句话变成一个能被查询的向量，交叉注意力负责让图像每一步去查它。

三、可是原生 CLIP 不懂病理——我那句"真的能行吗"

我当时的算盘是：用文本引导染色风格、又想让结构别崩，于是很怀疑——就一句话，真能靠一个原生 CLIP 就让模型精准认知吗？ 我原话是："因为我的文本主要是用于风格的引导……但是还是要保持结构的一致性，所以我就好奇，就这一段话，真的用一个原生的 CLIP 就能实现让模型精准的认知？然后就能生成？" 答案是干脆的「不能」。

让我清醒的认识 · CLIP 只知道"有什么"，不知道"在哪"

原生 CLIP 是在自然图片上训的，它的强项是全局风格识别（"这张是粉色系""那张偏紫"），但细粒度结构（基底膜钉突、系膜增生）很弱、空间关系很弱。一句话概括：它给出的是全局的、统计性的表示，而不是空间布局的蓝图——"只知道有什么，不知道在哪里"。

这解释了一个我早就纳闷的现象：SD 生成的病理图，远看像那么回事，近看结构全是错的。 因为 SD 结构好，并不是因为 CLIP 懂结构，而是 U-Net 自己学到了统计规律，CLIP 只是"提示"了一下风格。想让文本真正管住染色的细部，就得换一个见过病理的文本/图像编码器。

四、换编码器：CONCH / UNI / Phikon，我拍板用 CONCH

对症下药就是换成在病理数据上预训练的编码器。我当时拉了张对比表，核心是"谁见过 PAS/Masson 这种特殊染色"：

整理归纳 · 几个病理编码器（按我当时掌握的信息）
编码器是什么对我的价值
CONCHMahmoodLab，CoCa 架构，117 万对病理图文训练，其中超 71 万对来自 IHC 和特殊染色（含 PAS/Masson/PASM），输出 512 维最对路——它专门对比学过"病理图+它的文字描述"，正好是我的"文本引导染色"
UNI哈佛，ViT-L，超 1 亿张病理图块自监督预训练，输出 1024 维主要在 H&E 上强，偏图像特征而非图文对齐
PhikonViT + iBOT/DINOv2，千万级病理图块，输出 768/1024 维HistDiST 拿它替掉 CLIP 当条件源（见下）

我的结论原话："我觉的还是要用 CONCH。" 因为它见过 PAS/Masson 的图文对，最可能听懂"生成 PAS 染色"这种话。

一个工程细节 · 维度对不上，加个适配层 CONCH 输出 512 维、CLIP(ViT-L) 是 768 维、UNI 是 1024 维——直接替换会维度不匹配。解决办法是加一个可训练的线性适配层（比如 nn.Linear(512, 768)）把维度对齐，而且因为语义空间也对不上，这个适配层通常还要微调。这跟我 006 里"HistDiST 用 Phikon 代替 CLIP，处理后的维度跟 CLIP 一样"是同一个操作——换个条件源，维度对齐后照样喂交叉注意力。

五、结构化 prompt：把每种染色的特点说明白

换了 CONCH 还不够，喂什么文本同样关键。我当时的主张是："我觉得这个文本最好可以是结构化的吧，我感觉是格式化会更加的有效，另外需要都是英文的"，而且要"不同的染色突出的不同特征……每种染色特点都说明白，因为我要微调 SD v1.5 需要让 UNET 去学习这个部分的"。落地成按染色定制的键值对模板——每种染色只强调它该强调的特征：

我的结构化 prompt 思路 · 一染色一模板

· PASM（重点看基底膜）：stain: pasm / gbm_thickness: [...] / gbm_spike: [...] / gbm_tram_track / mesangial_interposition / quality: highly_detailed, sharp_focus

· Masson（重点看胶原纤维/纤维化/硬化）；· PAS（重点看糖原/系膜基质/K-W 结节）。

可以借 LLaVA 这类模型批量生成，再人工抽样检查。但有个硬约束：CLIP/CONCH 都有 77 token 上限，键值对写太长会被截断——所以策略是把最重要的信息（染色类型、主要病变）放前面，别去改 max_position_embeddings（有风险）。

六、另一条暗线：同一个思想，也是你保住结构的武器

最有意思的在这儿：我一开始学对比学习是为了文本编码器，回头一看，我 001/002 里保住结构的 CUT，用的也是对比学习——只不过正负样本的定义换了地方。CUT（Contrastive Unpaired Translation）干的是无配对染色迁移：要改外观、又不能动结构，它的 PatchNCE 损失把对比做到了块（patch）级：

PatchNCE · 用对比锁住结构

· 锚点：输出图里的某一个小块（比如一块细胞边缘）；
· 正样本：输入图里相同位置的小块（内容一致、外观不同）；
· 负样本：输入图里其他位置的小块（内容不同）。

拉近同位置、推远别处——于是输出的每一块都被钉回输入的对应位置，只让染色变、不让结构跑。妙在它不需要跨图找负样本，一张图内部就能算，训练稳、结构保得好。这比我 002 里纠结的循环一致性更细粒度。CUT 就是我"只改染色不改结构"的那个方法，而它的内核是对比学习。

顺带说，我还琢磨过把对比学习用在染色-结构解耦上：用局部对比（PatchNCE）锁结构，再用全局对比（监督对比，SupCon）约束染色特征——让同一染色域的图（都 H&E）染色向量聚拢、不同域（Masson）推远，这样染色编码器就只学颜色统计、不碰结构。当时摸到的范本是 DCLGAN（PatchNCE 保结构 + 判别器侧全局对比分离风格）和 MUNIT（内容/风格双编码器，可把风格损失换成对比）。这个"一个管结构、一个管染色、各司其职"的思路，我记到现在。

当前结论 对比学习剥到底就一句话：构造正负样本，把正的拉近、负的推远，逼模型学到"不随无关变换改变的、有区分性的本质特征"。它在我的世界里有两副面孔：CLIP 把图文对齐，充当 SD 的文本编码器（prompt → z_text → 交叉注意力，接 006）；CUT/PatchNCE 把同位置块对齐，充当无配对染色的结构保持器（接 001/002）。而原生 CLIP 不懂病理（只知道"有什么"不知道"在哪"），所以我拍板换 CONCH（见过 PAS/Masson 图文对），再配按染色定制的结构化英文 prompt，并处理 77 token 截断和维度适配。一个"拉近推开"，同时管住了我的"风格"和"结构"——这是我最得意的一次融会贯通。
未解决问题 / 待核实

  • Phikon 提的特征偏结构还是偏染色我设计了实验（同组织不同染色 + 算距离）但没做——它只在 H&E 上训练，换到 PAS/IHC 可能只是域偏移，未必说明它编码了"染色美学"。
