    <p>微调配置：lr=2e-5，batch_size=32，epochs=5，序列长度128，准确率<strong>93.27%</strong>，各类F1均超0.92。</p>

    <h3>7.2 Erlangshen句子嵌入 + SVM (封神榜系列)</h3>
    <p><strong>方法</strong>：Erlangshen-TCBert-110M提取[CLS]+MeanPool (1536维) → PCA降至128维 → SVM分类。</p>
    <div class="card-grid">
        <div class="card"><strong>准确率</strong><br><span class="stat-number">92.07%</span></div>
        <div class="card"><strong>训练时间</strong><br>≈20秒 (vs BERT微调600秒)</div>
        <div class="card"><strong>F1宏平均</strong><br>0.9219</div>
    </div>
    <p><strong>虚假标签算法实验</strong>：用聚类标签替换置信度低样本导致准确率降至57.69% → 人工标注不可替代。</p>

class LSTMClassifier(nn.Module):
    def __init__(self, vocab_size, embedding_dim=128, hidden_dim=256, num_labels=3):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, num_layers=2, 
                           batch_first=True, dropout=0.3, bidirectional=True)
        self.dropout = nn.Dropout(0.3)
        self.fc = nn.Linear(hidden_dim * 2, num_labels)

7.2.2 技术方案

特征提取流程:

输入文本
    ↓
Erlangshen-TCBert (冻结权重，仅特征提取)
    ↓
句子嵌入向量 (1536维 = [CLS]768 + MeanPool768)
    ↓
PCA降维 (128维，保留95%方差)
    ↓
StandardScaler标准化
    ↓
SVM分类器 (训练)
    ↓
三分类预测 (0/1/2)

关键代码:

# 提取句子嵌入
def extract_embeddings(texts):
    outputs = erlangshen_model(input_ids, attention_mask)
    cls_emb = outputs.last_hidden_state[:, 0, :]  # [CLS] token
    mean_emb = torch.mean(outputs.last_hidden_state, dim=1)  # Mean pooling
    return torch.cat([cls_emb, mean_emb], dim=1)  # 1536维

# PCA降维
pca = PCA(n_components=128)
X_reduced = pca.fit_transform(X_embeddings)

# SVM分类
svm = SVC(kernel='rbf', C=1.0, probability=True)
svm.fit(X_reduced, y_train)

  • TF-IDF: 84.98%（简单但有效）

  • 结论: 好的特征表示比复杂模型更重要
