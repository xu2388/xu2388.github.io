1. A 解析：无约束优化指可行域为整个 \(R^n\)。A 选项 \(\min x_1^2 + x_2^2\) 没有约束条件，自由变量；B、C、D 均有等式或不等式约束。

2. B 解析：课件第53页给出：若 \(A\) 对称，则 \(f(x)=\frac12 x^T A x + b^T x + c\) 的梯度为 \(Ax+b\)。但本题中 \(f(x)=x^T A x + b^T x + c\)，没有系数 \(\frac12\)，因此梯度为 \(2Ax+b\)。也可由课件第51页推导：\(\nabla f(x)=A^T x + Ax + b\)，当 \(A\) 对称时 \(A^T=A\)，故为 \(2Ax+b\)。

3. B 解析：凸集要求任意两点连线仍在集合内。A 是圆周（空心），不满足；B 是圆盘（实心），凸；C 是两条直线 \(x=\pm y\)，取两点 \((1,1)\) 和 \((1,-1)\)，连线中点 \((1,0)\) 不满足方程；D 是双曲线区域，非凸。

4. A 解析：课件第90页定理：凸函数的下水平集是凸集。

5. A 解析：\(f(x_1,x_2)=x_1^2-4x_1x_2+x_2^2\)，则 \(\frac{\partial^2 f}{\partial x_1^2}=2\)，\(\frac{\partial^2 f}{\partial x_2^2}=2\)，\(\frac{\partial^2 f}{\partial x_1\partial x_2}=-4\)，故 Hesse 矩阵为 \(\begin{pmatrix}2 & -4\\ -4 & 2\end{pmatrix}\)。

1. 设 \(f(x) = 3x_1^2 + 2x_1x_2 + 4x_2^2 + 5x_1 - 3x_2 + 1\)

解： (1) 梯度 \[ \frac{\partial f}{\partial x_1} = 6x_1 + 2x_2 + 5,\quad \frac{\partial f}{\partial x_2} = 2x_1 + 8x_2 - 3 \] \[ \nabla f(x) = \begin{pmatrix} 6x_1 + 2x_2 + 5 \\ 2x_1 + 8x_2 - 3 \end{pmatrix} \]

(2) Hesse 矩阵 \[ \frac{\partial^2 f}{\partial x_1^2} = 6,\quad \frac{\partial^2 f}{\partial x_2^2} = 8,\quad \frac{\partial^2 f}{\partial x_1\partial x_2} = 2 \] \[ \nabla^2 f(x) = \begin{pmatrix} 6 & 2 \\ 2 & 8 \end{pmatrix} \]

2. 给定 \(f(x,y)=x^2+2y^2\)，\(\bar{x}=(1,1)^T\)，\(d=(1,-1)^T\)

解： 首先计算梯度：\(\nabla f = (2x, 4y)\)，在 \(\bar{x}\) 处 \(\nabla f(\bar{x}) = (2, 4)\)。 Hesse 矩阵：\(\nabla^2 f = \begin{pmatrix}2 & 0 \\ 0 & 4\end{pmatrix}\)。

(1) 一阶方向导数 \[ \frac{\partial f}{\partial d} = \frac{1}{\|d\|} d^T \nabla f(\bar{x}),\quad \|d\|=\sqrt{1^2+(-1)^2}=\sqrt{2} \] \[ d^T \nabla f(\bar{x}) = (1,-1)\begin{pmatrix}2\\4\end{pmatrix}=2-4=-2 \] \[ \frac{\partial f}{\partial d} = \frac{-2}{\sqrt{2}} = -\sqrt{2} \]

(2) 二阶方向导数 \[ \frac{\partial^2 f}{\partial d^2} = \frac{1}{\|d\|^2} d^T \nabla^2 f(\bar{x}) d \] \[ d^T \nabla^2 f(\bar{x}) d = (1,-1)\begin{pmatrix}2&0\\0&4\end{pmatrix}\begin{pmatrix}1\\-1\end{pmatrix} = (1,-1)\begin{pmatrix}2\\-4\end{pmatrix}=2+4=6 \] \[ \frac{\partial^2 f}{\partial d^2} = \frac{6}{2} = 3 \]

题目： 设 \(f: \mathbb{R}^n \to \mathbb{R}\) 是可微函数。证明：\(f\) 是凸函数当且仅当对任意 \(x, y \in \mathbb{R}^n\)，有 \[ f(y) \ge f(x) + \nabla f(x)^T (y - x). \]

证明：

(1) 必要性（\(\Rightarrow\)） 假设 \(f\) 是凸函数。对任意 \(x, y \in \mathbb{R}^n\) 和任意 \(\alpha \in (0,1]\)，由凸函数定义： \[ f(\alpha y + (1-\alpha)x) \le \alpha f(y) + (1-\alpha) f(x) \] 移项得： \[ \frac{f(x + \alpha(y-x)) - f(x)}{\alpha} \le f(y) - f(x) \] 令 \(\alpha \to 0^+\)，左边极限为 \(\nabla f(x)^T (y-x)\)，于是 \[ \nabla f(x)^T (y-x) \le f(y) - f(x) \] 即 \[ f(y) \ge f(x) + \nabla f(x)^T (y-x) \]

(2) 充分性（\(\Leftarrow\)） 假设对任意 \(x, y\) 有 \(f(y) \ge f(x) + \nabla f(x)^T (y-x)\)。 取任意 \(x_1, x_2\) 和 \(\lambda \in [0,1]\)，令 \(x_\lambda = \lambda x_1 + (1-\lambda) x_2\)。 由条件，对 \(x = x_\lambda\) 和 \(y = x_1\) 有： \[ f(x_1) \ge f(x_\lambda) + \nabla f(x_\lambda)^T (x_1 - x_\lambda) \] 对 \(y = x_2\) 有： \[ f(x_2) \ge f(x_\lambda) + \nabla f(x_\lambda)^T (x_2 - x_\lambda) \] 将第一式乘以 \(\lambda\)，第二式乘以 \((1-\lambda)\) 并相加： \[ \lambda f(x_1) + (1-\lambda) f(x_2) \ge f(x_\lambda) + \nabla f(x_\lambda)^T \big[\lambda (x_1 - x_\lambda) + (1-\lambda)(x_2 - x_\lambda)\big] \] 而 \(\lambda (x_1 - x_\lambda) + (1-\lambda)(x_2 - x_\lambda) = \lambda x_1 + (1-\lambda)x_2 - x_\lambda = x_\lambda - x_\lambda = 0\)。 因此 \[ \lambda f(x_1) + (1-\lambda) f(x_2) \ge f(x_\lambda) \] 即 \[ f(\lambda x_1 + (1-\lambda) x_2) \le \lambda f(x_1) + (1-\lambda) f(x_2) \] 故 \(f\) 是凸函数。证毕。

问题： \(\min f(x) = x_1^2 + x_2^2 - 4x_1 - 6x_2\)

(1) 判断是否为凸优化问题 解：计算 Hesse 矩阵： \[ \frac{\partial f}{\partial x_1}=2x_1-4,\; \frac{\partial f}{\partial x_2}=2x_2-6 \] \[ \frac{\partial^2 f}{\partial x_1^2}=2,\; \frac{\partial^2 f}{\partial x_2^2}=2,\; \frac{\partial^2 f}{\partial x_1\partial x_2}=0 \] \[ \nabla^2 f = \begin{pmatrix}2 & 0 \\ 0 & 2\end{pmatrix} \] 该矩阵正定，故 \(f\) 是严格凸函数。问题无约束，因此是凸优化问题（无约束凸优化）。

(2) 求全局最优解 令 \(\nabla f = 0\)： \[ 2x_1 - 4 = 0 \Rightarrow x_1 = 2,\quad 2x_2 - 6 = 0 \Rightarrow x_2 = 3 \] 最优解 \(x^* = (2,3)^T\)。最小值 \(f(2,3) = 4 + 9 - 8 - 18 = -13\)。

(3) Hesse 矩阵及其正定性 Hesse 矩阵为 \(\begin{pmatrix}2 & 0 \\ 0 & 2\end{pmatrix}\)。 特征值均为 2 > 0，故正定。
