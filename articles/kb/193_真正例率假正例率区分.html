真正例率假正例率区分

2026-05-05 · 主题：课程-数学 · 18 条消息 · 对话编号 193
我问

我在复习机器学习，真正例率和假正例率分不清

这两个概念特别容易搞混，因为它们名字长得像，又经常一起出现在 ROC 曲线里。其实抓住“分母是谁”就永远不会错了。

  • 真正例率 (TPR)：实际为正的样本中，被模型正确揪出来的比例 → “正例的覆盖率”
  • 假正例率 (FPR)：实际为负的样本中，被模型错判为正的比例 → “对负例的误伤率”

先写标准混淆矩阵：

预测为正预测为负
实际为正TP (真正例)FN (假负例)
实际为负FP (假正例)TN (真负例)

那么：

  • 真正例率 TPR = TP / (TP + FN)

分母是所有实际为正的样本。 这个值就是 Recall（召回率）或 Sensitivity（敏感度）。

  • 假正例率 FPR = FP / (FP + TN)

分母是所有实际为负的样本。 这个值等于 1 - Specificity（特异性）。

假设你在用模型筛“生病的人”，正例 = 生病，负例 = 健康。

  • TPR = 90%

→ 真实有病的 100 个人里，你找出了 90 个。 （很好，漏诊不多）

  • FPR = 10%

→ 真实健康的 100 个人里，你把 10 个人错判成生病。 （误报，让他们白担心）

你细品：

  • TPR 关注的是 “正例有没有被遗漏”。
  • FPR 关注的是 “负例有没有被冤枉”。
  • “真正例率”里有个“真”字，它对应真实正例中的比例 → 分母是真·正例。
  • “假正例率”里有个“假”字，它对应把负例假装成正例的比例 → 分母是真·负例。

或者直接记公式里的那个字： TPR → 分母带 P（真实 Positive） FPR → 分母带 N（真实 Negative，因为 FP 是预测错，但来源于负例）

ROC 曲线的纵轴是 TPR，横轴是 FPR。

  • 我们希望 TPR 高（正例多召回）
  • 我们希望 FPR 低（负例少误伤）

所以曲线越靠近左上角越好。把这两个指标分开看，就能判断模型是不是在提高召回率的同时，过度牺牲了对负例的准确性。

如果还分不清，下次直接在纸上画出混淆矩阵，写完公式先看分母——问题就解决了。需要我出个小题考考你吗？

核心思想：从“只能分两类”到“能分多类”

大多数基础分类器（比如逻辑回归、SVM）生来只会回答“是或不是”（二分类）。现在你要分类“猫/狗/猪”，就得骗过它们——通过“拆分+投票”把一个多分类问题，变成很多个二分类问题。

笔记里讲的两大战术

翻译：让任意两个类别单挑，最后看谁赢得多。

  • 拆分：猫vs狗，猫vs猪，狗vs猪 → 共 \( C_3^2=3 \) 场比赛（分类器）
  • 训练：每个分类器只学“这俩怎么区分”，比如只看猫和狗的图
  • 测试：来一张图，三个分类器都投票：
  • 猫vs狗 → 猫赢（给猫一票）
  • 猫vs猪 → 猪赢（给猪一票）
  • 狗vs猪 → 狗赢（给狗一票）

票数：猫1，狗1，猪1 → 平局时看谁的“胜出优势”更大（置信度）

优点：每个分类器任务简单，只学两个类别的细微差别。 缺点：类别多时分类器数量暴增（100类要训练4950个分类器）。

翻译：每次选一个类别当“主角”，问“是不是它？”。

  • 拆分：是猫吗？是狗吗？是猪吗？ → 共 \( N=3 \) 场比赛
  • 训练：每个分类器看全部数据，但标签不同：
  • “猫识别器”：猫是正例，狗+猪全是反例
  • “狗识别器”：狗是正例，猫+猪全是反例
  • “猪识别器”：猪是正例，猫+狗全是反例
  • 测试：来一张图，三个分类器各自回答：
  • 猫识别器：不是（0%像猫）
  • 狗识别器：是（95%像狗）✅
  • 猪识别器：是（60%像猪）❌

若有多个说是，比置信度，选最高的（狗）。

优点：分类器少（100类只训练100个），训练快。 缺点：反例是“其他所有类别混在一起”，乱七八糟，训练难；且正负样本数量悬殊（1:99），类别不平衡严重。

看到这些公式头皮发麻很正常，我来把它们翻译成“人话”，你马上就能懂。

这堆东西到底在干什么？

它们都是决策树用来挑“最佳划分属性”的标准。 决策树的思路就是：不断问问题，让分出来的组里样本越来越纯（同一个组里尽量是同一类）。

这些指标就在量化“纯度”和“划分效果”。

1. 信息熵：混乱度

\[ Ent(D) = -\sum_{k=1}^{|y|} p_k \log_2 p_k \]

  • 一句话：衡量一堆样本有多乱，是不是各色人等混杂。
  • 值越小，纯度越高。
  • 极端情况：
  • 全是一个类（比如全是正例）→ \( Ent = 0 \)，最纯。
  • 正负各一半 → 熵最大，最混乱。

联想：一个房间，只有男生 → 熵为0；男女人数一样多 → 熵最大。

2. 信息增益：划分带来的纯度提升

\[ Gain(D, a) = Ent(D) - \sum_{v=1}^{V} \frac{|D^v|}{|D|} Ent(D^v) \]

  • 用属性 \( a \) 划分前，样本有个混乱度 \( Ent(D) \)。
  • 划分后，每个分支有自己的混乱度，按分支大小加权平均。
  • 混乱度下降越多，增益越大 → 划分效果越好。

比喻： 你有一篮子水果（苹果、橘子），很乱。

  • 按“颜色”分 → 红苹果一堆，橙橘子一堆，分完都很纯，增益大。
  • 按“形状”分 → 可能效果没那么好，增益小。

信息增益偏好“取值多的属性”。 比如“编号”属性：每个样本一个号，分完后每个分支只有一个样本，纯得不得了（熵=0），增益最大。但这显然没有泛化能力，没用。

所以需要改进：增益率。

3. 增益率：给“取值多”的属性加惩罚

\[ IV(a) = -\sum_{v=1}^{V} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|} \] \[ Gain\_ratio = \frac{Gain(D, a)}{IV(a)} \]

  • \( IV(a) \) 是属性 \( a \) 的“内在信息”，可以理解为属性自身有多少种取值。
  • 属性取值越多（比如编号有1000个值），\( IV(a) \) 越大；分得越均匀，它也越大。
  • 用\( IV(a) \)当分母，取值很多的属性就被“罚款”了。

C4.5的巧妙操作： 不直接选增益率最大的，而是先选出信息增益高于平均水平的“候选者”，再从里面挑增益率最高的。这样既不会选到太差的属性，又避免了“编号陷阱”。

4. 基尼指数：另一个角度测量纯度

\[ Gini(D) = 1 - \sum_{k=1}^{|y|} p_k^2 \]

  • 也是越小越纯。
  • 它其实在算：随机抽两个样本，它俩类别不同的概率。这个概率越小，说明样本越可能是同一类，纯度越高。
  • 计算上比熵简单（没有对数），所以CART树用它。

一张总结对比表

指标用于哪个算法一句话解释优点缺点/注意事项
信息增益ID3划分后纯度提升多少直观偏好取值多的属性
增益率C4.5增益除以属性固有的“乱度”惩罚多值属性实际是增益+增益率两步筛选
基尼指数CART随机抽俩样本，类别不同的概率计算快与熵效果接近

帮你串联记忆

  • 熵/基尼：描述“纯度”，越低越好。
  • 信息增益：划分前熵 − 划分后加权熵，越大越好。
  • 增益率：信息增益 ÷ 分裂信息，平衡之。
  • 算法选择逻辑：
  • ID3：只看增益
  • C4.5：先看增益达不达标，再看增益率
  • CART：分类用基尼指数，回归用MSE

这些概念初看像天书，其实都是在回答一个问题：“按哪个属性分开，能让各组标签更纯粹？” 你只要抓住这句核心，再回看公式就顺了。需要的话，我可以给你一个具体的手算例子，帮你彻底打通。

好，我们直接用一个超级简化的西瓜数据集，手算一遍，你就能彻底分清这几种准则的算计方式。

数据集：判断好瓜还是坏瓜

我们有 6 个西瓜样本，两个特征：色泽、编号，要预测好瓜。

编号色泽好瓜
1青绿是
2乌黑是
3青绿是
4浅白否
5乌黑否
6浅白否

目标类别：“是”有 3 个，“否”有 3 个，各占一半。

第一步：计算初始信息熵（混乱度）

\[ Ent(D) = -\sum p_k \log_2 p_k \]

  • \( p_{\text{是}} = 3/6 = 0.5 \)
  • \( p_{\text{否}} = 3/6 = 0.5 \)

\[ Ent(D) = -0.5\log_2 0.5 - 0.5\log_2 0.5 = -0.5\times(-1) - 0.5\times(-1) = 1 \]

初始熵为 1，表示最大混乱度（正反例一样多）。

第二步：按“色泽”划分，算信息增益

“色泽”有 3 个取值：青绿、乌黑、浅白。

  • 青绿：样本 {1,3}，2 个全为“是” → 熵 = 0
  • 乌黑：样本 {2,5}，1 是 1 否 → 熵 = 1
  • 浅白：样本 {4,6}，2 个全为“否” → 熵 = 0

每个子集大小都是 2，权重均为 2/6 = 1/3。

加权平均熵： \[ \frac{1}{3}\times 0 + \frac{1}{3}\times 1 + \frac{1}{3}\times 0 = \frac{1}{3} \]

信息增益： \[ Gain(D, \text{色泽}) = Ent(D) - \text{加权熵} = 1 - \frac{1}{3} = 0.667 \]

第三步：信息增益的缺陷——看看“编号”属性

“编号”有 6 个取值（1 到 6），每个取值恰好对应一个样本。 划分后每个分支只有一个样本，必然纯得不得了，熵全都是 0。

加权平均熵 = 0。

信息增益： \[ Gain(D, \text{编号}) = 1 - 0 = 1 \]

它比色泽的增益 0.667 更大！如果只看增益，算法会选“编号”来划分，但这显然毫无泛化能力——这就是 ID3 偏好取值多的属性。

第四步：用增益率来“惩罚”编号

增益率的分母 IV(a) 衡量属性本身有多少“内在信息”（取值越多、越均匀，IV 越大）。

  • 色泽的 IV：三个取值各占 2/6 = 1/3

\[ IV(\text{色泽}) = -3 \times \left(\frac{1}{3}\log_2 \frac{1}{3}\right) = -3 \times \frac{1}{3} \times (-1.585) = 1.585 \]

增益率： \[ Gain\_ratio(\text{色泽}) = \frac{0.667}{1.585} \approx 0.421 \]

  • 编号的 IV：六个取值各占 1/6

\[ IV(\text{编号}) = -6 \times \left(\frac{1}{6}\log_2 \frac{1}{6}\right) = \log_2 6 \approx 2.585 \]

增益率： \[ Gain\_ratio(\text{编号}) = \frac{1}{2.585} \approx 0.387 \]

色泽的增益率 0.421 > 编号的 0.387，优劣瞬间反转。C4.5 就靠这招避坑。

第五步：基尼指数（CART 的视角）

初始基尼值： \[ Gini(D) = 1 - (0.5^2 + 0.5^2) = 0.5 \]

按色泽划分，计算每个子集的基尼值并加权：

  • 青绿（全是）：Gini = 1 - (1² + 0²) = 0
  • 乌黑（1是1否）：Gini = 1 - (0.5² + 0.5²) = 0.5
  • 浅白（全否）：Gini = 0

加权基尼指数： \[ Gini\_index(D, \text{色泽}) = \frac{1}{3}\times 0 + \frac{1}{3}\times 0.5 + \frac{1}{3}\times 0 = 0.167 \]

数值越小，划分越纯。CART 会比较所有候选属性，选基尼指数最小的那个。若用“编号”划分，每个分支 Gini=0，加权为 0，依然最小，所以基尼本身也有偏好多值属性的倾向，但 CART 通过强制二分（比如把编号先按某个值分成两组）来缓解此问题。

核心对比总结

指标公式核心数值变化本例“色泽”本例“编号”谁胜出
信息增益熵降幅越大越好0.6671编号（不公平）
增益率增益 ÷ IV越大越好0.4210.387色泽（公平）
基尼指数划分后加权基尼值越小越好0.1670编号（仍有偏好）

你现在可以清晰地看到，同一个数据，不同准则会选出不同的划分属性，所以设计这些准则就是为了在某些场景下做出更合理的选择。

我问

我记得机器学习中的方差和偏差一个是代表训练集的训练误差，一个是模型在测试集上的误差，但是我分不清了

你的问题切中了一个超级常见的误区——“偏差=训练误差，方差=测试误差”这个说法是不准确的，但它能流传开，是因为背后确实有点关联。

让我帮你从根本上理清楚。

核心纠偏：偏差和方差不是对应某个数据集的误差

偏差和方差是对模型误差来源的分解，它们描述的是模型本身的属性，而不是在具体哪个数据集上的表现。

我们要看的是期望泛化误差（模型在无穷多测试点上的平均表现）。它可以被分解为三部分：

\[ \text{期望泛化误差} = \text{偏差}^2 + \text{方差} + \text{不可消除的噪声} \]

  • 偏差：模型的平均预测与真实值之间的差距。反映模型本身的准确度。
  • 方差：对于不同的训练集，模型预测值的变化程度。反映模型的稳定性。
  • 噪声：数据本身自带的误差，无法消除。

用打靶图秒懂（最经典图解）

想象你手里有把枪，靶心是真实值。你用不同的训练集训练出多个模型，每个模型都开一枪。

情况偏差方差图像
理想情况低低弹孔全集中在靶心
欠拟合高低弹孔很集中，但全部偏离靶心（瞄歪了）
过拟合低高弹孔很散，虽然平均可能落在靶心附近，但每一枪都飘得厉害
最差情况高高弹孔又散又偏
  • 偏差高：模型连训练数据都学不好（欠拟合），在训练集和测试集上误差都大。
  • 方差高：模型把训练数据里的随机噪声都学进去了，换一组训练数据结果就大变样（过拟合），在训练集上误差极低，但在测试集上误差会炸。

为什么你会记成“偏差是训练误差，方差是测试误差”？

因为它们在典型表现上很像：

  • 高偏差模型（如线性模型 fit 非线性数据）：训练误差就很大，测试误差自然也大 → 你印象里“偏差≈训练误差大”。
  • 高方差模型（如深度学习完全记住了训练数据）：训练误差可以到0，但一到测试集就扑街 → 你印象里“方差≈测试误差大”。

但这是症状，不是定义。 偏差和方差的本质是：你的模型预测的“准星”在哪里，以及“晃得有多厉害”。

一张表彻底区分

记忆口诀

“偏差看准不准，方差看稳不稳”

  • 偏差大 → 连训练集都学不好（瞄得就不对）
  • 方差大 → 训练集学太好，换个数据就完蛋（手太抖，每把都天差地别）

  1. OvO：锦标赛模式（一对一）

翻译：让任意两个类别单挑，最后看谁赢得多。

拆分：猫vs狗，猫vs猪，狗vs猪 → 共 C 3 2 = 3 C 3 2 ​ =3 场比赛（分类器）

训练：每个分类器只学“这俩怎么区分”，比如只看猫和狗的图

测试：来一张图，三个分类器都投票：

猫vs狗 → 猫赢（给猫一票）

猫vs猪 → 猪赢（给猪一票）

狗vs猪 → 狗赢（给狗一票）

票数：猫1，狗1，猪1 → 平局时看谁的“胜出优势”更大（置信度）

优点：每个分类器任务简单，只学两个类别的细微差别。 缺点：类别多时分类器数量暴增（100类要训练4950个分类器）。

你这里说的这一对一的情况，如果有100类，训练4950个分类器，那么在分类的时候是如何做的呢

这个问题问得特别好，而且你抓住了关键：4950个分类器，到底怎么“投票”？

我来把整个过程一步一步拆开。

预测一张新图片的全过程

假设现在有100个类别，已经训好了 \( C_{100}^{2} = 4950 \) 个二分类器。 现在来了一张新图片，我们要判断它属于哪个类别。

对于任意两个类别 \( i \) 和 \( j \)（比如“猫 vs 狗”），对应的分类器会做两件事：

  1. 预测图片属于 \( i \) 还是 \( j \)。
  2. 给出一个置信度，通常是概率，或SVM的决策函数值。

这个分类器只负责“这两个中选一个”，它根本不知道世界上还有其他98个类别存在。

例如得到类似这样的结果：

分类器预测胜者置信度
猫 vs 狗猫0.9
猫 vs 牛猫0.8
猫 vs 汽车汽车0.7
狗 vs 牛狗0.6
狗 vs 汽车汽车0.85
牛 vs 汽车汽车0.9
.........

一共4950行。

实际实现时，不是人手动数票，而是用一个计数器（通常是一个长度为100的数组），来累积每个类别得到的“信任度”。

对于每一个分类器：

  • 给被预测为“胜者”的那个类别加上它的置信度。
  • 另一个类别得0分。

比如“猫 vs 汽车”预测汽车胜，置信度0.7：

  • 汽车得分 +0.7
  • 猫得分 +0

所有4950个分类器跑完后，每个类别都有一个累积总信任度。

有两种常见做法，但殊途同归：

  1. 按累积信任度总和选出最高分（最常见，化解平局）。
  2. 按获胜场次（赢了多少个分类器）选出票数最多者，平局时再用信任度。

大多数实现直接用第1种，因为平局概率极低，且信任度能精细区分。

用你的例子（3类）重新验证

猫、狗、猪，3个分类器：

分类器胜者信任度
猫 vs 狗猫0.9
猫 vs 猪猪0.6
狗 vs 猪狗0.8

累积：

  • 猫：0.9 + 0 = 0.9
  • 狗：0 + 0.8 = 0.8
  • 猪：0.6 + 0 = 0.6

结果是猫获胜，而不是平局。 如果按场次：猫1胜、狗1胜、猪1胜，是平局，这时就必须看信任度了。

100类的极端情况

如果每个分类器给出的置信度都是0.5上下浮动（模型很差），可能出现：

  • 各分类器预测结果非常分散。
  • 最终最高分那个类别可能只比第二高高零点几分。

这时预测就不可靠，但也因此信任度机制能反映模型的不确定性，比单纯数票数强得多。

一句话总结

4950个分类器就是4950场“擂台赛”，每个分类器给胜者加置信度分，最后100个类别中累计信任度最高的那个获胜。用置信度而不是票数，能解决平局，还能衡量模型对自己的判断有多大把握。
