《无约束最优化方法》模拟试题

考试时间：120分钟 &nbsp;&nbsp;&nbsp; 满分：100分

  1. 关于无约束优化问题的局部解和全局解，下列说法正确的是（ ）。

A. 局部解一定是全局解 B. 全局解不一定是局部解 C. 严格局部解一定是唯一全局解 D. 全局解一定是局部解

  1. 设 \(f(x)\) 二阶连续可微，若 \(x^*\) 是 \(f(x)\) 的一个局部极小点，则下列条件中不必须成立的是（ ）。

A. \(\nabla f(x^) = 0\) B. \(\nabla^2 f(x^)\) 是半正定矩阵 C. \(\nabla^2 f(x^)\) 是正定矩阵 D. \(x^\) 是 \(f(x)\) 的一个平稳点

  1. 在用黄金分割法（0.618法）求解一元单峰函数 \(\phi(\alpha)\) 在区间 \([a, b]\) 上的极小点时，两个试探点的取法通常为（ ）。

A. \(a_l = a + 0.382(b-a), \quad a_r = a + 0.618(b-a)\) B. \(a_l = a + 0.618(b-a), \quad a_r = a + 0.382(b-a)\) C. \(a_l = a + 0.5(b-a), \quad a_r = a + 0.5(b-a)\) D. \(a_l = a + 0.2(b-a), \quad a_r = a + 0.8(b-a)\)

  1. 对于下降算法，若产生的迭代序列 \(\{x^k\}\) 满足 \(\lim_{k\to\infty} \frac{\|x^{k+1}-x^\|}{\|x^k-x^\|} = 0\)，则称该序列的收敛速度是（ ）。

A. 线性收敛 B. 超线性收敛 C. 次线性收敛 D. 二阶收敛

  1. 下列哪种性质是评价一个无约束优化算法是否高效的重要指标，尤其针对正定二次函数？（ ）

A. 全局收敛性 B. 二次终止性 C. 线性收敛性 D. 稳定性

  1. 设 \(f(x)\) 是 \(\mathbb{R}^n\) 上一阶连续可微的凸函数，则 \(x^*\) 是全局极小点的充分必要条件是 ______。
  2. 确定一维搜索区间的常用方法是 ______ 法。
  3. 在非精确线性搜索中，Armijo 条件（或称Goldstein第一不等式）的数学表达式为 ______。
  4. 若某个算法对于任意正定二次函数，从任意初始点出发都能经过有限步迭代达到其极小点，则称该算法具有 ______。
  5. 在最优化算法的收敛准则中，当 \(\|\nabla f(x^k)\| \le \varepsilon\) 时停止迭代，这种准则称为 ______ 准则。
  1. （10分）简述一个标准下降算法的基本迭代格式，并说明对搜索方向 \(d^k\) 和步长 \(a_k\) 的基本要求。
  2. （10分）解释什么是精确线性搜索，并写出其数学定义。课件中给出了正定二次函数精确步长的计算公式，请写出该公式（无需推导）。

题目： 用黄金分割法（0.618法）求解函数 \(f(x) = x^2 + 2x\) 在区间 \([-3, 5]\) 上的极小点。 要求：迭代两次（即完成两次区间缩进后），给出每次迭代后的搜索区间、两个试探点及其函数值。初始区间为 \([-3, 5]\)，保留小数点后四位。

题目： 设 \(f(x)\) 是定义在 \(\mathbb{R}^n\) 上的二阶连续可微函数，且 \(x^*\) 是 \(f(x)\) 的一个局部极小点。 请证明以下两个必要条件：

  1. \(\nabla f(x^*) = 0\) （一阶必要条件）
  2. \(\nabla^2 f(x^*)\) 是半正定矩阵 （二阶必要条件）

参考答案及评分标准

  1. D。解析：全局解是定义在整个定义域上的最小值点，一定是某个邻域内的最小值点，因此一定是局部解。反之则不一定（课件第3页）。
  2. C。解析：局部极小点的二阶必要条件是Hessian矩阵半正定，而非正定。正定是二阶充分条件的一部分（课件第6-8页）。
  3. A。解析：黄金分割法中，两个试探点关于区间对称，且缩短率为0.618。左试探点距左端点距离为区间长的0.382倍，即 \(a + 0.382(b-a)\)，右试探点为 \(a + 0.618(b-a)\)（课件第23-26页）。
  4. B。解析：收敛速度定义：\(0<\beta<1\)为线性，\(\beta=0\)为超线性，\(\beta=1\)为次线性（课件第49页）。
  5. B。解析：二次终止性是评价算法对正定二次函数求解效率的重要指标（课件第51页）。
  1. \(\nabla f(x^*) = 0\) （或“梯度为零”或“驻点条件”）
  2. 进退法
  3. \(\phi(\mu) \le \phi(0) + \mu \beta_1 \phi'(0)\) （其中 \(0<\beta_1<1\)）
  4. 二次终止性
  5. 梯度准则（或“目标函数梯度准则”）
  1. 参考答案（10分）：

基本迭代格式：从一个初始点 \(x^1\) 出发，按照如下规则产生迭代序列： \[ x^{k+1} = x^k + a_k d^k, \quad k = 1, 2, \dots \] 其中 \(d^k\) 为搜索方向，\(a_k > 0\) 为步长。（4分） 基本要求： - 对 \(d^k\) 的要求：必须是下降方向，即满足 \(\nabla f(x^k)^T d^k < 0\)。理想情况下，该方向应与负梯度方向夹角小于90度，以保证函数值有“充分”下降。（3分） - 对 \(a_k\) 的要求：通过某种线性搜索（精确或非精确）选取，使得 \(f(x^{k+1}) = f(x^k + a_k d^k) < f(x^k)\)，即保证目标函数值单调下降。（3分）

  1. 参考答案（10分）：

精确线性搜索：在给定搜索方向 \(d^k\) 后，沿着该方向寻找一个步长 \(\alpha_k\)，使得一元函数 \(\phi(\alpha) = f(x^k + \alpha d^k)\) 达到其最小值。（5分） 数学定义： \[ \phi(\alpha_k) = \min_{\alpha \ge 0} f(x^k + \alpha d^k) \] 正定二次函数的精确步长公式：（5分） \[ \alpha_k = -\frac{d^{k^T} \nabla f(x^k)}{d^{k^T} G d^k} \] 其中 \(G\) 是正定二次函数的Hessian矩阵。或者根据课件第15页的符号，若 \(f(x) = \frac{1}{2} x^T H x + C^T x + b\)，则 \(\alpha_k = -\frac{d^{k^T} (H x^k + C)}{d^{k^T} H d^k}\)。

解： 给定 \(f(x) = x^2 + 2x\)，区间 \([a, b] = [-3, 5]\)，缩短率 \(\tau = 0.618\)。 初始区间长度 \(L_0 = 5 - (-3) = 8\)。

第一次迭代：

  • 左试探点：\(x_1 = a + (1-\tau)(b-a) = -3 + 0.382 \times 8 = -3 + 3.056 = 0.0560\)
  • 右试探点：\(x_2 = a + \tau (b-a) = -3 + 0.618 \times 8 = -3 + 4.944 = 1.9440\)
  • 计算函数值：

\(f(x_1) = (0.0560)^2 + 2 \times 0.0560 = 0.0031 + 0.1120 = 0.1151\) \(f(x_2) = (1.9440)^2 + 2 \times 1.9440 = 3.7791 + 3.8880 = 7.6671\)

  • 比较：\(f(x_1) < f(x_2)\)，因此舍去右区间 \([x_2, b] = [1.9440, 5]\)。
  • 新区间：\([a_1, b_1] = [a, x_2] = [-3, 1.9440]\)，长度 \(L_1 = 4.9440\)。

第二次迭代： 新区间 \([a, b] = [-3, 1.9440]\)，长度 \(L = 4.9440\)。

  • 新左试探点：注意 \(x_1\) 在原区间中已经计算过，它成为了新区间的右试探点。

\(x_1' = a + (1-\tau)L = -3 + 0.382 \times 4.9440 = -3 + 1.8886 = -1.1114\)

  • 右试探点：\(x_2' = a + \tau L = -3 + 0.618 \times 4.9440 = -3 + 3.0554 = 0.0554\) （由于舍入误差，此值应等于第一次迭代的左试探点0.0560）
  • 计算函数值：

\(f(x_1') = (-1.1114)^2 + 2 \times (-1.1114) = 1.2352 - 2.2228 = -0.9876\) \(f(x_2') = (0.0554)^2 + 2 \times 0.0554 = 0.0031 + 0.1108 = 0.1139\)

  • 比较：\(f(x_1') < f(x_2')\)，因此舍去右区间 \([x_2', b] = [0.0554, 1.9440]\)。
  • 新区间：\([a_2, b_2] = [a, x_2'] = [-3, 0.0554]\)。（或精确地，\([ -3, 0.0560 ]\)）

证明：

  1. **证明一阶必要条件 \(\nabla f(x^*) = 0\)** （10分）：

对任意的非零方向 \(d \in \mathbb{R}^n\)，构造函数 \(\varphi(\alpha) = f(x^ + \alpha d)\)。 由于 \(x^\) 是 \(f\) 的局部极小点，则 \(\alpha=0\) 是 \(\varphi(\alpha)\) 的局部极小点。 根据一元函数极小点的一阶必要条件，有 \(\varphi'(0) = 0\)。 又因为 \(\varphi'(\alpha) = \nabla f(x^ + \alpha d)^T d\)，所以 \(\varphi'(0) = \nabla f(x^)^T d = 0\)。 由于方向 \(d\) 是任意的，要使 \(\nabla f(x^)^T d = 0\) 对任意 \(d\) 都成立，必有 \(\nabla f(x^) = 0\)。证毕。

  1. **证明二阶必要条件 \(\nabla^2 f(x^*)\) 是半正定矩阵** （10分）：

由一阶必要条件已知 \(\nabla f(x^) = 0\)。 对任意非零方向 \(d \in \mathbb{R}^n\)，由 \(x^\) 是局部极小点知，存在 \(\varepsilon > 0\)，使得对任意 \(0 < \alpha < \varepsilon\)，有 \[ f(x^ + \alpha d) \ge f(x^) \] 将 \(f(x^ + \alpha d)\) 在 \(x^\) 处作二阶泰勒展开： \[ f(x^ + \alpha d) = f(x^) + \alpha \nabla f(x^)^T d + \frac{1}{2} \alpha^2 d^T \nabla^2 f(x^) d + o(\alpha^2) \] 代入 \(\nabla f(x^) = 0\)，并移项得： \[ \frac{1}{2} \alpha^2 d^T \nabla^2 f(x^) d + o(\alpha^2) \ge 0 \] 两边同除以 \(\alpha^2\)，并令 \(\alpha \to 0^+\)，可得： \[ d^T \nabla^2 f(x^) d \ge 0 \] 由于 \(d\) 是任意非零向量，根据半正定矩阵的定义，\(\nabla^2 f(x^)\) 是半正定矩阵。证毕。
