全置信度不受规模影响

2026-10-09 · 主题：课程-数学、课程-编程/计算机 · 3 条消息 · 对话编号 012
我问

全置信度不是受规模影响吗

你会有这个疑问非常正常，因为在数据挖掘和关联规则中，“规模”这个词很容易引起歧义。

直接回答你的问题：从数学定义上来说，全置信度（All_confidence）确实是不受数据集总规模（N）影响的。

我们可以从以下几个方面来详细拆解：

PPT上的全置信度公式是： \[ All_conf(A,B) = \frac{sup(A,B)}{\max(sup(A), sup(B))} \] 假设数据集的总事务数为 N，绝对计数分别为 count(A,B)、count(A)、count(B)。 因为 \(sup(X) = \frac{count(X)}{N}\)，代入公式： \[ All_conf(A,B) = \frac{count(A,B)/N}{\max(count(A)/N, count(B)/N)} = \frac{count(A,B)}{\max(count(A), count(B))} \] 你会发现，分母的 N 和分子的 N 直接约掉了。

因此，如果你把整个数据集复制一遍（总规模 N 翻倍），或者向数据集中加入大量与 A 和 B 完全无关的记录，全置信度的值不会发生任何改变。这就是PPT右侧红字“不受规模影响”的本意。

你可能把以下几个概念混淆了：

  • 绝对支持度（频数）：绝对支持度（count）是强烈受规模影响的（数据越多，频数越大）。但全置信度使用的是相对支持度（概率 P）。
  • 受“项集不平衡”的影响：虽然不受总规模 N 的影响，但全置信度受 A 和 B 自身频率相对大小的影响（即 \(P(A)\) 和 \(P(B)\) 的差距）。如果 A 和 B 极度不平衡，全置信度可能会有偏差，但这属于“分布形态”的影响，不属于“数据集规模”的影响。
  • 零事务/零不变性：在数据挖掘中，有时候人们把“零事务”（同时不包含A和B的事务）也算作规模的一部分。加入大量零事务，绝对支持度计数不变，但总规模N变大。而全置信度因为约掉了N，所以对这种规模变化免疫。

PPT上列出的这四个度量（全置信度、最大置信度、Kulczynski、余弦），其共性就是它们都只依赖于 \(P(A|B)\) 和 \(P(B|A)\)。

  • 最大置信度：\(\max(P(A|B), P(B|A))\)
  • 余弦：\(\sqrt{P(A|B) \times P(B|A)}\)
  • Kulczynski：\(\frac{1}{2}(P(A|B) + P(B|A))\)
  • 全置信度：\(\min(P(A|B), P(B|A))\)

这些公式的本质都是条件概率的运算，条件概率本身是一种归一化的度量，所以它们全都不受数据集总量 N 的影响。

总结一下： PPT上的结论是正确的。全置信度不受数据集总规模（N）影响。你如果觉得它有偏颇，往往是因为它虽然不受规模影响，但受“A和B的绝对支持度极其稀疏”或“A和B频率极度倾斜”的影响（即它没有考虑 \(P(A \cup B)\) 的绝对数量大小，这是它和提升度（Lift）等指标的区别所在）。
