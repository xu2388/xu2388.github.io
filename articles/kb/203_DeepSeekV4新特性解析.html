2026-04-25 · 主题：杂项/其他 · 19 条消息 · 对话编号 203
我问

最新的ds v4有什么不一样啊

我问

贵吗

根据2026年4月24日的官方消息，大家常说的"ds v4"（全称DeepSeek-V4）预览版已正式发布并开源[reference:0][reference:1]。这一版的主要升级目标，是把百万级上下文（1M Token） 和更强的智能体（Agent）能力变成所有用户的标配。

  • 🚀 架构与规模升级：推出DeepSeek-V4-Pro（1.6万亿参数）和DeepSeek-V4-Flash（2840亿参数）两个版本[reference:2][reference:3]。V4采用了全新的DSA2注意力机制和MoE混合专家架构，将上下文长度从V3.2的128K提升至1M，实现了近10倍的跨越，可以轻松处理类似《三体》三部曲体量的超长文本[reference:4][reference:5][reference:6][reference:7]。
  • 🤖 核心能力与定位：V4的核心升级之一是Agent（智能体）能力，让模型可以自主思考和调用外部工具来完成复杂任务[reference:8][reference:9]。Pro版的Agent能力在开源模型中达到最佳，数学和编程推理能力已比肩世界顶级闭源模型[reference:10][reference:11]。而Flash版在核心推理能力接近Pro版的同时，响应更快、成本更低[reference:12][reference:13]。同时，现在你可以自主选择“快速模式”以获取即时响应，或“专家模式”深度解决复杂问题[reference:14][reference:15]。
  • 💰 定价与生态：Flash版价格为输入1元/百万tokens，输出2元/百万tokens；Pro版输出为24元/百万tokens[reference:16]。开发者现在就可以通过API调用（如deepseek-v4-pro或deepseek-v4-flash），或直接在官网/App上体验[reference:17]。

如果想深入了解某个方面，比如具体的API调用方式或技术细节，随时可以再问我～

我问

写代码的能力怎么样啊

不贵，甚至可以说非常有竞争力。 我们分两个版本来看：

  • Flash 版（输入 ¥1/百万tokens，输出 ¥2/百万tokens）

这个价格在同类高性能模型中属于极低水平。拿它来处理超长文档或日常对话，成本几乎可以忽略不计。举例来说，把整本《三体》三部曲（约90万字）全文输入加输出一次，费用也就在几元钱。

  • Pro 版（输出 ¥24/百万tokens）

这个价格看起来比 Flash 高，但它的能力对标的是 GPT-4o、Claude Opus 这样的顶级闭源模型。 对比一下：GPT-4o 的输出定价是 15 美元/百万tokens（约合 ¥108），Claude Opus 更是要 75 美元/百万tokens（约 ¥540）。 也就是说，Pro 版只用大约 1/5 甚至 1/20 的价格，就能拿到世界顶级的推理和 Agent 能力。

所以，无论你是想日常高频使用，还是处理复杂的深度推理任务，DeepSeek-V4 目前的定价都属于“量大管饱、丰俭由人”的类型。 而且，如果你是通过 官网或 App 直接使用，目前仍然是免费的。

我问

丰俭由人 这个是什么意思啊

DeepSeek-V4 的代码能力可以说是它最亮眼的标签之一，直接迈入了世界顶级行列，是它最核心的竞争力。不论是权威测试还是开发者的实际反馈，结果都很惊人，说是“王炸”级别的升级也不为过。

为了方便你对它的水平有个直观概念，我整理了一份它在几个权威测试中的成绩单：

  • LiveCodeBench (Pass@1)：V4-Pro 获 93.5 分，胜过 GPT-5.4 (91.7) 和 Gemini 3.1 Pro (89.2)[reference:0][reference:1]。
  • Codeforces Rating：V4-Pro 获 3206 分，超过 GPT-5.4 (3168) 和 Gemini 3.1 Pro (3052)[reference:2][reference:3][reference:4]。
  • SWE-bench Verified (Resolved)：V4-Pro 获 80.6%，与顶级闭源模型的 Claude Opus 4.6 (80.8%) 几乎持平[reference:5][reference:6][reference:7]。
  • HumanEval (Pass@1)：V4 获 98%，在当前权威榜单上占据领先地位[reference:8][reference:9]。
  • SWE-Bench Pro：V4 得分 58.6%[reference:10]。
  • Terminal-Bench 2.0：V4 得分 82.7%[reference:11]。
  • 内部R&D编程测试 (Pass Rate)：V4-Pro-Max 获 67%，远超 Sonnet 4.5 (47%)，已接近 Opus 4.6 Thinking (80%)[reference:12][reference:13]。该测试源自 50 余位工程师约 200 个真实任务，超九成参与调研的开发者认为 V4-Pro 已可作为首选编程模型[reference:14]。

测试分数或许有些抽象，但开发者的实际反馈最能说明问题，主要可以总结为三点：

  • 超强的独立编程能力（Agent能力）：V4能像真正的程序员一样自主工作。它能自主规划、调用工具并编写复杂代码，有测试显示它可以连续自主编程超过60分钟，无需任何人工干预就完成复杂的数据库设计和安卓模拟器开发[reference:15]。
  • 逻辑满分，审美需努力：对于后台逻辑、数据处理等任务，它的框架清晰、速度极快[reference:16]。不过，在前端页面设计等需要“审美”的任务上，它的成品功能完善但界面可能不够美观，需要人工微调[reference:17]。
  • 与顶尖闭源模型的差距：综合来看，V4的代码能力已经和Claude Opus 4.6、GPT-5.4这些顶级闭源模型处于同一梯队[reference:18]。现在，它已经是DeepSeek内部员工日常开发的主力模型，体验上已优于Sonnet 4.5，交付质量接近Claude Opus 4.6的非思考模式[reference:19][reference:20]。

V4 Flash是经济实惠版，推理能力接近Pro，响应速度更快、成本更低[reference:21][reference:22]。在处理常规编程任务时，性能与Pro版基本一致，是兼顾高性能与高性价比的选择[reference:23]。

所以，简单概括DeepSeek-V4的代码水平就是：开源模型的定价，世界顶级闭源模型的实力。

你目前主要用它来写哪类代码呢？是后台逻辑、脚本工具，还是前端页面？可以跟我说说你的具体场景，我帮你看看V4在你的领域里表现是否足够给力～

我问

你给我写一个论坛的前端吧，我就要一个html，你给我写一下

“丰俭由人”这个说法很形象，字面意思是“丰富还是节俭，由你自己决定”，后来常用来形容选择权完全在你自己手上，可以根据自己的需求和预算来灵活决定，高低档次都有得选。

结合我上次给你分析的 DeepSeek-V4 价格，就可以这么理解：

  • 想“俭”一点、日常够用就行

就选 V4 Flash 版。它推理能力接近 Pro，但响应更快，价格也极低（输出才 2 块钱/百万 tokens），用来处理超长文档或日常开发，成本几乎可以忽略不计。

  • 想“丰”一点、追求顶级体验

就选 V4 Pro 版。它的代码和 Agent 能力直接对标世界顶级闭源模型，但价格只要它们的 1/5 甚至 1/20，花更少的钱就能拿到顶尖的能力。

简单说就是：根据你现在要做的事，觉得够用就选实惠的，需要顶配就上最强的——丰俭由人，任君选择。

        function addReply(postId) {
            const input = document.getElementById('replyInput');
            if (!input || !input.value.trim()) return;
            const post = posts.find(p => p.id === postId);
            if (!post.replyList) post.replyList = [];
            post.replyList.push({
                author: currentUser.name,
                avatar: currentUser.avatar,
                time: '刚刚',
                text: input.value.trim()
            });
            post.replies = post.replyList.length;
            input.value = '';
            openDetail(postId); // 刷新详情页

        function submitPost() {
            const title = document.getElementById('newTitle').value.trim();
            const content = document.getElementById('newContent').value.trim();
            const category = document.getElementById('newCategory').value;
            if (!title || !content) return alert('请填写标题和内容');

            posts.unshift({
                id: nextId++,
                title,
                category,
                tags: [category === 'tech' ? '技术' : category === 'ask' ? '求助' : '分享'],
                author: currentUser.name,
                avatar: currentUser.avatar,
                time: '刚刚',
                excerpt: content.substring(0, 80) + '...',
                content,
                views: 0,
                replies: 0,
                likes: 0,
                isHot: false,
                isNew: true,
                replyList: []
            });

            closeModal();
            renderHome();
        }

        function handleSearch() {
            const keyword = document.getElementById('searchInput').value.trim().toLowerCase();
            if (keyword === '') {
                renderHome();
                return;
            }
            const filtered = posts.filter(p => 
                p.title.toLowerCase().includes(keyword) || 
                p.content.toLowerCase().includes(keyword)
            );
            let html = `
                <div class="page-header">
                    <h2 class="page-title">🔍 搜索结果：${keyword}</h2>
                    <button class="btn btn-outline btn-sm" onclick="renderHome()">清除</button>
                </div>
                <div class="post-list">
            `;
            if (filtered.length === 0) {
                html += `<div class="empty-state"><div class="icon">🔎</div><p>没有找到相关帖子</p></div>`;
            } else {
                filtered.forEach(post => {
                    html += `
                        <div class="post-card" onclick="openDetail(${post.id})">
                            <div class="post-avatar">${post.avatar}</div>
                            <div class="post-body">
                                <div class="post-title">${post.title}</div>

                                    <span>🕒 ${post.time}</span>
                                </div>
                                <div class="post-excerpt">${post.excerpt}</div>
                            </div>
                        </div>
                    `;
                });
            }
            html += `</div>`;
            document.getElementById('contentArea').innerHTML = html;

这份代码构建了一个可以直接交互的轻量级技术社区，它主要包含三大功能模块和一个清晰的操作路径：

  • 帖子浏览与筛选：页面左侧的导航栏可以按首页、热门、最新、技术讨论、问答求助快速分类浏览帖子。右侧的热门标签支持筛选特定话题，顶部的搜索框还能按标题和内容搜索帖子，方便你快速定位感兴趣的内容。
  • 发布与回复：点击“+ 发帖”按钮会弹出表单，你可以填写标题、选择分类并撰写内容来发布新帖子。点击任意帖子卡片可以进入详情页，查看完整内容和他人回复，并在底部输入框发表自己的回复。
  • 模拟真实社区体验：页面预置了多条与DeepSeek-V4相关的热门讨论帖和回复，帖子上会显示浏览量、回复数和点赞数，热门帖子还会带有角标，还原了真实论坛的浏览氛围。

优化建议： 代码中的帖子数据（如标题、内容、回复）是静态示例，你可以替换posts数组里的内容或对接后端API来展示真实数据。搜索功能目前为前端过滤，大批量数据建议改用后端接口。
