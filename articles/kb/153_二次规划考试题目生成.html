2. （15分）变量消去法

问题： \[ \min f(x)=x_1^2+x_2^2+x_3^2,\quad \begin{cases} x_1+2x_2-x_3=4 \\ x_1-x_2+x_3=-2 \end{cases} \]

解：将约束看作关于\(x_1,x_2\)的方程组（选\(x_3\)为自由变量）： \[ \begin{cases} x_1+2x_2 = 4 + x_3 \\ x_1 - x_2 = -2 - x_3 \end{cases} \] 两式相减得：\((x_1+2x_2)-(x_1-x_2)= (4+x_3)-(-2-x_3) \Rightarrow 3x_2 = 6+2x_3 \Rightarrow x_2 = 2+\frac{2}{3}x_3\) 代入第二式：\(x_1 - (2+\frac{2}{3}x_3) = -2-x_3 \Rightarrow x_1 = 2+\frac{2}{3}x_3 -2 - x_3 = -\frac{1}{3}x_3\) 所以 \[ x_1 = -\frac{1}{3}x_3,\quad x_2 = 2+\frac{2}{3}x_3 \] 代入目标函数： \[ f = \left(-\frac{1}{3}x_3\right)^2 + \left(2+\frac{2}{3}x_3\right)^2 + x_3^2 = \frac{1}{9}x_3^2 + \left(4 + \frac{8}{3}x_3 + \frac{4}{9}x_3^2\right) + x_3^2 \] \[ = \left(\frac{1}{9}+\frac{4}{9}+1\right)x_3^2 + \frac{8}{3}x_3 + 4 = \left(\frac{5}{9}+1\right)x_3^2 + \frac{8}{3}x_3 + 4 = \frac{14}{9}x_3^2 + \frac{8}{3}x_3 + 4 \] 求导：\(\frac{df}{dx_3} = \frac{28}{9}x_3 + \frac{8}{3} = 0 \Rightarrow \frac{28}{9}x_3 = -\frac{8}{3} \Rightarrow x_3 = -\frac{8}{3} \cdot \frac{9}{28} = -\frac{72}{84} = -\frac{6}{7}\)。

于是 \[ x_1 = -\frac{1}{3}\left(-\frac{6}{7}\right) = \frac{2}{7},\quad x_2 = 2 + \frac{2}{3}\left(-\frac{6}{7}\right) = 2 - \frac{12}{21} = 2 - \frac{4}{7} = \frac{10}{7} \] 故 \[ x^* = \left( \frac{2}{7},\ \frac{10}{7},\ -\frac{6}{7} \right)^T \]

求乘子\(\lambda\)：由KKT条件\(Gx^ + r + A^T\lambda = 0\)。此处\(G=2I\)（因为\(f=\frac12 x^T(2I)x + 0\)），\(r=0\)。 \[ 2I x^ + A^T\lambda = 0 \Rightarrow 2\begin{pmatrix}2/7\\10/7\\-6/7\end{pmatrix} + \begin{pmatrix}1 & 1 \\ 2 & -1 \\ -1 & 1\end{pmatrix} \begin{pmatrix}\lambda_1 \\ \lambda_2\end{pmatrix} = 0 \] 即 \[ \begin{cases} \frac{4}{7} + \lambda_1 + \lambda_2 = 0 \\[2pt] \frac{20}{7} + 2\lambda_1 - \lambda_2 = 0 \\[2pt] -\frac{12}{7} - \lambda_1 + \lambda_2 = 0 \end{cases} \] 由第一和第三式相加得：\(\frac{4}{7}-\frac{12}{7} + 2\lambda_2 = 0 \Rightarrow -\frac{8}{7}+2\lambda_2=0 \Rightarrow \lambda_2 = \frac{4}{7}\)。 代入第一式：\(\frac{4}{7}+\lambda_1+\frac{4}{7}=0 \Rightarrow \lambda_1 = -\frac{8}{7}\)。 验算第二式：\(\frac{20}{7}+2(-\frac{8}{7})-\frac{4}{7} = \frac{20}{7}-\frac{16}{7}-\frac{4}{7}=0\)，正确。

所以\(\lambda^* = \left(-\frac{8}{7},\ \frac{4}{7}\right)^T\)。

3. （15分）有效集法

问题： \[ \min f(x)=x_1^2+x_2^2-2x_1-4x_2,\quad \begin{cases} x_1+x_2-1\le 0 &(c_1)\\ -x_1\le 0 &(c_2)\\ -x_2\le 0 &(c_3) \end{cases} \] 初始点\(x^1=(0,0)^T\)。

第一轮迭代 (\(k=1\))

  • 检查可行性和有效集：

\(c_1(0,0)=-1\le0\)（无效），\(c_2(0,0)=0\)（有效），\(c_3(0,0)=0\)（有效）。 故\(I(x^1)=\{2,3\}\)。

  • 子问题：\(\min \frac12 d^T G d + \nabla f(x^1)^T d\)，约束\(\alpha_i^T d =0,\ i\in\{2,3\}\)。

\(G = \begin{pmatrix}2&0\\0&2\end{pmatrix},\ \nabla f(x) = (2x_1-2,\ 2x_2-4)^T\)，\(\nabla f(x^1)=(-2,-4)^T\)。 约束：\(-d_1=0,\ -d_2=0 \Rightarrow d_1=0,d_2=0\)。 于是子问题只有一点\(d=0\)，目标值0。

  • 解KKT系统求乘子：\(\begin{pmatrix}G & A^T\\ A & 0\end{pmatrix}\begin{pmatrix}d\\\lambda\end{pmatrix}=\begin{pmatrix}-\nabla f\\0\end{pmatrix}\)。

这里\(A\)的行对应有效约束(2)和(3)：\(\alpha_2^T=(-1,0),\ \alpha_3^T=(0,-1)\)。 方程组： \[ \begin{pmatrix}2&0&-1&0\\0&2&0&-1\\-1&0&0&0\\0&-1&0&0\end{pmatrix} \begin{pmatrix}d_1\\d_2\\\lambda_2\\\lambda_3\end{pmatrix} =\begin{pmatrix}2\\4\\0\\0\end{pmatrix} \] 解：第三行 \(-d_1=0\Rightarrow d_1=0\)；第四行 \(-d_2=0\Rightarrow d_2=0\)； 第一行 \(2\cdot0+0+(-1)\lambda_2+0=2 \Rightarrow -\lambda_2=2 \Rightarrow \lambda_2=-2\)； 第二行 \(0+2\cdot0+0+(-1)\lambda_3=4 \Rightarrow -\lambda_3=4 \Rightarrow \lambda_3=-4\)。

  • 由于\(d^1=0\)，检查乘子：\(\lambda_2=-2<0,\ \lambda_3=-4<0\)，存在负乘子，应删除其中最小者（最负）。\(\min\{-2,-4\}=-4\)，对应约束\(q=3\)。

令\(x^{2}=x^1=(0,0)\)，\(I(x^2)=I(x^1)\setminus\{3\}=\{2\}\)。 置\(k=2\)，转步骤2。

第二轮迭代 (\(k=2\))

  • 当前点\(x^2=(0,0)\)，有效集\(I(x^2)=\{2\}\)（即\(-x_1=0\)有效）。

子问题：\(\min \frac12 d^T G d + \nabla f(x^2)^T d\)，约束\(\alpha_2^T d = -d_1=0\)。 即\(\min d_1^2+d_2^2-2d_1-4d_2,\ s.t.\ d_1=0\)。

代入\(d_1=0\)，目标函数化为\(\phi(d_2)=d_2^2-4d_2\)，求导得\(2d_2-4=0 \Rightarrow d_2=2\)。 所以\(d^2=(0,2)^T\)，方向非零。

  • 步长计算：沿\(d^2\)移动，检查非有效约束（\(i\notin I(x^2)\)即\(i=1,3\)）：
  • 对\(c_1\)：\(\alpha_1=(1,1),\ b_1=1\)，\(\alpha_1^T x^2=0\)，\(\alpha_1^T d^2 = 0+2=2>0\)，

\(\frac{b_1-\alpha_1^T x^2}{\alpha_1^T d^2} = \frac{1-0}{2}=0.5\)。 - 对\(c_3\)：\(\alpha_3=(0,-1),\ b_3=0\)，\(\alpha_3^T x^2=0\)，\(\alpha_3^T d^2 = 0-2=-2\le0\)，不计入（要求\(\alpha_i^T d>0\)）。 故\(\hat{\alpha}=0.5\)。 取\(\alpha_k = \min\{\hat{\alpha},1\}=0.5\)。

  • 更新点：\(x^{3}=x^2+0.5 d^2 = (0,0)+ (0,1) = (0,1)^T\)。

因为\(\alpha_k = \hat{\alpha}=0.5<1\)，故新有效集增加约束\(p=1\)： \(I(x^3)=I(x^2)\cup\{1\}=\{2,1\}\)（即\(-x_1=0\)和\(x_1+x_2-1=0\)）。 置\(k=3\)，转步骤2。

第三轮迭代 (\(k=3\))

  • 当前点\(x^3=(0,1)^T\)，检查约束：

\(c_1=0+1-1=0\)（有效），\(c_2=-0=0\)（有效），\(c_3=-1<0\)（无效）。 \(I(x^3)=\{1,2\}\)。

  • 子问题：\(\min \frac12 d^T G d + \nabla f(x^3)^T d\)，约束\(\alpha_1^T d=0,\ \alpha_2^T d=0\)。

\(\nabla f(x^3)=(2\cdot0-2,\ 2\cdot1-4)^T = (-2,-2)^T\)。 约束： \(\alpha_1=(1,1),\ \alpha_1^T d = d_1+d_2=0\)； \(\alpha_2=(-1,0),\ \alpha_2^T d = -d_1=0 \Rightarrow d_1=0\)。 代入得\(d_1=0\)，再由\(d_1+d_2=0\Rightarrow d_2=0\)。 故唯一可行点\(d=0\)，解为\(d^3=0\)。

  • 求乘子：方程组\(\begin{pmatrix}G & A^T\\ A & 0\end{pmatrix}\begin{pmatrix}d\\\lambda\end{pmatrix}=\begin{pmatrix}-\nabla f\\0\end{pmatrix}\)。

这里\(A\)的行对应约束(1)和(2)：\(\alpha_1=(1,1),\ \alpha_2=(-1,0)\)。 注意\(-\nabla f = (2,2)^T\)。 \[ \begin{pmatrix}2&0&1&-1\\0&2&1&0\\1&1&0&0\\-1&0&0&0\end{pmatrix} \begin{pmatrix}d_1\\d_2\\\lambda_1\\\lambda_2\end{pmatrix} =\begin{pmatrix}2\\2\\0\\0\end{pmatrix} \] 第四行：\(-d_1=0\Rightarrow d_1=0\)； 第三行：\(0+d_2=0\Rightarrow d_2=0\)； 第一行：\(2\cdot0+0+\lambda_1 - \lambda_2 = 2 \Rightarrow \lambda_1-\lambda_2=2\)； 第二行：\(0+2\cdot0+\lambda_1+0=2 \Rightarrow \lambda_1=2\)，代入得\(\lambda_2=0\)。

  • 所有有效约束乘子：\(\lambda_1=2\ge0,\ \lambda_2=0\ge0\)，满足K-T条件。

因此\(x^3=(0,1)^T\)是最优解，乘子\(\lambda=(2,0,0)^T\)（对应\(c_1,c_2,c_3\)，非有效约束乘子为0）。

最终答案：最优解\(x^=(0,1)^T\)，最优值\(f^=0^2+1^2-2\cdot0-4\cdot1=1-4=-3\)。乘子\(\lambda^*=(2,0,0)^T\)。

题目：设凸二次规划（\(G\)半正定），\(x^\)是K-T点，证明\(x^\)是全局最优解。

证明： 任取可行点\(x\)，记\(D\)为可行域。由于\(x^\)是K-T点，存在乘子\(\lambda_i^(i\in E\cup I)\)满足： \[ \nabla f(x^) = Gx^ + r = -\sum_{i\in E\cup I}\lambda_i^\alpha_i, \tag{1} \] \[ \lambda_i^ \ge 0,\ \forall i\in I, \qquad \lambda_i^(\alpha_i^T x^-b_i)=0,\ \forall i\in I. \tag{2} \] 定义有效不等式指标集\(I(x^)=\{i\in I\mid \alpha_i^T x^=b_i\}\)，则对\(i\in I\setminus I(x^)\)，由(2)得\(\lambda_i^=0\)。于是(1)可写为 \[ \nabla f(x^) = -\sum_{i\in E\cup I(x^)}\lambda_i^*\alpha_i. \tag{3} \]

考虑\(f(x)-f(x^)\)的Taylor展开： \[ f(x)-f(x^) = \nabla f(x^)^T(x-x^) + \frac12 (x-x^)^T G (x-x^). \tag{4} \] 由于\(G\)半正定，第二项\(\ge 0\)。代入(3)： \[ \nabla f(x^)^T(x-x^) = -\sum_{i\in E\cup I(x^)}\lambda_i^\alpha_i^T(x-x^*). \tag{5} \]

对\(i\in E\)，有\(\alpha_i^T x = b_i\)且\(\alpha_i^T x^ = b_i\)，故\(\alpha_i^T(x-x^)=0\)。 对\(i\in I(x^)\)，有\(\alpha_i^T x^ = b_i\)，而由可行域定义\(\alpha_i^T x \le b_i\)，因此\(\alpha_i^T(x-x^) \le 0\)。 结合\(\lambda_i^ \ge 0\)，得 \[ -\lambda_i^\alpha_i^T(x-x^) \ge 0 \quad (\text{因为}-\lambda_i^\cdot(\le 0)\ge 0). \] 于是(5)中每一项均非负，故\(\nabla f(x^)^T(x-x^*) \ge 0\)。

由(4)和半正定性可得 \[ f(x)-f(x^) \ge \nabla f(x^)^T(x-x^) \ge 0, \] 即\(f(x)\ge f(x^)\)对所有可行点\(x\)成立，所以\(x^*\)是全局最优解。

若\(G\)正定，则第二项严格大于0（当\(x\neq x^\)），因此\(x^\)是严格全局最优解。

我问

最优化的问题中有一个一阶必要条件和一个二阶必要条件，他们之间就差了一个海森矩阵半正定的条件，他们之间没什么区别啊，他们分别是用于判断什么的？

你的问题很好，很多初学者都会有类似的疑惑：一阶必要条件（如梯度为零或KKT条件）和二阶必要条件（如海森矩阵在可行方向上半正定）看起来只是差了一个“海森矩阵半正定”，但它们的作用和判断能力是有本质区别的。

简单来说：

  • 一阶必要条件：用来筛选候选点（可能是极小点、极大点或鞍点）。
  • 二阶必要条件：用来排除不可能是局部极小点的候选点（比如排除极大点和某些鞍点），同时为充分条件奠定基础。

下面详细解释。

无约束优化：若 \(x^\) 是局部极小点，则 \(\nabla f(x^) = 0\)。 约束优化（KKT条件）：若 \(x^*\) 是局部极小点且约束规格成立，则存在乘子使得梯度条件成立。

作用：

  • 找出所有驻点（或K-T点）。
  • 但这些点可能是极小点、极大点、鞍点。
  • 无法区分到底属于哪一类。例如 \(f(x)=x^3\) 在 \(x=0\) 处导数为0，但它不是极值点；\(f(x)=-x^2\) 在0处导数为0，却是极大点。

若 \(x^\) 是局部极小点，则除了 \(\nabla f(x^) = 0\) 外，还必须有 **\(\nabla^2 f(x^*)\) 半正定**（即在任意方向 \(d\) 上，\(d^T \nabla^2 f(x^*) d \ge 0\)）。

作用：

  • 如果 \(\nabla^2 f(x^)\) 不是半正定（比如有负特征值），那么 \(x^\) 肯定不是局部极小点（可能是极大点或鞍点）。
  • 因此二阶必要条件可以排除那些一阶条件满足但实际为极大点或鞍点的候选点。

举例：

  • \(f(x)=x^3\)：\(\nabla f(0)=0\)，但 \(\nabla^2 f(0)=0\)（半正定，满足二阶必要条件？实际0是半正定，所以二阶必要条件通过，但0不是极值点。这说明二阶必要条件不够强，仍可能有假阳性。所以通常还需要二阶充分条件：\(\nabla^2 f(x^*)\) 正定才能保证严格局部极小。）
  • \(f(x)=-x^2\)：\(\nabla f(0)=0\)，\(\nabla^2 f(0)=-2\)（负定，不满足半正定）→ 二阶必要条件不成立 → 0不可能是局部极小点（事实是极大点）。
  • \(f(x)=x^4\)：\(\nabla f(0)=0\)，\(\nabla^2 f(0)=0\)（半正定，满足二阶必要条件，实际上0是局部极小点）。所以二阶必要条件是“必须满足”，但不是“充分”。

一阶条件只告诉我们“在该点处函数的一阶变化率为零”，但不知道沿着不同方向函数是上升还是下降。 二阶条件告诉我们曲率信息：如果某个方向上的二阶导数为负，那么沿该方向函数会下降（说明不是极小点）。

所以二者的关系是：

  • 一阶条件：候选点筛选器（宽泛，包括很多假阳性）。
  • 二阶必要条件：进一步筛选掉那些曲率不符合极小要求的候选点（缩小范围）。

对于约束优化，一阶必要条件就是KKT条件。 二阶必要条件：在KKT点处，对于所有可行方向（尤其是约束的切方向），必须有 \(d^T \nabla^2_{xx} L(x^,\lambda^) d \ge 0\)，其中 \(L\) 是拉格朗日函数。对于凸二次规划，因为 \(G\) 半正定，这个条件自动满足，所以一阶条件（KKT）就充要了。但一般非凸问题，二阶必要条件就很重要。

条件形式用途能排除什么？
一阶必要\(\nabla f=0\) 或 KKT找出所有候选点（驻点/K-T点）不能排除极大点、鞍点
二阶必要\(\nabla^2 f\) 半正定（在可行方向）验证候选点是否可能为局部极小排除曲率负定的点（如极大点、某些鞍点）

直观比喻：

  • 一阶条件说“你在平地上”（没有斜坡）。
  • 二阶条件说“你脚下的地面不是向下凹的（即不能有任何方向是下坡）”。

只满足一阶条件的人可能站在山顶、山脚或马鞍上；再加上二阶必要条件，至少能排除站在山顶的情况（如果是严格下坡方向）。

希望这个解释能帮你理清它们的区别。考试中常考：一阶必要条件用于得到K-T点；二阶必要条件用于判断该点是否为局部极小（或用于证明凸性时全局最优）。

我问

在约束规划问题中，如果不满足限制条件的话局部解就不一定是KKT点，请你给我举一个这样的函数的例子

在约束优化中，约束规格（Constraint Qualification，如LICQ） 是保证局部最优解满足KKT条件的核心前提。如果约束规格不成立，局部最优解可能不是KKT点。下面给出一个简单例子。

\[ \min_{x \in \mathbb{R}} f(x) = x \quad \text{s.t.} \quad g(x) = x^2 \le 0. \]

分析：

  • 约束 \(x^2 \le 0\) 等价于 \(x = 0\)（因为平方非负，只能等于0）。
  • 可行域 \(D = \{0\}\)。
  • 点 \(x^* = 0\) 显然是全局最小点（也是局部最小点），目标函数值 \(f(0)=0\)。

约束规格检查：

  • 在 \(x^=0\) 处，有效约束集 \(I(x^)=\{1\}\)（只有 \(g\) 起作用）。
  • 约束梯度 \(\nabla g(x^*) = 2x|_{x=0} = 0\)。
  • 由于有效约束的梯度向量是零向量，不满足LICQ（需要梯度线性无关，但零向量本身线性相关，也无法张成任何空间）。

KKT条件：

对于问题 \(\min f(x)\ \text{s.t.}\ g(x)\le 0\)，KKT条件为：存在 \(\lambda \ge 0\) 使得 \[ \nabla f(x^) + \lambda \nabla g(x^) = 0, \quad \lambda g(x^) = 0. \] 代入 \(x^=0\)：

  • \(\nabla f(0) = 1\)，\(\nabla g(0)=0\)，梯度条件变为 \(1 + \lambda \cdot 0 = 0\)，即 \(1=0\)，不可能。
  • 因此不存在非负乘子 \(\lambda\) 满足KKT条件。

\(x^*=0\) 是局部最优解，但由于约束规格不成立，它不是KKT点。这个例子说明：当约束梯度在最优解处退化（例如为零或线性相关）时，KKT条件可能不成立。在考试或实际应用中，若遇到这类问题，需要先验证约束规格，否则不能直接套用KKT条件。

我问

其实KKT条件也是必要条件是吧

是的，你的理解是正确的。

在约束规格成立的条件下，KKT条件是局部最优解的必要条件。

具体来说：

  • 如果 \(x^*\) 是一个局部最优解，并且在该点处某个约束规格（如 LICQ、MFCQ 等）成立，那么一定存在乘子 \(\lambda_i\) 使得 KKT 条件成立。
  • 所以对于一般（非凸）问题，KKT 是必要条件，但不是充分条件（即 KKT 点可能是局部极小、局部极大或鞍点）。
  • 对于凸优化问题（目标函数凸、约束函数为凸不等式、等式为线性），KKT 条件既是必要条件，也是充分条件——此时任何 KKT 点都是全局最优解。

你之前问的“不满足约束规格”的那个例子，正是因为约束规格不成立，所以局部最优解不满足 KKT 条件——这反过来也印证了：KKT 作为必要条件，其成立是有前提的。

简单总结：

  • 有约束规格 + 局部最优 ⇒ KKT（必要）
  • 凸问题 + KKT ⇒ 全局最优（充分）
  • 非凸问题 + KKT ⇒ 候选点（还需二阶条件判断）
我问

求解二次规划问题的变量消去法是怎么做的，请你给我讲解

变量消去法（也称直接消去法）是求解等式约束二次规划的一种经典方法。其核心思想是：利用等式约束，将部分变量表示为其余变量的线性函数，代入目标函数，从而将原问题转化为一个无约束的二次规划问题，然后通过求导直接得到最优解。下面详细讲解。

一、问题形式

考虑等式约束二次规划：

\[ \begin{aligned} \min_{x\in\mathbb{R}^n} \quad & f(x) = \frac{1}{2}x^T G x + r^T x \\ \text{s.t.} \quad & A x = b \end{aligned} \]

其中 \(A\) 是 \(m \times n\) 矩阵，\(\text{rank}(A)=m < n\)（约束独立且个数少于变量），\(G\) 对称且通常半正定（凸二次规划）。

二、变量消去法的基本步骤

对矩阵 \(A\) 进行列分块，选出 \(m\) 个线性无关的列（即基本列），其余 \(n-m\) 列为自由列。 设 \(A = (A_B \mid A_N)\)，其中 \(A_B\) 是 \(m\times m\) 可逆方阵，\(A_N\) 是 \(m\times (n-m)\) 矩阵。 相应地将变量分为基本变量 \(x_B\in\mathbb{R}^m\) 和自由变量 \(x_N\in\mathbb{R}^{n-m}\)：

\[ x = \begin{pmatrix} x_B \\ x_N \end{pmatrix} \]

同时，目标函数中的矩阵 \(G\) 和向量 \(r\) 也按相同分块：

\[ G = \begin{pmatrix} G_{BB} & G_{BN} \\ G_{NB} & G_{NN} \end{pmatrix}, \quad r = \begin{pmatrix} r_B \\ r_N \end{pmatrix} \]

等式约束 \(A_B x_B + A_N x_N = b\)，因为 \(A_B\) 可逆，可得：

\[ x_B = A_B^{-1} b - A_B^{-1} A_N x_N \]

记 \(P = -A_B^{-1} A_N\)（\(m\times (n-m)\) 矩阵），\(q = A_B^{-1} b\)，则：

\[ x_B = q + P x_N \]

将 \(x_B = q + P x_N\) 代入 \(f(x)\)，经过整理（过程略繁琐，课件第10-11页给出了推导），得到：

\[ \hat{f}(x_N) = \frac{1}{2} x_N^T \hat{G}_N x_N + \hat{r}_N^T x_N + \hat{\delta} \]

其中：

\[ \begin{aligned} \hat{G}_N &= G_{NN} - A_N^T (A_B^{-1})^T G_{BN} - G_{NB} A_B^{-1} A_N + A_N^T (A_B^{-1})^T G_{BB} A_B^{-1} A_N \\ \hat{r}_N &= r_N - A_N^T (A_B^{-1})^T r_B + \big(G_{NB} - A_N^T (A_B^{-1})^T G_{BB}\big) A_B^{-1} b \\ \hat{\delta} &= \frac{1}{2} b^T (A_B^{-1})^T G_{BB} A_B^{-1} b + r_B^T A_B^{-1} b \end{aligned} \]

这些公式看起来很复杂，但在实际手算中，我们通常不直接记忆，而是先写出 \(x_B\) 的表达式，然后代入目标函数并展开合并同类项。

由于 \(G\) 半正定，\(\hat{G}_N\) 也是半正定（可证明）。无约束问题的最优解满足梯度为零：

\[ \nabla \hat{f}(x_N) = \hat{G}_N x_N + \hat{r}_N = 0 \quad \Longrightarrow \quad x_N^* = -\hat{G}_N^{-1} \hat{r}_N \]

（若 \(\hat{G}_N\) 正定，则解唯一；若半正定，需考虑广义逆或添加正则项。）

将 \(x_N^\) 代入 \(x_B = q + P x_N\) 得到 \(x_B^\)，从而得到完整的最优解 \(x^ = \begin{pmatrix} x_B^ \\ x_N^* \end{pmatrix}\)。

乘子 \(\lambda^*\) 可由 KKT 条件中的梯度方程求得：

\[ G x^ + r + A^T \lambda^ = 0 \]

因为 \(A^T = \begin{pmatrix} A_B^T \\ A_N^T \end{pmatrix}\)，所以可以从 \(A_B^T\) 对应的方程解出 \(\lambda^*\)：

\[ \lambda^ = - (A_B^{-1})^T \big( G_{BB} x_B^ + G_{BN} x_N^* + r_B \big) \]

三、一个简单例题（课件第13-14页）

问题：

\[ \begin{aligned} \min \quad & f(x) = x_1^2 + x_2^2 + x_3^2 \\ \text{s.t.} \quad & x_1 + 2x_2 - x_3 = 4 \\ & x_1 - x_2 + x_3 = -2 \end{aligned} \]

解：

  1. 分块：取 \(x_B = (x_1, x_2)^T\)，\(x_N = (x_3)\)。约束矩阵：

\[ A = \begin{pmatrix} 1 & 2 & -1 \\ 1 & -1 & 1 \end{pmatrix}, \quad A_B = \begin{pmatrix} 1 & 2 \\ 1 & -1 \end{pmatrix}, \quad A_N = \begin{pmatrix} -1 \\ 1 \end{pmatrix}, \quad b = \begin{pmatrix} 4 \\ -2 \end{pmatrix} \]

  1. 解出 \(x_B\)：

\[ \begin{cases} x_1 + 2x_2 = 4 + x_3 \\ x_1 - x_2 = -2 - x_3 \end{cases} \] 解得 \(x_1 = -\frac{1}{3}x_3,\; x_2 = 2 + \frac{2}{3}x_3\)。

  1. 代入目标函数：

\[ f = \left(-\frac{1}{3}x_3\right)^2 + \left(2+\frac{2}{3}x_3\right)^2 + x_3^2 = \frac{14}{9}x_3^2 + \frac{8}{3}x_3 + 4 \]

  1. 无约束最小化：

对 \(x_3\) 求导：\(\frac{28}{9}x_3 + \frac{8}{3}=0 \Rightarrow x_3^* = -\frac{6}{7}\)。

  1. 回代：

\(x_1^ = -\frac{1}{3}(-\frac{6}{7}) = \frac{2}{7},\; x_2^ = 2 + \frac{2}{3}(-\frac{6}{7}) = \frac{10}{7}\)。 所以 \(x^* = (\frac{2}{7},\frac{10}{7},-\frac{6}{7})^T\)。

  1. 求乘子（略，见课件第14页）。

四、优缺点

优点：

  • 简单直观，适合手算小规模问题。
  • 将约束问题转化为无约束问题，理论清晰。

缺点：

  • 需要选择 \(A_B\) 可逆，若 \(A_B\) 接近奇异，数值不稳定。
  • 当 \(n\) 很大时，矩阵求逆和乘法计算量大。
  • 对于不等式约束不能直接使用（需结合有效集法）。

五、与其它方法的联系

  • 变量消去法本质上是利用约束消除自由度，与罚函数法或拉格朗日乘子法思路不同。
  • 在数值优化中，更常用的是KKT 系统直接求解法（如上一节的线性方程组法），因为可以避免显式求逆且数值更稳定。

罚函数的乘子法给我讲解一下

下面为你讲解乘子法（Method of Multipliers），也称为增广拉格朗日方法（Augmented Lagrangian Method）。它是罚函数法的改进，解决了经典罚函数法需要罚因子趋于无穷而导致数值病态的问题。

一、从罚函数法说起

考虑等式约束问题：

\[ \min f(x) \quad \text{s.t.} \quad h(x)=0 \]

外点罚函数法定义：

\[ P(x,\rho)=f(x)+\frac{\rho}{2}\|h(x)\|^2, \quad \rho>0 \]

逐步增大 \(\rho \to \infty\)，使 \(h(x)\to 0\)。

缺点：

  • \(\rho\) 很大时，罚项 \(\frac{\rho}{2}\|h\|^2\) 的海森矩阵条件数极差，优化变得病态；
  • 理论上需要 \(\rho\to\infty\) 才能精确满足约束，但实际中无法取无穷。

二、乘子法（增广拉格朗日法）的思想

乘子法在罚项的基础上显式地引入拉格朗日乘子的估计，从而可以用有限的惩罚参数精确满足约束，同时乘子序列收敛到真实乘子。

定义增广拉格朗日函数：

\[ \mathcal{L}_A(x,\lambda,\rho)=f(x)+\lambda^T h(x)+\frac{\rho}{2}\|h(x)\|^2 \]

其中：

  • \(\lambda\) 是乘子向量（大小与 \(h\) 相同）
  • \(\rho>0\) 是惩罚参数（通常取一个固定值，或缓慢增大）

关键观察：如果 \(\lambda\) 恰好等于最优乘子 \(\lambda^\)，那么对任意 \(\rho>0\)，\(\mathcal{L}_A\) 的无约束极小点就是原约束问题的解（因为 \(\nabla_x \mathcal{L}_A = \nabla f + (\lambda^+\rho h)^T \nabla h\)，在最优解处 \(h=0\)，退化为拉格朗日条件）。

三、乘子法的迭代步骤

  1. 初始化：选择 \(\lambda^0\)（例如 0），\(\rho>0\)，设置 \(k=0\)。
  2. 无约束最小化：固定 \(\lambda^k,\rho\)，求解

\[ x^{k} = \arg\min_x \mathcal{L}_A(x,\lambda^k,\rho) \] （可用梯度法、牛顿法等）

  1. 更新乘子：

\[ \lambda^{k+1} = \lambda^k + \rho \, h(x^{k}) \] 这个公式来源于使梯度 \(\nabla_x \mathcal{L}_A\) 中“乘子项”逼近真实乘子。可以证明，如果收敛，\(\lambda^k \to \lambda^*\)。

  1. 检查停止条件：若 \(\|h(x^k)\|\) 和 \(\|\lambda^{k+1}-\lambda^k\|\) 足够小，则停止；否则 \(k=k+1\)，转步骤2。
注：有时会缓慢增大 \(\rho\)（例如 \(\rho \leftarrow 1.5\rho\)），但不必趋向无穷。

四、为什么乘子法更好？

方法罚函数法乘子法
罚参数 \(\rho\)必须 \(\rho\to\infty\)固定或缓慢增长
条件数随 \(\rho\) 增大而变差良好
精确满足约束仅在 \(\rho=\infty\) 时有限 \(\rho\) 下通过乘子更新实现
收敛速度线性，且随 \(\rho\) 增大减慢超线性（近似牛顿）
乘子信息无法得到可得到最优乘子 \(\lambda^*\)

直观解释：罚函数法只靠“大重量”把解拉回可行域，而乘子法用“弹性带”（罚项）加上“拉力”（乘子项）共同作用，使得在有限刚度下就能精确拉回。

五、不等式约束的处理

对于不等式 \(g(x)\le 0\)，可引入松弛变量或将其转换为等式 \( \max(g(x),0)=0 \) 或使用“非负约束的增广拉格朗日”形式。常用广义乘子法：

\[ \mathcal{L}_A(x,\lambda,\rho)=f(x)+\frac{1}{2\rho}\sum_{i}\left[ \max(0, \lambda_i+\rho g_i(x))^2 - \lambda_i^2 \right] \]

或者保持为不等式，用内点形式的乘子法。但核心思想与等式情形相通。

六、一个简单例题（等式约束）

\[ \min f(x)=x_1^2+x_2^2 \quad \text{s.t.} \quad h(x)=x_1+x_2-2=0 \]

解： 取 \(\rho=1\)，\(\lambda^0=0\)。

  • 增广拉格朗日：

\[ \mathcal{L}=x_1^2+x_2^2 + \lambda(x_1+x_2-2) + \frac12 (x_1+x_2-2)^2 \]

  • 最小化：令梯度=0，得

\[ \frac{\partial}{\partial x_1}=2x_1+\lambda+(x_1+x_2-2)=0 \] \[ \frac{\partial}{\partial x_2}=2x_2+\lambda+(x_1+x_2-2)=0 \] 两式相减得 \(x_1=x_2\)，代入约束有 \(2x_1-2=0\Rightarrow x_1=1\)，所以 \(x=(1,1)\)，此即原问题解。此时乘子更新：\(\lambda^1 = \lambda^0 + 1\cdot h(x)=0+1\cdot0=0\)，已收敛。

实际中若 \(\lambda^0\) 不是最优乘子，需要迭代。

七、总结

  • 乘子法 = 拉格朗日函数 + 二次罚项
  • 通过交替无约束最小化和乘子更新，避免了罚因子趋于无穷。
  • 收敛更快、数值更稳定，是现代优化（特别是大规模、分布优化、ADMM）的基础。

有效集法的步骤请你给我讲解一下吧

有效集法（Active Set Method）是求解不等式约束二次规划的一种经典迭代算法。它的核心思想是：猜测在最优解处哪些不等式约束是起作用的（即取等号），然后把这些约束当作等式约束来处理，求解一个等式约束二次规划；再通过检验乘子和可行步长，不断修正有效集，直到满足KKT条件。

下面我分步骤为你讲解，并与课件第16-24页对应。

一、问题形式

考虑凸二次规划（\(G\) 半正定）：

\[ \begin{aligned} \min_{x\in\mathbb{R}^n} \quad & f(x)=\frac12 x^T G x + r^T x \\ \text{s.t.} \quad & \alpha_i^T x = b_i, \quad i\in E \quad (\text{等式约束})\\ & \alpha_i^T x \le b_i, \quad i\in I \quad (\text{不等式约束}) \end{aligned} \]

其中 \(E\) 和 \(I\) 分别表示等式约束和不等式约束的指标集。

二、有效集法的基本思想

  1. 猜测一个有效集 \(W\)（Working Set），它包含：
  • 所有等式约束 \(E\)（永远在有效集中）；
  • 一部分不等式约束 \(I\) 中那些在当前点处取等号的约束。
  1. 将有效集中的约束当作等式处理，忽略其他不等式，求解一个等式约束二次规划，得到搜索方向 \(d\)。
  2. 如果 \(d=0\)，说明当前点是该等式子问题的驻点。此时检查有效约束对应的拉格朗日乘子：
  • 若所有乘子 \(\lambda_i \ge 0\)（对不等式约束），则当前点就是原问题的KKT点（最优解）。
  • 若存在 \(\lambda_q < 0\)，说明该不等式约束实际上不应该被激活，将其从有效集中删除，重新求解子问题。
  1. 如果 \(d\neq 0\)，则沿方向 \(d\) 前进，但需要保证不违反任何不在有效集中的不等式约束。因此要计算最大可行步长 \(\alpha_{\max}\)，取 \(\alpha = \min(1, \alpha_{\max})\)。
  • 若 \(\alpha = 1\)，表示可以走到子问题的最优解，并且该点未触碰新约束，有效集不变。
  • 若 \(\alpha = \alpha_{\max} < 1\)，表示在到达子问题最优解之前会碰到某个新的不等式约束（设为第 \(p\) 个），则停在边界上，并将该约束加入有效集。
  1. 重复以上过程，直到找到满足KKT条件的点。

三、详细步骤（课件第23-24页）

设当前迭代点为 \(x^k\)（可行点），有效集 \(W^k = E \cup I(x^k)\)，其中 \(I(x^k)=\{i\in I \mid \alpha_i^T x^k = b_i\}\)。

考虑变量 \(d = x - x^k\)，将原问题在 \(x^k\) 处近似（其实这里是精确变换，因为二次函数展开后只有常数项变化）：

\[ \min_{d} \quad \frac12 d^T G d + \nabla f(x^k)^T d \] \[ \text{s.t.} \quad \alpha_i^T d = 0, \quad \forall i\in W^k \]

这是一个等式约束二次规划（无常数项）。求解得到最优方向 \(d^k\) 和对应的拉格朗日乘子 \(\lambda_i^k\)（对有效约束）。

  • 若 \(d^k = 0\)：当前点 \(x^k\) 是等式子问题的最优解。此时检查所有 \(i\in W^k \cap I\)（即有效的不等式约束）的乘子：
  • 如果 \(\lambda_i^k \ge 0\) 对所有 \(i\in W^k\cap I\) 成立，则 \(x^k\) 是原问题的KKT点，停止。
  • 否则，找出最小的乘子 \(\lambda_q^k = \min\{\lambda_i^k \mid i\in W^k\cap I\}\)（通常取负得最多的那个），从有效集中删除该约束：\(W^{k+1} = W^k \setminus \{q\}\)，置 \(x^{k+1}=x^k\)，\(k=k+1\)，返回 Step 1。
  • 若 \(d^k \neq 0\)：继续到 Step 3。

为避免违反不在有效集中的不等式约束，需计算最大可行步长 \(\alpha_{\max}\)：

\[ \alpha_{\max} = \min_{i\notin W^k,\; \alpha_i^T d^k > 0} \frac{b_i - \alpha_i^T x^k}{\alpha_i^T d^k} \]

若没有这样的 \(i\)，则 \(\alpha_{\max} = +\infty\)。令

\[ \alpha_k = \min(1, \alpha_{\max}) \]

\[ x^{k+1} = x^k + \alpha_k d^k \]

  • 如果 \(\alpha_k = \alpha_{\max} < 1\)，说明在到达子问题最优解之前碰到了某个新约束（比如第 \(p\) 个），那么将该约束加入有效集：\(W^{k+1} = W^k \cup \{p\}\)。
  • 如果 \(\alpha_k = 1\)，说明走到了子问题的最优解，并且没有碰到任何新约束，有效集保持不变：\(W^{k+1} = W^k\)。

然后 \(k=k+1\)，返回 Step 1。

五、例题（课件第25-27页）

题目（简化）：

\[ \min f=x_1^2+x_2^2-2x_1-4x_2,\quad \begin{cases} x_1+x_2\le 1,\\ -x_1\le 0,\\ -x_2\le 0 \end{cases},\quad x^0=(0,0) \]

初始点：\(x^0=(0,0)\)，有效集 \(W^0=\{2,3\}\)（因为 \(-x_1=0\) 和 \(-x_2=0\) 取等）。

第一轮：求解子问题 \(\min d_1^2+d_2^2-2d_1-4d_2\)，约束 \(d_1=0,d_2=0\) → 得 \(d=0\)。检查乘子：由KKT求得 \(\lambda_2=-2,\lambda_3=-4\)，负值，删除 \(\lambda_3\)（最负），新有效集 \(W^1=\{2\}\)，点仍为 \((0,0)\)。

第二轮：子问题 \(\min d_1^2+d_2^2-2d_1-4d_2\)，约束 \(d_1=0\) → 得 \(d=(0,2)\)。计算步长：检查非有效约束 \(i=1\) 和 \(i=3\)。对 \(i=1\)：\(\alpha_1^T d = (1,1)^T(0,2)=2>0\)， \(\frac{1-0}{2}=0.5\)；对 \(i=3\)：\(\alpha_3^T d = (0,-1)^T(0,2)=-2\le0\)，忽略。故 \(\alpha_{\max}=0.5\)，取 \(\alpha=0.5\)。新点 \(x=(0,0)+0.5(0,2)=(0,1)\)。因为 \(\alpha<1\)，将约束 \(i=1\) 加入有效集，\(W^2=\{2,1\}\)。

第三轮：子问题约束 \(d_1=0\) 和 \(d_1+d_2=0\) → 得 \(d=0\)。计算乘子：由KKT得 \(\lambda_1=2,\lambda_2=0\)（对应约束1和2），均非负 → 停止。最优解 \(x^*=(0,1)\)，乘子 \((2,0,0)\)。

  • 收敛性：在凸二次规划中，有效集法在有限步内收敛到最优解，因为有效集组合有限。
  • 实际应用中，有效集法是求解中小规模凸二次规划的常用方法（如 MATLAB 的 quadprog 中可选算法之一）。

一阶方向导数的几何意义是什么啊a

一阶方向导数的几何意义非常直观：它描述了多元函数在某一点处，沿着给定方向的变化率（即“斜率”）。

具体来说：

  • 设函数 \(f(x)\) 在点 \(x_0\) 处可微，\(d\) 是一个单位方向向量。则方向导数

\[ \frac{\partial f}{\partial d}(x_0) = \lim_{t\to 0^+} \frac{f(x_0+td)-f(x_0)}{t} \] 表示从 \(x_0\) 出发沿方向 \(d\) 移动时，函数值变化的瞬时速率。

  • 几何图像：过点 \(x_0\) 作平行于 \(d\) 的垂面，该面与函数曲面 \(z=f(x)\) 相交得到一条曲线。方向导数就是这条曲线在点 \(x_0\) 处的切线斜率（类似一元函数的导数）。
  • 与梯度的关系：方向导数等于梯度在该方向上的投影，即

\[ \frac{\partial f}{\partial d}(x_0) = \nabla f(x_0)^T d \] 因此，沿梯度方向方向导数最大（函数上升最快），沿负梯度方向最小（下降最快），沿与梯度垂直的方向方向导数为零（等值面的切线方向）。

总结：一阶方向导数 = 函数沿特定方向的瞬时变化率，其符号决定上升或下降，大小决定变化快慢。

记不住乘子罚函数的公式很正常，因为它看起来比纯罚函数多了一项。我帮你从逻辑推导的角度理解，这样就不需要死记硬背了。

一、我们想要什么？

对于等式约束问题 \[ \min f(x),\quad \text{s.t. } h(x)=0 \] 我们希望用一个无约束函数 \( \Phi(x) \) 来近似，并且希望：

  • 当参数固定时，\(\Phi(x)\) 的极小点接近原问题的解；
  • 不需要把罚因子 \(\rho\) 取到无穷大也能精确满足约束。

二、从拉格朗日函数出发

拉格朗日函数是 \[ L(x,\lambda) = f(x) + \lambda^T h(x) \] 它的鞍点（对 \(x\) 极小、对 \(\lambda\) 极大）对应原问题的解。 但直接对 \(x\) 无约束极小化 \(L(x,\lambda)\) 通常不行，因为 \(L\) 在 \(x\) 方向上可能无下界（比如线性约束时）。

三、加上二次罚项来稳定

为了把 \(L\) 变成在 \(x\) 方向上有下界的函数，我们在后面加一个二次惩罚项 \(\frac{\rho}{2}\|h(x)\|^2\)，得到 \[ \mathcal{L}_A(x,\lambda,\rho) = f(x) + \lambda^T h(x) + \frac{\rho}{2}\|h(x)\|^2 \] 这就是增广拉格朗日函数。注意：

  • 当 \(\rho=0\) 时，它就是普通拉格朗日函数。
  • 当 \(\rho>0\) 时，它强制 \(h(x)\) 不能太大，否则二次项会急剧增加。

四、为什么这个形式“自然”？

把二次项配成平方形式： \[ \lambda^T h + \frac{\rho}{2} h^2 = \frac{\rho}{2} \left( h + \frac{\lambda}{\rho} \right)^2 - \frac{\lambda^2}{2\rho} \] （这里 \(h\) 是标量，向量情形类似，需要点乘） 所以 \[ \mathcal{L}_A = f(x) + \frac{\rho}{2}\left\| h(x) + \frac{\lambda}{\rho} \right\|^2 - \frac{\|\lambda\|^2}{2\rho} \] 最后一项常数不影响对 \(x\) 的极小化。 这个形式很清楚：它等价于在原目标后加上一个偏移了的二次罚函数，偏移量正好是 \(\lambda/\rho\)。 也就是说，乘子法相当于在罚函数中“移动目标”而不是让罚因子趋于无穷。

五、乘子更新公式的由来

假设我们固定 \(\lambda^k, \rho\)，极小化 \(\mathcal{L}_A\) 得到 \(x^k\)。 KKT 条件对于原问题是 \( \nabla f + \nabla h^T \lambda^* = 0,\ h=0 \)。 而我们极小化 \(\mathcal{L}_A\) 的一阶条件是： \[ \nabla f(x^k) + \nabla h(x^k)^T (\lambda^k + \rho h(x^k)) = 0 \] 对比发现，括号里的 \(\lambda^k + \rho h(x^k)\) 起到了 **\(\lambda^*\)** 的作用。 因此自然的乘子更新是： \[ \lambda^{k+1} = \lambda^k + \rho h(x^k) \] 这样，即使 \(\rho\) 固定，乘子迭代也会收敛到真实乘子。

六、记忆技巧（口诀）

“拉格朗日加平方半，乘子更新加罚残。”

  • 拉格朗日函数：\(f + \lambda^T h\)
  • 加上 \(\frac{\rho}{2}\|h\|^2\)（平方半）
  • 乘子更新：\(\lambda_{\text{new}} = \lambda_{\text{old}} + \rho \cdot h\)（加罚残差 \(h\)）

对于不等式 \(g(x)\le 0\)，有两种常见写法：

  1. 转化为等式：引入松弛变量 \(s\ge0\)，令 \(g(x)+s=0\)，然后对 \(s\) 有非负约束 —— 这会导致增广拉格朗日函数中包含对 \(s\) 的极小化，可以显式求出 \(s^* = \max(0, -\lambda/\rho - g)\)，最后整理成：

  1. 另一种简单记忆：直接使用等式形式的增广拉格朗日，但把 \(h(x)\) 换成 \(\max(g(x),0)\)（即违反度），不过这样不可微。实际常用第一种。

七、一个具体例子帮你固定记忆

问题：\(\min x^2\)，约束 \(x-1=0\)（最优解 \(x=1\)）。 增广拉格朗日： \[ \mathcal{L}_A = x^2 + \lambda (x-1) + \frac{\rho}{2}(x-1)^2 \] 对 \(x\) 求导：\(2x + \lambda + \rho(x-1)=0\) 得 \(x = \frac{\rho - \lambda}{2+\rho}\)。 乘子更新：\(\lambda_{k+1} = \lambda_k + \rho(x_k-1)\)。 取 \(\lambda_0=0,\rho=1\)，第一轮 \(x_0 = (1-0)/(2+1)=1/3\)，更新 \(\lambda_1 = 0+1(1/3-1)=-2/3\)；第二轮 \(x_1 = (1-(-2/3))/(3)= (1+2/3)/3 = (5/3)/3=5/9\)，\(\lambda_2 = -2/3+1(5/9-1)= -2/3-4/9=-10/9\)… 收敛到 \(x=1\)，\(\lambda=-2\)（真实乘子）。

\[ \frac{\partial f}{\partial d}(x_0) = \lim_{t \to 0^+} \frac{f(x_0 + t d) - f(x_0)}{t} \]

其几何意义：从 \(x_0\) 出发沿 \(d\) 方向移动时，函数值的瞬时变化率。

常用写法（可微时）： \[ \frac{\partial f}{\partial d}(x_0) = \nabla f(x_0)^\top d \] 即梯度与方向向量的点积。

如果 \(d\) 不是单位向量，方向导数通常定义为 \(\nabla f(x_0)^\top \frac{d}{\|d\|}\)，即只考虑方向，与长度无关。

特例：

  • 沿坐标轴方向 \(e_i\)，方向导数就是偏导数 \(\frac{\partial f}{\partial x_i}(x_0)\)。
  • 沿梯度方向，方向导数最大，等于 \(\|\nabla f(x_0)\|\)。
  • 沿负梯度方向，方向导数最小，等于 \(-\|\nabla f(x_0)\|\)。
  • 沿与梯度垂直的方向，方向导数为 0。

所以你只要记住：方向导数 = 梯度点乘单位方向向量。

你的理解基本正确，但要完整判断一个点是否为 KT点（Kuhn-Tucker 点），需要同时满足以下四个条件（以标准形式 \(\min f(x),\; s.t.\; c_i(x)=0 (i\in E),\; c_i(x)\le 0 (i\in I)\) 为例）：

点 \(x^\) 必须满足所有约束： \[ c_i(x^) = 0 \ (i\in E), \quad c_i(x^*) \le 0 \ (i\in I) \]

存在乘子 \(\lambda_i\ (i\in E\cup I)\)，使得： \[ \nabla f(x^) + \sum_{i\in E\cup I} \lambda_i \nabla c_i(x^) = 0 \]

\[ \lambda_i \ge 0,\quad \forall i\in I \] （等式约束的乘子 \(\lambda_i\) 无符号限制）

\[ \lambda_i \, c_i(x^) = 0,\quad \forall i\in I \] 即：若约束不起作用（\(c_i(x^)<0\)），则乘子必须为 0；若乘子 > 0，则约束必须起作用（\(c_i(x^*)=0\)）。

  1. 检查可行性：代入约束看是否成立。
  2. 假设起作用的不等式约束：一般先假设哪些不等式是紧的（\(c_i(x^)=0\)），哪些是松的（\(c_i(x^)<0\)）。对于松的约束，直接令乘子为 0。
  3. 建立梯度方程：将未知乘子（等式约束 + 起作用的不等式约束）代入梯度方程，求解乘子。
  4. 检验：
  • 所有求出的不等式乘子 ≥ 0；
  • 互补松弛自动满足（因为松的乘子已设为 0，紧的约束 \(c_i=0\) 乘积为 0）。

若所有条件满足，则 \(x^*\) 是 KT点；否则不是。

注意：KT 点不一定是局部最优解（非凸问题中可能是鞍点或极大点），但凸问题中 KT 点就是全局最优解。另外，约束规格（如 LICQ）是局部最优解 ⇒ KT 点的前提，但判断 KT 点本身不需要约束规格。

\[ \beta_k^{\text{FR}} = \frac{g_k^\top g_k}{g_{k-1}^\top g_{k-1}} \]

  • 只依赖于当前梯度和上一步梯度的模长。
  • 理论性质好，常用于线性共轭梯度法（求解 \(Ax=b\) 时与 PRP 等价）。
  • 对非线性优化，收敛性较好，但可能因函数非二次而出现“jamming”。

\[ \beta_k^{\text{PRP}} = \frac{g_k^\top (g_k - g_{k-1})}{g_{k-1}^\top g_{k-1}} \]

  • 显式利用了梯度的变化量，对非二次函数的适应性更强。
  • 在接近最优点时，若梯度变化小，βₖ 自然变小，有助于自动重置方向，避免“锯齿现象”。
  • 计算量略大于 FR（多一个向量内积）。
  • 当目标函数为严格凸二次函数（即 \(f(x)=\frac12 x^\top A x - b^\top x\)）时，FR 与 PRP 公式等价，因为 \(g_k^\top (g_k - g_{k-1}) = g_k^\top g_k\)（由 A-共轭性可证）。

  • FR：当前梯度模长平方 / 上一梯度模长平方
  • PRP：当前梯度点乘（当前减上一梯度） / 上一梯度模长平方

FR的算法流程给我描述一下

FR（Fletcher–Reeves）共轭梯度法主要用于求解无约束优化问题，特别是当目标函数是正定二次函数时，它能在 n 步内收敛；也可推广到一般非线性函数（配合线搜索）。以下是 FR 方法的完整算法流程（针对一般非线性优化）：

  • 目标函数 \(f(x)\)，梯度 \(g(x)=\nabla f(x)\)
  • 初始点 \(x_0\)
  • 停止条件（如梯度模长阈值 \(\varepsilon\)）
  • 计算 \(g_0 = g(x_0)\)
  • 若 \(\|g_0\| < \varepsilon\)，停止，输出 \(x_0\)
  • 设置初始搜索方向 \(d_0 = -g_0\)
  • 置迭代计数 \(k = 0\)
  1. 线搜索：求步长 \(\alpha_k > 0\)，使得

\[ f(x_k + \alpha_k d_k) = \min_{\alpha>0} f(x_k + \alpha d_k) \] 对于二次函数，\(\alpha_k = \frac{g_k^\top d_k}{d_k^\top A d_k}\)（精确线搜索）；对于非二次函数，需使用 Wolfe 条件或精确一维搜索（如黄金分割、多项式插值）。

  1. 更新点：

\[ x_{k+1} = x_k + \alpha_k d_k \]

  1. 计算新梯度：

\[ g_{k+1} = \nabla f(x_{k+1}) \]

  1. 收敛性检查：若 \(\|g_{k+1}\| < \varepsilon\)，停止，输出 \(x_{k+1}\)。
  1. 计算 FR 参数 \(\beta_{k+1}\)：

\[ \beta_{k+1}^{\text{FR}} = \frac{g_{k+1}^\top g_{k+1}}{g_k^\top g_k} \]

  1. 更新搜索方向：

\[ d_{k+1} = -g_{k+1} + \beta_{k+1}^{\text{FR}} \, d_k \]

  1. 重置策略（可选）：若 \(k+1\) 达到 \(n\)（变量维度）或方向丧失共轭性（例如 \(\|g_{k+1}^\top g_k\|\) 很大时），可重置 \(d_{k+1} = -g_{k+1}\)（相当于重新开始）。
  1. 令 \(k = k+1\)，转步骤 1。
  • 对于严格凸二次函数，精确线搜索下 FR 方法保证至多 \(n\) 步收敛到精确解。
  • 对于非二次函数，需要配合非精确线搜索（如 Wolfe 条件）以保证全局收敛性。
  • FR 公式的优点是 \(\beta_k \ge 0\)，且理论收敛性较强；缺点是可能产生“jamming”（方向停滞），通常结合重置策略使用。
  • 在步骤 5 中，PRP 使用 \(\beta_{k+1}^{\text{PRP}} = \frac{g_{k+1}^\top (g_{k+1}-g_k)}{g_k^\top g_k}\)。
  • FR 的 \(\beta\) 始终非负；PRP 的 \(\beta\) 在非凸问题中可能为负，需取 \(\max(\beta,0)\) 来保证下降性。

希望这个流程描述能帮助你掌握 FR 算法。如需更具体的线搜索实现细节，也可以继续问我。

互信息（Mutual Information） 衡量两个随机变量 \(X\) 和 \(Y\) 之间的相互依赖程度。其定义为：

\[ I(X;Y) = \sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x,y) \log \frac{p(x,y)}{p(x)p(y)} \]

对于连续变量，求和变为积分，概率密度函数 \(p(x,y)\)、\(p(x)\)、\(p(y)\) 代替。

\[ I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y) \] 其中：

  • \(H(X)\)、\(H(Y)\) 为边缘熵，
  • \(H(X|Y)\)、\(H(Y|X)\) 为条件熵，
  • \(H(X,Y)\) 为联合熵。

互信息表示知道 \(Y\) 后，\(X\) 的不确定性减少的量（或反过来）。当 \(X\) 和 \(Y\) 独立时，\(I(X;Y)=0\)；当存在函数关系时，互信息最大（受限于各自的熵）。

这是信息论中最核心的概念之一。

\[ I(X;Y) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X) = H(X)+H(Y)-H(X,Y) \]

所以互信息本质上就是 “熵的减少量”：知道 \(Y\) 后，\(X\) 的不确定性（熵）减少了多少。这个关系非常常用，也是理解互信息最直观的方式。

我要的是互信息的定义式

明白了，您需要的是互信息的原始定义式（不借助熵，直接用概率分布表示）：

对于离散随机变量 \(X\) 和 \(Y\)（取值于 \(\mathcal{X}, \mathcal{Y}\)），互信息的定义为：

\[ I(X;Y) = \sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} p(x,y) \log \frac{p(x,y)}{p(x)\,p(y)} \]

其中：

  • \(p(x,y)\) 是联合概率质量函数；
  • \(p(x)\)、\(p(y)\) 分别是边缘概率质量函数；
  • 对数通常取底 2（单位比特）或自然对数（单位奈特）。

对于连续随机变量，将求和换为积分，概率质量函数换为概率密度函数：

\[ I(X;Y) = \int_{\mathcal{X}} \int_{\mathcal{Y}} p(x,y) \log \frac{p(x,y)}{p(x)\,p(y)} \, dy \, dx \]

这就是互信息的标准定义。

我问

那平均互信息是什么啊、

在信息论中，“平均互信息”通常就是互信息（Mutual Information） 的另一个称呼，因为互信息的定义本身就是对联合分布求期望（平均）的结果。

具体来说：

对于两个具体取值 \(x\) 和 \(y\)，其点态互信息定义为： \[ \text{PMI}(x;y) = \log \frac{p(x,y)}{p(x)p(y)} \] 它表示单个事件对之间的互信息。

对所有可能的 \((x,y)\) 按联合概率 \(p(x,y)\) 取平均，就得到平均互信息： \[ I(X;Y) = \sum_{x,y} p(x,y) \cdot \text{PMI}(x;y) = \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)} \] 这正是互信息的定义。所以平均互信息 = 互信息，不加“平均”二字也是指这个期望值。

为了与“点态互信息”区分，强调它是全局的平均量。在多数教材和论文中，直接说“互信息”就是指平均互信息。

总结：平均互信息就是互信息的标准定义，即联合分布与边缘分布乘积之间的 KL 散度： \[ I(X;Y) = D_{\text{KL}}(p(x,y) \parallel p(x)p(y)) \]

这个步长公式确实容易记混，但理解其几何意义后就好记了。

核心目的

当我们从当前可行点 \(x^k\) 沿方向 \(d^k\) 移动时，要保证所有不在当前有效集中的不等式约束 \(a_i^T x \le b_i\) 不被违反。即对每个 \(i \notin I(x^k)\)，要求： \[ a_i^T (x^k + \alpha d^k) \le b_i \quad \Rightarrow \quad \alpha \le \frac{b_i - a_i^T x^k}{a_i^T d^k} \quad (\text{当 } a_i^T d^k > 0) \] 若 \(a_i^T d^k \le 0\)，则移动不会违反该约束，无需限制。

公式记忆口诀

“正方向上看比值，取最小非负限；再与1比取小值。”

  1. 只看正方向：只考虑那些与方向 \(d^k\) 夹角小于 90° 的约束（\(a_i^T d^k > 0\)），因为只有这些约束会随着 \(\alpha\) 增加而变紧。
  2. 计算每个约束允许的最大步长：\(\frac{b_i - a_i^T x^k}{a_i^T d^k}\)，分子是当前“剩余容量”（约束值离上限的距离），分母是方向上的变化率。
  3. 取所有正方向约束的最小值：\(\hat{\alpha}_k = \min_{i: a_i^T d^k>0} \frac{b_i - a_i^T x^k}{a_i^T d^k}\)。这就是走多远会碰到第一个新约束。
  4. 与1比较：因为我们希望走到子问题的最优解（步长为1时恰好到达子问题无约束最优点），所以实际步长取 \(\alpha_k = \min\{1, \hat{\alpha}_k\}\)。

形象化记忆

  • 想象你开车从 \(x^k\) 沿 \(d^k\) 前进，路边有“墙”（约束边界）。每个墙有个距离 \(\frac{\text{剩余距离}}{\text{接近速度}}\)，取最近的墙的距离作为 \(\hat{\alpha}_k\)。但你不能超过目的地（步长1），所以最终步长就是 \(\min(\text{到墙的距离}, 1)\)。

这样理解后，公式就不用死记了。
