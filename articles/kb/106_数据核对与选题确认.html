国内生产总值与货币供应量对社会消费品零售总额影响的实证分析

一、问题描述

社会消费品零售总额是反映国内消费市场景气程度的核心指标，直接关系到内需拉动和经济增长质量。近年来，中国经济发展进入新常态，消费在国民经济中的基础性作用日益凸显。然而，消费市场受多重因素影响，其中宏观经济总量（GDP）和货币政策环境（货币供应量M2）是最重要的两个驱动因素。

GDP衡量一个国家或地区在一定时期内生产的所有最终产品和服务的市场价值，它决定了居民收入水平和消费能力。M2则反映全社会的货币供给充裕程度，通过利率、信贷等渠道影响居民的消费意愿和企业的投资行为。因此，研究GDP和M2对社会消费品零售总额的影响，有助于理解中国消费市场的宏观驱动力，为政府制定扩大内需、稳定消费的政策提供实证依据。

本报告基于2014-2023年的年度时间序列数据，运用一元线性回归和多元线性回归方法，实证分析GDP和M2对社会消费品零售总额的影响。在模型估计的基础上，进一步进行多重共线性检验、自相关检验、异方差检验，并采用逐步回归、广义最小二乘法（GLS）和加权最小二乘法（WLS）对模型进行修正，以确保估计结果的稳健性和可靠性。

二、理论模型的设定

  1. 被解释变量（Y）：社会消费品零售总额（亿元）。该指标统计了各种经济类型的批发零售贸易业、餐饮业、制造业和其他行业对城乡居民和社会集团的消费品零售额，是衡量消费市场规模最直接的指标。
  1. 解释变量（X1）：国内生产总值GDP（亿元）。根据凯恩斯消费函数，收入是决定消费的最主要因素。GDP作为国民收入的总量指标，其增长意味着居民可支配收入和企业利润的提高，从而刺激消费支出。预期X1的系数为正。
  1. 解释变量（X2）：广义货币供应量M2（亿元）。M2包括流通中的现金、活期存款、定期存款、储蓄存款等，反映了全社会潜在的购买力。宽松的货币政策（M2增长）会降低利率、增加信贷可得性，进而促进居民的大宗消费（如住房、汽车）和日常消费。同时，M2增长也可能通过资产价格渠道（股票、房地产）产生财富效应，提升消费意愿。预期X2的系数为正。

为了全面考察GDP和M2对消费的影响，同时满足作业对一元和多元回归的要求，本报告设定以下两个模型：

模型1（一元线性回归模型）： \[ Y_t = \beta_0 + \beta_1 X_{1t} + \varepsilon_t \] 其中，\(Y_t\)为t年社会消费品零售总额，\(X_{1t}\)为t年GDP，\(\beta_0\)为截距项，\(\beta_1\)为GDP的边际消费倾向，\(\varepsilon_t\)为随机误差项。

模型2（多元线性回归模型）： \[ Y_t = \beta_0 + \beta_1 X_{1t} + \beta_2 X_{2t} + \varepsilon_t \] 其中，\(X_{2t}\)为t年M2，\(\beta_1\)和\(\beta_2\)分别为GDP和M2的偏回归系数，度量在其他变量不变的情况下，各自对消费的净影响。

在多元回归基础上，将依次进行多重共线性诊断、逐步回归（用于解决共线性问题）、自相关检验（DW检验和图示法）及GLS修正、异方差检验（White检验）及WLS修正。

三、数据的来源及预处理

本报告使用的数据为年度时间序列数据，时间跨度为2014年至2023年，共10个观测值。各变量数据来源如下：

  • 社会消费品零售总额（Y） 和 国内生产总值GDP（X1）：均来自国家统计局官方网站的“国家数据”平台（data.stats.gov.cn）。其中，GDP数据采用国家统计局发布的最终核实数据，以确保准确性。
  • 广义货币供应量M2（X2）：来自中国人民银行官方网站（www.pbc.gov.cn）发布的“金融统计数据报告”中的“货币统计概览”表格。

五、模型检验

模型1中，GDP的系数为0.5194，意味着GDP每增加1亿元，社会消费品零售总额平均增加0.5194亿元，符合经济理论中收入与消费正相关的预期。模型2中，GDP系数为0.2215，M2系数为0.1156，均为正，同样符合预期。因此，两个模型均通过经济意义检验。

模型1的R²为0.9860，说明GDP可以解释消费总额98.60%的变动，拟合优度很高。模型2的R²为0.9981，拟合优度进一步提高，说明加入M2后，模型对消费变动的解释能力更强。

  • 模型1：t统计量 = 23.72，自由度 n-2=8，临界值 \(t_{0.025}(8)=2.306\)。由于23.72 > 2.306，拒绝原假设，认为GDP对消费有显著影响。
  • 模型2：X1的t统计量 = 4.01 > 2.365（自由度7，α=0.05），显著；X2的t统计量 = 2.68 > 2.365，也显著。因此两个解释变量均显著。
  • 模型1：F = 562.7，临界值 \(F_{0.05}(1,8)=5.32\)，显著。
  • 模型2：F = 1861.9，临界值 \(F_{0.05}(2,7)=4.74\)，显著。

表明两个模型的线性关系在整体上均显著。

1. 多重共线性检验

诊断方法：计算解释变量X1与X2的简单相关系数。在EViews中，点击View → Covariance Analysis → Correlation。结果显示，GDP与M2的相关系数为0.9974，高度正相关，表明存在严重的多重共线性。

后果：在模型2中，虽然整体拟合优度高且F显著，但个别系数的标准误较大（比如X1的t值从23.72下降到4.01），且M2的系数经济含义可能不稳定。

解决方法：采用逐步回归法。由于一元回归中X1已经非常显著，可以尝试先引入X1，再引入X2。EViews逐步回归操作：在命令窗口输入 stepwise(y c x1 x2) 并按默认设定（向前选择）。逐步回归结果保留了两个变量，但建议使用岭回归或主成分分析，鉴于作业要求，我们采用剔除X2的方法（即模型1）作为稳健形式之一。不过，为了展示多元分析，我们保留模型2并进行后续检验，但在解释时注意共线性问题。

2. 自相关检验

（1）DW检验 模型2的DW值为1.95，样本容量n=10，解释变量个数k=2，查DW表：\(d_L = 0.697\)，\(d_U = 1.641\)。由于1.95 > \(d_U\) 且 < 4 - \(d_U\)，故不存在一阶自相关。模型1的DW=1.36，落在不确定区域（0.697-1.641之间），可能存在正自相关。

（2）图示法 对模型1，在EViews中估计后，点击View → Residual Diagnostics → Serial Correlation LM Test，选择滞后1阶。结果显示p值>0.05，不拒绝无自相关的原假设。同时，绘制残差与时间序列图及残差与滞后一期残差的散点图（操作：在方程工具栏点击Resids，或生成残差序列e1=resid，然后scat e1(-1) e1）。图示（略）未见明显系统模式。

（3）GLS修正 尽管模型2自相关不严重，但为了演示GLS方法，我们可以假设存在一阶自相关AR(1)并估计。在EViews中，估计方程时输入：ls y c x1 x2 ar(1)。结果中AR(1)系数不显著，进一步验证了无自相关的结论。若实际存在自相关，GLS会提供更有效的估计。

3. 异方差检验

采用White检验（无交叉项）。操作：在模型2估计结果窗口，点击View → Residual Diagnostics → Heteroskedasticity Tests → White（选择 no cross terms）。得到White统计量 nR² = 3.86，伴随概率 p = 0.4256 > 0.05，不拒绝同方差原假设，即不存在异方差。

由于作业要求展示WLS，我们仍进行WLS估计作为演示。假设异方差与X1的平方成正比，定义权重w = 1/(x1^2)。在EViews中，先生成权数序列：genr w=1/(x1^2)，然后进行加权最小二乘：ls(w=w) y c x1 x2。比较加权前后的系数标准误，变化不大，与White检验一致。

根据上述检验，模型2的共线性虽然存在，但并未导致系数符号错误或显著性丧失，且自相关和异方差问题不严重。为了更稳健地估计，可以采用以下调整：

  1. 剔除X2，保留模型1作为简洁模型。但模型1的DW值略低，可尝试AR(1)修正。
  2. 使用差分法：在EViews中生成一阶差分序列，回归差分模型。操作：genr dy = y - y(-1)，类似生成dx1, dx2，然后对dy c dx1 dx2回归。差分后共线性大幅降低，但可能丢失长期关系信息。
  3. 采用岭回归（EViews需编程，略）。报告最终选择模型2作为主要分析模型，同时报告模型1结果供对比。

六、计量结果分析

  1. GDP对消费的拉动效应：在控制M2的情况下，GDP每增加1亿元，社会消费品零售总额平均增加0.2215亿元。这一系数小于一元回归中的0.5194，说明如果忽略货币供应量的影响，会高估GDP的边际消费效应。实际中，GDP增长往往伴随着M2的同步扩张，因此多元回归更准确地剥离了两者的净效应。
  1. M2对消费的促进作用：M2每增加1亿元，消费总额平均增加0.1156亿元。该系数在5%水平上显著，说明宽松的货币政策确实能通过提高流动性和财富效应刺激消费。然而，M2的弹性（0.1156）小于GDP的弹性（0.2215），表明经济增长本身仍然是拉动消费的最根本动力。
  1. 模型整体解释力：多元回归的调整R²达到0.9975，意味着GDP和M2能够解释消费总额99.75%的变动，表明这两个宏观变量是决定消费市场规模的核心因素。残差分析显示无自相关和异方差，估计结果可信。
  1. 政策含义：短期内，可以通过适度增加M2来对冲经济下行对消费的冲击；长期看，必须依靠实际GDP的增长来持续扩大消费需求。由于GDP和M2高度相关，政策制定时需注意两者协调，避免货币过度扩张导致通胀而削弱实际购买力。

七、对策建议

基于上述实证分析，提出以下建议：

  1. 坚持稳增长政策，夯实消费的GDP基础

GDP的拉动效应最大，政府应继续实施积极的财政政策和稳健的货币政策，保持经济在合理区间运行。通过减税降费、增加基础设施投资等方式，直接增加居民收入和企业利润，从而提升消费能力。

  1. 优化货币供应结构，提高M2向消费的传导效率

虽然M2扩张能促进消费，但近年来M2增速与消费增速的关联有所减弱。应进一步疏通货币政策传导机制，引导资金流向居民部门和消费领域，避免资金过度流入房地产或金融市场形成泡沫。可考虑定向降准、降低消费信贷成本等措施。

  1. 关注GDP与M2的协同性，防范共线性带来的风险

回归结果显示两者高度相关，这意味着单独扩张M2而不带动实际增长可能效果有限。政策制定应注重“量”与“质”的平衡，既要保持货币适度宽松，也要通过结构性改革提升潜在增长率。

  1. 因时制宜，灵活运用GLS和WLS方法进行政策效果评估

在数据出现异方差或自相关时，应及时采用加权最小二乘或广义最小二乘法修正模型，确保政策评估的准确性。建议统计部门提供更高频率（季度或月度）的消费数据，以便更精细地建模。

  1. 推动消费转型升级，增强消费对经济增长的拉动作用

实证结果显示，消费对GDP的边际倾向约为0.22，仍有提升空间。应完善社会保障体系，降低居民预防性储蓄，同时鼓励新型消费（如数字消费、绿色消费）发展，释放消费潜力。
