现有如下函数

int fun(SqString s, SqString t) {
    int i=0, j=0, count=0;
    int next[MaxSize];
    GetNext(t,next);
    while (i<s.length && j<t.length) {
        if (j==-1 || s.data[i]==t.data[j]) {
            i++;
            j++;
        }
        else
            j=next[j];
        if (j>=t.length) {
            count++;
            j=0;
        }
    }
    return count;
}

设有两个顺序存储的字符串S和T，S的串值为"abaabaabcaabaabc"，T的串值为"abaabc"，则函数调用fun(S,T)的返回值为 _______（输入答案）。

把这个题目做一下，确保你是真正的了解了题目的内涵

根据给定的函数代码和字符串S="abaabaabcaabaabc"、T="abaabc"，模拟KMP匹配过程后，函数返回T在S中出现的次数为2。

匹配过程简要说明：

  • 第一次匹配发生在S的索引3至8（子串"abaabc"）。
  • 第二次匹配发生在S的索引10至15（子串"abaabc"）。

因此，返回值为2。

答案：2
