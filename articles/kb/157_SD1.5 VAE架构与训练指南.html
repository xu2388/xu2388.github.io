SD1.5 VAE架构与训练指南

2026-05-22 · 主题：科研-深度学习/模型、课程-编程/计算机 · 24 条消息 · 对话编号 157
我问

请你给我一些SDv1.5的官方的代码行吗，我要训练一个VAE，但是我不知道VAE的架构是什么啊

训练一个SD1.5的VAE是一项非常有挑战性的工作，我来帮你梳理一下。需要先说明的是，目前在公开的官方渠道，并没有一个开箱即用的脚本来单独训练一个全新的SD1.5 VAE。

我的回答会从两个部分来帮你理解这件事：

  1. 理解SD1.5 VAE的架构：这是训练的起点，你必须知道要训练的目标长什么样。
  2. 引用官方/核心代码与训练方法：为你整理出最接近官方定义的代码和架构来源，并说明如何在此基础上进行训练。

SD1.5使用的VAE架构被正式称为 AutoencoderKL [reference:0]，其核心架构是一个8倍下采样的KL-正则化自编码器[reference:1][reference:2]。

它的架构细节在官方代码配置文件中有明确定义。根据 v1-inference.yaml 和 autoencoder_kl_8x8x64.yaml 等官方配置文件，其核心参数如下[reference:3][reference:4]：

模块核心参数说明
整体 (AutoencoderKL)target: ldm.models.autoencoder.AutoencoderKL模型的目标类，指向官方代码库中的实现[reference:5]。
resolution: 256训练时内部处理的分辨率[reference:6][reference:7]。
in_channels: 3输入图像的通道数 (RGB)[reference:8][reference:9]。
out_ch: 3输出图像的通道数 (RGB)[reference:10][reference:11]。
z_channels: 4最终隐空间向量的通道数，这是SD1.5的核心特征[reference:12][reference:13]。
double_z: True如果为True，编码器输出会翻倍，一半为均值，一半为方差[reference:14][reference:15]。
编码器/解码器 (DDConfig)ch: 128模型的基础通道数，后续特征图通道数会以此为基础进行倍增[reference:16]。
ch_mult: [1, 1, 2, 2, 4, 4]控制特征图通道数的倍增系数。例如，第一个阶段通道数为128 (1281)，第二个阶段为128 (1281)，第三个阶段为256 (128*2)，以此类推[reference:17]。
num_res_blocks: 2每个分辨率阶段的残差块数量[reference:18]。
attn_resolutions: [16, 8]在哪个分辨率的特征图上应用注意力机制[reference:19]。
损失函数 (LossConfig)target: ldm.modules.losses.LPIPSWithDiscriminator组合了LPIPS感知损失、GAN对抗损失和KL散度损失的损失函数[reference:20]。

简单来说，它是一个经典的编码器-解码器结构[reference:21]，其核心任务就是将图像在高维像素空间和低维隐空间之间进行转换，从而在SD1.5中实现高效的图像生成[reference:22][reference:23]。

关于“官方的代码”，可以从官方源码、官方训练方法和官方衍生代码三个层面来理解：

官方源码参考

这是最接近“官方代码”定义的资料，即Stable Diffusion原始研究团队的代码库。

  • 核心模型实现：ldm/models/autoencoder.py 文件。这个文件定义了 AutoencoderKL 这个核心类[reference:24]。
  • 配置文件：
  • v1-inference.yaml：定义了 AutoencoderKL 如何被SD1.5模型调用[reference:25]。
  • configs/autoencoder/autoencoder_kl_8x8x64.yaml：定义了训练 AutoencoderKL 所需的详尽架构和超参数，如通道数、层数、损失函数权重等[reference:26]。

官方训练方法与代码解读

VAE的训练本身是 两阶段训练 的第一阶段[reference:27]，其训练过程在官方文档中有明确描述。

  • 训练损失函数：VAE的训练目标由三部分复合损失组成[reference:28]：
  1. Reconstruction Loss: L1 或 L2 损失，保证重建图像与原图的像素级相似。
  2. Perceptual Loss: LPIPS 损失，保证重建图像在感知上与原图相似。
  3. Adversarial Loss: GAN-based 损失，使重建图像的细节更锐利、真实。
  4. Regularization Loss: KL divergence，确保隐空间的正则化，使其平滑且连续。
  • 核心训练脚本：main.py 是官方训练流程的入口，它使用PyTorch Lightning框架和YAML配置文件来管理整个训练过程[reference:29][reference:30]。

官方衍生代码与微调示例

如果你不打算从零开始，更常见的做法是基于已有的官方VAE进行微调。

  • AutoencoderKL from Diffusers：这是最常用的方式。你可以通过以下代码加载和使用官方或第三方训练的VAE[reference:31][reference:32]:
    from diffusers import AutoencoderKL
    # 加载官方微调过的VAE
    vae = AutoencoderKL.from_pretrained("stabilityai/sd-vae-ft-mse")
    # 或加载原版VAE
    # vae = AutoencoderKL.from_pretrained("runwayml/stable-diffusion-v1-5", subfolder="vae")
  • 官方微调案例：Stability AI官方发布过两个微调版本 sd-vae-ft-ema 和 sd-vae-ft-mse[reference:33]。它们的训练细节是公开的[reference:34]:
  • 训练集：在1:1比例的LAION-Aesthetics和LAION-Humans数据集上进行微调。
  • 重点：主要微调了解码器（decoder）部分[reference:35]。
  • 超参数：ft-MSE 版本使用了 MSE + 0.1 * LPIPS 的损失函数，在16块A100上用192的批次大小训练了280k步[reference:36]。

总的来说，训练一个新的SD1.5 VAE是一项系统工程，你需要：

  1. 理解架构：基于上述的架构信息，构建自己的模型。
  2. 准备环境：搭建支持PyTorch Lightning和OmegaConf的深度学习环境。
  3. 编写代码：参考 ldm.models.autoencoder.AutoencoderKL 等官方代码，并实现对应的数据集加载和训练逻辑。
  4. 配置超参数：使用类似 autoencoder_kl_8x8x64.yaml 的配置文件定义模型和训练细节。
  5. 开始训练：运行类似 main.py --base configs/your_config.yaml -t --gpus 0, 的命令[reference:37]。

如果只是想提升生成效果，我更建议你从微调开始，直接使用 stabilityai/sd-vae-ft-mse 或 sd-vae-ft-ema 这些官方微调好的版本，这样成本会低很多。如果你确定要挑战从头训练，我们可以基于此继续探讨更具体的技术细节。
