Trae WebStorage 删除指南

2026-06-20 · 主题：科研-论文调研、课程-编程/计算机 · 3 条消息 · 对话编号 083
我问

trae的webstorage可以删除嘛、

你提到的 “Trae” 应该是字节跳动推出的 AI IDE（集成开发环境），它基于 VS Code 深度定制。而 “webstorage” 通常指浏览器/WebView 提供的 localStorage 和 sessionStorage。

可以直接回答你：可以删除，但要分清楚你具体想删的是哪一类“webstorage”。 通常就以下两种场景：

Trae 和 VS Code 一样是 Electron 应用，会把自身的一些状态、面板布局、插件数据等存储在本地类似 localStorage 的文件里。 ✅ 可以手动删除，但清除后部分个性化设置会丢失（如界面布局、最近打开项目等），重新打开 Trae 会重建。

清除方法：直接删除对应的存储文件夹

  • Windows

删除或重命名目录： %APPDATA%\Trae\Local Storage （在文件资源管理器地址栏粘贴该路径回车即可）

  • macOS

~/Library/Application Support/Trae/Local Storage

  • Linux

~/.config/Trae/Local Storage

操作前建议先完全退出 Trae，再将 Local Storage 文件夹删除（或改名备份），重启 Trae 即完成清除。

也就是你在 Trae 内置浏览器或 WebView 中打开的页面所存储的数据。 ✅ 完全可以删除，标准做法有两种：

  • 方法一：用 Trae 内置开发者工具清除
  • 在 Trae 中预览你的网页（比如使用内置的简单浏览器或预览功能）。
  • 打开该 WebView 的开发者工具：一般快捷键是 Ctrl+Shift+I（Mac Cmd+Option+I），或者右键 → 检查。
  • 切换到 Application（应用程序）面板 → 左侧找到 Storage → Local Storage / Session Storage，点击 “Clear” 按钮即可。
  • 方法二：在控制台执行 JS

同样在内置页面的开发者工具控制台中输入：

  localStorage.clear();
  sessionStorage.clear();

回车即可清空当前域名下的存储。

有些朋友会把 “Trae” 打成 “tauri”，如果你实际指的是 Tauri 应用中的 webstorage，删除的方法同样可行：

  • 在前端页面代码中调用 localStorage.clear()。
  • 或者在 Tauri 后端通过 Rust 删除整个 WebView 的数据目录（需配置 data_dir），但一般直接前端清除就足够了。

总结一下：

  • 想清 Trae 编辑器本身的配置缓存 → 去应用数据目录删 Local Storage 文件夹。
  • 想清你正在开发的网页存储 → 在 Trae 预览中用开发者工具或控制台执行 localStorage.clear()。

如果你能补充更具体的场景（例如“为什么想删，删哪个网站的数据”），我可以给你更精准的步骤。
