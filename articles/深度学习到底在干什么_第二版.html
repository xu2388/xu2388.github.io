深度学习到底在干什么（定稿）

2026-10-23 · 随笔

我其实一直想写点东西，关于深度学习到底在干什么，倒不是想把知识点讲一遍，卷积怎么算、反向传播怎么推、attention 矩阵长什么样，这些东西书上都有，我讲也讲不过人家，我想说的是另外一件事，就是我们天天在那儿调模型、跑实验，到底在忙什么。

这个念头是从一个很具体的地方来的，有一次别人问我，你做的这个东西到底在干什么，我张口就说我在做图像翻译，说完自己都觉得虚，因为这就是个任务名，跟"我在上班"差不多，等于没说，更别扭的是这个问题后来不是别人问的，是我自己问自己的，因为我发现很多时候我不是在设计模型，我是在试，加个模块试试，换个 loss 试试，不降就调学习率，试出来了说不清为什么，试不出来更说不清，就这样混了很久。

后来我大概想明白一点，就是深度学习这件事说到底是在拿一个有很多旋钮的机器，去凑一个我们从来没写出过公式的函数。

为什么是凑不是写，因为很多事的规则人根本写不出来，你说判断一张图里有没有猫，这个规则怎么写，写有尖耳朵有胡须有毛？那折耳猫怎么办，布偶猫怎么办，一只被挡了一半的猫怎么办，你写着写着规则越来越长，例外越来越多，最后变成一个没人敢改的东西，所以干脆不写了，我给你一堆例子，你自己找，找出来的那个近似规则就是一个函数，这个说法听起来有点糊弄，但工程上就是这个逻辑，我总结不出规则，那我就让机器从数据里拟合一个近似的。

那为什么是很多旋钮，因为简单的函数装不下这件事，一张 256 乘 256 的彩色图有十九万个数字，要把它变成另一张一样大的图，中间要做的事多到没法想，所以得找个能装得下的东西，这就是神经网络，几百万几千万个参数，每个参数就是一个旋钮，你拧一下它，输出就变一点，单独看每个旋钮都很蠢，几百万个一起拧，就能拧出一张像样的图。

这套想法其实很早就有了，卡了几十年，真正跑起来是三件事凑齐，数据够多了，算力便宜了，还有一个大家不太提的，就是这套东西可微，我觉得第三个才是命门，因为下山必须知道哪边更低，你的目标函数要是不可导、是跳变的，那梯度就没有意义，你就只能瞎猜，深度学习这几十年的进展，很大一部分不是模型变聪明了，是我们不断把原来"没法算错多少"的东西，重新写成"能算错多少"的东西。

比如生成一张图这件事，本来没有明确的对错，什么叫像，谁来定，后来有了 GAN，拿一个判别器当裁判，于是有了可以算的分数，再后来有了扩散，把生成拆成一步步去噪，每一步都是个能算误差的小任务，这不是它突然会画画了，是我们把问题重新写了一遍，让它变得可以算。

拆开看其实就三件事，把东西变成数，把一堆数变成另一堆数，然后判断变得对不对，再往回改。

第一件是表示，一张图在人眼里是一只猫，在机器眼里是一串数字，第一步不是看懂，是换一种摆法，为什么要换，因为原始摆法很笨，同一个东西往左挪十个像素，十九万个数字全变了，可东西还是那个东西，在原始表示里位置和内容是搅在一起的，所谓特征，说穿了就是换一种更能反映结构的摆法，卷积在做的事是让相邻的像素先互相看一眼凑出边缘，再让边缘互相看一眼凑出纹理，再往上凑出部件，一层一层把像素翻译成概念，这里有个我后来才想明白的点，网络不是先理解再表示，它是在表示的过程中顺便理解了，没有独立的理解这一步，你觉得它懂，是因为它最后输出的那个东西看起来像懂。

第二件是映射，一层网络干了什么，说穿了就一句话，乘一个矩阵，加一个偏置，过一个非线性函数，没有别的了，那个非线性看起来最不起眼，但它决定了这套东西有没有意义，因为只有矩阵乘的话，叠一百层也等于一层，线性叠线性还是线性，你叠再多也还是在画直线，加了这个弯，函数才能弯，才能去贴那些弯弯曲曲的真实规律，那深有什么用，我的理解是每一层都在换一次坐标系，原始空间里猫和狗可能缠在一起，怎么切都切不开，换几次坐标之后它们可能就被摊到两边了，一张平面就能分开，所以深度不是更聪明，是换的角度更多。

第三件是学习，这部分我觉得最漂亮，我们有一台几百万个旋钮的机器，输出错得离谱，怎么知道该往哪拧，答案是定义一个数叫 loss，衡量错了多少，然后看这个数对每个旋钮的导数，导数告诉你这个旋钮往右拧一点 loss 会变大还是变小，于是每个旋钮都往变小的方向拧一点点，几百万个同时拧，重复几百万次，这就是训练，说白了就是蒙着眼睛下山，你看不见山，只能感觉脚下哪边更低，然后往那边迈一小步，步子迈大了会滚下去，学习率太大 loss 就炸了，迈小了走到天亮也下不去，反向传播也不是什么玄学，它就是把这个"错了多少"的信息从最后一层一路传回第一层，让每个旋钮该往哪拧这件事，变成一次能算完的乘法。

然后是我觉得整件事里最要紧的一句话，你考什么，它就学什么。

模型的全部动机就是让 loss 变小，它不关心你的初衷，不关心物理意义，不关心看起来自不自然，它只关心那个数，这跟应试一模一样，你考默写他就背，你考解题套路他就刷题型，你考综合素质他就去搞一堆能加分的证书，学生不坏，他只是在最大化你的评分标准，深度学习就是一群极度听话、极度较真的学生，所以你只写输出和标签的像素差，它就学会平均一下最安全，你只写判别器分不出真假，它就学会找最容易骗过裁判的那个破绽而不是学会画，你只写分类正确，它就学会背景里有草地就是狗，因为训练集里狗都在草地上，这个现象有个名字叫捷径学习，我觉得它不是 bug，它就是模型在忠实完成你交代的任务。

这件事我是自己踩过坑才真信的，我们那条线做 H&E 到 IHC 的虚拟染色，输入一张常规染色的病理切片，输出一张对应的免疫组化图，走的是两通道浓度域的路线，训着训着输出就塌了，不管输入什么，出来的图都差不多，像一张平均脸，结构还在，但该深的地方不深，该浅的地方不浅，整张糊成一团中间调，loss 看着还不算难看，因为切片里大部分区域是背景和低浓度区，全输出一个均值，大部分像素都不太错，后来定位到归一化那一层，InstanceNorm 干的事是把每个样本自己减均值除方差，它天生对尺度不敏感，而浓度恰恰是个绝对量纲的东西，被这一除就在中间层里消失了，模型没有任何理由把它保留下来，因为 loss 从来没要求过。

所以那句话我是信的，你没写进 loss 的东西，它一定不会自己懂，不是它笨，是你没考。

当然我也知道，把一次训练失败归因到某一层，永远要留个余地，也可能是几件事凑在一起，但我现在的直觉就是它找到了一个省事的解，而我没拦住它。

那它到底学到了什么，我觉得不是概念，也不是因果，是统计规律，就是在训练数据那个分布里，输入和输出一起出现的规律，这个定义听起来很平淡，但它能解释一堆事，换个数据集就崩，因为分布变了，加一点噪声就错，因为它抓的规律很脆，对抗样本，往正确的方向加一点人眼看不见的扰动它反而错得离谱，因为扰动虽小但正好戳在它依赖的那个维度上，还有它能背下训练集，参数够多的时候它可以把训练集记下来，记忆和泛化是两件完全不同的事，所以泛化才是真本事，见过的题会做不算，没见过的题会做才算，而"没见过"到底有多没见过，没人能保证，这是这个领域最诚实也最难受的地方，你永远不知道它是在举一反三，还是背到的那道题刚好长得像。

那为什么它看起来像懂，因为高维空间里东西往往比我们想的更容易分开，一张图有几十万维，在这个空间里猫和狗的样本可能各自聚成一团，中间隔着一层薄薄的边界，深度学习做的事是一层层换坐标，把缠在一起的东西抖开，抖到能用一张平面切开，它不是在理解猫，它是在找一个让猫和狗分开的角度，这个视角我觉得有用，一是它把神秘感去掉了，不是魔法是几何，二是它解释了为什么数据越多越好，点越多那个边界才画得越准。

但它不能做的事我也想说清楚，因为它不能外推，训练里没有的东西它不会推理出来，只会硬套一个最像的答案，它不能解释，热力图好看不等于原因，它看哪里和它因为哪里做决定是两回事，它不能保证，没有证明只有统计，今天对不代表明天对，它也不知道自己错了，它永远会给你一个答案，哪怕那个答案是胡扯，它没有"我不确定"这个状态，除非你专门教它说这句话，这四条我觉得不是暂时的缺陷等模型大了就好，很多就是这类方法的性质，认不清这个就会把它当万能。

所以回到那个问题，深度学习在干什么，我的答案是它在做我们让它做的事，我们把想要写成一个能算的数，它就朝那个数去，写得糙它就学糙，写漏了它就抄近路，写错了它会非常高效地帮你实现一个你不想要的东西，所以所谓调模型，大部分时候其实是在调我们自己的表达，我到底想要什么，我能不能把它写成 loss，这件事做对了，一个很普通的网络也能 work，做不对，再大的模型也是在拟合一个错的目标。

我现在看别人的工作，也看自己的，会先问三个问题，它的 loss 到底写了什么，写了几项，每项在鼓励什么，有没有互相打架，loss 里藏着一篇论文真正的想法，它的数据是什么分布，训练集和测试集像不像，如果测试集是从训练集里随机切一块，那指标好看是应该的，说明不了太多，它比 baseline 好在哪，这个好是不是它想证明的那件事，有时候指标涨了但涨的原因是模型变大了，不是方法变好了，这三个问题问下来，很多看起来很厉害的工作会露馅，很多看起来朴素的工作反而站得住。

落到我自己的位置上，我觉得深度学习这行有个很奇怪的门槛，跑起来很容易，知道自己在干什么很难，pip install 完改两行就能训，loss 会降图会出，但为什么 work、为什么不 work，答不上来的人很多，包括很长一段时间的我，这恰好也是本科生能站的位置，别人的 backbone 别人的 loss 已经跑通了，你去用，然后在你的数据上找一个具体的不足，不是"效果不够好"这种空话，是浓度塌了、边界糊了、某一类一直错，再定位到具体哪一层哪个操作造成的，改掉它，说清楚为什么这么改，这就是增量，不大，但站得住，而且这个过程会逼着你回答最开始那个问题，你到底在让它干什么。

我现在的答案大概是这样，深度学习不是一个在思考的东西，它是一个极其听话、极其较真、但完全没有常识的执行者，你给它一个标准，它能把那个标准做到极致，包括你没想让它做到的那部分，所以我们做的事本质上是把一个模糊的愿望，一点点翻译成一个精确的能计算的标准，翻译得越准，它就越像懂。

至于它到底懂不懂，我觉得这个问题问错了。

该问的是，我们有没有把话说清楚。

写于 2026 年 10 月。里面有些判断我明年可能就想改，但现在就是这么想的。
