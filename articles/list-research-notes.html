研究笔记

研究过程中的专题笔记：概念、推导、实验设置与踩坑记录。　共 15 篇

  • DCLGAN（双对比学习无配对翻译）· 论文解读2026-10-24DCLGAN 以对偶双向生成器配合两套域独立的编码器与投影头，用多层 PatchNCE 替代循环一致性约束，并通过域内相似度损失构成 SimDCL 变体，解决单嵌入难以建模域间鸿沟与语义分割任务的模式崩溃问题。
  • ODA-GAN（正交解耦对齐）· 方法梳理2026-10-24ODA-GAN 以冻结 UNI 与 Grad-CAM 产生弱监督掩膜，用 O-MLP 将病理特征正交拆为染色相关与形态相关两支，再以对抗损失、双流 PatchNCE 与多层 MMD 域对齐共同训练，实现无配对 H&E→IHC 虚拟染色。
  • 医学图像染色转换 · 相关工作综述2026-10-24按监督强度与约束空间将 H&E→IHC 虚拟染色的现有工作归为全监督像素回归、无配对对比学习、弱配对错位鲁棒、病理语义保持、物理浓度域建模与评测基础设施六族，逐族梳理代表工作、核心机制与优缺点，并归纳可引用的对比链与研究空位。
  • 医学影像实验室上机路线 · DICOM 转换、FSL、CUDA、Slurm 与 nnUNet2026-10-25面向实验室共享 GPU 服务器的上机操作路线，按「账号与环境准备 → DICOM 转 NIfTI → 预处理与配准 → GPU 侧依赖 → 排队与训练 → 容器化」的顺序，整理 dcm2niix 与 find 批量转换写法、FSL 的 bet/flirt/fast 分工、CUDA 与 cuDNN、PyTorch 安装通道的版本对应、Slurm 的 sbatch 关键参数、nnUNet 规划预处理与训练的命令顺序，以及 Docker/Singularity 镜像片段，并保留权限、软件源、pip 受限等真实卡点。
  • 基于分数的无配对虚拟组织学染色 · 方法梳理2026-10-24MIU-Diff 以全局互信息引导的能量函数在表征空间分离组织结构与染色特征，配合时间步定制的反向扩散实现染色强度可控，并以局部互信息对比学习约束细胞级结构一致，从而在无配对 H&E–IHC 数据上完成虚拟染色。
  • 多尺度注意力机制 · 论文论述与整理2026-10-24梳理多尺度注意力的综述与理论文献脉络，逐层推导 Haar 小波变换的卷积化实现（正/逆变换与正交性），并以 SegNeXt 的 MSCA 为例说明多分支带状深度卷积如何在 O(n) 复杂度下同时获得多尺度感受野与空间注意力。
  • 对比学习与 CUT：无配对染色翻译的结构保持 · 研究笔记2026-10-24从 InfoNCE 出发梳理 PatchNCE 与 CUT 的单侧无配对翻译框架，说明其在病理 H&E→IHC 任务中如何以块级对比约束组织结构，并讨论 ASP 自适应监督、DAB 浓度与梯度边界三类互补监督，以及由 GAN 迁移至光密度域扩散的可行路径。
  • 服务器、训练与实验 · 长对话整理2026-10-25记录 HE→IHC 虚拟染色浓度域扩散模型的服务器训练与诊断过程，梳理噪声调度的四类问题及代表性文献，报告时间步损失诊断的实测结果（早期损失仅为晚期的 0.28 倍）、Beta(2,2) 重采样实验的损失轨迹，并据此修正研究假设、确定 M0→M1→M2 的分阶段路线与论文叙事。
  • H&E→IHC 浓度空间 Diffusion 的最小可运行实现 · 研究笔记2026-10-24以比尔-朗伯定律为物理基础，把 H&E 与 IHC 分解为染料浓度图，仅在 DAB 浓度通道上做条件扩散并以 H/E 浓度作为干净条件，最后经染色矩阵回投重建 IHC RGB，据此设计可判定该路线是否成立的最小基线 M0。
  • 病理 · 肾脏染色类型与形态学术语2026-10-25从显色化学出发区分 H&E、PAS、PASM、Masson 与 IHC：前两者靠染料与糖类的化学反应，PASM 靠银沉积，Masson 靠分子量与大分子亲和差异，IHC 靠抗体定位。再按肾小球、肾小管、间质、血管四条线列出各染色的表现，解释系膜增生、基底膜增厚、硬化、纤维化、炎细胞浸润的判读含义与读片顺序，最后说明 Camelyon17 五个域为何全是 H&E 却仍构成域偏移。
  • 虚拟染色 · HistDiT 与 HISTDIST 架构对比2026-10-25两个名字相近的病理扩散模型，结构路线不同。HistDiT 把 H&E 经 VAE 压到 64×64 潜空间，切成 1024 个 token 当作空间条件，用交叉注意力锁结构，语义条件经 AdaLN 调制注入，主干是 DiT。HISTDIST 走潜扩散加双条件（病理自监督 ViT 全局特征与 VAE 潜码），关键是 v-prediction、重标定噪声调度与 DDIM 反演。本文比较 patchify 与 UNet 的取舍、条件注入位置的差异、结构保持与染色准确的侧重，并估算显存与步数代价。
  • 虚拟染色 · 染色归一化方法谱系2026-10-25染色差异来自染液批次、扫描仪响应与切片厚度，表现为同一组织在不同域下的颜色漂移。本文按物理假设的强弱梳理归一化谱系：Reinhard 只做 Lab 三通道均值方差匹配；Macenko 在光密度空间用 SVD 取前两个主方向并按极角分位数定染料向量；Vahadane 改用带 L1 稀疏与非负约束的 NMF，并把源图密度图配目标染料基重构，从机制上保住结构；BeerLaNet 把 NMF 展开成可训练网络，去掉模板依赖。末段讨论归一化与虚拟染色的分工、评价指标的选择与五类常见陷阱。
  • 虚拟染色 · 轻量染色转换模型综述2026-10-25按「参数量从千到亿」的顺序梳理五个染色转换模型。StainNet 用三层 1×1 卷积加蒸馏，约一千参数，像素级映射不碰空间结构；BeerLaNet 把稀疏非负分解展开成十层网络，去掉模板依赖；AGMDT 借相邻切片做弱配对，用邻域形变场监督单个模型输出三种特殊染色；StainFuser 以条件潜扩散加零卷积锁结构，靠两百万 NST 合成对训练；StainPrompt 冻结扩散主干，只在推理时优化视觉提示。末段给出对照表与转向扩散的原因。
