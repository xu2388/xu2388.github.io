为什么 H&E 到 DAB 的逐像素预测不可行：一份归因报告的关键数据

写于 2026-10-24 · 归因篇

我曾拿到一份内部技术复盘报告，初读时难以理解——其中充满 T0、M0、M1、Cocos、CFG、probe_scale 等缩写——但它给出的结论非常坚硬，以至于我后来多次想绕开它都未能成功。本文完整记录这份报告的结论，以及我当时一连串的追问与困惑。

一、报告的背景与核心结论

背景如下：我们希望用扩散模型从 H&E 预测 DAB（即 IHC 中的某种标志物），输入 H&E、输出一张 128×128 的 DAB 预测图，模型带有将 H&E 注入的条件通道。报告要回答的是「这个任务是否可行」。结论相当不留情面：该任务在逐像素层面无法完成，原因不是模型未调好，而是数据中不存在这一规律。 我最初并不相信，因为领域内已有大量 H&E→IHC 的工作发表；但报告对口径限定得非常严格——仅在「128×128 逐像素 + 跨不同患者图像 + MSE 衡量」这一组合下讨论，并明确说明从未否定扩散模型在虚拟染色领域本身的可行性。这一边界我是后来才真正理解的。

二、问题一：模型并未真正利用条件

报告首先确认了第一件事：把条件从「正确的 H&E」换成「他人的 H&E」，输出几乎不变，差异仅在 0.2%–2%。在 t=999（几乎是纯噪声）时刻，条件本是唯一的信息来源，替换后输出仅变化 0.0014。这说明网络学到的是「无论给什么条件，都输出一张平均图」，条件自始至终未进入梯度。他们尝试了 CFG、cross-attention 等标准方案，均未奏效。

原始记录 · 报告对「条件失效」的解释 扩散模型的噪声起点跟条件无关，所以条件难以区分时，梯度退化成拟合边缘分布。这个现象有篇论文叫 「loss collapse」，解药叫 Cocos——把条件塞进采样起点（z_t），而不是指望它从 concat 通道里自己长出来。这是真问题，但注意：它救的是「条件进不了梯度」，拿不到本来就不存在的东西。

三、问题二（真正的主问题）：即使条件进入梯度，逐像素答案也不存在

这是报告中最关键的部分，由四个独立实验支撑。当时我对每一条逐一追问，因为每一条都与直觉相悖。

实验 1：信号随块变大才出现，但 M0 的目标整体在「地板以下」

8 px 块的预测还不如直接输出一个常数。而 M0 的 128×128 逐像素目标，整体落在错位地板以下。

实验 2：错位确实存在，但并非瓶颈

我最初的直觉是「问题一定出在 H&E 与 IHC 未配准上，应先修配准」，而报告恰恰否定了这一设想。H&E 与 IHC 之间存在几何错位，中位 22.5 px。但实验表明：用估出的平移做 oracle 对齐干预，块级 r 反而更差；全平移扫描遍历了 ±48 px 范围内的全部 625 个平移，其中最优者比不平移还差，没有任何一个平移能使预测超过常数基线。因此「先修配准」这条路径被实测排除——它曾是我最想走的捷径。

实验 4：结论

「H&E 的哪个像素对应多少 DAB」这一问题本身不存在跨图可迁移的规律。这不能归因于错位、目标函数或超参数，三个独立实验（线性探针、CNN 留出、oracle 对齐干预）均指向同一结论。我当时反而有些释然，因为这意味着我此前关于「模型没调好」的焦虑，方向本身就是错的。

四、下一步方向：轨道 A（改任务）与轨道 B（改模型）

原始记录 · 报告给的两条路线

轨道 A（主推）：先改任务，再改模型。把目标从「逐像素场」降到「组织级统计量」（比如 H-score 路线）。先跑一个小 CNN 在 32 px 块均值上，看能不能超过线性上界 +11%；超不过就不要做 A-2。

轨道 B（次要）：M1/Cocos。修的是「条件进不了梯度」这个真问题，但它拿不到本来就不存在的东西。验收标准变了：不是 loss 曲线好看，而是 32 px 块口径上跨图 MSE 能不能超过平凡基线 11%。只有在留出 r ≥ 0.4 时才做。

已经明确不要做的：不要再调扩散超参；不要指望「先做配准」；不要用 min-SNR / t 重加权当解药。

补充解释 · 改 CNN 是不是就「改变了」 我当时追问：报告建议先改任务、不要改模型，但轨道 A 又提出使用 CNN，这是否矛盾？当时的解释很直接——更换 CNN 本身不会改变数据中的信息量。若只是把 M0 的 UNet 换成 CNN 继续做 128×128 逐像素预测，并无意义，因为报告已排除架构是主因（同一 UNet 的路径回归分支可达 r=0.99，扩散分支仅有 0.02；cross-attention 无差别；各尺度 r 仅从 0.183 升至 0.293）。CNN 在轨道 A 中扮演的是「探针」角色——用于在 32px 块均值的新口径上检验「目标是否仍存在」。一个贴切的类比是：无论用毛笔还是钢笔，纸上本来就没有那个字；换笔不改变纸上是否有字，报告建议的是换纸，而 CNN 只是用来检查新纸上有没有字。

五、领域内 H&E→IHC 已有成功案例，与报告结论矛盾吗？

这是我最后一个、也是最执着的追问。后来的回答化解了矛盾：并不冲突，是口径不同。领域内绝大多数 H&E→IHC 工作的评估方式是分布级指标（FID、JSD、LPIPS、SSIM）、病理医生盲评、下游任务验证（检验 HER2 分类器性能是否下降），并不要求逐像素对应。有研究报告称，病理医生区分真实与虚拟 IHC 的准确率仅为 52%、区分真实与合成 Ki-67 仅为 60%，接近随机水平——这说明在临床可用的标准下，虚拟染色是成立的。

而报告否定的，是「BCI 连续切片 + 128×128 逐像素 + 完全不微调跨图」这一严苛组合。领域内的默认做法是未配对/弱配对训练（CycleGAN、Star-Diff 不要求逐像素对应），或主动进行弹性配准（DGR 框架、Spatial Transformer、BiReC）；而报告的全平移扫描只测试了刚性平移——真实组织形变是非刚性的，平移无法挽回并不代表弹性配准也无法挽回。概括而言：领域内的成功源于未在报告所限定的组合条件下工作；报告否定的正是这一组合，而非扩散模型本身。

当前结论 BCI 连续切片在逐像素、跨图口径下，H&E 与 DAB 之间不存在可迁移的逐像素规律——这是数据属性，而非模型问题。我的交付口径应当接受「组织级染色浓度」（H-score 路线），或改用配准良好的数据；M1/Cocos 在这两个选择中都只是辅助性改进。这一结论纠正了我「执着于逐像素」的预设，也是我所需要的停止规则。
