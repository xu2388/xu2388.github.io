二、核心知识点

2.1 数组的基本特性

  • 同类型：一个数组只能存放同一种数据类型的数据，元素类型由声明时的分量类型决定。
  • 定长：数组长度在创建时确定，运行期间不可增删，length 是只读属性。
  • 连续存储：数组元素在内存中连续排列，因而支持 $O(1)$ 随机访问。
  • 下标从 0 开始：长度为 $n$ 的数组合法下标为 $0\sim n-1$。

2.2 数组的初始化语法

int[] a = {1, 2, 3};            // 静态初始化（声明同时赋值，可省略 new）
int[] b = new int[]{1, 2, 3};   // 静态初始化的完整写法，new 后必须有 []
int[] c = new int[3];           // 动态初始化，元素取默认值 0
int[][] d = {{1, 2}, {3}};      // 二维数组，各行长度可不同

错误写法辨析：

  • int a = {1,2,3};：缺少 []，a 被声明为 int 而非数组；
  • int[] a = new int{1,2,3};：new 后必须写 []，正确形式为 new int[]{...}；
  • int a[] = new int(3);：长度用 [] 指定，() 是构造方法语法，不适用于数组。

2.3 数组与对象的内存分布

Java 的内存模型中与本题相关的部分：

  • 栈（stack）：存放局部变量、方法参数、引用变量，随方法调用入栈、返回出栈，自动释放；
  • 堆（heap）：存放 new 创建的对象与数组实体，由垃圾回收器管理；
  • 方法区/常量池：存放类元信息与字符串字面量等。

因此"数组对象在堆、数组引用变量在栈"是标准结论：int[] a = new int[3]; 中，new int[3] 的实体在堆，变量 a 本身（保存地址）在栈。

2.4 多维数组的本质

Java 的多维数组是数组的数组：int[][] a 的类型是"元素为 int[] 的数组"。因此：

  • 各行的长度不必相同，即允许不规则（锯齿）数组；
  • 可以逐行单独创建：a[0] = new int[2]; a[1] = new int[5];
  • 可以使用增强 for 循环遍历，外层取行、内层取元素。

2.5 String、StringBuffer 与 StringBuilder

类型可变性线程安全适用场景
String不可变，任何"修改"都产生新对象安全（因不可变）常量、少量拼接、作为 map 的 key
StringBuffer可变，原地修改安全（方法加锁）多线程频繁修改
StringBuilder可变，原地修改不安全单线程频繁修改，效率最高

String 的对象一旦创建内容不可改变；字面量存放在字符串常量池，new String(...) 创建的对象在堆中。由于不可变，循环内大量拼接会产生大量临时对象，此时应改用 StringBuffer/StringBuilder。

2.6 正则表达式

正则表达式是描述字符串模式的规则，核心用途是匹配、查找、替换、分割：

String s = "a1b22c333";
boolean ok = s.matches("\\d+");        // 整个字符串是否匹配
String t  = s.replaceAll("\\d+", "#"); // 替换
String[] parts = s.split("\\d+");      // 分割

常用方法辨析：

  • matches()：判断整个字符串是否完全匹配给定正则；
  • find()：在字符串中查找是否存在匹配的子串（Matcher 的方法）；
  • group()：取出捕获组的内容；
  • split()：按正则分割字符串。

适用边界：正则擅长格式验证（邮箱、手机号、身份证号）、文本抽取与替换；不适用于数值排序、求和、计数等数值计算任务。

2.7 常见易错点

  1. 认为数组长度可动态改变——Java 数组定长，扩容需新建数组并复制。
  2. 混淆 length 属性与 length() 方法：数组用 length，字符串用 length()，集合用 size()。
  3. 认为多维数组必须是规则矩阵——Java 允许各行不等长。
  4. 认为 String 是基本类型——它是引用类型，只是使用频繁、有字面量优化。
  5. 认为 StringBuffer 线程不安全——StringBuffer 安全，StringBuilder 才不安全。
  6. 认为 matches() 是"包含匹配"——它要求整个字符串匹配，部分匹配应使用 find()。

第 5 题专项说明（原始答案唯一错误处）：

题目要求选出正确的一维数组初始化写法，选项为

  • A. int a = {1,2,3};
  • B. int[] a = new int{1,2,3};

3.4 综合问答

问 为什么 String 频繁拼接效率低，而 StringBuffer 高？ 答：String 不可变，每次拼接都创建新对象并复制原内容，时间复杂度随拼接次数呈平方增长，同时产生大量待回收对象；StringBuffer 内部维护可变字符数组，追加时按容量扩容，原地修改，均摊代价接近 $O(1)$。

问 数组与 ArrayList 的主要区别是什么？ 答：数组定长、可存基本类型、内存连续、访问最快；ArrayList 基于数组封装，可动态扩容，只能存对象（基本类型需装箱），提供更丰富的 API，但扩容时存在复制开销。

本套自测围绕 Java 语言的三组基础概念：数组的"同类型、定长、连续存储、下标从 0 起"四项特征与三种初始化写法；对象实体在堆、引用变量在栈的内存分布；String 不可变而 StringBuffer/StringBuilder 可变的差异及其线程安全取舍；正则表达式"匹配、查找、替换、分割"的用途边界与 matches() 的全串匹配语义。全部 20 题中仅第 5 题原答案有误，正确选项为 C。
