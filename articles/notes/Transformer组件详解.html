Transformer 组件详解 · FFN、掩码自注意力、交叉注意力与残差归一化

课程笔记 · 深度学习/神经网络

一、概述

本笔记只做一件事：把 Transformer 拆成若干可以单独检验的组件，逐个给出公式、张量维度与执行次序。循环神经网络语言模型、Seq2Seq 编码器—解码器、注意力机制的历史动机与束搜索等解码策略已在《循环神经网络语言模型（RNN-LM）》一篇中展开，本文不再重复，只处理其内部构件。

需要说明的是，本笔记所依据的材料是一次课程幻灯片的逐页讲解记录，幻灯片图像本身并不可得。因此凡属"必须看图才讲得通"的内容（图示连线、热力图、架构框图的空间排布），本文只用一句话概括结论，不补写图内细节；凡是 AI 回答中自足成立的公式、结构说明与配置数值，才完整收录。材料末尾关于课程报名、选题推荐与师生往来的部分与主题无关，一律不取。

本文覆盖的组件为：词嵌入与位置编码、前馈网络（FFN）、缩放点积注意力与自注意力、带掩码的自注意力、交叉注意力、残差连接与层归一化，最后以 Base 与 Big 两种配置把上述组件的具体尺寸落到实处。

二、核心概念：整体数据流与组件分工

2.1 端到端数据流

材料给出的主干流程可以写成两步：输入侧先做嵌入，再堆叠若干层，最后投影回词表。

编码器侧：

源词 → 词嵌入 Ew·xj + 位置嵌入 Epj → Add & Norm 包裹的（自注意力 + FFN）× N → 编码器状态 H

解码器侧：

已生成目标词 → 词嵌入 + 位置嵌入 →（掩码自注意力 → 交叉注意力 → FFN）× N → 线性层 + Softmax → 下一词概率分布

其中输入向量由词嵌入向量与位置嵌入向量相加得到，材料的转录写法是 EwXi + Epj，即"第 $i$ 个词的词嵌入"加上"位置 $j$ 的位置嵌入"；解码器顶层的输出需经线性层与 Softmax 才成为词表上的概率分布。层数 $N$ 在 Base 与 Big 两种配置中均取 6。

2.2 组件职责表

下表按"是否混合位置""是否引入新参数"两项把组件分工排开，这是理解后文的关键框架。

组件职责是否跨位置混合信息主要可训练参数
词嵌入层把离散词映射为 $d_{model}$ 维稠密向量否嵌入矩阵
位置编码补回自注意力丢失的词序信息否无（正弦余弦形式为固定值）
自注意力让每个位置从同一序列的全局范围取上下文是$W^Q$、$W^K$、$W^V$、$W^O$
掩码自注意力同上，但只允许看当前位置及之前是同上（掩码本身无参数）
交叉注意力让目标侧位置读取源侧表示 $H$是同上

一句概括材料反复强调的分工：注意力决定"从哪里取信息"，前馈网络决定"取到之后怎么加工"，残差与归一化决定"深层堆叠时数值是否还稳得住"。

三、前馈网络 FFN

3.1 公式与逐符号维度

前馈层是最经典的组件：给定输入向量 $x$，先做一次仿射变换 $Mx+b$，再加非线性激活，写作 $y=a(Mx+b)$。若只有矩阵乘法与偏置，多层堆叠仍等价于单层仿射变换，非线性能力完全来自激活函数。矩阵乘法又称仿射变换，这个称呼源于其几何性质——输入空间中的直线，变换后仍是直线。

Transformer 中的 FFN 是两层线性变换夹一个激活：

$$ \mathrm{FFN}(x)=\max\left(0,\; x W_1 + b_1\right) W_2 + b_2 $$

逐符号说明：$x$ 是某一位置的输入向量，维度为 $d_{model}$；$W_1$ 把维度从 $d_{model}$ 升到中间维度 $d_{ff}$；$b_1$ 是升维后的偏置；$\max(0,\cdot)$ 即 ReLU，逐元素把负值截为 0；$W_2$ 再把 $d_{ff}$ 降回 $d_{model}$；$b_2$ 为输出偏置。材料也给出同一公式的向量写法 $\mathrm{FFN}(\hat{h}_j)=\mathrm{relu}(W_1\hat{h}_j+b_1)W_2+b_2$，二者只是行的位置与列的向量之争，含义一致。

Base 配置下的形状变化如下：

阶段张量形状说明
输入$n \times 512$$n$ 为序列长度
乘 $W_1$ 后$n \times 2048$升维，$W_1$ 为 $512 \times 2048$
过 ReLU 后$n \times 2048$逐元素，形状不变
乘 $W_2$ 后$n \times 512$降维，$W_2$ 为 $2048 \times 512$
输出$n \times 512$与输入同形，故可直接做残差相加

3.2 为什么要"中间大、两头小"

材料把这一设计与因子分解并置为一组对照。二者方向相反，目的也相反：

设计维度走向目的典型场景
因子分解高维 → 低维 $k$ → 高维削减参数量大词表嵌入与输出层
Transformer 的 FFN$d_{model}$ → 更大的 $d_{ff}$ → $d_{model}$允许更复杂的特征交互每层的前馈子层

因子分解的做法是把 $M$ 近似为 $A$ 与 $B$ 之积，参数量从 $\lvert x\rvert \times \lvert y\rvert$ 降到 $\lvert x\rvert \times k+k\times \lvert y\rvert$。材料给出的幻灯片算例是 $\lvert x\rvert=20000$、$\lvert y\rvert=50000$ 时参数量为 $10^9$，取瓶颈 $\lvert v\rvert=100$ 后降为 $200$ 万加 $500$ 万，即 $7\times 10^6$。其代价是秩被强行压低，属于有信息损失的近似；收益是瓶颈会迫使模型只保留显著特征，与主成分分析的思路同构。

FFN 取相反方向：输入与输出维度不变，只把中间放大。中间向量维度变大后，模型可以在更高维的空间里组合、交叉特征；真正起作用的是在这个高维中间向量上施加非线性，相当于把输入映射到高维空间用超平面分割数据，再映射回原维度。Base 配置 $512 \rightarrow 2048 \rightarrow 512$ 的两个矩阵各有 $512\times 2048=1{,}048{,}576$ 个参数，合计约 $2.1\times 10^6$（幻灯片原文把这组数字口语化为"一百万"，材料已注明这是取整所致）。

3.3 逐位置独立、参数共享

FFN 作用在序列的每个位置上，位置之间不交换信息，同一组 $W_1,W_2$ 在所有位置共享。因此它等价于一个对整条序列滑用的同一映射，也等价于核宽为 1 的逐位置变换。材料对此的表述是"不同位置的参数是共享的，相当于对序列中每个词向量做一次相同的特征映射"。

伪代码：

# FFN：逐位置独立，位置数 n 不参与计算
def FFN(x, W1, b1, W2, b2):
    h = relu(x @ W1 + b1)      # (n, d_model) -> (n, d_ff)
    y = h @ W2 + b2            # (n, d_ff)   -> (n, d_model)
    return y                   # 与 x 同形，可直接做残差

一个值得记录的延伸：材料后半部分讲到混合专家（MoE）时指出，专家本质上就是标准 Transformer 层里的那个 FFN（两层全加激活），MoE 只是把单个 FFN 换成多组不共享权重的 FFN，再加一个路由门控按得分取前 $k$ 个加权求和，注意力层与归一化保持不变。换句话说，FFN 是架构里最容易被替换的一块。

四、缩放点积注意力：先投影，再匹配

4.1 三个量与一次查询

注意力可以按数据库查询理解：拿 Query 去和所有 Key 匹配，匹配度越高的 Key 对应的 Value 权重越大，最后按权重把 Value 加权求和。核心公式为：

$$ \text{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{Q K^{\top}}{\sqrt{d_k}}\right)V $$

材料强调，注意力不直接在原始向量上计算，而要先用权重矩阵投影，即从 $\text{Attention}(Q,K,V)$ 变为 $\text{Attention}(QW^Q, KW^K, VW^V)$。投影的作用有三层：把 $d_{model}$ 降到更小的 $d_k$ 以减少点积计算量；引入可学习参数，让模型自己学到更适合算相似度的特征空间；构成多头注意力的前提——多个头就是多组独立的投影。

4.2 缩放因子 $\sqrt{d_k}$ 的作用

材料给出的理由是：维度很高时点积结果的方差会变大，Softmax 之后梯度容易消失，除以 $\sqrt{d_k}$ 是对方差做缩放以稳定梯度。换言之，缩放不是数学技巧上的装饰，而是为了让归一化后的权重分布不至于在训练初期就塌成近乎 one-hot 的形状。

4.3 自注意力：三个量同源于一个序列

编码器侧的自注意力把序列自身的表示 $H$（每一行是一个词的向量 $h_j$）同时作为 Query、Key、Value 的来源：

$$ \text{self-attention}(H)=\text{MultiHead}(H,H,H),\qquad Q=HW^{Q},\; K=HW^{K},\; V=HW^{V} $$

材料转录的幻灯片公式写作 $\text{self-attention}(H)=\text{Attention}(HW^{Q},HW^{K},H)$，即 Value 直接取原始输入而不再投影；另一处讲解则写作 $V=HW^{V}$。两处并不矛盾：前者是幻灯片为省符号做的简化，后者是带 $W^V$ 的一般形式，本文以一般形式为准，并在误区一节提示这一写法差异。自注意力的目的很明确：每个词的表示既包含自身，也结合上下文，从而区分多义词。

多头则并行做多次单头注意力再拼接：

$$ \text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^{O} $$

每个头的 $W_i^{Q},W_i^{K},W_i^{V}$ 独立，会学到不同的注意力模式，最后用 $W^{O}$ 做一次线性变换融合所有头。头数与单头维度的关系由配置给出：Base 为 $512/8=64$，Big 为 $1024/16=64$（材料原文写明"每个头的维度 = 总维度 / 头数"）。单头维度停在 64，正是为了让参与点积的向量不要维度过高，从而避免点积值过大影响 Softmax 的梯度稳定性。

注意力不识别词序：计算权重时只用到词向量，不看词在句子中的位置，把词序打乱而词不变，自注意力的结果完全相同。而词序对语言至关重要，因此需要位置编码：给每个位置生成一个独特向量加到词嵌入上。材料给出正弦余弦形式：

$$ PE_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d_{model}}}\right),\qquad PE_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$

不同频率的波给每个位置生成独一无二的"指纹"，位置越近的向量模式越相似。

伪代码（单头，含掩码接口）：

def attention(Q, K, V, mask=None, dk):
    s = (Q @ transpose(K)) / sqrt(dk)     # (n_q, n_k) 相似度分数
    if mask is not None:
        s = s + mask                      # 禁止的位置置为 -inf
    a = softmax(s, axis=-1)               # 每行和为 1
    return a @ V                          # (n_q, d_k)

五、掩码自注意力：上三角置 $-\infty$

5.1 具体做法

解码器是自回归的：生成第 $i$ 个词时只能依据第 $1$ 到第 $i-1$ 个词。若不加限制，位置 $i$ 的 Query 会与位置 $j>i$ 的 Key 计算相似度，从而读到尚未生成的目标词，训练时等于把答案泄露给模型。做法是把注意力分数矩阵的上三角（严格上三角部分）置为 $-\infty$，再做 Softmax：

$$ s_{ij}=-\infty \quad (j>i),\qquad \alpha_{ij}=\frac{\exp(s_{ij})}{\sum_{k\le i}\exp(s_{ik})} $$

由于 $\exp(-\infty)=0$，被屏蔽位置在归一化后权重严格为 0，位置 $i$ 的上下文只是它自身与左侧位置加权和。以三个位置为例，分数矩阵加上掩码后的形状是：

$$ \begin{bmatrix} s_{11} & -\infty & -\infty \\ s_{21} & s_{22} & -\infty \\ s_{31} & s_{32} & s_{33} \end{bmatrix} $$

第一行只有一个非屏蔽项，Softmax 后权重为 1；第三行三项全部参与。计算式仍可写成与编码器完全同形的多头自注意力，只是输入序列换成"带掩码的目标侧表示"：

$$ \text{self-attention}(\tilde{S})=\text{MultiHead}(\tilde{S},\tilde{S},\tilde{S}) $$

掩码本身不含参数，多头计算方式与编码器一致，差别仅在"只能看前面"这一条限制。

5.2 为什么必须掩码

训练时目标序列是已知的（材料在讲解 GPT 一节同样强调：生成第 $i$ 个词只能看第 $1$ 到 $i-1$ 个词）。不加掩码，模型可以在训练阶段从右侧位置直接抄到正确标签，损失下降得很快却学不到任何预测能力；推理时未来词根本不存在，掩码又必须生效，训练与推理的可见范围就会不一致。掩码保证两者看到的信息集合完全相同，是自回归生成的前提。

维度编码器自注意力解码器掩码自注意力
可见范围整个句子的所有位置当前位置及其之前
掩码无上三角置 $-\infty$
用途编码源句，完善每个词的上下文表示生成目标句，防止未来信息泄露
计算式$\text{MultiHead}(H,H,H)$$\text{MultiHead}(\tilde{S},\tilde{S},\tilde{S})$

六、交叉注意力：唯一区别在 Q 的来路

6.1 接法

解码器在掩码自注意力之后还有一层注意力，其 Query 来自目标侧，Key 与 Value 来自编码器的最终输出 $H$：

$$ \text{attention}(\tilde{S},H)=\text{MultiHead}(Q=\tilde{S},\; K=H,\; V=H) $$

材料对应的转录式写作 attention(Ṡ, H) = softmax MultiHead(Ṡ, H, H)，其中 $\tilde{S}$ 是解码器侧表示、$H$ 是编码器状态。这一层是编码器与解码器之间的桥梁：生成每个词时回读源句信息，使输出与输入对齐。

6.2 与自注意力的关系

把两节公式并排看，即可确认二者只差 $Q,K,V$ 的来源，点积、缩放、掩码、Softmax、加权求和五步完全相同。RNN 时代的加性注意力（$a(s_{i-1},h_j)=v^{\top}\tanh(W s_{i-1}+U h_j+b)$）同样是"目标侧查询、源侧键值"这一格局，只是打分函数不同，因此交叉注意力并不是 Transformer 新发明的机制，而是把打分函数换成了缩放点积。

对照项自注意力交叉注意力
Query 来源序列自身（或解码器自身）解码器侧表示 $\tilde{S}$
Key、Value 来源同一序列自身编码器输出 $H$
分数矩阵形状$n \times n$（同侧）$n_{tgt} \times n_{src}$（异侧）
是否用上三角掩码编码器不用；解码器自注意力用一般不用（源侧已完整可读）
功能建模序列内部依赖对齐源侧与目标侧
计算式缩放点积注意力与左列完全同式

材料亦指出 $Q/K/V$ 的角色可以互换：既可以让目标侧查源侧，也可以反过来让源侧查目标侧，取决于任务；而在编码器—解码器翻译模型中，固定取前者。至于架构层面的取舍：只用编码器（如 BERT 一类的双向模型）时不存在交叉注意力，只用解码器时保留掩码自注意力但没有编码器可供查询，交叉注意力随之整体消失——这恰好说明它是可选组件而非注意力机制的本体。

七、残差连接与层归一化

7.1 两种连接的位置

每个子层都配一条残差通路：把子层输出与子层输入直接相加，材料写作

$$ \text{output}=\text{self-attention}(h_j)+h_j $$

其作用有两点：梯度可沿残差路径直接传到前面的层，缓解深层堆叠的梯度消失；即使子层没学到有效变换，原始信息也不会丢。相加要求两侧同形，这正是 FFN 必须"升上去再降回原维度"、注意力输出必须经 $W^{O}$ 投回 $d_{model}$ 的结构原因。

残差之后接层归一化，把该位置的向量分布拉回稳定范围：

$$ \mathrm{LN}(x)=\gamma\cdot\frac{x-\mu}{\sqrt{\sigma^{2}+\varepsilon}}+\beta $$

$\mu$ 与 $\sigma^{2}$ 是均值与方差，$\gamma$、$\beta$ 为可学习的缩放与偏移。材料强调其收益是训练更快更稳、缓解梯度爆炸与消失。

7.2 一层的完整次序

材料给出的堆叠链条是"子层 → 残差相加 → 层归一化"重复两次：

$$ h_j \rightarrow \text{MultiHead} \rightarrow +h_j \rightarrow \mathrm{LN} \rightarrow \mathrm{FFN} \rightarrow +\text{输入} \rightarrow \mathrm{LN} \rightarrow h_j^{\mathrm{new}} $$

解码器层则是同一骨架套三个子层：掩码自注意力、交叉注意力、FFN，每个子层各配一次残差与一次层归一化。材料在编码器结构图上把这一对操作合标为 Add & Norm，并特别说明 FFN 之后的残差与归一化在图上未画出但属标配。

需要如实标注一点：本材料只给出上述这一种放法，即归一化位于残差相加之后（通常称 post-LN），并未讨论把归一化提到子层之前的 pre-LN 变体，故本文不作两种放法的对照，也不补写其优劣结论。

7.3 层骨架伪代码

把前述组件串起来，两种堆叠的差别只在于解码器多两层注意力：

# 编码器层（重复 N 次）
x = LN( x + SelfAttn(x) )           # 自注意力：Q=K=V= x，无掩码
x = LN( x + FFN(x) )                # 逐位置前馈

# 解码器层（重复 N 次）
y = LN( y + MaskedSelfAttn(y, causal_mask) )   # 上三角置 -inf
y = LN( y + CrossAttn(Q=y, K=H, V=H) )         # H 为编码器最终输出
y = LN( y + FFN(y) )
return y                            # 送线性层 + Softmax

其中 H 只在整个编码器算完之后产生，并被解码器每一层的交叉注意力重复读取；causal_mask 不携带参数。三处 LN(... + ...) 正是材料里 Add & Norm 的展开写法。

八、Base 与 Big：两种配置

8.1 配置表

8.2 关于 4094 的核对

成文时对本节数值做了联网核对。原论文表 3 中 Base 行给出 $N=6$、$d_{model}=512$、$d_{ff}=2048$、$h=8$、$d_k=d_v=64$，Big 行给出 $N=6$、$d_{model}=1024$、$d_{ff}=4096$、$h=16$。本文所依据的材料转录值即 4096，与原论文一致；若在其他转录或笔记中看到 Big 的 FFN 中间维度写作 4094，应判定为笔误：一则 4094 与原论文表 3 不符，二则 4096 恰为 $4\times 1024=2^{12}$，与"中间维度取 $d_{model}$ 四倍"的规律及本材料的"升维—降维"叙述完全吻合，4094 不具备这种可解释性。据此本文统一采用 4096，并在此显式记录核对过程，而非默默改数。

8.3 头数与 $d_k$ 的关系

材料把这一关系写成一句话：每个头的维度等于总维度除以头数。两种配置算下来都等于 64，说明从 Base 到 Big 放大的不是单头维度，而是头的数量与主干维度。这个设计有两处好处：单头维度稳定在 64，参与点积的向量维度不变，就不会因维度过高把点积值推大、破坏 Softmax 的梯度稳定性；头数翻倍则意味着可以并行捕捉两倍的关系模式，而各头的计算量与 Base 相同。

九、常见误区

  1. 把掩码当成参数。上三角的 $-\infty$ 只是加在分数上的常量偏置，不引入任何可训练权重；参数量与编码器自注意力完全相同。
  2. 以为交叉注意力是一种新算法。二者只在 $Q$（以及 $K,V$）的来源上不同，点积、除以 $\sqrt{d_k}$、Softmax、加权求和四步一字不差。
  3. 忽略 FFN 的位置独立性。FFN 不跨位置交换信息，若把整条序列展平后当一个大矩阵做变换，就会误以为它能替代注意力。
  4. 混淆两种维度设计。因子分解是"高—低—高"，为的是降参数；FFN 是"低—高—低"，为的是增强特征交互。二者方向相反，不能互相解释。
  5. 把幻灯片里 Value 不投影的写法当作一般形式。$\text{Attention}(HW^{Q},HW^{K},H)$ 是简化记法，一般形式应写 $HW^{V}$。
  6. 忘记残差要求同形。$\mathrm{FFN}$ 与多头注意力的输出必须回到 $d_{model}$，否则 $+h_j$ 无法进行；"中间放大再压回"不只是性能选择，也是形状约束。
  7. 误记 Big 的 FFN 内维为 4094。已核对为 4096，见第八节。
  8. 把词序问题归给归一化。自注意力对词序不敏感，补位信息靠位置编码，与层归一化无关。
  9. 用编码器视角理解解码器。编码器可以看全句，解码器的第一层注意力必须只看左侧；两种"自注意力"计算式同形，可见范围完全不同。

十、总结要点

  1. Transformer 每层由"注意力混合位置信息 + FFN 逐位置加工 + 残差与层归一化稳住数值"三件事构成，组件职责互不重叠。
  2. FFN 的公式为 $\mathrm{FFN}(x)=\max(0,\,xW_1+b_1)W_2+b_2$，形状沿 $d_{model}\rightarrow d_{ff}\rightarrow d_{model}$ 走一圈，参数在位置间共享。
  3. 缩放点积注意力先投影再匹配，除以 $\sqrt{d_k}$ 是为压制高维点积的方差、避免 Softmax 梯度消失；多头即多组独立投影后拼接再经 $W^{O}$ 融合。
  4. 掩码自注意力把分数矩阵严格上三角置 $-\infty$，Softmax 后被屏蔽位置权重恰为 0，其必要性在于让训练与推理的可见信息集合一致。
  5. 交叉注意力取 $\text{MultiHead}(Q=\tilde{S},K=H,V=H)$，与自注意力唯一区别是 Query（与 Key/Value）的来路，去掉编码器它便整体消失。
  6. 残差连接与层归一化在每个子层后各出现一次，材料给出的是"相加之后再归一化"的次序；pre-LN 变体未见于材料，故本文不作对照。
  7. Base 与 Big 的差异集中在 $d_{model}$、$h$ 与 $d_{ff}$ 三项，单头维度 64 与层数 6 保持不变，$d_{ff}$ 恒为 $d_{model}$ 的 4 倍（2048 与 4096）。
