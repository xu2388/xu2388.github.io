课程笔记 · 计算机网络

一、概述

本笔记以 OSI 与 TCP/IP 折中得到的五层原理体系结构为组织框架，覆盖计算机网络课程与 408 统考的主体考点，重点集中在数据链路层与网络层，并补充物理层的设备与定理、传输层的连接管理与流量控制。

五层结构自下而上为：物理层 → 数据链路层 → 网络层 → 传输层 → 应用层。发送方数据自上而下逐层封装，接收方自下而上逐层解封装；下层为上层提供服务，各层保持相对独立。

各层职责与主要考点分布如下：

需要牢记的分层判据：

  • 端到端（进程—进程）：传输层。
  • 主机—主机：网络层。
  • 结点—结点（相邻设备）：数据链路层。
  • 比特传输、电路管理、屏蔽物理介质差异：物理层。
  • 流量控制控制发送方速率，属链路层与传输层；拥塞控制针对整个网络，属网络层与传输层。

二、核心知识点

2.1 数据链路层的三个基本问题

数据链路层要解决封装成帧、透明传输、差错检测三个问题。

帧定界：用特定比特/字节模式标记一帧的起止。HDLC 使用标志字段 01111110，PPP 使用 0x7E。

透明传输：数据载荷中若恰好出现与定界符相同的比特串或字节，会被误判为帧边界，因此必须对载荷做转义处理。

  • 零比特填充（HDLC，面向比特的同步链路）：发送方在数据部分每出现连续 5 个 1，立即插入一个 0；接收方每收到连续 5 个 1，就删除其后的一个 0。标志字段本身不参与填充。
  • 字节填充（PPP，面向字节的异步链路）：转义字符为 0x7D。
  • 数据中出现 0x7E → 替换为 0x7D 0x5E（0x5E = 0x7E ⊕ 0x20）；
  • 数据中出现 0x7D → 替换为 0x7D 0x5D（0x5D = 0x7D ⊕ 0x20）；
  • 出现小于 0x20 的 ASCII 控制字符（如 0x03）→ 前插 0x7D，原字节异或 0x20，得 0x7D 0x23。

接收方读到 0x7D 即删除之，并将后一字节异或 0x20 还原。

易错点：PPP 并非一律使用零比特填充——异步链路用字节填充，同步链路才用比特填充；HDLC 始终使用零比特填充。

2.2 差错控制：奇偶校验、CRC 与海明码

编码检错能力纠错能力冗余位
奇偶校验仅能检出奇数个比特错无1 位
CRC全部单比特错、长度 ≤ r 的突发错无r 位（由生成多项式最高次幂决定）
海明码可检出 2 位错可定位并纠正 1 位错r 位，满足 $2^r \ge k+r+1$

CRC 计算四步：

  1. 由生成多项式 $G(x)$ 的最高次幂确定冗余位数 $r$；
  2. 在原始数据后补 $r$ 个 0；
  3. 用模 2 除法（异或运算，无进位无借位）除以 $G(x)$ 对应的比特串，取余数（必须保留 r 位，前导 0 不能省）；
  4. 用余数替换尾部补的 $r$ 个 0，得到发送帧。

接收端将收到的比特串模 2 除以 $G(x)$，余数为 0 判为无错。

关键结论：CRC 只能检错，不能定位出错比特位置，更不能纠错；出错时整帧丢弃，由上层（如 HDLC 的 ARQ）重传。能够定位错误比特位置的是海明码，其校正子直接给出出错比特编号。

2.3 可靠传输：GBN 与 SR

后退 N 帧（GBN）：接收窗口恒为 1，采用累计确认。ACK = n 表示 0 ~ n−1 号帧已全部正确收到，接收方期待 n 号帧。超时后从最早未确认帧开始，把其后所有已发帧全部重传。发送窗口上限 $W_T \le 2^n - 1$。

选择重传（SR）：逐帧单独确认，超时只重传出错的那一帧。约束为

$$W_T + W_R \le 2^n,\qquad W_R \le W_T$$

取最优配置 $W_T = W_R$ 时得 $W \le 2^{n-1}$，即 n 比特序号下 SR 的最大窗口为 $2^{n-1}$。

约束的由来：若 $W_T + W_R > 2^n$，接收窗口的序号会与发送方重传的旧帧序号重叠，接收方无法区分“重传的旧帧”与“新一轮的新帧”，导致重复接收。

协议接收窗口最大发送窗口确认方式超时处理
GBN1$2^n-1$累计确认重传全部未确认帧
SR$W_R \le W_T$$2^{n-1}$逐帧确认只重传超时帧

2.4 PPP 协议与状态机

PPP 是数据链路层的点对点协议，用于串行/拨号链路，帧定界符为 0x7E。链路建立过程为：

静止（Dead）→ 建立（Establish，LCP 协商）→ 鉴别（Authenticate）→ 网络（Network，NCP 协商）→ 打开（Open，传输数据）→ 终止（Terminate）→ 静止

  • LCP（链路控制协议）：协商最大帧长、是否鉴权、采用 PAP 还是 CHAP。LCP 不分配 IP 地址。协商失败直接退回静止。
  • 鉴权：PAP 明文传送账号口令、两次握手，安全性低；CHAP 不传送口令本身，采用挑战—应答、三次握手，安全性高。鉴权失败进入终止状态。
  • NCP（网络控制协议）：配置网络层参数。承载 IP 时具体实现为 IPCP，负责为两端分配 IP 地址。
  • Open 状态才真正传输用户数据。
高频陷阱：LCP 负责链路层参数与鉴权方式，NCP（IPCP）负责分配 IP 地址，二者不可混淆。

2.5 介质访问控制（MAC）

共享介质上多台主机同时发送会产生冲突。MAC 子层的任务就是规定“谁在何时可以发送”。

介质访问控制
├─ 静态划分信道（无冲突，资源预先分配）
│   ├─ FDMA 频分多址
│   ├─ TDMA 时分多址
│   └─ CDMA 码分多址
└─ 动态接入（按需使用）
    ├─ 受控访问：轮询、令牌传递
    └─ 随机访问（竞争，可能冲突）
        ├─ ALOHA
        ├─ CSMA
        ├─ CSMA/CD（有线以太网，碰撞检测）
        └─ CSMA/CA（无线局域网，碰撞避免）

静态划分不会冲突，但资源空闲时被浪费；随机访问灵活，但存在冲突与重传开销。

CDMA 码分多址：所有站点在同一时间、同一频率发送，依靠两两正交的码片序列区分用户。

  • 发送比特 1：发送本用户完整码片序列；发送比特 0：发送码片序列的反码。
  • 接收端用目标用户码片与混合信号做内积：结果为 $+m$ 表示该用户发送 1，$-m$ 表示发送 0，$0$ 表示该用户未发送。

其数学本质与傅里叶变换一致，都是正交基分解：傅里叶以不同频率的正弦函数为正交基，通过积分内积提取某一频率分量；CDMA 以离散的码片向量为正交基，通过向量内积提取某一用户的分量。其他正交基上的分量内积为零，自动抵消。

$$\int \sin(\omega_1 t)\sin(\omega_2 t)\,dt = 0\ (\omega_1 \ne \omega_2) \qquad \boldsymbol{S}_A \cdot \boldsymbol{S}_B = 0$$

2.6 CSMA/CD 与争用期

设 $\tau$ 为单程传播时延，则 $2\tau$ 为往返传播时延，称为争用期（碰撞窗口）。

最坏情形：A 在 $t=0$ 发送，信号经 $\tau$ 才到达最远端的 D；若 D 在 $t=\tau-\delta$ 时检测到信道空闲而开始发送，二者在途中碰撞，碰撞信号再传回 A 需 $\tau$，故 A 最迟在 $2\tau-\delta$ 才能确认碰撞。令 $\delta \to 0$，得最长等待 $2\tau$。

由此得到两条结论：

  1. 帧发出后最多经过 $2\tau$ 即可确定是否发生碰撞；熬过 $2\tau$ 未检测到碰撞，本次发送必定成功。
  2. 最小帧长由争用期决定：

$$\text{最小帧发送时延} \ge 2\tau,\qquad \text{最小帧长} = \text{数据率} \times 2\tau$$

传统 10 Mb/s 以太网 $2\tau = 51.2\ \mu s$，故最小帧长为 $10\ \mathrm{Mb/s}\times 51.2\ \mu s = 64$ 字节；小于 64 字节的帧按冲突碎片丢弃。

二进制指数退避：第 $k$ 次冲突后，取随机整数 $r \in [0,\,2^k-1]$，等待 $r \times 2\tau$ 后重试。最长等待为 $(2^k-1)\times 2\tau$。以太网规定冲突 16 次后丢弃该帧。

现代交换机以太网为全双工、无冲突，CSMA/CD 不再起作用；该机制仅适用于早期共享总线以太网。

2.7 MAC 地址、交换机与以太网帧

MAC 地址：48 比特（EUI-48），固化于网卡 EEPROM，写作 6 组十六进制共 12 个字符。

  • 广播信道（局域网）必须使用 MAC 地址区分接口；点对点信道（PPP）不需要。
  • MAC 地址标识网络接口而非设备：路由器有 4 个网口就有 4 个 MAC。
  • 名为“物理地址”，但属于数据链路层，不属于物理层。
  • 发送顺序：字节按第 1 至第 6 字节顺序发送，字节内先发 b0（最低位）后发 b7。
  • 类型判据看目的地址第一字节最低位 b0：b0 = 0 为单播；b0 = 1 为多播；全 1（FF-FF-FF-FF-FF-FF）为广播。源 MAC 永远是单播地址。

交换机自学习与转发：

  1. 收到帧后，将源 MAC 与入端口写入交换表（自学习）；
  2. 查表匹配目的 MAC：命中则仅向对应端口明确转发；未命中则泛洪，向除入端口外的所有端口转发；
  3. 帧未到达的交换机不学习、不动作。

以太网帧：数据载荷最大 1500 字节（MTU），最小帧长 64 字节，最大帧长 1518 字节（首部 14 + 数据 1500 + FCS 4）。

拓扑与标准：

  • 星形拓扑优点为易于扩展、故障隔离；缺点是线缆用量大、依赖中心设备。10BASE-T 物理拓扑为星形，逻辑上仍是总线以太网。
  • 100BASE-T：100 Mb/s、基带传输、双绞线，单段最大长度 100 m。
  • IEEE 802.2 = LLC 子层；802.3 = 以太网（CSMA/CD）；802.4 = 令牌总线；802.5 = 令牌环。
  • MAC 与 LLC 同属数据链路层的两个子层。

冲突域与广播域：

设备冲突域广播域
中继器 / 集线器（物理层）不隔离不隔离
网桥 / 交换机（链路层）每端口独立，隔离不隔离（未划 VLAN 时）
交换机 + VLAN每端口独立每个 VLAN 独立

2.8 IP 编址：分类、子网划分与 CIDR

分类编址：IPv4 共 32 比特，按前缀比特固定划分网络号与主机号。

类别前缀网络号位数主机号位数首字节范围用途
A08241–126大型网络
B101616128–191中型网络
C110248192–223小型网络
D1110——224–239组播
E1111——240–255保留

只有 A、B、C 类可分配给主机接口；主机号全 0 为网络地址，全 1 为广播地址，均不可分配。127 开头为环回地址。

子网划分：从主机号中借出若干比特作为子网号，网络号本身不变。子网掩码中连续的 1 对应“网络号 + 子网号”，连续的 0 对应主机号，且 1 与 0 必须各自连续。

计算模板：

  1. 判断地址类别，确定原生网络位与主机位；
  2. 将掩码写成二进制，统计连续 1 的个数 $N$；
  3. 子网位数 $n = N - $ 原生网络位数；主机位数 $m = 32 - N$；
  4. 子网数 $=2^n$；每个子网可用主机 $=2^m-2$；
  5. IP 与掩码按位与，得子网网络地址；网络地址 + 块大小 − 1 得广播地址。
-2 永远针对单个子网，扣除本子网的网络地址与广播地址；若有 4 个子网，总浪费为 $4\times 2 = 8$ 个地址，而不是在单个子网内减 8。

CIDR 无分类编址：取消 A/B/C 固定边界，用 /N 直接给出前缀长度。

  • 主机位 $= 32-N$，地址块总数 $=2^{32-N}$，可用主机 $=2^{32-N}-2$。
  • 子网划分使前缀变长（切小），路由聚合使前缀变短（合并为超网）。
  • 聚合的 C 类网个数：前缀每缩短 $d$ 位，可聚合 $2^d$ 个 /24。

FLSM 与 VLSM：定长子网掩码要求所有子网掩码相同、大小相等；变长子网掩码允许各子网长度不同，按需分配以减少浪费。VLSM 的二叉树划分规则是：任一父块一旦切分，必须同时产生两个等大子块，左分支记 0、右分支记 1，已分配子网为叶子，空闲块继续下切；主机位最少保留 2 位（/31 无可用主机）。

最长前缀匹配：多条路由均可匹配目的 IP 时，选择前缀最长者。/32 为特定主机路由（掩码 255.255.255.255），优先级高于默认路由 0.0.0.0/0。

RIP 路由更新五条规则（收到邻居路由后先将距离 +1）：

  1. 同一目的网络且下一跳相同：无条件用新距离覆盖；
  2. 路由表中没有该网络：直接添加；
  3. 下一跳不同且新距离更小：更新；
  4. 下一跳不同且距离相等：两条路由并存，实现负载均衡；
  5. 下一跳不同且新距离更大：不更新。

2.9 IP 数据报与相关协议

IP 首部固定部分为 5 行 × 32 bit = 20 字节，可选字段存在时按 4 字节对齐扩展，最大 60 字节。

行字段
1版本(4) + 首部长度(4) + 区分服务(8) + 总长度(16)
2标识(16) + 标志(3) + 片偏移(13)
3TTL(8) + 协议(8) + 首部检验和(16)
4源 IP 地址(32)
5目的 IP 地址(32)
  • 首部长度字段单位为 4 字节：取值 5 表示 20 字节，取值 15 表示 60 字节。
  • TTL 单位为跳数而非秒，每经过一台路由器减 1，减至 0 则丢弃分组并向源主机发送 ICMP 超时差错报文。初始值 Windows 常为 128，Linux 常为 64。TTL 用于防止路由环路导致分组无限循环；tracert 即利用逐级增大 TTL 触发 ICMP 超时来探测路径。
  • 协议字段：1 = ICMP，6 = TCP，17 = UDP。
  • 首部检验和只校验首部，不校验数据部分；路由器转发时 TTL 减 1 后需重新计算。

网络层协议族：IP 为主干；ICMP 报告差错与查询（封装在 IP 数据部分，传输不可靠，含源抑制拥塞控制）；ARP 完成 IP → MAC 的解析（属网络层）；RARP 完成 MAC → IP（已淘汰，现由应用层的 DHCP 承担）。路由协议中 RIP 基于 UDP、按跳数选路，OSPF 直接封装于 IP、按链路状态计算，BGP 基于 TCP、用于自治系统之间。

两种广播：

类型目的地址路由器行为
受限广播255.255.255.255一律不转发，无法跨越路由器
定向广播某一子网的广播地址默认可以转发，到达目标网段后再广播

路由器的职责：运行路由协议维护路由表；拥塞时合理丢弃分组；对首部做差错校验（但不保证不丢失）；依据目的 IP 查表转发。路由器依据逻辑地址（IP）转发，依据物理地址转发的是交换机；“最佳路由”由度量值（跳数、带宽、时延、代价）决定，不等于时延最小。

端到端传输中地址的变化：IP 分组的源 IP、目的 IP 全程不变；以太网帧的源 MAC、目的 MAC 每经过一台路由器即被重写。跨网段时，源主机填写的目的 MAC 是默认网关接口的 MAC，而非最终目的主机的 MAC。

2.10 传输层：TCP 连接管理与窗口

三次握手（客户端主动发起）：

  1. 客户端 → 服务器：SYN=1, seq=x，进入 SYN-SENT；
  2. 服务器 → 客户端：SYN=1, ACK=1, seq=y, ack=x+1，进入 SYN-RCVD；
  3. 客户端 → 服务器：ACK=1, seq=x+1, ack=y+1，双方进入 ESTABLISHED。

序号消耗规则：SYN 报文不携带数据但消耗 1 个序号；纯 ACK 报文不携带数据时不消耗序号。

四次挥手（客户端主动关闭）：

  1. 客户端 → 服务器：FIN=1, seq=u，进入 FIN-WAIT-1；
  2. 服务器 → 客户端：ACK=1, seq=v, ack=u+1，服务器进入 CLOSE-WAIT，客户端进入 FIN-WAIT-2，此时处于半关闭状态（服务器仍可继续发送数据）；
  3. 服务器数据发完后 → 客户端：FIN=1, ACK=1, seq=w, ack=u+1，服务器进入 LAST-ACK；
  4. 客户端 → 服务器：ACK=1, seq=u+1, ack=w+1，客户端进入 TIME-WAIT，等待 2MSL 后关闭；服务器收到后立即关闭。

FIN 报文同样消耗 1 个序号。TIME-WAIT 等待 2MSL 的两个原因：保证最后一个 ACK 能到达服务器（否则可重发 ACK）；使本连接的残留报文在网络中消失，避免干扰新建连接。

建立连接三次而释放连接四次，是因为握手阶段服务器的 SYN 与 ACK 可合并在同一报文；挥手阶段服务器收到 FIN 后可能仍有数据待发，ACK 与自己的 FIN 不能合并。

发送窗口：

$$\text{发送窗口} = \min(\text{cwnd},\ \text{rwnd})$$

已发送但未确认的数据同样占用窗口额度，故实际还可发送量 $=$ 发送窗口上限 $-$ 已发送未确认字节数。

TCP 首部数据偏移：占 4 bit，单位为 4 字节，取值 5 ~ 15，对应首部长度 20 ~ 60 字节。取 8 时首部为 32 字节，其中选项部分占 12 字节。

三、典型例题 / 关键问答

例 1（HDLC 零比特填充） 数据部分为 0111110001111110，求填充后的比特串。

逐段处理：首段 011111 出现 5 连 1，其后插入 0，得 0111110；中间 000 原样保留；末段 1111110 前 5 位为 5 连 1，插入 0 后为 11111010。拼接结果：

011111 0 000 11111 0 10  →  011111000011111010

要点：只对数据载荷填充，首尾标志字段不填充；口诀为“逢 5 个 1 插 1 个 0”。

例 2（GBN 重传帧数） GBN 发送 0 ~ 7 号帧，收到 ACK0、ACK2、ACK3，未收到 ACK1，超时后需重传多少帧？

ACK3 为累计确认，表示 0 ~ 3 号帧均已正确收到，ACK1 丢失不影响结论。未确认帧为 4、5、6、7，故重传 4 帧。若改为 SR，则需重传 1、4、5、6、7，共 5 帧。

例 3（SR 最大窗口） 帧序号为 3 bit，采用选择重传，发送窗口最大为多少？

$n=3$，$2^n=8$，$W_T+W_R \le 8$，取 $W_T=W_R$ 得 $W \le 2^{n-1} = 4$。

例 4（PPP 字节填充） 原始数据为 0x7E，填充后为 0x7D 0x5E；原始数据 0x7D → 0x7D 0x5D；原始数据 0x03 → 0x7D 0x23。

例 5（二进制指数退避） 10BASE-T 争用时间片 51.2 μs，连续发生 4 次冲突，最长等待时间？

$k=4$，$r_{\max}=2^4-1=15$，$T_{\max}=15\times 51.2 = 768\ \mu s$。干扰项 $16\times 51.2 = 819.2\ \mu s$ 源于误用 $2^k$。

例 6（MAC 地址跨网段） H1（192.168.3.2，MAC 00-1a-2b-3c-4d-52）经路由器 R（左口 192.168.3.1 / 00-1a-2b-3c-4d-51，右口 192.168.4.1 / 00-a1-b2-c3-d4-61）访问 H2（192.168.4.2 / 00-a1-b2-c3-d4-62）。求 H1 发出帧的目的 MAC 与 H2 收到帧的源 MAC。

H1 与 H2 不同网段，H1 只能将帧发给网关，故目的 MAC 为 R 左口 00-1a-2b-3c-4d-51；R 拆帧后重新封装，源 MAC 为自己的右口 00-a1-b2-c3-d4-61。两空依次为 00-1a-2b-3c-4d-51、00-a1-b2-c3-d4-61。IP 全程不变。

例 7（交换机转发表） 2014 统考 34 题：主机 a1、b1、c1 分别接端口 1、2、3，初始转发表含 a1→1、b1→2，不含 c1。a1 向 c1 发数据帧，c1 回确认帧，问两帧的转发端口集合。

第一帧自学习源 MAC a1 已存在，表项不变；查目的 MAC c1 未命中，执行泛洪，除入端口 1 外全部转发，集合为 {2,3}。第二帧从端口 3 进入，学习到 c1→3；查 a1 命中端口 1，仅向端口 1 转发，集合为 {1}。答案为 {2,3} 与 {1}。

该题的常见误判源于课件把 c1 误画进初始转发表，若如此则第一帧会直接单播到端口 3。

例 8（子网划分） C 类网络 218.75.230.0，掩码 255.255.255.192，求子网数与每子网可用主机数。

掩码末字节 192 = 11000000，借 2 位作子网号，主机位 6 位。子网数 $2^2=4$，每子网总地址 $2^6=64$，可用 $64-2=62$。

子网网络地址可用范围广播地址
0218.75.230.0.1 – .62.63
1218.75.230.64.65 – .126.127
2218.75.230.128.129 – .190.191

块大小 $=256-192=64$，子网网络地址依次加 64。判断 IP 218.75.230.70 归属：70 & 192 的末字节运算为 01000110 & 11000000 = 01000000 = 64，属子网 1。

例 9（求广播地址） IP 180.80.77.55，掩码 255.255.252.0，求本子网广播地址。

B 类地址，掩码第三字节 252 = 11111100，借 6 位作子网号，主机位 10 位。块大小 $=256-252=4$，77 向下取 4 的倍数为 76，子网网络地址 180.80.76.0；广播地址为 76+4-1=79，第四字节主机位全 1，得 180.80.79.255。

例 10（CIDR 参数） 地址块 128.14.35.7/20，求地址总数、最小地址、最大地址、可用主机数。

主机位 $32-20=12$，地址总数 $2^{12}=4096$，掩码 255.255.240.0，块大小 $256-240=16$，35 向下取 16 的倍数为 32。最小地址 128.14.32.0，最大地址 128.14.47.255，可用主机 $4096-2=4094$。该块等价于 $2^{24-20}=16$ 个 C 类网。

例 11（VLSM 最小子网） 网络 101.200.0.0/20 划分为 5 个子网，求可能的最小子网可分配 IP 数。

原始主机位 $32-20=12$，总地址 $2^{12}=4096$。二叉对半切分至 5 个叶子：4096 → 2048 + 2048 → 1024 + 1024 → 512 + 512 → 256 + 256，最深叶子深度为 4。最小子网主机位 $12-4=8$，可用 $2^8-2=254$。五个子网可用主机依次为 2046、1022、510、254、254，总和 4086。

例 12（定长子网） 将 21.3.0.0/16 划分为 128 个等长子网，每子网可分配最大 IP 数？

$2^n \ge 128$ 得 $n=7$，新前缀 $16+7=23$，主机位 $32-23=9$，可用 $2^9-2=510$。干扰项 512 为地址总数。

例 13（RIP 更新） D 收到 C 的路由（N2:4、N3:8、N6:4、N8:3、N9:5），各距离先 +1 得 5、9、5、4、6。D 原表为 N1:7(A)、N2:2(C)、N6:8(F)、N8:4(E)、N9:4(F)。

  • N2：同下一跳 C，强制更新为 5；
  • N3：新网络，新增距离 9，下一跳 C；
  • N6：新距离 5 < 8，更新为 5，下一跳改为 C；
  • N8：新距离 4 = 4，两条并存（经 E 与经 C），负载均衡；
  • N9：新距离 6 > 4，不更新。

例 14（TCP 发送窗口） MSS = 1000 B，cwnd = 4000 B，甲已发送 0–999、1000–1999 两段，收到 ACK=1000，且乙通告 rwnd = 2000 B，问还能发送多少字节。

发送窗口 $=\min(4000, 2000)=2000$ 字节，窗口自字节 1000 起算，覆盖 1000–2999；其中 1000–1999 已发送未确认，占用 1000 字节，故还可发送 1000 字节（2000–2999）。

例 15（IP 首部十六进制解析） 首部字节序列：

45 00 00 30  01 9b 40 00  80 06 1d e8  c0 a8 00 08  d3 44 47 50

按每 4 字节切分为 5 个逻辑行：

  • 第 1 行：45 → 版本 4、首部长度 5（即 20 字节，无选项）；00 为区分服务；00 30 为总长度 48 字节，故数据部分 $48-20=28$ 字节。
  • 第 2 行：01 9b 为标识；40 00 中 DF=1（禁止分片），片偏移 0。
  • 第 3 行：80 为 TTL = 128；06 为协议号 TCP；1d e8 为首部检验和。
  • 第 4 行：c0 a8 00 08 → 源 IP 192.168.0.8。
  • 第 5 行：d3 44 47 50 → 目的 IP 211.68.71.80。

若首字节为 46，则首部长度 $6\times 4=24$ 字节，说明含可选字段。

例 17（奈氏准则） 带宽 6 MHz、8 种码元状态、不考虑噪声，求最大数据率。

$$C = 2W\log_2 M = 2\times 6\times10^6 \times \log_2 8 = 36\times10^6\ \mathrm{bit/s}$$

例 18（集线器共享带宽） 10 Mb/s 集线器连接 5 台主机，平均每台可用带宽为 $10/5 = 2$ Mb/s。集线器为共享带宽设备，交换机才是每端口独享。

例 19（综合选择题）

  • 以太网卡地址位数：48 位。
  • IEEE 802.3 最大可传送帧长（数据部分）：1500 个 8 位组。
  • 局域网与广域网互连设备：路由器；仅扩展同一局域网可用集线器、网桥、交换机。
  • 一个 VLAN 对应一个广播域；交换机每个端口对应一个冲突域。
  • 共享总线节点数增加一倍，平均带宽变为原来的一半。
  • 基带 CSMA/CD 中，帧传输时延至少为信号传播时延的 2 倍。
  • TCP/IP 模型中传输层的下一层（网际层）主要功能为路由选择。
  • 关于路由器：支持多种网络层协议并提供分组转换的说法正确；路由器依据逻辑地址转发，不依据物理地址转发。
  • ICMP 描述中“ICMP 消息的传输是可靠的”错误；D 类地址用于组播；同一网络内各主机网络号相同、主机号不同。
  • 分类 IP 分配中“同一网络上每台主机必须有不同的网络号”错误。

例 20（交换机/路由器功能判断） 2012 统考 37 题：路由器可完成“运行路由协议设置路由表”“拥塞时合理丢弃 IP 分组”“依据目的 IP 转发”，但“对 IP 首部校验以确保分组不丢失”不成立——首部校验只能发现错误，可靠性由传输层 TCP 负责。答案选 I、II、IV。

四、小结

  1. 数据链路层的核心是“成帧—透明—检错—控流—接入”五件事。零比特填充与字节填充解决透明传输；CRC 只检错、海明码可纠一位错；GBN 累计确认、整窗重传，SR 逐帧确认、单帧重传，窗口上限分别为 $2^n-1$ 与 $2^{n-1}$。
  2. CSMA/CD 的全部结论都源自争用期 $2\tau$：最长检测时间、最小帧长 64 字节、二进制指数退避的上界 $(2^k-1)\times 2\tau$。
  3. MAC 地址标识接口而非设备，交换机按“源 MAC 学习、目的 MAC 转发、未知则泛洪”工作；冲突域由交换机端口隔离，广播域由 VLAN 与路由器隔离。
  4. IP 编址的三代方案层层递进：分类编址固定边界 → 子网划分向主机位借位（前缀变长）→ CIDR 任意前缀（既可切分也可聚合）。所有计算围绕 $2^{\text{主机位}}$、$2^{\text{主机位}}-2$ 与块大小 $256-$ 掩码字节展开。
  5. 端到端传输中 IP 地址不变、MAC 地址逐跳重写；路由器依据逻辑地址转发，交换机依据物理地址转发。
  6. TCP 的序号消耗规则（SYN、FIN 各占 1 个序号，纯 ACK 不占）与发送窗口 $\min(\text{cwnd},\text{rwnd})$ 减去已发未确认量的计算，是传输层最易失分的两处。
