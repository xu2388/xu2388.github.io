数字图像处理 · 傅里叶变换与频域 · 学习笔记

一、概述

数字图像处理中的灰度变换与频域分析回答两个不同层次的问题：空域点运算只依据像素自身灰度改变明暗分布，用于调整对比度、扩展动态范围；频域分析把图像分解为不同空间频率的正弦分量，用于分离"平缓的背景"与"突变的边缘"，是滤波、压缩、特征提取的共同基础。

本笔记分两部分：第一部分整理灰度变换族（全局线性、分段线性、图像反转、直方图均衡化、直方图规定化）与一阶微分锐化，重点给出可手算的标准步骤；第二部分整理傅里叶变换的定义、频谱概念、典型信号的变换对、卷积定理与采样定理，并落到二维离散傅里叶变换与频域滤波。

二、核心知识点

2.1 灰度变换的基本形式

灰度变换是点运算：$s=T(r)$，$r$ 为输入灰度，$s$ 为输出灰度，输出仅取决于该像素自身灰度，与邻域无关。

全局线性变换：

$$ s=kr+b $$

  • $k=1$：整体平移，灰度范围大小不变，对比度不变；
  • $k>1$：动态范围扩展，对比度增大（如原图 0—100，$k=2$ 后为 0—200）；
  • $k<1$：动态范围压缩，对比度减小，画面发灰。

分段线性变换（三段式）：

$$ s= \begin{cases} \dfrac{c}{a}\,r, & 0\le r\le a\\[8pt] \dfrac{d-c}{b-a}(r-a)+c, & a<r\le b\\[8pt] \dfrac{M_g-d}{M_f-b}(r-b)+d, & b<r<M_f \end{cases} $$

其中 $M_f$、$M_g$ 分别为输入、输出最大灰度。设计思路是给关心的灰度段配置大斜率（拉伸），给不关心的段配置小斜率（压缩）。例如显微镜花粉图像只关心颗粒的中等灰度，就把 $(a,b)$ 段拉伸、暗背景与高亮区压缩。

数值例：$a=20,b=80,c=10,d=240,M_f=M_g=255$。

  • $r=10$：$s=\frac{10}{20}\times10=5$；
  • $r=50$：$s=\frac{240-10}{80-20}(50-20)+10=125$，输入跨度 60 被拉成输出跨度 230；
  • $r=120$：$s=\frac{255-240}{255-80}(120-80)+240\approx243$，输入跨度 175 被压成 15。

图像反转：$s=L-1-r$，8 位图为 $s=255-r$，归一化为 $s=1.0-r$。它是 $k=-1,b=255$ 的线性变换特例，斜率为 $-1$，只颠倒明暗、不改变对比度，细节全部保留。适用于黑色背景中嵌入浅色细节的图像，如车牌、X 光片。16 位图像对应 $s=65535-r$。

I = imread('sag.bmp');   % uint8 矩阵，0~255
I = 255 - I;             % 逐像素反转
figure; imshow(I);

2.2 直方图均衡化

灰度直方图以灰度为横轴、像素数为纵轴。直方图集中在一小段则对比度低，均匀铺满整个区间则对比度高。

目标：寻找变换 $s=T(r)$，使输出直方图尽量接近均匀分布 $P_s(s)=1/L$。

离散公式：

$$ s_k=(L-1)\sum_{j=0}^{k}P_r(r_j)=(L-1)\cdot \mathrm{CDF}(r_k) $$

变换函数是累积分布函数（CDF），因此属于非线性灰度变换。

五步计算流程：

  1. 统计各灰度像素数 $n_k$；
  2. 计算概率 $P_r(r_k)=n_k/N$，$N$ 为总像素数；
  3. 求累积概率 $\mathrm{CDF}(r_k)=\sum_{j=0}^{k}P_r(r_j)$；
  4. 映射 $s_k=(L-1)\cdot\mathrm{CDF}(r_k)$，四舍五入取整；
  5. 建立灰度映射表，逐像素查表替换。

算例：$N=16$，$L=4$（灰度 0—3），$n_0=8,n_1=4,n_2=2,n_3=2$。

$r_k$$n_k$$P_r$CDF$(L-1)\cdot\mathrm{CDF}$取整 $s_k$
080.5000.5001.5002
140.2500.7502.2502
220.1250.8752.6253
320.1251.0003.0003

映射结果为 $0\to2,\ 1\to2,\ 2\to3,\ 3\to3$。原本 4 个灰度只剩 $\{2,3\}$ 两个输出灰度，这正是"灰度级减少、出现颗粒感"的直接来源。

两个特点：优点是扩展动态范围、显著提升对比度；副作用是合并灰度级、产生颗粒感，并可能放大噪声。图像熵增大，信息量增加。

为什么不能得到完全平坦的直方图：像素灰度是离散整数，总数固定，映射后只能整体铺开，无法使每根柱子严格等高；理想均匀分布只在连续模型下成立。

import cv2
img = cv2.imread("test.jpg", cv2.IMREAD_GRAYSCALE)
img_eq = cv2.equalizeHist(img)   # 内部即：统计→CDF→映射→LUT 替换

2.3 直方图规定化（匹配）

均衡化把直方图强制变为均匀分布，不可控；规定化允许用户指定目标直方图 $P_z(z)$，把原图变换为与目标尽量一致的分布。

核心思路：以均衡化为中间桥梁。

  1. 原图均衡化：$s=T(r)=(L-1)\sum_{j\le k}P_r(r_j)$；
  2. 目标直方图均衡化：$v=G(z)=(L-1)\sum_{i\le k}P_z(z_i)$；
  3. 理想情况下 $s=v$，求反函数 $z=G^{-1}(s)$；
  4. 复合映射：$z=G^{-1}[T(r)]$。

离散条件下的两个限制：$G(z)$ 不一定严格可逆，只能取最接近的匹配；输出直方图只能逼近目标，无法完全一致。

from skimage.exposure import match_histograms
out = match_histograms(image, reference)   # reference 的直方图即规定直方图

2.4 一阶微分锐化（梯度）

图像离散，微分用差分近似。梯度幅值精确式为

$$ \|\nabla f\|=\sqrt{[f(x+1,y)-f(x,y)]^2+[f(x,y+1)-f(x,y)]^2} $$

计算题通常用绝对值近似：

$$ g(x,y)=|f(x+1,y)-f(x,y)|+|f(x,y+1)-f(x,y)| $$

水平差分模板为 $[-1\ \ 1]$，垂直差分模板为 $\begin{bmatrix}-1\\1\end{bmatrix}$。梯度大对应灰度突变（边缘），梯度近 0 对应平坦区域。

算例：$5\times5$ 图像，外围灰度 3、中心 $3\times3$ 区域灰度 7。

3 3 3 3 3
3 7 7 7 3
3 7 7 7 3
3 7 7 7 3
3 3 3 3 3
  • $g(0,0)=|f(1,0)-f(0,0)|+|f(0,1)-f(0,0)|=|3-3|+|3-3|=0$；
  • $g(0,1)=|7-3|+|3-3|=4$；
  • $g(1,1)=|7-7|+|7-7|=0$（内部灰度不变）；
  • $g(3,3)=|3-7|+|3-7|=8$（右下边界，两个方向同时跳变）。

输出矩阵：

0 4 4 4 0
4 0 0 4 0
4 0 0 4 0
4 4 4 8 0
0 0 0 0 0

注意：最右列 $x=4$ 无 $x+1$、最下行 $y=4$ 无 $y+1$，差分取 0。梯度算子是一阶微分，与二阶的拉普拉斯算子相区别。

2.5 傅里叶变换的定义

周期信号可用傅里叶级数分解为离散谐波；当周期 $T_1\to\infty$ 时，谱线间隔 $\omega_0=2\pi/T_1\to0$，离散谱过渡为连续谱，级数过渡为积分，即傅里叶变换。

正变换：

$$ X(j\omega)=\int_{-\infty}^{+\infty}x(t)e^{-j\omega t}\,dt $$

逆变换：

$$ x(t)=\frac{1}{2\pi}\int_{-\infty}^{+\infty}X(j\omega)e^{j\omega t}\,d\omega $$

物理意义：把信号分解为角频率为 $\omega$ 的复指数分量，$X(j\omega)$ 表示该频率分量的复振幅（含幅度与相位）。

存在条件（狄利克雷条件，充分非必要）：绝对可积 $\int|x(t)|dt<\infty$；任意有限区间内间断点有限且为第一类间断；极值点有限。

与级数的关系：周期信号既可以写级数（离散谱），也可以代入变换式得到冲激串形式的连续谱，二者信息等价。

2.6 频谱、幅度谱与相位谱

傅里叶变换的结果 $X(j\omega)$ 本身即频谱，是复函数，可写成

$$ X(j\omega)=|X(j\omega)|e^{j\varphi(\omega)} $$

  • $|X(j\omega)|$：幅度谱，表示各频率分量的强弱；
  • $\varphi(\omega)$：相位谱，表示各频率分量的初相。

对实信号，幅度谱为偶函数、相位谱为奇函数。周期信号的频谱是离散谱线，非周期信号是连续谱。

2.7 典型变换对与性质

$$ \delta(t)\longleftrightarrow 1,\qquad 1\longleftrightarrow 2\pi\delta(\omega) $$

$$ \cos\omega_0 t\longleftrightarrow \pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)] $$

$$ \sin\omega_0 t\longleftrightarrow \frac{\pi}{j}[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)] $$

周期冲激串 $\delta_T(t)=\sum_n\delta(t-nT)$ 的变换仍为冲激串，间隔为 $2\pi/T$，幅度为 $2\pi/T$。

周期信号的傅里叶变换：设 $x(t)=\sum_n F_n e^{jn\omega_0 t}$，由 $e^{jn\omega_0 t}\leftrightarrow 2\pi\delta(\omega-n\omega_0)$ 与线性性得

$$ X(j\omega)=2\pi\sum_{n=-\infty}^{+\infty}F_n\,\delta(\omega-n\omega_0) $$

即"周期信号的频谱是位于谐波频率处的冲激串，冲激强度为 $2\pi F_n$"。

对称性与级数系数（实周期信号）：

信号性质消失的分量保留分量
奇函数 $x(-t)=-x(t)$直流 $a_0$、余弦 $a_n$正弦 $b_n$
偶函数 $x(-t)=x(t)$正弦 $b_n$直流、余弦
奇谐 $x(t\pm T/2)=-x(t)$直流、全部偶次谐波奇次谐波
偶谐 $x(t+T/2)=x(t)$全部奇次谐波偶次谐波

奇谐函数偶次谐波为零的证明要点：把 $a_n$ 的积分拆为 $0\sim T/2$ 与 $T/2\sim T$，第二段令 $\tau=t-T/2$，利用 $x(\tau+T/2)=-x(\tau)$ 与 $\cos(n\omega_0\tau+n\pi)=(-1)^n\cos n\omega_0\tau$，得

$$ a_n=\frac{2}{T}\left[1+(-1)^{n+1}\right]\int_0^{T/2}x(t)\cos n\omega_0 t\,dt $$

$n$ 为偶数时方括号为 0，故 $a_n=0$；$b_n$ 同理。

2.8 卷积与卷积定理

$$ x(t)*h(t)=\int_{-\infty}^{+\infty}x(\tau)h(t-\tau)\,d\tau $$

推导思路：把输入 $x(t)$ 切成宽 $\Delta\tau$ 的窄条，每条近似为强度 $x(\tau)\Delta\tau$ 的冲激；LTI 系统对冲激的响应为 $h(t-\tau)$，由线性与时不变性叠加，取 $\Delta\tau\to0$ 即得积分。

常用性质：

$$ f(t)\delta(t)=f(t),\quad f(t)\delta(t-t_0)=f(t-t_0),\quad f(t)*u(t)=\int_{-\infty}^{t}f(\lambda)d\lambda $$

卷积定理：

$$ x(t)h(t)\longleftrightarrow X(j\omega)H(j\omega),\qquad x(t)h(t)\longleftrightarrow \frac{1}{2\pi}X(j\omega)H(j\omega) $$

时域卷积对应频域相乘，这是频域滤波的理论依据：用 $H(j\omega)$ 直接对频谱加权，等效于在空域做卷积。

2.9 采样定理

理想抽样：$x_s(t)=x(t)\cdot\delta_{T_s}(t)$。由频域相乘定理，

$$ X_s(j\omega)=\frac{1}{T_s}\sum_{k=-\infty}^{+\infty}X\bigl(j(\omega-k\omega_s)\bigr),\qquad \omega_s=\frac{2\pi}{T_s} $$

即采样后频谱是原频谱以 $\omega_s$ 为周期搬移、幅度乘以 $1/T_s$ 的复制。若 $\omega_s\ge2\omega_m$（$\omega_m$ 为信号最高频率），各复制谱不重叠，可用理想低通恢复原信号；若 $\omega_s<2\omega_m$，发生频谱混叠，无法无失真恢复。

奈奎斯特条件：$f_s\ge2f_m$，$f_s$ 为采样频率，$f_m$ 为信号最高频率。

2.10 四种傅里叶形式与二维 DFT

形式时域频域特点
FT连续、非周期连续、非周期积分变换
FS连续、周期离散、非周期谐波系数
DTFT离散、非周期连续、周期频谱以 $2\pi$ 为周期
DFS/DFT离散、周期/有限长离散、周期可计算机实现

时域周期化对应频域离散化，时域离散化对应频域周期化，这是四种形式相互转化的对偶规律。

二维离散傅里叶变换：

$$ F(u,v)=\sum_{x=0}^{M-1}\sum_{y=0}^{N-1}f(x,y)e^{-j2\pi\left(\frac{ux}{M}+\frac{vy}{N}\right)} $$

逆变换符号取正并除以 $MN$。实现时常把频谱原点移到图像中心（乘以 $(-1)^{x+y}$ 或用 fftshift），中心为低频、外围为高频。

频域滤波流程：图像 → DFT → 中心化 → 乘以滤波器 $H(u,v)$ → 逆 DFT → 取实部。低通滤波保留低频、抑制高频，起平滑去噪作用；高通滤波抑制低频、保留高频，起锐化边缘作用。理想低通会产生振铃，常用巴特沃斯、高斯等平滑过渡的滤波器。

三、典型例题或关键问答

例 1 8 位灰度图，$r=100$，求反转后的灰度；若为 16 位图，$r=1000$ 时结果是多少？ 解：8 位 $s=255-100=155$；16 位 $s=65535-1000=64535$。

例 2 对 $N=16$、$L=4$、$n_0=8,n_1=4,n_2=2,n_3=2$ 的图像做直方图均衡化，写出映射表并说明灰度级变化。 解：CDF 为 $0.5,0.75,0.875,1.0$，乘 3 后取整得 $2,2,3,3$，映射为 $0\to2,1\to2,2\to3,3\to3$。输出仅剩 2 个灰度级，说明均衡化会合并灰度、产生颗粒感。

例 3 上例中为何不能得到完全平坦的直方图？ 解：灰度为离散整数，映射后多个输入灰度落入同一输出灰度，只能近似均匀；完全平坦仅在连续模型下可实现。

例 4 求 $5\times5$ 图像中 $g(3,3)$ 与 $g(0,1)$ 的梯度值（外围 3、中心 7）。 解：$g(3,3)=|3-7|+|3-7|=8$；$g(0,1)=|7-3|+|3-3|=4$。

例 5 已知 $x(t)$ 为奇谐函数，判断其傅里叶级数中含哪些分量。 解：只含奇次谐波的正弦与余弦项，直流与全部偶次谐波为零。

例 6 信号最高频率 $f_m=3\ \mathrm{kHz}$，求不发生混叠的最低采样频率。 解：$f_s\ge2f_m=6\ \mathrm{kHz}$。

例 7 说明时域卷积定理在图像滤波中的作用。 解：空域用模板卷积等效于频域用 $H(u,v)$ 相乘，可先在频域设计滤波器再逆变换回空域，计算量与滤波特性更易控制。

四、小结

灰度变换以 $s=T(r)$ 统一描述：线性变换调节整体对比度，分段线性变换选择性拉伸目标灰度段，反转只颠倒明暗，直方图均衡化以 CDF 为变换函数自动摊平直方图，规定化以两次均衡化为桥梁实现任意目标分布。离散取整决定了均衡化必然合并灰度、只能近似均匀。

傅里叶变换把信号从时域映射到频域，$X(j\omega)$ 的模与辐角分别给出幅度谱与相位谱；周期信号对应离散谱线，非周期信号对应连续谱。卷积定理把时域卷积化为频域相乘，采样定理给出频谱不重叠的条件 $f_s\ge2f_m$。在图像处理中，二维 DFT 把"平缓区域"集中到低频、"边缘与噪声"集中到高频，低通平滑、高通锐化，构成频域增强的基本范式。
