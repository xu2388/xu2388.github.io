课程与科研笔记

这里把豆包对话里的大一大二专业课复习、以及科研讨论，逐条整理成系统、正式的学习笔记，按学科分组，完整覆盖知识点与结论。

计算机网络（4）

  • 计算机网络 · 系统复习笔记以五层体系结构为纲，系统梳理数据链路层的帧定界、差错控制、可靠传输与介质访问，网络层的IP编址、子网划分、CIDR与路由，以及传输层TCP连接管理与窗口计算等核心考点与典型例题。
  • 计算机网络 · TCP 连接管理与拥塞控制机制以状态机与定时器为主线重写 TCP：先拆首部字段与「序号按字节编号」的语义，再逐段列出三次握手、四次挥手的报文与十一个状态迁移，给出 2MSL 的两条理由与取值口径；可靠传输部分给出 RTT 加权估计的四样本演算与四区窗口模型；拥塞控制给出慢开始、拥塞避免、快重传、快恢复的完整二十轮时间线，并推导 AIMD 下平均窗口为峰值四分之三；末节以首部开销与封装效率对比 UDP。文末附五处原料勘误。
  • 计算机网络 · 子网划分、滑动窗口与协议分层精算只做计算，不复述定性内容。核心结论：存储—转发流水线总时延 T=(N+k−1)t_s+k t_p，980000 字节文件经 3 段链路为 80.16 ms；时延带宽积反推 t_p=D/R；奈氏与香农联立须先把 30 dB 还原为 1000，反解得 V 不小于 31.64 取 32；CRC 对 1101011011 补 4 个 0 后余数 1110；C 类借 n 位后可用地址总和为 256−2^(n+1)，借 2 位得 248 而非 252；片偏移以 8 字节为单位，13 bit 上界对应 65528 字节；SR 窗口取 5 会因序号集合重叠而失效；DNS 迭代查询本地服务器外发最少 0 次、最多 4 次。文末附十二处按定义复核的差异。
  • 计算机网络 · 应用层协议与 DNS 解析流程按「报文语义、连接复用、身份与加密、名字到地址」四条线组织应用层：先列 HTTP/1.1 的方法、状态码与缓存首部，再逐项对照 HTTP/2 的二进制分帧、多路复用与 HPACK，指出它并未消除传输层队头阻塞；Cookie 与 Session 部分给出属性表与服务端会话的分布式困境；HTTPS 部分拆 TLS 1.2 与 1.3 的握手轮次并给出证书链五步校验；DNS 部分区分递归与迭代、列出资源记录与缓存 TTL，并说明 CDN 通过别名与就近调度介入解析。文末以自设口径统计一次页面加载的往返次数。

计算机组成原理（4）

  • 计算机组成原理 · 总线、Cache 与存储层次以总线、Cache、存储层次三条主线组织公式与算例：总线按连接范围分片内、系统、输入输出与通信四类，按传输信息分地址、数据、控制三组线，带宽计算须区分时钟周期与总线传输周期；Cache 给出命中率、平均访问时间、效率三式与两类典型算例，并逐档量化命中率对平均访问时间的影响；另含主从设备判据、三种总线仲裁对照、局部性、三种地址映射与容量换算，并订正原料中单位换算与命中率取整两处错误。
  • 计算机组成原理 · Cache 映射与命中率计算从地址切分出发把 Cache 讲成一套可计算的机制：先由块大小、块数、相联度推出三段地址的位数，再用同一配置对比三种映射的比较器代价；随后以十二条访存序列逐次模拟 FIFO、LRU 与最优替换，命中数为 2、4、6；写策略部分区分写直达与写回、写分配与非写分配，并算出写回带来的额外流量；AMAT 一节给出两级 Cache 的 1.85 ns 与 CPI 由 5.5 降到 2.28 的对照；末节用三个模型量化命中率随容量、块大小、相联度的变化。文末说明与前篇的分工。
  • 计算机组成原理 · I/O 方式与主机信息交换按 CPU 介入的粒度把四种 I/O 方式排成一条线：程序查询逐字节轮询、中断按事件切入、DMA 按块搬运、通道按通道程序自治。先拆开接口的端口与状态位，再用同一组参数算出查询占用率随设备间隔反比变化、中断每字节一百二十五个周期只够零点八兆字节每秒、DMA 搬运一千字节块的开销低到万分之二；随后给出周期挪用的百分之六点二五与磁盘十三点二一毫秒的访问时间，并把中断向量、屏蔽与嵌套讲成可核对的流程。
  • 计算机组成原理 · 总线地址译码与指令执行把总线从「分类」推进到「定时与选通」：先给出三组信号线的方向性与四类总线的层级，再逐拍拆解同步定时的读写的时序与等待周期、异步定时的三种互锁，量化等待周期对有效带宽的削减；随后用同一组 8K×8 芯片分别做全译码、线选与部分译码，列出三张地址表说明冲突与镜像的成因；最后沿 PC、MAR、MDR、IR 的流转写出取指与执行阶段的微操作序列，并以九拍指令周期与五段流水线收束。文末订正原料中算术左移的结论。

操作系统/Linux（5）

  • 操作系统/Linux · 用户权限与 ACL从权限串解码出发，梳理 rwx 在文件与目录上的不同语义、属主/属组/其他三类身份的匹配顺序、chmod 的数字与符号写法、umask 的按位取反推导（含 033 与 027 的逐位复核）、SUID/SGID/粘滞位与四位八进制的换算、进程四类 ID 的取值规则，以及 getfacl 与 setfacl、mask 与默认 ACL 的继承条件，最后落到共享目录的最小权限配置与常见误判。
  • 操作系统/Linux · 进程、线程与作业控制从资源归属与调度单位两条线区分进程和线程，梳理 task_struct 与 R/S/D/T/Z 状态迁移、fork 的写时复制与返回值、exec 换映像、wait 回收退出码，再进入会话与进程组之上的作业控制、常用信号的语义、ps/top/pgrep 的排查路径，以及僵尸、孤儿进程的成因与 Python 多进程在临时目录、共享内存和 CUDA 上的典型故障。
  • 操作系统/Linux · 远程连接与文件传输从 SSH 握手的几个阶段讲起，说明首次连接的主机密钥确认、公钥认证的权限要求与 ssh_config 的写法，再对比 scp、sftp 与 rsync 的能力边界和断点续传、校验做法，并给出跳板机、本地与远程端口转发、VNC 与 RDP 经 SSH 隧道的配置思路，以及断线重连、校验和核对与常见报错的完整排查顺序。
  • Linux 本地存储管理 · 分区、LVM、文件系统与挂载以「磁盘—分区—LVM—格式化—挂载—权限与配额—备份」为主线，系统整理 Linux 本地存储管理：MBR 512 字节引导扇区结构与 GPT 对比、fdisk/gdisk/parted 与 mkfs 系列、LVM 全流程（pvcreate、vgcreate、lvcreate、lvextend 加 resize2fs，PE 默认 4MB）、fstab 六字段与 mount -a 验证、fuser 解除占用、df 与 du 分工、八进制与符号两种权限写法及 umask 推算（含 666 减 033 不等于 633 的实测订正）、quota 软硬限额六步配置、tar 与 crontab 定时备份实操。
  • 操作系统与 Linux 上机 · 进程、权限与 Shell 脚本进程与线程的定义差异、状态字母 R/S/D/T/Z 与四类身份标识、前后台与作业控制、信号与进程终止、用户组的四类账户文件、SUID/SGID/粘滞位的四位八进制推算与 FACL 细粒度授权、Shell 脚本的变量扩展与条件测试及五种流程结构、grep/sed/awk 的典型用法、at/batch/crontab 三类定时、gzip/tar 归档，末附 gcc 编译链与 Makefile 变量展开。最实用：`ps -u`、`jobs` 配 `bg` 与 `fg`、`kill -9`、`setfacl -m`、`test -f`。

数据库/MySQL（7）

  • 数据库与 MySQL · 复习与实操笔记以学生选课数据库的四个实验为主线，梳理 MySQL 8.0 的安装配置与排错、Navicat 图形化操作、建表与约束、触发器、索引与视图、交互式 SQL 查询及用户权限管理，并归纳常见报错的成因与解决办法。
  • 数据库 · SQL 查询、视图、触发器与完整性安全性围绕从查询到安全保护的链条梳理结论：SELECT 子句按 FROM、WHERE、GROUP BY、HAVING、ORDER BY 次序执行，故「不计不及格」只能写在 WHERE、「门数不小于四」只能写在 HAVING；自然连接会匹配并合并全部同名列，两个同名列同时相等才保留，因而李四一行被排除；NOT IN 在子查询含空值时整体返回空集，NOT EXISTS 免疫；「每门课至多 60 人选修」可用断言配 ALL 表达，但 MySQL 不支持断言，须改用 BEFORE 触发器加 SIGNAL 拦截；收回用 REVOKE 加 CASCADE。
  • 数据库 · 事务、并发控制与恢复事务是不可分割的操作序列，ACID 分别由锁与日志支撑。并发带来丢失更新、脏读、不可重复读与幻读，四级隔离级别划定允许范围，三级封锁协议与两段锁保证可串行化，意向锁与间隙锁细化封锁粒度。MVCC 用隐藏事务号与回滚指针串成版本链，由 ReadView 判定可见性。redo 重放已提交修改，undo 支持回滚与旧版本，WAL 要求日志先落盘，恢复按分析、重做、回滚推进。文末对原料结论作限定与勘误。
  • 数据库 · 关系代数与 SQL 互译关系代数与 SQL 是同一件事的形式层与实现层。五种基本运算为并、差、笛卡尔积、选择、投影，交、连接、除均由它们导出。翻译规则可机械执行：选择落 WHERE，投影落 SELECT，笛卡尔积落 FROM 多表，连接落 JOIN ON，并差交由集合运算承担。除运算有两种写法，双重 NOT EXISTS 对应全称语义，分组计数对应包含。外连接补空值，WHERE 与 ON 的位置决定它是否退化为内连接。
  • 数据库 · 函数依赖、候选码与范式分解从函数依赖与 Armstrong 公理切入，梳理完全/部分/传递三个层次，给出属性闭包算法与按 L/R/LR 分类速判候选码的通用步骤；以 F={A→B, A→C, D→A}、F={BCD→A, A→C} 两组字母算例演示候选码由「AD」修正为「D」、由「仅 BCD」补全为「ABD、BCD」；沿 1NF→2NF→3NF→BCNF 逐级给出「在防什么」对照，并用学生-选课-课程与图书-作者-出版社两组语义算例演示保持依赖且无损的 3NF 分解，同时整理 chase 表格法与规范化取舍。
  • 数据库 · 索引原理与查询优化索引以写代价换取定位能力，B+ 树因高扇出、数据集中在叶子、叶子成链而适配磁盘。InnoDB 以主键建聚簇索引，二级索引叶子存主键，取整行需回表，查询列全在索引内即覆盖索引。复合索引按最左前缀匹配，范围列会截断后续列；列上函数、隐式转换、前导通配符是失效写法。IN 与 EXISTS 差别在值匹配与存在判断，NOT IN 遇空值整体为空。执行计划看扫描行数与回表次数，优化是否成立须对照实验验证。
  • 数据库原理 · 关系运算、SQL 查询与权限管理以关系模型的形式化定义为主线，梳理关系、元组、属性、域与候选码、主码、外码的术语层级及三类完整性约束；给出选择、投影、连接、除法的运算对照与五种基本运算的完备性，用象集完整推演 R÷S 得 {201,202} 的算例；归纳「书写时先连接再选择投影最保险、执行层应先选择后投影」的顺序结论，并整理 SQL 侧的等值连接写法、WHERE 与 HAVING 的分工、DELETE、DROP、TRUNCATE 的五项区别与库到行的授权粒度。

JavaWeb（7）

  • JavaWeb · 学习笔记按“页面结构—样式—脚本—数据描述—通信协议—服务器”的顺序，系统整理 HTML/CSS/JavaScript 基础、XML 的 DTD 与 XSD 约束、C/S 与 B/S 架构、HTTP 请求响应报文及 Tomcat 与 Servlet 的运行流程。
  • JavaWeb · JDBC 与 DAO 分层JDBC 是 Java 访问关系型数据库的统一接口，核心是驱动、连接、语句、结果集与资源关闭五件事。DriverManager 每次取连接都要重新建连，DataSource 把连接交给池管理，省掉握手与认证成本。PreparedStatement 用占位符绑定参数，把数据与 SQL 结构分离，既预编译也阻断注入。事务边界应放在 Service 层，DAO 只负责单表读写，连接必须同源，回滚与关闭都要在 finally 或 try-with-resources 中完成。
  • Java IO 流与多线程 · 学习笔记以本科 Java 课程复习为线索，把 IO 流按处理单元（字节流 / 字符流）、流向（输入 / 输出）、角色（节点流 / 处理流）三个维度归位，梳理 `File`、缓冲流、`SequenceInputStream`、管道流、`RandomAccessFile` 与 `PrintStream` 标准流重定向的用法，讲清转换流对中文乱码的处理及 `Serializable`、`transient`、`serialVersionUID` 的序列化规则；多线程部分对比 `Thread` 继承与 `Runnable` 实现两种创建方式，展开 `Callable` 加 `FutureTask` 的带返回值线程、五种状态流转、`sleep`/`yield`/`join`/优先级调度、`synchronized` 同步与 `wait`/`notify` 通信，并补充线程池的通用用法。
  • JavaWeb · Socket 网络编程与简易服务器Socket 是 Java 对一条 TCP 连接的进程内句柄，connect 触发三次握手，accept 返回的已是完成握手的连接。ServerSocket 负责绑定与监听，阻塞式服务器按每连接一线程扩展，受文件描述符、线程栈与上下文切换限制。TCP 只提供字节流，消息边界必须由应用层用分隔符、定长或长度字段划分。BIO、NIO 到 Netty 的演进，本质是把等待方式从阻塞改为就绪通知，并封装事件循环与编解码。
  • Java Swing 实战 · 一个简易浏览器的设计与实现以一个 Java Swing 简易浏览器为线索，串起 GUI、网络编程与项目组织这条实战线。核心结论有三条：其一，界面装配用 BorderLayout 分东南西北中，同一区域重复 add 只会保留最后一个；其二，只有事件分发线程（EDT）能改 UI，所有网络与文件耗时操作放进 SwingWorker 的 doInBackground，在 done 里回 EDT 更新；其三，JEditorPane 只支持 HTML 3.2，不执行 JS、不认 CSS3，大量现代网页渲染不出来是能力边界而非代码缺陷。此外还整理了 HttpURLConnection 的超时与字符集处理、前进后退的双栈与索引两种实现，以及中文乱码、构造期空引用等真实踩坑。
  • Java 数组·字符串·正则 · 自测题整理原始对话标题为「物理帮帮棒」，实际内容为 Java 数组、字符串与正则表达式单元自测的完整题目提取、答案订正与逐题解析。
  • Java 面向对象 · 继承、多态、异常与集合泛型梳理 Java 面向对象主线：构造器与 this/static 取值规则、四级访问控制、重写四条约束（签名一致、协变返回、受检异常不得更宽、访问权限不得更严）、多态「编译看左边、运行看右边」与 instanceof 向下转型、abstract 与 interface 成员差异、final 引用不可变与内容可变之辨、四类内部类；给出 Throwable 体系、finally 先于 return 交付、try-with-resources 的 close 先于 catch 等执行序结论；集合与泛型覆盖 Collection/Map 双体系、Map.put 返回被覆盖旧值、Iterator 独占删除、类型擦除与通配符 PECS 原则。

数据结构与算法（6）

  • 最短路、传递闭包、哈希表与栈队列 · 算法与数据结构（二）以原料算例为线索，逐步跑通 Dijkstra 的每轮选点与松弛、Floyd 的三重循环与矩阵快照、Warshall 的布尔矩阵迭代，并给出链地址法与公共溢出区两种散列表实现、装填因子与平均查找长度公式，最后落到循环队列判满判空的三种方案与括号匹配、中缀转后缀求值的完整代码。
  • 数据结构与算法 · 排序与查找方法对比以八种内部排序的复杂度与稳定性总表为主线，比较插入、希尔、冒泡、快速、选择、堆、归并和基数排序的适用场景；逐步演示快速排序的中间元素枢轴划分与最坏情况、大根堆的建堆插入删除和堆排序；再讨论折半查找判定树的高度与成功失败平均查找长度、分块查找的组织方式，以及散列表与折半查找在有序性、时间复杂度和适用范围上的取舍。
