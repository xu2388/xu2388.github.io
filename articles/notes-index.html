课程与科研笔记

这里把豆包对话里的大一大二专业课复习、以及科研讨论，逐条整理成系统、正式的学习笔记，按学科分组，完整覆盖知识点与结论。

计算机网络（1）

  • 计算机网络 · 系统复习笔记以五层体系结构为纲，系统梳理数据链路层的帧定界、差错控制、可靠传输与介质访问，网络层的IP编址、子网划分、CIDR与路由，以及传输层TCP连接管理与窗口计算等核心考点与典型例题。

数据库/MySQL（1）

  • 数据库与 MySQL · 复习与实操笔记以学生选课数据库的四个实验为主线，梳理 MySQL 8.0 的安装配置与排错、Navicat 图形化操作、建表与约束、触发器、索引与视图、交互式 SQL 查询及用户权限管理，并归纳常见报错的成因与解决办法。

JavaWeb（2）

  • JavaWeb · 学习笔记按“页面结构—样式—脚本—数据描述—通信协议—服务器”的顺序，系统整理 HTML/CSS/JavaScript 基础、XML 的 DTD 与 XSD 约束、C/S 与 B/S 架构、HTTP 请求响应报文及 Tomcat 与 Servlet 的运行流程。
  • Java 数组·字符串·正则 · 自测题整理原始对话标题为「物理帮帮棒」，实际内容为 Java 数组、字符串与正则表达式单元自测的完整题目提取、答案订正与逐题解析。

数据结构与算法（2）

  • 算法与数据结构 · 学习笔记梳理堆的结构与 O(log n) 复杂度来源、C++ priority_queue 的模板参数与堆化实现、AVL 平衡因子、二分查找三种区间写法，以及 0-1 背包的 DFS 与滚动数组优化。
  • 蓝桥杯 · 典型题解与算法整理整理蓝桥杯赛制层级、2025 年第十六届各项赛事的时间与报名规则，并归纳省赛软件赛的备赛范围与常见算法模板要点。

深度学习/神经网络（1）

  • 循环神经网络语言模型（RNN-LM）· 学习笔记以“预测下一个词”为主线，梳理 RNN 语言模型的结构与交叉熵损失、Seq2Seq 编码器—解码器与注意力机制、束搜索与温度采样等解码策略、集成学习与训练流程，并说明其与 GPT 的演进关系。

大数据技术（1）

  • 大数据技术原理与应用 · 复习笔记系统梳理 Hadoop 的起源与五大特点、HDFS 主从架构与读写流程、MapReduce 1.x 四组件与 Shuffle 全流程，并附教材填空题、判断题、简答题的标准答案。

信号与系统（1）

  • 信号与系统 · 复习笔记以单位阶跃与单位冲激为主线，整理基本奇异信号的定义、微积分关系、筛选与尺度性质、复合阶跃化简及典型计算，并给出易错点与规范例题。

数字图像处理（1）

  • 数字图像处理 · 傅里叶变换与频域 · 学习笔记从灰度变换与直方图处理出发，系统整理线性与分段线性变换、图像反转、直方图均衡化与规定化的计算流程，并梳理傅里叶变换、频谱概念、卷积定理、采样定理与二维频域处理的基本框架。

英语/雅思（2）

  • 英语 · 学习笔记以“词—句—篇”为线索，系统整理高频学术词汇的释义与搭配、易混词辨析、构词规律、课文精读与长难句译法，并以全国大学生英语竞赛大作文为例归纳立场型议论文的写作框架与高级词汇替换方案。
  • 英语词汇与语法填空 · 学习笔记系统整理选词填空（十五选十）与语法填空的解题流程、词性判定方法、备选词库精讲、构词与词形变化规律，并以真题空格为例演示“词性—语法—语义—搭配—复查”的五步推理与逐项排除过程。

思政/毛概/近代史（3）

  • 思政实践报告 · 写作要点整理系统整理思政综合实践课实践报告的格式规范、结构要件、正文“调研结果—积极特征—问题与原因—对策建议”的写作逻辑、日志与访谈附录的编排方法，以及查重与 AIGC 检测等提交合规要求。
  • 毛泽东思想和中国特色社会主义理论体系概论 · 复习笔记以“毛泽东思想—新民主主义革命—社会主义改造—建设道路探索—中国特色社会主义理论体系”为时间轴，系统梳理各阶段的核心概念、标志著作、会议节点与高频选择题考点，并归纳易混问题的辨析标准。
  • 中国近现代史纲要 · 口述史作业与复习围绕口述史作业的全流程，整理选题与访谈对象确定、提纲设计、伦理规范、转录整理、报告结构与史料互证方法，并附中国近现代史分期坐标，使个体记忆能够被准确定位于宏观历史进程之中。

虚拟染色/科研（10）

  • DCLGAN（双对比学习无配对翻译）· 论文解读DCLGAN 以对偶双向生成器配合两套域独立的编码器与投影头，用多层 PatchNCE 替代循环一致性约束，并通过域内相似度损失构成 SimDCL 变体，解决单嵌入难以建模域间鸿沟与语义分割任务的模式崩溃问题。
  • ODA-GAN（正交解耦对齐）· 方法梳理ODA-GAN 以冻结 UNI 与 Grad-CAM 产生弱监督掩膜，用 O-MLP 将病理特征正交拆为染色相关与形态相关两支，再以对抗损失、双流 PatchNCE 与多层 MMD 域对齐共同训练，实现无配对 H&E→IHC 虚拟染色。
  • 医学图像染色转换 · 相关工作综述按监督强度与约束空间将 H&E→IHC 虚拟染色的现有工作归为全监督像素回归、无配对对比学习、弱配对错位鲁棒、病理语义保持、物理浓度域建模与评测基础设施六族，逐族梳理代表工作、核心机制与优缺点，并归纳可引用的对比链与研究空位。
  • 基于分数的无配对虚拟组织学染色 · 方法梳理MIU-Diff 以全局互信息引导的能量函数在表征空间分离组织结构与染色特征，配合时间步定制的反向扩散实现染色强度可控，并以局部互信息对比学习约束细胞级结构一致，从而在无配对 H&E–IHC 数据上完成虚拟染色。
  • 多尺度注意力机制 · 论文论述与整理梳理多尺度注意力的综述与理论文献脉络，逐层推导 Haar 小波变换的卷积化实现（正/逆变换与正交性），并以 SegNeXt 的 MSCA 为例说明多分支带状深度卷积如何在 O(n) 复杂度下同时获得多尺度感受野与空间注意力。
  • 对比学习与 CUT：无配对染色翻译的结构保持 · 研究笔记从 InfoNCE 出发梳理 PatchNCE 与 CUT 的单侧无配对翻译框架，说明其在病理 H&E→IHC 任务中如何以块级对比约束组织结构，并讨论 ASP 自适应监督、DAB 浓度与梯度边界三类互补监督，以及由 GAN 迁移至光密度域扩散的可行路径。
  • 服务器、训练与实验 · 长对话整理记录 HE→IHC 虚拟染色浓度域扩散模型的服务器训练与诊断过程，梳理噪声调度的四类问题及代表性文献，报告时间步损失诊断的实测结果（早期损失仅为晚期的 0.28 倍）、Beta(2,2) 重采样实验的损失轨迹，并据此修正研究假设、确定 M0→M1→M2 的分阶段路线与论文叙事。
  • H&E→IHC 浓度空间 Diffusion 的最小可运行实现 · 研究笔记以比尔-朗伯定律为物理基础，把 H&E 与 IHC 分解为染料浓度图，仅在 DAB 浓度通道上做条件扩散并以 H/E 浓度作为干净条件，最后经染色矩阵回投重建 IHC RGB，据此设计可判定该路线是否成立的最小基线 M0。
  • 虚拟染色关键论文精读（含 PSPStain）· 整理对 PSPStain、MisalignResistantVS（DGR）、StainBridge 三篇工作逐篇梳理问题、方法、贡献与局限，并据 PSPStain 的摘要级材料复原其 PALS 与 PCLS 两个模块的设计逻辑与实测指标。
  • 论文写作与研究内容 · 长对话整理围绕《国家安全教育》课程论文，从总体国家安全观的理论框架出发确立"具身智能安全风险传导与协同治理"选题，逐节完成摘要、引言、文献综述与四章正文，并系统梳理论文格式、参考文献著录与语言规范，其间反复暴露并修正了案例真实性与文献可核查性问题。
