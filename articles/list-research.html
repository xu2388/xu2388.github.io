  • 虚拟染色要解决的到底是什么：一份问题地图与评价口径的自我审查2026-10-27虚拟染色问题定义评价口径H&E→IHC在进入方法迭代之前，先把「虚拟染色」与「风格迁移」的边界划清，把任务拆成六个可分别攻关的子问题，并质疑当时主流的下游分割评价口径——分割器各有泛化差异，换一个模型结论就翻转。评价最终改为 FID、SSIM、DAB 相关性与 H-score 分级四类口径，这张问题地图直接决定了其后三次归因（023–025）的走向。

  • 当模型输出「平均 IHC」：指标上升与表达坍缩2026-10-27虚拟染色模式坍缩评价口径PSNR区域统计损失某个配置把 PSNR 从 16.14 拉到 19.40（+3.26 dB），看似成功——但 D/H 从 0.976 掉到 0.339、阳性率从 0.001 掉到 0.009，指标上升是用「整体压淡」换来的。全量 796 张的逐图统计显示：真值 D/H 的 IQR 宽 0.767，模型只有 0.037；真值跨度 4.5 倍，模型 1.14 倍。模型不是每张图偏一点，而是对所有输入输出同一个「平均 IHC」。本文记录这套骗人的指标是怎么被拆穿的，以及此后「中位数 + IQR 宽度必须同报」的评价纪律。
  • 频域能约束什么：一次概念纠错与位置约束的边界2026-10-27虚拟染色频域分析概念澄清负结果AI 提出的「伊红能量在低频、DAB 能量在高频，所以 H&E→IHC 存在能量搬迁」被笔者反驳：两张图各自的统计只说明各有频率特点，不能说是能量被重新分配——帕塞瓦尔定理只保证同一幅图内守恒，不保证两图之间守恒。进一步：幅度谱对平移几乎不敏感，频域对空间位置几乎没有约束力，只能约束纹理尺度；要约束位置必须引入相位或空间域手段。附 FFT 损失失败的负结果记录。
  • 从 OD 到 FOD：蛋白表达的物理量谱系与一条设计路线2026-10-27虚拟染色光密度FODH-score约束设计把蛋白表达的物理量按来历排成谱系：Beer–Lambert 定律（Lambert 1760、Beer 1852）→ 吸光度 / OD（光谱学成熟量）→ 1980 年代起用于定量免疫组化 → Ruifrok & Johnston 2001 色解卷积 → PSPStain 2024 提出 FOD = OD^α。看清这条线后，「设计一个新约束」的合理工作路线浮现出来：不是发明物理，而是把成熟科学量改写成适合优化的形式。同时记录笔者当时对「物理精转换 + 粗略统计约束」的自我批判，以及把 H-score 做进损失的风险分析。
  • 条件注入还是约束引导：扩散结构保持的两条路2026-10-27虚拟染色扩散模型条件注入约束引导未收敛扩散主干学的是噪声预测 ε，在含噪状态上挂辅助损失会与主损失抢梯度——这个判断把结构保持的方案推向条件注入；但随后又被自己推翻：条件注入只能带进信息、带不进约束，结构保持可能需要 restrict / guidance。中间夹着一次多层条件注入实验的完败（六项指标全线变差）。本文完整记录这个「支持 → 否定 → 未收敛」的反复，不抹平，也不假装有结论。
  • 浓度域双模型：蛋白后验与物理真实的两处拟合2026-10-27虚拟染色扩散模型方案设计蛋白后验未完成的实验一个把「蛋白表达」与「物理真实」拆开拟合的方案：A 模型用 PSPStain 生成的伪配对数据学习蛋白表达条件（后验的代理），B 模型用真实 IHC 拟合浓度空间的物理分布。方案设计完成、A 模型的监督定义被严格钉死（学的是 PSPStain 派生的条件分布，不是临床真实蛋白定量），但实验未跑成——随后主线转向 PSPStain 2 通道 GAN。本文按「方案设计」记录，并如实标注完成度。

  • 潜空间扩散该预测什么：从 x-prediction、流匹配到病理模态转移的表示改造2026-10-25扩散模型潜空间流匹配x-prediction虚拟染色潜空间扩散有三个可独立改动的旋钮：表示空间、预测目标、条件注入。ε、x₀、v 只是同一目标在不同噪声水平上的加权差异，三者对 x₀ 误差的隐含加权之比为 α²:1:σ²；x₀-预测在原生像素上可行靠的是流形假设，潜空间压缩掩盖而非解决容量问题。而病理模态转移缺配对切片，目标模态作条件只能约束分布、给不出像素级对应，前两个旋钮的改造因此无法单独兑现。原料中的论文编号与指标已逐条联网核实，不符者列入勘误。

  • UMDST：无监督多染色图像转换的统一框架 —— 论文精读2026-10-25论文精读虚拟染色染色转换无监督肾脏病理针对肾脏病理「每种染色对各建一个模型」的成本困境，UMDST（AAAI 2022）用单一非配对 GAN 同时支持 H&E、MAS、PAS、PASM 四种染色之间的任意转换：风格引导归一化（SGN）以目标域风格仿射因子平衡内容与风格，多风格编码（MSE）把染色标签映射为可学习风格码，改进独热标签（δ=0.05）进一步解锁混合染色与对比度调节；ANHIR 数据集上 CSS 达 0.682 / 0.674 / 0.600（MAS / PAS / PASM），五位病理医生评分 ER=4.4（与 UGATIT 持平）。
