MBTI 连续人格空间研究管线（阶段总览）

研究 · 豆包上传 · 2026-09-14
来源这是我做的一个研究项目——MBTI 连续人格空间与分布建模的阶段总览图，从豆包上传记录里原样恢复。核心链路 X → Z_attr → Z_neural → P(Z|M) → P(A|S,Z)，中间设 6 道阶段闸门，每一步不达标就不往下走。完整的数学结构与方案在下面的 agent 会话存档里。
MBTI 连续人格空间研究管线（阶段总览）
X → Z_attr → Z_neural → P(Z|M) → P(A|S,Z)，中间设 6 道阶段闸门
阶段 0–1 · 立项与数据准备
登记假设 H1–H4（四维非独立 / 维度＞4 / 类型内异质 / Z 优于 M）→ 数据字典 → 清洗（重复/无效/缺失/直线作答）→ 按题型编码 → 产出干净的 N×D 逐题矩阵
↓
Gate 1 数据闸门：无逐题数据 → 不训练任何模型
↓
阶段 2 · MBTI 四维依赖分析
16 类联合分布 P(E,N,T,J) vs 完全独立模型 → 6 个二阶依赖（χ²/Cramér's V/OR/MI）→ 条件互信息 → 三/四阶交互 → Log-linear 模型比较 → Bootstrap + 置换检验。回答：四维到底独不独立
↓
Gate 2 统计闸门：未完成四维分析 → 不进高维建模
↓
阶段 3 · 题目级人格属性挖掘（3A–3X，全项目核心中间层）
① 题目质量（均值/方差/偏度/熵）→ 相关矩阵 → PCA → 平行分析定因子数
② EFA（Oblimin/Promax 斜交旋转）→ 载荷 → 交叉载荷 → 信度（α/ω）→ IRT 逐题信息量
③ 题目语义 embedding → 语义聚类 → 「统计空间 × 语义空间」双空间对齐
④ 形成候选属性（统计+语义+信度+稳定四重证据）→ 多人独立命名验证
⑤ 输出连续属性分数 Z_attr（因子分数 / IRT θ / 加权分三种）→ 标准化
⑥ 属性间依赖图（偏相关网络/贝叶斯网）→ P(Z_k|M) 分布比较 → 类型内异质性（GMM/HDBSCAN）→ 跨源稳定性 + 因子匹配 + 测量不变性
↓
Gate 3/4 心理测量闸门 + 属性闸门：无稳定可解释属性 → 不声称发现「人格属性」
↓
阶段 4–5 · 属性数据集 + 深度前基线
阶段4：汇总成 person × MBTI × attr_1..K 属性表；阶段5：先跑 5 个基线（16类 one-hot / 四维分数 / 因子分数 / IRT θ / Z_attr），作为深度模型的对照
↓
阶段 6–11 · 神经表示学习
AE（证明可低维重构）→ VAE（β=1 起，扫 0.1–4）→ β-VAE 解耦 → 潜空间相关性解释 → 线性探针（验证可解释信息真的在 latent 里）→ 潜变量干预（只动 z_k，看是否稳定改变某一属性）
↓
Gate 5 深度模型闸门：VAE 必须赢过 PCA/EFA/IRT/简单 AE，否则说明不了贡献
↓
阶段 12–14 · 条件分布与对照基线
CVAE 建模 P(Z|M)，采样观察 16 类的均值/方差/重叠/多峰 → 比较 one-hot vs 连续 MBTI vs Z_attr vs Z_neural 的信息损失 → 引入 Big Five 作强基线，看 MBTI 表示是否提供增量信息
↓
阶段 15–17 · 行为验证
收集「同一人回答多个情境」的行为数据 → 训练 P(A|S,Z)（情境编码+人格编码+决策头）→ 对比 P(A|S)、P(A|S,M)、P(A|S,Z_attr)、P(A|S,Z_neural)。只有 Z 显著优于 M，才支持连续空间有增量行为解释力
↓
Gate 6 行为闸门：Z 没有明确增益 → 不投入 CLIP / LLM / RL
↓
阶段 18–22 · 进阶扩展（后期，非 MVP）
对比学习增强表示 → Normalizing Flow（密度估计）→ Diffusion 生成 P(Z|M)（MMD/Wasserstein 检验）→ 多模态 P(Text|Image,Z) 同图异人格对照 → RL 智能体 π(a|s,z)，比较不同人格的策略分布差异
